Semantics of Propositional Logic

Semantics defines the meaning of sentences — specifically, how to determine whether a sentence is true or false in a given model.

Model in Propositional Logic
Model = assignment of True/False to every propositional symbol
Number of models = 2n where n = number of distinct propositional symbols
Atomic Sentence Semantics
True is always True. False is always False. A symbol P is True if P is assigned True in the model.
Complex Sentence Semantics
Defined recursively based on the main connective: truth tables for ¬, ∧, ∨, ⇒, ⇔
Example: A Model for Wumpus World

With symbols P₁,₂, P₂,₂, P₃,₁ (three pit locations), a model could be:

m = { P₁,₂ = True, P₂,₂ = False, P₃,₁ = True }

This means: "There IS a pit in [1,2], NO pit in [2,2], and there IS a pit in [3,1]"

Note: models are abstract mathematical entities. P₁,₂ = True doesn't mean [1,2] is a specific room — it means the proposition "pit in [1,2]" is true in this possible world.

Key Insight: In propositional and first-order logic, every sentence is either true or false in each possible world — there is no middle value. Fuzzy logic allows degrees of truth, but classical logic is bivalent (two-valued).

KB as Conjunction

The Knowledge Base (KB) is treated as the conjunction of all its sentences:

KB Semantics
KB = S₁ ∧ S₂ ∧ ... ∧ Sₙ
A model satisfies the KB if and only if ALL sentences in the KB are true in that model.

When we ask whether KB ⊧ α, we are asking: in every model where all sentences of KB are true, is α also true?

Memory Aid for Implication

Implication Intuition
P ⇒ Q ≡ ¬P ∨ Q
"If P is true, then Q must be true. If P is false, the implication imposes no requirement." This equivalence explains the truth table: ¬P ∨ Q is false only when P=True and Q=False.

Memory Aid for Biconditional

Biconditional Intuition
P ⇔ Q ≡ (P ⇒ Q) ∧ (Q ⇒ P)
"P if and only if Q" means both directions hold. This is why P⇔Q is true exactly when P and Q agree.

Recursive Sentence Evaluation

The truth value of any complex sentence can be computed recursively from the truth values of its atomic parts.

Recursive Evaluation Rules
function PL-True(sentence, model) returns true or false if sentence is True: return true if sentence is False: return false if sentence is a symbol: return model[symbol] if sentence is ¬α: return not PL-True(α, model) if sentence is (α ∧ β): return PL-True(α, model) AND PL-True(β, model) if sentence is (α ∨ β): return PL-True(α, model) OR PL-True(β, model) if sentence is (α ⇒ β): return (not PL-True(α, model)) OR PL-True(β, model) if sentence is (α ⇔ β): return PL-True(α, model) == PL-True(β, model)
This recursive definition is the formal semantics of propositional logic.
Example: Step-by-Step Evaluation

Sentence: True ∧ (False ∨ True)

Model: Not needed — this sentence contains only constants

Result: True

XOR (Exclusive Or)

While ∨ denotes inclusive OR (at least one), sometimes we need exclusive OR (exactly one is true):

XOR Definition
P ⊕ Q = (P ∨ Q) ∧ ¬(P ∧ Q)
P XOR Q is true when exactly one of P, Q is true. It is false when both are true or both are false.
PQP ∨ Q (Inclusive)P ⊕ Q (Exclusive)

Important: Propositional logic does NOT have a built-in XOR connective. XOR is expressed as a combination of AND, OR, and NOT. The difference matters: "Coffee or tea?" (inclusive: can have both) vs "The cake is either in the fridge or in the oven" (exclusive: can't be in both).

Implication Truth Table: Intuition

The implication P ⇒ Q is often confusing. Here's the intuition:

PQP ⇒ QIntuition
TrueTrueTrue The premise holds and the conclusion holds — the implication is satisfied
TrueFalseFalse The premise holds but the conclusion fails — the implication is violated (counterexample)
FalseTrueTrue The premise doesn't hold — we can't test the conclusion, so we consider the implication "vacuously true"
FalseFalseTrue Same as above: the premise doesn't hold, so the implication is vacuously true
Why is "If P then Q" true when P is false?

Consider the sentence: "If it is raining, then the ground is wet" (Rain ⇒ Wet).

On a sunny day (Rain = False), is this sentence true?

  • The sentence is a claim about what happens when it rains
  • On a sunny day, the claim is not tested — we cannot falsify it
  • We consider it true because no counterexample exists

Similarly: "If 5 is even, then Sam is smart" is true (vacuously) regardless of Sam's intelligence — because 5 is not even, the condition never applies.

Key Property
If P is false, P ⇒ Q is ALWAYS true
This is called "vacuously true" or "trivially true." It matches mathematical convention: "If x > 2, then x² > 4" is true even for x=1 (since the antecedent is false).

Evaluation Examples

Example 1: Wumpus World Breeze Rule Evaluation

Sentence: B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁)

Model m: {B₁,₁ = False, P₁,₂ = False, P₂,₁ = False} (no breeze, no pits in adjacent rooms)

StepExpressionValue
1P₁,₂ ∨ P₂,₁False ∨ False = False
2B₁,₁False
3False ⇔ FalseTrue (they agree)

Result: True — the model is consistent with the breeze rule.

Example 2: Inconsistent Model

Same sentence: B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁)

Model m: {B₁,₁ = True, P₁,₂ = False, P₂,₁ = False} (breeze but no pits?)

StepExpressionValue
1P₁,₂ ∨ P₂,₁False ∨ False = False
2B₁,₁True
3True ⇔ FalseFalse

Result: False — this model violates the breeze rule (breeze without a pit is impossible in Wumpus World).

Example 3: Complex Knowledge Base Evaluation

KB: ¬B₁,₁ ∧ B₂,₁ ∧ (B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁)) ∧ (B₂,₁ ⇔ (P₁,₁ ∨ P₂,₂ ∨ P₃,₁)) ∧ ¬P₁,₁

Model m: {B₁,₁=False, B₂,₁=True, P₁,₁=False, P₁,₂=True, P₂,₁=False, P₂,₂=False, P₃,₁=True}

ComponentEvaluation
¬B₁,₁¬False = True
B₂,₁True
B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁)False ⇔ (True ∨ False) = False ⇔ True = False

This model violates the first breeze rule! B₁,₁ is False but (P₁,₂ ∨ P₂,₁) is True. So KB is False in this model.

Result: KB is false — this model is not a model of the knowledge base.

Example 5: Checking Entailment via Semantics

Question: Does (P ⇒ Q) ∧ P ⊧ Q?

KB: (P ⇒ Q) ∧ P

Query α: Q

PQP ⇒ QKB = (P ⇒ Q) ∧ P
FFTF
FTTF
TFFF
TTTT

KB is true in exactly one model: {P=True, Q=True}. In this model, Q is also True. Therefore, in all models where KB is true, Q is true → KB ⊧ Q.

Answer: Yes, (P ⇒ Q) ∧ P ⊧ Q (this is Modus Ponens)

Example 6: XOR in Wumpus World

Situation: After visiting [1,1] (no breeze), the agent knows there is no pit in [1,2] or [2,1]. After visiting [2,1] (breeze), the pit is in [2,2] or [3,1]. After visiting [1,2] (no breeze), [2,2] has no pit. So the pit must be in [3,1].

This can be expressed as:

(Pit₂,₂ ⊕ Pit₃,₁) ∧ ¬Pit₂,₂ ⇒ Pit₃,₁

Where ⊕ is exclusive OR (exactly one is true).

Semantics check: In model m = {Pit₂,₂ = False, Pit₃,₁ = True}:

  • Pit₂,₂ ⊕ Pit₃,₁ = False ⊕ True = True (exactly one true)
  • ¬Pit₂,₂ = True
  • Premise: True ∧ True = True
  • Conclusion Pit₃,₁ = True
  • Implication: True ⇒ True = True ✓

The model confirms: the pit is indeed in [3,1].
