Problem Setup

The 0-1 Knapsack problem: given n items each with a weight and value, and a knapsack with capacity W, choose items to maximize total value without exceeding capacity. Each item can be taken at most once (0-1).

Available items:

Item 1: w=2, v=12  |  Item 2: w=1, v=10  |  Item 3: w=3, v=20  |  Item 4: w=2, v=15

Knapsack capacity: W = 5

Recurrence

dp[i][w] = max(dp[i-1][w], dp[i-1][w-wᵢ] + vᵢ)

dp[i-1][w]  = value if we skip item i (best using prior items at full capacity)
dp[i-1][w-wᵢ] + vᵢ  = value if we take item i = (best using prior items with w-wᵢ capacity) + item i's value
dp[i][w]  = max value using first i items with capacity w

Base: dp[0][w] = 0   (no items = no value)
