🎓 Prim's Algorithm

Prim's algorithm finds a Minimum Spanning Tree (MST) by growing a tree from a starting vertex, always adding the cheapest edge from the tree to a vertex not yet in the tree.

📜 How It Works

key[v]: minimum weight of any edge connecting v to the current tree. Starts at ∞.

π[v]: parent of v in the growing MST tree. Starts at NIL.

Q: min-priority queue of all vertices not yet in the tree, keyed by key[v].

📖 Pseudocode

Prim(G, w, r):

1. For each u ∈ V: u.key = ∞, u.π = NIL

2. r.key = 0, Q = V

3. While Q ≠ ∅:

u = EXTRACT-MIN(Q)

For each v ∈ Adj[u]:

if v ∈ Q and w(u,v) < v.key:

v.π = u, v.key = w(u,v)

DECREASE-KEY(Q, v, v.key)

4. Return A = {(v, v.π) : v ∈ V − {r}}
