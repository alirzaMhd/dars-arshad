Intelligent Backtracking — Backjumping

Smarter Backtracking Using Conflict Sets

The Problem with Naive Backtracking

Standard backtracking (chronological backtracking) always returns to the most recent variable when it reaches a dead end. But this is often wasteful.

Example: Wasted Backtracking

Assignment order: WA → SA → T → V → NSW → Q → NT

Partial assignment: {WA=red, SA=blue, T=red, V=green, NSW=red, Q=red}

Next variable: NT has no valid color (neighbors WA=red, SA=blue, Q=red use all colors).

Naive backtrack: Goes back to Q and tries a different color for Q.

But: Changing Q's color won't help! The conflict is with WA and SA, not Q.

Naive backtracking wastes time exploring irrelevant alternatives.

Chronological Backtracking Problem

Standard backtracking jumps to the most recent variable regardless of whether that variable is related to the conflict. This can lead to thrashing — repeatedly exploring branches that are doomed to fail.

Backjumping with Conflict Sets

Backjumping (also called intelligent backtracking) uses the concept of a conflict set to jump back to the relevant variable — the one actually involved in the conflict.

Conflict Set:
ConflictSet(X) = {previously assigned variables that are connected to X in the constraint graph}
Only variables in the conflict set can be responsible for X having no valid value

How Backjumping Works

  • 1. When assigning X, track which previous variables eliminate which values
  • 2. If all values for X are eliminated, the union of their conflict sets = the conflict set for X
  • 3. Jump back to the most recent variable in X's conflict set
  • 4. Return failure + conflict set so the target variable knows which conflicts remain

Implementation

function BACKTRACKING-SEARCH(csp) returns a solution or failure return RECURSIVE-BACKJUMPING({}, csp) function RECURSIVE-BACKJUMPING(assignment, csp) returns (solution, conflictSet) if assignment is complete then return (assignment, {}) var ← SELECT-UNASSIGNED-VARIABLE(VARIABLES[csp], assignment, csp) for each value in ORDER-DOMAIN-VALUES(var, assignment, csp) do if value is consistent with assignment then add {var = value} to assignment (result, conflict) ← RECURSIVE-BACKJUMPING(assignment, csp) if result ≠ failure then return (result, conflict) remove {var = value} from assignment return (failure, ConflictSet(var))
Key Point: Backjumping doesn't just go back one step — it goes back to the variable that actually caused the conflict, skipping irrelevant variables.

Worked Examples

Example 1: Australia Map — Backjumping in Action

Assignment order: WA → SA → T → V → NSW → Q → NT

Assignment: WA=red, SA=blue, T=red, V=green, NSW=red, Q=red

NT fails: Needs color different from WA(red), SA(blue), Q(red). No color left.

NT's conflict set: {WA, SA, Q} (the three variables connected to NT)

Backjump to Q (most recent in conflict set), skipping V, NSW, T.

Try Q=green (instead of Q=red). Now NT can be blue.

Backjumping saved 3 backtrack steps (T, V, NSW were skipped)!

Example 2: Comparison — Chronological vs Intelligent

Problem: Small CSP with variables {A, B, C, D, E}, ordering A→B→C→D→E

Conflict: E conflicts with A and B only (not with C, D).

Chronological: D fails → try D again → still fails → try C again → still fails → try B → success!

Backjumping: E's conflict set = {A, B} → jump directly to B. Skip C, D entirely.

Backjumping jumps from depth 5 (E) to depth 2 (B), skipping 2 irrelevant variables.

Example 3: Forward Checking Does It Better

Forward checking (FC) naturally prevents reaching dead-ends that backjumping would handle.

With FC, when X is assigned, it eliminates values from neighbors. If a neighbor's domain becomes empty, backtrack happens immediately — without needing to assign the empty-domain variable.

In fact, it's been proven that every branch pruned by backjumping is also pruned by forward checking. Therefore, pure backjumping offers no advantage over FC.

Backjumping is redundant when using forward checking or arc consistency.

Example 4: MAC + Backjumping is Redundant

MAC (Maintaining Arc Consistency) is even more powerful than forward checking. After each assignment, AC-3 propagates all constraints until quiescence. This catches inconsistencies even earlier.

With MAC:

  • • Inconsistencies are detected as early as possible
  • • The "culprit" variable is already identified by the propagation
  • • Backjumping adds no additional pruning power

Modern CSP solvers use FC or MAC; backjumping is mainly of historical interest.

Quick Reference

Backjumping

• Jumps to the relevant variable

• Uses conflict sets

• Skips irrelevant variables

• Avoids thrashing

Conflict Set

• Set of previously assigned variables connected to X

• Union of conflicts from each eliminated value

• Tells you where to jump back

Limitations

• Redundant with Forward Checking

• Every branch backjumping prunes is pruned by FC

• No benefit with MAC either

• Mainly of historical importance
