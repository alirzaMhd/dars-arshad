Context-Free Languages

Definition, Derivation, and CFG Properties — Complete Guide

What is a Context-Free Grammar (CFG)?

A context-free grammar G is a 4-tuple G = (V, Σ, P, S) where:

  • V: Finite set of variables (non-terminals)
  • Σ: Finite set of terminals (alphabet), V ∩ Σ = ∅
  • P: Finite set of production rules of the form A → α, where A ∈ V and α ∈ (V ∪ Σ)*
  • S: Start variable, S ∈ V
Key Property:
A → α : the left side is ALWAYS a single variable (no context needed)
This is why it's called "context-free" — the variable can be replaced regardless of its surrounding symbols.
Context-Sensitive vs Context-Free: In context-sensitive grammars, rules look like αAβ → αγβ (the replacement of A depends on context α and β). In context-free grammars, A → γ regardless of context.

Context-Free Languages

A language L is context-free if there exists a CFG G such that L = L(G).

Hierarchy:
Regular ⊂ Context-Free ⊂ Context-Sensitive ⊂ Recursively Enumerable
Every regular language is context-free, but not every context-free language is regular.

Derivation

A derivation is a sequence of rule applications that transforms the start variable into a string of terminals.

Leftmost Derivation (LMD):
At each step, replace the LEFTMOST variable
If αAβ ⇒ αγβ (where A → γ is a rule), and A is the leftmost variable in αAβ.
Rightmost Derivation (RMD):
At each step, replace the RIGHTMOST variable
If αAβ ⇒ αγβ, and A is the rightmost variable in αAβ.

Example: Leftmost vs Rightmost Derivation

Grammar G: S → AB, A → aA | a, B → bB | λ

String: w = a²bc²d² (using S → AB, A → aAb, B → cBd)

Leftmost Derivation:

S ⇒ AB ⇒ aAB ⇒ aaAB ⇒ aabB ⇒ aabcBd ⇒ aabccBdd ⇒ a²bc²d²

Rightmost Derivation:

S ⇒ AB ⇒ AcBd ⇒ AccBdd ⇒ Accdd ⇒ aAccdd ⇒ aaAccdd ⇒ a²bc²d²

Both derivations produce the same string, just in different order.

Ordered Derivations

Since leftmost and rightmost derivations follow a specific order, they are called ordered derivations. Any other derivation order is called an unordered derivation.

Language of a Grammar

Definition:
L(G) = {w ∈ Σ* : S ⇒* w}
The language of G is the set of all terminal strings derivable from S.

Example: Find Language of Grammar

G: S → AB | CD, A → aAc | M, D → bDd | E, C → aC | a, B → dB | λ, E → cE | λ, M → bM | λ

Analysis:

• Through S → AB: generates a^n · b^m · c^n · d^k (n,m,k ≥ 0)

• Through S → CD: generates a^n · b^m · c^k · d^p (n=k or m=p)

L(G) = {a^n b^m c^n d^p : n=m or m=p}

This language is NOT regular, but IS context-free.

Example: Palindromes

G: S → aSa | bSb | a | b | λ

L(G) = {w ∈ {a,b}* : w = wᴿ}

All even-length and odd-length palindromes over {a, b}.

This language is context-free but NOT regular.

Example 1: Design CFG for L = {aⁿbⁿ : n ≥ 2}

G: S → aSb | a²b²

S → aSb → aaSbb → aaaSbbb → ... → aⁿbⁿ (n ≥ 2)

Example 2: Design CFG for L = {aⁿb³ⁿ : n ≥ 0}

G: S → aSbbb | λ

S → aSbbb → aaSbbbbb → ... → aⁿb³ⁿ

Example 3: Design CFG for L = {aⁿbᵐ : n ≠ m}

L = {aⁿbᵐ : n > m} ∪ {aⁿbᵐ : n < m}

S → S₁ | S₂

S₁ → aS₁b | aB, B → bB | a

S₂ → aS₂b | Ab, A → aA | b

Example 4: L = {wwᴿ : w ∈ {a,b}*

Even-length palindromes (without odd-length):

G: S → aSa | bSb | λ

Odd-length palindromes included: S → aSa | bSb | a | b | λ

Example 5: L = {aⁿbᵐ : nₐ(w) = 2nᵦ(w)}

Number of a's is exactly twice the number of b's.

G: S → aSaSbS | aSbSaS | bSaSaS | λ

Or equivalently: S → aSab | aaSb | aSba | abSa | bSaa | baSa | SS | λ

Example 6 (L₄): L = {aⁿbᵐcⁿ : n,m > 0}

Not regular, but linear and CFL.

G₄: S → aSc | B,   B → bB | λ

Derivation: S → aSc → aaScc → ... → aⁿBcⁿ → aⁿbcⁿ → aⁿbᵐcⁿ

Example 7 (L₅): L = {aⁿbᵐcⁿᵐ : n,m > 0}

Not regular, but linear and CFL.

G₅: S → aScA,   A → aAb | λ

Each a generates a c and a copy of A (which produces b's matching a's), resulting in nm copies of b.

Example 8 (L₉): L = {aⁿbⁿ : n ≥ 0} ∪ {aⁿb²ⁿ : n ≥ 0}

Not regular, but CFL (union of two linear languages).

S → S₁ | S₂

S₁ → aS₁b | λ    (generates {aⁿbⁿ})

S₂ → aS₂bb | λ    (generates {aⁿb²ⁿ})

Example 9 (L₁₀): L = {w ∈ {a,b}* : nₐ(w) = 2nᵦ(w)}

Not regular, not linear, but CFL.

G₁₀: S → aSab | aaSb | aSba | abSa | bSaa | baSa | SS | λ

This is the same language as Example 5, confirming it is CFL but not linear.

Example 10 (L₁₁): L = {w ∈ {a,b}* : nₐ(w) = 2nᵦ(w) + 1}

CFL (a's exceed b's by exactly 1 after doubling).

G₁₁: S → AaA,   A → aAab | aaAb | aAba | abAa | bAaa | baAa | AA | λ

Example 11 (L₁₂): L = {aⁿbᵐ : n ≤ m + 3}

Not regular, but linear and CFL.

G₁₂: S → aSb | B,   B → Bb | ε | a | aa | aaa

S generates matched a-b pairs, B adds up to 3 extra b's (allowing n ≤ m + 3).

Example 12 (L₁₃): L = {aⁿbᵐ : m ≥ 2n} ∪ {aⁿbᵐ : m < 2n}

Not regular but linear and CFL. Union of two linear languages.

L₁₃ = L(A) ∪ L(B)

L(A) = {aⁿbᵐ : m ≥ 2n}: matched pairs where each a contributes 2 b's

L(B) = {aⁿbᵐ : m < 2n}: the complement with respect to {aⁿbᵐ}

Example 13 (L₁₄): L = {aⁿbᵐcʳ : n=m or m=r}

Not regular but CFL. This language is inherently ambiguous.

Inherently ambiguous: some strings can be derived in two distinct ways (e.g., when n=m=r).

S → S₁ | S₂,   S₁ → aS₁b | C,   C → cC | λ,   S₂ → bS₂c | A,   A → aA | λ

Example 14 (L₁₅): L = {w ∈ {a,b,c}* : nₐ(w) + nᵦ(w) = n_c(w)}

Not regular but CFL.

S → aSc | bSc | cS | λ

Each a or b is matched by a c on the right; extra c's are also allowed.

Example 15 (L₁₇): Balanced Parentheses Language

L = {w ∈ {a,b}* : (nₐ(w) = nᵦ(w)) ∧ (∀ prefix u of w: nₐ(u) ≥ nᵦ(u))}

Not regular but CFL. This is the Dyck language (balanced parentheses).

G₁₇: S → aSb | SS | λ

Every prefix has at least as many a's as b's, and total counts are equal.

Example 16 (L₁₈): Prefix-Balanced Language

L = {w ∈ {a,b}* : ∀ prefix u of w: nₐ(u) ≥ nᵦ(u)}

Not regular but CFL. Every prefix has at least as many a's as b's (total need not be equal).

G₁₈: S → aSb | SS | aS | λ

Like L₁₇ but without requiring nₐ(w) = nᵦ(w) globally.

Example 17 (L₁₉): L = {aⁿbᵐ : n ≠ m − 1}

Not regular but linear and CFL.

S → S₁ | S₂

S₁ → aS₁b | aS₁bb | A,   A → aA | λ

S₂ → aS₂b | aS₂bb | B,   B → bB | λ

Generates all strings where the number of a's is not one less than the number of b's.

Example 18 (L₂₀): L = {aⁿbᵐcᵏ : k ≠ n + m}

Not regular but CFL.

S → S₁ | S₂

S₁ → aS₁c | bS₁c | C,   C → cC | λ

S₂ → aS₂c | bS₂c | D,   D → aD | bD | λ

S₁ generates strings where k > n+m, S₂ generates strings where k < n+m.

Test Problem 1: Prefix Property Grammar

Which grammar generates L where nₐ(u) ≥ nᵦ(u) for all prefixes?

Answer: Option (1): S → aS | aSbS | ε

• aS: adds an extra a (increases a-count)

• aSbS: adds a matched a-b pair (prefix property maintained)

• ε: base case

Test Problem 2: Palindrome Grammar

Grammar G: S → aA | bB | ε. L(G) = ?

If A → aS, B → bS, then:

Answer: Option (2): L(G) = {wwᴿ : w ∈ {a,b}*}

S → aA → aaS → aabBS → aabbεS → aabb → ... (generates even-length palindromes)

Test Problem 3: Weighted Counting Language

L = {aⁿbᵐcᵏ : n + 2m = k}. Find the grammar.

Answer: Option (1): S → aScA,   A → bAcc | λ

Each a contributes 1 c (via aSc), each b contributes 2 c's (via bAcc → bAcc → bcAcc → bcc). A is copied for each b.
