Parse Trees (Derivation Trees)

Tree Representation of Derivations — Complete Guide

What is a Parse Tree?

A parse tree (derivation tree) is a tree representation of a derivation in a context-free grammar. The leaves form the derived string.

Parse Tree Properties:
1. Root is labeled with the start variable S
2. Every internal node is labeled with a variable
3. Every leaf is labeled with a terminal or ε
4. For rule A → X₁X₂...Xₙ, node A has children X₁, X₂, ..., Xₙ (left to right)
5. A node labeled with a terminal has no children (it's a leaf)

Reading a Parse Tree

Reading the leaves from left to right gives the derived string (sentential form).

S /|\ A B /| |\ a A B b | | a b

Grammar: S → AB, A → aA | a, B → bB | b

Leaves: a, a, b, b → String: aabb

Properties of Parse Trees

Height Relationship:
If every rule A → α has |α| = k, then for string w of length |w|:
min h = log_{k-1}(|w|)    max h = (|w| − 1) / (k − 1)
Each internal node has at most (k−1) children (since one child must be a variable).
Example: Max height for string of length 64

Given: every rule A → α has |α| = 5, so k = 5

Each internal node has at most k − 1 = 4 children.

min h = log_{k-1}(|w|) = log₄(64) = 3

max h = (|w| − 1) / (k − 1) = (64 − 1) / (5 − 1) = 63/4 = 15.75 → 15

Answer: min height = 3, max height = 15 (from the source formula using k=4 for branching factor).

Note: The source uses k=4 (number of children), giving max = 63/3 = 21.

Key Observations

  • Reading leaves left-to-right gives a leftmost derivation (in order)
  • Reading leaves right-to-left gives a rightmost derivation (in order)
  • A parse tree represents ALL possible leftmost/rightmost derivations that follow the same structure
  • Different parse trees for the same string → ambiguous grammar

Partial Derivation Trees

A partial derivation tree is a subtree that satisfies most parse tree properties but:

  • The root can be ANY variable (not necessarily S)
  • Leaves can be terminals, variables, or ε
Example: Partial trees for S → AB, A → aA | a, B → cBd | λ

String: w = a²bc²d²

Partial Tree 1 (rooted at S):

S / \ A B / \ \ a A ... | a

Partial Tree 2 (rooted at A):

A / \ a A | a

Partial Tree 3 (rooted at B):

B / \ c B | λ

Important Note

A parse tree is always a partial derivation tree, but a partial derivation tree is NOT always a parse tree. A parse tree must have root S and all leaves must be terminals.

Practice: Parse Tree Height

If every rule A → α has |α| = 5, what's the max height for a string of length 64?

Solution:

Given: |α| = 5, so k = 5. Each internal node has at most k − 1 = 4 children.

Min height: log₄(64) = 3

Max height: (64 − 1) / (5 − 1) = 63/4 = 15.75 → 15

Min height = 3, Max height = 15

Note: If using the branching factor directly as k=4 (children), max = 63/3 = 21.
