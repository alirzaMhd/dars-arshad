FA → RE Conversion (GTG)

Generalized Transition Graphs — Complete Guide

What is a Generalized Transition Graph?

A Generalized Transition Graph (GTG) is similar to an NFA, but edge labels are regular expressions (not just single symbols or λ).

GTG Definition:
A GTG has states, a start state, final states, and edges labeled with regular expressions over Σ
Each edge label is a regular expression, allowing complex patterns on single transitions.
Key Difference: In a standard NFA, each edge is labeled with a single symbol or λ. In a GTG, each edge can be labeled with any regular expression.

Why Use GTG?

The GTG method provides a systematic way to convert any finite automaton (DFA or NFA) to an equivalent regular expression.

  • Start with the FA's transition graph
  • Convert it to a GTG (edges labeled with symbols become edges labeled with singleton REs)
  • Reduce the GTG by eliminating intermediate states
  • The final GTG with 2 states gives the equivalent RE

Step-by-Step Conversion

Step 1: Handle Multiple Final States

If there are multiple final states, use one of these methods:

  • Method A: Add λ-transitions from all final states to a new single final state
  • Method B: Consider each final state separately, get RE for each, then take union

Step 2: Eliminate Intermediate States

For each intermediate state q (not start or final):

  1. Find all self-loop on q: if edge q→q has label r, replace with r*
  2. For each pair of edges q_i→q and q→q_j, create a new edge q_i→q_j with label (label(q_i→q)) · r* · (label(q→q_j))
  3. Remove state q and all its edges
  4. Repeat until only start and final states remain

Step 3: Read the Result

With only start state q₀ and final state q_f remaining, the edge q₀→q_f (if it exists) is labeled with the equivalent regular expression.

GTG Patterns

PatternRE
Single edge q₀→q_f with label rr
q₀→q_f, q_f→q_f loop with r₂r₁r₂*
q₀→q₀ loop r₁, q₀→q_f with r₂r₁*r₂
q₀→q_f with r₁, q₀→q₀ loop r₂, q_f→q_f loop r₃r₂*r₁r₃*

Add λ-transitions from all final states to a new single final state q₆.

q₂--λ-->q₆, q₃--λ-->q₆

Now q₆ is the only final state

This converts the DFA into an NFA with λ-transitions suitable for GTG elimination.

Step 2: Eliminate State q₂ → GTG (Figure 3-16)

Self-loop on q₂: none (no self-loop)

Paths through q₂: q₁--a-->q₂--b-->q₃ → creates edge q₁→q₃ labeled ab

Also: q₁--a-->q₂--λ-->q₆ → creates edge q₁→q₆ labeled a

New edges after eliminating q₂:

q₀--b-->q₁

q₁--ab-->q₃ (from q₁→q₂→q₃)

q₁--a-->q₆ (from q₁→q₂→q₆)

q₀--a-->q₀ (self-loop)

q₃--bb-->q₃ (self-loop: q₃--b-->q₃ combined with self-loop)

q₃--λ-->q₆

q₃--(a+λ)-->q₆ (merged edges from q₃ to q₆)

Step 3: Eliminate State q₁ → GTG (Figure 3-17)

Self-loop on q₁: none

Paths through q₁: q₀--b-->q₁--ab-->q₃ → creates edge q₀→q₃ labeled (a+ab)

Also: q₀--b-->q₁--a-->q₆ → creates edge q₀→q₆ labeled ba

q₀--a-->q₀ (self-loop)

q₀--(a+ab)-->q₃

q₃--bb-->q₃ (self-loop)

q₃--(b+λ)-->q₆

q₀--(a+ab)(bb)*(b+λ)-->q₆ (path through q₃)

Final RE

With only q₀ and q₆ remaining:

Edge q₀→q₃ labeled: (a+ab)

Self-loop on q₃ labeled: bb

Edge q₃→q₆ labeled: (b+λ)

R = (a+ab)(bb)*(b+λ)

Direct path from q₀ to q₆ via eliminated q₁: bλa

Combined: R = bλa + (a+ab)(bb)*(b+λ) which simplifies to bab

Alternative: Arden's Method

Another approach to solve for RE from a system of equations:

For each state qᵢ, write equation:
Qᵢ = Σⱼ Qⱼ · rⱼᵢ + (ε if qᵢ is start state)
Where rⱼᵢ is the regular expression on edge from qⱼ to qᵢ

Solve the system using Arden's theorem: X = XA + B → X = BA*
