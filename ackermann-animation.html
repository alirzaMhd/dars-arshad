Ackermann Function Ak(j)

The Ackermann function is a classic example of a total computable function that is not primitive recursive. It grows extremely fast through iterated composition.

Defined for k ≥ 0 and j ≥ 0:

A0(j) = j + 1 Ak+1(j) = Ak(j+1)(j)

where Ak(j+1) means applying Ak (j+1) times in succession.

Growth Pattern

A0 = successor (add 1) • A1 = doubling (2j+1) • A2 = exponential (2j+1(j+1)-1) • A3 = tetration • ...
