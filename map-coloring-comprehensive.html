Map Coloring — Australia Example

The Classic CSP Demonstration

Australia Map Coloring CSP

The problem: Color the map of Australia's regions using 3 colors (red, green, blue) so that adjacent regions never share the same color.

Variables

One variable per region:

Variables = {WA, NT, SA, Q, NSW, V, T}
Western Australia, Northern Territory, South Australia, Queensland, New South Wales, Victoria, Tasmania

Domains

Di = {red, green, blue}
Each region can be assigned any of the 3 colors

Constraints

Adjacent regions must have different colors. For example, NT and WA:

Allowed pairs for (NT, WA):
{(R,G), (R,B), (G,R), (G,B), (B,R), (B,G)}
6 out of 9 possible pairs are allowed; same-color pairs are forbidden
Note: The constraint WA ≠ NT can also be written as a binary inequality constraint: WA != NT

Constraint Graph Representation

CSPs can be represented as a constraint graph where:

  • • Nodes = Variables (regions)
  • • Edges = Constraints (adjacency)
Graph Structure:
SA connected to: WA, NT, Q, NSW, V (degree 5)
T connected to: nothing (degree 0)
All others have degree 2-3

Tasmania (T) is isolated — it never conflicts with any other region. This makes it an independent subproblem!

Solutions and Examples

Example 1: A Valid Solution

Assignment: {WA=red, NT=green, Q=red, NSW=green, V=red, SA=blue, T=red}

Check: WA(red) ≠ NT(green) ✓, NT(green) ≠ SA(blue) ✓, SA(blue) ≠ Q(red) ✓, Q(red) ≠ NSW(green) ✓, NSW(green) ≠ V(red) ✓, V(red) ≠ SA(blue) ✓, and all others satisfied.

✓ Complete consistent solution found

Example 2: Another Valid Solution

Assignment: {WA=green, NT=red, Q=green, NSW=red, V=green, SA=blue, T=blue}

Note that T can be any color since it is isolated.

✓ Solution exists with T=blue

Example 3: Invalid Assignment (Conflict)

Assignment: {WA=red, NT=red, Q=green, SA=blue}

Violation: WA and NT are adjacent but both assigned red!

This partial assignment is inconsistent and cannot lead to any solution.

✗ Constraint WA ≠ NT violated

Example 4: Counting Solutions

With 7 variables and 3 colors each, the total possible assignments = 37 = 2,187.

However, the number of valid solutions is much smaller due to constraints.

Since T is independent, if the mainland has S solutions, total solutions = 3 × S (T can be any of 3 colors).

The constraint graph structure helps analyze the solution space!
