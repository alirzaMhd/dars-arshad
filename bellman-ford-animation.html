Bellman-Ford Algorithm

Finds single-source shortest paths in a weighted directed graph, even with negative edge weights.

Why Bellman-Ford

• Handles negative edge weights (unlike Dijkstra)

• Detects negative cycles reachable from the source

• Uses V−1 passes over all edges: each pass propagates distance information one edge further along shortest paths

Algorithm

1. INIT-SINGLE-SOURCE(G, s) — d[s]=0, d[v]=∞ 2. For i = 1 to |V|−1: for each edge (u,v): RELAX(u,v,w) 3. For each edge (u,v): if v.d > u.d + w(u,v): return FALSE 4. Return TRUE (no negative cycle)
