What is a Semiconnected Graph?

A directed graph G = (V, E) is semiconnected if for every pair of vertices (u, v), there is a path u ⇝ v or v ⇝ u (or both).

This is weaker than strong connectivity (where both directions must exist) but stronger than weak connectivity.

Algorithm: How to Test

1. Compute SCCs (Kosaraju's algorithm)

2. Build the condensation DAG GSCC

3. G is semiconnected iff GSCC has a unique topological ordering (equivalently: a Hamiltonian path covering all SCCs)
