Infix to Postfix Conversion

Algorithm:
InfixToPostfix(expression): stack = new Stack output = "" for each token in expression: if token is operand: output += token elif token == '(': stack.Push(token) elif token == ')': while stack.Top() != '(': output += stack.Pop() stack.Pop() // remove '(' else: // operator while not stack.IsEmpty() and Precedence(stack.Top()) >= Precedence(token): output += stack.Pop() stack.Push(token) while not stack.IsEmpty(): output += stack.Pop() return output

Infix to Prefix Conversion

Algorithm:
InfixToPrefix(expression): 1. Reverse the expression 2. Swap '(' with ')' and vice versa 3. Convert to Postfix (using modified algorithm) 4. Reverse the result to get Prefix

⚠ Shortcut for Prefix:

1. Add parentheses to enforce precedence

2. Move each operator before its operands

3. Remove all parentheses

Example: A + (B × C) → + A (× B C) → + A × B C

Expression Evaluation

Evaluate Postfix

EvaluatePostfix(expression): stack = new Stack for each token in expression: if token is operand: stack.Push(token) else: // operator b = stack.Pop() a = stack.Pop() result = Apply(token, a, b) stack.Push(result) return stack.Pop()

Associativity Examples

Left to Right: A - B - C = (A - B) - C

Right to Left: A ^ B ^ C = A ^ (B ^ C)

Correct

A - B + C = (A - B) + C

A × B + C = (A × B) + C

A + B × C = A + (B × C)

Wrong

A - (B - C) ≠ A - B - C

(A × B) + C ≠ A × (B + C)

(A + B) × C ≠ A + B × C

⚠ Common Mistakes:

• Forgetting that ^ is right-associative

• Confusing - and + precedence (same level!)

• Not handling parentheses first
