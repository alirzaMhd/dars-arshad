Strongly Connected Components

A strongly connected component (SCC) of a directed graph G = (V, E) is a maximal set of vertices C ⊆ V such that for every pair of vertices u, v ∈ C, u is reachable from v and v is reachable from u.

The graph has |V| = 8 vertices and |E| = 12 directed edges.

Kosaraju's Algorithm (Two-Pass)

Pass 1: Run DFS on G, recording finish times f[u].

Pass 2: Compute GT (transpose). Run DFS on GT in decreasing order of finish times. Each DFS tree in Pass 2 = 1 SCC.

Key Insight

The component graph GSCC (contracting each SCC to one node) is always a DAG — if there were a cycle, the SCCs would merge into one.
