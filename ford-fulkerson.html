Problem Setup

Find the maximum flow from source s to sink t in a flow network.

A flow network is a directed graph where each edge has a capacity c(u,v) ≥ 0.

Network Definition

Nodes: V = {s, u, v, t}

Edges & Capacities:

s → u : 10 s → v : 10 u → v : 5 u → t : 10 v → t : 10

Algorithm Idea

Repeatedly find an augmenting path from s to t in the residual network Gf, then push as much flow as possible along it.

Ford-Fulkerson(G, s, t): 1. Initialize f(u,v) = 0 for all edges 2. While exists augmenting path p in G_f: - c_f(p) = min{c_f(u,v) : (u,v) in p} - For each (u,v) in p: - if (u,v) in E: f(u,v) += c_f(p) - else: f(v,u) -= c_f(p) 3. Return f
