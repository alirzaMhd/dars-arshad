Signal Classification

Signals and Systems — Complete Guide for Exam Preparation

Continuous-Time Signals

A continuous-time signal is defined for every value of time. The independent variable (time) is continuous, meaning the signal has a value at every instant.

Notation:
x(t)
Parentheses () denote continuous-time signals. The signal x is a function of continuous variable t.
Example 1: Voltage across a resistor

Consider the voltage across a resistor in an electrical circuit. If we measure this voltage continuously over time, we obtain a continuous-time signal. The voltage exists at every instant t.

Example 2: Temperature readings

If we record the temperature of a room continuously using an analog thermometer, the resulting signal x(t) is continuous-time because temperature is defined at every moment.

Discrete-Time Signals

A discrete-time signal is defined only at specific, countable instants of time. The independent variable takes on integer values only.

Notation:
x[n]
Square brackets [] denote discrete-time signals. The signal x is a function of discrete variable n (integer).
Example 1: Sampled voltage

If we sample the voltage across a resistor at times t = 2k seconds where k is an integer, we obtain a discrete-time signal. The signal only has values at t = 0, 2, 4, 6, ...

Example 2: Daily stock prices

The closing price of a stock recorded at the end of each trading day forms a discrete-time signal x[n] where n represents the day number.

Key Difference: The notation matters! Use x(t) for continuous and x[n] for discrete. Mixing up () and [] is a common mistake on exams.

Signal Amplitude Classification

Signals can also be classified based on whether their amplitude (dependent variable) is continuous or discrete.

Type Time Amplitude Notation Example
Continuous-Continuous Continuous Continuous x(t) Analog voltage
Continuous-Discrete Continuous Discrete x(t) Quantized analog signal
Discrete-Continuous Discrete Continuous x[n] Sampled analog signal
Discrete-Discrete Discrete Discrete x[n] Digital signal
Note: In most practical systems today, we deal with digital signals (discrete in both time and amplitude). However, in this course, we focus primarily on whether signals are continuous or discrete in TIME, not amplitude.

Key Definitions

Independent Variable

The variable on the horizontal axis. For continuous signals it is t (time), for discrete signals it is n (sample index).

Dependent Variable (Amplitude)

The value of the signal at a given time. Denoted as x(t) or x[n]. Can be real or complex-valued.

Real vs Complex Signals

A signal is real if x(t) is real for all t. A signal is complex if x(t) has both real and imaginary parts: x(t) = xR(t) + j·xI(t)

Complete Signal Classification

Combining time and amplitude classifications gives us four signal types:

Type 1: Continuous in both time and amplitude
Analog signal
Examples: speech signal, temperature, voltage in analog circuits
Type 2: Continuous in time, discrete in amplitude
Quantized signal
An analog signal whose amplitude is quantized to discrete levels
Type 3: Discrete in time, continuous in amplitude
Sampled signal
Obtained by sampling an analog signal at regular intervals
Type 4: Discrete in both time and amplitude
Digital signal
The most common type in modern systems. Both time and amplitude are discrete.
Important: In this course, we focus on continuous-time and discrete-time signals. We do NOT consider discrete amplitude in our analysis.

Worked Examples

Example 1: Classify the signal

Problem: Is x(t) = 5cos(3πt) continuous or discrete?

Solution: The signal uses parentheses () and the variable t appears without restriction. This is a continuous-time signal. It is defined for all real values of t.

Example 2: Classify the signal

Problem: Is x[n] = 0.5n·u[n] continuous or discrete?

Solution: The signal uses square brackets [] and the variable n is an integer. This is a discrete-time signal. It is defined only for integer values of n.

Example 3: Mixed notation

Problem: A signal is defined as x(t) = sin(2πt) for t = 0, 1, 2, 3, ... Is this continuous or discrete?

Solution: Even though the formula uses t and parentheses, the signal is only defined at integer values of t. This is effectively a discrete-time signal and should be written as x[n] = sin(2πn).

Example 4: Real vs Complex

Problem: Classify x(t) = ej2πt as real or complex.

Solution: Using Euler's formula: x(t) = cos(2πt) + j·sin(2πt). This signal has both real and imaginary parts, so it is a complex-valued signal.

Example 5: Practical classification

Problem: A microphone converts sound to voltage. Is the output continuous or discrete?

Solution: The microphone produces a voltage that varies continuously with time. The output is a continuous-time signal. If this voltage is then digitized by an ADC (Analog-to-Digital Converter), it becomes a discrete-time signal.
