Binary Tree Traversal

Data Structures — Complete Guide for 20/20 Exam

What is Tree Traversal?

Tree traversal is the process of visiting every node in a binary tree exactly once in a systematic order. The goal is to access data in each node in a specific sequence.

Two Main Categories

Depth-First Traversal

Explores as deep as possible along each branch before backtracking.

Uses stack (recursion or explicit stack)

6 types: DLR, LDR, LRD, RLD, RDL, DRL

Level-Order Traversal

Visits nodes level by level, from left to right.

Uses queue (FIFO)

Also called breadth-first traversal (BFS)

Reference Tree for All Examples: a / \ b c / \ \ d e f / \ g h

Traversal Naming Convention

Using D = visit node (Data), L = traverse Left subtree, R = traverse Right subtree:

The three most important traversals are DLR (preorder), LDR (inorder), and LRD (postorder). The reverse versions (RLD, RDL, DRL) visit nodes in the opposite order of their standard counterparts.

Preorder Traversal (DLR)

Order:
Visit Root → Traverse Left → Traverse Right
Visit the current node first, then recursively visit the left subtree, then the right subtree.
preorder(node) { if (node == NIL) return; visit(node); // D: Visit root preorder(node.left); // L: Traverse left preorder(node.right); // R: Traverse right }
Preorder Example
a → Visit a first / \ b c → Then traverse b's subtree, then c's subtree / \ \ d e f / \ g h

Result: a, b, d, e, g, h, c, f

Explanation: Visit a → left to b → left to d → back to b → right to e → left to g → back to e → right to h → back to a → right to c → right to f

Preorder Applications

• Creating a copy/serialization of the tree

• Generating prefix expressions from expression trees

• Serializing a tree structure for storage

Inorder Traversal (LDR)

Order:
Traverse Left → Visit Root → Traverse Right
Traverse the left subtree first, then visit the current node, then traverse the right subtree.
inorder(node) { if (node == NIL) return; inorder(node.left); // L: Traverse left visit(node); // D: Visit root inorder(node.right); // R: Traverse right }
Inorder Example
a / \ b c / \ \ d e f / \ g h

Result: d, b, g, e, h, a, c, f

Explanation: Go left to d → visit d → back to b → visit b → right to e → left to g → visit g → back to e → visit e → right to h → visit h → back to a → visit a → right to c → visit c → right to f → visit f

Inorder Applications

• For BSTs, inorder gives sorted order

• Generating infix expressions from expression trees

• Most common traversal for BST operations

Postorder Traversal (LRD)

Order:
Traverse Left → Traverse Right → Visit Root
Traverse the left subtree first, then the right subtree, then visit the current node.
postorder(node) { if (node == NIL) return; postorder(node.left); // L: Traverse left postorder(node.right); // R: Traverse right visit(node); // D: Visit root }
Postorder Example
a / \ b c / \ \ d e f / \ g h

Result: d, g, h, e, b, f, c, a

Explanation: Left subtree of b → d → g → h → e → b → Right subtree of a → f → c → finally visit a

Postorder Applications

• Deleting a tree (delete children before parent)

• Generating postfix expressions from expression trees

• Evaluating expressions in expression trees

Recursive vs Iterative Traversal

All three depth-first traversals can be implemented recursively (simple) or iteratively using an explicit stack.

Recursive

• Simple and clean code

• Uses call stack implicitly

• Risk of stack overflow for deep trees

O(n) time, O(h) space

Iterative (with stack)

• More complex code

• Explicit stack control

• No stack overflow risk

O(n) time, O(h) space

Traversal Complexity (All Types):
Time: Θ(n), Space: O(h)
Every node is visited exactly once → Θ(n) time. Space depends on tree height h (stack depth for recursion). For balanced tree h = lg n; for skewed tree h = n.

Level-Order Traversal (BFS)

Process:
Visit nodes level by level, left to right at each level
Uses a queue (FIFO) to maintain the order of visitation. Also known as breadth-first search (BFS) on trees.
Levelorder(root) { Q = empty queue addq(Q, root) while (not empty(Q)) { node = delq(Q) visit(node) if (left(node) != NIL) addq(Q, left(node)) if (right(node) != NIL) addq(Q, right(node)) } }
Level-Order Example
Level 0: a / \ Level 1: b c / \ \ Level 2: d e f / \ Level 3: g h

Result: a, b, c, d, e, f, g, h

Step-by-step queue trace:

StepDequeueVisitEnqueueQueue After
1--a[a]
2aab, c[b, c]
3bbd, e[c, d, e]
4ccf[d, e, f]
5dd-[e, f]
6eeg, h[f, g, h]
7ff-[g, h]
8gg-[h]
9hh-[]
Complexity:
Time: Θ(n), Space: O(w)
w = maximum width of tree (max number of nodes at any level). For a complete binary tree, w = 2^⌊lg n⌋ ≈ n/2. In worst case (perfect tree), space is Θ(n).
Level-order traversal requires a QUEUE, while depth-first traversals use a STACK (recursion). This is a common exam distinction! Confusing the two data structures is a frequent mistake.

Reverse Traversals

These traversals visit nodes in the opposite order of their standard counterparts. They are obtained by swapping the roles of left and right subtrees.

RLD (Reverse Preorder)

Order:
Traverse Right → Visit Root → Traverse Left
Mirror of preorder. Visit root, then right subtree, then left subtree.

RDL (Reverse Inorder)

Order:
Traverse Right → Traverse Left → Visit Root
Mirror of inorder. For BSTs, gives reverse sorted order (descending).

DRL (Reverse Postorder)

Order:
Visit Root → Traverse Right → Traverse Left
Mirror of postorder. Visit root first, then right, then left.

Tree Reconstruction from Traversals

Given one or two traversal sequences, can we uniquely determine the binary tree?

DLR + LDR → Unique

Always uniquely determines the tree

Root is first in DLR. Split LDR by root position. Recurse on subtrees.

LRD + LDR → Unique

Always uniquely determines the tree

Root is last in LRD. Split LDR by root position. Recurse on subtrees.

DLR + LRD → NOT Unique

May not uniquely determine the tree

If any node has exactly one child, there are multiple possible trees.

DLR + LRD Uniqueness Theorem:
If preorder and postorder have k single-child nodes, there are 2^k possible trees
Only when every node has 0 or 2 children (full binary tree) is the tree uniquely determined. Each single-child node creates a binary choice (left or right child).
Example 1: Reconstruct from DLR + LDR

Given DLR = a b d e g h c f, LDR = d b g e h a c f

Solution:

1. DLR first element = a (root)

2. In LDR, left of a: {d, b, g, e, h} = left subtree. Right of a: {c, f} = right subtree

3. Left subtree: DLR = b d e g h, LDR = d b g e h → root = b

4. In LDR left of b: {d}. Right of b: {g, e, h}

5. Continue recursively for each subtree

Result: a / \ b c / \ \ d e f / \ g h
Example 2: Reconstruct from LRD + LDR

Given LRD = d g h e b f c a, LDR = d b g e h a c f

Solution:

1. LRD last element = a (root)

2. In LDR, left of a: {d, b, g, e, h} = left subtree. Right of a: {c, f} = right subtree

3. Left subtree: LRD = d g h e b, LDR = d b g e h → last in LRD = b

4. Continue recursively...

Result: a / \ b c / \ \ d e f / \ g h
Example 3: DLR + LRD Non-Uniqueness

Given DLR = a b, LRD = b a

Single-child nodes: a has only left child b

Number of single-child nodes = 1

Number of possible trees = 2^1 = 2

Possible trees:

Tree 1: Tree 2: a a / \ b b

Both give DLR = a, b and LRD = b, a.

Worked Examples

Example 1: Basic Traversal

Given the tree below, find all 6 traversal orders:

a / \ b c / / \ d e f

Solution:

DLR: a, b, d, c, e, f

LDR: d, b, a, e, c, f

LRD: d, b, e, f, c, a

RLD: a, c, f, e, d, b

RDL: f, c, e, a, d, b

DRL: a, c, f, e, d, b

Example 2: Number of Function Calls

How many times is the preorder function called for a tree with n nodes?

Solution:

For n nodes, the function is called 2n + 1 times (once per node visit + once for each NIL pointer).

For the reference tree (8 nodes): 2(8) + 1 = 17 calls

Why? Each node has 2 children pointers. Total pointers = 2n. NIL pointers = n+1 (for n nodes). Non-NIL calls = n. Total = (n+1) + n = 2n+1.

Example 3: Skewed Tree Traversals

What are the traversals for a right-skewed tree: a → b → c → d?

a \ b \ c \ d

Solution:

DLR: a, b, c, d

LDR: a, b, c, d (same as DLR!)

LRD: d, c, b, a (reverse of DLR)

For right-skewed trees: DLR = LDR (both give root-to-leaf order). For left-skewed trees: LDR = LRD (both give leaf-to-root order).
Example 4: Catalan Numbers

Given inorder = a b c, how many different binary trees exist?

Solution:

For n nodes with inorder traversal, the number of possible trees = Catalan(n) = C(2n,n)/(n+1)

For n=3: Catalan(3) = C(6,3)/4 = 20/4 = 5

Each choice of root splits the remaining elements into left and right subtrees, and the count multiplies.

Example 5: Building Tree from LRD + LDR

Given LRD = CBEGHFDA and LDR = BCDAEDGFH, build the tree.

Solution:

1. Last in LRD is root: A

2. In LDR: BC left of A, EDGFH right of A

3. Left subtree: LRD = CB, LDR = BC → last of CB is B, C is left child

4. Right subtree: LRD = EGHFD, LDR = EDGFH → last of EGHFD is D

5. Continue: D's left = {E}, D's right = {G, F, H}...

A / \ B D / / \ C E F / \ G H
Example 6: Complete Tree from DLR + LDR

Given DLR = faeckdghb, LDR = eakcfgdhb, find LRD.

Solution:

1. DLR first = f (root)

2. LDR: {e, a, k, c} left of f, {g, d, h, b} right of f

3. Left subtree: DLR = a e c k, LDR = e a k c → root = a

4. a's left: {e}, a's right: {k, c} → root of right: c, k is c's left

5. Right subtree: DLR = g d h b, LDR = g d h b → root = g

6. g's left: {}, g's right: {d, h, b} → root = d, d's left: {}, d's right: {h, b} → h, b is h's left

f / \ a g / \ \ e c d / \ k h / b

LRD: e, k, c, a, b, h, g, d, f

Reconstruction Rules

DLR + LDR → Unique tree always
Root is first in DLR. Split LDR by root position. Recurse on subtrees.
LRD + LDR → Unique tree always
Root is last in LRD. Split LDR by root position. Recurse on subtrees.
DLR + LRD → NOT always unique
If k single-child nodes exist, there are 2^k possible trees. Only unique when tree is full (every node has 0 or 2 children).

Common Exam Mistakes:
  • Confusing LEVEL-ORDER (queue) with DFS (stack/recursion)
  • Assuming DLR + LRD always gives a unique tree
  • Forgetting the 2n+1 function call count for DFS
  • Confusing RDL order: it is R-L-D, NOT R-D-L
  • Not accounting for skewed trees where h = n
