Regular Expressions

Formal Languages & Automata Theory — Complete Guide

What is a Regular Expression?

A regular expression is a formal notation for describing regular languages. Every regular expression describes a language, and every regular language can be described by a regular expression.

Key Insight: A language is regular if and only if a finite automaton (DFA or NFA) exists for it. Regular expressions are one of several equivalent ways to describe regular languages.

Syntax of Regular Expressions

Regular expressions are built from an alphabet Σ using recursive rules:

Base Cases:
ε (empty string) and ∅ (empty set) are regular expressions
For each symbol a ∈ Σ, 'a' is a regular expression
Recursive Rules:
If r₁ and r₂ are regular expressions, then (r₁ + r₂), (r₁r₂), and (r₁*) are regular expressions
+ = union (alternation), concatenation, * = Kleene star

Operator Precedence (lowest to highest):

OperatorSymbolPrecedenceDescription
Union+LowestMatches either expression
Concatenation· (implicit)MiddleMatches both in sequence
Kleene Star*HighZero or more repetitions
Parentheses( )HighestGrouping
Note: The union operator + may also be written as | or ∪. Concatenation dot · is usually omitted (e.g., ab means a·b).

Building Regular Expressions

Steps to construct a regular expression from base expressions:

  • Start with base expressions: ε, ∅, and individual symbols from Σ
  • Apply concatenation: if r₁ and r₂ are regular expressions, so is r₁r₂
  • Apply union: if r₁ and r₂ are regular expressions, so is r₁ + r₂
  • Apply Kleene star: if r₁ is a regular expression, so is r₁*
Example: Building (a+b)*aaa

Given Σ = {a, b}, we can derive:

a, b → a+b → (a+b) → (a+b)* → (a+b)*a → (a+b)*aa → (a+b)*aaa

This is a valid regular expression over {a, b}.

Invalid expressions: +a+b and (aba) are NOT valid regular expressions. Every operator must have proper operands.

Semantics (Language of a Regular Expression)

Every regular expression r describes a language L(r). The language is defined recursively:

Base Cases:
L(ε) = {ε}, L(∅) = {}, L(a) = {a} for each a ∈ Σ
ε describes the empty string, ∅ describes the empty language, 'a' describes the singleton set {a}
Union:
L(r₁ + r₂) = L(r₁) ∪ L(r₂)
The language of r₁ + r₂ is the union of the languages of r₁ and r₂
Concatenation:
L(r₁r₂) = L(r₁) · L(r₂) = {xy : x ∈ L(r₁), y ∈ L(r₂)}
All strings formed by concatenating a string from L(r₁) with a string from L(r₂)
Kleene Star:
L(r*) = (L(r))* = {ε} ∪ L(r) ∪ L(r)L(r) ∪ L(r)L(r)L(r) ∪ ...
Zero or more concatenations of strings from L(r)
Parentheses:
L((r)) = L(r)
Parentheses don't change the language, only grouping

Detailed Example: L((a+b)*ab)

Finding the language of (a+b)*ab

L((a+b)*ab) = L((a+b)*) · L(ab)

= [L(a+b)]* · L(ab)

= [{a} ∪ {b}]* · {a} · {b}

= {a, b}* · {ab}

= {a, b}* · {ab}

= All strings over {a, b} that end with substring "ab"

More Language Examples

L₁ = (a+b)*aa(a+b)*:
All strings over {a, b} containing substring "aa"
L₂ = a(a+b)*d(a+b)*d(a+b)*b:
All strings over Σ={a,b,d} starting with 'a', ending with 'b', containing exactly 2 d's

Example 1: Strings divisible by 3

Language: L = {w ∈ {0,1}* : |w| mod 3 = 0}

Problem: Write a regular expression for all binary strings whose length is a multiple of 3.

Solution: We need groups of exactly 3 characters. Each position can be 0 or 1.

r = ((0+1)(0+1)(0+1))* = ((0+1)³)*

This generates all strings where length is 0, 3, 6, 9, ...

Example 2: Contains substring 011

Language: L = {w ∈ {0,1}* : w contains "011"}

Solution: Any prefix, then "011", then any suffix.

r = (0+1)* 011 (0+1)*

This matches all binary strings containing "011" as a substring.

Example 3: Exactly one pair of consecutive zeros

Language: Strings with exactly one "00" substring

Solution:

r₃ = (1+01)* 00 (10+1)*

Before "00": no consecutive zeros → (1+01)*

After "00": no consecutive zeros → (10+1)*

Example 4: No consecutive zeros

Language: L = {w ∈ {0,1}* : w has no "00" substring}

Solution: Two equivalent forms:

r₄ = (1+01)*(0+ε)

r₄' = (ε+0)(1+10)*

Both describe strings where no two zeros are adjacent.

Example 5: Maximum one pair of consecutive zeros

Language: L₅ = L₃ ∪ L₄

Solution: Union of "exactly one 00" and "no 00":

r₅ = r₃ + r₄ = (1+01)*00(10+1)* + (1+01)*(0+ε)

Example 6: Length divisible by 4

Language: L = {w ∈ {a,b}* : |w| mod 4 = 0}

r₆ = ((a+b)⁴)*

Groups of exactly 4 characters, repeated zero or more times.

Example 7: Length mod 4 > 0

Language: L = {w ∈ {a,b}* : |w| mod 4 > 0}

r₇ = ((a+b)⁴)* ((a+b) + (a+b)² + (a+b)³)

Zero or more groups of 4, then 1, 2, or 3 extra characters.

Practice Problem 1

Count strings of length ≤ 3 in R = (a+b)*(aa+b)(a+b)*

Length 0: 0 strings (empty string doesn't match)

Length 1: 1 string: b

Length 2: 4 strings: aa, ab, ba, bb

Length 3: 8 strings: aaa, aab, aba, abb, baa, bab, bba, bbb

Total: 0 + 1 + 4 + 8 = 13 strings

Total: 0 + 1 + 3 + 7 = 11 strings

Practice Problem 3

Which RE describes strings with exactly one "000"?

Options:

(1) (1+01+001)* 000 (100+10+1)*

(2) (1+0+00)* 000 (10+1)*

(3) (1+01)* 000 (10+1)*

(4) (0+1)*000(0+1)*

Answer: Option (2) — it generates exactly the strings with one "000" and no extra restrictions

Practice Problem 4

Complement of L = (0+1)*

Problem: What is the complement of language described by (0+1)*?

Solution: (0+1)* describes ALL strings over {0, 1}. Its complement is ∅ (empty set).

Answer: ∅

Practice Problem 5

Strings NOT containing "aaa"

Problem: Which RE accepts all strings of a and b that don't contain "aaa"?

Answer: (b + ab + aab)*(ε + a + aa)

This ensures we never have three consecutive a's.

Practice Problem 6

Odd length strings with exactly 2 b's

Problem: Over Σ = {a, b}, write RE for odd length strings with exactly 2 b's.

Answer: (aa)*b(aa)*b(aa)* + (aa)*b(aa)*a + a(aa)*b(aa)*b(aa)*

More precisely: (aa)*b(aa)*b(aa)*a + a(aa)*b(aa)*b(aa)* + (aa)*b(aa)*a(aa)*b(aa)*

All four expressions together: (aa)*b(aa)*b(aa)* + similar patterns ensuring exactly 2 b's and odd total length.
