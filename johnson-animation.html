The Problem with Dijkstra

Dijkstra's algorithm fails with negative edge weights because it assumes that once a vertex is finalized, its distance won't decrease.

With negative edges, a later path through a "negative shortcut" can produce a shorter distance than Dijkstra already found.

Johnson's Solution

Reweight all edges to make them non-negative, run Dijkstra from every vertex, then undo the reweighting.

ŵ(u,v) = w(u,v) + h(u) − h(v)

Where h(v) = shortest distance from a new source vertex s to v.
