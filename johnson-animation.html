🎯 Johnson's Algorithm

Johnson's algorithm finds all-pairs shortest paths in a weighted directed graph, handling negative edge weights (without negative cycles).

📝 How It Works

Key insight: Reweight edges to make all weights non-negative, then run Dijkstra from each vertex.

📜 Pseudocode

Johnson(G, w):

1. Add vertex s with 0-weight edges to all v

2. Bellman-Ford(G, w, s) → h(v)=δ(s,v)

3. If negative cycle detected → report & exit

4. Reweight: ŵ(u,v)=w(u,v)+h(u)−h(v) ≥ 0

5. For each u ∈ V: Dijkstra(G, ŵ, u) → d̂[u]

6. Unwind: d[u,v] = d̂[u,v] + h(v) − h(u)

7. Return D
