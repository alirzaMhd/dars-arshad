Array Implementation

Structure:
struct Queue { Type items[MAX_SIZE]; int front; int rear; } // Initialize void Init(Queue &q): q.front = -1 q.rear = -1 // Enqueue void Enqueue(Queue &q, Type x): if q.rear == MAX_SIZE - 1: print("Queue Overflow") return if q.front == -1: q.front = 0 q.rear++ q.items[q.rear] = x // Dequeue Type Dequeue(Queue &q): if q.front == -1 or q.front > q.rear: print("Queue Underflow") return null Type x = q.items[q.front] q.front++ if q.front > q.rear: q.front = q.rear = -1 return x

Solution: Circular Queue

Circular Queue

Key Insight:
Use modulo arithmetic to wrap around
After reaching end, go back to beginning
Algorithm:
// Enqueue void Enqueue(Queue &q, Type x): if (q.rear + 1) % MAX_SIZE == q.front: print("Queue Full") return if q.front == -1: q.front = 0 q.rear = (q.rear + 1) % MAX_SIZE q.items[q.rear] = x // Dequeue Type Dequeue(Queue &q): if q.front == -1: print("Queue Empty") return null Type x = q.items[q.front] if q.front == q.rear: q.front = q.rear = -1 else: q.front = (q.front + 1) % MAX_SIZE return x // Check Full bool IsFull(Queue q): return (q.rear + 1) % MAX_SIZE == q.front // Check Empty bool IsEmpty(Queue q): return q.front == -1 // Count int Count(Queue q): if q.front == -1: return 0 return (q.rear - q.front + MAX_SIZE) % MAX_SIZE + 1

⚠ Key Formulas:

• Next position: (rear + 1) % MAX_SIZE

• Count: (rear - front + MAX_SIZE) % MAX_SIZE + 1

• One slot wasted to distinguish full/empty

Linked List Implementation

Structure:
struct Node { Type data; Node* next; } struct Queue { Node* front; Node* rear; } // Enqueue void Enqueue(Queue &q, Type x): Node* newNode = new Node(x) if q.rear != NULL: q.rear.next = newNode q.rear = newNode if q.front == NULL: q.front = newNode // Dequeue Type Dequeue(Queue &q): if q.front == NULL: print("Queue Empty") return null Node* temp = q.front Type x = temp.data q.front = q.front.next if q.front == NULL: q.rear = NULL delete temp return x

BFS Using Queue
BFS(graph, start): queue = new Queue visited = set queue.Enqueue(start) visited.add(start) while not queue.IsEmpty(): node = queue.Dequeue() Process(node) for each neighbor of node: if neighbor not in visited: queue.Enqueue(neighbor) visited.add(neighbor)
