BINARY SEARCH

What is Binary Search?

Binary search is an efficient algorithm for finding a target element in a sorted array. Unlike linear search which checks every element, binary search repeatedly divides the search interval in half.

Key Principle:
If x == A[mid]: found!
If x < A[mid]: search left half. If x > A[mid]: search right half.

Requirements

• Array must be sorted

• Elements must be comparable

• Access by index must be O(1)

Advantage

• Much faster than linear search

• O(log n) vs O(n)

• For n = 1,000,000: ~20 vs 1,000,000 comparisons

⚠ Common Mistake: Forgetting that the array MUST be sorted before applying binary search!

Iterative Binary Search

Algorithm Pseudocode:
iterative_binarysearch(L, U, x) { while (L ≤ U) { mid = ⌊(L + U) / 2⌋ if (x == A[mid]) return mid if (x > A[mid]) L = mid + 1 else U = mid - 1 } return NIL }
L = left index, U = upper index, x = target element

Variables

• L: Left boundary

• U: Right boundary

• mid: Middle index

• x: Target value

Key Steps

1. Calculate mid = ⌊(L+U)/2⌋

2. Compare x with A[mid]

3. Update L or U based on comparison

4. Repeat until found or L > U

⚠ When array has even number of elements, two middle elements exist. This algorithm takes the left middle element (floor).

Recursive Binary Search

Algorithm Pseudocode:
recbinarysearch(L, U, x) { if (L > U) return NIL mid = ⌊(L + U) / 2⌋ if (x == A[mid]) return mid if (x > A[mid]) return recbinarysearch(mid + 1, U, x) else return recbinarysearch(L, mid - 1, x) }
Recursive version with same logic as iterative

Recursive Version

• Calls itself with smaller subarray

• Base case: L > U (not found)

• Same O(log n) complexity

Comparison

• Iterative: Uses while loop

• Recursive: Uses function calls

• Both have same time complexity

Worked Examples

Example 1: Search for 50 in sorted array

Array: [10, 20, 30, 40, 50, 60, 70, 80, 90]

Searching for x = 50

Step 1: mid = ⌊(1+9)/2⌋ = 5, A[5] = 50 → Found at index 5!

Only 1 comparison needed.

Example 2: Search for 20 in sorted array

Array: [10, 20, 30, 40, 50, 60, 70, 80, 90]

Searching for x = 20

Step 1: mid = 5, A[5] = 50, 20 < 50 → search left

Step 2: mid = ⌊(1+4)/2⌋ = 2, A[2] = 20 → Found at index 2!

2 comparisons needed.

Example 3: Search for 75 (not in array)

Array: [10, 20, 30, 40, 50, 60, 70, 80, 90]

Searching for x = 75

Step 1: mid = 5, A[5] = 50, 75 > 50 → search right

Step 2: mid = 7, A[7] = 80, 75 < 80 → search left

Step 3: mid = 6, A[6] = 70, 75 > 70 → search right

Step 4: L > U → Not found (NIL)

Example 4: Comparison counts for 9-element array

Time & Space Complexity

Time Complexity Formula:
T(n) = T(n/2) + Θ(1)
Recurrence relation for binary search
Solution:
T(n) = Θ(log n)
By Master Theorem or recursion tree analysis

Time Complexity

Best: O(1) - element at middle

Average: O(log n)

Worst: O(log n) - element at end or not present

Space Complexity

Iterative: O(1) - only variables

Recursive: O(log n) - call stack
