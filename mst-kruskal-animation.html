🌳 Welcome! Let's learn about Minimum Spanning Trees

This page will teach you Kruskal's algorithm — a famous method for finding a Minimum Spanning Tree (MST) in a graph. Don't worry if those words sound scary — we'll explain everything step by step!

🔤 Key Concepts — What Is a Graph?

Vertex (plural: vertices) — a point or a node. In our example: 0, 1, 2, 3, 4, 5, 6, 7. Think of them as cities on a map.

Edge — a connection between two vertices. Think of it as a road between two cities.

Weight — a number on each edge representing cost. Higher weight = more expensive road (longer distance, more materials, etc.)

Graph — a collection of vertices connected by edges. Like a road map of cities.

🔤 What is a "Spanning Tree"?

Tree — a set of edges that connects all vertices without any loops (no cycles). Like a family tree — no one is their own grandparent!

Spanning — means it "spans" (reaches) every vertex in the graph.

Spanning Tree — a selection of edges that connects all cities using the fewest possible roads (|V|−1 edges for |V| vertices), with no loops.

Minimum Spanning Tree (MST) — the spanning tree with the smallest total weight. The cheapest way to connect all cities!

🏙️ Real-world analogy: Imagine you're building a fiber-optic network to connect 8 cities. Laying cable between two cities costs money (the weight). You want to connect all cities for the lowest total cost. You'd build exactly enough cables so every city is connected, with no wasteful loops. That's the MST!

🔤 How Kruskal's Algorithm Works

Kruskal's algorithm uses a greedy strategy (take the best option right now, without worrying about the future):

1. List all roads from cheapest to most expensive.

2. Start with each city in its own group.

3. Go through the list from cheapest to most expensive:

• If the two cities are in different groups → build this road (merge the groups)

• If they're already in the same group → skip it (would create a wasteful loop)

4. Stop when all cities are in one group.

Greedy rule: pick the cheapest road that connects two separated groups
