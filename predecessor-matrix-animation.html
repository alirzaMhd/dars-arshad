What is the Predecessor Matrix Π?

The predecessor matrix Π stores the predecessor of vertex j on the shortest path from vertex i.

Together with the distance matrix D, Π lets us reconstruct the actual shortest path between any pair of vertices.

Key Formula

π[i][j] = predecessor of j on shortest path i→...→j π[i][j] = NIL if no path exists or i=j

D gives you how long the shortest path is. Π tells you which path to take.
