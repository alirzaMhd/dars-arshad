Arc Consistency (AC-3 Algorithm)

Constraint Propagation for All Binary Constraints

What is Arc Consistency?

An arc in a constraint graph is a directed edge from variable Xi to Xj. The arc (Xi, Xj) is consistent if for every value x in Di, there exists some value y in Dj such that (x, y) satisfies all constraints between Xi and Xj.

Arc Consistency Definition:
Arc (Xi, Xj) is consistent ⇔ ∀x ∈ Di: ∃y ∈ Dj such that (x,y) satisfies Cij
Every value in Xi's domain must have a compatible value in Xj's domain

Forward Checking vs Arc Consistency

FeatureForward CheckingArc Consistency
Propagation1-step (from assigned var)Full (all arcs repeatedly)
PowerCatches neighbor conflictsCatches all binary conflicts
Example missedNT=blue, SA=blue (conflict)Detects this via (NT,SA) arc
OverheadLowerHigher (O(n²·d³))
Key Contrast: Forward checking only looks at arcs from an assigned variable. Arc consistency iteratively corrects ALL arcs, propagating changes through the entire constraint graph.

The AC-3 Algorithm

function AC-3(csp) returns the CSP, possibly with reduced domains inputs: csp, a binary CSP with variables {X₁, X₂, ..., Xₙ} local variables: queue, a queue of arcs, initially all arcs in csp while queue is not empty do (Xᵢ, Xⱼ) ← REMOVE-FIRST(queue) if REMOVE-INCONSISTENT-VALUES(Xᵢ, Xⱼ) then for each Xₖ in NEIGHBORS[Xᵢ] do add (Xₖ, Xᵢ) to queue function REMOVE-INCONSISTENT-VALUES(Xᵢ, Xⱼ) returns true if domain changed removed ← false for each x in DOMAIN[Xᵢ] do if there is no y in DOMAIN[Xⱼ] such that (x,y) satisfies Cᵢⱼ then delete x from DOMAIN[Xᵢ] removed ← true return removed

Complexity Analysis

Time Complexity:
O(n² · d³)
where n = number of variables, d = max domain size
  • • At most O(n²) arcs in a binary CSP (n choose 2 pairs)
  • • Each arc is added to queue at most d times (each domain removal)
  • • Each consistency check takes O(d²) (checking all pairs of values)
  • • Total: O(n² · d · d²) = O(n² · d³)
Note: AC-3 can be used as a preprocessing step before search, or as a propagation step (called MAC — Maintaining Arc Consistency) after each assignment during search.

Worked Examples

Example 1: Australia — Arc Consistency Detects Hidden Conflict

State: WA=red, Q=green, V=blue, with arcs not yet propagated.

Domains after forward checking: NT={blue}, SA={blue}, NSW={red, blue}

Forward checking didn't detect that NT and SA would conflict (both must be blue, but they're adjacent).

AC-3 checks arc (NT, SA):

• NT=blue requires SA ≠ blue. But SA only has {blue}.

• No compatible value → remove blue from SA → SA becomes empty!

AC-3 detects the inconsistency that forward checking missed!

Example 2: Arc Consistency as Preprocessing

Initial CSP: Variables A, B, C with domains {1, 2, 3}

Constraints: A < B, B < C

Preprocessing with AC-3:

• Check arc (A, B): A must have a value less than some B value. A=3 has no partner in B → remove A=3. DA = {1, 2}

• Check arc (B, A): B must have a value greater than some A value. B=1 has no partner → remove B=1. DB = {2, 3}

• Check arc (B, C): B must have value less than some C. B=3 has no partner → remove B=3. DB = {2}

• Check arc (C, B): C must have value greater than some B. C=1,2 have no partner → remove them. DC = {3}

Final domains: DA={1,2}, DB={2}, DC={3}

The search now proceeds with no backtracking!

Example 3: AC-3 on a Small Constraint Graph

Variables: X, Y with domains {a, b, c}

Constraint: X ≠ Y

Check arc (X, Y):

• X=a → Y can be {b, c} ✓

• X=b → Y can be {a, c} ✓

• X=c → Y can be {a, b} ✓

Arc (X,Y) is consistent — no values removed.

Check arc (Y, X): Same — all values have partners.

No domain reduction possible with just binary inequality when both domains have ≥2 values.

Example 4: When Arc Consistency Cannot Detect the Problem

AC-3 checks binary arcs individually. It does not detect all inconsistencies.

Consider: WA=red, NT=red. AC-3 checks (WA, NT) and finds:

• WA=red needs NT≠red, but NT's remaining domain is {red} → remove red from WA → WA's domain becomes {green, blue}.

But if there are ternary constraints or complex interactions, AC-3 might not catch them.

K-consistency (for k>2) is needed for stronger propagation, but at exponential cost.

Quick Reference

Arc Definition

Directed edge (Xi, Xj)

Consistent: each Xi value has a compatible Xj value

Not symmetric! (Xi,Xj) can be consistent while (Xj,Xi) is not

AC-3 Properties

• Time: O(n² · d³)

• Space: O(n²) for queue

• Complete for binary consistency

• Still misses some conflicts

Use Cases

• Preprocessing before search

• MAC (Maintaining Arc Consistency) during search

• More powerful than forward checking

Limitations

• Cannot detect n-ary inconsistencies

• SAT is a special case of CSP — no poly-time algorithm can detect all inconsistencies

• K-consistency is stronger but exponential
