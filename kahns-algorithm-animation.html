What is Kahn's Algorithm?

Kahn's algorithm performs a topological sort of a Directed Acyclic Graph (DAG) by repeatedly removing vertices with in-degree 0.

Key Idea

Every DAG has at least one vertex with in-degree 0 (no incoming edges). Such a vertex has no prerequisites and can be placed first in the order.

Algorithm Steps

1. Compute in-degree for every vertex.

2. Enqueue all vertices with in-degree 0.

3. While queue is not empty:

• Dequeue u, append to output.

• For each neighbor v, decrement in-degree(v).

• If in-degree(v) becomes 0, enqueue v.

4. If all vertices output → valid topological sort.

5. If some remain → graph has a cycle.
