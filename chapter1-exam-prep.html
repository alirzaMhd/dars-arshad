نکته ۴ سوال C11 — ترتیب رشد توابع

نکته ۴ سوال C30 — مسئله خرس قطبی
خرس قطبی n تکه پنیر دارد. هر روز اگر تعداد فرد باشد یکی می‌خورد و بقیه را ذخیره می‌کند. اگر زوج باشد نصفش را ذخیره و نصف دیگر را می‌خورد. عمر خرس چند روز است؟
هر بار که خرس غذا می‌خورد، ذخیره‌اش n/2 می‌شود (تقریباً). مجموع عمر = n + n/2 + n/4 + ... = 2n. این یک سری هندسی است با مجموع 2n.
سری هندسی 1 + 1/2 + 1/4 + ... = 2. این فرمول بارها در تحلیل الگوریتم‌ها استفاده می‌شود.

نکته ۴ سوال P2 — درست/نادرست درباره نمادها
عبارات زیر درست یا نادرست هستند؟ (۶ قسمت)

نکته ۴ سوال P3 — f=O(g) و g=O(f)
آیا ممکن است f(n)=O(g(n)) و g(n)=O(f(n)) هر دو برقرار باشند؟
خیر — اگر f=O(g) و g=O(f) هر دو برقرار باشند، آنگاه f=θ(g) است (همان نرخ رشد). ولی اگر توابع نوسانی باشند (مثل f=n و g=n+sin(n))، ممکن است هیچکدام برقرار نباشد.
این سوال یک مفهوم ظریف را آزمایش می‌کند: O و θ چه تفاوتی دارند.

حل کامل سوال C23 — حذف از انتهای لیست پیوندی
عبارت زیر کدام نادرست است؟
۱) n! = O(nⁿ)
۲) O(nⁿ) << O(6ⁿ · 2¹⁰)
۳) Θ(n²) همچنین O(n²) است
۴) حذف آخرین عنصر در لیست پیوندی تک‌طرفه با اشاره‌گرهای first و last از مرتبه O(1) است
حذف آخرین گره از لیست پیوندی تک‌طرفه حتی با اشاره‌گر last، O(n) است — نه O(1)!

حل کامل:

  1. گزینه ۱: n! = O(nⁿ) — صحیح است. فاکتوریل همیشه از nⁿ کمتر رشد می‌کند.
  2. گزینه ۲: O(nⁿ) رشد سریع‌تری از O(6ⁿ) دارد — این نیز صحیح است.
  3. گزینه ۳: Θ(g(n)) ⊂ O(g(n)) — هر θ لزوماً O هم هست. صحیح است.
  4. گزینه ۴: برای حذف آخرین گره از لیست تک‌طرفه، باید گره قبل از آخر را پیدا کنید. حتی با اشاره‌گر last، باید از اول لیست پیمایش کنید → O(n). این گزینه نادرست است.
اشتباه رایج: دانشجوها فکر می‌کنند داشتن اشاره‌گر last = دسترسی O(1) به آخر. ولی در لیست تک‌طرفه، حذف گره نیاز به گره قبلی دارد!
نکته حفظی: در لیست دوطرفه حذف از آخر O(1) است. در لیست تک‌طرفه O(n) است — حتی با اشاره‌گر last.

حل کامل سوال C7 — بهترین و بدترین حالت
قطعه برنامه زیر: بهترین و بدترین حالت زمان مصرفی چیست؟
for i=2 to n do
  if k|i then mod=0
  for j=i to k do
    k*=l; l++
وقتی شرطی تعیین می‌کند حلقه داخلی اجرا شود یا نه، بهترین حالت = شرط هرگز برقرار نباشد، بدترین حالت = شرط همیشه برقرار باشد.

حل کامل:

  1. تحلیل کد: حلقه بیرونی n-1 بار اجرا می‌شود (از 2 تا n). حلقه داخلی فقط زمانی اجرا می‌شود که k divides i باشد.
  2. بهترین حالت: اگر k بین 2 و n نباشد (مثلاً k=1 یا k>n)، حلقه inside هرگز اجرا نمی‌شود → زمان = O(n).
  3. بدترین حالت: اگر k بین 2 و n باشد و k هر i را تقسیم کند (مثلاً k=2)، حلقه inside هر بار اجرا می‌شود → زمان = O(n²).
اشتباه رایج: فقط بدترین حالت را حساب کردن و بهترین حالت را فراموش کردن.
نکته حفظی: در تحلیل بهترین/بدترین حالت، باید ویژگی‌های ورودی که شرط را تحت تأثیر قرار می‌دهند شناسایی کنید.

حل کامل سوال C20 — تابع sin(n) در Ω
کدام گزینه صحیح است؟
۱) n²·sin(n) ∈ Ω(n²)
۲) n²·sin(n) ∈ O(n²)
۳) n²·sin(n) ∈ Θ(n²)
۴) n²·sin(n) ∈ ω(n²)
برای توابع نوسانی مثل sin، باید دقیق بررسی کنید: sin(n) همیشه مثبت نیست ولی گاهی مقدار مثبت می‌گیرد.

حل کامل:

  1. بررسی sin(n): تابع sin(n) بین -1 و 1 نوسان می‌کند. برای n‌های طبیعی، sin(n) گاهی مثبت و گاهی منفی است.
  2. اثبات Ω: برای Ω(n²) باید C مثبتی پیدا کنیم که n²·sin(n) ≥ C·n² برای n ≥ n₀. چون sin(n) ≥ -1، پس n²·sin(n) ≥ -n². ولی این Ω(n²) نیست!我们需要找到 n₀ و C که sin(n) ≥ C > 0 باشد. از آنجا که sin(n) گاهی بزرگ‌تر از 1/2 می‌شود (مثلاً sin(π/2)=1)، و اعداد طبیعی به π نزدیک می‌شوند، وجود دارد n‌هایی که sin(n) > 0.5. پس n²·sin(n) ≥ 0.5·n² برای این n‌ها → Ω(n²).
  3. بررسی O: n²·sin(n) ≤ n²·1 = n² → O(n²) هم صحیح است.
  4. نتیجه: هر دو Ω و O صحیح هستند، پس Θ هم صحیح است. گزینه ۳ بهترین پاسخ است.
اشتباه رایج: فکر کردن sin(n) همیشه مثبت است یا همیشه منفی — باید نوسان آن را در نظر بگیرید.
نکته حفظی: برای Ω اثبات کنید f(n) ≥ C·g(n). برای O اثبات کنید f(n) ≤ C·g(n). اگر هر دو درست باشد → θ.

حل کامل سوال C11 — ترتیب رشد توابع
مجموعه توابع زیر بر حسب Order از کدامیک راست به چپ هستند؟
۱) n! و n¹⁰⁰⁰ و n^(100/5)
۲) n! و n^(100/5) و n¹⁰⁰⁰
۳) n¹⁰⁰⁰ و n! و n^(100/5)
۴) n^(100/5) و n! و n¹⁰⁰⁰
ترتیب رشد از کم به زیاد: n^(100/5) = n²⁰ < n¹⁰⁰⁰ < n!. فاکتوریل همیشه سریع‌تر از هر توانی رشد می‌کند.

حل کامل:

  1. محاسبه n^(100/5): 100/5 = 20. پس n^(100/5) = n²⁰.
  2. مقایسه n²⁰ و n¹⁰⁰⁰: چون 1000 > 20، n¹⁰⁰⁰ سریع‌تر از n²⁰ رشد می‌کند.
  3. مقایسه n¹⁰⁰⁰ و n!: از قضیه Stirling: n! ≈ (n/e)ⁿ · √(2πn). این از هر توان nᵏ سریع‌تر رشد می‌کند چون توان خود n است.
  4. ترتیب نهایی: n²⁰ < n¹⁰⁰⁰ < n! → گزینه ۲ صحیح است.
اشتباه رایج: فکر کردن n¹⁰⁰⁰ سریع‌تر از n! است — در واقع n! خیلی سریع‌تر رشد می‌کند.
نکته حفظی: n! > aⁿ > nᵏ > n·log n > n² > n > log n > 1 (برای a > 1 و k > 0).

حل کامل سوال C30 — مسئله خرس قطبی
خرس قطبی n تکه پنیر دارد. هر روز اگر n فرد باشد یکی می‌خورد و بقیه را ذخیره می‌کند. اگر n زوج باشد نصفش را ذخیره و نصف دیگر را می‌خورد. اگر خرس نباشد، گوشتی باقی نمی‌ماند. عمر خرس چند روز است؟
مجموع عمر خرس = n + n/2 + n/4 + ... = 2n (سری هندسی). مرتبه Θ(n).

حل کامل:

  1. روز اول: n تکه پنیر. اگر فرد: یکی می‌خورد، n-1 باقی می‌ماند. اگر زوج: نصف را می‌خورد، n/2 باقی می‌ماند.
  2. روز دوم: تعداد باقی‌مانده تقریباً n/2 است. دوباره همان فرآیند تکرار می‌شود.
  3. الگو: هر روز تعداد پنیر تقریباً نصف می‌شود. تعداد روزها = n + n/2 + n/4 + ...
  4. محاسبه سری: s = n(1 + 1/2 + 1/4 + ...) = n · 2 = 2n.
  5. مرتبه: 2n ∈ Θ(n). پس گزینه ۱ صحیح است.
اشتباه رایج: فکر کردن عمر خرس log(n) است — در واقع مجموع سری هندسی 2n است.
نکته حفظی: سری هندسی 1 + r + r² + ... = 1/(1-r) برای |r| < 1. اینجا r = 1/2 → مجموع = 2.

حل کامل سوال C17 — ترکیب توابع
فرض کنید f و g توابع دلخواه f,g: ℝ⁺→ℝ⁺ هستند و lim(n→∞) f(n)/g(n) = +∞. کدام یک از گزاره‌های زیر صحیح است؟
۱) g(f(n)) ∈ Ω و f(n) ∈ O(g(n))
۲) f(n) ∈ O(g(n)) و g(n) ∈ O(f(n))
۳) f(g(n)) ∈ Ω و f(g(n)) ∉ θ
۴) g(f(n)) ∈ Ω و f(g(n)) ∈ θ
اگر f سریع‌تر از g رشد کند، ترکیب f(g(n)) حتی سریع‌تر رشد می‌کند — ترکیب تفاوت رشد را تقویت می‌کند.

حل کامل:

  1. تحلیل شرط: lim f/g = +∞ یعنی f خیلی سریع‌تر از g رشد می‌کند. مثلاً f=n² و g=n.
  2. بررسی f(g(n)): اگر f=n² و g=n باشد، f(g(n)) = f(n) = n². اگر f=n³ و g=n² باشد، f(g(n)) = f(n²) = (n²)³ = n⁶. پس f(g(n)) خیلی سریع‌تر از f(n) رشد می‌کند.
  3. نتیجه: f(g(n)) ∈ Ω (رشدش بیشتر از هر تابع معینی است) ولی f(g(n)) ∉ θ (رشدش دقیقاً برابر هیچ تابع معینی نیست). گزینه ۳ صحیح است.
اشتباه رایج: فکر کردن f(g(n)) = g(f(n)) — ترکیب توابع commutative نیست!
نکته حفظی: f(g(n)) و g(f(n)) متفاوت هستند. اگر f سریع‌تر باشد، f(g(n)) سریع‌تر از g(f(n)) رشد می‌کند.

حل کامل سوال C19 — ترتیب رشد (ε > 0)
ترتیب صحیح توابع رشد کدام است؟ (ε > 0)
۱) n·log(n/3) < n^ε < n·log₂n
۲) n·log₂n < n^ε < n·log(n/3)
۳) n^ε < n·log(n/3) < n·log₂n
۴) n·log(n/3) < n·log₂n < n^ε
برای هر ε > 0 مثبت، n^ε سریع‌تر از log n رشد می‌کند. پس n·log(n/3) < n^ε < n·log₂n.

حل کامل:

  1. مقایسه n·log(n/3) و n^ε: از حد انتها: lim(n→∞) n·log(n/3) / n^ε = lim log(n/3) / n^(ε-1). چون ε-1 < 0 (برای ε < 1)، مخرج به 0 می‌لارد → حد = 0. پس n·log(n/3) < n^ε.
  2. مقایسه n^ε و n·log₂n: از حد انتها: lim(n→∞) n^ε / (n·log₂n) = lim n^(ε-1) / log₂n. چون ε-1 < 0 (برای ε < 1)، حد = 0. پس n^ε < n·log₂n.
  3. نتیجه: n·log(n/3) < n^ε < n·log₂n → گزینه ۱ صحیح است.
اشتباه رایج: فکر کردن log n سریع‌تر از n^ε است — در واقع هر توان مثبتی از n سریع‌تر از log n رشد می‌کند.
نکته حفظی: lim(n→∞) n^ε / log n = ∞ برای هر ε > 0. یعنی n^ε همیشه سریع‌تر از log n رشد می‌کند.

حل کامل سوال P2 — درست/نادرست درباره نمادها (۶ قسمت)
عبارات زیر درست یا نادرست هستند؟
a) max{f(n)+1, g(n)} = Θ(f(n)+g(n))
b) اگر f(n)=Ω(n²) و g(n)=Ω(n²) باشد آنگاه f(n)·g(n)=Ω(n³)
c) f(g(n)) = θ(f(n)·g(n))
d) f(n) = θ(f(n²))
e) اگر T₁(n)=O(f(n)) و T₂(n)=O(f(n)) باشد...
f) اگر f(n)=Ω(g(n)) و g(n)=O(f(n)) باشد آنگاه f(n)=Ω(g(n))
هر بخش یک قاعده متفاوت از نمادهای نمادی را آزمایش می‌کند — باید هر کدام را جداگانه بررسی کنید.

حل کامل:

  1. (a) صحیح: max{f+1, g} ≤ f+1+g ≤ 2(f+g) و max{f+1, g} ≥ max{f, g} ≥ (f+g)/2. پس Θ(f+g).
  2. (b) نادرست: اگر f(n)=n² و g(n)=n³ باشد (هر دو Ω(n²))، آنگاه f·g=n⁵. ولی n⁵ ∈ Ω(n⁴) لزوماً Ω(n³) نیست... در واقع n⁵ ≥ n³ است پس Ω(n³) هم هست. بله، (b) صحیح است.
  3. (c) نادرست: f(g(n)) لزوماً برابر f(n)·g(n) نیست. مثلاً f(n)=n و g(n)=n → f(g(n))=n ولی f·g=n².
  4. (d) نادرست: f(n) لزوماً θ(f(n²)) نیست. مثلاً f(n)=n → f(n²)=n² که θ(n) نیست.
  5. (e) بستگی به قسمت دارد: T₁+T₂ = O(f) صحیح است. T₁·T₂ = O(f²) ولی لزوماً O(f) نیست.
  6. (f) صحیح: f=Ω(g) یعنی f رشدش بیشتر از g است. g=O(f) یعنی g رشدش کمتر از f است. هر دو یک چیز می‌گویند.
اشتباه رایج: فکر کردن O(f) = θ(f) — O فقط upper bound است، θ هم upper و هم lower.
نکته حفظی: f=θ(g) ⟺ f=O(g) و f=Ω(g). θ یعنی «مرتبه دقیقاً برابر».
