Simple Grammars (S-Grammars)

Efficient Parsing with Restricted CFGs — Complete Guide

What is a Simple Grammar?

A context-free grammar G is a simple grammar (S-grammar) if all production rules are of the form:

Rule Form:
A → aα
where A ∈ V (variable), a ∈ Σ (terminal), α ∈ V* (zero or more variables), and the pair (A, a) appears at most once in P.
Key Restriction:
For each variable A and terminal a, there is AT MOST ONE rule of the form A → aα
This means the choice of which rule to apply is uniquely determined by the current variable and the next input symbol.

Why Simple Grammars?

  • Deterministic parsing: At each step, the next rule is uniquely determined
  • O(n) parsing: Membership testing can be done in linear time
  • No backtracking needed: The parser never needs to try multiple alternatives
  • Unambiguous: Every simple grammar is unambiguous

Properties of Simple Grammars

Property 1:
Every simple grammar is unambiguous
The unique rule selection ensures only one parse tree per string.
Property 2:
For simple grammars, |P| ≤ |V| × |Σ|
Each (variable, terminal) pair can have at most one rule.
Property 3:
Membership testing: O(n) where n = |w|
Simply scan the input left to right, applying the unique applicable rule at each step.
Property 4:
Not every CFL has a simple grammar
Simple grammars are a strict subset of all CFGs.

Example 4: True Simple Grammar

Simple grammar for aⁿbⁿ (n ≥ 1):

S → aB

B → aBb | b

Check:

• S → aB: (S, a) ✓

• B → aBb: (B, a) ✓

• B → b: (B, b) ✓

All pairs are unique — this IS a simple grammar!
