Linear Search (Sequential Search)

Definition:
Search sequentially through array from first to last element
Works on both sorted and unsorted arrays
Algorithm:
seqsearch(A[1..n], x): loc = 1 while loc <= n and A[loc] != x: loc = loc + 1 if loc > n: return NIL // not found else: return loc // found at position loc

Binary Search

Requirement:
Array MUST be sorted (ascending or descending)
Divide search space in half at each step

Recursive Version

recbinary(A, low, high, x): if low > high: return NIL mid = floor((low + high) / 2) if x == A[mid]: return mid elif x > A[mid]: return recbinary(A, mid + 1, high, x) else: return recbinary(A, low, mid - 1, x)

Iterative Version

iterbinary(A, low, high, x): while low <= high: mid = floor((low + high) / 2) if x == A[mid]: return mid elif x > A[mid]: low = mid + 1 else: high = mid - 1 return NIL

• If A[mid] > x: search left half (high = mid - 1)

Use Linear When:

Example 3: Recurrence Relation

Solve: T(n) = T(n/2) + 1, T(1) = 1

T(n) = T(n/2) + 1 = T(n/4) + 1 + 1 = T(n/8) + 1 + 1 + 1 = ... = T(n/2^k) + k When n/2^k = 1 → k = log₂n T(n) = 1 + log₂n = ⌊log₂n⌋ + 1

This proves binary search is O(log n)

Example 4: Comparisons Count

For array of size 1000:

Linear Search:

• Best: 1 comparison

• Worst: 1000 comparisons

• Average: 500 comparisons

Binary Search:

• Best: 1 comparison

• Worst: 10 comparisons (⌊log₂1000⌋ + 1)

• Average: ~9 comparisons

Example 5: When Binary Search Fails

Array: [5, 3, 8, 1, 9, 2] — UNSORTED

Search for x = 8 using Binary Search:

mid = 2, A[mid] = 8 → Found!

This worked by luck! But search for x = 5:

mid = 2, A[mid] = 8, 5 < 8, go left

mid = 0, A[mid] = 5 → Found! (but wrong logic)

Binary search is UNRELIABLE on unsorted arrays!

⚠ Exam Tips:

• Binary search needs sorted array

• mid = ⌊(low + high) / 2⌋ (floor function)

• Recurrence: T(n) = T(n/2) + 1

• Solution: T(n) = ⌊log₂n⌋ + 1

• Linear: O(n), Binary: O(log n)
