سوال پایهتمرین ۱اهمیت: ★★★☆☆
حاصل عبارات زیر را بیابید (اجزای a تا e شامل مجموع‌ها)
  • a) Σ(k=1 to n) k
  • b) Σ(k=1 to n) k²
  • c) Σ(k=0 to n) x^k
  • d) Σ(k=1 to n) (2k-1)
  • e) Σ(k=1 to n) 1/k²
چرا این سوال پایه‌ای است
  • محاسبه ساده سیگما — پیش‌نیاز درک سایر سوالات فصل

پاسخ

a) Σ k = n(n+1)/2
b) Σ k² = n(n+1)(2n+1)/6
c) Σ x^k = (1 - x^(n+1)) / (1 - x) (x ≠ 1)
d) Σ (2k-1) = n² (مجموع n عدد فرد اول)
e) Σ 1/k² < π²/6 (سری بازل)

نکته کلیدی: فرمول‌های مجموع‌ها را حفظ کنید — اینها پایه تحلیل الگوریتم‌ها هستند.

نکته پنهانتمرین ۲تکنیک: مشتق سری هندسی
نشان دهید Σ(k=1 to ∞) kx^k = x/(1-x)² به ازاي |x|<1

نکته‌ای که کتاب توضیح نداده

استفاده از مشتق سری هندسی برای به دست آوردن فرمول — این تکنیک در بخش توضیحات کتاب به صورت کامل توضیح داده نشده است.

چرا مهم است

تکنیک مشتق گرفتن از سری هندسی در بسیاری از مسائل انتگرال و سری کاربرد دارد.

چرا مهم است
  • تکنیک مشتق گرفتن از سری هندسی در بسیاری از مسائل انتگرال و سری کاربرد دارد

حل گام به گام

  1. از سری هندسی شروع کنید: Σ(k=0 to ∞) x^k = 1/(1-x) برای |x|<1
  2. هر دو طرف را نسبت به x مشتق بگیرید: d/dx [Σ x^k] = Σ kx^(k-1) = 1/(1-x)²
  3. هر دو طرف را در x ضرب کنید: Σ kx^k = x/(1-x)²

هرگاه مجموعی به صورت k·x^k باشد، مشتق گرفتن از سری هندسی کلید حل است.

سوال پایهتمرین ۳اهمیت: ★★★★★
نشان دهید Σ(k=1 to n) 1/k = ln(n) + c برای ثابتی c
چرا این سوال پایه‌ای است
  • سری همسازه — مفهوم پایه‌ای که در تحلیل الگوریتم‌ها استفاده می‌شود

پاسخ

سری همسازه Σ(1/k) با ln(n) معاوض است (harmonic series). ثابت c برابر است با ثابت اویلر-ماسچرونی (γ ≈ 0.5772).

حفظ کنید

سری همسازه H(n) = Σ(1/k) ≈ ln(n) + γ — این رابطه در تحلیل زمان اجرای بسیاری از الگوریتم‌ها (مثل Quicksort) استفاده می‌شود.

سوال پایهتمرین ۴اهمیت: ★★★☆☆
نشان دهید Σ(k=1 to ∞) (1/2)^k به یک ثابت محدود می‌شود
چرا این سوال پایه‌ای است
  • درک محدود بودن سری هندسی

پاسخ

Σ(k=1 to ∞) (1/2)^k یک سری هندسی با r=1/2 است. مقدار آن: (1/2)/(1-1/2) = 1

سری هندسی Σ r^k همگراست اگر |r|<1 باشد و مقدار آن r/(1-r) است.

نکته پنهانتمرین ۵تکنیک: انتگرال برای تخمین کران
بهترین کران را برای مج‌های زیر بیابید (r≥0 و s ثابت):
  • a) Σ(k=1 to n) k^r
  • b) Σ(k=1 to n) k^s · r^k

نکته‌ای که کتاب توضیح نداده

استفاده از تکنیک انتگرال برای تخمین کران سیگما — در کتاب توضیح داده شده اما استفاده عملی آن در سوالات تمرین نشده است.

چرا مهم است
  • این تکنیک برای تحلیل زمان اجرای حلقه‌ها ضروری است

حل گام به گام

  1. نابرابری انتگرالی: ∫(1 to n) f(x)dx ≤ Σ(k=1 to n) f(k) ≤ ∫(1 to n+1) f(x)dx
  2. برای حالت a: Σ k^r ≈ n^(r+1)/(r+1) برای r≠-1
  3. برای حالت b: از تقسیم به دو حالت r<1 و r≥1 استفاده کنید

هرگاه مجموع به صورت Σ f(k) باشد، از انتگرال برای تخمین کران استفاده کنید.

سوال دشوارتمرین ۶درجه سختی: ★★★★★
ثابت کنید lg n! = Θ(n·lg n)
چرا این سوال دشوار است
  • استفاده از تقریب استرلینگ (Stirling's approximation) که ممکن است دانشجوها آن را ندانند
  • نیاز به دقت در اثبات کران بالا و پایین

حل گام به گام

  1. تقریب استرلینگ: n! ≈ √(2πn)(n/e)^n
  2. lg n! ≈ lg(√(2πn)) + n·lg(n/e) = ½·lg(2πn) + n·lg n - n·lg e
  3. بنابراین lg n! = n·lg n - n·lg e + O(lg n) = Θ(n·lg n)

حفظ کنید

lg n! ≈ n·lg n - n·lge + O(lg n) — این فرمول را حفظ کنید.

سوال دشوارتمرین ۷درجه سختی: ★★★★★
درستی یا نادرستی گزاره‌های زیر را مشخص کنید:
  • a) f(n)∈O(g(n)) → f(n²)∈O(g(n²))
  • d) f(n)∈O(f(n)²)
  • h) f+g = θ(min{f,g})
چرا این سوال دشوار است
  • گزاره (a): نادرست — counterexample: f=n, g=n²
  • گزاره (d): بستگی به مقدار f(n) دارد
  • گزاره (h): نادرست — باید max باشد نه min

پاسخ

a) نادرست: f(n)=n, g(n)=n² → f(n²)=n² اما g(n²)=n⁴.

d) نادرست: اگر f(n)=0.5 باشد، f(n)∉O(f(n)²) چون 0.5 ∉ O(0.25).

h) نادرست: f+g = Θ(max{f,g}) نه min{f,g}.

O(f(n)) ∩ Ω(f(n)) = Θ(f(n)) — این را به خاطر بسپارید.

سوال دشوارتمرین ۸درجه سختی: ★★★☆☆
آیا تابع f(n) = ⌈lg n!⌉ محدود به چندجمله‌ای است?
چرا این سوال دشوار است
  • نیاز به درک رشد فاکتوریل نسبت به چندجمله‌ای‌ها

پاسخ

خیر. lg n! ≈ n·lg n - n·lge + O(lg n) که از هر چندجمله‌ای P(n) بیشتر رشد دارد.

lg n! از همه چندجمله‌ای‌ها بیشتر رشد دارد — پاسخ همیشه خیر است.

سوال پایهتمرین ۹اهمیت: ★★★★☆

نکته پنهانتمرین ۱۲تکنیک: جایگذاری
نشان دهید اگر k·ln k = Θ(n) آنگاه k = Θ(n/ln n)

نکته‌ای که کتاب توضیح نداده

تکنیک جایگذاری — قرار دادن k = n/ln n در عبارت اولیه و ساده‌سازی

چرا مهم است
  • تکنیک جایگذاری (substitution) — قرار دادن k = n/ln n در عبارت اولیه

حل گام به گام

  1. فرض کنید k = Θ(n/ln n). باید نشان دهیم k·ln k = Θ(n).
  2. ln k = ln(n/ln n) = ln n - ln ln n ≈ ln n
  3. k·ln k ≈ (n/ln n)·ln n = n ✓

این تکنیک جایگذاری در حل بازگشت‌ها (recurrences) بسیار مهم است.

چرا این سوال دشوار است
  • استفاده از تقریب استرلینگ (Stirling's approximation) که ممکن است دانشجوها آن را ندانند
  • نیاز به دقت در اثبات کران بالا و پایین

حل گام به گام

  1. تقریب استرلینگ: n! ≈ √(2πn)(n/e)^n
  2. lg n! ≈ lg(√(2πn)) + n·lg(n/e) = ½·lg(2πn) + n·lg n - n·lg e
  3. بنابراین lg n! = n·lg n - n·lg e + O(lg n) = Θ(n·lg n)

حفظ کنید

lg n! ≈ n·lg n - n·lge + O(lg n) — این فرمول را حفظ کنید.

سوال دشوارتمرین ۷درجه سختی: ★★★★★

چرا این سوال دشوار است

  • گزاره (d): بستگی به مقدار f(n) دارد
  • گزاره (h): نادرست — باید max باشد نه min

پاسخ

a) نادرست: f(n)=n, g(n)=n² → f(n²)=n² اما g(n²)=n⁴.

d) نادرست: اگر f(n)=0.5 باشد، f(n)∉O(f(n)²) چون 0.5 ∉ O(0.25).

h) نادرست: f+g = Θ(max{f,g}) نه min{f,g}.

O(f(n)) ∩ Ω(f(n)) = Θ(f(n)) — این را به خاطر بسپارید.

نکته پنهانتمرین ۲تکنیک: مشتق سری هندسی
نشان دهید Σ(k=1 to ∞) kx^k = x/(1-x)² به ازاي |x|<1

نکته‌ای که کتاب توضیح نداده

استفاده از مشتق سری هندسی برای به دست آوردن فرمول — این تکنیک در بخش توضیحات کتاب به صورت کامل توضیح داده نشده است.

چرا مهم است

تکنیک مشتق گرفتن از سری هندسی در بسیاری از مسائل انتگرال و سری کاربرد دارد.

چرا مهم است
  • تکنیک مشتق گرفتن از سری هندسی در بسیاری از مسائل انتگرال و سری کاربرد دارد

حل گام به گام

  1. از سری هندسی شروع کنید: Σ(k=0 to ∞) x^k = 1/(1-x) برای |x|<1
  2. هر دو طرف را نسبت به x مشتق بگیرید: d/dx [Σ x^k] = Σ kx^(k-1) = 1/(1-x)²
  3. هر دو طرف را در x ضرب کنید: Σ kx^k = x/(1-x)²

هرگاه مجموعی به صورت k·x^k باشد، مشتق گرفتن از سری هندسی کلید حل است.

نکته پنهانتمرین ۵تکنیک: انتگرال برای تخمین کران
بهترین کران را برای مج‌های زیر بیابید (r≥0 و s ثابت):
  • a) Σ(k=1 to n) k^r
  • b) Σ(k=1 to n) k^s · r^k

نکته‌ای که کتاب توضیح نداده

استفاده از تکنیک انتگرال برای تخمین کران سیگما — در کتاب توضیح داده شده اما استفاده عملی آن در سوالات تمرین نشده است.

چرا مهم است
  • این تکنیک برای تحلیل زمان اجرای حلقه‌ها ضروری است

حل گام به گام

  1. نابرابری انتگرالی: ∫(1 to n) f(x)dx ≤ Σ(k=1 to n) f(k) ≤ ∫(1 to n+1) f(x)dx
  2. برای حالت a: Σ k^r ≈ n^(r+1)/(r+1) برای r≠-1
  3. برای حالت b: از تقسیم به دو حالت r<1 و r≥1 استفاده کنید

هرگاه مجموع به صورت Σ f(k) باشد، از انتگرال برای تخمین کران استفاده کنید.

نکته پنهانتمرین ۱۲تکنیک: جایگذاری
نشان دهید اگر k·ln k = Θ(n) آنگاه k = Θ(n/ln n)

نکته‌ای که کتاب توضیح نداده

تکنیک جایگذاری — قرار دادن k = n/ln n در عبارت اولیه و ساده‌سازی

چرا مهم است
  • تکنیک جایگذاری (substitution) — قرار دادن k = n/ln n در عبارت اولیه

حل گام به گام

  1. فرض کنید k = Θ(n/ln n). باید نشان دهیم k·ln k = Θ(n).
  2. ln k = ln(n/ln n) = ln n - ln ln n ≈ ln n
  3. k·ln k ≈ (n/ln n)·ln n = n ✓

این تکنیک جایگذاری در حل بازگشت‌ها (recurrences) بسیار مهم است.
