Problem Setup

Multiply two matrices A and B to produce result matrix C.

For each element C[i,j], compute the dot product of row i from A and column j from B.

Formula

C[i,j] = Σ(k=1 to m) A[i,k] × B[k,j]

Where m is the number of columns in A (must equal rows in B)

Complexity

Time: O(n³) for n×n matrices

Space: O(n²) for result matrix
