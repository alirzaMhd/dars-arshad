SYSTEM PROPERTIES

Signal Processing — Complete Guide for 20/20 Exam

Memory Property

Memoryless System:
y(t) = f(x(t))
Output depends only on current input, not past or future values
LTI Memoryless Condition:
h(t) = k·δ(t)
Impulse response must be a scaled impulse for memoryless system

Memoryless

• Output = f(current input)

• No storage needed

• Example: y(t) = 2x(t)

With Memory

• Output depends on past/future inputs

• Requires storage

• Example: y(t) = x(t) + x(t-1)

Causality Property

Causal System:
h(t) = 0 for t < 0
Output depends only on present and past inputs, not future inputs
Discrete Causal System:
h[n] = 0 for n < 0
Output at time n depends only on x[k] for k ≤ n
Anti-Causal System:
h[n] = 0 for n > 0
Output depends only on present and future inputs, not past inputs
Key Point: All real-time systems must be causal because we cannot access future input values.

Causal System

• h(t) = 0 for t < 0

• Realizable in real-time

• Example: y(t) = x(t) + x(t-1)

Non-causal System

• h(t) ≠ 0 for t < 0

• Requires future information

• Example: y(t) = x(t+1)

Anti-Causal System

• h[n] = 0 for n > 0

• Output depends on future inputs

• Example: h[n] = u[-n]

Example: Causality Check

h(t) = e^(-t)·u(t+3)

For t < -3: h(t) = 0

For -3 ≤ t < 0: h(t) ≠ 0

Result: System is non-causal because h(t) ≠ 0 for some t < 0

Stability Property (BIBO)

BIBO Stability:
Bounded Input → Bounded Output
If |x(t)| ≤ Mx < ∞, then |y(t)| ≤ My < ∞
LTI Stability Condition:
∫|h(t)|dt < ∞ (absolutely integrable)
Impulse response must be absolutely integrable for stability
Discrete Stability:
Σ|h[n]| < ∞ (absolutely summable)
Impulse response must be absolutely summable for discrete LTI stability
Example: Stability Check

h(t) = e^(-t)·u(t)

∫|h(t)|dt = ∫e^(-t)dt from 0 to ∞ = 1 < ∞

Result: System is stable

Invertibility Property

Invertible System:
h(t) * hᵢ(t) = δ(t)
System has an inverse such that cascading gives impulse
Inverse System:
H(s)·Hᵢ(s) = 1
In frequency domain, transfer functions multiply to 1
In practice, we usually find inverse systems in the frequency domain (Fourier or Laplace) rather than time domain.

Invertible

• Can recover input from output

• Inverse system exists

• Example: y(t) = 2x(t)

Non-invertible

• Cannot recover input from output

• Information is lost

• Example: y(t) = x²(t)
