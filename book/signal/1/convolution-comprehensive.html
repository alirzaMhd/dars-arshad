CONVOLUTION OPERATION

Signal Processing — Complete Guide for 20/20 Exam

What is Convolution?

Discrete Convolution:
y[n] = x[n] * h[n] = Σ x[k]·h[n-k]
Where * denotes convolution operation, k ranges from -∞ to +∞
Continuous Convolution:
y(t) = x(t) * h(t) = ∫ x(τ)·h(t-τ) dτ
Where the integral ranges from -∞ to +∞

Convolution is the mathematical operation that describes how an LTI system responds to any input signal. It combines the input signal with the system's impulse response to produce the output signal.

Key Concept

• Convolution is commutative: x*h = h*x

• It's associative: (x*h₁)*h₂ = x*(h₁*h₂)

• It's distributive: x*(h₁+h₂) = x*h₁ + x*h₂

Physical Meaning

• Represents system response to input

• Combines input with impulse response

• Output at time n depends on all input values

Properties of Convolution

Commutative Property

Property:
x(t) * h(t) = h(t) * x(t)
Order of convolution doesn't matter

Associative Property

Property:
[x(t) * h₁(t)] * h₂(t) = x(t) * [h₁(t) * h₂(t)]
Grouping of convolution doesn't matter

Distributive Property

Property:
x(t) * [h₁(t) + h₂(t)] = x(t)*h₁(t) + x(t)*h₂(t)
Convolution distributes over addition

Shift Property

Shift Property:
x(t) * δ(t-t₀) = x(t-t₀)
Convolution with shifted impulse gives shifted signal

Derivative/Integral Property

Derivative Property:
d/dt[x(t)*h(t)] = [dx/dt]*h = x*[dh/dt]
Derivative can be applied to either signal in convolution
Integral Property:
∫[x(λ)*h(λ)]dλ = [∫x(λ)dλ]*h = x*[∫h(λ)dλ]
Integration can be applied to either signal in convolution

Duration Property

Duration Property:
If x is non-zero in [a₁,b₁] and h in [a₂,b₂], then y is non-zero in [a₁+a₂, b₁+b₂]
The duration of convolution output is sum of durations of input signals
Important: Convolution with impulse gives the original signal: x(t) * δ(t) = x(t). This is called the sifting property.

Worked Examples

Example 1: Discrete Convolution

Find y[n] = x[n] * h[n] where:

x[n] = {1, 2, 3} for n = 0,1,2

h[n] = {1, 1} for n = 0,1

Solution:

y[0] = x[0]·h[0] = 1·1 = 1

y[1] = x[0]·h[1] + x[1]·h[0] = 1·1 + 2·1 = 3

y[2] = x[1]·h[1] + x[2]·h[0] = 2·1 + 3·1 = 5

y[3] = x[2]·h[1] = 3·1 = 3

Result: y[n] = {1, 3, 5, 3}

Example 2: Convolution with Impulse

Find y(t) = x(t) * δ(t-2)

Solution:

By sifting property: y(t) = x(t-2)

The output is simply the input shifted by 2 units.

Example 3: Graphical Convolution

For rectangular pulses, convolution results in triangular or trapezoidal shapes depending on pulse widths.

Key Insight: The width of convolution output is sum of widths of input signals.

Example 4: Continuous Convolution

Find y(t) = x(t) * h(t) where:

x(t) = e^(-t)·u(t), h(t) = u(t)

Solution:

y(t) = ∫x(τ)h(t-τ)dτ from 0 to t (for t ≥ 0)

y(t) = ∫e^(-τ)·1 dτ from 0 to t

y(t) = [-e^(-τ)] from 0 to t = 1 - e^(-t)

Result: y(t) = (1 - e^(-t))·u(t)

Example 5: Convolution with Shifted Impulse

Find y(t) = x(t) * δ(t-2) where x(t) = e^(-t)·u(t)

Solution:

By shift property: y(t) = x(t-2) = e^(-(t-2))·u(t-2)
