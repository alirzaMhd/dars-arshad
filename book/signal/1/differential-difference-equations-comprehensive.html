DIFFERENTIAL AND DIFFERENCE EQUATIONS

Signal Processing — Complete Guide for 20/20 Exam

Linear Constant-Coefficient Differential Equations

General Form:
Σ aₖ·dᵏy/dtᵏ = Σ bₖ·dᵏx/dtᵏ
Linear differential equation with constant coefficients relating input x(t) and output y(t)
First-Order Example:
dy/dt + 2y = 3x
First-order linear ODE with constant coefficients
Second-Order Example:
d²y/dt² + 2dy/dt = 3x
Second-order linear ODE with constant coefficients
Key Point: For the system to be LTI, the differential equation must be linear with constant coefficients, and the initial rest condition must be satisfied.
Example: Solving First-Order ODE

Given: dy/dt + 2y = 3x, y(a) = 0

For t < 0: x(t) = 0, so dy/dt + 2y = 0

Characteristic equation: s + 2 = 0 → s = -2

Homogeneous solution: y(t) = Ae^(-2t)

Applying initial condition: y(a) = 0 → A = 0

For t ≥ 0: y(t) = Ae^(-2t) + B

Substituting: -2Ae^(-2t) + 2(Ae^(-2t) + B) = 3x

Result: y(t) = (3/2)(1 - e^(-2t)) for t ≥ 0

Linear Constant-Coefficient Difference Equations

General Form:
Σ aᵢ·y[n-i] = Σ bⱼ·x[n-j]
Linear difference equation with constant coefficients relating input x[n] and output y[n]
First-Order Example:
y[n] - 0.5y[n-1] = x[n]
First-order linear difference equation
Example: Solving Difference Equation

Given: y[n] - 0.5y[n-1] = x[n], y[-1] = 0

For n < 0: x[n] = 0, so y[n] = 0.5y[n-1]

Homogeneous solution: y[n] = A(0.5)^n

Applying initial condition: y[-1] = 0 → A = 0

For n ≥ 0: y[n] = (0.5)^n·u[n]

Initial Rest Condition

Definition:
If x(t) = 0 for t < t₀, then y(t) = 0 for t < t₀
System produces zero output for zero input before time t₀
Why Initial Rest? The initial rest condition ensures that the system is LTI. Without it, the system may be linear but not time-invariant.
Implication:
y(t) = 0 for all t when x(t) = 0 for all t
Zero input produces zero output (zero-state response)
Example: Checking Initial Rest

System: dy/dt + 2y = 3x

If x(t) = 0 for t < 0, and y(a) = 0

Then y(t) = 0 for t < 0 (initial rest satisfied)

System is LTI with this condition
