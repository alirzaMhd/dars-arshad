STEP RESPONSE

Signal Processing — Complete Guide for 20/20 Exam

What is Step Response?

Definition:
s(t) = System response to u(t)
The output of an LTI system when the input is a unit step function
Discrete Version:
s[n] = System response to u[n]
The output of a discrete LTI system when input is unit step sequence

The step response is another important way to characterize LTI systems. It shows how the system responds to a sudden change in input from 0 to 1 at t=0.

Key Properties

• Shows transient response

• Reveals steady-state behavior

• Easy to measure experimentally

Applications

• Control system design

• System identification

• Performance analysis

Relationship to Impulse Response

From Impulse Response to Step Response

Integration:
s(t) = ∫h(τ)dτ from -∞ to t
Step response is the integral of impulse response

From Step Response to Impulse Response

Differentiation:
h(t) = ds(t)/dt
Impulse response is the derivative of step response
Key Insight: For LTI systems, knowing either h(t) or s(t) is sufficient to characterize the system completely. They are related by integration/differentiation.
In practice, step response is often easier to measure than impulse response because generating a perfect impulse is difficult.

Worked Examples

Example 1: RC Circuit Step Response

For RC low-pass filter with time constant τ = RC:

s(t) = (1 - e^(-t/τ))·u(t)

Explanation: The step response shows exponential rise to steady-state value of 1.

Example 2: Finding h(t) from s(t)

Given: s(t) = (1 - e^(-2t))·u(t)

Solution:

h(t) = ds(t)/dt = d/dt[(1 - e^(-2t))·u(t)]

h(t) = 2e^(-2t)·u(t) + (1 - e^(-0))·δ(t)

h(t) = 2e^(-2t)·u(t)

Example 3: Discrete Step Response

System: y[n] = 0.5y[n-1] + x[n]

h[n] = (0.5)^n·u[n]

Solution:

s[n] = Σh[k] from k=0 to n

s[n] = Σ(0.5)^k from k=0 to n

s[n] = (1 - (0.5)^(n+1))/(1 - 0.5) = 2(1 - (0.5)^(n+1))

Common Step Responses

• First-order: Exponential rise

• Second-order: Oscillatory (underdamped)

• Integrator: Ramp function
