IMPULSE RESPONSE

Signal Processing — Complete Guide for 20/20 Exam

What is Impulse Response?

Definition:
h(t) = System response to δ(t)
The output of an LTI system when the input is a unit impulse function
Discrete Version:
h[n] = System response to δ[n]
The output of a discrete LTI system when input is unit impulse sequence

The impulse response is the most important characteristic of an LTI system. Once we know the impulse response, we can determine the system's response to any input signal using convolution.

Key Properties

• Completely characterizes LTI system

• Output = Input * Impulse Response

• Determines system stability

Relationship

• y(t) = x(t) * h(t)

• y[n] = x[n] * h[n]

• h(t) = system's "fingerprint"

Why Impulse Response Matters

System Characterization

Key Insight:
Any signal can be expressed as sum of shifted impulses
x(t) = ∫ x(τ)·δ(t-τ) dτ

Convolution Integral

Output Calculation:
y(t) = ∫ x(τ)·h(t-τ) dτ
This is how we find system output for any input
Important: The impulse response h(t) contains complete information about the LTI system. If you know h(t), you know everything about the system.
In practice, we often determine h(t) experimentally by applying an impulse input and measuring the output, or analytically from system differential equations.

Worked Examples

Example 1: RC Circuit Impulse Response

For an RC low-pass filter with time constant τ = RC:

h(t) = (1/RC)·e^(-t/RC)·u(t)

Explanation: The impulse response is an exponential decay starting at t=0. The time constant RC determines how quickly the response decays.

Example 2: Discrete System Impulse Response

System: y[n] = 0.5y[n-1] + x[n]

Solution:

Apply δ[n] as input:

h[0] = 1

h[1] = 0.5

h[2] = 0.25

h[n] = (0.5)^n · u[n]

Example 3: Impulse Response from Difference Equation

System: y[n] - 0.8y[n-1] = x[n]

Solution:

h[n] = (0.8)^n · u[n]

This is a causal, stable system since |0.8| < 1.
