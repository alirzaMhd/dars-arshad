What is Feedback?

Definition:
Feedback = Output is fed back to input
A portion of the output is returned to modify the input

Feedback is one of the most important concepts in systems and signal processing. It allows us to control and modify system behavior by returning a portion of the output to the input.

Positive Feedback

Reinforces the input signal

Can cause instability

Used in oscillators

Negative Feedback

Opposes the input signal

Improves stability

Used in control systems

Transfer Function of Feedback System

Negative Feedback Transfer Function:
T(s) = H(s) / (1 + H(s)G(s))
H(s) = forward path, G(s) = feedback path
Positive Feedback Transfer Function:
T(s) = H(s) / (1 - H(s)G(s))
Note the sign difference in denominator

Worked Examples

Example 1: Unity Feedback

H(s) = 1/(s+1), G(s) = 1

T(s) = (1/(s+1)) / (1 + 1/(s+1)) = 1/(s+2)

Example 2: Non-unity Feedback

H(s) = 1/s, G(s) = K

T(s) = (1/s) / (1 + K/s) = 1/(s+K)
