What is an LTI System?

Definition:
LTI = Linear Time-Invariant
A system that satisfies both linearity and time-invariance properties

An LTI system is a fundamental concept in signal processing. It represents a class of systems that have two key properties:

Linearity

• Superposition principle holds

• Homogeneity property

• Additivity property

Time-Invariance

• System behavior doesn't change with time

• Input shift causes output shift

• Parameters are constant

LTI systems are widely used because they are mathematically tractable and many physical systems can be modeled as LTI systems.

Mathematical Properties

Linearity Property

Superposition:
T{a·x₁(t) + b·x₂(t)} = a·T{x₁(t)} + b·T{x₂(t)}
Where T{} represents system transformation, a and b are constants

Time-Invariance Property

Shift Invariance:
If x(t) → y(t), then x(t-t₀) → y(t-t₀)
Time shift in input causes same time shift in output
Key Point: A system that is both linear and time-invariant is called an LTI system. Most physical systems in nature can be approximated as LTI systems.

Worked Examples

Example 1: Linearity Check

System: y(t) = 2x(t) + 3

Is this system linear?

Solution: No. This system is not linear because it doesn't satisfy the homogeneity property. When input is scaled by a, output becomes 2·a·x(t) + 3, not a·(2x(t) + 3).

Example 2: Time-Invariance Check

System: y(t) = x(t)·cos(t)

Is this system time-invariant?

Solution: No. This system is not time-invariant because the cosine term explicitly depends on time. If we shift input by t₀, output becomes x(t-t₀)·cos(t), not x(t-t₀)·cos(t-t₀).

Example 3: LTI System Verification

System: y(t) = x(t-2)

Is this system LTI?

Solution: Yes. This system is both linear (superposition holds) and time-invariant (shifting input by t₀ shifts output by t₀). Therefore, it's an LTI system.

Key Points

• LTI systems are completely characterized by impulse response

• Convolution gives output for any input

• Frequency response analysis is possible
