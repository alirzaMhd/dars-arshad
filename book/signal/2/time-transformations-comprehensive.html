Time Variable Transformations

Signals and Systems — Complete Guide for Exam Preparation

Time Shifting (Delay and Advance)

Time shifting moves a signal forward or backward along the time axis without changing its shape. The key rule is: the shift is OPPOSITE to the sign in the argument.

Continuous-Time Shifting

Right Shift (Delay):
y(t) = x(t - t₀) where t₀ > 0
Signal shifts RIGHT by t₀ units (signal occurs LATER)
Left Shift (Advance):
y(t) = x(t + t₀) where t₀ > 0
Signal shifts LEFT by t₀ units (signal occurs EARLIER)
Delay vs Advance — Key Clarification: When we write x(t − t₀), the signal is delayed (shifted RIGHT) because the event that used to happen at t = 0 now happens at t = t₀. When we write x(t + t₀), the signal is advanced (shifted LEFT) because the event now happens earlier at t = −t₀. In both cases, t₀ is assumed to be a positive number. The sign inside the parentheses tells you which direction: minus → right (delay), plus → left (advance).

Discrete-Time Shifting

Right Shift (Delay):
y[n] = x[n - n₀] where n₀ is a positive integer
Signal shifts RIGHT by n₀ samples
Left Shift (Advance):
y[n] = x[n + n₀] where n₀ is a positive integer
Signal shifts LEFT by n₀ samples
Important: For discrete-time signals, the shift amount n₀ must be an integer. Non-integer shifts are not defined for discrete signals.

Examples

Example 1: Shift a Unit Pulse

Given: x(t) = u(t) - u(t-1) (unit pulse from t=0 to t=1)

Find: y(t) = x(t - 2)

Solution: x(t-2) = u(t-2) - u(t-3)

The pulse now spans from t=2 to t=3 (shifted right by 2)

Example 2: Shift an Exponential

Given: x(t) = e-t u(t)

Find: y(t) = x(t + 3)

Solution: Replace t with (t+3):

y(t) = e-(t+3) u(t+3) = e-t-3 u(t+3)

The exponential starts at t = -3 instead of t = 0 (shifted left by 3)

Example 3: Discrete Shift

Given: x[n] = δ[n] (unit impulse at n=0)

Find: y[n] = x[n - 4]

Solution: The impulse moves to n = 4

y[n] = δ[n - 4]

Key Rule

Minus sign → Shift RIGHT (delay)

Plus sign → Shift LEFT (advance)

Discrete Constraint

n₀ must be an integer

Non-integer shifts are undefined

Time Scaling (Compression and Expansion)

Time scaling changes the speed at which a signal evolves. The scaling factor a determines whether the signal is compressed or expanded.

Continuous-Time Scaling

Time Scaling:
y(t) = x(at)
If |a| > 1: signal COMPRESSES (plays faster)
If |a| < 1: signal EXPANDS (plays slower)

Discrete-Time Scaling

Discrete Time Scaling:
y[n] = x[a·n] where a is integer or rational
Only specific values of n produce valid output samples
Discrete Scaling is Special: For discrete signals, x[2n] takes every other sample (decimation), and x[n/2] inserts zeros between samples (interpolation with zero-stuffing).
Critical Constraint: For discrete-time signals, the scaling factor a must be an integer (or rational in general). If a is not an integer, the result is undefined because x[a·n] would require non-integer indices. For example, x[2.5·n] is not a valid discrete signal operation.

Decimation vs Interpolation

Operation Formula Effect Samples
Decimation (Compression) x[2n] Keeps every 2nd sample Loses samples
Interpolation (Expansion) x[n/2] Inserts zeros between samples Adds zeros

Examples

Example 1: Compress a Cosine

Given: x(t) = cos(t)

Find: y(t) = x(2t) = cos(2t)

Solution: The period changes from 2π to π

The signal compresses by factor 2 (oscillates twice as fast)

Example 2: Expand a Unit Pulse

Given: x(t) = u(t) - u(t-1) (pulse of width 1)

Find: y(t) = x(t/2)

Solution: x(t/2) = u(t/2) - u(t/2 - 1) = u(t/2) - u((t-2)/2)

The pulse now spans from t=0 to t=2 (expanded by factor 2)

Example 3: Discrete Decimation

Given: x[n] = {1, 2, 3, 4, 5, 6} for n = 0,1,2,3,4,5

Find: y[n] = x[2n]

Solution:

y[0] = x[0] = 1

y[1] = x[2] = 3

y[2] = x[4] = 5

Result: y[n] = {1, 3, 5} (samples 2,4,6 are lost)

Example 4: Discrete Interpolation

Given: x[n] = {1, 3, 5} for n = 0,1,2

Find: y[n] = x[n/2] (upsample by 2)

Solution:

y[0] = x[0] = 1

y[1] = x[0.5] = 0 (undefined → zero)

y[2] = x[1] = 3

y[3] = x[1.5] = 0 (undefined → zero)

y[4] = x[2] = 5

Result: y[n] = {1, 0, 3, 0, 5}

Example 5: Decimation by Factor 3

Given: x[n] = {2, 4, 6, 8, 10, 12, 14} for n = 0,1,2,3,4,5,6

Find: y₁[n] = x[3n] (compression/decimation by factor 3)

Solution: Only indices that are multiples of 3 are kept.

y₁[0] = x[0] = 2

y₁[1] = x[3] = 8

y₁[2] = x[6] = 14

Result: y₁[n] = {2, 8, 14} at n = 0,1,2

4 out of 7 samples are lost. Decimation by factor 3 keeps only every 3rd sample — this is irreversible data loss.

Example 6: Expansion by Factor 2

Given: x[n] = {5, 10, 15} for n = 0,1,2

Find: y₂[n] = x[n/2] (expansion by factor 2)

Solution: At even indices n = 2k, we get x[k]. At odd indices, the result is zero.

y₂[0] = x[0] = 5

y₂[1] = x[0.5] = 0 (non-integer index → zero)

y₂[2] = x[1] = 10

y₂[3] = x[1.5] = 0 (non-integer index → zero)

y₂[4] = x[2] = 15

Result: y₂[n] = {5, 0, 10, 0, 15} at n = 0,1,2,3,4

Zeros are inserted at odd indices. This is zero-stuffing interpolation — it stretches the signal but does not add real information.

Example 7: Signal Width Under Scaling and Shift

Given: f(t) has width T and its maximum occurs at t = 2.

Find: width and maximum location of g(t) = f(rt − n).

Solution:

The argument of f is (rt − n). The signal is non-zero when rt − n is in the support of f, i.e., when the argument is between 0 and T.

Width: The span in t is T/r. So width = T/r.

Maximum location: Set rt − n = 2 → t = (n + 2)/r. So maximum at t = (n + 2)/r.

Scaling by r compresses the width by factor r. The shift n moves the center of the signal, and the scaling also affects the shift amount.

Compression Rule

|a| > 1 → Compress

Signal gets narrower

Expansion Rule

|a| < 1 → Expand

Signal gets wider

Discrete Warning

Decimation loses information

Interpolation adds zeros

Time Reversal (Reflection)

Time reversal reflects a signal about the vertical axis (t=0 or n=0). It is a special case of time scaling with a = -1.

Continuous-Time Reversal

Time Reversal:
y(t) = x(-t)
Signal is reflected about the vertical axis t = 0

Discrete-Time Reversal

Discrete Time Reversal:
y[n] = x[-n]
Sample at index n becomes sample at index -n
Relationship to Time Scaling:
x(-t) = x(at) where a = -1
Time reversal is a special case of time scaling

Examples

Example 1: Reverse an Exponential

Given: x(t) = e-t u(t) (causal exponential, exists for t ≥ 0)

Find: y(t) = x(-t)

Solution: Replace t with -t:

y(t) = e-(-t) u(-t) = et u(-t)

The signal now exists for t ≤ 0 and grows as t approaches 0 from the left

Example 2: Reverse a Unit Step

Given: x(t) = u(t) (unit step)

Find: y(t) = x(-t)

Solution: y(t) = u(-t)

u(-t) = 1 when -t ≥ 0, i.e., when t ≤ 0

Result: y(t) = u(-t) (step that is 1 for t ≤ 0, 0 for t > 0)

Example 3: Reverse a Discrete Signal

Given: x[n] = {1, 2, 3} for n = 0, 1, 2

Find: y[n] = x[-n]

Solution:

y[0] = x[0] = 1

y[-1] = x[1] = 2

y[-2] = x[2] = 3

Result: y[n] = {3, 2, 1} at n = -2, -1, 0

Example 4: Reverse a Rectangular Pulse

Given: x(t) = u(t) - u(t-3) (pulse from t=0 to t=3)

Find: y(t) = x(-t)

Solution: y(t) = u(-t) - u(-t-3)

u(-t) = 1 for t ≤ 0

u(-t-3) = 1 for -t-3 ≥ 0 → t ≤ -3

y(t) = 1 for -3 ≤ t ≤ 0 (pulse reflected to negative axis)

Geometric Meaning

Reflect about vertical axis

Right side ↔ Left side

Special Case

x(-t) = x(at) with a = -1

Part of time scaling family

Combined Transformations

When multiple transformations are combined, the order of operations matters. The general form is y(t) = x(at + b).

Two Approaches

Approach 1 (Shift then Scale):
x(t) → x(t + b) → x(at + b)
Step 1: Shift by b (left if b > 0)
Step 2: Scale by a
Approach 2 (Scale then Shift):
x(t) → x(at) → x(a(t + b/a)) = x(at + b)
Step 1: Scale by a
Step 2: Shift by b/a (NOT b!)
Common Mistake: When scaling first, the shift amount becomes b/a, not b. Many students forget this and get the wrong answer.

Worked Examples

Example 1: y(t) = x(2t + 6)

Approach 1 (Shift then Scale):

Step 1: x(t) → x(t + 6) [shift left by 6]

Step 2: x(t + 6) → x(2t + 6) [compress by 2]

Approach 2 (Scale then Shift):

Step 1: x(t) → x(2t) [compress by 2]

Step 2: x(2t) → x(2(t + 3)) = x(2t + 6) [shift left by 3]

Result: Both approaches give x(2t + 6)

Example 2: y(t) = x(-t + 4)

Approach 1 (Shift then Scale):

Step 1: x(t) → x(t + 4) [shift left by 4]

Step 2: x(t + 4) → x(-t + 4) [reverse time]

Approach 2 (Scale then Shift):

Step 1: x(t) → x(-t) [reverse time]

Step 2: x(-t) → x(-(t - 4)) = x(-t + 4) [shift RIGHT by 4]

Result: Both approaches give x(-t + 4)

Example 3: With Specific Signal

Given: x(t) = u(t) - u(t-1) (unit pulse 0 ≤ t < 1)

Find: y(t) = x(2t + 1)

Solution (Shift then Scale):

Step 1: x(t+1) = u(t+1) - u(t) [pulse from -1 to 0]

Step 2: x(2t+1) = u(2t+1) - u(2t) = u(2(t+0.5)) - u(2t)

Pulse exists when: -0.5 ≤ t < 0

Result: Pulse from t = -0.5 to t = 0

Example 4: Discrete Combined

Given: x[n] = δ[n] (impulse at n=0)

Find: y[n] = x[2n + 4]

Solution:

For discrete: x[2n + 4] = δ[2n + 4]

δ[2n + 4] = 1 when 2n + 4 = 0, i.e., n = -2

Result: y[n] = δ[n + 2] (impulse at n = -2)

Example 5: Complex Combination

Given: x(t) = e-t u(t)

Find: y(t) = x(3t - 9)

Solution (Scale then Shift):

Step 1: x(3t) = e-3t u(3t) [compress by 3]

Step 2: x(3(t-3)) = x(3t-9) = e-3(t-3) u(3(t-3))

y(t) = e-3t+9 u(3t-9)

Signal starts at t = 3 (not t = 9!)

Example 6: Combined Transformation with Cosine

Given: x(t) = cos(t + 1)

Find: y(t) = x(−2t + 1)

This example demonstrates how the order of operations and the scaling factor affect the shift amount.

Method 1: Shift first, then scale and reverse

Step 1: z(t) = x(t + 1) = cos((t + 1) + 1) = cos(t + 2) [shift left by 1]

Step 2: z(2t) = cos(2t + 2) [compress by 2]

Step 3: z(−2t) = cos(−2t + 2) = cos(2t − 2) [reverse time]

Since cos is even: cos(−2t + 2) = cos(2t − 2). But we need x(−2t + 1), so we adjust the shift.

Let's redo carefully. We want x(−2t + 1) = cos(−2t + 1 + 1) = cos(−2t + 2).

Step 1: z(t) = x(t + 1) = cos(t + 2)

Step 2: z(−2t) = cos(−2t + 2) = cos(2t − 2) ✓

Method 2: Scale and reverse first, then shift

Step 1: f(t) = x(2t) = cos(2t + 1) [compress by 2]

Step 2: f(−t) = cos(−2t + 1) = cos(2t − 1) [reverse]

Step 3: f(−2(t − π/2)) = cos(−2(t − π/2) + 1) = cos(−2t + π + 1)

Wait — let's be precise. When scaling first, we write x(−2t + 1) = x(−2(t − 1/2)). So after reversing: x(−2t), then shift RIGHT by 1/2.

Step 1: f(t) = x(2t) = cos(2t + 1)

Step 2: f(−t) = cos(−2t + 1)

Step 3: f(−(t − 1/2)) = cos(−2(t − 1/2) + 1) = cos(−2t + 1 + 1) = cos(−2t + 2) ✓

Result: y(t) = cos(−2t + 2). Both methods agree. The key insight: when you scale first by factor 2, the shift amount changes from 1 to 1/2 (i.e., b/a = 1/2).

Quick Reference Card

Transformation Formula Effect
Time Shift (Delay) x(t - t₀) Shift RIGHT by t₀
Time Shift (Advance) x(t + t₀) Shift LEFT by t₀
Time Compression x(at), |a| > 1 Compress by factor a
Time Expansion x(at), |a| < 1 Expand by factor 1/a
Time Reversal x(-t) Reflect about vertical axis
Combined x(at + b) Scale by a, shift by b/a

Common Mistakes to Avoid

1. Forgetting that shift is OPPOSITE to the sign: x(t-3) shifts RIGHT, not left.
2. When applying scale then shift to x(at+b), shifting by b instead of b/a.
3. For discrete signals, assuming non-integer shifts or scales are valid.
4. Confusing decimation (loses data) with simple compression (just changes speed).
5. Not tracking the domain change when combining reversal with shift (e.g., x(-t+3) requires careful handling).

Shift Rule

x(t - b) → Right by b

x(t + b) → Left by b

Scale Rule

|a| > 1 → Compress

|a| < 1 → Expand

Combined Order

Shift then Scale: easy

Scale then Shift: shift = b/a
