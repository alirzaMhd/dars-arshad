System Properties

Signals and Systems — Complete Guide for Exam Preparation

Memory

A system is memoryless if its output at any time depends ONLY on the input at that same time.

Memoryless System Definition
y(t) = f[x(t)]
Output at time t depends only on input at time t — no past or future values needed.

Memoryless vs. Systems with Memory

PropertyMemorylessWith Memory
Depends onCurrent input onlyPast and/or future inputs
Exampley(t) = x(t)y(t) = x(t-2)
Storage neededNonePrevious values must be stored
Example 1: Memoryless System
y(t) = x(t)
Output equals input at the same time. No past or future values needed.

✓ Memoryless — At t = 3, y(3) = x(3). Only current value used.

Example 2: System with Memory
y(t) = x(t - 2)
Output is input delayed by 2 seconds — needs past values.

✗ Has Memory — At t = 3, y(3) = x(1). Requires value from 2 seconds ago.

⚠ Common Mistake: y(t) = x(2t) looks like it only uses current time, but at t = 3 it needs x(6) — a future value. This is NOT memoryless.
Example: Capacitor (Physical System with Memory)
y(t) = (1/C) ∫₋∞ᵗ x(τ) dτ
Capacitor voltage depends on ALL past input current — accumulates charge over entire history.
Analysis: At time t, the output requires x(τ) for ALL τ ≤ t (the entire past, not just current value)
Why: A capacitor stores charge. The current voltage depends on every bit of charge that has flowed into it since the beginning of time.

✗ Has Memory — Classic example of a system with infinite memory. The output at time t depends on the entire past history of the input.

Invertibility

A system is invertible if different inputs always produce different outputs. The inverse system recovers the original input from the output.

Invertibility Condition
If x₁(t) ≠ x₂(t) ⟹ y₁(t) ≠ y₂(t)
Distinct inputs must produce distinct outputs for invertibility.
Inverse System
y(t) = f[x(t)] → x(t) = f⁻¹[y(t)]
If the system is invertible, we can recover x(t) from y(t).
Example 3: Invertible System
y(t) = 3x(t)
Step 1: Different inputs give different outputs: x₁(t) = 1 → y₁(t) = 3, x₂(t) = 2 → y₂(t) = 6
Step 2: Inverse: x(t) = y(t) / 3

✓ Invertible

Example 4: Non-Invertible System
y(t) = x²(t)
Step 1: Test: x₁(t) = 2 → y₁(t) = 4, x₂(t) = -2 → y₂(t) = 4
Step 2: Different inputs (2 and -2) produce SAME output (4)

✗ Not Invertible — Cannot distinguish between x and -x from output.

Example: Invertible — Cosine Multiplication
y[n] = cos(πn/5 · x[n])
Output is cosine of a product involving the input.
Key Insight: For n = 1, 2, 3, 4 the argument πn/5 never equals zero, and cos(θ) ≠ 0 for these values
Why Invertible: Since cos(θ) is one-to-one over a suitable range, different x[n] values produce different y[n] values. We can recover x[n] from y[n] using arccos.

✓ Invertible — The cosine function restricted to a suitable domain is invertible.

Example: Non-Invertible — Delta Function Sum
y[n] = Σₖ₌₂ⁿ⁺² x[k]δ[k-n]
Sum involving delta functions — need to simplify first.
Step 1: δ[k-n] = 1 only when k = n, so only the k = n term survives in the sum
Step 2: The sum is non-zero only if n ≥ 2 and n ≤ n+2 (always true). So y[n] = x[n] when n ≥ 2
Step 3: For n < 2, no valid k exists in the range, so y[n] = 0
Conclusion: We can only recover x[n] for n ≥ 2. For n < 2, the output is always 0 regardless of input.

✗ Not Invertible — Cannot recover x[0], x[1], or any negative-index values from the output.

⚠ Common Mistake: y(t) = |x(t)| is NOT invertible because x(t) = 2 and x(t) = -2 both give y(t) = 2.

Causality

A system is causal if its output at any time depends only on current and PAST inputs (not future inputs).

Causal System Condition
y(t₀) depends on x(t) where t ≤ t₀ only
No future values of input are used.

Key Properties of Causal Systems

All memoryless systems are causal
No memory = no future values used
Systems with delays are causal
x(t-t₀) for t₀ > 0 uses past values
Real-time systems must be causal
Cannot access future inputs in real-time
Example 5: Causal System
y(t) = x(t - 2)
Output at time t uses input from 2 seconds ago (past).

✓ Causal — Only past input values are used.

Example 6: Non-Causal System
y(t) = x(t + 2)
Output at time t uses input from 2 seconds in the future.

✗ Non-Causal — Requires future input value.

Example 7: Mixed System
y(t) = x(t) + x(t - 1)
Uses current input and one past input.

✓ Causal — Only current and past values used.

Example: Non-Causal — Depends on x[0]
y[n] = x[n] · sin(x[0])
Output at n is input at n, scaled by sin of input at n=0.
Step 1: For n = -1, y[-1] = x[-1] · sin(x[0]) — needs x[0] which is in the FUTURE relative to n = -1
Step 2: For n = -2, y[-2] = x[-2] · sin(x[0]) — same problem, needs future x[0]
Step 3: For any n < 0, the system requires x[0] which is a future value

✗ Non-Causal — Even though it looks like it only uses x[n], the sin(x[0]) factor accesses a "future" value for n < 0.

⚠ y(t) = x(t+1) + x(t-1) is NOT causal because of the x(t+1) term (future input).

Stability (BIBO)

A system is BIBO Stable (Bounded-Input Bounded-Output) if every bounded input produces a bounded output.

BIBO Stability Condition
|x(t)| ≤ Mₓ < ∞ ⟹ |y(t)| ≤ Mᵧ < ∞
If input is bounded by Mₓ, output must be bounded by some finite Mᵧ.
Example 8: Stable System
y(t) = x(t - 1)
Output is just a delayed version of input.
Step 1: If |x(t)| ≤ Mₓ for all t, then |x(t-1)| ≤ Mₓ
Step 2: Therefore |y(t)| = |x(t-1)| ≤ Mₓ = Mᵧ

✓ BIBO Stable

Example 9: Unstable System
y(t) = t · x(t)
Output is input multiplied by time.
Step 1: Let x(t) = u(t) (unit step), which is bounded: |x(t)| ≤ 1
Step 2: Then y(t) = t · u(t) which grows without bound as t → ∞

✗ Not BIBO Stable — Bounded input produces unbounded output.

Example 10: Unstable Accumulator
y(t) = ∫₋∞ᵗ x(τ) dτ
System accumulates (integrates) all past input values.
Step 1: Let x(t) = u(t) (unit step), bounded at 1
Step 2: y(t) = ∫₋∞ᵗ u(τ) dτ = t for t > 0, which grows without bound

✗ Not BIBO Stable

Example: Conditionally Stable
y[n] = x[n] · cos(x[0])
Output is input scaled by cos of input at n=0.
Step 1: If |x[0]| ≤ 1, then |cos(x[0])| ≤ 1, so |y[n]| = |x[n]|·|cos(x[0])| ≤ |x[n]|
Step 2: If x[0] ≠ ±1, then cos(x[0]) is bounded and finite, so bounded input → bounded output
Warning: If x[0] = π/2, cos(π/2) = 0 → output is always 0. Still bounded.

✓ BIBO Stable (when x[0] ≠ ±1) — The cosine factor is always bounded, so output remains bounded.

Example: Unstable — Exponential of Delayed Input
y(t) = x(t) · e^(-x(t-1)²/2)
Output is input times an exponential involving a delayed version of input.
Step 1: Consider x(t) = δ(t-1) + 1. This is bounded: |x(t)| ≤ 2
Step 2: When x(t-1) = 1, the exponent becomes -1/2, and e^(-1/2) ≈ 0.607 — still bounded
Step 3: But when x(t-1) = 0, e^(0) = 1, and when x(t) is large, output = x(t)·1 → can be large
Key Issue: When x(t-1) = 0, y(t) = x(t)·1 = x(t). If x(t) is large, output is large. But this is still bounded if input is bounded.
Correction: Actually, consider x(t) such that x(t-1) = 0 for some t, then y(t) = x(t). This is fine. But consider x(t) = 2 for all t: y(t) = 2·e^(-4/2) = 2·e^(-2) ≈ 0.27 — bounded.
Real Issue: The system IS stable because |e^(-x(t-1)²/2)| ≤ 1 always (since exponent is ≤ 0), so |y(t)| ≤ |x(t)| · 1 = |x(t)| ≤ Mₓ.

✓ BIBO Stable — The exponential term is always ≤ 1, so |y(t)| ≤ |x(t)|. (Note: The PDF claims this is unstable, but mathematically the system IS stable since the exponential decay factor always reduces the output.)

⚠ A system can be causal but unstable (like y(t) = t·x(t)), or stable but non-causal.

Time Invariance

A system is time-invariant if a time shift in the input produces the same time shift in the output.

Time Invariance Condition
If x(t) → y(t), then x(t - t₀) → y(t - t₀)
Shifting input by t₀ shifts output by t₀.

How to Test for Time Invariance

Step 1: Find y(t) = T{x(t)}
Step 2: Find y(t - t₀) by replacing t with (t - t₀) in the output expression
Step 3: Find response to shifted input: T{x(t - t₀)}
Step 4: If Step 2 = Step 3, system is time-invariant
Example 11: Time-Invariant System
y(t) = 2x(t) + 3
Step 1: y(t) = 2x(t) + 3
Step 2: y(t - t₀) = 2x(t - t₀) + 3
Step 3: Response to x(t-t₀): 2x(t-t₀) + 3
Step 4: They match! ✓ Time-Invariant
Example 12: Time-Variant System
y(t) = t · x(t)
Step 1: y(t) = t · x(t)
Step 2: y(t - t₀) = (t - t₀) · x(t - t₀)
Step 3: Response to x(t-t₀): t · x(t - t₀)
Step 4: (t - t₀)·x(t-t₀) ≠ t·x(t-t₀) → ✗ Time-Variant
Example: Time-Invariant — Constant Coefficient
y(t) = x(t) · e⁻²
Output is input multiplied by a constant (e⁻² ≈ 0.135).
Step 1: y(t) = e⁻² · x(t)
Step 2: y(t - t₀) = e⁻² · x(t - t₀)
Step 3: Response to x(t - t₀): e⁻² · x(t - t₀)
Step 4: They match! The constant e⁻² doesn't depend on t.

✓ Time-Invariant — Multiplying by a constant (not a function of t) preserves time invariance.

Example: Time-Variant — Unit Step Multiplier
y(t) = x(t - 2) · u(t)
Delayed input multiplied by unit step — the u(t) makes it time-variant.
Step 1: y(t) = x(t - 2) · u(t)
Step 2: y(t - t₀) = x(t - t₀ - 2) · u(t - t₀)
Step 3: Response to x(t - t₀): x(t - t₀ - 2) · u(t)
Step 4: u(t - t₀) ≠ u(t) → Not equal!

✗ Time-Variant — The u(t) multiplier changes behavior depending on when the input is applied.

Example: Time-Invariant — Accumulator
y[n] = Σₖ₌₋∞ⁿ x[k]
Running sum of all past inputs up to time n.
Step 1: y[n] = Σₖ₌₋∞ⁿ x[k]
Step 2: y[n - n₀] = Σₖ₌₋∞ⁿ⁻ⁿ⁰ x[k]
Step 3: Response to x[n - n₀]: Σₖ₌₋∞ⁿ x[k - n₀]. Let m = k - n₀: = Σₘ₌₋∞ⁿ⁻ⁿ⁰ x[m] = y[n - n₀]
Step 4: They match!

✓ Time-Invariant — The accumulator is time-invariant because shifting the input simply shifts the entire sum.

Example: Time-Variant — n·x[n]
y[n] = n · x[n]
Input multiplied by the time index n.
Step 1: y[n] = n · x[n]
Step 2: y[n - n₀] = (n - n₀) · x[n - n₀]
Step 3: Response to x[n - n₀]: n · x[n - n₀]
Step 4: (n - n₀)·x[n-n₀] ≠ n·x[n-n₀] → Not equal!

✗ Time-Variant — The coefficient n depends on time, so the system behaves differently at different times.

⚠ Systems with time-dependent coefficients (like t, sin(t), eᵗ multiplying x) are typically time-variant.

Linearity

A system is linear if it satisfies the principle of superposition, which combines two properties:

Additivity
x₁(t) + x₂(t) → y₁(t) + y₂(t)

Sum of inputs produces sum of outputs

Homogeneity (Scaling)
a · x(t) → a · y(t)

Scaling input scales output by same factor

Linearity Condition (Superposition)
a·x₁(t) + b·x₂(t) → a·y₁(t) + b·y₂(t)
Combined additivity and homogeneity must hold for all inputs and all constants a, b.

How to Test for Linearity

Step 1: Apply input a·x₁(t) + b·x₂(t) to the system
Step 2: Find the output y(t) = T{a·x₁(t) + b·x₂(t)}
Step 3: Find a·y₁(t) + b·y₂(t) where y₁ = T{x₁} and y₂ = T{x₂}
Step 4: If Step 2 = Step 3 for ALL a, b, x₁, x₂ → Linear
Example 13: Linear System
y(t) = 2x(t)
Step 1: T{a·x₁ + b·x₂} = 2(a·x₁ + b·x₂) = 2a·x₁ + 2b·x₂
Step 2: a·y₁ + b·y₂ = a·(2x₁) + b·(2x₂) = 2a·x₁ + 2b·x₂
Step 3: They match! ✓ Linear
Example 14: Non-Linear System
y(t) = x(t) + 1
Step 1: Test with x = 0: y = 0 + 1 = 1 ≠ 0
Step 2: Linear system must give 0 output for zero input!

✗ Not Linear — Fails homogeneity (zero input should give zero output).

Example 15: Non-Linear System (Squared)
y(t) = x²(t)
Step 1: T{a·x₁} = (a·x₁)² = a²·x₁²
Step 2: a·T{x₁} = a·x₁²
Step 3: a²·x₁² ≠ a·x₁² (unless a = 0 or 1)

✗ Not Linear — Fails homogeneity.

Example: Not Linear — Imaginary Part
y[n] = Im{x[n]}
Output is the imaginary part of a possibly complex input.
Test Homogeneity: Let a = j (imaginary unit), x[n] = 1 (real)
Step 1: T{j · 1} = Im{j} = 1
Step 2: j · T{1} = j · Im{1} = j · 0 = 0
Step 3: 1 ≠ 0 → Fails homogeneity for complex scalar a

✗ Not Linear — The imaginary part operator fails homogeneity when the scaling constant is complex. (It would be linear over real scalars only.)

Example: Linear — Time-Varying Coefficient f(t)·x(t)
y(t) = e⁻ᵗ sin(t) · x(t)
Input multiplied by a time-varying function f(t) = e⁻ᵗ sin(t).
Key Principle: ANY system of the form y(t) = f(t)·x(t) is linear, regardless of how complex f(t) is
Step 1: T{a·x₁ + b·x₂} = f(t)·(a·x₁(t) + b·x₂(t)) = a·f(t)·x₁(t) + b·f(t)·x₂(t)
Step 2: a·y₁ + b·y₂ = a·f(t)·x₁(t) + b·f(t)·x₂(t)
Step 3: They match!

✓ Linear — The form y(t) = f(t)·x(t) always satisfies superposition. The function f(t) can be anything — constant, time-varying, exponential, etc.

Example: Linear — Piecewise Definition
y[n] = { Σₖ₌₀ⁿ x[k] for n < 1, x[n] for n ≥ 1 }
System behaves as accumulator for n < 1, and passes through for n ≥ 1.
For n < 1: T{a·x₁ + b·x₂} = Σₖ₌₀ⁿ (a·x₁[k] + b·x₂[k]) = a·Σₖ₌₀ⁿ x₁[k] + b·Σₖ₌₀ⁿ x₂[k] = a·y₁ + b·y₂ ✓
For n ≥ 1: T{a·x₁ + b·x₂} = a·x₁[n] + b·x₂[n] = a·y₁ + b·y₂ ✓
Both cases satisfy superposition

✓ Linear — Both branches of the piecewise definition individually satisfy superposition.

⚠ Common Mistake: y(t) = x(t) + 1 looks "almost linear" but the constant +1 makes it non-linear. Any additive constant breaks linearity.

Property Relationships Diagram

Understanding the logical relationships between Memory and Causality properties:

Memoryless → Causal
ALWAYS TRUE

If a system uses only the current input value, it cannot possibly use future values. Therefore all memoryless systems are causal.

Causal → Memoryless
NOT NECESSARILY TRUE

A causal system can still use past values (e.g., y(t) = x(t-1) is causal but has memory). Causal does NOT imply memoryless.

Non-Causal → Has Memory
ALWAYS TRUE

If a system is non-causal, it uses future values, which means it must store or access values other than the current one — hence it has memory.

Has Memory → Non-Causal
NOT NECESSARILY TRUE

A system can have memory but still be causal if it only uses PAST values (e.g., y(t) = x(t-1) has memory but is causal).

⚠ Key Exam Point: Memoryless ⟹ Causal, but Causal ⟹/ Memoryless. Non-causal ⟹ Has memory, but Has memory ⟹/ Non-causal. Don't confuse the direction of implication!

Linearity Test Method

The formal method to test whether a system is linear:

Superposition Test
Assume x₁[n] → y₁[n] and x₂[n] → y₂[n]
Apply the combined input a·x₁[n] + b·x₂[n] and check if output equals a·y₁[n] + b·y₂[n].
Step 1: Let x₁ → y₁ and x₂ → y₂ (find individual outputs)
Step 2: Apply input x₃ = a·x₁ + b·x₂ to the system, find y₃ = T{a·x₁ + b·x₂}
Step 3: Compute a·y₁ + b·y₂
Step 4: If y₃ = a·y₁ + b·y₂ for ALL choices of a, b, x₁, x₂ → Linear. If even ONE choice fails → Not Linear.
Quick Test: Zero Input
Set x(t) = 0, check if y(t) = 0
If x = 0 does not produce y = 0, the system is automatically NOT linear.

This is the fastest way to disprove linearity in an exam. If x(t) = 0 → y(t) = C ≠ 0, stop — it's not linear.
