Special Continuous-Time Signals

Signals and Systems — Complete Guide for Exam Preparation

1. General Complex Exponential Signal

Definition
x(t) = C · e^(at)
where C and a are, in general, complex numbers

When C and a are restricted to be real, we obtain the real exponential signal. When a is purely imaginary, we obtain sinusoidal signals.

General Case: a = r + jω₀
x(t) = C · e^((r + jω₀)t) = C · e^(rt) · e^(jω₀t)
r is the real part (growth/decay rate), ω₀ is the imaginary part (oscillation frequency)

r < 0: Decaying Sinusoids

x(t) = C · e^(rt) · e^(jω₀t)

Real and imaginary parts are decaying sinusoids. Not periodic (amplitude decays). The signal dies out as t → ∞.

r > 0: Growing Sinusoids

x(t) = C · e^(rt) · e^(jω₀t)

Real and imaginary parts are growing sinusoids. Not periodic (amplitude grows). The signal blows up as t → ∞.

r = 0: Pure Complex Exponential

x(t) = C · e^(jω₀t)

Pure oscillation. Periodic with T₀ = 2π/ω₀. Both real and imaginary parts are sinusoids of constant amplitude.

⚠ Key: When a is purely imaginary (r = 0), the signal is periodic. When r ≠ 0, the signal is NOT periodic because the amplitude changes over time.

2. Real Exponential Signal

Definition
x(t) = C · e^(at)
where C and a are real numbers

Growing Exponential (a > 0)

    x(t)
    |         /
    |       /
    |     /
    |   /
    | /
    +------------→ t
    0
a > 0 → x(t) grows

As t → ∞, x(t) → ∞ (unbounded)

Decaying Exponential (a < 0)

    x(t)
    | \
    |   \
    |     \
    |       \_________
    |
    +------------→ t
    0
a < 0 → x(t) decays

As t → ∞, x(t) → 0 (stable)

⚠ Key: a > 0 means growth (unbounded), a < 0 means decay (stable). a = 0 gives constant x(t) = C.

3. Complex Exponential Signal

Definition
x(t) = A · e^(j(ω₀t + φ))
A: amplitude, ω₀: angular frequency (rad/s), φ: phase (rad)
Euler's Formula
e^(jθ) = cos(θ) + j·sin(θ)
This decomposes the complex exponential into real and imaginary parts
Expanded Form
x(t) = A·cos(ω₀t + φ) + j·A·sin(ω₀t + φ)
⚠ The complex exponential is periodic with period T₀ = 2π/ω₀. For it to be periodic, ω₀ must be a real number.
Periodicity Proof
x(t + T₀) = A · e^(j(ω₀(t+T₀) + φ)) = A · e^(j(ω₀t + φ + 2π)) = A · e^(j(ω₀t + φ)) · e^(j2π) = x(t)
Since e^(j2π) = cos(2π) + j·sin(2π) = 1, the signal repeats every T₀ = 2π/ω₀
Power of Complex Exponential
P_x = A²/2
The power of x(t) = Ae^(j(ω₀t+φ)) equals A²/2. Both real and imaginary parts (cosine and sine) have the same power A²/2.

4. Sinusoidal Signal

Definition
x(t) = A · cos(ω₀t + φ)
A: amplitude (peak value), ω₀: angular frequency (rad/s), φ: phase angle (rad)
Sinusoids as Special Cases of Complex Exponential
cos(ω₀t + φ) = Re{e^(j(ω₀t + φ))}
sin(ω₀t + φ) = Im{e^(j(ω₀t + φ))}
Cosine is the real part, sine is the imaginary part of the complex exponential
Power (same for both cosine and sine)
P = A²/2
Both cos(ω₀t+φ) and sin(ω₀t+φ) have power P = A²/2
    x(t)

   -A ─ ─ ─╲╱─ ─ ─ ─ ─ ─ ╲╱─ ─ ─

   |←─ T₀ ─→|
Period
T₀ = 2π / ω₀
The fundamental period (seconds). Only periodic if ω₀ ≠ 0.
Frequency (Hz)
f₀ = 1/T₀ = ω₀ / (2π)
Frequency in Hertz (cycles per second)
Average Power
P = A² / 2
Power of a sinusoidal signal (finite, so sinusoid is a power signal)
⚠ Sinusoidal signals are power signals (finite power), NOT energy signals (infinite energy).

1. Unit Step Signal

Definition
u(t) = { 1, t ≥ 0
{ 0, t < 0
The unit step function "turns on" at t = 0
    u(t)
    1 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─╱────────
                                │
    0 ──────────────────────────0──────────→ t
                                │

2. Generalized Unit Step

Generalized Definition
u(f(t)) = { 1, when f(t) ≥ 0
{ 0, when f(t) < 0
The argument can be any function f(t), not just t
Example: Sketch u(t + 2)
u(t + 2) = { 1, t + 2 ≥ 0 → t ≥ -2
{ 0, t + 2 < 0 → t < -2
    u(t+2)
    1 ─ ─ ─ ─ ─ ─╱─────────────────
                 │
    0 ──────────0──────────────────→ t
               -2

The step shifts left by 2 units

Example: Sketch u(t² - 4)
u(t² - 4) = { 1, t² - 4 ≥ 0 → |t| ≥ 2
{ 0, t² - 4 < 0 → |t| < 2
    u(t²-4)
    1 ──╱───╲───────────╱───╲───
      ╱     ╲         ╱     ╲
    0 ─────────╲──────╱────────────→ t
             -2     2

u(t² - 4) = 1 for t ≤ -2 and t ≥ 2; zero between -2 and 2

Example: Evaluate u(t² + 5t + 7)
Analysis
f(t) = t² + 5t + 7
Discriminant: Δ = 5² - 4(1)(7) = 25 - 28 = -3 < 0
Since discriminant is negative and leading coefficient (1) is positive, f(t) > 0 for all t.
Therefore: u(t² + 5t + 7) = 1 for all t.
u(t² + 5t + 7) = 1 (constant signal)

Key rule: If f(t) has no real roots and opens upward (positive leading coefficient), then f(t) > 0 always, so u(f(t)) = 1 everywhere.

3. Unit Impulse (Dirac Delta)

Definition
δ(t) = du(t)/dt
The unit impulse is the derivative of the unit step
Properties
∫₋∞^∞ δ(t) dt = 1
The impulse has unit area (integral equals 1)
Key Property
δ(t) = 0 for t ≠ 0
The impulse is zero everywhere except at t = 0
    δ(t)
    1 ─ ─ ─ ─ ─ ─ ─|─ ─ ─ ─ ─ ─ ─ ─
                    │
                    │  ← impulse at t=0
    0 ──────────────0───────────────→ t
                    │
⚠ Important: δ(t) is NOT a function in the ordinary sense! It is a distribution (generalized function). You cannot evaluate δ(0) — it is not defined. Only its integral (area) is meaningful.
Impulse as Limit of Standard Functions
δ(t) = lim_{T→0} (1/T) · Π(t/T)
The impulse is the limit of a rectangular pulse with width T and height 1/T as T → 0
Impulse as Limit of Triangular Pulse
δ(t) = lim_{T→0} (1/T) · Λ(t/T)
The impulse is also the limit of a triangular pulse with base width 2T and height 1/T
Impulse as Limit of Sinc
δ(t) = lim_{T→0} sinc(t/T)
The impulse can be viewed as the limit of a sinc function being compressed
    (1/T)Π(t/T)
    T→0:
    1/T ─╲          ╱─
         │        │
         │        │
    0 ────│────────│────→ t
         -T/2    T/2

    As T → 0, width → 0, height → ∞, area = 1

4. Sifting Property of the Impulse

Sifting Property
∫₋∞^∞ x(t) · δ(t - t₀) dt = x(t₀)
The impulse "sifts out" the value of x(t) at t = t₀

Derivation

Since δ(t - t₀) = 0 for t ≠ t₀, the integrand is zero except at t = t₀
So ∫ x(t)δ(t - t₀) dt = x(t₀) · ∫ δ(t - t₀) dt = x(t₀) · 1 = x(t₀)
Multiplication Property
x(t) · δ(t - t₀) = x(t₀) · δ(t - t₀)
Multiplying a signal by an impulse scales the impulse by the signal value at that point

5. Other Impulse Properties

Scaling
δ(at) = (1/|a|) · δ(t)
Time scaling affects the area of the impulse
Even Function
δ(t) = δ(-t)
The impulse is an even function
Integration
∫₋∞^t δ(τ) dτ = u(t)
Integrating the impulse gives the unit step
Differentiation
du(t)/dt = δ(t)
Differentiating the step gives the impulse

6. Examples with Impulse and Step

Example: Simplify δ(t - 3) · x(t)
δ(t - 3) · x(t) = x(3) · δ(t - 3)
The impulse samples x(t) at t = 3, then scales the impulse

Result: an impulse at t = 3 with area x(3)

Example: Evaluate ∫₋∞^∞ cos(t) · δ(t - π/2) dt
= cos(π/2) = 0
Using sifting property: x(t₀) = cos(π/2) = 0
Example: Simplify ∫₋∞^∞ e^(-t²) · δ(t - 1) dt
= e^(-(1)²) = e^(-1) = 1/e ≈ 0.368
Sifting property: x(1) = e^(-1)
Example: Polynomial × Impulse
Property
f(t) · δ(t) = f(0) · δ(t)
Multiplying any function by δ(t) replaces the function with its value at t = 0
(t² + 3t + 2) · δ(t) = (0² + 3·0 + 2) · δ(t) = 2δ(t)
Only the constant term survives! All higher-order terms vanish because t = 0 at the impulse.
⚠ General rule: For any polynomial f(t), f(t)δ(t) = f(0)δ(t). Only the constant term matters!
Example: Generalized Polynomial × Shifted Impulse
f(t) · δ(t - t₀) = f(t₀) · δ(t - t₀)
(t² + 3t + 2) · δ(t - 1) = (1 + 3 + 2) · δ(t - 1) = 6δ(t - 1)
Evaluate the polynomial at t₀ = 1: f(1) = 1² + 3(1) + 2 = 6

1. Ramp Signal

Definition
r(t) = t · u(t)
r(t) = t for t ≥ 0, r(t) = 0 for t < 0
Integral Relation
r(t) = ∫₋∞^t u(τ) dτ
The ramp is the integral of the unit step
    r(t)
    |            /
    |          /
    |        /
    |      /
    |    /
    |  /
    |/
    +──────────────→ t
    0
⚠ Note: dr(t)/dt = u(t), and d²r(t)/dt² = δ(t). The ramp connects to the impulse through double differentiation.
Higher-Order Ramp Signals (Repeated Integration)
u₋₁(t) = r(t) = t · u(t)
First-order ramp (integral of unit step)
u₋₂(t) = (t²/2) · u(t)
Second-order ramp (integral of first-order ramp)
General Formula
u₋ₙ(t) = [t^(n-1) / (n-1)!] · u(t)
n-th order ramp signal. Each integration increases the power by 1 and divides by the new exponent.
Example: Compute u₋₃(t)
u₋₃(t) = [t² / 2!] · u(t) = (t²/2) · u(t)
Using the formula with n = 3: u₋₃(t) = t^(3-1)/(3-1)! · u(t) = t²/2 · u(t)
⚠ Naming convention: u₋₁(t) is the ramp, u₋₂(t) is the parabolic ramp, and so on. The negative index indicates repeated integration (not differentiation).

2. Signum (Sign) Function

Definition
sgn(t) = { 1, t > 0
{ 0, t = 0
{ -1, t < 0
Returns the sign of t
Relation to Unit Step
sgn(t) = 2u(t) - 1
Can be derived from the unit step
    sgn(t)
     1 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─╱────────
                             │
     0 ──────────────────────0──────────→ t
                             │
    -1 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─╲────────
Derivation: sgn(t) = 2u(t) - 1
For t > 0: 2u(t) - 1 = 2(1) - 1 = 1 ✓
For t < 0: 2u(t) - 1 = 2(0) - 1 = -1 ✓
For t = 0: 2u(0) - 1 = 2(1) - 1 = 1 (convention: u(0) = 1)

5. Sinc Function

Definition (Normalized)
sinc(t) = sin(πt) / (πt)
The normalized sinc function (used in signal processing)
Value at Origin
sinc(0) = 1
Using L'Hopital's rule: lim_{t→0} sin(πt)/(πt) = 1
    sinc(t)
    1 ─ ─ ─ ─ ─ ─|─ ─ ─ ─ ─ ─ ─ ─
                  │
    0 ──╱╲────╱╲──0──╱╲────╱╲────→ t
      ╱  ╲  ╱  ╲   ╱  ╲  ╱  ╲
    - ─ ─ ╲╱ ─ ─ ╲╱ ─ ─ ╲╱ ─ ─
Integral Properties
∫₋∞^∞ sinc(t) dt = 1
Total area under the sinc function equals 1
Energy
∫₋∞^∞ sinc²(t) dt = 1
Total energy of the sinc function also equals 1
Absolute Integral
∫₋∞^∞ |sinc(t)| dt = ∞ (undefined/divergent)
The integral of the absolute value of sinc(t) diverges. The positive and negative lobes alternate with decreasing amplitude, but the total absolute area is infinite.
⚠ Key distinction: ∫sinc(t)dt = 1 (converges due to cancellation of positive and negative lobes), but ∫|sinc(t)|dt = ∞ (diverges because absolute values prevent cancellation).

Worked Example 1: Classifying Signal Behavior

Problem: Determine if x(t) = e^(-3t) · u(t) is periodic, and find its energy/power.
Solution
x(t) = e^(-3t) for t ≥ 0, x(t) = 0 for t < 0
Step 1: Is it periodic? No — the exponential decay means x(t+T) ≠ x(t) for any T.
Step 2: Energy = ∫₀^∞ e^(-6t) dt = [-1/6 · e^(-6t)]₀^∞ = 0 - (-1/6) = 1/6
Step 3: Power = 0 (finite energy → energy signal → zero power)
x(t) is an energy signal with E = 1/6

Worked Example 2: Impulse Sampling

Problem: Simplify ∫₋∞^∞ t² · δ(t + 2) dt
Solution using Sifting Property
∫₋∞^∞ t² · δ(t + 2) dt = x(t₀) where t₀ = -2
Apply sifting: ∫x(t)δ(t-t₀)dt = x(t₀)
Here x(t) = t², t₀ = -2
x(t₀) = (-2)² = 4
Answer: 4

Worked Example 3: Constructing Signals from Steps

Problem: Express a rectangular pulse of width 2 centered at t = 1 using unit steps.
Solution
p(t) = u(t) - u(t - 2)
u(t) turns on at t = 0
u(t - 2) turns on at t = 2
Subtracting: p(t) = 1 for 0 ≤ t < 2, and 0 otherwise
    p(t)
    1 ─ ─ ─╱────────╲─ ─ ─ ─ ─ ─
           │          │
    0 ─────│──────────│──────────→ t
           0          2
p(t) = u(t) - u(t - 2)

Worked Example 4: Sinusoid Periodicity Check

Problem: Is x(t) = cos(3t) + cos(5t) periodic? If so, find the fundamental period.
Solution
Period of cos(3t): T₁ = 2π/3
Period of cos(5t): T₂ = 2π/5
Check: T₁/T₂ = (2π/3)/(2π/5) = 5/3 (rational number → periodic!)
Fundamental period: T₀ = LCM(T₁, T₂) = LCM(2π/3, 2π/5)
T₀ = 2π · LCM(1/3, 1/5) = 2π · (LCM(1,1)/GCD(3,5)) = 2π/1 = 2π
Fundamental period: T₀ = 2π seconds

Rule: If T₁/T₂ is rational, the sum is periodic. The fundamental period is the LCM of the individual periods.

Worked Example 5: Impulse and Step Relationships

Problem: Given x(t) = δ(t - 1) + δ(t + 1), find ∫₋∞^∞ x(t) · cos(πt) dt
Solution
∫₋∞^∞ [δ(t-1) + δ(t+1)] · cos(πt) dt
= ∫₋∞^∞ δ(t-1)·cos(πt) dt + ∫₋∞^∞ δ(t+1)·cos(πt) dt
= cos(π·1) + cos(π·(-1))
= cos(π) + cos(-π)
= (-1) + (-1) = -2
Answer: -2

⚠ Common Mistakes to Avoid:

1. Thinking δ(0) = ∞ — the impulse is a distribution, not a function. Only its integral is defined.

2. Forgetting the |a| in δ(at) = (1/|a|)δ(t) — the absolute value is critical.

3. Confusing energy and power signals: sinusoids are power signals (P = A²/2), decaying exponentials are energy signals.

4. Forgetting that u(0) = 1 in most conventions (not undefined).

5. When checking periodicity of sums: the ratio of periods must be RATIONAL, not necessarily integers.

6. Thinking complex exponentials with r ≠ 0 are periodic — they are NOT. Only pure complex exponentials (r = 0) are periodic.

7. Forgetting that f(t)δ(t) = f(0)δ(t) — only the constant term of a polynomial survives multiplication by δ(t).

8. Confusing ∫sinc(t)dt = 1 (converges) with ∫|sinc(t)|dt = ∞ (diverges) — absolute value changes everything.
