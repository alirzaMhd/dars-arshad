Periodicity of Signals

Signals and Systems — Complete Guide for Exam Preparation

Definition of Continuous-Time Periodicity

A continuous-time signal x(t) is periodic if there exists a positive constant T₀ such that:

Periodicity Condition
x(t) = x(t + T₀) for all t
This must hold for every value of t in the domain of the signal.
Fundamental Period
T₀ = smallest positive value satisfying x(t) = x(t + T₀)
If no such T₀ exists, the signal is aperiodic (non-periodic).
The fundamental period T₀ can be any real number (positive, not necessarily an integer).

Proof Method for Periodicity

The PDF's approach to proving periodicity:

General Method
Assume x(t) is periodic with period T₀ → Form x(t + T₀) → Set x(t + T₀) = x(t) → Solve for T₀
If a valid T₀ > 0 exists that satisfies all conditions for all t, the signal is periodic. If no such solution exists, the signal is non-periodic (aperiodic).
Step 1: Assume Periodicity
Assume x(t) is periodic with unknown period T₀. Write x(t + T₀).
Step 2: Set Equal
Set x(t + T₀) = x(t) and expand both sides.
Step 3: Solve for T₀
Find conditions on T₀. For trigonometric functions, use cos(θ + 2πk) = cos(θ).
Step 4: Conclude
If T₀ > 0 exists → periodic. If no solution → non-periodic.
This method works for both continuous and discrete signals. For discrete signals, T₀ must also be a positive integer.

Worked Example 1: Prove x(t) = cos(2πt) is Periodic

Example: x(t) = cos(2πt)

Step 1: Write x(t + T):

x(t + T) = cos(2π(t + T)) = cos(2πt + 2πT)

Step 2: Set x(t + T) = x(t):

cos(2πt + 2πT) = cos(2πt)

Step 3: For cosine, cos(θ + 2πk) = cos(θ) for any integer k. Therefore:

2πT = 2πk → T = k

Step 4: Smallest positive T is when k = 1:

Result
T₀ = 1 second
The signal x(t) = cos(2πt) is periodic with fundamental period T₀ = 1.

Worked Example 2: Find Period of x(t) = e^(j6t)

Example: x(t) = e^(j6t)

Step 1: Write x(t + T):

x(t + T) = e^(j6(t + T)) = e^(j6t) · e^(j6T)

Step 2: Set x(t + T) = x(t):

e^(j6t) · e^(j6T) = e^(j6t) → e^(j6T) = 1

Step 3: For complex exponential, e^(jθ) = 1 when θ = 2πk. Therefore:

6T = 2πk → T = (2πk)/6 = (πk)/3

Step 4: Smallest positive T is when k = 1:

Result
T₀ = π/3 ≈ 1.047 seconds
The signal x(t) = e^(j6t) is periodic with fundamental period T₀ = π/3.

Definition of Discrete-Time Periodicity

A discrete-time signal x[n] is periodic if there exists a positive integer N₀ such that:

Periodicity Condition
x[n] = x[n + N₀] for all integer n
This must hold for every integer value of n.
Fundamental Period
N₀ = smallest positive INTEGER satisfying x[n] = x[n + N₀]
N₀ must be an integer — this is the critical difference from continuous-time signals!
⚠ Critical Rule: N₀ must be a positive INTEGER. If no such integer exists, the signal is NOT periodic.

The Periodicity Condition for Discrete Sinusoids

For x[n] = cos(ω₀n) to be periodic:

Necessary and Sufficient Condition
ω₀N₀ = 2πk for some integers N₀ > 0 and k
Equivalently: ω₀/(2π) = k/N₀ must be a RATIONAL number.
Why This Matters
2π/ω₀ must be rational (equivalently, ω₀/2π must be rational)
Only when 2π/ω₀ is a ratio of integers can we find integer N₀ and k satisfying ω₀N₀ = 2πk.
Rational Number
Can be expressed as ratio of two integers (e.g., 1/4, 3/8, 7/2)
Irrational Number
Cannot be expressed as ratio of integers (e.g., π, √2, e)
⚠ Key Insight: If ω₀/(2π) is irrational, the discrete-time sinusoid is NOT periodic, even though its continuous-time counterpart IS periodic!
Example: For x[n] = cos(2n/3), ω₀ = 2/3, so ω₀/(2π) = (2/3)/(2π) = 1/(3π), which is irrational. Therefore N₀ = 6πk/5 can never be an integer (since π is irrational), and the signal is NOT periodic.

Worked Example 3: x[n] = cos(πn/4)

Example: x[n] = cos(πn/4)

Step 1: Identify ω₀:

ω₀ = π/4

Step 2: Check if ω₀/(2π) is rational:

ω₀/(2π) = (π/4)/(2π) = 1/8

Step 3: Since 1/8 is rational, the signal IS periodic. The condition ω₀N₀ = 2πk becomes:

(π/4)N₀ = 2πk → N₀ = 8k

Step 4: Smallest positive integer N₀ is when k = 1:

Result
N₀ = 8 samples
The signal x[n] = cos(πn/4) is periodic with fundamental period N₀ = 8.

Worked Example 4: x[n] = cos(n/3) — NOT Periodic!

Example: x[n] = cos(n/3)

Step 1: Identify ω₀:

ω₀ = 1/3

Step 2: Check if ω₀/(2π) is rational:

ω₀/(2π) = (1/3)/(2π) = 1/(6π)

Step 3: Since π is irrational, 1/(6π) is IRRATIONAL.

⚠ Conclusion: There is NO integer N₀ that satisfies (1/3)N₀ = 2πk for any integer k.
Result
x[n] = cos(n/3) is NOT periodic
Even though cos(t/3) is periodic in continuous time, its discrete-time version is NOT periodic because the sampling interval (n = 0, 1, 2, ...) creates an irrational frequency ratio.

Continuous vs Discrete Periodicity

Property Continuous-Time Discrete-Time
Signal Notation x(t) x[n]
Period Notation T₀ N₀
Period Type Any real number Must be an integer
Periodicity Condition x(t) = x(t + T₀) x[n] = x[n + N₀]
Fundamental Period Smallest T₀ > 0 Smallest integer N₀ > 0
Cosine: cos(ω₀t) Always periodic (T₀ = 2π/ω₀) Only if ω₀/(2π) is rational
Key Constraint None — any frequency works Frequency must yield rational ratio with 2π

Why cos(n/3) is NOT Periodic but cos(πn/4) IS

cos(πn/4) — Periodic
ω₀ = π/4
ω₀/(2π) = (π/4)/(2π) = 1/8 (rational)
Therefore: N₀ = 8
cos(n/3) — NOT Periodic
ω₀ = 1/3
ω₀/(2π) = (1/3)/(2π) = 1/(6π) (irrational)
Therefore: No integer N₀ exists
⚠ Common Exam Trap: Students often assume that if cos(ω₀t) is periodic in continuous time, then cos(ω₀n) must also be periodic in discrete time. This is FALSE! The discrete version requires the additional condition that ω₀/(2π) must be rational.

Quick Decision Flowchart

Step 1: Identify ω₀
Extract the frequency from cos(ω₀n) or sin(ω₀n)
Step 2: Compute ω₀/(2π)
Divide the frequency by 2π
Step 3: Check Rationality
If rational → periodic. If irrational → NOT periodic.
Step 4: Find N₀
If rational = k/N₀ in lowest terms, then N₀ is the fundamental period.

Worked Example 8: x(t) = sin(3πt) + cos(5πt)

Example: Sum of Two Periodic Signals

Step 1: Find individual periods:

For sin(3πt): T₁ = 2π/(3π) = 2/3
For cos(5πt): T₂ = 2π/(5π) = 2/5

Step 2: Check if T₁/T₂ is rational:

T₁/T₂ = (2/3)/(2/5) = 5/3 (rational)

Step 3: Find LCM of the periods:

T₀ = LCM(T₁, T₂) = LCM(2/3, 2/5) = LCM(2,2)/GCD(3,5) = 2/1 = 2
Result
T₀ = 2 seconds

Worked Example 9: x[n] = e^(jπn/2)

Example: Complex Exponential in Discrete Time

Step 1: Identify ω₀:

ω₀ = π/2

Step 2: Check if ω₀/(2π) is rational:

ω₀/(2π) = (π/2)/(2π) = 1/4 (rational)

Step 3: The signal is periodic. Find N₀:

ω₀N₀ = 2πk → (π/2)N₀ = 2πk → N₀ = 4k
Result
N₀ = 4 samples

Worked Example 10: x(t) = cos(4πt) + sin(6πt)

Example: Sum of Cosine and Sine

Step 1: Find individual periods:

For cos(4πt): T₁ = 2π/(4π) = 1/2
For sin(6πt): T₂ = 2π/(6π) = 1/3

Step 2: Check if T₁/T₂ is rational:

T₁/T₂ = (1/2)/(1/3) = 3/2 (rational)

Step 3: Find LCM:

T₀ = LCM(1/2, 1/3) = LCM(1,1)/GCD(2,3) = 1/1 = 1
Result
T₀ = 1 second

Worked Example 5: x[n] = cos(3πn/7 + 2)

Example: Discrete Cosine with Phase Offset

Step 1: Identify ω₀:

ω₀ = 3π/7

Step 2: Check if ω₀/(2π) is rational:

ω₀/(2π) = (3π/7)/(2π) = 3/14

Step 3: Since 3/14 is rational, the signal IS periodic. Find N₀:

ω₀N₀ = 2πk → (3π/7)N₀ = 2πk → N₀ = 14k/3

Step 4: Smallest positive integer N₀ is when k = 3:

Result
N₀ = 14 samples
The signal x[n] = cos(3πn/7 + 2) is periodic with fundamental period N₀ = 14. The phase offset +2 does not affect the period.

Worked Example 6: x[n] = sin(2n/3 + 5π/3) — NOT Periodic!

Example: Discrete Sine with Irrational Frequency Ratio

Step 1: Identify ω₀:

ω₀ = 2/3

Step 2: Check if ω₀/(2π) is rational:

ω₀/(2π) = (2/3)/(2π) = 1/(3π)

Step 3: Since π is irrational, 1/(3π) is IRRATIONAL.

Step 4: Alternatively, from ω₀N₀ = 2πk:

(2/3)N₀ = 2πk → N₀ = 6πk/5

For any integer k, the value 6πk/5 is always irrational (since π is irrational), so N₀ can never be an integer.

⚠ Conclusion: There is NO integer N₀ that satisfies the periodicity condition. The signal x[n] = sin(2n/3 + 5π/3) is NOT periodic, even though its continuous-time counterpart sin(2t/3 + 5π/3) IS periodic with T₀ = 3π.

Worked Example 7: x[n] = cos(3n/7)

Example: Discrete Cosine with Fractional Frequency

Step 1: Identify ω₀:

ω₀ = 3/7

Step 2: Check if ω₀/(2π) is rational:

ω₀/(2π) = (3/7)/(2π) = 3/(14π)

Step 3: Since π is irrational, 3/(14π) is IRRATIONAL.

⚠ Result: x[n] = cos(3n/7) is NOT periodic!

Worked Example 11: x(t) = Σ e^(-t+6n) from n=-∞ to ∞

Example: Periodic Sum of Shifted Exponentials

Understanding the signal:

x(t) = Σ_{n=-∞}^{∞} e^(-t+6n)
This is a sum of exponentially decaying terms, each shifted by multiples of 6 in the exponent.

Step 1: To find the period, check if x(t + T₀) = x(t) for some T₀:

x(t + T₀) = Σ_{n=-∞}^{∞} e^(-(t+T₀)+6n) = Σ_{n=-∞}^{∞} e^(-t - T₀ + 6n)

Step 2: For this to equal x(t), we need each term to map to another term in the sum. Shifting the index: let m = n - 1 (or adjusting):

Σ_{n=-∞}^{∞} e^(-t - T₀ + 6n) = Σ_{n=-∞}^{∞} e^(-t + 6(n - T₀/6))

Step 3: For the sum to remain unchanged, T₀/6 must be an integer (so the shift maps terms onto each other). The smallest positive T₀ is when T₀/6 = 1:

Result
T₀ = 1/6 seconds
The signal x(t) = Σ e^(-t+6n) is periodic with fundamental period T₀ = 1/6.

Worked Example 12: x(t) = e^(j2t) + cos(3πt)

Example: Mixed Continuous-Time Signals

Step 1: Find individual periods:

For e^(j2t): T₁ = 2π/2 = π
For cos(3πt): T₂ = 2π/(3π) = 2/3

Step 2: Check if T₁/T₂ is rational:

T₁/T₂ = π/(2/3) = 3π/2 (irrational)

Step 3: Since π is irrational, T₁/T₂ is irrational.

⚠ Result: x(t) = e^(j2t) + cos(3πt) is NOT periodic!
Even though both individual signals are periodic, their sum is not periodic because the ratio of their periods is irrational.

Quick Reference Card

Continuous: x(t) = cos(ω₀t)
Period: T₀ = 2π/ω₀
Always periodic for ω₀ ≠ 0
Discrete: x[n] = cos(ω₀n)
Periodic iff ω₀/(2π) ∈ ℚ
N₀ = smallest integer with ω₀N₀ = 2πk
Sum of Periodic Signals
Periodic iff T₁/T₂ is rational
T₀ = LCM(T₁, T₂)
Common Mistake
Assuming discrete periodicity from continuous periodicity
Always check rationality condition!

Common Exam Warnings

⚠ Warning 1: Never assume cos(n/ω) is periodic just because cos(t/ω) is periodic. The discrete version requires ω to be a rational multiple of π.
⚠ Warning 2: When finding the period of a sum of signals, always verify that the ratio of individual periods is rational. If irrational, the sum is NOT periodic.
⚠ Warning 3: The fundamental period is the SMALLEST positive value. Don't just find any period — find the smallest one.
⚠ Warning 4: For discrete-time signals, N₀ must be a positive INTEGER. If your calculation gives a non-integer, the signal is NOT periodic.
