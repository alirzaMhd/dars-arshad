حل کامل تمرین ۷
▼
درستی یا نادرستی گزاره‌های زیر را بررسی کنید و یا شرایط درستی را بیان کنید:
(a) اگر \(f(n) \in O(g(n))\) آنگاه \(f(n)^2 \in O(g(n)^2)\)
(b) اگر \(f(n) \in o(g(n))\) آنگاه \(f(n)^2 \in o(g(n)^2)\)
(c) اگر \(f(n) \in O(g(n))\) آنگاه \(\lg f(n) \in O(\lg g(n))\) (برای n‌های به اندازه کافی بزرگ)
(d) \(f(n) \in O(f(n)^2)\)
(e) \(f(n) \in \theta(f(\sqrt{n}))\)
(f) \(f(n) + o(f(n)) \in O(f(n))\)
(g) \(O(f(n)) - \Omega(f(n))\) با \(o(f(n))\) مساوی است
(h) \(f(n) + g(n) = \theta(\min\{f(n), g(n)\})\)
(i) \(\max\{f(n), g(n)\} = \theta(f(n) + g(n))\)
نکته اصلی: بسیاری از خواص نمادهای جانبی که به نظر درست می‌آیند، فقط به شرطی درست هستند که توابع شرط خاصی داشته باشند (مثلاً \(\geq 1\)).

حل کامل:

(a) نادرست. مثال نقض: \(f(n) = \frac{1}{n}\) و \(g(n) = \frac{1}{n^2}\).

\(f(n) \in O(g(n))\) یعنی \(\frac{1}{n} \leq c \cdot \frac{1}{n^2}\) — این برای n‌های بزرگ نادرست است. پس این گزاره اصلاً معنادار نیست. ولی مثال بهتر: اگر \(f(n) = \frac{1}{\sqrt{n}}\) و \(g(n) = \frac{1}{n}\)، آنگاه \(f(n) \in O(g(n))\) نیست. مثال صحیح‌تر: اگر \(0 < f(n) < 1\) باشد، آنگاه \(f(n)^2 < f(n)\) یعنی رشد \(f(n)^2\) کمتر است.

در واقع، اگر \(f(n) \leq c \cdot g(n)\) آنگاه \(f(n)^2 \leq c^2 \cdot g(n)^2\) — پس گزاره (a) درست است!

(b) درست. اگر \(f(n) < c \cdot g(n)\) برای همه c > 0 از یک n₀ به بعد، آنگاه \(f(n)^2 < c^2 \cdot g(n)^2\) نیز برقرار است.

(c) درست. اگر \(f(n) \leq c \cdot g(n)\) آنگاه \(\lg f(n) \leq \lg c + \lg g(n)\). برای n‌های بزرگ، \(\lg c\) نسبت به \(\lg g(n)\) ناچیز است، پس \(\lg f(n) \leq (1+\epsilon) \lg g(n)\).

(d) نادرست. اگر \(f(n) < 1\) باشد، آنگاه \(f(n)^2 < f(n)\) یعنی \(f(n) \notin O(f(n)^2)\). مثال: \(f(n) = \frac{1}{n}\).

(e) نادرست. مثال: \(f(n) = n\). آنگاه \(f(\sqrt{n}) = \sqrt{n}\) و \(n \neq \theta(\sqrt{n})\).

(f) درست. \(o(f(n))\) توابعی با رشد کمتر از \(f(n)\) است. پس \(f(n) + o(f(n)) \leq f(n) + \epsilon \cdot f(n) = (1+\epsilon) f(n)\).

(g) نادرست. \(O(f(n)) - \Omega(f(n))\) می‌تواند شامل توابعی با رشد منفی (نزدیک صفر) باشد که لزوماً \(o(f(n))\) نیستند.

(h) نادرست. مثال: \(f(n) = n\) و \(g(n) = 1\). آنگاه \(\min\{n, 1\} = 1\) ولی \(f(n) + g(n) = n + 1 = \theta(n)\).

(i) درست. \(\max\{f(n), g(n)\} \leq f(n) + g(n) \leq 2 \max\{f(n), g(n)\}\). پس \(\max\{f,g\} = \theta(f+g)\).

بیشتر دانشجوها فکر می‌کنند \(f(n) \in O(f(n)^2)\) همیشه درست است. ولی برای توابع کوچکتر از ۱ (مثل \(1/n\)) نادرست است.
خواص O، θ، Ω را به صورت مجموعه‌ای حفظ کنید: \(O \cap \Omega = \theta\) و \(o \cap \omega = \emptyset\).

ترتیب رشد زیر را بررسی کنید:
\(\lg^* n \ll \lg\lg n \ll \lg n \ll \sqrt{\lg n} \ll \sqrt{n} \ll n \ll n\lg n \ll n\lg(n\lg n) \ll n^2 \ll n^3 \ll (\frac{3}{2})^n \ll 2^n \ll n! \ll n^n\)
نکته اصلی: ترتیب کامل رشد توابع را حفظ کنید — این پایه تمام تحلیل‌های الگوریتم است.

حل کامل (مرحله به مرحله):

مرحله ۱: مقایسه لگاریتمی‌ها

  • \(\lg^* n\): تعداد دفعاتی که باید لگاریتم گرفت تا به ۱ برسیم. بسیار کند رشد می‌کند (مثلاً \(\lg^* 65536 = 4\)).
  • \(\lg\lg n\): لگاریتم دوبار لگاریتم — رشد بیشتری از \(\lg^* n\) دارد.
  • \(\lg n\): لگاریتم ساده.
  • \(\sqrt{\lg n} = (\lg n)^{0.5}\): ریشه دوم لگاریتم — از \(\lg n\) کمتر است.

مرحله ۲: مقایسه توان‌های کوچک

  • \(\sqrt{n} = n^{0.5}\): ریشه دوم — از هر تابع لگاریتمی بیشتر است.
  • \(n = n^1\): خطی — از \(\sqrt{n}\) بیشتر است.

مرحله ۳: مقایسه جمله‌های ناچیز

  • \(n \lg n\): حاصل ضرب لگاریتم در خطی.
  • \(n \lg(n \lg n) = n(\lg n + \lg\lg n) = n\lg n + n\lg\lg n\): جمله \(n\lg\lg n\) نسبت به \(n\lg n\) ناچیز است، پس \(\theta(n\lg n)\) — هم‌رشد!

مرحله ۴: مقایسه توان‌ها

  • \(n^2 < n^3\) واضح است.

مرحله ۵: مقایسه نمایی‌ها

  • \((\frac{3}{2})^n\): نمایی با پایه ۱.۵.
  • \(2^n\): نمایی با پایه ۲ — از \((\frac{3}{2})^n\) بیشتر.
  • \(n!\): فاکتوریل — از \(2^n\) بیشتر است (چون \(n! \approx (\frac{n}{e})^n\)).
  • \(n^n\): بزرگترین — از \(n!\) بیشتر است.

نتیجه نهایی:

\[\lg^* n \ll \lg\lg n \ll \lg n \ll \sqrt{\lg n} \ll \sqrt{n} \ll n \ll n\lg n \ll n^2 \ll n^3 \ll \left(\frac{3}{2}\right)^n \ll 2^n \ll n! \ll n^n\]
بیشتر دانشجوها \(n\lg(n\lg n)\) را از \(n\lg n\) بزرگتر می‌دانند. در حالی که هم‌رشد هستند چون \(\lg(n\lg n) = \lg n + \lg\lg n \sim \lg n\).
规矩 طلایی: لگاریتمی < توانی < نمایی < فاکتوریلی < توانی-توانی. در هر دسته، پایه یا توان بزرگتر = رشد بیشتر.

▼
نشان دهید \(f(n) = \begin{cases} n^2 & n \text{ زوج} \\ 0 & n \text{ فرد} \end{cases}\)، از مرتبه O هیچ یک از توابع تمرین قبل نیست.
نکته اصلی: توابع نامونوتون ممکن است در هیچ نماد جانبی (O، Ω، θ) قرار نگیرند — باید دقیقاً اثبات کرد.

حل کامل:

فرض: می‌خواهیم نشان دهیم هیچ تابع صعودی \(g(n)\) وجود ندارد که \(f(n) \in O(g(n))\) باشد.

مرحله ۱: فرض خلاف. فرض کنیم \(f(n) \in O(g(n))\) برای تابعی صعودی \(g(n)\). یعنی:

\[f(n) \leq c \cdot g(n) \quad \text{برای همه } n \geq n_0\]

مرحله ۲: بررسی مقادیر زوج. برای اعداد زوج \(n = 2k\):

\[f(2k) = (2k)^2 = 4k^2 \leq c \cdot g(2k)\]

پس \(g(2k) \geq \frac{4k^2}{c}\) — یعنی \(g\) باید حداقل مرتبه \(n^2\) رشد کند.

مرحله ۳: بررسی مقادیر فرد. برای اعداد فرد \(n = 2k+1\):

\[f(2k+1) = 0 \leq c \cdot g(2k+1)\]

این همیشه درست است (چون \(g \geq 0\)).

مرحله ۴: نقض. اکنون اگر \(g(n)\) صعودی باشد، باید \(g(n) \geq g(n-1)\). برای \(n\) زوج:

\[g(n) \geq \frac{n^2}{c} \quad \text{و} \quad g(n-1) \geq 0\]

ولی مشکل اینجاست که \(g(n)\) باید صعودی باشد و \(f(n)\) برای مقادیر فرد صفر است. پس \(g(n)\) باید هم صعودی باشد و هم برای n‌های فرد مقادیر کوچکی داشته باشد — این متناقض نیست!

مرحله ۵: اثبات دقیق‌تر. در واقع، \(f(n) \in O(n^2)\) درست است! چون \(f(n) \leq n^2\) برای همه n. پس گزاره اصلی نادرست است — \(f(n)\) از مرتبه \(O(n^2)\) هست.

دانشجوها فکر می‌کنند تابع نامونوتون نمی‌تواند در O قرار بگیرد. ولی O فقط می‌گوید \(f(n) \leq c \cdot g(n)\) — نیازی به صعودی بودن f نیست!
\(f(n) \in O(g(n))\) فقط یک نامساوی است: \(f(n) \leq c \cdot g(n)\). تابع f لزوماً صعودی نیست.

آرایه A حاوی n بیت است. گونه ۱: نیمی صفر، نیمی یک (بدون ترتیب خاص). گونه ۲: \(\frac{n}{3}\) صفر و \(\frac{n}{3}\) یک. با احتمال یکسان یکی از گونه‌هاست. در بدترین حالت دست کم چند درایه باید بررسی شود؟
نکته اصلی: در بدترین حالت باید \(n/3 + 1\) درایه بخوانید — نه \(n/2\).

حل کامل:

مرحله ۱: تحلیل گونه ۱. در گونه ۱، n بیت داریم که نیمی صفر و نیمی یک است:

\[\text{تعداد صفرها} = \frac{n}{2}, \quad \text{تعداد یک‌ها} = \frac{n}{2}\]

مرحله ۲: تحلیل گونه ۲. در گونه ۲:

\[\text{تعداد صفرها} = \frac{n}{3}, \quad \text{تعداد یک‌ها} = \frac{n}{3}, \quad \text{باقیمانده} = \frac{n}{3}\]

یعنی \(\frac{n}{3}\) درایه خالی (صفر) و \(\frac{n}{3}\) درایه یک داریم.

مرحله ۳: بدترین حالت. فرض کنید درایه‌ها را یکی یکی می‌خوانید. در بدترین حالت:

  • اولین \(\frac{n}{3}\) درایه‌ای که می‌خوانید، همه صفر باشند (گونه ۲).
  • درایه بعدی یک باشد — حالا مطمئنید گونه ۲ است (چون گونه ۱ فقط \(\frac{n}{2}\) تا صفر دارد).

مرحله ۴: محاسبه.

\[\text{تعداد درایه‌ها} = \frac{n}{3} + 1 = \frac{n+3}{3}\]

پس گزینه (۴) \(\frac{n+5}{6}\) نیست — در واقع پاسخ صحیح \(\frac{n}{3}+1\) است.

دانشجوها فکر می‌کنند باید نصف آرایه را بخوانند (\(n/2\)). ولی چون تفاوت بین دو گونه در تعداد صفرهاست، کافی است از مرز \(\frac{n}{3}\) عبور کنید.

اگر زمان اجرای یک الگوریتم با رابطه \(T(n) = T(\lg^* n) + O(n)\) تعریف شود، کدام گزینه مرتبه زمانی این الگوریتم را نشان می‌دهد؟
نکته اصلی: بازگشت‌هایی که در هر قدم اندازه ورودی لگاریتمی کاهش می‌یابد، مرتبه جمله غیربازگشتی (\(O(n)\)) هستند.

حل کامل:

مرحله ۱: تحلیل بازگشت.

\[T(n) = T(\lg^* n) + O(n)\]

مرحله ۲: گسترش بازگشت.

با فرض \(T(n_0) = O(1)\) برای مقدار کوچک:

\[T(n) = T(\lg^* n) + c_1 \cdot n\]
\[T(\lg^* n) = T(\lg^*(\lg^* n)) + c_1 \cdot \lg^* n\]
\[T(n) = T(\lg^*(\lg^* n)) + c_1 \cdot \lg^* n + c_1 \cdot n\]

مرحله ۳: الگو. هر بار \(\lg^* n\) کاهش می‌یابد. تعداد گام‌ها حدود \(\lg^* n\) است. مجموع:

\[T(n) \approx c_1 \cdot n + c_1 \cdot \lg^* n + c_1 \cdot \lg^*(\lg^* n) + \ldots\]

مرحله ۴: تخمین. چون \(\lg^* n\) بسیار کند رشد می‌کند، جمله غالب \(c_1 \cdot n\) است:

\[T(n) = O(n)\]

پاسخ: گزینه (۳) \(O(n)\)

دانشجوها فکر می‌کنند چون بازگشت وجود دارد، حتماً پیچیدگی بیشتر از \(O(n)\) است. ولی کاهش لگاریتمی ورودی آنقدر سریع است که تأثیری بر جمله غالب ندارد.
بازگشت \(T(n) = T(\text{logarithmic reduction}) + O(f(n))\) معمولاً \(O(f(n))\) است — جمله بازگشتی ناچیز است.

▼
با فرض مثبت بودن توابع f و g، تعداد گزاره‌های درست از میان گزاره‌های زیر چند است؟
گزاره ۱: \(f(n) \in O(f(n)^2)\)
گزاره ۲: \(f(n) \in o(f(n)) + \theta(f(n))\)
گزاره ۳: \(f(n) \in O(g(n)) \Rightarrow f(n)^2 \in O(g(n)^2)\)
گزاره ۴: \(f(n) \in \theta(f(\sqrt{n}))\)
نکته اصلی: گزاره ۱ برای توابع کوچکتر از ۱ نادرست است — اولین گزاره همیشه درست نیست!

حل کامل:

گزاره ۱: \(f(n) \in O(f(n)^2)\)

آیا \(f(n) \leq c \cdot f(n)^2\) برای همه n ≥ n₀؟

اگر \(f(n) < 1\) باشد (مثلاً \(f(n) = \frac{1}{n}\))، آنگاه \(f(n)^2 = \frac{1}{n^2} < \frac{1}{n} = f(n)\).

پس \(f(n) \notin O(f(n)^2)\). نادرست.

گزاره ۲: \(f(n) \in o(f(n)) + \theta(f(n))\)

\(o(f(n)) + \theta(f(n))\) یعنی مجموع تابعی با رشد کمتر از f و تابعی هم‌رشد با f.

\(o(f(n)) + \theta(f(n)) = \theta(f(n))\) — چون جمع تابع کوچکتر با هم‌رشد، هم‌رشد است.

پس \(f(n) \in \theta(f(n))\) که درست است. درست.

گزاره ۳: \(f(n) \in O(g(n)) \Rightarrow f(n)^2 \in O(g(n)^2)\)

اگر \(f(n) \leq c \cdot g(n)\) آنگاه \(f(n)^2 \leq c^2 \cdot g(n)^2\). درست.

گزاره ۴: \(f(n) \in \theta(f(\sqrt{n}))\)

مثلاً \(f(n) = n\): آیا \(n = \theta(\sqrt{n})\)? خیر، \(n \gg \sqrt{n}\). نادرست.

نتیجه: فقط گزاره‌های ۲ و ۳ درست هستند → گزینه (۱) «یک گزاره صحیح» یا (۲) «دو گزاره صحیح»

پاسخ: گزینه (۱) — فقط یک گزاره (گزاره ۲) درست است.

بیشتر دانشجوها فکر می‌کنند \(f(n) \in O(f(n)^2)\) همیشه درست است چون \(f \leq f^2\). ولی این فقط برای \(f \geq 1\) صادق است!
قبل از تأیید هر گزاره، اول با یک تابع ساده (مثل \(1/n\) یا \(n\)) آزمایش کنید.

کدامیک از موارد زیر صحیح است؟
(1) \(n \sin n \in \Omega^2\)
(2) \(n \sin n \in O(n)\)
(3) \(n^2 \in \theta(n \sin n)\)
(4) \(n^2 \in \Omega(n \sin n)\)
نکته اصلی: تابع \(n \sin n\) متناوب است — هیچ‌وقت دقیقاً صفر نمی‌شود (چون دامنه اعداد طبیعی است) ولی مرتباً نزدیک صفر می‌شود.

حل کامل:

مرحله ۱: بررسی دامنه. در این درس، دامنه توابع اعداد طبیعی \(\{0, 1, 2, 3, \ldots\}\) است. \(\sin n\) برای اعداد صحیح هیچ‌وقت دقیقاً صفر نمی‌شود (چون \(\pi\) گنگ است). پس \(|\sin n|\) همیشه یک مقدار ثابت کوچکتر از ۱ است.

مرحله ۲: بررسی گزینه (۱) \(n \sin n \in \Omega^2\).

\(\Omega^2\) یعنی \(f(n) \geq c \cdot n^2\) — ولی \(|n \sin n| \leq n\) پس \(n \sin n\) رشدی بیشتر از \(n\) ندارد. نادرست.

مرحله ۳: بررسی گزینه (۲) \(n \sin n \in O(n)\).

\(|n \sin n| = n \cdot |\sin n| \leq n \cdot 1 = n\). پس \(n \sin n \leq c \cdot n\) با \(c = 1\). درست!

مرحله ۴: بررسی گزینه (۳) \(n^2 \in \theta(n \sin n)\).

\(n \sin n\) رشدی حدود \(n\) دارد (چون \(|\sin n|\) بین ۰ و ۱ است). \(n^2\) رشد بیشتری دارد. پس هم‌رشد نیستند. نادرست.

مرحله ۵: بررسی گزینه (۴) \(n^2 \in \Omega(n \sin n)\).

آیا \(n^2 \geq c \cdot n \sin n\)? در نقاطی که \(\sin n > 0\) داریم \(n^2 \geq c \cdot n\) که برای \(c \leq n\) درست است. ولی در نقاطی که \(\sin n < 0\)، \(n \sin n\) منفی است و \(n^2 \geq \text{منفی}\) همیشه درست است. پس درست — ولی گزینه (۲) دقیق‌تر است.

پاسخ نهایی: گزینه (۲)

دانشجوها فکر می‌کنند چون \(\sin n\) گاهی صفر می‌شود، \(n \sin n\) هم صفر می‌شود. ولی در اعداد طبیعی، \(\sin n\) هیچ‌وقت دقیقاً صفر نیست.
دامنه توابع در این درس اعداد طبیعی \(\{0,1,2,...\}\) است. \(\sin n\) برای عدد صحیح هیچ‌وقت صفر نمی‌شود.

نشان دهید \(\sum_{k=0}^{\infty} k x^k = \frac{x}{(1-x)^2}\) به ازای \(|x| < 1\)
نکته اصلی: گرفتن مشتق از سری هندسی ساده، فرمول سری وزن‌دار را ایجاد می‌کند — تکنیکی که در تحلیل الگوریتم‌ها خیلی مفید است.

حل کامل:

مرحله ۱: شروع از سری هندسی.

\[\sum_{k=0}^{\infty} x^k = 1 + x + x^2 + x^3 + \ldots = \frac{1}{1-x} \quad \text{برای } |x| < 1\]

مرحله ۲: گرفتن مشتق از طرفین.

\[\frac{d}{dx}\left(\sum_{k=0}^{\infty} x^k\right) = \frac{d}{dx}\left(\frac{1}{1-x}\right)\]
\[\sum_{k=1}^{\infty} k x^{k-1} = \frac{1}{(1-x)^2}\]

توجه: مشتق جمله اول (\(k=0\)) صفر است، پس مجموع از \(k=1\) شروع می‌شود.

مرحله ۳: ضرب در x.

\[x \cdot \sum_{k=1}^{\infty} k x^{k-1} = x \cdot \frac{1}{(1-x)^2}\]
\[\sum_{k=1}^{\infty} k x^k = \frac{x}{(1-x)^2}\]

مرحله ۴: تغییر اندیس. چون جمله \(k=0\) برابر صفر است، می‌توانیم مجموع را از \(k=0\) شروع کنیم:

\[\boxed{\sum_{k=0}^{\infty} k x^k = \frac{x}{(1-x)^2}}\]
دانشجوها فراموش می‌کنند بعد از مشتق گیری، در x ضرب کنند. بدون این ضرب، فرمول نادرست می‌شود.
规矩: سری هندسی → مشتق → ضرب در x = سری وزن‌دار. این تکنیک برای \(\sum k^2 x^2\) هم کار می‌کند (مشتق دوم).
