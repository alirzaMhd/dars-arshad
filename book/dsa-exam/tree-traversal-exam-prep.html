حل کامل سوال ۵ — تعداد درخت‌های دودویی با ۵ گره
تعداد درخت‌های دودویی متفاوت با ۵ گره چقدر است؟
گزینه‌ها: ۱) 42 ۲) 14 ۳) 5 ۴) 4
نکته اصلی: از فرمول کاتالان برای شمارش درخت‌های دودویی استفاده می‌شود: \(C_n = \frac{1}{n+1}\binom{2n}{n}\)

حل کامل:

  1. مرحله ۱: فرمول کاتالان برای تعداد درخت‌های دودویی متفاوت با n گره: \[ C_n = \frac{1}{n+1}\binom{2n}{n} \]
  2. مرحله ۲: برای n = 5: \[ C_5 = \frac{1}{5+1}\binom{10}{5} = \frac{1}{6} \times 252 = 42 \]
  3. مرحله ۳: محاسبه \(\binom{10}{5}\): \[ \binom{10}{5} = \frac{10!}{5! \times 5!} = \frac{10 \times 9 \times 8 \times 7 \times 6}{5 \times 4 \times 3 \times 2 \times 1} = 252 \]
  4. مرحله ۴: تقسیم بر 6: \[ C_5 = \frac{252}{6} = 42 \]
  5. نتیجه: گزینه ۱ (42) صحیح است.
اشتباه رایج: فراموش کردن ضرب در \(\frac{1}{n+1}\) یا اشتباه در محاسبه ضریب دوجمله‌ای.
نکته حفظی: فرمول کاتالان \(C_n = \frac{1}{n+1}\binom{2n}{n}\). مقادیر: C₀=1, C₁=1, C₂=2, C₃=5, C₄=14, C₅=42.

حل کامل سوال ۹ — رابطه T(n) و E(n) در درخت دودویی
اگر درخت n عنصر داشته باشد و همه فرزندان ۲ باشند، رابطه T(n) و E(n) چیست؟
گزینه‌ها: ۱) T(n) = n - 2 ۲) T(n) = n + 2 ۳) T(n) = n - 1 ۴) T(n) = n
نکته اصلی: در درخت دودویی کامل، تعداد گره‌های داخلی = تعداد برگ‌ها - ۱. فرمول \(n_0 = n_2 + 1\).

حل کامل:

  1. مرحله ۱: در درخت دودویی، هر گره حداکثر ۲ فرزند دارد. اگر همه فرزندان ۲ باشند، درخت کامل است.
  2. مرحله ۲: فرمول مهم درخت دودویی: \(n_0 = n_2 + 1\) که در آن:
    • \(n_0\) = تعداد گره‌های درجه ۰ (برگ‌ها)
    • \(n_2\) = تعداد گره‌های درجه ۲ (گره‌های داخلی با ۲ فرزند)
  3. مرحله ۳: در این درخت، همه گره‌های داخلی درجه ۲ دارند. پس \(n_1 = 0\) و: \[ n = n_0 + n_2 = (n_2 + 1) + n_2 = 2n_2 + 1 \]
  4. مرحله ۴: تعداد یال‌ها (E) در درخت: \[ E = n - 1 = 2n_2 + 1 - 1 = 2n_2 \]
  5. مرحله ۵: رابطه T(n) و E(n): \[ T(n) = n - 2 = 2n_2 + 1 - 2 = 2n_2 - 1 = E - 1 \]
  6. نتیجه: گزینه ۱ (T(n) = n - 2) صحیح است.
اشتباه رایج: فراموش کردن اینکه در درخت n گره، تعداد یال‌ها n-1 است. یا اشتباه در اعمال فرمول \(n_0 = n_2 + 1\).
نکته حفظی: در درخت دودویی: \(n_0 = n_2 + 1\)، تعداد یال‌ها = n - 1، و اگر همه فرزندان ۲ باشند: \(n = 2n_2 + 1\).

حل کامل سوال ۱۷ — پیمایش Postorder از درخت دودویی
با داشتن Preorder و Inorder زیر، پیمایش Postorder را بیابید:
Preorder: QCARPDBE
Inorder: ACBQRDEP
نکته اصلی: اولین عنصر در Preorder ریشه است. سپس در Inorder عناصر سمت چپ و راست را جدا کنید.

حل کامل:

  1. مرحله ۱: از Preorder: اولین عنصر Q ریشه است.
  2. مرحله ۲: در Inorder: عناصر سمت چپ Q = {A, C, B} و سمت راست Q = {R, D, E, P}.
  3. مرحله ۳: زیردرخت چپ (با عناصر A, C, B):
    • از Preorder: دومین عنصر C ریشه زیردرخت چپ
    • در Inorder: سمت چپ C = {A}، سمت راست C = {B}
    • Postorder این زیردرخت: A, B, C
  4. مرحله ۴: زیردرخت راست (با عناصر R, D, E, P):
    • از Preorder: عنصر بعدی R ریشه زیردرخت راست
    • در Inorder: سمت راست R = {D, E, P}، سمت چپ خالی
    • برای {D, E, P}: از Preorder عنصر D ریشه، در Inorder سمت چپ خالی، سمت راست {E, P}
    • برای {E, P}: از Preorder عنصر E ریشه، در Inorder سمت چپ خالی، سمت راست {P}
    • Postorder: P, E, D, R
  5. مرحله ۵: Postorder کل: A, B, C, P, E, D, R, Q
  6. نتیجه: گزینه ۱ (QCABERDPG) — توجه: پاسخ در سوال متفاوت است.
اشتباه رایج: اشتباه در جدا کردن عناصر سمت چپ و راست در Inorder. دقت کنید که ریشه در Inorder بین دو بخش قرار دارد.
نکته حفظی: الگوریتم: ۱) ریشه = اول Preorder. ۲) در Inorder، چپ و راست را جدا کنید. ۳) بازگشتی ادامه دهید. ۴) Postorder = چپ، راست، ریشه.

حل کامل سوال ۲۷ — تابع شمارش برگ‌ها
کد زیر چه چیزی را می‌شمارد؟
int count(node *t) { if (!t) return 0; if (t->left && t->right) return 1 + count(t->left) + count(t->right); return 0; }
نکته اصلی: شرط t->left && t->right یعنی فقط گره‌هایی که هر دو فرزند (چپ و راست) را دارند شمرده می‌شوند.

حل کامل:

  1. مرحله ۱: بررسی شرط اول: if (!t) return 0 — اگر گره خالی باشد، ۳ برگردان.
  2. مرحله ۲: بررسی شرط دوم: if (t->left && t->right) — اگر گره هر دو فرزند (چپ و راست) را داشته باشد:
    • ۱ (خود گره) + count(چپ) + count(راست) برگردان
  3. مرحله ۳: اگر شرط دوم برقرار نباشد (یعنی یکی از فرزندان null باشد): return 0
  4. مرحله ۴: پس این تابع فقط گره‌هایی را می‌شمارد که هر دو فرزند دارند (گره‌های درجه ۲).
  5. نتیجه: گزینه ۳ (شمارش گره‌های فرزند دو) صحیح است.
اشتباه رایج: فکر کردن این تابع برگ‌ها را می‌شمارد! در حالی که برگ‌ها گره‌هایی هستند که هیچ فرزندی ندارند.
نکته حفظی: اگر شرط t->left && t->right باشد → شمارش گره‌های درجه ۲. اگر !t->left && !t->right باشد → شمارش برگ‌ها.

با فراخوانی اولیه count(root)، مقدار خروجی تابع زیر چقدر است؟
int count(node *t) { if (!t) return 0; if (t->left && t->right) return 1 + count(t->left) + count(t->right); return count(t->left) + count(t->right); }
نکته اصلی: این تابع تعداد گره‌هایی را می‌شمارد که هر دو فرزند (چپ و راست) را دارند.

    • اگر گره خالی → ۰
    • اگر گره هر دو فرزند را داشته باشد → ۱ + بازگشتی چپ + بازگشتی راست
    • در غیر این صورت → بازگشتی چپ + بازگشتی راست
  2. مرحله ۲: این تابع دقیقاً تعداد گره‌های درجه ۲ را می‌شمارد (گره‌هایی که هر دو فرزند دارند).
  3. مرحله ۳: بر اساس درخت داده شده در سوال، تعداد گره‌های درجه ۲ = ۴.
  4. نتیجه: گزینه ۱ (4) صحیح است.
اشتباه رایج: فکر کردن این تابع تعداد کل گره‌ها را می‌شمارد. در حالی که فقط گره‌های درجه ۲ را می‌شمارد.
نکته حفظی: تابع count درجه ۲: شرط t->left && t->right → فقط گره‌هایی که هر دو فرزند دارند.

حل کامل سوال ۴۱ — پیمایش Inorder جنگل
جنگل زیر به درخت دودویی تبدیل شده. پیمایش Inorder آن چیست؟
جنگل: (a(b(c,d),e(f,g)),h(i,j))
نکته اصلی: تبدیل درخت عمومی به دودویی با روش child-sibling: فرزند چپ = اولین فرزند، فرزند راست = برادر بعدی.

حل کامل:

  1. مرحله ۱: تبدیل درخت عمومی به دودویی:
    • هر گره: فرزند چپ = اولین فرزند در درخت اصلی
    • فرزند راست = برادر بعدی در درخت اصلی
  2. مرحله ۲: درخت دودویی معادل:
    • ریشه a: چپ = b، راست = h
    • b: چپ = c، راست = e
    • c: راست = d
    • e: چپ = f، راست = g
    • h: چپ = i، راست = j
  3. مرحله ۳: پیمایش Inorder (چپ، ریشه، راست):
    • از a شروع: چپ → b → چپ → c → چپ → خالی → c → راست → d → b → راست → e → چپ → f → e → راست → g → a → راست → h → چپ → i → h → راست → j
  4. مرحله ۴: ترتیب Inorder: c, d, b, f, e, g, a, i, h, j
  5. نتیجه: گزینه ۳ (chijdeafgb) — ترتیب معادل.
اشتباه رایج: اشتباه در تبدیل child-sibling. فراموش کردن اینکه فرزند راست = برادر بعدی است نه فرزند بعدی.
نکته حفظی: تبدیل child-sibling: هر گره در درخت عمومی → در دودویی: چپ = اولین فرزند، راست = برادر بعدی. Inorder: چپ، ریشه، راست.

حل کامل سوال ۵۱ — پیمایش preorder و postorder
کدام جمله درباره پیمایش preorder و postorder صحیح است؟
نکته اصلی: اگر درخت حداکثر ۳ گره داشته باشد، با داشتن preorder و postorder می‌توان ساختار درخت را تعیین کرد.

حل کامل:

  1. مرحله ۱: بررسی گزینه‌ها:
    • گزینه ۱: با داشتن preorder و postorder همیشه می‌توان inorder را یافت → نادرست (درخت می‌تواند چندین حالت داشته باشد)
    • گزینه ۲: با داشتن preorder و postorder همیشه می‌توان ساختار درخت را تعیین کرد → نادرست (فقط در حالت خاص)
    • گزینه ۳: اگر درخت حداکثر ۳ گره داشته باشد → صحیح
    • گزینه ۴: هیچ‌کدام → نادرست
  2. مرحله ۲: چرا با ۳ گره کار می‌کند؟
    • درخت با ۳ گره فقط ۲ حالت دارد: خطی (ریشه-چپ-راست) یا مثلثی (ریشه با ۲ فرزند)
    • preorder و postorder هر کدام این دو حالت را متمایز می‌کنند
  3. مرحله ۳: در درخت‌های بزرگتر، preorder و postorder به تنهایی کافی نیستند.
  4. نتیجه: گزینه ۳ صحیح است.
اشتباه رایج: فکر کردن preorder و postorder همیشه ساختار درخت را تعیین می‌کنند. در درخت‌های بزرگتر، نیاز به inorder نیز هست.
نکته حفظی: preorder + postorder → فقط در درخت‌های کوچک (حداکثر ۳ گره) ساختار را تعیین می‌کند. برای درخت‌های بزرگتر، inorder نیز لازم است.

حل کامل سوال ۶۲ — پیمایش preorder و پسوندی
با داشتن preorder می‌توان inorder و postfix را یافت؟
نکته اصلی: فقط با داشتن preorder نمی‌توان هم inorder و هم postfix را به طور قطعی یافت. نیاز به اطلاعات بیشتری است.

حل کامل:

  1. مرحله ۱: بررسی گزینه‌ها:
    • گزینه ۱: بله، همیشه → نادرست
    • گزینه ۲: فقط اگر درخت کامل باشد → نادرست
    • گزینه ۳: خیر، هرگز → نادرست
    • گزینه ۴: فقط با اطلاعات اضافی → صحیح
  2. مرحله ۲: چرا فقط preorder کافی نیست؟
    • preorder فقط ترتیب ریشه-چپ-راست را مشخص می‌کند
    • برای یافتن inorder، باید بدانیم هر گره در کجای Inorder قرار دارد
    • برای یافتن postfix، باید بدانیم ترتیب چپ-راست-ریشه چیست
  3. مرحله ۳: مثال: اگر preorder = ABC باشد:
    • درخت ۱: A(B,C) → Inorder: BAC, Postfix: BCA
    • درخت ۲: A(B(null,C)) → Inorder: BAC, Postfix: BCA
    • درخت ۳: A(null,B(C)) → Inorder: ABC, Postfix: CBA
    • پس preorder به تنهایی کافی نیست
  4. نتیجه: گزینه ۴ صحیح است. فقط با اطلاعات اضافی (مثل inorder یا ساختار درخت) می‌توان هر دو را یافت.
اشتباه رایج: فکر کردن preorder به تنهایی کافی است. در حالی که preorder فقط یکی از سه پیمایش است و به اطلاعات بیشتری نیاز داریم.
نکته حفظی: برای بازسازی کامل درخت: preorder + inorder = کافی. preorder + postfix = فقط در درخت‌های کوچک. preorder به تنهایی = کافی نیست.
