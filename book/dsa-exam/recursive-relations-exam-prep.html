حل کامل سوال ۸ (چهارگزینه‌ای)
دنباله T با معادله بازگشتی زیر تعریف شده است: T(n) = T(√n) + 1, T(2) = 1
کدام یک از موارد زیر برای T(n) درست است؟
1) T(n) ∈ θ(log log n)
2) T(n) ∈ θ(log n · log log n)
3) T(n) ∈ θ(n · log log n)
4) T(n) ∈ θ(n · log n · log log n)
نکته اصلی: وقتی T(√n) می‌بینید، با تغییر متغیر n=2^m مشکل حل می‌شود.

حل کامل:

  1. طرفین رابطه را به توان ۲ می‌رسانیم: T(2^m) = T(2^(m/2)) + 1
  2. تعریف می‌کنیم a(m) = T(2^m)
  3. پس a(m) = a(m/2) + 1
  4. طبق قاضی Master: a=1, b=2, f(m)=1 → θ(log m)
  5. چون m = lg n پس T(n) = θ(log log n)
اشتباه رایج: بسیاری T(√n) را مستقیماً با قاضی Master حل می‌کنند که نادرست است.
نکته حفظی: T(√n) → تغییر متغیر n=2^m → a(m)=T(2^m)

حل کامل سوال ۲۰ (چهارگزینه‌ای)
کدام یک از شرایط زیر برای مقادیر صحیح و مثبت a₁ تا aₖ تضمین می‌کند که θ(n) حل رابطه بازگشتی T(n) = ΣaᵢT(n/bᵢ) + θ(n) است؟
1) Σaᵢ/bᵢ = 1
2) Σaᵢ/bᵢ > 1
3) Σaᵢ/bᵢ < 1
4) Σaᵢ/bᵢ < 1
نکته اصلی: شرط حل θ(n) برابر Σaᵢ/bᵢ < 1 است.

حل کامل:

  1. طبق قاضی Master برای رابطه T(n) = aT(n/b) + f(n):
  2. اگر f(n) از n^(log_b a) رشد بیشتری داشته باشد → T(n) = θ(f(n))
  3. اینجا f(n) = θ(n) و n^(log_b a) باید کوچکتر از n باشد
  4. پس log_b a < 1 یعنی a/b < 1
  5. برای حالت کلی: Σaᵢ/bᵢ < 1
اشتباه رایج: بسیاری Σaᵢ/bᵢ = 1 را انتخاب می‌کنند که در آن حالت جواب θ(n lg n) است.
نکته حفظی: Σaᵢ/bᵢ < 1 → θ(n) | Σaᵢ/bᵢ = 1 → θ(n lg n) | Σaᵢ/bᵢ > 1 → θ(n^(log_b a))

حل کامل سوال ۵ (چهارگزینه‌ای)
جواب فرمولی بازگشتی T(n) = 2T(n/2) + lg(n!) برابر است با:
1) θ(n²)
2) θ(n lg n)
3) θ(n² lg n)
4) θ(n² lg n)
نکته اصلی: lg(n!) با n·lg n هم رشد دارد.

حل کامل:

  1. می‌دانیم lg(n!) ≈ n·lg n (از قضیه Stirling)
  2. پس رابطه می‌شود: T(n) = 2T(n/2) + n·lg n
  3. طبق قاضی Master: a=2, b=2, f(n)=n·lg n
  4. log_b a = lg 2 = 1 پس n^(log_b a) = n
  5. چون f(n) = n·lg n از n رشد بیشتری دارد و condition 3 برقرار است
  6. پس T(n) = θ(n lg n)
اشتباه رایج: فراموش کردن اینکه lg(n!) ≈ n·lg n و تلاش برای حل مستقیم.
نکته حفظی: lg(n!) ≈ n·lg n و T(n) = aT(n/b) + n·lg n با k=1 از θ(n·lg^(k+1) n) است.
