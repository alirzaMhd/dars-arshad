حل کامل سوال ۸ (چهارگزینه‌ای)
دنباله T با معادله بازگشتی زیر تعریف شده است: T(n) = T(√n) + 1, T(2) = 1
کدام یک از موارد زیر برای T(n) درست است؟
1) T(n) ∈ θ(log log n)
2) T(n) ∈ θ(log n · log log n)
3) T(n) ∈ θ(n · log log n)
4) T(n) ∈ θ(n · log n · log log n)
نکته اصلی: وقتی T(√n) می‌بینید، با تغییر متغیر n=2^m مشکل حل می‌شود.

حل کامل:

  1. طرفین رابطه را به توان ۲ می‌رسانیم: T(2^m) = T(2^(m/2)) + 1
  2. تعریف می‌کنیم a(m) = T(2^m)
  3. پس a(m) = a(m/2) + 1
  4. طبق قاضی Master: a=1, b=2, f(m)=1 → θ(log m)
  5. چون m = lg n پس T(n) = θ(log log n)
اشتباه رایج: بسیاری T(√n) را مستقیماً با قاضی Master حل می‌کنند که نادرست است.
نکته حفظی: T(√n) → تغییر متغیر n=2^m → a(m)=T(2^m)
📝 Memo
حل کامل سوال ۲۰ (چهارگزینه‌ای)
کدام یک از شرایط زیر برای مقادیر صحیح و مثبت a₁ تا aₖ تضمین می‌کند که θ(n) حل رابطه بازگشتی T(n) = ΣaᵢT(n/bᵢ) + θ(n) است؟
1) Σaᵢ/bᵢ = 1
2) Σaᵢ/bᵢ > 1
3) Σaᵢ/bᵢ < 1
4) Σaᵢ/bᵢ < 1
نکته اصلی: شرط حل θ(n) برابر Σaᵢ/bᵢ < 1 است.

حل کامل:

  1. طبق قاضی Master برای رابطه T(n) = aT(n/b) + f(n):
  2. اگر f(n) از n^(log_b a) رشد بیشتری داشته باشد → T(n) = θ(f(n))
  3. اینجا f(n) = θ(n) و n^(log_b a) باید کوچکتر از n باشد
  4. پس log_b a < 1 یعنی a/b < 1
  5. برای حالت کلی: Σaᵢ/bᵢ < 1
اشتباه رایج: بسیاری Σaᵢ/bᵢ = 1 را انتخاب می‌کنند که در آن حالت جواب θ(n lg n) است.
نکته حفظی: Σaᵢ/bᵢ < 1 → θ(n) | Σaᵢ/bᵢ = 1 → θ(n lg n) | Σaᵢ/bᵢ > 1 → θ(n^(log_b a))

حل کامل سوال ۵ (چهارگزینه‌ای)
جواب فرمولی بازگشتی T(n) = 2T(n/2) + lg(n!) برابر است با:
1) θ(n²)
2) θ(n lg n)
3) θ(n² lg n)
4) θ(n² lg n)
نکته اصلی: lg(n!) با n·lg n هم رشد دارد.

حل کامل:

  1. می‌دانیم lg(n!) ≈ n·lg n (از قضیه Stirling)
  2. پس رابطه می‌شود: T(n) = 2T(n/2) + n·lg n
  3. طبق قاضی Master: a=2, b=2, f(n)=n·lg n
  4. log_b a = lg 2 = 1 پس n^(log_b a) = n
  5. چون f(n) = n·lg n از n رشد بیشتری دارد و condition 3 برقرار است
  6. پس T(n) = θ(n lg n)
اشتباه رایج: فراموش کردن اینکه lg(n!) ≈ n·lg n و تلاش برای حل مستقیم.
نکته حفظی: lg(n!) ≈ n·lg n و T(n) = aT(n/b) + n·lg n با k=1 از θ(n·lg^(k+1) n) است.

حل کامل سوال ۳۹ (چهارگزینه‌ای)
الگوریتم ضرب ماتریس استرسن (Strassen) تعداد جمع‌ها و تفریق‌ها در حالت عادی برابر است با:
1) T(n) = T(n/2) + 7n², T(1)=1
2) T(n) = nT(n/2) + 7n², T(1)=0
3) T(n) = 7T(n/2) + 18n², T(1)=0
4) T(n) = 7T(n/2) + 9n⁴, T(1)=1
نکته اصلی: استرسن ۷ فراخوانی بازگشتی و ۱۸ عمل جمع/تفریق انجام می‌دهد.

حل کامل:

  1. استرسن ماتریس n×n را به ۴ ماتریس n/2×n/2 تقسیم می‌کند
  2. بجای ۸ ضرب ماتریسی (روش عادی)، ۷ ضرب انجام می‌دهد
  3. تعداد جمع/تفریق‌ها ۱۸ عمل است (بیشتر از ۴ عمل روش عادی)
  4. پس T(n) = 7T(n/2) + 18n²
  5. برای n=1 (ماتریس ۱×۱) هیچ عملی نداریم پس T(1)=0
اشتباه رایج: اشتباه در به یاد آوردن اعداد ۷ و ۱۸ یا T(1).
نکته حفظی: استرسن: ۷ فراخوانی + ۱۸ جمع/تفریق | ضرب عادی: ۸ فراخوانی + ۴ جمع

حل کامل سوال ۴۰ (چهارگزینه‌ای)
اگر دو ماتریس 4×4 با روش ضرب استرسن در یکدیگر ضرب شوند، چند ضرب عددی صورت می‌گیرد؟
1) 28
2) 49
3) 7
4) 11
نکته اصلی: برای ماتریس 4×4: T(4) = 7×T(2) = 7×7 = 49

حل کامل:

  1. تعداد ضرب‌های عددی: T(n) = 7T(n/2) و T(1) = 1
  2. برای ماتریس 2×2: T(2) = 7×T(1) = 7×1 = 7
  3. برای ماتریس 4×4: T(4) = 7×T(2) = 7×7 = 49
  4. پس ۴۹ ضرب عددی انجام می‌شود
اشتباه رایج: محاسبه T(4) = 7×T(2) = 7×8 = 56 یا ۳۴۳ = 7³
نکته حفظی: T(2^k) = 7^k برای ضرب عددی استرسن

حل کامل سوال ۶۴ (چهارگزینه‌ای)
در مسئله ژوزفوس n نفر با شماره‌های ۱ تا n به صورت ساعت گرد دور یک میز نشسته‌اند. f(n) شماره فرد زنده آخر است. مثال: f(9)=3. کدام رابطه بازگشتی درست است؟
1) f(2n) = 2f(n) - 2, f(2n+1) = 2f(n) - 1
2) f(2n) = 2f(n) + 2, f(2n+1) = 2f(n) + 1
3) f(2n) = 2f(n) - 1, f(2n+1) = 2f(n) + 1
4) f(2n) = 2f(n) - 1, f(2n+1) = 2f(n) - 2
نکته اصلی: روابط ژوزفوس: f(2n) = 2f(n) - 1 و f(2n+1) = 2f(n) + 1

حل کامل:

  1. برای n=9: f(9) = 3 (از صورت سوال)
  2. آزمایش گزینه ۳: f(2×4+1) = f(9) = 2f(4) + 1
  3. f(4) = 2f(2) - 1 = 2(2×1-1) - 1 = 2(1) - 1 = 1
  4. f(9) = 2(1) + 1 = 3 ✓
  5. پس گزینه ۳ صحیح است
اشتباه رایج: اشتباه در علائم + و - در روابط بازگشتی.
نکته حفظی: f(2n) = 2f(n) - 1 | f(2n+1) = 2f(n) + 1

حل کامل سوال ۴ (چهارگزینه‌ای)
در مورد رابطه بازگشتی T(n) = T(n/4) + 1, T(2) = 1 کدام گزینه صحیح است؟
1) T(n) = (4/3)lg n - (1/3)
2) T(n) = (4/3)n - (4/3)
3) T(n) = (4/3)lg n - (1/3)
4) T(n) = (4/3)n - (4/3)
نکته اصلی: وقتی گزینه‌ها فرمول دقیق دارند، با n=2 آزمایش کنید.

حل کامل:

  1. از صورت سوال T(2) = 1
  2. گزینه ۱: T(2) = (4/3)lg(2) - 1/3 = 4/3 - 1/3 = 1 ✓
  3. گزینه ۲: T(2) = (4/3)(2) - 4/3 = 8/3 - 4/3 = 4/3 ≠ 1 ✗
  4. گزینه ۳: مشابه گزینه ۱
  5. گزینه ۴: مشابه گزینه ۲
  6. پس گزینه ۳ صحیح است
اشتباه رایج: حل دقیق رابطه بازگشتی به جای آزمایش سریع با مقادیر خاص.
نکته حفظی: در تست‌ها، آزمایش با مقادیر کوچک سریع‌ترین راه است.
