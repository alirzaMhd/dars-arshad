BINARY SEARCH TREE (BST)

Data Structures — Complete Guide for 20/20 Exam

BST Definition

A Binary Search Tree is a binary tree where each node contains a key and satisfies the BST property:

BST Property (for every node x):
key[x] >= keys in left subtree(x) AND key[x] < keys in right subtree(x)
Left subtree keys ≤ node key; Right subtree keys > node key

Node Structure

Node {
  key      // satellite data / value
  left    // pointer to left child
  right   // pointer to right child
  p      // pointer to parent
}

Inorder Traversal Property

An inorder traversal of a BST visits nodes in non-decreasing sorted order.

INORDER-TREE-WALK(x):
  if x != NIL:
    INORDER-TREE-WALK(left[x])
    print key[x]
    INORDER-TREE-WALK(right[x])
WARNING: If you modify a BST (insert/delete), the inorder property may break. Always verify BST property holds after any modification.

Key Properties

Inorder Output

Inorder traversal of BST yields sorted keys

Height Dependency

Height h can range from lg(n) to n-1

No duplicate keys

All keys in left subtree ≤ node; all keys in right > node

TREE_SEARCH

Searches for a key k starting from root x. Compares k with key[x] at each step.

TREE-SEARCH(x, k):
  if x == NIL or k == key[x]:
    return x
  if k < key[x]:
    return TREE-SEARCH(left[x], k)
  else:
    return TREE-SEARCH(right[x], k)
Time Complexity:
O(h) where h = height of tree
Worst case O(n) for skewed tree, best case O(lg n) for balanced tree

TREE_MIN and TREE_MAX

MIN

TREE-MIN(x):
  while left[x] != NIL:
    x = left[x]
  return x

Follow left pointers until no more left child

MAX

TREE-MAX(x):
  while right[x] != NIL:
    x = right[x]
  return x

Follow right pointers until no more right child

Complexity:
O(h) time, O(1) space (iterative)

TREE_SUCCESSOR

Returns the node with the next larger key (inorder successor) of node x.

TREE-SUCCESSOR(x):
  if right[x] != NIL:
    return TREE-MIN(right[x])  // min of right subtree
  y = p[x]
  while y != NIL and x == right[y]:
    x = y
    y = p[y]
  return y

Two Cases

Case 1: Right subtree exists

Successor = minimum of right subtree

Case 2: No right subtree

Walk up parent pointers until you come from a left child

WARNING: TREE_SUCCESSOR and TREE_PREDECESSOR are inverses. If you need predecessor instead, swap left/right in the algorithm.

TREE_INSERT

Inserts a new node z with key[z] into BST rooted at T.

TREE-INSERT(T, z):
  y = NIL
  x = T.root
  while x != NIL:
    y = x
    if key[z] < key[x]:
      x = left[x]
    else:
      x = right[x]
  p[z] = y
  if y == NIL:
    T.root = z  // tree was empty
  elif key[z] < key[y]:
    left[y] = z
  else:
    right[y] = z
Insert Complexity:
O(h) time — same as search
Only traverses one path from root to leaf

TREE_DELETE

Removes node z from BST. Three cases based on number of children.

TRANSPLANT(T, u, v):
  if p[u] == NIL:
    T.root = v
  elif u == left[p[u]]:
    left[p[u]] = v
  else:
    right[p[u]] = v
  if v != NIL:
    p[v] = p[u]
TREE-DELETE(T, z):
  if left[z] == NIL:
    TRANSPLANT(T, z, right[z])
  elif right[z] == NIL:
    TRANSPLANT(T, z, left[z])
  else:
    y = TREE-MIN(right[z])  // successor
    if p[y] != z:
      TRANSPLANT(T, y, right[y])
      right[y] = right[z]
      p[right[y]] = y
    TRANSPLANT(T, z, y)
    left[y] = left[z]
    p[left[y]] = y

Three Delete Cases

Case 1: No child

Simply remove (set parent pointer to NIL)

Case 2: One child

Transplant with that child

Case 3: Two children

Replace with successor (min of right subtree), then delete successor

WARNING: In Case 3, if the successor is the immediate right child of z, we only transplant right child of successor. If successor is deeper, we first transplant successor's right child to replace successor, then replace z with successor.

Time & Space Complexity

Operation Average (Balanced) Worst (Skewed) Space
Search O(lg n) O(n) O(lg n) recursion
Insert O(lg n) O(n) O(1) iterative
Delete O(lg n) O(n) O(1) iterative
Min / Max O(lg n) O(n) O(1)
Successor O(lg n) O(n) O(1)
Inorder Walk O(n) O(n) O(lg n) recursion
WARNING: Height h is at most n-1 (skewed tree). For a balanced BST, h ≈ lg n. All single operations are O(h).

Catalan Number

The number of structurally distinct BSTs with n distinct keys is given by the nth Catalan number.

Catalan Number Formula:
C(n) = C(2n, n) / (n + 1) = (2n)! / ((n+1)! * n!)
C(n) = number of distinct BSTs with n keys

Recursive Definition

Recursive Catalan:
C(0) = 1, C(n) = Sum_{i=0}^{n-1} C(i) * C(n-1-i)
Pick each key as root; left subtree has i keys, right has n-1-i

Small Values

n012345
C(n)11251442
WARNING: C(3) = 5 means 5 distinct BSTs exist with 3 keys {1,2,3}. Don't confuse this with the number of nodes in a BST.

Example 1: Inorder Traversal

Problem: Build BST by inserting 15, 6, 18, 3, 7, 17, 20. Give inorder traversal.

Solution:

Insert 15: root = 15

Insert 6: 6 < 15, goes left of 15

Insert 18: 18 > 15, goes right of 15

Insert 3: 3 < 15, 3 < 6, goes left of 6

Insert 7: 7 < 15, 7 > 6, goes right of 6

Insert 17: 17 > 15, 17 < 18, goes left of 18

Insert 20: 20 > 15, 20 > 18, goes right of 18

Result: 3, 6, 7, 15, 17, 18, 20

Inorder always gives sorted order for BST.

Example 2: TREE_SEARCH

Problem: Search for key 7 in BST from Example 1.

Solution:

Start at root (15): 7 < 15, go left

At node 6: 7 > 6, go right

At node 7: 7 == 7, found!

Search path: 15 → 6 → 7 (3 comparisons)

Example 3: TREE_SUCCESSOR

Problem: Find successor of node 6 in BST from Example 1.

Solution:

Node 6 has right child 7 → Case 1 applies

Successor = TREE-MIN(right[6]) = TREE-MIN(7)

Node 7 has no left child, so minimum is 7 itself

Successor of 6 is 7

Successor = next node in inorder traversal

Example 4: TREE_DELETE (Two Children Case)

Problem: Delete node 15 (root with two children).

Solution:

15 has both left and children → Case 3

Find successor: TREE-MIN(right[15]) = TREE-MIN(17) = 17

Since 17's parent is 18 (not 15), we need to transplant 17 first

TRANSPLANT(17, right[17]) = TRANSPLANT(17, NIL)

Then TRANSPLANT(15, 17): replace 15 with 17 as root

Set left[17] = left[15] = 6, right[17] = right[15] = 18

New root is 17 with left=6, right=18

Example 5: Catalan Number

Problem: How many distinct BSTs with 4 keys?

Solution:

Using formula: C(4) = C(8,4) / 5

C(8,4) = 8! / (4! * 4!) = 70

C(4) = 70 / 5 = 14

Answer: 14 distinct BSTs
