Fibonacci Heap Structure

A Fibonacci heap is a collection of min-heap-ordered trees stored in a circular doubly-linked root list.

Core Properties

1. Collection of min-heap-ordered trees (not necessarily binomial)

2. Trees are rooted and unordered (children can be in any order)

3. Root list is a circular doubly-linked list

4. Each node has: key, degree, mark, parent, child, left, right

Node Fields

• key: priority value

• degree: number of children

• mark: has this node lost a child? (boolean)

• parent, child: tree pointers

• left, right: circular doubly-linked list pointers

Fibonacci Number Connection

F(0) = 0, F(1) = 1, F(k) = F(k-1) + F(k-2)

If a node has degree k, it has at least F(k+2) ≥ φ^k nodes (φ ≈ 1.618)

This bounds maximum degree to O(lg n)

Amortized Costs

INSERT: O(1) | FIND-MIN: O(1) | UNION: O(1) EXTRACT-MIN: O(lg n) | DECREASE-KEY: O(1) | DELETE: O(lg n)
