Fibonacci with Dynamic Programming

Problem Definition

The Fibonacci sequence is defined by the recurrence:

Fibonacci Recurrence
F(n) = F(n-1) + F(n-2),   F(0) = 0,   F(1) = 1
The n-th Fibonacci number is the sum of the two preceding numbers.

Naive Recursive Algorithm

function fibRecursive(n): if n == 0: return 0 if n == 1: return 1 return fibRecursive(n-1) + fibRecursive(n-2)

Time Complexity Analysis

Recurrence for Recursive Fibonacci
T(n) = T(n-1) + T(n-2) + 1
This recurrence solves to O(φⁿ) where φ = (1+√5)/2 ≈ 1.618 (the golden ratio)
Call Tree for fibRecursive(5)

fibRecursive(5) calls fibRecursive(4) and fibRecursive(3). Each of those calls makes two more calls, creating an exponential explosion.

Total calls: 15 function calls for n=5

For n=10: 177 calls

For n=30: ~2.69 million calls

For n=50: ~40 billion calls (impractical!)

Warning: Recursive Fibonacci recalculates the same subproblems exponentially! F(3) is computed multiple times independently. This is the quintessential example of why DP is needed.

Complexity

Time: O(φⁿ)

Space: O(n) call stack

Recursive calls: 2F(n+1) - 1

Golden Ratio

φ = (1+√5)/2 ≈ 1.618

F(n) ≈ φⁿ/√5

Growth is exponential

DP Fibonacci — Bottom-Up with Array

The DP approach stores computed values in an array, computing each Fibonacci number exactly once.

Algorithm: DP with Array (O(n) time, O(n) space)

function fibDP(n): if n == 0: return 0 if n == 1: return 1 dp = array of size n+1 dp[0] = 0 dp[1] = 1 for i = 2 to n: dp[i] = dp[i-1] + dp[i-2] return dp[n]
DP Table Fill
dp[i] = dp[i-1] + dp[i-2]   for i = 2, 3, ..., n
Each dp[i] is computed once in O(1) time using previously stored values.

Algorithm: Space-Optimized (O(n) time, O(1) space)

We only need the last two values, not the entire array.

function fibConstSpace(n): if n == 0: return 0 if n == 1: return 1 prev2 = 0 prev1 = 1 for i = 2 to n: curr = prev1 + prev2 prev2 = prev1 prev1 = curr return curr
Space Optimization
F(n) only requires F(n-1) and F(n-2) → O(1) extra space
Since the recurrence only depends on the two previous values, we don't need to store the whole array.

Performance Gain: DP transforms an O(φⁿ) exponential algorithm into O(n) linear time — an astronomical improvement for large n.

Top-Down (Memoization)

function fibMemo(n, memo): if n == 0: return 0 if n == 1: return 1 if memo[n] != -1: return memo[n] memo[n] = fibMemo(n-1, memo) + fibMemo(n-2, memo) return memo[n]

Matrix Exponentiation

F(n) can be computed in O(log n) using:

[F(n+1) F(n); F(n) F(n-1)] = [[1,1],[1,0]]ⁿ

See Challenge Example.

Example 4: Challenge — Matrix Exponentiation (F(n) in O(log n))

Concept: The Fibonacci recurrence can be expressed as a matrix power:

Matrix Form
[F(n+1), F(n); F(n), F(n-1)] = [1, 1; 1, 0]ⁿ
Computing the n-th power using exponentiation by squaring yields O(log n) time.
function fibMatrix(n): if n == 0: return 0 base = [[1, 1], [1, 0]] result = matrixPow(base, n-1) return result[0][0] // F(n) function matrixPow(M, k): if k == 0: return identity matrix if k == 1: return M if k is even: half = matrixPow(M, k/2) return half * half else: return M * matrixPow(M, k-1)

Example: Compute F(10) using matrix exponentiation

[[1,1],[1,0]]⁹ → compute via squaring (only 4 multiplications instead of 9)

Time: O(log n), Space: O(log n) for recursion stack

Note: This is not strictly DP, but an advanced technique for linear recurrences.
