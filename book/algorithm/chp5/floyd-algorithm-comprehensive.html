All-Pairs Shortest Paths

Given a directed weighted graph G = (V, E) with n vertices, find the shortest path between every pair of vertices (i, j). The graph is represented by a cost matrix C where C[i,j] = weight of edge (i→j), with C[i,i] = 0 and C[i,j] = ∞ if no edge exists.

Cost Matrix Initialization
C[i,j] = weight(i,j)   if i ≠ j and (i,j) ∈ E
C[i,i] = 0
C[i,j] = ∞   if i ≠ j and (i,j) ∉ E
A⁰[i,j] = C[i,j] is the starting matrix (no intermediate vertices allowed).

Graph Representation

Floyd's algorithm uses a sequence of matrices A⁰, A¹, A², ..., Aⁿ where A^k[i,j] is the length of the shortest path from i to j using only vertices from {1, 2, ..., k} as intermediate vertices.

A⁰ Matrix

Direct edges only

No intermediate vertices

Initial cost matrix C

Aⁿ Matrix

All vertices allowed

Final shortest paths

All-pairs distances

Warning: Floyd's algorithm requires that the graph has no negative cycles. If Aⁿ[i,i] < 0 for any i, a negative cycle exists and shortest paths are undefined (unbounded below).

The DP Recurrence

Let A^k[i,j] denote the shortest path from i to j using only vertices from {1, 2, ..., k} as intermediate vertices.

Base Case (k=0)
A⁰[i,j] = C[i,j]
Direct edges only, no intermediate vertices allowed.
DP Recurrence
A^k[i,j] = min( A^{k-1}[i,j], A^{k-1}[i,k] + A^{k-1}[k,j] )
Either the shortest path using vertices {1,...,k-1} stays optimal, or going through vertex k gives a shorter path.

Floyd's Algorithm

function floyd(C, n): // C = n×n cost matrix A = C // A⁰ = C for k = 1 to n: for i = 1 to n: for j = 1 to n: if A[i][k] + A[k][j] < A[i][j]: A[i][j] = A[i][k] + A[k][j] return A // Aⁿ = all-pairs shortest paths

Path Reconstruction with P Matrix

We maintain a P matrix that stores the predecessor information for path reconstruction.

function floydWithPath(C, n): A = C // distance matrix P = n×n matrix initialized to 0 // Initialize P: P[i][j] = j if edge exists for i = 1 to n: for j = 1 to n: if C[i][j] != INF and C[i][j] != 0: P[i][j] = j for k = 1 to n: for i = 1 to n: for j = 1 to n: if A[i][k] + A[k][j] < A[i][j]: A[i][j] = A[i][k] + A[k][j] P[i][j] = P[i][k] // path goes through k return (A, P) function path(i, j, P): if P[i][j] == 0: return "No path" pathSeq = [i] while i != j: i = P[i][j] pathSeq.append(i) return pathSeq

Negative Cycle Detection

Negative Cycle Condition
If Aⁿ[i,i] < 0   for any i in {1,...,n}
A negative cycle exists — shortest paths are undefined (can go infinitely negative).
Important: In Floyd's algorithm, we can perform the update in-place (overwriting A^{k-1} with A^k). This works because the recurrence uses A^{k-1}[i,k] and A^{k-1}[k,j] which are not modified during iteration k.

Correctness

Invariant: After k iterations, A[i][j] contains the shortest path using vertices {1,...,k}.

Proof by induction on k.

Complexity

Time: O(n³)

Space: O(n²)

Suitable for dense graphs

Critical: If Aⁿ[i,i] < 0 for any i, the graph contains a negative cycle reachable from i. In this case, Floyd's algorithm still produces a result, but it is meaningless — path costs can be arbitrarily negative.

• Aⁿ = all-pairs shortest paths

• Invariant: A^k uses vertices 1..k

• In-place update is safe

Applications

• Network routing tables

• Social network analysis

• Graph diameter computation

• Transitive closure

• Negative cycle detection

Note: Floyd's algorithm only works correctly in directed graphs with no negative cycles. In undirected graphs, an edge with negative weight immediately creates a negative cycle (u→v→u). Use Bellman-Ford or Johnson's algorithm for such cases.

Matrix Multiplication Method for All-Pairs Shortest Paths

An alternative DP approach uses a different recurrence. Let Lᵏ[i,j] be the shortest path from i to j using at most k edges. This resembles matrix multiplication with (min, +) operations instead of (+, ×).

Recurrence (at most k edges):
Lᵏ[i,j] = min{Lᵏ⁻¹[i,j], Lᵏ⁻¹[i,t] + w(t,j)} for 1 ≤ t ≤ n
L¹ = C (cost matrix). Compute L², L³, ... up to Lⁿ⁻¹. Complexity: O(n⁴).
Repeated Squaring (Accelerated):
L²ᵏ[i,j] = min{Lᵏ[i,t] + Lᵏ[t,j]} for 1 ≤ t ≤ n
Compute L¹, L², L⁴, L⁸, ... up to Lⁿ⁻¹. Complexity: O(n³ log n).

Algorithm Steps

L = C // L¹ = cost matrix for step = 1 to ⌈log₂(n-1)⌉: L' = ∞ matrix of size n×n for i = 1 to n: for j = 1 to n: L'[i,j] = min(L[i,t] + L[t,j]) for 1≤t≤n L = L' return L // Lⁿ⁻¹ = all-pairs shortest paths
