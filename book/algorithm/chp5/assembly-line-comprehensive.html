Assembly Line Scheduling Problem

A car factory has two assembly lines, each with n stations. A chassis enters one of the two lines, goes through all n stations (in order), and exits. The goal is to find the fastest route through the factory.

Components

  • Two lines: Line 1 and Line 2, each with n stations (S1,1, S1,2, ..., S1,n and S2,1, S2,2, ..., S2,n)
  • Entry costs: e1 (enter line 1), e2 (enter line 2)
  • Station costs: a1,j (station j on line 1), a2,j (station j on line 2)
  • Transfer costs: t1,j (transfer from line 1 to line 2 after station j), t2,j (transfer from line 2 to line 1 after station j)
  • Exit costs: x1 (exit from line 1), x2 (exit from line 2)
Objective:
Minimize total time from entry to exit through the factory
At each station, the chassis can either stay on the same line or transfer to the other line (with additional cost)
Warning: Transfers between lines have additional costs — don't forget to include them! Forgetting ti,j-1 when computing fi[j] is a common mistake.

Input Parameters

• n: number of stations per line

• e1, e2: entry costs

• ai,j: station costs

• ti,j: transfer costs

• x1, x2: exit costs

Key Property

Optimal substructure: the fastest way through station j depends only on the fastest ways through station j-1 on both lines.

Dynamic Programming Solution

Recurrence Relations

Let f1[j] = fastest time to reach station j on line 1,
f2[j] = fastest time to reach station j on line 2.

Base Cases (j = 1):
f1[1] = e1 + a1,1
f2[1] = e2 + a2,1
Entry cost + first station cost on each line
Recurrence for j ≥ 2:
f1[j] = min(f1[j-1] + a1,j, f2[j-1] + t2,j-1 + a1,j)

f2[j] = min(f2[j-1] + a2,j, f1[j-1] + t1,j-1 + a2,j)
Stay on same line (no transfer) vs. transfer from other line
Final Answer:
f* = min(f1[n] + x1, f2[n] + x2)
Fastest time to complete all stations + exit cost

Path Tracking

Arrays L1[j] and L2[j] store which line was used to reach station j optimally:

  • L1[j] = 1 if the optimal path to S1,j came from line 1, or 2 if from line 2
  • L2[j] = 1 or 2 indicating the source line for the optimal path to S2,j

Algorithm: FASTEST-WAY

FASTEST-WAY(a, t, e, x, n):
  f1[1] = e1 + a1,1
  f2[1] = e2 + a2,1
  for j = 2 to n:
    if f1[j-1] + a1,j ≤ f2[j-1] + t2,j-1 + a1,j:
      f1[j] = f1[j-1] + a1,j; L1[j] = 1
    else:
      f1[j] = f2[j-1] + t2,j-1 + a1,j; L1[j] = 2
    if f2[j-1] + a2,j ≤ f1[j-1] + t1,j-1 + a2,j:
      f2[j] = f2[j-1] + a2,j; L2[j] = 2
    else:
      f2[j] = f1[j-1] + t1,j-1 + a2,j; L2[j] = 1
  if f1[n] + x1 ≤ f2[n] + x2:
    f* = f1[n] + x1; L* = 1
  else:
    f* = f2[n] + x2; L* = 2

Algorithm: PRINT-STATIONS

PRINT-STATIONS(L, L*, n):
  i = L*
  print "Line " i ", Station " n
  for j = n down to 2:
    i = Li[j]
    print "Line " i ", Station " j-1
Complexity:
FASTEST-WAY: O(n), Space: O(n)
PRINT-STATIONS: O(n)
Linear time — both algorithms process n stations once

Exam Tip: Common pitfalls:
• Forgetting transfer costs ti,j-1 in recurrence
• Using ti,j instead of ti,j-1 (transfer happens AFTER station j-1)
• Not adding exit costs x1 or x2 in final answer
• Misreading L arrays during path reconstruction

Space Optimization Exercise

Current Space Usage:
f₁[1..n], f₂[1..n], L₁[2..n], L₂[2..n] = 4n - 2 cells
Two arrays of size n for f-values, two arrays of size n-1 for L-values.
Textbook Exercise (Page 413): The tables Lⱼ[i] and fⱼ[i] together contain 4n - 2 cells. Show how to reduce the space to 2n + 2 cells while still being able to compute f* and print the optimal path.
Solution Approach

Key observation: To compute f₁[j] and f₂[j], we only need f₁[j-1] and f₂[j-1]. We don't need the full arrays!

Reduction plan:

1. Keep only 2 variables for current f₁ and f₂ (instead of arrays of size n)

2. However, to reconstruct the path, we still need L arrays

3. Instead of L₁[2..n] and L₂[2..n] (2n-2 cells), keep a single decision array D[2..n] (n-1 cells) where D[j] = line number after station j

4. Then we only need: f₁ (scalar), f₂ (scalar), L* (scalar), decision[n]

New space: f* (1) + f_current (2) + D[2..n] (n-1) + L* (1) = n + 3 cells (which is ≤ 2n + 2 for n ≥ 1)

Before Optimization

f₁[n]: n cells

f₂[n]: n cells

L₁[2..n]: n-1 cells

L₂[2..n]: n-1 cells

Total: 4n - 2

After Optimization

f*: 1 cell

f_current[2]: 2 cells

D[2..n]: n-1 cells

L*: 1 cell

Total: n + 3 ≤ 2n + 2
