World Series (Tournament) Problem

Two teams, A and B, are playing a series of games. Team A needs i more wins to win the championship, and team B needs j more wins. Each game is independent with a fixed probability p that team A wins and q = 1-p that team B wins. What is the probability that team A eventually wins the championship?

Problem Parameters:
i = number of wins A still needs
j = number of wins B still needs
p = probability A wins any single game
q = 1 - p = probability B wins any single game
Goal: Find P(i,j) = probability A wins the series from state (i,j)
Boundary Conditions:
P(0,j) = 1   for j ≥ 1   (A already has enough wins)
P(i,0) = 0   for i ≥ 1   (B already has enough wins)
P(0,0) = undefined (series already over)
Answer is P(n,n) for a "best-of-(2n-1)" series where n wins are needed

Real-World Analogy

This models any best-of series where two opponents compete until one reaches a target number of wins:

  • World Series (best-of-7, n=4)
  • NBA Finals (best-of-7, n=4)
  • Any tournament final series

Series Formats

• Best-of-5: n=3 (first to 3 wins)

• Best-of-7: n=4 (first to 4 wins)

• Best-of-9: n=5 (first to 5 wins)

Key Assumptions

• Games are independent

• p is fixed for all games

• No draws or ties

Warning: This model only works when each game is independent with a fixed probability p! In real sports, factors like home-field advantage, player injuries, and momentum invalidate this assumption. Use this model only when the independence assumption holds.

Dynamic Programming Solution

Recurrence Relation

From state (i,j) where A needs i wins and B needs j wins, A can win the next game (probability p) moving to state (i-1,j), or lose (probability q) moving to state (i,j-1).

Recurrence (for i, j ≥ 1):
P(i,j) = p × P(i-1,j) + q × P(i,j-1)
p × P(i-1,j): A wins this game, needs 1 fewer win
q × P(i,j-1): A loses this game, B needs 1 fewer win
Boundary Conditions:
P(0,j) = 1   (A wins the series)
P(i,0) = 0   (B wins the series)
P(0,0) is undefined
For all i ≥ 1 and j ≥ 1

Algorithm: World Series DP

WORLD-SERIES(n, p):
  // n = wins needed to win the series
  // p = probability A wins a single game
  let P[0..n][0..n] be 2D array
  q = 1 - p
  for i = 0 to n:
    P[i][0] = 0
  for j = 0 to n:
    P[0][j] = 1
  for i = 1 to n:
    for j = 1 to n:
      P[i][j] = p * P[i-1][j] + q * P[i][j-1]
  return P[n][n]

Space-Optimized Version

Since P(i,j) only depends on P(i-1,j) and P(i,j-1), we can use a 1D array of size n+1.

WORLD-SERIES-1D(n, p):
  let P[0..n] be 1D array
  q = 1 - p
  P[0] = 0  // P(i,0) = 0 for all i
  for i = 1 to n: P[i] = 1  // P(0,j) = 1 for all j
  for i = 1 to n:
    for j = 1 to n:
      P[j] = p * P[j] + q * P[j-1]
  return P[n]
Complexity:
Time: O(n²), Space: O(n) with 1D optimization
Standard version: O(n²) time, O(n²) space

Understanding the Calculation

The DP table is filled row by row (or column by column). Each cell P(i,j) represents the probability of A winning the series starting from needing i wins while B needs j wins.

Key insight: P(i,j) is a weighted average of P(i-1,j) and P(i,j-1), weighted by p and q respectively.

When p = 0.5 (equal teams), the probability simplifies to P(i,j) = i / (i+j). This can be verified by induction.

Exam Tip: Key observations:
• P(i,j) with p=0.5: P(i,i) = 0.5 for all i, and P(i,j) + P(j,i) = 1
• The DP is essentially computing a weighted sum over all possible game sequences
• For large n, the table grows as O(n²), but only half needs to be computed (by symmetry when p=0.5)
• The problem demonstrates optimal substructure: the probability from state (i,j) depends only on states one win away
• Memory optimization: since we only need the previous row, a 1D array suffices
