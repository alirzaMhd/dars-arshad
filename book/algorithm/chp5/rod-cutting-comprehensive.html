Rod Cutting Problem

Given a rod of length n inches and a price array p[i] for i = 1, 2, ..., n (where p[i] is the price of a rod of length i), determine the maximum revenue obtainable by cutting the rod and selling the pieces. You can make any number of cuts.

Problem:
Maximize revenue by cutting a rod of length n
Given price array p[1..n], find maximum revenue rn
Number of Possible Cuts:
2n-1 ways to cut a rod of length n
Each of the n-1 potential cut points can either be cut or not cut
Optimal Substructure (Recurrence):
rn = max1 ≤ i ≤ n (pi + rn-i)
with r0 = 0. Cut off a piece of length i, sell it, and optimally cut the rest.

Example Price Table

A typical price table (example):

Length i12345678
Price p[i]158910171720

Note: p[4] = 9, but 2+2 gives 5+5 = 10 > 9. So cutting can produce more revenue than selling the whole rod!

Input

• Rod length n

• Price array p[1..n]

Output

• Maximum revenue rn

• Cutting positions (via s array)

Three Approaches to Rod Cutting

1. Recursive (Divide & Conquer) — Exponential

Directly implements the recurrence rn = max(pi + rn-i) recursively.

RECURSIVE-CUT-ROD(p, n):
  if n == 0: return 0
  q = -∞
  for i = 1 to n:
    q = max(q, p[i] + RECURSIVE-CUT-ROD(p, n-i))
  return q
Complexity:
Time: O(2n), Space: O(n) (recursion stack)

2. Memoized (Top-Down DP) — O(n²)

Same recursive structure but caches results to avoid recomputation.

MEMOIZED-CUT-ROD(p, n):
  let r[0..n] = -∞
  return MEMOIZED-CUT(p, n, r)

MEMOIZED-CUT(p, n, r):
  if r[n] ≥ 0: return r[n]
  if n == 0: q = 0
  else:
    q = -∞
    for i = 1 to n:
      q = max(q, p[i] + MEMOIZED-CUT(p, n-i, r))
  r[n] = q
  return q
Complexity:
Time: O(n²), Space: O(n)

3. Bottom-Up DP — O(n²)

Iteratively solves subproblems from smallest to largest.

BOTTOM-UP-CUT-ROD(p, n):
  let r[0..n] = 0
  for j = 1 to n:
    q = -∞
    for i = 1 to j:
      q = max(q, p[i] + r[j-i])
    r[j] = q
  return r[n]
Complexity:
Time: O(n²), Space: O(n)

Extended Version with Cut Positions

Track which cut gives the optimal value using array s[1..n].

EXTENDED-BOTTOM-UP(p, n):
  let r[0..n] = 0, s[1..n] = 0
  for j = 1 to n:
    q = -∞
    for i = 1 to j:
      if q < p[i] + r[j-i]:
        q = p[i] + r[j-i]
        s[j] = i
    r[j] = q
  return r, s

PRINT-CUTS(s, n):
  while n > 0:
    print s[n]
    n = n - s[n]

Exam Tip: Key points:
• The recurrence rn = max(pi + rn-i) considers cutting off a piece of length i and optimally cutting the rest
• Bottom-up and memoized both achieve O(n²), but bottom-up avoids recursion overhead
• The s array stores the first cut position, enabling full reconstruction
• Number of ways to cut = 2n-1 (exponential), but DP finds the best in polynomial time
