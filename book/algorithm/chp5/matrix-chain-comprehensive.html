Matrix Multiplication Cost

Multiplying two matrices A (p × q) and B (q × r) costs p × q × r scalar multiplications and produces a (p × r) matrix.

Cost of One Matrix Multiplication
Cost(A × B) = p × q × r
Where A has dimensions p×q and B has dimensions q×r.

Why Parenthesization Matters

Matrix multiplication is associative: (A×B)×C = A×(B×C). However, the total number of scalar multiplications can differ vastly based on the parenthesization order.

Example: 3 Matrices Showing Why Order Matters

Given: A₁(10×30), A₂(30×5), A₃(5×60)

Option 1: (A₁ × A₂) × A₃

Step 1: A₁×A₂ → 10×30×5 = 1500 multiplications, result is 10×5

Step 2: (10×5)×A₃ → 10×5×60 = 3000 multiplications

Total: 1500 + 3000 = 4500

Option 2: A₁ × (A₂ × A₃)

Step 1: A₂×A₃ → 30×5×60 = 9000 multiplications, result is 30×60

Step 2: A₁×(30×60) → 10×30×60 = 18000 multiplications

Total: 9000 + 18000 = 27000

Best choice: (A₁×A₂)×A₃ with 4500 operations vs 27000 — a 6× improvement!

Optimal Substructure

The Matrix Chain Multiplication problem exhibits optimal substructure: to optimally parenthesize Aᵢ × Aᵢ₊₁ × ... × Aⱼ, we split at some k (i ≤ k < j), optimally parenthesize the left and right subchains, and combine.

Warning: The number of ways to parenthesize n matrices follows the Catalan numbers: C_{n-1} = (1/n) × C(2n-2, n-1) ≈ Ω(4ⁿ/n^(3/2)). For n=10, there are 4862 ways; for n=20, over 6.5 × 10⁹ ways. Brute force is impossible!

Catalan Numbers

Parenthesizations of n matrices:

C₀ = 1, C₁ = 1, C₂ = 2

C₃ = 5, C₄ = 14, C₅ = 42

C₆ = 132, C₇ = 429

Formula: C_n = (2n)!/((n+1)!n!)

Problem Input

Dimensions: p₀, p₁, ..., pₙ

Matrix Aᵢ: p_{i-1} × pᵢ

Output: Minimum scalar multiplications

Also: optimal split positions

The DP Recurrence

Let m[i,j] be the minimum number of scalar multiplications needed to compute the product Aᵢ × Aᵢ₊₁ × ... × Aⱼ.

Base Case
m[i,i] = 0   for i = 1, 2, ..., n
A single matrix requires no multiplications.
DP Recurrence
m[i,j] = min { m[i,k] + m[k+1,j] + p_{i-1} × p_k × p_j }   for i ≤ k < j
Split at k: cost of left chain + cost of right chain + cost of final multiplication.

Table Construction

We fill the m[i,j] table diagonally. The length L = j - i + 1 varies from 2 to n.

function optMM(p, n): // p[0..n] = dimensions (p[i-1] × p[i] for matrix i) // m[1..n][1..n] = cost matrix // s[1..n-1][2..n] = split position matrix for i = 1 to n: m[i][i] = 0 // single matrix for L = 2 to n: // L = chain length for i = 1 to n-L+1: j = i + L - 1 m[i][j] = infinity for k = i to j-1: cost = m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j] if cost < m[i][j]: m[i][j] = cost s[i][j] = k // store split position return m[1][n] // minimum cost

Reconstructing the Parenthesization

function parenthesize(s, i, j): if i == j: print "A" + i else: print "(" parenthesize(s, i, s[i][j]) print " × " parenthesize(s, s[i][j]+1, j) print ")"

m[i,j] Table

Rows: i (start index)

Cols: j (end index)

Diagonal: m[i,i] = 0

Filled by increasing chain length

s[i,j] Table

Stores optimal split k

Used to reconstruct order

s[i,j] = k means:

Split after A_k

Complexity: The algorithm uses 3 nested loops (L, i, k) → O(n³) time. The m and s tables each use O(n²) space.

Worked Examples

Example 1: 3 Matrices — A₁(10×30), A₂(30×5), A₃(5×60)

Dimension array p: p₀=10, p₁=30, p₂=5, p₃=60

Base cases: m[1,1] = m[2,2] = m[3,3] = 0

L=2 (chains of length 2):

m[1,2] = m[1,1] + m[2,2] + p₀×p₁×p₂ = 0 + 0 + 10×30×5 = 1500, split at k=1

m[2,3] = m[2,2] + m[3,3] + p₁×p₂×p₃ = 0 + 0 + 30×5×60 = 9000, split at k=2

L=3 (chain of length 3):

m[1,3] = min of:

• k=1: m[1,1] + m[2,3] + p₀×p₁×p₃ = 0 + 9000 + 10×30×60 = 9000 + 18000 = 27000

• k=2: m[1,2] + m[3,3] + p₀×p₂×p₃ = 1500 + 0 + 10×5×60 = 1500 + 3000 = 4500

Minimum: m[1,3] = 4500, split at k=2

Parenthesization: (A₁ × A₂) × A₃

Example 4: When is (AB)C Better Than A(BC)?

Problem: A(w×x), B(x×y), C(y×z). Find the condition for (AB)C to be better than A(BC).

Solution: Compare multiplication counts:

(AB)C: AB costs w×x×y, then (AB)C costs w×y×z → wxy + wyz

A(BC): BC costs x×y×z, then A(BC) costs w×x×z → xyz + wxz

(AB)C is better when: wxy + wyz < xyz + wxz

Divide both sides by wxyz: 1/z + 1/w < 1/x + 1/y

Example: A(7×5), B(5×3), C(3×2):

(AB)C: 7×5×3 + 7×3×2 = 105 + 42 = 147

A(BC): 5×3×2 + 7×5×2 = 30 + 70 = 100

A(BC) is better: 100 < 147

Complexity Analysis

Time Complexity
T(n) = Σ_{L=2}^{n} Σ_{i=1}^{n-L+1} Σ_{k=i}^{i+L-2} 1 = O(n³)
Three nested loops: chain length L, start index i, split position k.

Time Complexity

Optimal Order: O(n³)

Brute Force: Ω(4ⁿ/n^(3/2))

Improvement: Exponential → Polynomial

Space Complexity

m Table: O(n²)

s Table: O(n²)

Total: O(n²)
