Problem Setup

Topological Sort orders vertices of a DAG such that for every directed edge u → v, vertex u appears before v in the ordering.

DFS-based approach: run DFS, push vertex to stack when finished (all descendants visited). Reverse the stack for topological order.

Key Idea

finish_time[u] > finish_time[v] ⟹ u comes before v

A vertex finishes only after all its descendants are done, so it naturally appears before them in the reversed finish order.
