GRAPH FUNDAMENTALS

Data Structures — Complete Guide for 20/20 Exam

Graph Definition

A graph is an ordered pair G = (V, E) where:

  • V — set of vertices (nodes), |V| = n
  • E — set of edges (connections), |E| = e

Each edge connects a pair of vertices. Graphs model relationships: road networks, social networks, dependency graphs, etc.

Graph Representation
G = (V, E)
Where V = {v₁, v₂, ..., vₙ} is the vertex set, E ⊆ V × V is the edge set

Directed vs Undirected Graphs

Undirected Graph

Edges have no direction

Edge (u, v) = (v, u)

Used for: symmetric relationships (friendship, network cables)

Directed Graph (Digraph)

Edges have direction

Edge (u → v) ≠ (v → u)

Used for: asymmetric relationships (followers, page links, prerequisites)

Property Undirected Directed
Edge notation {u, v} or (u, v) (u → v)
Max edges n(n−1)/2 n(n−1)
Adjacency Symmetric matrix May be asymmetric
Degree deg(v) deg⁻(v), deg⁺(v)
Self-loop allowed? No (simple graph) No (simple graph)

Vertex Degree

Degree of a vertex = number of edges incident to it.

Handshaking Lemma (Undirected)
∑ deg(v) = 2|E|
Every edge contributes 1 to the degree of each of its 2 endpoints
Directed Graph Degrees
deg⁺(v) = out-degree,   deg⁻(v) = in-degree
deg⁺(v) = number of edges leaving v; deg⁻(v) = number of edges entering v
Handshaking Lemma (Directed)
∑ deg⁺(v) = ∑ deg⁻(v) = |E|
Sum of out-degrees = sum of in-degrees = total edges

Simple Graphs

A simple graph has:

  • No self-loops (no edge from a vertex to itself)
  • No multi-edges (at most one edge between any pair of vertices)
Note: Unless otherwise stated, graph problems assume simple graphs.

Connectivity

Connected Graph

Every vertex is reachable from every other vertex via some path

|E| ≥ n − 1

Disconnected Graph

Contains ≥ 2 connected components

Max components = n (no edges)

Strongly Connected (Digraph)

Path from u to v and v to u for all u, v

Strongly Connected Component (SCC) = maximal strongly connected subgraph

Weakly Connected (Digraph)

Underlying undirected graph is connected

Directions ignored

Trees and Forests

Tree Properties (n vertices)
|E| = n − 1,   acyclic,   connected
A tree is a connected acyclic undirected graph. Any two of: {connected, acyclic, |E| = n−1} implies the third.
Forest Properties
|E| = n − c   (c = number of connected components)
A forest is an acyclic undirected graph (may be disconnected). Each component is a tree.

Tree

• Connected

• Acyclic

• |E| = n − 1

• Exactly 1 path between any 2 vertices

Forest

• Acyclic (may be disconnected)

• |E| = n − c

• Each component is a tree

• Removing 1 tree from forest still leaves forest

Common Mistake: Remember that a tree has exactly n−1 edges, but having n−1 edges does NOT guarantee a graph is a tree — it could be disconnected with cycles! The complete condition is: connected AND |E| = n − 1.

Order, Size & Graph Terminology

The order of a graph is the number of vertices: |V| = n = p.

The size of a graph is the number of edges: |E| = e = q.

The degree of a graph (graph degree) is the maximum degree among all vertices: Δ(G) = maxv∈V deg(v).

A subgraph G' = (V', E') of G = (V, E) satisfies V' ⊆ V and E' ⊆ E, where every edge in E' has both endpoints in V'.

Graph Terminology
Order = |V| = n, Size = |E| = e
Order counts vertices, size counts edges
Graph Degree
Δ(G) = max{deg(v) | v ∈ V}
Maximum degree among all vertices in the graph

Dense vs Sparse Graphs

Common Mistake: Dense and sparse are relative. There is no exact threshold. The typical boundary: if |E| is close to the maximum possible (e.g., > n√n), consider the graph dense.

Maximum and Minimum Edge Counts

Max Edges — Undirected Simple Graph
|E|max = n(n − 1) / 2
A complete graph Kₙ where every pair of distinct vertices is connected by an edge
Max Edges — Directed Simple Graph
|E|max = n(n − 1)
Every ordered pair (u, v) with u ≠ v is an edge. Twice the undirected maximum.
Min Edges — Connected Undirected Graph
|E|min = n − 1
Achieved by a tree (or any spanning tree of the graph)
Min Edges — Strongly Connected Digraph
|E|min = n
A directed cycle achieves exactly n edges and is strongly connected
Min Edges — Weakly Connected Digraph
|E|min = n − 1
Same as undirected: a directed tree where edge directions form a rooted tree
Common Mistake: Students often think "connected" implies |E| ≥ n. The minimum is n−1 (a tree). For strongly connected digraphs, the minimum is n (a cycle).

Graph Isomorphism Key Facts

  • Two graphs G₁ = (V₁, E₁) and G₂ = (V₂, E₂) are isomorphic if there exists a bijection f: V₁ → V₂ such that (u, v) ∈ E₁ ⇔ (f(u), f(v)) ∈ E₂
  • Necessary (but not sufficient) conditions: same |V|, same |E|, same degree sequence
  • Graph isomorphism problem is in NP but not known to be NP-complete (GI-complete)

Bipartite Graph Characterization

A graph is bipartite iff its vertex set can be partitioned into two independent sets A and B such that every edge connects a vertex in A to a vertex in B.

Bipartite Equivalent Condition
Graph is bipartite   ⟺   Graph has no odd-length cycles
Testing: 2-color the graph via BFS/DFS. If a conflict arises, the graph is not bipartite.

Worked Example 1: Degree Calculation

Example 1 — Handshaking Lemma Verification

Consider an undirected graph G with n = 6 vertices and edges: {1,2}, {1,3}, {1,4}, {2,3}, {2,5}, {3,4}, {3,5}, {4,6}, {5,6}

Step 1: Count edges: |E| = 9

Step 2: Compute degrees:

  • deg(1) = 3 (edges to 2, 3, 4)
  • deg(2) = 3 (edges to 1, 3, 5)
  • deg(3) = 4 (edges to 1, 2, 4, 5)
  • deg(4) = 2 (edges to 1, 6)
  • deg(5) = 3 (edges to 2, 3, 6)
  • deg(6) = 2 (edges to 4, 5)

Step 3: ∑ deg(v) = 3 + 3 + 4 + 2 + 3 + 2 = 17

Step 4: 2|E| = 2 × 9 = 18 ... wait, these don't match!

Why? ∑ deg(v) must equal 2|E| for any undirected graph. Let's recount deg(3):

deg(3) = neighbors {1, 2, 4, 5} = 4 ✓. deg(5) = neighbors {2, 3, 6} = 3 ✓. Total = 3+3+4+2+3+2 = 17 ≠ 18.

Issue: Edge {4,6} counted as: 4 has neighbor 6, 6 has neighbor 4 → both counted. Let's verify deg(6): edges to {4,5} = 2 ✓.

Wait — 3+3+4+2+3+2 = 17. But 2|E| = 18. There is a counting error!

Re-counting edges: {1,2}, {1,3}, {1,4}, {2,3}, {2,5}, {3,4}, {3,5}, {4,6}, {5,6} = 9 edges. Total degree should be 18.

Correction: deg(2) = {1,3,5} = 3 ✓. deg(3) = {1,2,4,5} = 4 ✓. deg(1) = {2,3,4} = 3 ✓. deg(5) = {2,3,6} = 3 ✓. deg(4) = {3,6} = 2 ✓. deg(6) = {4,5} = 2 ✓.

Sum = 3+3+4+3+2+2 = 17? Let me re-add: 3+3=6, +4=10, +3=13, +2=15, +2=17. Still 17!

Mistake found: Let me list edges again: (1,2), (1,3), (1,4), (2,3), (2,5), (3,4), (3,5), (4,6), (5,6). That's 9 edges.

deg(1) = 3, deg(2) = 3, deg(3) = 4, deg(4) = 2, deg(5) = 3, deg(6) = 2 — Sum = 17 ≠ 18!

The issue: I likely missed one edge in my list. Count edges properly: 1-2, 1-3, 1-4, 2-3, 2-5, 3-4, 3-5, 4-6, 5-6. That's 9 edges. But deg sums to 17, not 18.

There's actually an error in my example construction: deg(3) = edges to 1,2,4,5 = 4 ✓. deg(4) = edges to 1,3,6 = 3 (not 2!) {1,4}, {3,4}, {4,6}.

Corrected: deg(4) = 3, not 2. Sum = 3+3+4+3+3+2 = 18 ✓ = 2|E| ✓

Lesson: Always double-check degree counts! A single missed edge breaks the handshaking lemma.

Worked Example 2: Maximum Edges

Example 2 — Complete Graph Edge Count

Problem: How many edges are in a complete undirected graph with 10 vertices? What about a complete directed graph?

Solution:

Undirected K₁₀:

|E| = n(n−1)/2 = 10 × 9 / 2 = 90/2 = 45 edges

Directed complete:

|E| = n(n−1) = 10 × 9 = 90 edges

Verification:

Each of the 10 vertices connects to 9 others. Undirected doubles count edges (each counted twice), so 10×9/2 = 45.

For directed, each ordered pair counts once, so 10×9 = 90.

Example 3 — Minimum Connected Graph

Problem: What is the smallest number of edges in an undirected graph with 15 vertices such that it is connected?

Solution:

The minimum edges for a connected undirected graph is achieved by a tree: |E| = n − 1 = 15 − 1 = 14 edges

Any connected graph must have at least n−1 edges. If |E| < n−1, the graph is necessarily disconnected.

Check: A path graph P₁₅ with 15 vertices has exactly 14 edges and is connected. A star K₁,₁₄ also has 14 edges and is connected.

Worked Example 6: Complete Bipartite Graph

Example 6 — K₃,₃ Edge and Degree Analysis

Problem: For the complete bipartite graph K₃,₃, compute: (a) total vertices, (b) total edges, (c) degree of each vertex, (d) sum of degrees.

Solution:

(a) n = a + b = 3 + 3 = 6 vertices

(b) |E| = a × b = 3 × 3 = 9 edges

(c) Each vertex in partition A connects to all 3 vertices in partition B → deg = 3 for all vertices

(d) ∑ deg = 6 × 3 = 18 = 2|E| = 2 × 9 = 18 ✓

K₃,₃ is a well-known non-planar graph (Kuratowski's theorem).
