Breadth-First Search (BFS)

Graph Traversal — Level-by-Level Exploration | Complete Guide for 20/20 Exam

What is BFS?

BFS (Breadth-First Search) is a graph traversal algorithm that explores vertices level by level — all neighbors at the current depth are visited before moving to the next depth level. It uses a FIFO queue to manage the frontier of discovery.

BFS is fundamental for finding shortest paths in unweighted graphs (minimum number of edges).

Vertex Color Convention

ColorMeaningDescription
 WHITE UnvisitedVertex has not been discovered yet
 GRAY Discovered / In QueueVertex is in the frontier queue, waiting to be processed
 BLACK ProcessedAll neighbors of this vertex have been discovered

BFS Pseudocode

BFS(G, s): // Initialize all vertices for each vertex u ∈ G.V - {s}: u.color = WHITE u.d = ∞ u.π = NIL // Initialize source s.color = GRAY s.d = 0 s.π = NIL Q = ∅ // FIFO queue Enqueue(Q, s) while Q ≠ ∅: u = Dequeue(Q) for each v ∈ G.Adj[u]: if v.color == WHITE: v.color = GRAY v.d = u.d + 1 v.π = u Enqueue(Q, v) u.color = BLACK

BFS Tree & Forest

BFS produces a BFS tree (or BFS forest for disconnected graphs) rooted at the source vertex s. The predecessor array π defines the tree edges: for each vertex v ≠ s, the edge (π[v], v) is a tree edge.

BFS Tree

• Single source, one component → one tree

• All vertices reachable from s

• No forward edges in BFS

• No back edges in undirected BFS

BFS Forest

• Disconnected graph → multiple trees

• Run BFS on each unvisited vertex

• Each component yields one tree

• Total: one forest per graph

⚠ Common Mistake: In BFS of undirected graphs, there are no back edges — every edge connects vertices at the same or adjacent levels. In directed BFS, cross edges can exist between vertices at the same level.

Distance Properties

For any vertex v reachable from s:

BFS Shortest Path Distance:
d[v] = minimum number of edges from s to v
BFS guarantees d[v] = δ(s,v) where δ(s,v) is the shortest path distance in the unweighted graph
Distance Update Rule:
d[v] = d[u] + 1   where   u = π[v]
The distance of a child vertex is exactly one more than the distance of its parent
Queue Invariant:
d[Q[i+1]] ≥ d[Q[i]]   and   d[Q[last]] - d[Q[first]] ≤ 1
Queue always contains vertices with at most two distinct distance values (d and d+1)

Time & Space Complexity

Adjacency List

Time: O(V + E)

Space: O(V) — queue, color, d, π

Each vertex enqueued/dequeued once: O(V). Each edge examined once: O(E).

Adjacency Matrix

Time: O(V²)

Space: O(V²) — matrix storage

For each dequeued vertex, scanning V entries: O(V²) total.

PrintPath Algorithm

Using the predecessor array π computed by BFS, we can reconstruct the shortest path from source s to any vertex v.

PrintPath(G, s, v): if v == s: print(s) else if v.π == NIL: print("No path from", s, "to", v) else: PrintPath(G, s, v.π) print(v)

Shortest Paths in Unweighted Graphs

BFS is optimal for finding shortest paths in unweighted graphs because it explores vertices in order of increasing distance from the source.

Shortest Path Distance (Unweighted):
δ(s,v) = minimum number of edges on any path from s to v
BFS guarantees d[v] = δ(s,v) for all v reachable from s
BFS Correctness (Triangle Inequality):
δ(s,v) ≤ δ(s,u) + 1
For any edge (u,v) in the graph, the shortest distance to v cannot exceed shortest distance to u plus 1
Example: Finding Shortest Paths
A --- B --- C --- D | | E ----------F

BFS from A gives distances: A:0, B:1, E:1, C:2, F:2, D:3

The shortest path A→D: A → B → C → D (3 edges).

Note: Direct path A→E→F→D is also 3 edges. BFS finds one of the shortest paths (based on discovery order).

Complexity Analysis

Runtime (Adjacency List):
T(V,E) = O(V + E)
Proof: Each vertex is enqueued and dequeued at most once (O(V)). Each adjacency list is scanned when its vertex is dequeued. Sum of |Adj[v]| over all v = 2|E| for undirected graphs and |E| for directed graphs. Thus total = O(V+E).
Runtime (Adjacency Matrix):
T(V,E) = O(V²)
Each dequeue requires scanning V entries in the matrix row to find neighbors. With V dequeues, total = O(V²).

Space Breakdown

Queue: O(V)

Color array: O(V)

Distance array d: O(V)

Predecessor π: O(V)

Total auxiliary: O(V)

BFS Variants

Bidirectional BFS: O(bd/2)

Lexicographic BFS: O(V+E)

Weighted BFS (0-1 BFS): O(V+E)

Bidirectional BFS runs two simultaneous BFS searches and is much faster for large graphs.

Application: Bipartite Graph Detection

A graph is bipartite if its vertices can be colored with 2 colors such that no two adjacent vertices share the same color. BFS can detect bipartiteness in O(V+E):

BIPARTITE(G, s): color all vertices WHITE color[s] ← BLACK enqueue(Q, s) while Q ≠ ∅: u ← dequeue(Q) for each v in Adj[u]: if color[v] = WHITE: color[v] ← opposite(color[u]) enqueue(Q, v) else if color[v] = color[u]: return FALSE // not bipartite return TRUE

Key: A graph is bipartite iff it has no odd-length cycle. BFS detects this by checking if two adjacent vertices get the same color. Runtime: O(V+E).

Exam tip: Bipartite graph questions often appear with BFS. Remember: odd cycle ⟹ not bipartite. BFS-based 2-coloring is the standard detection method.

Edge Cases & Common Mistakes

⚠ Warning: BFS does NOT work for weighted graphs — it assumes all edges have equal weight. Use Dijkstra's algorithm instead.
⚠ Warning: For very large graphs, the queue can grow to O(V). In memory-constrained environments, iterative deepening DFS (IDDFS) may be preferred for its O(V) worst-case memory.
⚠ Warning: When implementing BFS, always mark vertices as GRAY/FOUND when enqueuing, not when dequeuing. Otherwise, the same vertex could be enqueued multiple times, breaking the algorithm.
⚠ Warning: BFS distance d[v] is the number of edges, not the number of vertices, on the path. A path with k edges has k+1 vertices.

BFS Distance Invariant:
d[v] = smallest integer k such that there exists a path of k edges from s to v
Equivalently: d[v] = level of v in the BFS tree
Queue Property:
If u is dequeued before v, then d[u] ≤ d[v]
FIFO ordering respects distance ordering
