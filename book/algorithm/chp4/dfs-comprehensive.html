DEPTH-FIRST SEARCH (DFS)

Data Structures — Complete Guide for 20/20 Exam

DFS Overview

Depth-First Search explores a graph by going as deep as possible along each branch before backtracking. It uses a stack (implicitly via recursion or explicitly).

Key Idea

Explore as far as possible along each path before backtracking

Data Structure

Stack (LIFO) — recursive call stack or explicit stack

Applications

Cycle detection, topological sort (DAG), connected components, SCCs

Runtime

O(V + E) with adjacency lists, O(V²) with adjacency matrix

Color Coding Scheme

Each vertex v ∈ V is assigned a color during DFS to track its state:

Color Meaning Discovered? Finished? Notation
WHITE Unvisited No No color[v] = WHITE
GRAY Discovered, not finished Yes No color[v] = GRAY, d[v] set
BLACK Finished (all descendants processed) Yes Yes color[v] = BLACK, f[v] set
Timestamps Definition
d[v] = discovery time (when v turns GRAY),   f[v] = finish time (when v turns BLACK)
Timestamps are integers from 1 to 2|V|. Each vertex has d[v] < f[v].
Common Mistake: WHITE, GRAY, BLACK are NOT just colors — they encode critical algorithmic state. A GRAY vertex means "currently on the recursion stack." Finding a GRAY neighbor means a back edge (cycle)!

DFS Pseudocode

DFS(G): for each vertex u ∈ G.V: color[u] = WHITE π[u] = NIL // predecessor time = 0 for each vertex u ∈ G.V: if color[u] == WHITE: DFS-VISIT(u) DFS-VISIT(u): color[u] = GRAY // discover u time = time + 1 d[u] = time for each v ∈ Adj[u]: // explore neighbors if color[v] == WHITE: π[v] = u DFS-VISIT(v) color[u] = BLACK // finish u time = time + 1 f[u] = time
Key Observation: DFS-VISIT is called exactly once for each vertex. The inner loop iterates over all neighbors of the vertex. Total work = O(V + E).

Runtime Analysis

DFS Runtime — Adjacency Lists
T(n, e) = O(V + E)
Lines 1-3: O(V). DFS-VISIT called V times total. Each edge examined once (directed) or twice (undirected). Total = O(V + E).
DFS Runtime — Adjacency Matrix
T(n) = O(V²)
Each DFS-VISIT must scan the entire row (V entries) to find neighbors. V calls × V entries = V².
Operation Cost per call Times called Total
Initialize colors O(1) V O(V)
DFS-VISIT (lists) O(deg(v)) V O(V+E)
DFS-VISIT (matrix) O(V) V O(V²)

DFS Forest

When DFS explores a graph, it produces a depth-first forest consisting of multiple depth-first trees. Each tree corresponds to a call to DFS-VISIT from the main loop.

DFS Forest Structure
DFS Forest = {T₁, T₂, ..., Tk}
Each Tᵢ is a depth-first tree rooted at the vertex where DFS-VISIT was first called. k = number of connected components (for undirected) or reachable subgraphs (for directed).
Tree edges: Edges (u, v) where DFS-VISIT(v) is called from u. These form the DFS forest.

Parenthesis Theorem

One of the most important properties of DFS timestamps.

Parenthesis Theorem
For any vertices u, v, exactly one of the following holds:
(1) [d[u], f[u]] and [d[v], f[v]] are disjoint → neither is an ancestor of the other
(2) [d[u], f[u]] ⊂ [d[v], f[v]] → u is a descendant of v
(3) [d[v], f[v]] ⊂ [d[u], f[u]] → v is a descendant of u
The intervals are either nested or disjoint — they never partially overlap.

This is called the parenthesis theorem because if we write (v when discovering and )v when finishing, the resulting string has properly nested parentheses.

Parenthesis Representation

If DFS on a graph gives: d[a]=1, f[a]=8, d[b]=2, f[b]=7, d[c]=3, f[c]=4, d[d]=5, f[d]=6

Parenthesis form: (a (b (c) (d) )b )a

This shows: b is a descendant of a, c and d are descendants of b.

Common Mistake: The intervals are [d, f], not (d, f). If d[u] < d[v] < f[v] < f[u], then v is a descendant of u. If d[u] < f[u] < d[v] < f[v], they are in different branches.

White Path Theorem

White Path Theorem
Vertex v is a descendant of u in the DFS forest ⟺ at time d[u], v can be reached from u along a path consisting entirely of WHITE vertices.
This characterizes which vertices get visited during a DFS-VISIT call.

Corollary: If v is a descendant of u in the DFS forest, then d[u] < d[v] < f[v] < f[u] (nested intervals).

Worked Example 1: Simple Undirected Graph

Example 1 — DFS on a Small Graph

Graph: V = {a, b, c, d, e}. Undirected edges: a-b, a-c, b-d, c-e

Assume adjacency lists sorted alphabetically. Start DFS from vertex a.

Step-by-step execution:

time=1: DFS-VISIT(a), color[a]=GRAY, d[a]=1
time=2: explore a→b (WHITE), call DFS-VISIT(b), d[b]=2
time=3: explore b→a (GRAY → skip), b→d (WHITE), call DFS-VISIT(d), d[d]=3
time=4: d has no unvisited neighbors, finish d, f[d]=4, color[d]=BLACK
time=5: back to b → explore b→d (BLACK skip), finish b, f[b]=5
time=6: back to a → explore a→c (WHITE), call DFS-VISIT(c), d[c]=6
time=7: explore c→a (GRAY skip), c→e (WHITE), call DFS-VISIT(e), d[e]=7
time=8: e has no unvisited neighbors, finish e, f[e]=8
time=9: back to c, finish c, f[c]=9
time=10: back to a, finish a, f[a]=10

Result table:

Parenthesis form: (a (b (d) )b (c (e) )c )a

Verified: intervals nest correctly. d, e are leaves (f = d+1). b finishes before c is explored.

Worked Example 3: Directed Graph with Cycle

Example 3 — Cycle Detection via DFS

Graph: V = {x, y, z}, edges: x→y, y→z, z→x (directed cycle)

time=1: DFS-VISIT(x), d[x]=1, color[x]=GRAY
time=2: x→y (WHITE), DFS-VISIT(y), d[y]=2, color[y]=GRAY
time=3: y→z (WHITE), DFS-VISIT(z), d[z]=3, color[z]=GRAY
time=4: z→x → x is GRAY! ← BACK EDGE (cycle detected!)
z has no more edges, finish z, f[z]=4
time=5: finish y, f[y]=5
time=6: finish x, f[x]=6

Critical moment at time=4: When exploring z→x, we find x is GRAY. This means x is an ancestor of z in the recursion stack, and the edge z→x is a back edge.

Cycle Detection Rule: A directed graph has a cycle ⟺ DFS produces at least one back edge. This is the standard algorithm for cycle detection in directed graphs.

Parenthesis form: (x (y (z) )y )x — Intervals are nested, but the back edge z→x breaks the tree structure.
