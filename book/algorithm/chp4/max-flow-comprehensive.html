Max Flow / Ford-Fulkerson

Flow Networks — Maximum Flow & Minimum Cut

Flow Network Definition

A flow network is a directed graph G = (V, E) where:

  • Each edge (u, v) ∈ E has a capacity c(u, v) ≥ 0
  • If (u, v) ∉ E, then c(u, v) = 0
  • There is a source s and a sink t
  • Every vertex lies on some path from s to t
  • No antiparallel edges (initially — handled later)
Flow Function f: V × V → ℝ must satisfy:
1.  Capacity constraint:  0 ≤ f(u, v) ≤ c(u, v)
2.  Flow conservation:  ∑v∈V f(u, v) = ∑v∈V f(v, u)   for all u ≠ s, t
Flow on each edge cannot exceed capacity. Flow entering a vertex (except s, t) equals flow leaving it.
Value of Flow:
|f| = ∑v∈V f(s, v) = ∑v∈V f(v, t)
Total flow out of source = total flow into sink.
Skew Symmetry (for residual network):
f(v, u) = -f(u, v)
Flow in opposite direction is negative of forward flow. Used to simplify residual graph notation.

Key Concepts

Capacity c(u,v)

Maximum allowable flow on edge (u, v)

Non-negative real number

Analogous to pipe diameter

Flow f(u,v)

Actual flow on edge (u, v)

0 ≤ f(u,v) ≤ c(u,v)

Analogous to water flowing in pipe

Residual Capacity

cf(u,v) = c(u,v) - f(u,v)

cf(v,u) = f(u,v) (cancellation)

Remaining capacity in residual graph

Augmenting Path

A path from s to t in Gf where every edge has cf > 0

Bottleneck capacity = min cf along path

Variable Definitions

  • G = (V, E) — Flow network with directed edges
  • c(u, v) — Capacity of edge (u, v)
  • f(u, v) — Flow on edge (u, v)
  • s — Source vertex
  • t — Sink vertex
  • |f| — Total flow value from s to t
  • Gf — Residual network of G with respect to flow f
  • cf(u, v) — Residual capacity of edge (u, v) in Gf
  • f* — Maximum flow value
  • c(S, T) — Capacity of cut (S, T)

The Ford-Fulkerson Method

The Ford-Fulkerson method is an iterative approach to compute the maximum flow. It repeatedly finds augmenting paths in the residual network and pushes flow along them.

Core Idea:
|f| = |f| + cf(p)   where   cf(p) = min{ cf(u,v) : (u,v) ∈ p }
Each iteration adds the bottleneck capacity of the augmenting path to the total flow.

Algorithm Pseudocode

FORD-FULKERSON(G, s, t) // Initialize flow to zero for each edge (u, v) ∈ E f[u][v] = 0 f[v][u] = 0 // Main loop: while there exists an augmenting path while there exists a path p from s to t in Gf // Find bottleneck capacity cf(p) = min{ cf(u, v) : (u, v) ∈ p } // Augment flow along path p for each edge (u, v) in p if (u, v) ∈ E // forward edge f[u][v] = f[u][v] + cf(p) else // backward edge (v, u) ∈ E f[v][u] = f[v][u] - cf(p) return f

The residual capacities update automatically: cf(u,v) = c(u,v) - f(u,v) and cf(v,u) = f(u,v).

Residual Network Construction

Given a flow f on network G, the residual network Gf has:

  • Forward edges: if c(u,v) - f(u,v) > 0, add edge (u,v) with capacity cf(u,v) = c(u,v) - f(u,v)
  • Backward edges: if f(u,v) > 0, add edge (v,u) with capacity cf(v,u) = f(u,v) (allows cancellation)
Residual Capacity:
cf(u, v) = c(u, v) - f(u, v) + f(v, u)
When there's no antiparallel edges, either f(u,v) or f(v,u) is zero initially.

⚠ Backward Edge Necessity

If we had sent flow s→a→b→t first (if edge a→b existed), backward edges allow us to "undo" that decision and reroute flow. This is why the residual graph includes backward edges — they enable the algorithm to correct suboptimal routing choices.

Runtime Analysis

Ford-Fulkerson Runtime (general):
O(E · |f*|)
where |f*| is the maximum flow value. Each augmenting path increases flow by at least 1 (for integer capacities). In worst case, path selection can be very inefficient.
⚠ Worst-Case Example (Integer Capacities)
s --(M)--> a --(M)--> t | | +----(1)---> b ----+ M is very large

If Ford-Fulkerson picks s→a→t (bottleneck=M), then s→b→a→t (bottleneck=1), then s→a→t (M-1), ..., it can take 2M iterations! This is why Edmonds-Karp (BFS-based path selection) is preferred.

Edmonds-Karp Algorithm

The Edmonds-Karp algorithm is a specific implementation of Ford-Fulkerson that uses BFS to find the shortest augmenting path (fewest edges) in each iteration.

Key insight:
BFS in Gf finds the path with the fewest edges from s to t
This guarantees that the distance (in edges) from s to every vertex increases monotonically, bounding the number of augmentations to O(V · E).
EDMONDS-KARP(G, s, t) for each edge (u, v) ∈ E f[u][v] = 0 while true // BFS to find shortest augmenting path run BFS on Gf starting from s if t is not reachable break // Reconstruct path and find bottleneck p = shortest path s → ... → t cf(p) = min{ cf(u, v) : (u, v) ∈ p } // Augment for each edge (u, v) in p if (u, v) ∈ E f[u][v] += cf(p) else f[v][u] -= cf(p) return f
Edmonds-Karp Runtime:
T(V, E) = O(V · E²)
Each augmentation runs BFS in O(E), and a vertex can be on the critical edge at most V/2 times, giving O(V · E) augmentations total.

The Min-Cut / Max-Flow Theorem

Fundamental Theorem:
max{ |f| : f is a flow } = min{ c(S, T) : (S, T) is an s-t cut }
The maximum feasible flow value equals the minimum capacity of any s-t cut.

Cut definition: A partition (S, T) of V such that s ∈ S, t ∈ T.

Cut Capacity:
c(S, T) = ∑u∈S, v∈T c(u, v)
Sum of capacities of all edges from S to T. Edges from T to S are not counted.

Three equivalent statements (any implies all):

  1. |f| = c(S, T) for some cut (S, T) → f is a max flow
  2. f is a maximum flow
  3. The residual network Gf has no augmenting path

Example 5: Finding Min Cut from Max Flow

8 s -------> a |\ /| | \5 / | | \ / | | v / | | b | | / \ | | / \ | | 7 6 | v v c -------> t 4

After running max flow to completion:

Finding the Min Cut (S, T)
1. Run Ford-Fulkerson / Edmonds-Karp to find max flow.
2. Compute residual network Gf.
3. Run BFS/DFS from s in Gf.
4. S = set of vertices reachable from s in Gf.
5. T = V \ S (unreachable vertices).
The cut (S, T) is a minimum cut with capacity = max flow value.
Concrete Example

Suppose after max flow computation on the above graph, the reachable set from s in Gf is S = {s, a, b}.

Then T = {c, t}.

Edges from S to T: a→t (weight 8 if not saturated), b→t (6), b→c (0), s→c (7).

But if the flow saturated some of these edges, the residual edges from S to T have capacity 0 for saturated edges, so they don't contribute to cut capacity.

The min cut capacity = sum of saturated edges from S to T = max flow value.

({s}, {a,b,c,t})s→a(8), s→b(5), s→c(7)20
({s,a}, {b,c,t})s→c(7), a→b(0), a→t(8)15
({s,a,b}, {c,t})s→c(7), b→t(6), a→t(8)21

The minimum cut is ({s,a}, {b,c,t}) with capacity 15 = max flow value.

Advanced Variations

Multiple Sources / Multiple Sinks

Add a super-source s' with infinite-capacity edges to each original source, and a super-sink t' with infinite-capacity edges from each original sink.

s1 -----\ s2 ------> [network] ----> t1 s3 -----/ \---> t2 After transformation: s' --∞--> s1 ---\ /-- t1 --∞--> t' s' --∞--> s2 --> [network] --- t2 --∞--> t' s' --∞--> s3 ---/ \-- t3 --∞--> t'

Vertex Capacities

Split each capacity-constrained vertex v into vin and vout, connected by an edge with capacity equal to the vertex capacity.

u ---> v ---> w (cv = capacity of v) After splitting: u ---> vin ---(cv)---> vout ---> w

Antiparallel Edges

If both (u,v) and (v,u) exist, insert a dummy vertex to eliminate the antiparallel pair while preserving the flow behavior.

u <---> v (both directions) After transformation: u ---> dummy ---> v v ---> u

Applications of Max Flow

Bipartite Matching

Connect source to left set, left to right, right to sink — all with capacity 1. Max flow = max matching size.

Edge-Disjoint Paths

Set all capacities to 1. Max flow = maximum number of edge-disjoint paths from s to t.

Image Segmentation

Cut-based segmentation: min cut separating foreground from background.

Baseball Elimination

Determine if a team can still win the championship using max flow feasibility.
