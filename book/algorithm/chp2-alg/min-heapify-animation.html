MIN-HEAPIFY Algorithm

MIN-HEAPIFY(A, i) is a recursive algorithm that maintains the min-heap property at a given node i.

Min-Heap Property:
A[parent(i)] ≤ A[i]
Every parent is ≤ its children — the root is the minimum element
Array Representation:
parent(i) = ⌊i/2⌋, left(i) = 2i, right(i) = 2i+1
For node at index i (1-based indexing)

How it works

1. Compare node at index i with its left child (2i) and right child (2i+1)

2. Find the smallest among the three

3. If smallest ≠ i, swap A[i] with A[smallest] and recursively min-heapify at smallest

Pseudocode

MIN-HEAPIFY(A, i, n) { left = 2*i; right = 2*i + 1; smallest = i; if (left ≤ n and A[left] < A[i]) smallest = left; if (right ≤ n and A[right] < A[smallest]) smallest = right; if (smallest ≠ i) { swap(A[i], A[smallest]); MIN-HEAPIFY(A, smallest, n); } }

Note: This is the same as MAX-HEAPIFY but with the comparison operator reversed (< instead of >).

Worked Examples

Example: MIN-HEAPIFY(A, 1) where A = [16, 4, 10, 14, 7, 9, 3, 2, 8, 1]

i=1, A[1]=16

left=2, A[2]=4. 4 < 16, smallest=2

right=3, A[3]=10. 10 ≮ 4, smallest=2

Swap A[1]↔A[2]: [4, 16, 10, 14, 7, 9, 3, 2, 8, 1]

Recurse i=2. A[2]=16, left=4→14, right=5→7. smallest=5.

Swap A[2]↔A[5]: [4, 7, 10, 14, 16, 9, 3, 2, 8, 1]

Recurse i=5. A[5]=16, left=10→1. right=11 OOB. smallest=10.

Swap A[5]↔A[10]: [4, 7, 10, 14, 1, 9, 3, 2, 8, 16]

Recurse i=10. No children. Done.

Result: [4, 7, 10, 14, 1, 9, 3, 2, 8, 16]

Time Complexity

Worst Case:
O(h) = O(log n)
Where h is the height of the subtree rooted at i
Best Case:
Ω(1)
When A[i] already satisfies the min-heap property
Recurrence:
T(n) = T(2n/3) + O(1)
The worst-case recurrence for heapify

Called on root

Time: O(log n)

Worst case: element sifts from root to leaf

Called on leaf

Time: Ω(1)

Leaf has no children, no work needed

Build Heap (n calls)

Time: O(n)

Most nodes are near the bottom

Properties

Stable

No

Swapping may change relative order of equal elements

In-Place

Yes

Uses only O(1) extra space

Recursive

Yes

Tail-recursive; can be implemented iteratively

Comparison

Min vs Max

Min-Heapify uses < ; Max-Heapify uses >

Min-Heap vs Max-Heap:

• Min-Heap: Root is the smallest element. A[parent(i)] ≤ A[i]

• Max-Heap: Root is the largest element. A[parent(i)] ≥ A[i]

• MIN-HEAPIFY is the "mirror" of MAX-HEAPIFY — same logic, reversed comparison

Applications

• Priority queues (min-priority)

• Dijkstra's shortest path algorithm

• Prim's minimum spanning tree

• Heap Sort (when sorting in descending order)
