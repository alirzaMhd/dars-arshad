Count Leaf Nodes

function countLeaves(t: tree): integer; begin if t = nil then countLeaves := 0 else if (t.left = nil) AND (t.right = nil) then countLeaves := 1 // It's a leaf else countLeaves := countLeaves(t.left) + countLeaves(t.right); end;
Complexity:
Time: O(n), Space: O(h)
Trace: Count Leaves
a / \ b c / \ d e

countLeaves(a) = countLeaves(b) + countLeaves(c)

countLeaves(b) = countLeaves(d) + countLeaves(e) = 1+1 = 2

countLeaves(c) = 1 → countLeaves(a) = 2+1 = 3

Count All Nodes

function countNodes(t: tree): integer; begin if t = nil then countNodes := 0 else countNodes := 1 + countNodes(t.left) + countNodes(t.right); end;
Trace: Count Nodes
a / \ b c / \ d e

countNodes(a) = 1 + countNodes(b) + countNodes(c)

countNodes(b) = 1+1+1 = 3, countNodes(c) = 1 → total = 5

Count Internal Nodes

function countInternal(t: tree): integer; begin if t = nil then countInternal := 0 else if (t.left = nil) AND (t.right = nil) then countInternal := 0 else countInternal := 1 + countInternal(t.left) + countInternal(t.right); end;
Alternative:
countInternal = countNodes - countLeaves

Compute Tree Height

function treeHeight(t: tree): integer; begin if t = nil then treeHeight := -1 else treeHeight := 1 + max(treeHeight(t.left), treeHeight(t.right)); end;
Complexity:
Time: O(n), Space: O(h)
Trace: Height
a / \ b c / \ d e

treeHeight(d) = 0, treeHeight(e) = 0, treeHeight(c) = 0

treeHeight(b) = 1+max(0,0) = 1

treeHeight(a) = 1+max(1,0) = 2

Count Nodes at Level k

function countAtLevel(t: tree, level: integer): integer; begin if t = nil then countAtLevel := 0 else if level = 0 then countAtLevel := 1 else countAtLevel := countAtLevel(t.left, level-1) + countAtLevel(t.right, level-1); end;
Trace: Count at Level 2
Level 0: a / \ Level 1: b c / \ Level 2: d e

countAtLevel(a,2) = countAtLevel(b,1) + countAtLevel(c,1) = 2 + 0 = 2

Check if Balanced

function isBalanced(t: tree): boolean; begin if t = nil then isBalanced := true else begin leftH := treeHeight(t.left); rightH := treeHeight(t.right); isBalanced := (abs(leftH - rightH) <= 1) AND isBalanced(t.left) AND isBalanced(t.right); end; end;
This naive approach is O(n²). Optimized O(n) combines height and balance check.

Copy Tree

Tree* copyTree(Tree* source) { Tree* temp; if (source != NULL) { temp = new(Tree); temp->data = source->data; temp->left = copyTree(source->left); temp->right = copyTree(source->right); return temp; } return NULL; }
Complexity:
Time: O(n), Space: O(h)
Trace: Copy Tree
Original: Copy: a a' / \ / \ b c b' c'

Creates an independent copy with same structure and data.

Tree Equality

bool isEqual(Tree* a, Tree* b) { if (a == NULL && b == NULL) return true; if (a != NULL && b != NULL && a->data == b->data && isEqual(a->left, b->left) && isEqual(a->right, b->right)) return true; return false; }
Conditions:
Both empty OR (same data AND equal left+right subtrees)
Equality Check

Tree A

a\n / \\\nb c

Tree B (Equal)

a\n / \\\nb c

Tree C (Not Equal)

a\n / \\\nc b

isEqual(A,B)=true, isEqual(A,C)=false

Mirror (Reverse) Tree

Tree* mirror(Tree* source) { Tree* temp; if (source != NULL) { temp = new(Tree); temp->left = mirror(source->right); // Swap! temp->right = mirror(source->left); // Swap! temp->data = source->data; return temp; } return NULL; }
Key Difference from Copy:
Left ↔ Right children are SWAPPED
Note:
reverse() = mirror() = invert()
Mirror Example

Original

a\n / \\\n b c\n / \\\nd e

Mirror

a\n / \\\n c b\n / \\\n e d

In-Place Mirror

void mirrorInPlace(Tree* node) { if (node == NULL) return; Tree* temp = node->left; node->left = node->right; node->right = temp; mirrorInPlace(node->left); mirrorInPlace(node->right); }
mirror() creates a NEW tree. mirrorInPlace() modifies the ORIGINAL. Know the difference!

Other Useful Algorithms

Check if BST

bool isBST(Tree* node, int min, int max) { if (node == NULL) return true; if (node->data <= min || node->data >= max) return false; return isBST(node->left, min, node->data) && isBST(node->right, node->data, max); }

Find LCA

Tree* findLCA(Tree* root, Tree* a, Tree* b) { if (root == NULL) return NULL; if (root == a || root == b) return root; Tree* left = findLCA(root->left, a, b); Tree* right = findLCA(root->right, a, b); if (left && right) return root; return left ? left : right; }
