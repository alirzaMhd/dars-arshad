General Tree (N-ary Tree)

A general tree is a tree where each node can have any number of children, unlike a binary tree which limits to two.

Example tree: Root A with children [B, C, D].

• B has children [E, F]

• C has child [G]

• D has children [H, I]

• F has child [J]

We'll demonstrate: Preorder, Postorder, Level-order traversals, plus Depth, Height, and Find Node operations.
