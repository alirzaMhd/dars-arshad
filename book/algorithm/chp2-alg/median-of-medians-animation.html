What is the Selection Problem?

Given an array A of n elements, find the k-th smallest element (k-th order statistic).

Problem Statement:
Find the k-th minimum in array A[1..n]
k is the rank (1 ≤ k ≤ n)

Special Cases

• k = 1: Find minimum

• k = n: Find maximum

• k = ⌈n/2⌉: Find median

Naive Approach

• Sort then select

Time: O(n lg n)

Select Algorithm

• Blum-Floyd-Pratt-Rivest-Tarjan

• Worst-case O(n)

The Select Algorithm

A divide-and-conquer algorithm that finds the k-th smallest element in Θ(n) time.

sel(A[L..u], k)
{
  n = u - L + 1;
  if (n ≤ 25) use brute force!
  else {
    m = ⌈n/5⌉; B[1..m]
    /* Step 1: Find medians of groups of 5 */
    for (i = 1 to m)
      B[i] = sel(A[5i-4 .. 5i], 3);
    /* Step 2: Find median of medians */
    x = sel(B[1..m], ⌈m/2⌉);
    /* Step 3: Partition around x */
    j = partition(A[L..u], x);
    i = j - L + 1;
    /* Step 4: Check position and recurse */
    if (k == i) return A[j];
    else if (k < i) return sel(A[L..j-1], k);
    else return sel(A[j+1..u], k-i);
  }
}
Key Insight: Threshold of 25: brute force for small n. The constant factors make recursion impractical for small arrays.

Median of Medians Analysis

Step 1: Divide into groups of 5

Divide A into ⌈n/5⌉ groups, each with 5 elements (last may have fewer). Time: Θ(n).

Step 2: Find median of each group

Sort each group of 5 (Θ(1) per group). Store medians in B[1..m], m = ⌈n/5⌉.

Step 3: Recursively find median of B

Call sel(B[1..m], ⌈m/2⌉) to find median of medians x.

Recurrence for Step 2:
T(n/5)
Finding median of ⌈n/5⌉ medians

Step 4: Partition and recurse

x guarantees at least 3n/10 elements ≤ x and at least 3n/10 ≥ x.

Worst case for Step 4:
T(7n/10)
At most 7n/10 elements on one side
Precise Recurrence:
T(n) = T(⌈n/5⌉) + T(7n/10 + 6) + Θ(n)
+6 accounts for last group and group containing x

Detailed 3n/10 Bound Derivation

Step-by-step bound proof:

1. ⌈n/5⌉ groups → ⌈n/5⌉ medians in B.

2. x = sel(B[1..m], ⌈m/2⌉) → x is median of B → at least ⌈m/2⌉ medians ≤ x.

3. Each median is 3rd smallest in its group → 2 elements in each such group ≤ that median (hence ≤ x).

4. Total ≤ x ≥ 3 × ⌈n/10⌉ ≥ 3n/10.

5. By symmetry, at least 3n/10 elements ≥ x.

6. x has rank between 3n/10 and 7n/10 → larger side ≤ 7n/10 elements.

Why Groups of 5 but Not 3?

Groups of 5

T(n/5) + T(7n/10) + Θ(n)

Sum: 9/10 < 1

Result: Θ(n)

Groups of 3

T(n/3) + T(2n/3) + Θ(n)

Sum: 1

Result: Θ(n lg n)

Groups of 7

T(n/7) + T(5n/7) + Θ(n)

Sum: 6/7 < 1

Result: Θ(n)

Exam Tip: Groups of 3 is the counterexample: n/3 + 2n/3 = 1 → Θ(n lg n). If sum < 1 → Θ(n).

Time Complexity Analysis

Recurrence:
T(n) = T(n/5) + T(7n/10) + Θ(n)
T(n/5) = median of medians, T(7n/10) = larger partition, Θ(n) = partition
Solution:
T(n) = Θ(n)
1/5 + 7/10 = 9/10 < 1 → Master Theorem solves to linear
