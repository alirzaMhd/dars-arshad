What is a Rooted Tree?

A rooted tree is a connected acyclic graph with one designated node called the root. The root has no parent, and all other nodes have exactly one parent.

Formal Definition:
T = (V, E, r)
A rooted tree consists of vertices V, edges E, and a distinguished root node r ∈ V. Connected and acyclic.
a ← Root (no parent) /|\ b c d ← Children of a /| | e f g ← Grandchildren | h | k ← Leaf (no children)

Depth and Height

Depth of a Node:
depth(v) = length of path from root to v
Number of edges from root to node v. Root has depth 0.
Height of a Node:
height(v) = longest path from v to any leaf
Maximum distance to a descendant leaf. Leaves have height 0.
Height of a Tree:
height(T) = height(root) = max(depth of all nodes)
Tree height = root height = maximum depth among all nodes.
Warning: Some textbooks define leaf height as 1 instead of 0. Check your course convention!
Example: Depth and Height
a (depth=0, height=3) /|\ b c d (d: depth=1, height=2) /| | e f g (g: depth=2, height=0) | \ h (f: depth=2, height=1) | k (k: depth=3, height=0)

Tree height = 3

Properties of Rooted Trees

Edge-Vertex Relationship:
e = n - 1
A tree with n nodes has exactly n-1 edges.
Level Counting (k-ary tree):
At level i, maximum k^i nodes
Level 0: 1 node, Level 1: at most k nodes, Level 2: at most k^2 nodes, etc.
Example: 3-ary Tree with 4 Levels

Level 0

1 node

Level 1

3 nodes

Level 2

9 nodes

Level 3

27 nodes

Total: 1+3+9+27 = 40. Leaves: 27. Internal: 13.

General k-ary with x Levels
Max Nodes:
n = (k^x - 1)/(k - 1)
Max Leaves:
leaves = k^(x-1)
Max Internal:
internal = (k^(x-1) - 1)/(k - 1)

Key Relationship: n₀ = n₂ + 1

Node Degree Relationship (Binary Trees):
n₀ = n₂ + 1
Leaves = nodes with 2 children + 1. Holds for ALL binary trees.
Proof

Let n = n₀ + n₁ + n₂. Edges e = n - 1. Also e = n₁ + 2n₂. Substituting: n₀ + n₁ + n₂ - 1 = n₁ + 2n₂ → n₀ = n₂ + 1.

k-ary Trees

A k-ary tree is a rooted tree where every node has at most k children.

TypekMax Children
Binary22
Ternary33
k-arykk
Max Nodes (height h):
n_max = (k^(h+1) - 1)/(k - 1)
Sum of geometric series: 1 + k + k^2 + ... + k^h
Max Leaves:
leaves_max = k^h
Max Internal:
internal_max = (k^h - 1)/(k - 1)
A tree of height h has h+1 levels (0 through h).

Minimum Height & Full k-ary Trees

Minimum Height for n nodes:
h_min = ⌈log_k(n(k-1) + 1)⌉ - 1
Minimum Levels for 1000 Nodes in 3-ary Tree

Need (3^x - 1)/2 ≥ 1000 → 3^x ≥ 2001. Since 3^6=729, 3^7=2187, x ≥ 7. Minimum levels = 7 (height=6).

Full k-ary Tree

Every internal node has exactly k children.

Properties:
Internal = (k^h - 1)/(k - 1), Leaves = k^h

Worked Examples

Example 1: Basic Terminology

Root: a. Leaves: {c,e,f,g,i,j}. Internal: {a,b,d,h}.

Depth a=0, b=1, e=2, i=3. Height a=3, b=2, d=2, f=1, h=1.

Example 2: Full Binary Tree Height 4

n = (2^5 - 1)/(2-1) = 31 nodes. Leaves = 16. Internal = 15.

Example 3: Min Height for 25 Nodes

Need 2^(h+1) - 1 ≥ 25 → h=4. Levels: 1+2+4+8=15, remaining 10 at level 4.

Example 4: Using n₀ = n₂ + 1

10 nodes with 2 children → leaves = 10 + 1 = 11.

Example 5: Min Nodes Height 5

Skewed tree: n_min = h + 1 = 6.

Example 6: Degree Count in 3-ary Tree

29 nodes: 4 leaves, 3 degree-3, 2 degree-2. n₁ = 29 - 4 - 2 - 3 = 20.

Example 7: Full 7-ary Tree Leaves

279,936 leaves → 7^m = 279,936 → m=6. Internal = (7^6-1)/6 = 46,655.
