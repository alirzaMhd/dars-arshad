What is an Expression Tree?

An expression tree is a binary tree representing a mathematical expression. Operators are internal nodes, operands are leaf nodes.

Structure Rule:
Internal nodes = operators, Leaf nodes = operands/constants
Unary operators have one child; binary operators have two children.
Example: a + b
+ / \ a b
Example: (a + b) × (c - d)
* / \ + - / \ / \ a b c d

Building Expression Trees

Algorithm (from infix):
1. Find operator with LOWEST precedence
2. Make it the root
3. Recursively build left subtree
4. Recursively build right subtree
Parentheses have highest precedence — evaluate inside first.
Example: (a - b) + (c × (d / e))

Step 1: '+' has lowest precedence → root

Step 2: Left subtree: (a - b), Right subtree: (c × (d / e))

+ / \ - * / \ / \ a b c / / \ d e

Build from Postfix

Algorithm: 1. Create empty stack 2. For each symbol in postfix: a. If operand: create node, push b. If operator: - pop right operand - pop left operand - create operator node - push node 3. Stack top = root

Expression Tree Traversals

Key Relationship:
Preorder = Prefix | Inorder = Infix | Postorder = Postfix
Example: + - a b × c d
+ / \ - * / \ / \ a b c d

Preorder: + - a b × c d → Prefix: + - a b × c d

Inorder: a - b + c × d → Infix: a - b + c × d

Postorder: a b - c d × + → Postfix: a b - c d × +

Operator Precedence

When building expression trees, operator precedence determines the tree structure. Lower precedence operators appear higher in the tree (closer to root).

PrecedenceOperatorsTree Position
1 (Highest)()Deepest
2^ (power)Lower
3× /Middle
4 (Lowest)+ -Root area
Building Rule:
Operator with LOWEST precedence becomes the ROOT
This ensures correct evaluation order.
Example: a × b + c / d - e

'-' has lowest precedence → root

- / \ + e / \ * / / \ / \ a b c d

Prefix: - + × a b / c d e

Postfix: a b × c d / + e -

Worked Examples

Example 1: Build from Infix

Build expression tree for: (a + b) × (c - d) / e

/ / \ * e / \ + - / \ / \ a b c d

Prefix: / × + a b - c d e

Postfix: a b + c d - × e /

Example 2: Build from Postfix

Postfix: a b + c d - ×

1. Push a, Push b

2. Read '+': pop b, a → create '+' node, push

3. Push c, Push d

4. Read '-': pop d, c → create '-' node, push

5. Read '×': pop '-', '+' → create '×' node, push

* / \ + - / \ / \ a b c d

Infix: (a + b) × (c - d)

Example 3: Evaluate Tree

Evaluate tree for: + - 3 1 × 2 4

+ / \ - * / \ / \ 3 1 2 4

Left: 3 - 1 = 2

Right: 2 × 4 = 8

Root: 2 + 8 = 10

Example 4: Unary Operator

Expression: a × (-b + c)

* / \ a + / \ - c | b

'-' node has only one child (b) — unary operator.
