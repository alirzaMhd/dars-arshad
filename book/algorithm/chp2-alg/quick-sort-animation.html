Quick Sort Algorithm

A divide-and-conquer algorithm that uses partitioning to sort elements. Picks a pivot, partitions around it, then recursively sorts the two partitions.

Pseudocode

quicksort(A[L..U]) { if (L < U) { // Step 1: Partition around pivot j = partition(A[L..U]); // Step 2: Sort left partition quicksort(A[L..j-1]); // Step 3: Sort right partition quicksort(A[j+1..U]); } }
Recurrence Relation:
T(n) = T(k) + T(n-k-1) + Θ(n)
k = number of elements in left partition, Θ(n) = partition time

The Partition Operation

Partitions the array around a pivot element. After partitioning, all elements ≤ pivot are on the left, and all elements > pivot are on the right.

Lomuto Partition Scheme

partition(A[L..U]) { pivot = A[L]; i = L; for (j = L+1 to U) { if (A[j] ≤ pivot) { i++; swap(A[i], A[j]); } } swap(A[L], A[i]); return i; }

Partition Example

Partition A = [3, 8, 2, 5, 1, 4, 7, 6] with pivot = 3

Initial: [3, 8, 2, 5, 1, 4, 7, 6], pivot = 3, i = 0

j=1: 8 > 3, skip

j=2: 2 ≤ 3, i=1, swap A[1] and A[2] → [3, 2, 8, 5, 1, 4, 7, 6]

j=3: 5 > 3, skip

j=4: 1 ≤ 3, i=2, swap A[2] and A[4] → [3, 2, 1, 5, 8, 4, 7, 6]

Final swap: swap A[0] and A[2] → [1, 2, 3, 5, 8, 4, 7, 6]

Return j = 2 (pivot position)

Worked Examples

Example 1: Sort A = [10, 80, 30, 90, 40, 50, 70]

Step 1: Partition around 10 → [10, 80, 30, 90, 40, 50, 70]

Step 2: Partition left of 10 (empty)

Step 3: Partition right of 10 → [80, 30, 90, 40, 50, 70]

Continue until fully sorted: [10, 30, 40, 50, 70, 80, 90]

Example 2: Worst Case - Already Sorted Array

A = [1, 2, 3, 4, 5], pivot = first element

Each partition produces empty left and right subarray of size n-1

Total comparisons: 4+3+2+1 = 10 = n(n-1)/2

This is Θ(n²) — worst case!

Example 3: Best Case - Balanced Partition

A = [4, 2, 6, 1, 3, 5], pivot divides evenly

Each partition roughly halves the problem

Depth of recursion: lg n. Work at each level: n

Total: Θ(n lg n)

Quick Sort Variants

1. Randomized Quick Sort

Choose pivot randomly from the subarray. Expected time is always Θ(n lg n) regardless of input. By selecting the pivot uniformly at random from the subarray, no single input can guarantee worst-case behavior.

2. Median-of-Three

Choose pivot as median of first, middle, and last elements. Avoids worst case for sorted inputs.

3. Three-Way Partition

Handles duplicate elements efficiently. Partitions into three parts: less than, equal to, and greater than pivot.

Key Points:

• Quick Sort is in-place (O(lg n) stack space)

• Quick Sort is NOT stable

• In practice, Quick Sort is often faster than Merge Sort

• Maximum comparisons: n(n-1)/2 (worst case)

Average Case Derivation — Step-by-Step

All n Possible Cases (k = 0 to n-1)

After partitioning, let k be the number of elements in the left partition.

Recurrence for each case:
T(n) = T(k) + T(n-k-1) + (n-1)

Step 1: Sum Over All Cases

Sum of all n recurrences:
n·T(n) = Σ(T(k) + T(n-k-1) + n-1) for k=0 to n-1
Simplify symmetric sums:
n·T(n) = 2·Σ(T(k)) + n(n-1)

Step 2: Eliminate the Summation

Write the same equation for (n-1) and subtract:

Subtract (n-1) equation:
n·T(n) - (n-1)·T(n-1) = 2·T(n-1) + 2(n-1)

Step 3: Simplify

Non-summation recurrence:
n·T(n) = (n+1)·T(n-1) + 2(n-1)

Step 4: Substitution a_n = T(n)/(n+1)

Divide by n(n+1):
a_n = a_(n-1) + 2(n-1)/(n(n+1)) ≈ a_(n-1) + 2/(n+1)

Step 5: Telescoping

Telescoping sum:
a_n ≈ 2·(H_(n+1) - 1)
Where H_n is the nth harmonic number ≈ ln(n) + γ

Step 6: Back-Substitute

Final Result:
T(n) = 2(n+1)·H_n - 4n ≈ 2n·ln(n) = Θ(n lg n)
