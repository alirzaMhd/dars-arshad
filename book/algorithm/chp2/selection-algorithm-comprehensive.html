Selection Algorithm (Select)

Algorithm Design — Complete Guide for 20/20 Exam

What is the Selection Problem?

Given an array A of n elements, find the k-th smallest element (k-th order statistic).

Problem Statement:
Find the k-th minimum in array A[1..n]
k is the rank we're looking for (1 ≤ k ≤ n)

Special Cases

• k = 1: Find minimum

• k = n: Find maximum

• k = ⌈n/2⌉: Find median

Naive Approach

• Sort the array first

• Return A[k]

Time: O(n lg n)

The Select Algorithm

A divide-and-conquer algorithm that finds the k-th smallest element in Θ(n) time.

sel(A[L..u], k)
{
  n = u - L + 1;
  if (n ≤ 25) use brute force!
  else {
    m = ⌈n/5⌉; B[1..m]
    // Step 1: Find medians of groups of 5
    for (i = 1 to m)
      B[i] = sel(A[5i-4 .. 5i], 3);
    // Step 2: Find median of medians
    x = sel(B[1..m], ⌈m/2⌉)
    // Step 3: Partition around x
    j = partition(A[L..u], x)
    // Step 4: Recurse on appropriate side
    if (k < j) return sel(A[L..j-1], k)
    else if (k = j) return A[j]
    else return sel(A[j+1..u], k-j)
  }
}
Key Insight: The threshold of 25 is used because for small n, brute force is more efficient. The constant factors in the recursive algorithm make it impractical for small arrays.

Median of Medians Analysis

Step 1: Divide into groups of 5

Array A is divided into ⌈n/5⌉ groups, each containing 5 elements (except possibly the last).

Time: Θ(n) - we simply scan through the array

Step 2: Find median of each group

For each group of 5, find the median using any method (sorting 5 elements takes Θ(1)).

Store medians in array B[1..m] where m = ⌈n/5⌉

Step 3: Recursively find median of B

Call sel(B[1..m], ⌈m/2⌉) to find the median of medians, call it x.

Recurrence for Step 2:
T(n/5)
Finding median of ⌈n/5⌉ medians

Step 4: Partition and recurse

The median of medians x guarantees that at least 3n/10 elements are ≤ x and at least 3n/10 elements are ≥ x.

Worst case for Step 4:
T(7n/10)
At most 7n/10 elements on one side of x
Why 3n/10? Half of the ⌈n/5⌉ medians are ≤ x. Each such median has 2 elements ≤ it in its group. So at least ⌈n/10⌉ × 3 = 3n/10 elements are ≤ x.

Worked Examples

Example 1: Find 3rd smallest in A = [19, 5, 1, 11, 15, 26, 59, 61, 48, 37]

n = 10, k = 3

Groups of 5: [19, 5, 1, 11, 15] and [26, 59, 61, 48, 37]

Medians: 11 and 48 → B = [11, 48]

Median of medians: x = 11

Partition around 11: [5, 1, 11, 19, 15, 26, 59, 61, 48, 37]

j = 3 (11 is at position 3)

Since k = j = 3, return A[3] = 11

Example 2: Find 5th smallest in A = [3, 1, 4, 1, 5, 9, 2, 6]

n = 8, k = 5

Groups of 5: [3, 1, 4, 1, 5] and [9, 2, 6]

Medians: 3 and 6 → B = [3, 6]

Median of medians: x = 3

Partition around 3: [1, 1, 2, 3, 4, 5, 9, 6]

j = 4 (3 is at position 4)

k > j, so recurse on right: sel([4, 5, 9, 6], 5-4) = sel([4, 5, 9, 6], 1)

Result: 4

Example 3: Find minimum (k=1)

For k=1, we can use the same algorithm or simply scan the array.

Minimum comparisons needed: n - 1

This is optimal - every element except one must be compared.

Example 4: Find median of [7, 10, 4, 3, 20, 15]

n = 6, k = 3 (or 4 for upper median)

Sorted: [3, 4, 7, 10, 15, 20]

Median = (7 + 10)/2 = 8.5

For lower median (k=3): 7

Time Complexity Analysis

Recurrence Relation:
T(n) = T(n/5) + T(7n/10) + Θ(n)
T(n/5) = find median of medians, T(7n/10) = recurse on larger part, Θ(n) = partition
Solution:
T(n) = Θ(n)
Since 1/5 + 7/10 = 9/10 < 1, the recurrence solves to linear time

Best Case

Time: Θ(n)

When partition is balanced

Average Case

Time: Θ(n)

Same as worst case!

Worst Case

Time: Θ(n)

Guaranteed linear

Space

Space: O(lg n)

Recursion stack depth

Comparison with Other Methods

Method Best Average Worst
Sort then select Θ(n lg n) Θ(n lg n) Θ(n lg n)
Naive partition Θ(n) Θ(n²) Θ(n²)
Select (median of medians) Θ(n) Θ(n) Θ(n)
Key Point: The Select algorithm is optimal for worst-case selection. No comparison-based algorithm can do better than Θ(n) in the worst case.
