Selection Algorithm (Select)

Algorithm Design — Complete Guide for 20/20 Exam

What is the Selection Problem?

Given an array A of n elements, find the k-th smallest element (k-th order statistic).

Problem Statement:
Find the k-th minimum in array A[1..n]
k is the rank we're looking for (1 ≤ k ≤ n)

Special Cases

• k = 1: Find minimum

• k = n: Find maximum

• k = ⌈n/2⌉: Find median

Naive Approach

• Sort the array first

• Return A[k]

Time: O(n lg n)

The Select Algorithm

A divide-and-conquer algorithm that finds the k-th smallest element in Θ(n) time.

sel(A[L..u], k)
{
  n = u - L + 1;
  if (n ≤ 25) use brute force!
  else {
    m = ⌈n/5⌉; B[1..m]
    /* Step 1: Find medians of groups of 5 */
    for (i = 1 to m)
      B[i] = sel(A[5i-4 .. 5i], 3);
    /* Step 2: Find median of medians */
    x = sel(B[1..m], ⌈m/2⌉);
    /* Step 3: Partition around x */
    j = partition(A[L..u], x);
    i = j - L + 1;
    /* Step 4: Check position and recurse */
    if (k == i) return A[j];
    else if (k < i) return sel(A[L..j-1], k);
    else return sel(A[j+1..u], k-i);
  }
}
Key Insight: The threshold of 25 is used because for small n, brute force is more efficient. The constant factors in the recursive algorithm make it impractical for small arrays.

Median of Medians Analysis

Step 1: Divide into groups of 5

Array A is divided into ⌈n/5⌉ groups, each containing 5 elements (except possibly the last).

Time: Θ(n) - we simply scan through the array

Step 2: Find median of each group

For each group of 5, find the median using any method (sorting 5 elements takes Θ(1)).

Store medians in array B[1..m] where m = ⌈n/5⌉

Step 3: Recursively find median of B

Call sel(B[1..m], ⌈m/2⌉) to find the median of medians, call it x.

Recurrence for Step 2:
T(n/5)
Finding median of ⌈n/5⌉ medians

Step 4: Partition and recurse

The median of medians x guarantees that at least 3n/10 elements are ≤ x and at least 3n/10 elements are ≥ x.

Worst case for Step 4:
T(7n/10)
At most 7n/10 elements on one side of x
Precise Recurrence (with boundary constants):
T(n) = T(⌈n/5⌉) + T(7n/10 + 6) + Θ(n)
The +6 accounts for the last group (may have <5 elements) and the group containing x, excluding at most 2 groups from the count.

Detailed 3n/10 Bound Derivation

Let's prove at least 3n/10 elements are ≤ x (the median of medians):

Step-by-step bound proof:

1. There are ⌈n/5⌉ groups → ⌈n/5⌉ medians in array B.

2. x = sel(B[1..m], ⌈m/2⌉) → x is the median of B → at least ⌈m/2⌉ = ⌈⌈n/5⌉/2⌉ = ⌈n/10⌉ medians are ≤ x.

3. Each median is the 3rd smallest in its group of 5 → there are 2 elements in each such group that are ≤ that median (hence ≤ x).

4. Total elements ≤ x ≥ 3 × ⌈n/10⌉ ≥ 3n/10.

5. By symmetry, at least 3n/10 elements are ≥ x.

6. Therefore x has rank between 3n/10 and 7n/10 → the larger side has at most 7n/10 elements.

Precise Bound (with group edge cases)

For a tighter analysis considering edge cases (the last group may have fewer than 5 elements, and one group contains x itself):

Refined counting:

• ⌈n/5⌉ medians are found in Step 1.

• Excluding the last group (possible deficit) and the group containing x → at least ⌈n/10⌉ − 2 groups contribute fully.

• In each such group, 3 elements are ≤ x (the median + 2 smaller elements).

• So at least 3(⌈n/10⌉ − 2) ≥ 3n/10 − 6 elements are ≤ x.

• Hence at most n − (3n/10 − 6) = 7n/10 + 6 elements are on the larger side.

• This yields the recurrence: T(n) = T(⌈n/5⌉) + T(7n/10 + 6) + Θ(n)

Key Point: The bound 3n/10 comes from: ⌈n/10⌉ medians ≤ x, each contributes 3 elements (median + 2 smaller) → 3⌈n/10⌉ ≥ 3n/10.

Worked Examples

Example 1: Find 3rd smallest in A = [19, 5, 1, 11, 15, 26, 59, 61, 48, 37]

n = 10, k = 3

Groups of 5: [19, 5, 1, 11, 15] and [26, 59, 61, 48, 37]

Medians: 11 and 48 → B = [11, 48]

Median of medians: x = 11

Partition around 11: [5, 1, 11, 19, 15, 26, 59, 61, 48, 37]

j = 3 (11 is at position 3)

Since k = j = 3, return A[3] = 11

Example 2: Find 5th smallest in A = [3, 1, 4, 1, 5, 9, 2, 6]

n = 8, k = 5

Groups of 5: [3, 1, 4, 1, 5] and [9, 2, 6]

Medians: 3 and 6 → B = [3, 6]

Median of medians: x = 3

Partition around 3: [1, 1, 2, 3, 4, 5, 9, 6]

j = 4 (3 is at position 4)

k > j, so recurse on right: sel([4, 5, 9, 6], 5-4) = sel([4, 5, 9, 6], 1)

Result: 4

Example 3: Find minimum (k=1)

For k=1, we can use the same algorithm or simply scan the array.

Minimum comparisons needed: n - 1

This is optimal - every element except one must be compared.

Example 4: Find median of [7, 10, 4, 3, 20, 15]

n = 6, k = 3 (or 4 for upper median)

Sorted: [3, 4, 7, 10, 15, 20]

Median = (7 + 10)/2 = 8.5

For lower median (k=3): 7

Example 5: Partition with pivot = 26 — A = [26, 5, 37, 1, 61, 11, 59, 15, 48, 19]

n = 10. Pivot = A[1] = 26, j = 1 initially.

i scans from 2 to 10, stopping on elements smaller than 26: 5 (i=2), 1 (i=4), 11 (i=6), 15 (i=8), 19 (i=10).

Each time i stops, j increments and swap(A[i], A[j]) is executed.

After loop: swap(A[1], A[6]) → pivot placed at position 6.

Result: [19, 5, 1, 11, 15, 26, 59, 61, 48, 37] — pivot=26 is the 6th smallest.

If k=6: return 26. If k<6: recurse left. If k>6: recurse right with k-6.

Example 6: What if we use groups of 3 instead of 5?

Given n = 12, find the 8th smallest in A = [35, 12, 8, 27, 3, 42, 19, 5, 30, 15, 22, 10] using groups of 3.

Groups: [35,12,8]→8, [27,3,42]→27, [19,5,30]→19, [15,22,10]→15

Medians B = [8, 27, 19, 15] → median of medians x = sel(B, 2) = 15

Partition around 15: [12, 8, 3, 5, 10, 15, 35, 27, 42, 19, 30, 22]

j = 6 (15 at position 6). k = 8 > 6 → recurse right on [35,27,42,19,30,22] with k = 8-6 = 2.

Groups of 3 on right: [35,27,42]→35, [19,30,22]→22 → medians [35,22], x = 22

Partition around 22: [19, 22, 42, 35, 30] → j = 2. k = 2 == j → return 22.

Time Complexity Analysis

Recurrence Relation:
T(n) = T(n/5) + T(7n/10) + Θ(n)
T(n/5) = find median of medians, T(7n/10) = recurse on larger part, Θ(n) = partition
Solution:
T(n) = Θ(n)
Since 1/5 + 7/10 = 9/10 < 1, the recurrence solves to linear time

Best Case

Time: Θ(n)

When partition is balanced

Average Case

Time: Θ(n)

Same as worst case!

Worst Case

Time: Θ(n)

Guaranteed linear

Space

Space: O(lg n)

Recursion stack depth

Comparison with Other Methods

Method Best Average Worst
Sort then select Θ(n lg n) Θ(n lg n) Θ(n lg n)
Naive partition Θ(n) Θ(n²) Θ(n²)
Select (median of medians) Θ(n) Θ(n) Θ(n)
Key Point: The Select algorithm is optimal for worst-case selection. No comparison-based algorithm can do better than Θ(n) in the worst case.

Analysis with Groups of 3 (Instead of 5)

An important exam question: what if we divide into groups of 3 instead of groups of 5? This changes the recurrence from Θ(n) to Θ(n lg n).

Recurrence with Groups of 3:
T(n) = T(n/3) + T(2n/3) + Θ(n)
T(n/3) = find median of ⌈n/3⌉ medians, T(2n/3) = worst-case size of larger partition side
Solution:
T(n) = Θ(n lg n)
Since n/3 + 2n/3 = 1, the recurrence falls into Case 2 of the Master Theorem: Θ(n lg n)

Why Groups of 5 but Not 3?

Groups of 5

Recurrence: T(n/5) + T(7n/10) + Θ(n)

Sum: 1/5 + 7/10 = 9/10 < 1

Result: Θ(n)

Linear time guaranteed

Groups of 3

Recurrence: T(n/3) + T(2n/3) + Θ(n)

Sum: 1/3 + 2/3 = 1

Result: Θ(n lg n)

No better than sorting!

Groups of 7

Recurrence: T(n/7) + T(5n/7) + Θ(n)

Sum: 1/7 + 5/7 = 6/7 < 1

Result: Θ(n)

Also linear, but larger constants

Derivation of the 2n/3 Upper Bound

Bound analysis for groups of 3:

Step 1: Divide A into ⌈n/3⌉ groups, each containing at most 3 elements. Find the median of each group (2nd smallest). Time: Θ(n).

Step 2: Recursively find the median x of the ⌈n/3⌉ medians. Time: T(⌈n/3⌉).

Step 3: Partition A around x. Time: Θ(n).

Step 4: Recurse on appropriate side.

— Half of the ⌈n/3⌉ medians are ≤ x → at least ⌈n/6⌉ medians.

— Each median of 3 has 1 element smaller than it in its group.

— So at least 2 × ⌈n/6⌉ ≥ n/3 elements are ≤ x.

— Hence at most n − n/3 = 2n/3 elements are on the larger side.

— Worst-case recurrence: T(n) = T(n/3) + T(2n/3) + Θ(n)

Why 3 Groups are Insufficient for Linearity

Master Theorem Analysis: For T(n) = T(αn) + T(βn) + Θ(n) with α + β = 1, the solution is Θ(n lg n). Only when α + β < 1 do we get Θ(n). Groups of 5 give α = 1/5, β = 7/10, sum = 9/10 < 1. Groups of 3 give α = 1/3, β = 2/3, sum = 1 → Θ(n lg n).

Worked Example with Groups of 3

Full trace: n = 9, find 5th smallest in A = [29, 14, 3, 42, 7, 21, 35, 18, 11]

Level 1: Groups of 3 → [29,14,3] median=14, [42,7,21] median=21, [35,18,11] median=18

B = [14, 21, 18], m = 3. sel(B, 2) → groups of 3 → [14,21] median=21 (or [14,21,18] median=18). x = 18.

Partition around 18: [14, 3, 7, 11, 18, 29, 42, 21, 35] → j = 5. k = 5 → return 18.

Lucky case: balanced partition found answer immediately.

Worst-case scenario: If k=9 (maximum), after partition the right side has 4 elements [29,42,21,35]. Groups of 3: [29,42,21]→29, [35]→35. Medians [29,35], x=29. Partition right around 29: [21, 29, 42, 35] → j=2. k−5=4 > 2 → recurse right on [42,35] with k=4−2=2. This gives T(9) = T(3) + T(6) + Θ(9), illustrating the Θ(n lg n) behavior.
