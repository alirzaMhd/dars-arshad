Finding Index where A[i] = i

Given an array A[1..n] with distinct integers, find an index i such that A[i] = i, if it exists.

Problem Statement:
Find i such that A[i] = i
Array must contain distinct integers

Key Insight

• If A[mid] = mid: found!

• If A[mid] < mid: search left half

• If A[mid] > mid: search right half

• Works because elements are distinct

Why It Works

• Distinct elements ensure monotonic behavior

• If A[mid] < mid: all left elements < their indices

• If A[mid] > mid: all right elements > their indices

⚠ Important: This algorithm only works with DISTINCT elements! If duplicates exist, the logic breaks down.

Algorithm

Algorithm Pseudocode:
find_index_equal_value(L, U) { if (L > U) return NIL mid = ⌊(L + U) / 2⌋ if (A[mid] == mid) return mid if (A[mid] < mid) return find_index_equal_value(mid + 1, U) else return find_index_equal_value(L, mid - 1) }
Binary search based on comparison of A[mid] with mid

Decision Logic

1. Calculate mid = ⌊(L+U)/2⌋

2. If A[mid] == mid: Found!

3. If A[mid] < mid: search right [mid+1..U]

4. If A[mid] > mid: search left [L..mid-1]

Recursive vs Iterative

• Recursive: cleaner code, O(log n) stack space

• Iterative: more efficient, O(1) space

• Both have same time complexity

Worked Examples

Example 1: Find i where A[i] = i

Array: [-2, -1, 0, 3, 5, 7, 9]

Step 1: L=1, U=7, mid=4, A[4]=3, 3 < 4 → search right

Step 2: L=5, U=7, mid=6, A[6]=7, 7 > 6 → search left

Step 3: L=5, U=5, mid=5, A[5]=5 → Found at index 5!

Example 2: No such index exists

Array: [1, 2, 3, 4, 5]

Step 1: L=1, U=5, mid=3, A[3]=3 → Found at index 3!

Wait, let's try a different array: [2, 3, 4, 5, 6]

Step 1: L=1, U=5, mid=3, A[3]=4, 4 > 3 → search left

Step 2: L=1, U=2, mid=1, A[1]=2, 2 > 1 → search left

Step 3: L=1, U=0 → Not found (NIL)

Example 3: Multiple possible indices

Array: [-5, -2, 0, 2, 4, 6, 8]

Step 1: L=1, U=7, mid=4, A[4]=2, 2 < 4 → search right

Step 2: L=5, U=7, mid=6, A[6]=6 → Found at index 6!

Note: Index 3 also works (A[3]=0), but algorithm finds index 6 first

Example 4: Negative numbers

Array: [-10, -5, -2, 0, 3, 7, 10]

Step 1: L=1, U=7, mid=4, A[4]=0, 0 < 4 → search right

Step 2: L=5, U=7, mid=6, A[6]=7, 7 > 6 → search left

Step 3: L=5, U=5, mid=5, A[5]=3, 3 < 5 → search right

Step 4: L=6, U=5 → Not found (NIL)

Time & Space Complexity

Time Complexity:
O(log n)
Standard binary search complexity
Space Complexity:
O(1) iterative, O(log n) recursive
Depends on implementation

Analysis

• Each step halves the search space

• Maximum depth = ⌊log₂ n⌋

• Each comparison is O(1)

Edge Cases

• Empty array: return NIL

• Single element: check if A[1] = 1

• No matching index: return NIL

⚠ Common Mistake: Forgetting that the array must have DISTINCT elements for this algorithm to work correctly!
