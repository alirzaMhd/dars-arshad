Chapter 5 Summary

Statistical Orders and Sorting — Complete Reference

Finding k-th Element

Finding min or max:
Θ(n)
Linear scan, n-1 comparisons
Finding min AND max together:
⌈3n/2⌉ - 2 comparisons
Pairwise comparison
Finding 2nd smallest:
n + ⌈lg n⌉ - 2 comparisons
Minimum possible
Finding k-th smallest:
Θ(n) with Select algorithm
Using median of medians
Key Formulas:

• Min/Max: n - 1 comparisons

• Min AND Max: ⌈3n/2⌉ - 2 comparisons

• 2nd smallest: n + ⌈lg n⌉ - 2 comparisons

• k-th smallest: Θ(n) worst case

Non-Comparison Sorts

Can beat Ω(n lg n) by not using comparisons

Algorithm Time Space Constraint
Counting Sort Θ(n + k) O(n + k) Integers in [1..k]
Radix Sort Θ(d(n + r)) O(n + r) d digits, base r

Comparison-Based Sorts Details

Merge Sort

T(n) = 2T(n/2) + Θ(n) = Θ(n lg n)
Divide and conquer, stable, not in-place

Quick Sort

Worst: Θ(n²), Average: Θ(n lg n)
In-place, not stable, fast in practice

Heap Sort

T(n) = Θ(n lg n) always
In-place, not stable, guaranteed performance

Decision Tree Lower Bound

h ≥ ⌈lg(n!)⌉ = Ω(n lg n)
Proves comparison sorts cannot do better
Key Points:

• Maximum comparisons for Bubble/Insertion/Quick: n(n-1)/2

• Maximum comparisons for Selection: n(n-1)/2 (always)

• Maximum swaps for Selection: n-1 (always)

• Maximum swaps for Bubble/Insertion: n(n-1)/2

Non-Comparison Sorts Details

Counting Sort

Time: Θ(n + k), Space: O(n + k)
Stable, works for integers in [1..k]

Radix Sort

Time: Θ(d(n + r)), Space: O(n + r)
Stable, processes d digits in base r

Bucket Sort

Average: Θ(n), Worst: Θ(n²)
Stable, works for uniform distributions
When to Use:

• Counting Sort: Small range k = O(n)

• Radix Sort: Large range, bounded digits

• Bucket Sort: Uniform distribution in [0, 1)

Optimal Base for Radix Sort

r = n is often optimal
Then d = ⌈log_n(max)⌉ and time = O(dn)
