MULTIPLEXING TECHNIQUES

Physical Layer — Complete Guide for Exam

What is Multiplexing?

Multiplexing is the technique of combining multiple signals or data streams into a single shared communication channel, then separating them at the receiving end (demultiplexing). This allows multiple users or connections to share the same physical medium simultaneously.

Core Concept:
Many signals → Shared Channel → Separate signals
Multiplexing maximizes the utilization of expensive communication links by allowing multiple transmissions over one wire, fiber, or wireless channel.

Why Multiplexing?

Problem Without Multiplexing:

If 10 users each need a dedicated channel, you need 10 separate physical links — extremely expensive and wasteful.

Solution With Multiplexing:

All 10 users share ONE physical link. Each user gets a portion of the channel's capacity. Cost is shared, link utilization increases dramatically.

Multiplexing vs Demultiplexing

Sender A ─┐ Sender B ─┤ Sender C ─┼──► [ MULTIPLEXER ] ═══ Shared Channel ═══ [ DEMULTIPLEXER ] ──┼──► Receiver A Sender D ─┘ │ ├──► Receiver B [ MUX combines ] ├──► Receiver C [ signals together] └──► Receiver D

MUX = Multiplexer (sender side) | DEMUX = Demultiplexer (receiver side)

FDM = Analog multiplexing (divides frequency). TDM = Digital multiplexing (divides time). WDM = Optical version of FDM (divides light wavelengths). STDM = Smart version of TDM (allocates slots on demand).

FDM — Frequency Division Multiplexing

FDM divides the available bandwidth into multiple non-overlapping frequency bands. Each signal is assigned its own frequency band (channel), and all signals are transmitted simultaneously on the same medium.

How FDM Works:
Total Bandwidth = BW₁ + BW₂ + BW₃ + ... + Guard Bands
Each channel gets a fraction of the total bandwidth. Guard bands separate channels to prevent crosstalk.

FDM: Each signal occupies a different frequency band

FDM — Key Properties

  • Each signal uses a different carrier frequency
  • All signals are transmitted simultaneously (in parallel)
  • Guard bands are placed between channels to prevent interference
  • Requires modulation to shift each signal to its assigned frequency band
  • Works with analog signals primarily
  • Guard bands waste some bandwidth

FDM — Real-World Applications

Radio Broadcasting

• Each radio station broadcasts on a different frequency

• FM: 88-108 MHz range

• Each station gets ~200 KHz band

Television

• Each TV channel uses a different frequency band

• 6 MHz per channel (analog TV)

ADSL

• Phone + Internet on same copper wire

• Voice: 0-4 KHz

• Data: 25 KHz - 1.1 MHz

Cable TV

• Multiple TV channels on one coaxial cable

• Each channel at a different frequency

FDM — Advantages & Disadvantages

Advantages

  • Simple concept and implementation
  • No synchronization needed
  • Multiple signals transmitted simultaneously
  • Well-established technology

Disadvantages

  • Guard bands waste bandwidth
  • Crosstalk between adjacent channels
  • Requires analog components (modulators)
  • Inflexible — fixed bandwidth allocation

WDM — Wavelength Division Multiplexing

WDM is essentially FDM applied to fiber optic cables. Instead of different electrical frequencies, it uses different wavelengths (colors) of light to carry multiple signals simultaneously through a single optical fiber.

WDM Concept:
1 Fiber = λ₁ + λ₂ + λ₃ + ... + λₙ (multiple light wavelengths)
Each wavelength carries an independent data stream. A prism or diffraction grating combines/separates them.

WDM — How It Works

Light Source 1 (λ₁ = 1310nm) ──┐ Light Source 2 (λ₂ = 1550nm) ──┼──► [ COMBINER ] ═══ Fiber ═══ [ SPLITTER ] ──┼──► Detector 1 (λ₁) Light Source 3 (λ₃ = 1490nm) ──┘ │ ├──► Detector 2 (λ₂) MUX └──► Detector 3 (λ₃) DEMUX

WDM: Multiple light wavelengths share one fiber

⚠ Key Point for Exam:

WDM is NOT a separate technique — it is FDM applied to optical fiber. The only difference is the medium (light vs electrical) and the unit of division (wavelength vs frequency). DWDM can carry terabits per second on a single fiber.

TDM — Time Division Multiplexing

TDM divides the channel by time rather than frequency. Each signal gets the full bandwidth of the channel, but only for a specific time slot. Signals take turns transmitting in a round-robin fashion.

TDM Concept:
Frame = Slot₁ + Slot₂ + Slot₃ + ... + Slotₙ
One complete cycle (frame) contains one time slot per signal. The frame repeats continuously.

TDM — How It Works

Time ──────────────────────────────────────────────────────► ┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐ │ Slot 1 │ Slot 2 │ Slot 3 │ Slot 4 │ Slot 1 │ Slot 2 │ ... │ User A │ User B │ User C │ User D │ User A │ User B │ └──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘ ├──────────────── Frame 1 ──────────────┼──────── Frame 2 ──────────┤ Each user gets the FULL bandwidth but only during their time slot.

Synchronous TDM (Fixed TDM)

In Synchronous TDM, each time slot is pre-assigned to a specific user, regardless of whether the user has data to send. If a user has no data, the slot remains empty (wasted).

Characteristics of Synchronous TDM:
  • Fixed, pre-assigned time slots for each input
  • Round-robin allocation: A → B → C → D → A → B → ...
  • Slots can be wasted if a device has no data
  • Simple implementation — no addressing needed
  • Frame structure is predictable and constant

Synchronous TDM — Frame Structure

Frame Example (4 users): ┌─────────┬─────────┬─────────┬─────────┐ │ Data A │ Data B │ Data C │ Data D │ │ (8 bits)│ (8 bits)│ (8 bits)│ (8 bits)│ └─────────┴─────────┴─────────┴─────────┘ ├── Slot 1 ├── Slot 2 ├── Slot 3 ├── Slot 4 ├── Frame = 4 × 8 = 32 bits If User C has nothing to send: ┌─────────┬─────────┬─────────┬─────────┐ │ Data A │ Data B │ EMPTY │ Data D │ └─────────┴─────────┴─────────┴─────────┘ Wasted slot!

Statistical TDM (STDM) — Dynamic Allocation

STDM is a smarter version of TDM that allocates time slots dynamically based on demand. Slots are NOT pre-assigned — they are given only to devices that actually have data to send.

STDM Key Difference:
Slots = allocated on-demand (not pre-assigned)
STDM includes address/label information in each slot so the receiver knows which device sent the data. No slots are wasted on idle users.

STDM — How It Works

Users A, C have data; B, D are idle: Synchronous TDM (fixed): ┌─────────┬─────────┬─────────┬─────────┐ │ Data A │ EMPTY │ Data C │ EMPTY │ ← 50% wasted! └─────────┴─────────┴─────────┴─────────┘ Statistical TDM (dynamic): ┌───┬───────┬───┬───────┐ │ A │ Data A│ C │ Data C│ ← 0% wasted! └───┴───────┴───┴───────┘ Each slot includes [Address][Data] STDM uses smaller slots + addresses = higher efficiency

Worked Examples

Example 1: FDM — Calculate Available Channels

Problem: A cable TV system has a total bandwidth of 500 MHz. Each TV channel requires 6 MHz. How many channels can be supported if guard bands of 0.5 MHz are placed between each channel?

Solution:

Step 1: Each channel + guard band = 6 + 0.5 = 6.5 MHz

Step 2: Number of channels = 500 / 6.5

Channels = Total BW / (Channel BW + Guard Band)
Channels = 500 / 6.5 = 76 channels

Step 3: Verify: 76 × 6.5 = 494 MHz (6 MHz unused at edges)

⚠ Without guard bands: 500/6 = 83 channels. Guard bands reduce capacity by ~8%.
Example 2: Synchronous TDM — Frame Rate and Data Rate

Problem: 4 digital signals are multiplexed using synchronous TDM. Each signal has a data rate of 9.6 Kbps. Each time slot carries 1 bit from each signal.

Solution:

Step 1: Calculate the required output data rate:

Output Rate = Number of inputs × Input Rate
Output Rate = 4 × 9.6 = 38.4 Kbps

Step 2: Frame rate: Each input contributes 1 bit per frame, so:

Frame Rate = Input Data Rate / Bits per Slot
Frame Rate = 9,600 / 1 = 9,600 frames/second

Step 3: Each frame contains 4 bits (1 from each input).

Verify: 9,600 frames/s × 4 bits/frame = 38,400 bps = 38.4 Kbps ✓

Example 3: STDM — Efficiency Calculation

Problem: A statistical TDM multiplexer serves 8 terminals. On average, only 3 terminals are active at any time. Each terminal generates data at 1200 bps. Each STDM slot includes a 3-bit address plus 8 bits of data.

Solution:

Step 1: Total data rate needed by active users:

Active data = 3 × 1200 = 3,600 bps

Step 2: Total bits per slot = 3 (address) + 8 (data) = 11 bits

Step 3: Efficiency = data bits / total bits per slot:

Efficiency = Data bits / (Address + Data bits)
Efficiency = 8 / 11 = 72.7%

Compare: Synchronous TDM with 8 slots would waste 5/8 = 62.5% when only 3 are active. STDM is much more efficient here.

Example 4: WDM — Channel Capacity

Problem: A DWDM system operates in the C-band (1530-1565 nm). If each channel uses a wavelength spacing of 0.8 nm, how many channels can fit? Each channel carries 10 Gbps. What is the total capacity?

Solution:

Step 1: Available wavelength range:

Range = 1565 - 1530 = 35 nm

Step 2: Number of channels:

Channels = Range / Spacing
Channels = 35 / 0.8 = 43 channels

Step 3: Total capacity:

Total = Channels × Per-channel rate
Total = 43 × 10 Gbps = 430 Gbps

This is on a SINGLE fiber strand — incredible capacity from WDM!

Example 5: FDM vs TDM — Bandwidth Allocation

Problem: A shared link has a capacity of 1 Mbps. 5 users need to share it. Compare FDM allocation vs Synchronous TDM allocation for each user.

Solution:

FDM approach:

Each user's bandwidth = Total BW / Number of users
BW per user = 1,000,000 / 5 = 200 Kbps per user (all the time)

Synchronous TDM approach:

Each user gets full bandwidth for 1/5 of the time
Each user = 1 Mbps × (1/5) = 200 Kbps average
MethodInstantaneous RateAvailableLatency
FDM200 KbpsAlwaysLow
TDM1 Mbps (during slot)Only 1/5 of timeHigher (waiting for slot)
⚠ Both give the same average throughput (200 Kbps/user), but FDM provides constant low-rate access while TDM provides bursty high-rate access. Choice depends on traffic type.

Common Mistakes to Avoid

Mistake 1

Confusing FDM and TDM

FDM = frequency bands (parallel)

TDM = time slots (sequential)

Mistake 2

Forgetting guard bands in FDM

Always subtract guard band BW

when calculating available channels

Mistake 3

Sync TDM ≠ STDM

Sync TDM: fixed slots (may waste)

STDM: dynamic slots (needs addresses)

Mistake 4

WDM is not separate from FDM

WDM = FDM on optical fiber

Same principle, different medium
