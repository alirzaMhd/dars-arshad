MODULATION TECHNIQUES

Physical Layer — Complete Guide for Exam

What is Modulation?

Modulation is the process of encoding digital data onto an analog carrier signal for transmission over a physical medium. The carrier signal's properties (amplitude, frequency, or phase) are varied to represent binary data (0s and 1s).

Core Concept:
Digital Data → Modulate Carrier → Analog Signal → Transmit → Demodulate → Digital Data
Modulation converts discrete digital bits into continuous analog waveforms suitable for transmission.

Why Do We Need Modulation?

Antenna Size

• Baseband digital signals require impractically large antennas

• Modulated signals allow smaller antennas

• Antenna size ∝ wavelength = c / f

Multiplexing

• Multiple signals can share the same medium

• Each signal uses a different carrier frequency

• Enables FDM (Frequency Division Multiplexing)

Noise Immunity

• Higher frequency signals are less affected by noise

• Better signal-to-noise ratio

• Easier to filter out interference

Long Distance

• Baseband signals衰减 quickly

• Modulated signals travel farther

• Required for wireless communication

Digital-to-Analog Conversion

The process of converting digital data (bits) into analog signals (waveforms) is called Digital-to-Analog Conversion. This is the foundation of all modulation techniques.

Bit Rate vs Baud Rate

• Bit Rate = number of bits per second (bps)

• Baud Rate = number of signal changes per second (baud)

• Bit Rate = Baud Rate × bits per signal element

Key Relationship

• 1 bit per signal: Bit Rate = Baud Rate

• 2 bits per signal: Bit Rate = 2 × Baud Rate

• n bits per signal: Bit Rate = n × Baud Rate

Baud Rate Formula:
Baud Rate = Bit Rate / (bits per signal element)
Baud rate is always ≤ bit rate. Higher bits per signal = more efficient modulation.

ASK — Amplitude Shift Keying

In ASK, the amplitude of the carrier signal varies to represent binary data, while frequency and phase remain constant.

ASK Signal Representation:
Bit 1 → High amplitude (A₁), Bit 0 → Low amplitude (A₂) or Zero
Typically: A₁ = A (signal present), A₂ = 0 (no signal) or A₁ = 2A, A₂ = A

How ASK Works

Binary 1

• Carrier wave is transmitted

• Signal has amplitude A₁

• Waveform visible on oscilloscope

Binary 0

• No carrier transmitted (OOK)

• Signal has amplitude 0 or A₂

• Flat line or reduced wave

ASK Mathematical Form:
s(t) = A(t) × sin(2πft)
A(t) changes between two levels to encode 0 and 1. Frequency and phase are constant.

Characteristics of ASK

PropertyValue
Bits per signal1 bit
Baud Rate = Bit RateYes
Noise sensitivityHigh (amplitude affected by noise)
Bandwidth efficiencyLow
ComplexityLow (simple to implement)
Used inFiber optics, short-range wireless

⚠ Weakness: ASK is highly susceptible to noise and interference because amplitude is the most vulnerable signal property. A small noise spike can change a 0 to a 1 or vice versa.

FSK — Frequency Shift Keying

In FSK, the frequency of the carrier signal varies to represent binary data, while amplitude and phase remain constant.

FSK Signal Representation:
Bit 1 → Frequency f₁, Bit 0 → Frequency f₂
Two distinct frequencies are used. The signal switches between f₁ and f₂ to encode data.

How FSK Works

Binary 1

• Carrier at higher frequency f₁

• More cycles per unit time

• Waveform appears "compressed"

Binary 0

• Carrier at lower frequency f₂

• Fewer cycles per unit time

• Waveform appears "stretched"

FSK Mathematical Form:
s(t) = A × sin(2πf₁t) for bit 1, s(t) = A × sin(2πf₂t) for bit 0
Amplitude A and phase are constant. Only frequency changes between two values.

Characteristics of FSK

PropertyValue
Bits per signal1 bit
Baud Rate = Bit RateYes
Noise sensitivityLow (frequency is robust)
Bandwidth efficiencyLow (needs wide bandwidth)
ComplexityLow-Medium
Used inModems, RFID, old telephone systems

⚠ Trade-off: FSK is more noise-resistant than ASK but requires more bandwidth because two separate frequencies must be allocated.

PSK — Phase Shift Keying

In PSK, the phase of the carrier signal varies to represent binary data, while amplitude and frequency remain constant.

PSK Signal Representation (BPSK):
Bit 1 → Phase 0°, Bit 0 → Phase 180°
Two phases 180° apart. The wave is "flipped" (inverted) for one of the bits.

How PSK Works

Binary 1

• Phase = 0° (normal sine wave)

• Signal starts at zero, goes positive

• Amplitude and frequency constant

Binary 0

• Phase = 180° (inverted sine wave)

• Signal starts at zero, goes negative

• Amplitude and frequency constant

PSK Mathematical Form:
s(t) = A × sin(2πft + φ)
A (amplitude) and f (frequency) are constant. Only φ (phase) changes to encode bits.

Characteristics of PSK (BPSK)

PropertyValue
Bits per signal1 bit
Phase levels2 (0° and 180°)
Phase separation180°
Noise immunityGood
Bandwidth efficiencyMedium
Used inWiFi, Bluetooth, satellite

⚠ Key Point: PSK is more noise-resistant than both ASK and FSK. Phase is harder to corrupt by noise than amplitude or frequency.

QPSK — Quadrature Phase Shift Keying (4PSK)

QPSK uses 4 phase levels (90° apart) instead of 2, allowing 2 bits per signal element. This doubles the data rate compared to BPSK for the same baud rate.

QPSK Signal Representation:
00 → 45°, 01 → 135°, 11 → 225°, 10 → 315°
4 phases, each 90° apart. Each phase represents a unique 2-bit combination (dibit).

How QPSK Works

2 Bits per Signal

• Each signal element carries 2 bits

• 4 possible phase values

• Bit Rate = 2 × Baud Rate

Phase Constellation

• 4 points on a circle

• Each point 90° from neighbors

• Equal amplitude for all points

QPSK Constellation Diagram: 4 points at 45°, 135°, 225°, 315°

QPSK Bandwidth Efficiency

Key Advantage:
Bit Rate = 2 × Baud Rate (2 bits per signal!)
For the same bandwidth as BPSK, QPSK achieves double the data rate. This is why QPSK is widely used in modern communications.

Characteristics of QPSK

PropertyValue
Bits per signal2 bits
Phase levels4 (90° apart)
Bandwidth efficiency2× BPSK
Noise immunityGood (but less than BPSK)
Used insatellite, cable TV, LTE, 4G

⚠ Trade-off: QPSK has 4 phase states vs BPSK's 2. With phases closer together (90° vs 180°), noise is more likely to cause errors. But the doubled data rate usually justifies this.

QAM — Quadrature Amplitude Modulation

QAM combines ASK (amplitude modulation) and PSK (phase modulation) simultaneously. Both amplitude AND phase vary to encode data, achieving higher data rates than either technique alone.

QAM Concept:
QAM = ASK + PSK (Amplitude + Phase both vary)
Two carrier signals 90° apart (I and Q) are amplitude-modulated and combined. The result varies in both amplitude and phase.
QAM Mathematical Form:
s(t) = A_I(t) × cos(2πft) + A_Q(t) × sin(2πft)
A_I and A_Q are independent amplitude levels on two carriers 90° apart. Each combination creates a unique signal point.

Why QAM?

Higher Data Rate

• More bits per signal element

• QAM-16: 4 bits per signal

• QAM-64: 6 bits per signal

Better Bandwidth Use

• Same bandwidth, more data

• Ideal for bandwidth-limited channels

• Used in cable modems, DSL

QAM-8 (8-QAM)

QAM-8 uses 8 distinct signal points in the constellation diagram. Each signal encodes 3 bits (2³ = 8).

QAM-8 Specifications:
Bits per signal = log₂(8) = 3 bits
Bit Rate = 3 × Baud Rate. Each signal element carries 3 bits of information.

8-QAM Constellation: 8 points, 3 bits per signal

PropertyValue

Phase levelsMultiple (varies by constellation)

QAM-16 (16-QAM)

QAM-16 uses 16 distinct signal points. Each signal encodes 4 bits (2⁴ = 16). This is the most commonly used QAM variant in practice.

QAM-16 Specifications:
Bits per signal = log₂(16) = 4 bits
Bit Rate = 4 × Baud Rate. Each signal element carries 4 bits of information.

16-QAM Constellation: 4×4 grid, 4 bits per signal

QAM-16 Key Properties

PropertyValue
Signal points16 (4×4 grid)
Bits per signal4 bits
Bit Rate= 4 × Baud Rate
Amplitude levels3 distinct levels per axis

Used inCable modems, WiFi, 4G LTE

⚠ Critical Trade-off: QAM-16 packs 4 bits per signal but the 16 constellation points are closer together. This means it needs higher SNR (Signal-to-Noise Ratio) to maintain low error rates compared to QPSK (2 bits) or BPSK (1 bit).

Bits per signal = log₂(N) where N = number of signal points

Worked Examples — Modulation Problems

Example 1: ASK Bit Rate and Baud Rate

Problem: An ASK signal transmits at 2400 baud. What is the bit rate? How many bits are in each signal element?

Given: Baud Rate = 2400, ASK modulation

Step 1: ASK encodes 1 bit per signal element
Step 2: Bit Rate = Baud Rate × bits per signal = 2400 × 1
Step 3: Bit Rate = 2400 bps
Remember:
For ASK and FSK: Bit Rate = Baud Rate (1 bit per signal)
Example 2: QPSK Data Rate Calculation

Problem: A QPSK system has a baud rate of 1500. What is the bit rate? How many signal levels are needed?

Given: Baud Rate = 1500, QPSK modulation

Step 1: QPSK encodes 2 bits per signal element
Step 2: Bit Rate = Baud Rate × bits per signal = 1500 × 2
Step 3: Bit Rate = 3000 bps = 3 kbps
Step 4: QPSK needs 4 signal levels (2² = 4 phases)
QPSK Formula:
Bit Rate = 2 × Baud Rate, Signal Levels = 4
Example 3: QAM-16 Bandwidth Efficiency

Problem: A cable modem uses QAM-16 with a baud rate of 6000. What is the bit rate? If we switch to QAM-64 with the same baud rate, what is the new bit rate?

Given: Baud Rate = 6000, QAM-16 then QAM-64

Step 1 (QAM-16): Bits per signal = log₂(16) = 4 bits
Step 2: Bit Rate = 6000 × 4 = 24,000 bps = 24 kbps
Step 3 (QAM-64): Bits per signal = log₂(64) = 6 bits
Step 4: Bit Rate = 6000 × 6 = 36,000 bps = 36 kbps
Key Insight:
Same bandwidth (baud rate), 50% more data with QAM-64!
QAM-64 = 36 kbps vs QAM-16 = 24 kbps at same 6000 baud.
Example 4: Modulation Technique Selection

Problem: You need to transmit at 9600 bps over a noisy channel with limited bandwidth. The channel can only support 2400 baud. Which modulation technique should you use? Justify your answer.

Given: Bit Rate = 9600 bps, Max Baud Rate = 2400 baud

Step 1: Calculate required bits per signal: 9600 / 2400 = 4 bits per signal
Step 2: Which technique gives 4 bits per signal? log₂(N) = 4 → N = 16
Step 3: Need 16 signal levels → QAM-16 or 16-PSK
Step 4: Since channel is noisy, QAM-16 is preferred (more robust than 16-PSK)
Decision Process:
Bits needed = Bit Rate / Baud Rate → Find technique with that bits/signal
Example 5: Comparing All Techniques

Problem: A system transmits 4800 bps. Calculate the baud rate for ASK, FSK, PSK, QPSK, QAM-8, and QAM-16. Which requires the least bandwidth?

Given: Bit Rate = 4800 bps for all techniques

TechniqueBits/SignalBaud Rate = Bit Rate / Bits
ASK14800 / 1 = 4800 baud
FSK14800 / 1 = 4800 baud
PSK (BPSK)14800 / 1 = 4800 baud
QPSK24800 / 2 = 2400 baud
QAM-834800 / 3 = 1600 baud
QAM-1644800 / 4 = 1200 baud

💡 Answer: QAM-16 requires the least bandwidth (1200 baud) because it packs the most bits per signal. Bandwidth is proportional to baud rate, so lower baud = less bandwidth needed.
