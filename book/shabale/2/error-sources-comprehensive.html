ERROR SOURCES IN DATA TRANSMISSION

Physical Layer — Network Fundamentals

What Are Error Sources?

Error sources are physical phenomena that corrupt data during transmission across a communication channel. When bits travel through a medium (copper wire, fiber optics, air), they are vulnerable to various impairments that flip, weaken, or destroy the signal.

These errors are unavoidable — they exist in every real-world transmission. Protocols must be designed to detect and correct them.

The Four Main Error Sources

⚡
1. Noise

Unwanted electromagnetic energy that interferes with the signal. Causes random bit flips.

→ Random errors
📉
2. Attenuation

Signal strength decreases with distance. The receiver may not distinguish 0 from 1.

→ Weakened signal
🔀
3. Distortion

Signal shape changes due to frequency-dependent delays. Pulses overlap and smear.

→ Signal deformation
💥
4. Collision

Multiple signals overlap on shared media, corrupting all participating transmissions.

→ Multiple signal conflict

Noise — The #1 Error Source

Noise is any unwanted electrical or electromagnetic energy that corrupts the transmitted signal. It is the most common and unavoidable source of errors in data communication.

Signal-to-Noise Ratio (SNR)
SNR = P_signal / P_noise
Measured in decibels: SNR(dB) = 10 × log₁₀(P_signal / P_noise). Higher SNR = cleaner signal.

Types of Noise

Thermal Noise

Caused by random motion of electrons in a conductor. Present in ALL electronic devices. Temperature-dependent.

P = k × T × B
k = Boltzmann constant, T = temperature (Kelvin), B = bandwidth
Crosstalk

Signal from one wire "leaks" into an adjacent wire via electromagnetic coupling. Common in telephone cables and Ethernet bundles.

→ Pairs twisted to reduce this
Impulse Noise

Sudden, short bursts of energy from lightning, power surges, or motor switching. Can corrupt multiple bits at once.

→ Causes burst errors
Intermodulation

When two signals mix and create new unwanted frequencies. Occurs when amplifiers are nonlinear.

→ Produces harmonics

How Noise Corrupts Bits

Example: Bit Flipping

Sender transmits: 1 0 1 1 0 1 0 0

Noise spike at position 4 (0-indexed):

Received: 1 0 1 1 1 1 0 0

A single bit flipped from 0 → 1. This is a single-bit error.

⚠ Common Mistake: Students often think noise only affects wireless channels. Copper wires and even fiber optics are affected by noise (thermal, crosstalk).

SNR and Bit Error Rate

SNR in Decibels
SNR(dB) = 10 × log₁₀(S/N)
If signal power = 100 mW and noise power = 1 mW, SNR = 10 × log₁₀(100) = 20 dB
Worked Example: SNR Calculation

Signal power = 50 mW, Noise power = 0.5 mW

SNR = 50 / 0.5 = 100

SNR(dB) = 10 × log₁₀(100) = 20 dB

Interpretation: Signal is 100× stronger than noise — good quality link.

Attenuation — Signal Loss

Attenuation is the reduction in signal amplitude (strength) as it travels through a medium. The longer the distance, the weaker the signal becomes.

Attenuation Formula
α(dB) = 10 × log₁₀(P_out / P_in)
P_out = received power, P_in = transmitted power. Negative value = loss. E.g., -3 dB means signal is halved.

Effects of Attenuation

Example: Attenuation Over Distance

Sender transmits at 100 mW (20 dBm). Cable attenuates at 3 dB per 100m.

DistancePowerdBm
0 m100 mW20 dBm
100 m50 mW17 dBm
200 m25 mW14 dBm
500 m3.125 mW5 dBm

At 500m, signal is only 3% of original — receiver may fail to detect bits correctly.

⚠ Common Mistake: Attenuation is NOT the same as noise. Attenuation weakens the signal uniformly; noise adds unwanted energy. Both cause errors but through different mechanisms.

Distortion — Signal Deformation

Distortion occurs when different frequency components of a signal travel at different speeds through the medium, causing the signal shape to change.

Dispersion
Δt = D × L × Δλ
D = dispersion coefficient, L = fiber length, Δλ = spectral width of source. Causes pulse spreading.

Types of Distortion

Chromatic Dispersion

Different wavelengths (colors) of light travel at different speeds in fiber optics. Pulses spread and overlap — called Inter-Symbol Interference (ISI).

Delay Distortion

In guided media, low frequencies arrive before high frequencies (or vice versa). Causes timing errors in bit detection.

Visual: Pulse Spreading

Original:   █░░█░░█░░  (clean pulses)

Distorted: ▓▒░▓▒░▓▒░  (pulses overlap → ISI)

Receiver cannot tell where one bit ends and the next begins.

How Attenuation + Distortion Combine

Combined Effect

Over long distances, both problems stack:

1. Signal gets weaker (attenuation) → harder to detect

2. Signal gets smeared (distortion) → bits overlap

Result: Receiver sees a weak, blurry signal — high error rate.

Solution: Repeaters & Equalizers
Repeaters: regenerate signal (fix attenuation)
Equalizers: compensate for frequency-dependent delays (fix distortion). Used together to extend range.

Collision — Signal Overlap

A collision occurs when two or more devices transmit simultaneously on a shared medium. The signals overlap and interfere with each other, resulting in corrupted data that is unrecoverable.

Collisions only occur on half-duplex shared media (e.g., classic Ethernet hubs, Wi-Fi). Full-duplex switches eliminate collisions.

When Do Collisions Happen?

CSMA/CD (Ethernet)

Before transmitting, device listens. If channel is busy, it waits. If two devices start at the same time → collision detected via voltage spike.

→ Binary Exponential Backoff
CSMA/CA (Wi-Fi)

Wi-Fi cannot detect collisions (hidden terminal problem). Instead, it avoids them with RTS/CTS and random backoff.

→ Collision avoidance, not detection

The Collision Problem

Scenario: Hub-Based Ethernet

Three devices (A, B, C) connected to a hub:

1. Device A sends frame to C

2. Device B sends frame to C (at the same time)

3. Both signals mix on the wire → garbled output

4. Both A and B detect collision → both retransmit after backoff

Ethernet Collision Domain
Max collision domain = 2 × propagation delay
Round-trip time determines minimum frame size. For 10 Mbps Ethernet: 64-byte minimum frame ensures collision is detected.
⚠ Common Mistake: Students confuse collisions with noise. Collisions are protocol-level events (multiple senders), while noise is a physical-level phenomenon (environmental energy).

Binary Exponential Backoff

Algorithm: IEEE 802.3 Backoff

After nth collision:

1. Choose random k from [0, 2ⁿ - 1]

2. Wait k × slot time (51.2 μs for 10 Mbps)

3. Retry transmission

4. If 16 collisions → give up, report failure

Collision #Backoff RangeMax Wait (10 Mbps)

2[0, 3]153.6 μs

10[0, 1023]~52 ms

Modern Solutions to Collisions

Switched Ethernet

Each port = separate collision domain. Full-duplex communication. No collisions possible.

Microsegmentation

Reduce number of devices per collision domain. Modern networks: one device per switch port.

Worked Example 1: Noise Impact

Problem

A channel has SNR = 30 dB. The signal power is 10 mW. Find the noise power.

Solution

Step 1: Convert SNR from dB to ratio

SNR = 10^(30/10) = 10³ = 1000

Step 2: Calculate noise power

SNR = P_signal / P_noise

P_noise = P_signal / SNR = 10 mW / 1000 = 0.01 mW = 10 μW

Noise power = 10 μW (0.01 mW)

Worked Example 2: Attenuation Over Fiber

Problem

An optical fiber has attenuation of 0.5 dB/km. Transmitter sends 1 mW. Receiver needs minimum 0.01 mW. What is the maximum cable length?

Solution

Step 1: Calculate required loss budget

Loss = 10 × log₁₀(P_in / P_out) = 10 × log₁₀(1 / 0.01) = 10 × 2 = 20 dB

Step 2: Calculate max distance

Distance = 20 dB / 0.5 dB/km = 40 km

Maximum cable length = 40 km

Worked Example 3: Bit Error Rate from SNR

Problem

A BPSK signal has Eb/N₀ = 10 dB. What is the approximate bit error rate?

Solution

Step 1: Convert Eb/N₀ from dB to ratio

Eb/N₀ = 10^(10/10) = 10

Step 2: Use BPSK BER formula

BPSK Bit Error Rate
BER = Q(√(2 × Eb/N₀))
Q(x) is the Q-function (tail probability of normal distribution)

BER = Q(√(2 × 10)) = Q(√20) = Q(4.47)

From Q-table: BER ≈ 3.9 × 10⁻⁶

Interpretation: ~1 in 250,000 bits will be in error.

Worked Example 4: Collision Detection Timing

Problem

In 10 Mbps Ethernet, the maximum cable length is 2500m and propagation speed is 2×10⁸ m/s. What is the minimum frame size to detect all collisions?

Solution

Step 1: Calculate propagation delay (one-way)

t_prop = distance / speed = 2500 / (2×10⁸) = 12.5 μs

Step 2: Calculate round-trip time

RTT = 2 × t_prop = 2 × 12.5 = 25 μs

Step 3: Calculate minimum frame size

Min size = data rate × RTT = 10 × 10⁶ × 25 × 10⁻⁶ = 250 bits = 31.25 bytes

IEEE 802.3 standard sets minimum = 64 bytes (safety margin + headers).

Worked Example 5: Combined Error Scenario

Problem

A 100 Mbps link sends 1500-byte frames over 1 km. Cable attenuation = 2 dB/km, cable loss = 1 dB. Noise floor = -80 dBm. Transmitter power = 0 dBm. Will the frame arrive intact?

Solution

Step 1: Calculate received power

P_received = P_transmit - (attenuation × distance) - cable_loss

P_received = 0 - (2 × 1) - 1 = -3 dBm

Step 2: Check if signal > noise floor

-3 dBm > -80 dBm → Signal is 77 dB above noise floor ✓

Step 3: Check SNR

SNR = -3 - (-80) = 77 dB → Very high SNR, extremely low error rate ✓

Step 4: Check if attenuation affects detection

Received power = -3 dBm = 0.5 mW → above minimum sensitivity of typical receiver (-20 dBm) ✓

Verdict: Frame arrives intact ✓

Exam Tips:
1. Attenuation ≠ Noise (weak signal vs. added energy)
2. Collisions are MAC-layer, not physical-layer
3. -3 dB means half power (not half distance)
4. SNR in dB ≠ linear ratio (10×log₁₀ conversion)
5. Fiber has low attenuation but still suffers from dispersion
