SIGNAL-TO-NOISE RATIO (SNR)

Physical Layer — Complete Guide for Exam

What is SNR?

Signal-to-Noise Ratio (SNR) is a measure of signal quality that compares the level of the desired signal to the level of background noise. It tells us how much stronger the signal is compared to the noise.

Fundamental Definition:
SNR = Signal Power / Noise Power
Ratio of useful signal power to unwanted noise power. Higher SNR = better quality.

Key Concepts

Signal Power (S)

• Desired information

• The useful component

• Measured in Watts or dBm

• Higher is better

Noise Power (N)

• Unwanted interference

• Random unwanted energy

• Measured in Watts or dBm

• Lower is better

SNR (Linear)

• Ratio S/N

• Dimensionless (no units)

• Direct power comparison

• e.g., SNR = 100

SNR (dB)

• Logarithmic scale

• Measured in decibels (dB)

• Easier to work with

• e.g., SNR = 20 dB

Why SNR Matters

SNR directly impacts the quality and reliability of data transmission:

High SNR

• Clear signal reception

• Low bit error rate

• Higher data rates possible

• Better channel capacity

Low SNR

• Signal corrupted by noise

• High bit error rate

• Lower data rates required

• May lose connection entirely

⚠ Key Relationship:
Higher SNR → Better signal quality → Higher channel capacity → More data can be transmitted reliably.

SNR Formulas

Linear SNR:
SNR = S / N
Where S = signal power, N = noise power. Result is a dimensionless ratio.
SNR in Decibels (dB):
SNR(dB) = 10 × log₁₀(S / N)
Convert linear SNR to logarithmic dB scale. More convenient for large ratios.
Alternative dB Formula (Power in dBm):
SNR(dB) = P_signal(dBm) − P_noise(dBm)
When signal and noise are already in dBm, subtract to get SNR in dB.
Linear SNR from dB:
SNR = 10^(SNR_dB / 10)
Convert dB back to linear ratio. Example: 20 dB = 10² = 100

Shannon's Channel Capacity Theorem

Shannon-Hartley Theorem:
C = B × log₂(1 + SNR)
C = channel capacity (bps), B = bandwidth (Hz), SNR = linear signal-to-noise ratio
Using SNR in dB:
C = B × log₂(1 + 10^(SNR_dB / 10))
When SNR is given in dB, convert to linear first inside the formula.
⚠ Shannon's Theorem Key Points:
• Channel capacity C is the theoretical maximum data rate
• Higher SNR → Higher capacity
• Higher bandwidth → Higher capacity
• C is achievable with proper coding, but not exceeded
• Relationship is logarithmic with SNR, linear with bandwidth

Signal Power Conversion

Watts to dBm:
P(dBm) = 10 × log₁₀(P(W) / 0.001)
Convert power in Watts to dBm (decibels relative to 1 milliwatt).
dBm to Watts:
P(W) = 0.001 × 10^(P(dBm) / 10)
Convert dBm back to Watts.
Noise Power (Thermal):
N = k × T × B
k = Boltzmann's constant (1.38×10⁻²³), T = temperature (Kelvin), B = bandwidth (Hz)
⚠ Logarithm Properties You Must Know:
• log₁₀(10) = 1 → 10 dB = 10× power ratio
• log₁₀(100) = 2 → 20 dB = 100× power ratio
• log₁₀(1000) = 3 → 30 dB = 1000× power ratio
• log₁₀(1) = 0 → 0 dB = 1× (equal power)
• log₁₀(0) is undefined — SNR of 0 is impossible in dB

Worked Examples with dB Calculations

Example 1: Basic SNR Calculation

Problem: Signal power is 0.1 W and noise power is 0.001 W. Find SNR in linear and dB.

Solution:

Step 1: Calculate linear SNR:

SNR = S / N
SNR = 0.1 / 0.001 = 100

Step 2: Convert to dB:

SNR(dB) = 10 × log₁₀(SNR)
SNR(dB) = 10 × log₁₀(100) = 10 × 2 = 20 dB
Example 2: SNR from dBm Values

Problem: Received signal power is −40 dBm and noise floor is −70 dBm. What is the SNR?

Solution:

Step 1: Use dB subtraction method:

SNR(dB) = P_signal(dBm) − P_noise(dBm)
SNR(dB) = (−40) − (−70) = −40 + 70 = 30 dB

Step 2: Verify by converting to Watts:

    Signal: 10^(−40/10) × 0.001 = 10⁻⁴ × 0.001 = 10⁻⁷ W = 0.1 μW

    Noise: 10^(−70/10) × 0.001 = 10⁻⁷ × 0.001 = 10⁻¹⁰ W = 0.1 nW

SNR = 10⁻⁷ / 10⁻¹⁰ = 10³ = 1000 → 10 × log₁₀(1000) = 30 dB ✓
Example 3: Converting SNR dB to Linear

Problem: A wireless link has SNR = 15 dB. What is the linear SNR ratio?

Solution:

Step 1: Apply inverse formula:

SNR = 10^(SNR_dB / 10)
SNR = 10^(15 / 10) = 10^1.5 = 31.62

Step 2: Interpretation: Signal is 31.62× stronger than noise.

Step 3: Verify: 10 × log₁₀(31.62) = 10 × 1.5 = 15 dB ✓

Example 4: Shannon Capacity with SNR

Problem: A channel has bandwidth B = 4000 Hz and SNR = 63 (linear). What is the maximum channel capacity?

Solution:

Step 1: Convert SNR to dB (optional, for reference):

SNR(dB) = 10 × log₁₀(63) = 10 × 1.799 = 18 dB

Step 2: Apply Shannon's formula:

C = B × log₂(1 + SNR)
C = 4000 × log₂(1 + 63) = 4000 × log₂(64)

Step 3: Calculate log₂(64):

log₂(64) = 6 (since 2⁶ = 64)
Final Answer:
C = 4000 × 6 = 24,000 bps = 24 kbps
Example 5: Required SNR for Target Capacity

Problem: A channel has B = 3000 Hz and needs capacity C = 15,000 bps. What SNR is required?

Solution:

Step 1: Rearrange Shannon's formula to solve for SNR:

C = B × log₂(1 + SNR) → log₂(1 + SNR) = C / B
log₂(1 + SNR) = 15000 / 3000 = 5

Step 2: Convert from log₂ to linear:

1 + SNR = 2^5 = 32
SNR = 32 − 1 = 31 (linear)

Step 3: Convert to dB:

SNR(dB) = 10 × log₁₀(31)
SNR(dB) = 10 × 1.491 = 14.91 dB ≈ 15 dB

The channel needs at least 15 dB SNR to achieve 15 kbps capacity.

SNR vs Data Rate Relationship

Low SNR (< 10 dB)

• Must use robust coding

• Low modulation (BPSK, QPSK)

• High error correction overhead

• Low data rates (kbps range)

Medium SNR (10-25 dB)

• Moderate coding needed

• Medium modulation (16-QAM)

• Moderate error correction

• Medium data rates (Mbps range)

High SNR (> 25 dB)

• Minimal coding overhead

• High modulation (64/256-QAM)

• Low error correction needed

• High data rates (Gbps range)

SNR Interpretation Guide

Quick dB to Linear Mapping:
0 dB = 1×  |  3 dB = 2×  |  6 dB = 4×  |  10 dB = 10×
13 dB = 20×  |  17 dB = 50×  |  20 dB = 100×  |  30 dB = 1000×
Each 3 dB increase roughly doubles the power ratio. Each 10 dB increase multiplies by 10.
⚠ Exam Warning:
• A common exam question: "If SNR = X dB, what is the linear ratio?" → Use SNR = 10^(dB/10)
• Don't confuse with amplitude ratios: 20 dB voltage = 10× amplitude, but 20 dB power = 100× power
• Shannon capacity uses linear SNR, not dB: C = B × log₂(1 + SNR_linear)

⚠ Top Exam Mistakes:
• Forgetting to use linear SNR in Shannon's formula (not dB!)
• Confusing power dB with voltage dB (power uses 10×log, voltage uses 20×log)
• Not knowing log₁₀(100) = 2, log₂(64) = 6, etc.
• Assuming higher SNR means proportionally higher capacity (it's logarithmic)
• Forgetting SNR = 0 dB means equal signal and noise power (ratio = 1)
