Nyquist & Shannon Theorems

Physical Layer - Maximum Data Rate Theorems

📊

Nyquist Theorem (Noiseless Channel)

Maximum data rate for a noiseless channel

R = 2 × W × log₂(M)
Nyquist Bit Rate Formula
R = Maximum data rate (bits per second)
W = Bandwidth of the channel (Hz)
M = Number of signal levels
log₂(M) = Bits per signal element

Key Concepts

  • Assumes noiseless channel - no signal degradation
  • Sampling theorem: Minimum sampling rate = 2 × W (Nyquist Rate)
  • Each signal element carries log₂(M) bits of information
  • Higher M = more bits per signal = higher data rate

Simplified Forms

When M = 2 (binary signaling):

R = 2 × W
Binary signaling: 1 bit per signal element

When M = 4 (4-level signaling):

R = 4 × W
2 bits per signal element
⚠️
Common Mistake #1 Confusing Nyquist Rate (sampling rate) with Nyquist Bit Rate (data rate). Nyquist Rate = 2W samples/sec, while Nyquist Bit Rate = 2W log₂(M) bits/sec.
💡
When to Use Nyquist Use this theorem for ideal, noiseless channels where the signal quality is perfect. Common in theoretical calculations and digital communication basics.

Shannon's Theorem (Noisy Channel)

Maximum data rate for a noisy channel

C = W × log₂(1 + S/N)
Shannon-Hartley Theorem
C = Channel capacity (bits per second)
W = Bandwidth of the channel (Hz)
S/N = Signal-to-Noise Ratio (linear, not dB)
log₂(1 + S/N) = Spectral efficiency (bits/symbol)

Key Concepts

  • Accounts for noise - realistic channel conditions
  • S/N can be given in dB - must convert to linear first
  • Channel capacity is the absolute theoretical maximum
  • Cannot be exceeded regardless of modulation scheme

Converting S/N from dB to Linear

(S/N)linear = 10(S/N)dB / 10

Example: S/N = 30 dB → S/Nlinear = 1030/10 = 103 = 1000

⚠️
Common Mistake #2 Using S/N in dB directly in the formula. Always convert to linear scale first! S/NdB = 10 × log₁₀(S/Nlinear)
✔️
When to Use Shannon Use this theorem for real-world noisy channels. It provides the absolute maximum capacity that cannot be exceeded, regardless of how clever the coding scheme is.

When to Use Which Theorem?

Use Nyquist When:
  • Channel is ideal and noiseless
  • You know the number of signal levels (M)
  • Doing theoretical calculations
  • Analyzing sampling rates
Use Shannon When:
  • Channel has noise (real-world scenario)
  • You know the signal-to-noise ratio (S/N)
  • Finding absolute maximum capacity
  • Designing communication systems
📌
Golden Rule: Actual Throughput The actual maximum throughput is always the MINIMUM of Nyquist and Shannon capacities. You cannot exceed either limit.

Actual Throughput = min(Nyquist Rate, Shannon Capacity)

Worked Examples

5 comprehensive examples comparing both theorems

1

Voice Channel (Phone Line)

Given: Bandwidth W = 3.1 kHz, M = 256 levels, S/N = 40 dB

Nyquist Calculation:

R = 2 × 3100 × log₂(256) = 2 × 3100 × 8 = 49,600 bps ≈ 49.6 kbps

Shannon Calculation:

S/N = 40 dB → 1040/10 = 10,000

C = 3100 × log₂(1 + 10,000) = 3100 × log₂(10,001) ≈ 3100 × 13.29 = 41,199 bps ≈ 41.2 kbps

Actual Throughput = min(49.6 kbps, 41.2 kbps) = 41.2 kbps
Shannon limits the actual rate despite higher Nyquist capacity
2

Wi-Fi Channel (802.11g)

Given: Bandwidth W = 20 MHz, M = 64 (64-QAM), S/N = 25 dB

Nyquist Calculation:

R = 2 × 20 × 106 × log₂(64) = 2 × 20 × 106 × 6 = 240 Mbps

Shannon Calculation:

S/N = 25 dB → 1025/10 = 102.5 ≈ 316.23

C = 20 × 106 × log₂(1 + 316.23) = 20 × 106 × 8.31 = 166.2 Mbps

Actual Throughput = min(240 Mbps, 166.2 Mbps) = 166.2 Mbps
Shannon capacity is the bottleneck here
3

DSL Line

Given: Bandwidth W = 1.1 MHz, M = 16 (16-QAM), S/N = 30 dB

Nyquist Calculation:

R = 2 × 1.1 × 106 × log₂(16) = 2 × 1.1 × 106 × 4 = 8.8 Mbps

Shannon Calculation:

S/N = 30 dB → 1030/10 = 1000

C = 1.1 × 106 × log₂(1 + 1000) = 1.1 × 106 × 9.97 = 10.97 Mbps

Actual Throughput = min(8.8 Mbps, 10.97 Mbps) = 8.8 Mbps
Nyquist is the bottleneck — need higher M to approach Shannon limit
4

Fiber Optic Link

Given: Bandwidth W = 5 THz, M = 2 (binary), S/N = 60 dB

Nyquist Calculation:

R = 2 × 5 × 1012 × log₂(2) = 2 × 5 × 1012 × 1 = 10 Tbps

Shannon Calculation:

S/N = 60 dB → 1060/10 = 106 = 1,000,000

C = 5 × 1012 × log₂(1 + 1,000,000) = 5 × 1012 × 19.93 = 99.65 Tbps

Actual Throughput = min(10 Tbps, 99.65 Tbps) = 10 Tbps
Nyquist limits here — fiber has excellent S/N but binary modulation limits rate
5

5G Cellular (mmWave)

Given: Bandwidth W = 400 MHz, M = 256 (256-QAM), S/N = 20 dB

Nyquist Calculation:

R = 2 × 400 × 106 × log₂(256) = 2 × 400 × 106 × 8 = 6.4 Gbps

Shannon Calculation:

S/N = 20 dB → 1020/10 = 100

C = 400 × 106 × log₂(1 + 100) = 400 × 106 × 6.66 = 2.66 Gbps

Actual Throughput = min(6.4 Gbps, 2.66 Gbps) = 2.66 Gbps
Shannon limits due to lower S/N at mmWave frequencies
📌
Key Pattern from Examples When Nyquist > Shannon: noise is the bottleneck (increase S/N). When Shannon > Nyquist: modulation is the bottleneck (increase M). Always the minimum determines actual throughput.

Quick Reference Card

Nyquist Formula

R = 2W log₂(M)
  • W = Bandwidth (Hz)
  • M = Signal levels
  • R = Data rate (bps)
  • NOISELESS Ideal channels only

Shannon Formula

C = W log₂(1 + S/N)
  • W = Bandwidth (Hz)
  • S/N = Linear (not dB!)
  • C = Capacity (bps)
  • REALISTIC Real channels

Key Relationships

  • Actual Rate = min(Nyquist, Shannon)
  • S/Nlinear = 10S/NdB/10
  • S/NdB = 10 × log₁₀(S/Nlinear)
  • Bits/symbol = log₂(M)
  • BOTH Use together

Common dB Values

  • 0 dB → S/N = 1
  • 10 dB → S/N = 10
  • 20 dB → S/N = 100
  • 30 dB → S/N = 1,000
  • 40 dB → S/N = 10,000

M to Bits Conversion

  • M = 2 → 1 bit/symbol
  • M = 4 → 2 bits/symbol
  • M = 8 → 3 bits/symbol
  • M = 16 → 4 bits/symbol
  • M = 64 → 6 bits/symbol
  • M = 256 → 8 bits/symbol

Decision Flowchart

  • 1. Identify: Noiseless or Noisy?
  • 2. Noiseless → Use Nyquist
  • 3. Noisy → Use Shannon
  • 4. Have both? Calculate both
  • 5. Answer = min(Nyquist, Shannon)

Cheat Sheet Summary

Scenario Given Info Use Formula
Noiseless channel W, M NYQUIST R = 2W log₂(M)
Noisy channel W, S/N (dB) SHANNON C = W log₂(1 + S/Nlin)
Both W, M, and S/N given W, M, S/N BOTH min(2W log₂(M), W log₂(1 + S/N))
Find M given Shannon limit W, S/N, target R BOTH M = 2R/(2W)
