BAUD RATE

Physical Layer — Signal Transmission Speed

What is Baud Rate?

Baud rate (also called symbol rate) is the number of signal changes (symbols) transmitted per second over a communication channel. It measures how frequently the signal on the wire changes state.

Key Definition

Baud Rate = Number of Signal Changes / Time (seconds)
Unit: baud (symbol/s) — named after Émile Baudot

Core Concepts

  • Each signal change is called a symbol
  • A symbol can represent one or more bits of data
  • Baud rate is limited by the bandwidth of the channel
  • Higher baud rate = more frequent signal transitions
  • Maximum baud rate is governed by the Nyquist theorem
Baud rate ≠ Bit rate. Baud rate counts signal changes; bit rate counts the actual number of bits transmitted per second. They are equal only when each symbol carries exactly 1 bit.

Analogy

Imagine a light switch. Baud rate is how many times per second you flip the switch. Bit rate is how much information each flip conveys. If each flip encodes 2 bits (e.g., 4 brightness levels), then bit rate = 2 × baud rate.

Master Formula

R = b × log₂(M)
R = bit rate (bps), b = baud rate (baud), M = number of signal levels

Bit Rate from Baud

R = b × log₂(M)

Baud from Bit Rate

b = R / log₂(M)

Number of Signal Levels

M = 2b_per_symbol
b_per_symbol = number of bits per symbol = R / baud_rate

Nyquist Baud Rate Limit

b_max = 2 × B
B = channel bandwidth (Hz). Max baud rate = 2× bandwidth (noise-free channel)

Shannon Capacity (with noise)

C = B × log₂(1 + SNR)
C = channel capacity (bps), B = bandwidth, SNR = signal-to-noise ratio
The Nyquist formula gives the maximum baud rate for a noise-free channel. The Shannon formula gives the maximum bit rate for a noisy channel. Both must be satisfied in practice.

Relationship Explained

Bit Rate = Baud Rate × Bits per Symbol
Or equivalently: R = b × log₂(M)

When M = 2 (binary signaling), baud rate = bit rate. As M increases, each symbol carries more bits, so bit rate exceeds baud rate.

Higher M means more bits per symbol, but also requires higher SNR to distinguish between the closely spaced signal levels. More levels = more susceptible to noise.

Modulation Impact

  • Baseband binary (NRZ): 1 bit/symbol → baud rate = bit rate
  • QPSK: 2 bits/symbol → bit rate = 2× baud rate
  • 16-QAM: 4 bits/symbol → bit rate = 4× baud rate
  • Higher modulation order increases throughput without increasing baud rate, but demands cleaner signal
Baud rate is a physical constraint; bit rate is an engineering optimization. By using multi-level signaling, engineers push bit rates above baud rates.

Example 1: Binary NRZ Transmission

A modem transmits binary NRZ signals at 5000 baud with 2 signal levels.
M = 2, so bits per symbol = log₂(2) = 1
Bit rate = 5000 × 1 = 5000 bps
✓ Baud rate = Bit rate (binary case)

Example 2: QPSK Modulation

A satellite link uses QPSK (M = 4) at 3000 baud.
Bits per symbol = log₂(4) = 2
Bit rate = 3000 × 2 = 6000 bps (6 kbps)
✓ 2 bits per symbol doubles the bit rate vs baud rate

Example 3: 16-QAM Cable Modem

A cable modem uses 16-QAM (M = 16) with baud rate of 3200 baud.
Bits per symbol = log₂(16) = 4
Bit rate = 3200 × 4 = 12,800 bps (12.8 kbps)
✓ 4 bits per symbol — efficient use of bandwidth

Example 4: Finding Baud from Bit Rate

A DSL line achieves 24,000 bps using 64-QAM (M = 64).
Bits per symbol = log₂(64) = 6
Baud rate = 24,000 / 6 = 4000 baud
✓ Lower baud rate reduces signal distortion while maintaining high bit rate

Example 5: Nyquist Limit Calculation

A channel has bandwidth B = 4000 Hz. What is the maximum baud rate?
Nyquist: b_max = 2 × B = 2 × 4000 = 8000 baud
With QPSK (M=4): max bit rate = 8000 × 2 = 16,000 bps
With 16-QAM (M=16): max bit rate = 8000 × 4 = 32,000 bps
✓ Higher modulation order → higher bit rate within same bandwidth
In real systems, the achievable baud rate is always lower than the Nyquist limit due to noise, distortion, and practical filter constraints.

When Baud = Bit Rate

  • Only when M = 2 (binary signaling)
  • Each symbol carries exactly 1 bit
  • Simple NRZ, NRZI, Manchester coding

When Bit Rate > Baud Rate

  • When M > 2 (multi-level signaling)
  • Each symbol carries log₂(M) bits
  • QPSK, QAM, PSK, FSK with multiple levels
