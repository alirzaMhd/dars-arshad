FIBER OPTIC TYPES

Physical Layer Networking — Complete Guide for Exam

Multimode Stepped Index Fiber

Structure

Core

Diameter: 50-62.5 μm

High refractive index (n₁)

Typical: n₁ = 1.48

Cladding

Diameter: 125 μm

Lower refractive index (n₂)

Typical: n₂ = 1.46

Index Profile

Step Change

Abrupt change at core-cladding boundary

Δ = (n₁-n₂)/n₁ ≈ 1-2%

How It Works

In stepped index fiber, light travels in straight lines until it hits the core-cladding boundary, where it undergoes total internal reflection. The refractive index changes abruptly at the boundary.

Numerical Aperture (NA):
NA = √(n₁² - n₂²)
Determines the light-gathering ability of the fiber
Maximum Acceptance Angle:
θ_max = sin⁻¹(NA/n₀)
Where n₀ is the refractive index of the external medium (usually air, n₀ = 1)
Number of Modes:
V = (2πa/λ) × NA
V-number determines mode count; multimode when V >> 1
⚠ Modal Dispersion Problem

Different modes travel different path lengths, causing pulse spreading. This limits bandwidth and distance. Higher-order modes travel longer paths and arrive later than lower-order modes.

LED

Multimode Graded Index Fiber

Structure

Core

Diameter: 50-62.5 μm

Graded refractive index

Parabolic profile: n(r) = n₁[1-2Δ(r/a)²]^(1/2)

Cladding

Diameter: 125 μm

Constant refractive index (n₂)

n₂ = 1.46 typical

Index Profile

Gradual Change

Parabolic profile from center to edge

Reduces modal dispersion

How It Works

In graded index fiber, the refractive index decreases gradually from the center to the edge. Light travels in sinusoidal curves. Higher-order modes travel through lower-index regions (faster speed), compensating for longer paths.

Refractive Index Profile:
n(r) = n₁√[1 - 2Δ(r/a)^(α)]
α ≈ 2 for parabolic profile; a = core radius; Δ = (n₁-n₂)/n₁
Modal Dispersion Reduction:
Δτ/L ≈ (n₁Δ²)/(2c)
Dispersion is reduced by factor Δ compared to step index
Bandwidth Improvement:
BW_graded ≈ BW_stepped / Δ
Graded index typically 50-100x better than stepped index
⚠ Manufacturing Precision

The graded index profile must be precisely controlled during manufacturing. Any deviations from the ideal parabolic profile increase dispersion and reduce performance.

Key Characteristics

Bandwidth

1-10 GHz·km

Much better than stepped index

Maximum Distance

~2 km

At 1 Gbps

Light Source

LED or Laser

More flexible options

Cost

Moderate

Higher than stepped index

Applications

  • Fast Ethernet (100BASE-FX)
  • Gigabit Ethernet (1000BASE-SX)
  • Fibre Channel
  • Enterprise LAN backbones
  • Data center interconnects

Single Mode Fiber

Structure

Core

Diameter: 8-10 μm

Very small, allows only one mode

Typical: n₁ = 1.4675

Cladding

Diameter: 125 μm

Standard cladding size

n₂ = 1.4625

V-Number

V < 2.405

Single mode condition

Cutoff wavelength determines V

How It Works

Single mode fiber has such a small core that only the fundamental mode (LP₀₁) can propagate. Light travels in a single straight path along the fiber axis, eliminating modal dispersion entirely.

Single Mode Condition:
V = (2πa/λ) × NA < 2.405
Must be below first zero of Bessel function J₀
Cutoff Wavelength:
λ_c = (2πa × NA) / 2.405
Wavelength above which fiber is single mode
Mode Field Diameter:
MFD ≈ 2a × (0.65 + 1.619/V^(3/2) + 2.879/V^6)
Effective diameter of fundamental mode (Marcuse formula)
⚠ Alignment Precision Required

Due to the small core size, single mode fiber requires precise alignment and connectors. Splicing and connectorization must be done with specialized equipment to minimize loss.

Key Characteristics

Bandwidth

10-100+ GHz·km

Limited only by chromatic dispersion

Maximum Distance

100+ km

With optical amplifiers

Light Source

Laser (LD)

Narrow linewidth required

Cost

Highest

Expensive equipment

Applications

  • Long-haul telecommunications
  • Submarine cables
  • CATV networks
  • WDM (Wavelength Division Multiplexing) systems
  • Fiber-to-the-Home (FTTH)
  • High-speed backbone networks

Cost Analysis

Graded Index: Moderate cost → Enterprise use

Single Mode: Highest cost → Telecom backbone

⚠ Choosing the Right Fiber

Don't automatically choose single mode for short distances. Multimode fiber with LED sources is more cost-effective for building and campus networks under 2 km. Single mode is essential only for long-haul or very high bandwidth requirements.

Worked Examples

Example 1: Calculating Acceptance Angle

Problem: A multimode stepped index fiber has n₁ = 1.48, n₂ = 1.46. Calculate the numerical aperture and maximum acceptance angle.

Solution:

Step 1: Numerical Aperture
NA = √(n₁² - n₂²) = √(1.48² - 1.46²) = √(2.1904 - 2.1316) = √0.0588 ≈ 0.2425
Step 2: Maximum Acceptance Angle
θ_max = sin⁻¹(NA) = sin⁻¹(0.2425) ≈ 14.04°

The acceptance angle is approximately 14°.

Example 2: Single Mode Cutoff Wavelength

Problem: A single mode fiber has core radius a = 4.5 μm and NA = 0.12. Find the cutoff wavelength.

Solution:

Cutoff Wavelength Formula:
λ_c = (2πa × NA) / 2.405 = (2π × 4.5 × 0.12) / 2.405 = 3.3929 / 2.405 ≈ 1.411 μm

The cutoff wavelength is approximately 1411 nm. Fiber operates single mode for λ > 1411 nm.

Example 3: Comparing Modal Dispersion

Problem: A stepped index fiber has Δ = 0.01. How much does a graded index fiber reduce modal dispersion?

Solution:

Dispersion Reduction Factor:
For parabolic graded index: Δτ_graded ≈ Δ × Δτ_stepped
With Δ = 0.01, graded index reduces dispersion by factor of 100

The graded index fiber reduces modal dispersion by approximately 100 times.

Example 4: Maximum Link Length

Problem: A graded index fiber has bandwidth-distance product of 500 MHz·km. What is the maximum length for a 155 Mbps link?

Solution:

Maximum Length:
L_max = (Bandwidth-Distance Product) / Required Bandwidth = 500 MHz·km / 155 MHz ≈ 3.23 km

The maximum link length is approximately 3.23 km.

Example 5: Fiber Selection Decision

Problem: A campus network needs to connect buildings 500m apart. Required bandwidth is 10 Gbps. Budget is limited. Which fiber type?

Solution:

Analysis:
Distance: 500m = 0.5 km (all types can handle)
Bandwidth Requirement:
10 Gbps over 0.5 km → Need 20 GHz·km
Decision:
Graded Index: 1-10 GHz·km → INSUFFICIENT
Single Mode: 10-100+ GHz·km → SUFFICIENT

Use Single Mode fiber. Despite higher cost, it's the only type meeting the bandwidth requirement.

Common Mistakes to Avoid

⚠ Exam Pitfalls

1. Don't confuse core diameter with cladding diameter (cladding is always 125 μm)

2. Remember: single mode requires V < 2.405, not V > 2.405

3. Graded index reduces modal dispersion but doesn't eliminate it

4. Single mode still has chromatic dispersion (material + waveguide)

5. Higher NA means better light gathering but more modes
