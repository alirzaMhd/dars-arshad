Binary Exponential Backoff Algorithm

BEB is the retransmission delay algorithm used in Ethernet (CSMA/CD) after a collision. The backoff time is chosen randomly from a window that doubles with each successive collision.

Algorithm Formula:
T_backoff = r × T_slot
Where r = random integer from [0, 2^n - 1], n = min(collision_count, 10), T_slot = 2 × T_propagation

Key Properties:

1. Binary: Window sizes are powers of 2 (2^0, 2^1, 2^2, ...)

2. Exponential: Window doubles with each collision

3. Random: Wait time is randomly chosen within the window

4. Bounded: Maximum window = 2^10 = 1024 slots

Why "Binary"?

• Window sizes are 2^n

• 1, 2, 4, 8, 16, 32, ...

• Powers of 2 (binary)

Why "Exponential"?

• Window doubles each time

• Growth rate = 2^n

• Exponential growth

Maximum Retries:
16 collisions → Report failure, discard frame
After 16 failed attempts, the frame is dropped and higher layer is notified

Key Point: After 10 collisions, the window stops growing and stays at 1024. After 16 total collisions, the frame is discarded.

Worked Examples

Example 1: Backoff After 3 Collisions

Given: 3rd collision, T_slot = 51.2 μs

Window size = 2^3 = 8, random r ∈ [0, 7]

If r = 5: T_backoff = 5 × 51.2 = 256 μs

If r = 0: T_backoff = 0 × 51.2 = 0 μs (immediate retransmit)

Example 2: Backoff After 5 Collisions

Given: 5th collision, T_slot = 51.2 μs

Window size = 2^5 = 32, random r ∈ [0, 31]

Average wait = (31/2) × 51.2 = 15.5 × 51.2 = 793.6 μs

Example 3: Maximum Wait Time

Given: 10th collision, T_slot = 51.2 μs

Window size = 2^10 = 1024, random r ∈ [0, 1023]

Maximum wait = 1023 × 51.2 = 52377.6 μs ≈ 52.4 ms

Example 4: Probability of Successful Retransmission

After 3 collisions, 4 stations retransmit simultaneously

Each chooses r ∈ [0, 7] (8 options)

Probability all choose different r = (8/8) × (7/8) × (6/8) × (5/8) = 40.6%

At least one collision: 1 - 0.406 = 59.4%

Example 5: Window Comparison

1st collision: window = 2 (max wait = 1 slot)

5th collision: window = 32 (max wait = 31 slots)

Ratio: 31/1 = 31× longer wait

This shows why BEB is effective at reducing collisions

Analysis and Properties

Why BEB Works

• Doubles wait → reduces collision probability

• Random choice → avoids synchronized retransmits

• Bounded maximum → prevents infinite waits

Key Properties

• Average backoff = (2^n - 1) / 2 slots

• Maximum backoff = 2^n - 1 slots

• Window caps at 2^10 = 1024

Average Backoff Time:
E[T] = ((2^n - 1) / 2) × T_slot
Expected value of uniform random selection from [0, 2^n - 1]
Example: Average Wait Analysis

After 4 collisions: E[T] = (2^4 - 1)/2 × 51.2 = 15/2 × 51.2 = 384 μs

After 8 collisions: E[T] = (2^8 - 1)/2 × 51.2 = 255/2 × 51.2 = 6528 μs
