Polling Methods

Network Access Control — Complete Guide for 20/20 Exam

Roll Call Polling

In roll call polling, the central controller (master) polls each station sequentially in a predetermined order. The master sends a poll message to each station one by one, asking if it has data to transmit.

How it works:
Master → Station 1 → Station 2 → ... → Station n → Master
The controller sequentially queries each station in a loop

Step-by-Step Process:

1. The master sends a poll message to the first station in the list

2. If the station has data, it transmits; otherwise, it sends a negative acknowledgment

3. The master then moves to the next station

4. After polling all stations, the cycle repeats from the first station

Key Issue: If the master fails, the entire network goes down. This is a single point of failure.

Advantages

• Simple to implement

• No collisions

• Fair access if stations are polled equally

Disadvantages

• Master is single point of failure

• High overhead if many stations are idle

• Latency increases with more stations

Hub Polling

In hub polling, the polling token is passed from one station to the next. The current station that holds the token can transmit data, then passes the token to the next station in sequence.

How it works:
Station 1 → Station 2 → Station 3 → ... → Station n → Station 1
The token circulates among stations without central controller

Step-by-Step Process:

1. The token starts at the first station

2. If the station has data, it transmits while holding the token

3. After transmission (or if no data), the station passes the token to the next station

4. The process continues in a circular fashion

Advantages

• No single point of failure

• More fault-tolerant than roll call

• Lower overhead when stations are distributed

Disadvantages

• More complex to implement

• Token can be lost

• Latency depends on station activity

Formulas and Calculations

Polling Time Formula:
T_polling = (n-1) × T_overhead + n × T_transmission
Where n = number of stations, T_overhead = time to send poll message, T_transmission = time for station to respond
Example 1: Roll Call Polling Time

Given: 10 stations, poll time = 0.1 ms, transmission time = 1 ms per station

T_polling = (10-1) × 0.1 + 10 × 1 = 0.9 + 10 = 10.9 ms

Example 2: Hub Polling Time

Given: 8 stations, token passing time = 0.05 ms, transmission time = 0.5 ms per station

T_cycle = 8 × (0.05 + 0.5) = 8 × 0.55 = 4.4 ms

Channel Utilization:
U = (n × T_data) / (n × (T_poll + T_data) + T_cycle)
Where T_data = data transmission time, T_poll = polling overhead, T_cycle = total cycle time
Example 3: Channel Utilization

Given: 5 stations, T_data = 2 ms, T_poll = 0.2 ms, T_cycle = 11 ms

U = (5 × 2) / (5 × (0.2 + 2) + 11) = 10 / (11 + 11) = 10/22 = 45.45%
