Ethernet (IEEE 802.3)

LAN Technology — Complete Guide for 20/20 Exam

Ethernet Overview

Ethernet is the most widely deployed LAN technology, standardized as IEEE 802.3. It defines both physical layer and MAC sublayer of the data link layer. Originally developed by Xerox in the 1970s, it has evolved from 10 Mbps to 400 Gbps.

OSI Layer Placement:
Layer 1 (Physical) + Layer 2 (Data Link - MAC sublayer)
Ethernet covers Physical layer and MAC sublayer; LLC sublayer (802.2) sits above

Key Characteristics:

Topology

• Original: Bus (coaxial)

• Modern: Star (twisted pair)

• Switched Ethernet eliminates collisions

MAC Address

48 bits (6 bytes)

• First 24 bits: OUI (vendor)

• Last 24 bits: NIC serial

• Format: XX:XX:XX:XX:XX:XX

Access Method

CSMA/CD

• Carrier Sense

• Multiple Access

• Collision Detection

Frame Sizes

• Min: 64 bytes

• Max: 1518 bytes

• MTU: 1500 bytes

• Min data: 46 bytes

Ethernet Frame Format

IEEE 802.3 Frame Structure:
Preamble | SFD | Dst Addr | Src Addr | Length/Type | Data + Pad | FCS
Total frame size: 64 to 1518 bytes (excluding preamble and SFD)

Frame Field Details:

Field Size (bytes) Description
Preamble 7 Alternating 1s and 0s (10101010...) for clock synchronization
SFD (Start Frame Delimiter) 1 Pattern 10101011 — signals start of actual frame
Destination Address 6 Receiver MAC address (48 bits); can be unicast, multicast, or broadcast
Source Address 6 Sender MAC address (48 bits); always unicast
Length/Type 2 If ≤ 1500: frame length in bytes. If ≥ 1536: EtherType (protocol ID)
Data + Padding 46–1500 Payload from upper layer; padded to 46 bytes minimum
FCS (Frame Check Sequence) 4 CRC-32 error detection code

Frame Size Calculations:

Minimum Frame Size (for CSMA/CD):
6 + 6 + 2 + 46 + 4 = 64 bytes
Excludes preamble (7) and SFD (1) = 8 bytes overhead on wire
Maximum Frame Size:
6 + 6 + 2 + 1500 + 4 = 1518 bytes
Standard Ethernet MTU = 1500 bytes
Wire Overhead (including preamble):
8 (preamble+SFD) + 64 (min frame) = 72 bytes on wire minimum
8 (preamble+SFD) + 1518 (max frame) = 1526 bytes on wire maximum
Key Point: The 64-byte minimum ensures collision detection works. At 10 Mbps, 64 bytes = 512 bits = 51.2 μs slot time. This is the time a station must transmit before being sure no collision occurred.

EtherType Values (Common):

802.3 vs Ethernet II (DIX) Frame:

IEEE 802.3

• Field 5 = Length

• Uses LLC (802.2) header

• Used in older networks

Ethernet II (DIX)

• Field 5 = EtherType

• Direct protocol identification

• Most common today

CSMA/CD Protocol

CSMA/CD Algorithm:
Carrier Sense → Multiple Access → Collision Detection
Used in half-duplex Ethernet to manage shared medium access

Step-by-Step Process:

1. Carrier Sense: Listen to medium before transmitting 2. If medium IDLE → Start transmitting 3. If medium BUSY → Wait until idle, then transmit 4. While transmitting: Monitor for collision 5. If COLLISION detected: a. Send jam signal (32 bits) b. Stop data transmission c. Wait random backoff time (binary exponential) d. Go to step 1 6. If no collision → Transmission successful

Slot Time Calculation:

Slot Time (10 Mbps Ethernet):
Slot Time = 51.2 μs = 512 bit times
Minimum frame size = 512 bits = 64 bytes (ensures collision detection)
Maximum Network Diameter:
D = (Slot Time × Propagation Speed) / 2
For 10 Mbps: D = (51.2 μs × 2×10⁸ m/s) / 2 = 5120 m ≈ 5 km

Binary Exponential Backoff:

Backoff Algorithm:
Wait time = random(0, 2^k - 1) × slot_time
k = min(n, 10) where n = collision number (16 max attempts)
Collision # k value Random Range Max Wait (slots)
1 1 0-1 1
2 2 0-3 3
3 3 0-7 7
4 4 0-15 15
10+ 10 0-1023 1023
Key Points:
1. CSMA/CD is used in half-duplex mode only
2. Full-duplex switched Ethernet doesn't need CSMA/CD
3. Maximum 16 collisions before frame is discarded
4. Jam signal ensures all stations detect collision

Worked Examples

Example 1: Frame Size Calculation

Data payload = 100 bytes

Frame size = 6 (dst) + 6 (src) + 2 (length) + 100 (data) + 4 (FCS) = 118 bytes

This is ≥ 64 bytes, so no padding needed.

Example 2: Padding Required

Data payload = 20 bytes

Frame without padding = 6 + 6 + 2 + 20 + 4 = 38 bytes

Minimum = 64 bytes → padding = 64 - 38 = 26 bytes padding

Final frame = 6 + 6 + 2 + (20 + 26) + 4 = 64 bytes

Example 3: Maximum Throughput Calculation

Given: 100 Mbps Ethernet, frame size = 1518 bytes, overhead = 26 bytes (headers + FCS)

Efficiency = (1518 - 26) / 1518 = 1492 / 1518 = 98.3%

Effective throughput = 100 × 0.983 = 98.3 Mbps

Example 4: Minimum Frame Time (Slot Time)

Given: 10 Mbps Ethernet, minimum frame = 64 bytes = 512 bits

Frame time = 512 / (10 × 10⁶) = 51.2 μs

This equals the slot time for CSMA/CD at 10 Mbps

Example 5: Maximum Network Size

Given: 10 Mbps, slot time = 51.2 μs, propagation speed = 2×10⁸ m/s

Max one-way delay = 51.2 / 2 = 25.6 μs (round trip must be within slot time)

Max distance = 25.6×10⁻⁶ × 2×10⁸ = 5120 m ≈ 5 km

Example 6: Throughput with Collisions

Given: 10 Mbps, 100 stations, each sending 1000-byte frames

Frame transmission time = (1518 × 8) / 10×10⁶ = 1.2144 ms

If G = 0.5 (offered load), throughput = G × e^(-2G) = 0.5 × e⁻¹ = 18.4% = 1.84 Mbps

Example 7: VLAN Tagged Frame Size

802.1Q VLAN tag = 4 bytes added to header

New max frame = 1518 + 4 = 1522 bytes

VLAN-tagged frame: Dst(6) + Src(6) + Tag(4) + Length(2) + Data(1500) + FCS(4) = 1522

Example 8: Encoding Efficiency

100BASE-TX uses 4B/5B encoding: 4 data bits → 5 line bits

Clock rate = 125 MHz → Line rate = 125 Mbaud

Data rate = 125 × (4/5) = 100 Mbps

Key Formulas for Exam:

Minimum Frame:
64 bytes = 6 + 6 + 2 + 46 + 4
dst + src + length + min_data + FCS
Slot Time:
T_slot = 2 × T_prop = 2 × (d/v)
Must equal frame transmission time for min frame
Max Distance:
d_max = (T_slot × v) / 2
For 10 Mbps: d = (51.2μs × 2×10⁸) / 2 = 5120 m
Throughput Efficiency:
η = (Frame - Overhead) / Frame
For max frame: η = (1518 - 26) / 1518 ≈ 98.3%
Exam Tips:
1. Minimum frame = 64 bytes (for collision detection)
2. Maximum data = 1500 bytes (MTU)
3. MAC address = 48 bits (6 bytes)
4. FCS = CRC-32
5. Slot time = 51.2 μs (for 10 Mbps Ethernet)
6. Preamble = 7 bytes, SFD = 1 byte
7. CSMA/CD: listen before talk, detect collisions
8. Binary exponential backoff: wait random(0, 2^k-1) slots
