CSMA/CD Protocol

CSMA/CD improves upon basic CSMA by detecting collisions during transmission. When a collision is detected, the station immediately stops transmitting and sends a jam signal to notify all other stations. This reduces wasted time compared to transmitting the entire frame.

Key Improvement:
Sense → Transmit → Detect Collision → Jam → Backoff → Retransmit
Collision detection stops transmission immediately, saving bandwidth

Algorithm:

Sense channel before transmitting
If idle, start transmitting frame
While transmitting, monitor for collision
If collision detected:
a. Stop transmitting immediately
b. Send jam signal (32-48 bits) to notify all stations
c. Wait random backoff time (Binary Exponential Backoff)
d. Reattempt transmission
If no collision and transmission complete, send ACK

Key Features

• Collision detection during transmission

• Jam signal on collision

• Binary Exponential Backoff

• Used in Ethernet (IEEE 802.3)

Vulnerable Period

• T_propagation (round trip)

• Must detect collision within 2× propagation delay

• Minimum frame size ensures detection

Binary Exponential Backoff (BEB)

After a collision, stations wait a random backoff time before retransmitting. The backoff time doubles with each successive collision, up to a maximum number of attempts.

Backoff Time Formula:
T_backoff = r × T_slot
Where r = random integer from [0, 2^n - 1], n = min(collision_count, 10), T_slot = 2 × T_propagation
Maximum Retransmissions:
n_max = 10 (for 1024 slots max)
After 16 collisions: give up and report failure
Backoff window grows exponentially: 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024

Backoff Window Progression:

Collision # Window Size (2^n) Random Range Max Wait Slots
1 2^1 = 2 [0, 1] 1
2 2^2 = 4 [0, 3] 3
3 2^3 = 8 [0, 7] 7
4 2^4 = 16 [0, 15] 15
5 2^5 = 32 [0, 31] 31
10+ 2^10 = 1024 [0, 1023] 1023
Key Point: BEB is "exponential" because the window doubles each time. It's "binary" because it's powers of 2. After 10 collisions, window stays at 1024. After 16 total collisions, transmission is abandoned.

Backoff Algorithm Visualization:

// Binary Exponential Backoff Algorithm
function calculateBackoff(collisionCount) {
  let n = Math.min(collisionCount, 10);
  let windowSize = Math.pow(2, n);
  let r = Math.floor(Math.random() * windowSize);
  return r * SLOT_TIME;
}

Throughput and Efficiency

Throughput Formula:
S_max = 1 / (1 + 2a)
Where a = T_prop / T_trans (ratio of propagation delay to transmission time)
Efficiency Formula:
η = 1 / (1 + 2a) × 100%
Maximum channel efficiency for CSMA/CD
Optimal Frame Size:
L_min ≥ 2 × R × T_prop
Minimum frame size to ensure collision detection. R = data rate, T_prop = propagation delay
Example: Ethernet Minimum Frame Size

Given: R = 10 Mbps, T_prop = 25.6 μs (for 2500m cable)

L_min = 2 × 10 × 10^6 × 25.6 × 10^-6 = 512 bits = 64 bytes

This is why Ethernet minimum frame size is 64 bytes!

Key Point: As network speed increases, minimum frame size must also increase to maintain collision detection. This is why Gigabit Ethernet uses different techniques.

Efficiency vs. Parameter 'a':

Parameter a Efficiency (η) Network Scenario

Worked Examples

Example 1: Backoff Time Calculation

Given: 3rd collision, T_slot = 51.2 μs

Window size = 2^3 = 8, random r ∈ [0, 7]

If r = 5: T_backoff = 5 × 51.2 = 256 μs

Example 2: Channel Efficiency

Given: T_prop = 5 μs, T_trans = 50 μs

a = 5/50 = 0.1

η = 1/(1 + 2×0.1) = 1/1.2 = 83.3%

Example 3: Minimum Frame Size

Given: R = 100 Mbps, T_prop = 10 μs

L_min = 2 × 100 × 10^6 × 10 × 10^-6 = 2000 bits = 250 bytes

Example 4: Maximum Network Diameter

Given: R = 10 Mbps, L_min = 512 bits (Ethernet)

T_trans = L_min / R = 512 / 10×10^6 = 51.2 μs

T_prop ≤ T_trans / 2 = 25.6 μs

Max distance = T_prop × speed = 25.6×10^-6 × 2×10^8 = 5120 m ≈ 5 km

Example 5: Backoff After Multiple Collisions

Station collides 4 times:

1st: r ∈ [0,1], max wait = 1 slot

2nd: r ∈ [0,3], max wait = 3 slots

3rd: r ∈ [0,7], max wait = 7 slots

4th: r ∈ [0,15], max wait = 15 slots

Example 6: Throughput Calculation

Given: T_prop = 2 μs, T_trans = 20 μs

a = 2/20 = 0.1

S_max = 1/(1 + 2×0.1) = 1/1.2 = 0.833 (83.3% efficiency)

Example 7: Jam Signal Transmission

Given: Jam signal = 32 bits, R = 10 Mbps

T_jam = 32 / 10×10^6 = 3.2 μs

Total collision time = T_prop + T_jam + T_prop = 2×T_prop + T_jam
