PSTN — Public Switched Telephone Network

PSTN is the global circuit-switched telephone network that provides voice communication over copper wires. It uses dedicated connections established for the duration of each call.

Exam Point: PSTN uses circuit-switching, which reserves a dedicated end-to-end path for the entire call. This is fundamentally different from packet-switching used in modern data networks.

A leased line is a dedicated, always-on communication channel leased from a service provider. Unlike PSTN, it is not shared and provides fixed, guaranteed bandwidth 24/7.

T1 Leased Line Calculation

T1 Bandwidth Calculation
24 channels × 64 kbps = 1.544 Mbps
T1 uses 24 DS0 channels (each 64 kbps) plus 8 kbps framing = 1.544 Mbps
Worked Example: T1 Frame Structure

A T1 frame contains 193 bits total:

  • 24 channels × 8 bits/channel = 192 bits of data
  • 1 framing bit per frame = 1 bit
  • Total: 193 bits per frame

Frame rate: 8000 frames/sec → 193 × 8000 = 1,544,000 bps = 1.544 Mbps

E1 Leased Line Calculation

E1 Bandwidth Calculation
30 channels × 64 kbps + 2 × 64 kbps = 2.048 Mbps
E1 uses 30 data channels + 2 signaling/sync channels = 32 × 64 kbps = 2.048 Mbps
Worked Example: Leased Line Cost Analysis

A company needs 2 Mbps dedicated bandwidth. Compare options:

  • Option 1 — T1: 1.544 Mbps (insufficient, need 2× T1)
  • Option 2 — E1: 2.048 Mbps (sufficient, single line)
  • Option 3 — Bonded T1: 2 × 1.544 = 3.088 Mbps (overkill)

Best choice: E1 provides exactly what's needed at 2.048 Mbps

Common Exam Trap: T1 = 1.544 Mbps (US standard), E1 = 2.048 Mbps (European standard). Do not confuse the two! E1 has more channels but is only used in countries following the E-carrier standard.

DSL — Digital Subscriber Line

DSL is a family of technologies that transmit digital data over existing telephone copper wires (the local loop). It enables high-speed internet access without requiring new cabling infrastructure.

ADSL Architecture

Asymmetric DSL (ADSL) is the most common variant. It provides different speeds for upstream (upload) and downstream (download), reflecting typical usage patterns where users download more than they upload.

FDM — Frequency Division Multiplexing

ADSL divides the telephone line into three separate frequency bands using FDM, allowing simultaneous voice and data transmission:

0-4 kHz → POTS (Voice) | 25-160 kHz → Upstream | 240 kHz-1.5 MHz → Downstream
Voice and data coexist on the same copper pair without interference

POTS0 - 4 kHzVoice callsN/A (analog)

Worked Example: ADSL Bandwidth Allocation

A home user has ADSL with maximum downstream of 8 Mbps and upstream of 800 kbps:

  • Phone call active: occupies 0-4 kHz → no impact on data speeds
  • Upstream band (25-160 kHz): carries 800 kbps upload
  • Downstream band (240 kHz-1.5 MHz): carries 8 Mbps download

Total bandwidth utilized: 8.8 Mbps simultaneously on a single phone line

Exam Point: DSL uses existing phone lines but requires a DSLAM (DSL Access Multiplexer) at the central office to separate voice and data. A splitter/filter at the customer premises also separates the signals.

T-Carrier System (North America / Japan)

The T-carrier system is a digital transmission hierarchy used primarily in North America and Japan. It uses Time-Division Multiplexing (TDM) to combine multiple DS0 (64 kbps) channels into higher-speed signals.

Base Channel
DS0 = 64 kbps (1 voice channel)
Digital Signal level 0 — the fundamental building block of the T-carrier hierarchy

T-Carrier Hierarchy Table

LevelDS LevelDS0 ChannelsSpeed (Mbps)Typical Use
T1DS1241.544Single office connection

T3DS367244.736Regional backbone
T4DS44,032274.176Long-haul backbone
Worked Example: T3 Bandwidth Calculation

A company needs to calculate T3 capacity:

  • T3 = 672 DS0 channels
  • Each DS0 = 64 kbps
  • Theoretical: 672 × 64 = 43,008 kbps = 43.008 Mbps

Actual T3 speed: 44.736 Mbps (includes framing and control bits)

The overhead for framing, synchronization, and signaling accounts for the difference

Exam Point: T-carrier speeds are NOT exact multiples of 64 kbps due to framing bits. T1 = 1.544 Mbps (not 1.536 Mbps). Always use the standard values from the table.

E-Carrier System (Europe / International)

The E-carrier system is the European digital transmission hierarchy. It differs from T-carrier in channel count and speed, and is the standard used in most countries outside North America and Japan.

E1 Base Calculation
32 channels × 64 kbps = 2.048 Mbps
E1 uses 30 data channels + 2 overhead channels (signaling + framing) = 32 total

Worked Example: E2 Bandwidth Verification

Verify E2 speed from E1 hierarchy:

  • E2 = 4 × E1 (four E1 multiplexed together)
  • E2 = 4 × 2.048 = 8.192 Mbps (theoretical)
  • Actual E2 speed = 8.448 Mbps (with overhead)

E2 supports 120 voice channels at 8.448 Mbps

Worked Example: International Link Capacity

A multinational company needs to connect offices in the US (T1) and Germany (E1):

  • US office: T1 = 1.544 Mbps (24 channels)
  • Germany office: E1 = 2.048 Mbps (30 channels)
  • Bottleneck: T1 at 1.544 Mbps limits throughput

Link capacity limited to 1.544 Mbps (T1 speed)

Solution: Use 2× T1 (3.088 Mbps) or upgrade to T3/E3

Common Mistake: E1 has 32 TOTAL channels but only 30 DATA channels. The 2 overhead channels (CH0 for framing, CH16 for signaling) carry no user data. Always specify "30 data channels" when asked.

SONET/SDH — Synchronous Optical Networking

SONET (Synchronous Optical Network) is the North American standard, while SDH (Synchronous Digital Hierarchy) is the international equivalent. Both define optical carrier (OC) levels for high-speed fiber optic transmission.

Worked Example: OC-48 Speed Verification

Calculate OC-48 speed using the formula:

  • OC-48 = 48 × 51.84 Mbps
  • OC-48 = 2,488.32 Mbps
  • OC-48 = 2.488 Gbps

OC-48 provides 2.488 Gbps bandwidth

Worked Example: OC-192 vs OC-48 Comparison

A backbone upgrade from OC-48 to OC-192:

  • OC-48: 2,488.32 Mbps
  • OC-192: 9,953.28 Mbps
  • Ratio: 9,953.28 ÷ 2,488.32 = 4× speed increase

OC-192 is exactly 4× faster than OC-48

This is expected: 192 ÷ 48 = 4, and OC speeds scale linearly

Worked Example: SONET Multiplexing

Multiplexing T3 signals into SONET:

  • 1 OC-1 = 51.84 Mbps
  • 1 T3 = 44.736 Mbps
  • Can fit: 51.84 ÷ 44.736 ≈ 1.16 (only 1 T3 per OC-1)

OC-1 can carry 1 T3 signal with overhead for framing

Higher OC levels (OC-3, OC-12) can carry multiple T3/E3 signals

Exam Point: SONET and SDH are the same technology with different naming conventions. OC-3 (SONET) = STM-1 (SDH) = 155.52 Mbps. Know both naming schemes for international exams.
