Slotted ALOHA Formulas

Throughput Formula:
S = G × e^(-G)
Where S = throughput (successful transmissions per slot), G = offered load (average transmission attempts per slot)
Maximum Throughput:
S_max = 1/e ≈ 0.368 (36.8%)
Occurs at G = 1.0 (optimal offered load). Exactly double P-ALOHA's maximum!
Success Probability:
P_success = e^(-G)
Probability that exactly one station transmits in a given slot
Collision Probability:
P_collision = 1 - e^(-G) - G×e^(-G)
Probability that 2 or more stations transmit in the same slot
Vulnerable Period:
T_vulnerable = T_frame
Only 1 frame duration (half of P-ALOHA's 2T_frame)
Optimal Load:
G_optimal = 1.0
Maximum throughput achieved when offered load equals 1
Key Insight: S-ALOHA achieves 36.8% efficiency, exactly twice that of P-ALOHA (18.4%). This is because the vulnerable period is halved from 2T to T.

Worked Examples

Example 1: Basic Throughput Calculation

Given: G = 1.0 (offered load)

S = G × e^(-G) = 1.0 × e^(-1) = 1.0 × 0.368 = 0.368 (36.8%)

Example 2: Success Probability

Given: G = 2.0 (offered load)

P_success = e^(-2) = 0.135 (13.5%)

Example 3: Throughput at Different Loads

G = 0.5: S = 0.5 × e^(-0.5) = 0.5 × 0.607 = 0.303 (30.3%)

G = 1.0: S = 1.0 × e^(-1) = 1.0 × 0.368 = 0.368 (36.8%)

G = 2.0: S = 2.0 × e^(-2) = 2.0 × 0.135 = 0.271 (27.1%)

Example 4: Network Capacity

Given: Channel data rate = 1 Mbps, frame size = 500 bits, slot time = 0.5 ms

Maximum throughput = 36.8% × 1 Mbps = 368 kbps

Example 5: Comparing P-ALOHA and S-ALOHA

For same offered load G = 1.0:

P-ALOHA: S = 1.0 × e^(-2×1) = 1.0 × 0.135 = 0.135 (13.5%)

S-ALOHA: S = 1.0 × e^(-1) = 1.0 × 0.368 = 0.368 (36.8%)

S-ALOHA is 2.73 times better at this load

Example 6: Number of Stations

Given: N = 50 stations, each transmits with probability p = 0.02 per slot

G = N × p = 50 × 0.02 = 1.0

S = 1.0 × e^(-1) = 0.368 (36.8%)

Average successful transmissions per slot = 0.368 frames
