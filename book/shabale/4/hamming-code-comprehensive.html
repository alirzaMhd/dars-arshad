Hamming Distance

Hamming distance is the number of bit positions where two codewords differ. It is a fundamental concept in error detection and correction.

Hamming Distance Definition:
d(x, y) = number of positions where x and y differ
Example: d(10101, 10011) = 2 (bits 3 and 4 differ)

Minimum Hamming Distance

Error Detection

• Minimum distance d+1

• Can detect up to d errors

• Example: d=2 detects 1 error

Error Correction

• Minimum distance 2t+1

• Can correct up to t errors

• Example: d=3 corrects 1 error

Error Detection/Correction Capability:
Detect: d_min ≥ e+1 | Correct: d_min ≥ 2t+1
e = number of errors to detect, t = number of errors to correct
Example 1: Hamming Distance Calculation

Calculate Hamming distance between codewords: 000000, 010101, 101010, 111111

Answer:

d(000000, 010101) = 3

d(000000, 101010) = 3

d(000000, 111111) = 6

d(010101, 101010) = 6

d(010101, 111111) = 3

d(101010, 111111) = 3

Minimum distance = 3

Example 2: Error Capability

If minimum Hamming distance is 5, what errors can be detected and corrected?

Answer:

Detect: d ≥ e+1 → 5 ≥ e+1 → e ≤ 4 (detect up to 4 errors)

Correct: d ≥ 2t+1 → 5 ≥ 2t+1 → t ≤ 2 (correct up to 2 errors)

Hamming Code

Hamming code is an error-correcting code that can detect up to 2-bit errors and correct 1-bit errors. It adds parity bits at positions that are powers of 2 (1, 2, 4, 8, 16, ...).

Hamming Code Structure:
r + m + 1 ≤ 2^r
r = number of parity bits, m = number of data bits, n = r + m (total codeword length)

Parity Bit Positions

Position 1 2 3 4 5 6 7 8
Type P1 P2 D1 P4 D2 D3 D4 P8

Parity Bit Coverage

P1 (position 1): 1, 3, 5, 7, 9, 11, ... (binary has 1 in position 0) P2 (position 2): 2, 3, 6, 7, 10, 11, ... (binary has 1 in position 1) P4 (position 4): 4, 5, 6, 7, 12, 13, ... (binary has 1 in position 2) P8 (position 8): 8, 9, 10, 11, 12, ... (binary has 1 in position 3)
Example 3: Hamming Code for 4-bit data

Data: 1011. Calculate Hamming code.

Answer:

Need r bits: r + 4 + 1 ≤ 2^r → r = 3 (3 + 4 + 1 = 8 ≤ 8)

Codeword positions: 1(P1), 2(P2), 3(D1=1), 4(P4), 5(D2=0), 6(D3=1), 7(D4=1)

P1 covers 1,3,5,7: P1 ⊕ 1 ⊕ 0 ⊕ 1 = 0 → P1 = 0

P2 covers 2,3,6,7: P2 ⊕ 1 ⊕ 1 ⊕ 1 = 0 → P2 = 1

P4 covers 4,5,6,7: P4 ⊕ 0 ⊕ 1 ⊕ 1 = 0 → P4 = 0

Result: 0110101

Example 4: Parity Bit Calculation

For data 1101, what are the parity bit values?

Answer:

Data bits: D1=1 (pos 3), D2=1 (pos 5), D3=0 (pos 6), D4=1 (pos 7)

P1 (even parity for 1,3,5,7): 1⊕1⊕1 = 1, need P1=1 to make even

P2 (even parity for 2,3,6,7): 1⊕0⊕1 = 0, need P2=0 to make even

P4 (even parity for 4,5,6,7): 1⊕0⊕1 = 0, need P4=0 to make even

Result: P1=1, P2=0, P4=0

Syndrome Calculation

The syndrome is calculated by the receiver to detect and locate errors. It is the XOR of all positions where the received bit is 1.

Syndrome Calculation:
S = position of received 1-bits (XOR)
If syndrome = 0: no error. If syndrome = k: error at position k.

Syndrome Calculation Process

1. Write received codeword 2. Identify all positions with 1-bits 3. XOR all these positions 4. Result = syndrome 5. If syndrome = 0 → No error 6. If syndrome ≠ 0 → Error at position = syndrome
Example 5: Syndrome Calculation

Received: 0110101. Calculate syndrome.

Answer:

Positions with 1-bits: 2, 3, 5, 7

Syndrome = 2 ⊕ 3 ⊕ 5 ⊕ 7

= 010 ⊕ 011 ⊕ 101 ⊕ 111

= 001 ⊕ 101 ⊕ 111

= 100 ⊕ 111

= 011 = 3

Error at position 3!

Example 6: Error Correction

Received: 0110101, Syndrome = 3. Correct the error.

Answer:

Error at position 3, so flip bit at position 3

Received: 0 1 1 0 1 0 1

Corrected: 0 1 0 0 1 0 1

Example 7: No Error Case

Received: 0110001. Calculate syndrome.

Answer:

Positions with 1-bits: 2, 3, 7

Syndrome = 2 ⊕ 3 ⊕ 7 = 010 ⊕ 011 ⊕ 111 = 001 ⊕ 111 = 110 = 6

Error at position 6!

Important: Hamming code can only correct single-bit errors. If two or more bits are flipped, the syndrome may point to the wrong position. Extended Hamming code (with extra parity bit) can detect 2-bit errors.

Example 9: 2-Error Detection

Can Hamming code detect 2-bit errors? Show example.

Answer:

Basic Hamming code: NO (it corrects 1 error, but 2 errors may go undetected)

Extended Hamming code (SEC-DED): YES (adds overall parity bit)

Example 10: Hamming Distance of Code

What is the minimum Hamming distance of a standard Hamming code?

Answer: 3

This means it can detect 2 errors or correct 1 error.

Example 11: Overhead Calculation

Calculate overhead for Hamming code with 8-bit data.

Answer:

Need r = 4 parity bits (r + 8 + 1 ≤ 2^r → 13 ≤ 16)

Total bits = 8 + 4 = 12

Overhead = (4 / 12) × 100 = 33.3%

Example 12: Application Comparison

When to use: (a) Parity, (b) CRC, (c) Hamming code?

Answer:

(a) Parity: Simple systems, memory ECC

(b) CRC: Network protocols, storage

(c) Hamming code: RAM, caches, high-reliability systems

Key Insight: As data bits increase, the overhead percentage decreases, making Hamming code more efficient for larger data blocks.
Hamming Code Efficiency:
Efficiency = m / (m + r) × 100%
Where m = data bits, r = parity bits. Efficiency improves with larger data blocks.
