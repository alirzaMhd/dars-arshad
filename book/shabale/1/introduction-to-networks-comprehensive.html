What is a Computer Network?

Definition:
A computer network is a collection of interconnected devices that share resources and communicate with each other.
Multiple computers linked together to exchange data and share resources

Key Characteristics

Resource Sharing

• Share files, printers, internet connections

• Reduces hardware costs

• Centralized data management

Communication

• Email, messaging, video calls

• Real-time collaboration

• Global connectivity

Reliability

• Backup and redundancy

• Fault tolerance

• Load balancing

Important: Networks can be as small as two computers in a room or as large as millions of devices worldwide (Internet).

Network Components

Hardware Components

End Devices

• Computers, laptops

• Smartphones, tablets

• Servers, printers

Intermediary Devices

• Routers

• Switches

• Hubs, bridges

Transmission Media

• Cables (copper, fiber)

• Wireless (Wi-Fi, Bluetooth)

• Microwaves, satellites

Software Components

Network OS

• Windows Server

• Linux

• macOS Server

Protocols

• TCP/IP

• HTTP/HTTPS

• FTP, SMTP

Network Applications

Common Applications

Web Browsing

• Uses HTTP/HTTPS protocols

• Client-server model

• Access websites and services

Email

• SMTP for sending

• POP3/IMAP for receiving

• Asynchronous communication

File Transfer

• FTP/SFTP protocols

• Upload/download files

• Cloud storage access

Streaming

• Video/audio streaming

• Real-time protocols (RTP)

• High bandwidth required

Example 1: Web Browsing

When you visit a website:

1. Your browser (client) sends a request to the web server

2. Server processes the request and sends back the webpage

3. Browser renders the HTML/CSS/JS content

Uses HTTP protocol on port 80 or HTTPS on port 443

Worked Examples

Example 1: Network Classification

A small office has 10 computers connected to share a printer and internet connection.

Question: What type of network is this?

Answer: LAN (Local Area Network) - covers a small geographic area like an office building

Example 2: E-Commerce Type

A company sells office supplies to another company for their employees.

Question: What e-commerce type is this?

Answer: B2B (Business to Business) - one business selling to another business

Example 3: Network Components

A home user wants to connect their laptop, phone, and tablet to the internet.

Question: What hardware components are needed?

Answer: Router (to connect devices), Modem (to connect to ISP), and Wireless access point (for Wi-Fi)

Example 4: Application Protocol

A user wants to send an email attachment to a colleague.

Question: What protocol is used?

Answer: SMTP (Simple Mail Transfer Protocol) for sending, POP3/IMAP for receiving

Example 5: Network Purpose

A company wants to ensure their data is safe even if one server fails.

Question: What network feature addresses this?

Answer: Redundancy and fault tolerance - multiple servers provide backup if one fails
