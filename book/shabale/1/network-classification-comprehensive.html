Network Classification

SAN • PAN • LAN • MAN • WAN — Complete Guide for Exam Preparation

Network Classification Overview

Core Concept:
Networks are classified by their geographic scope — the physical area they cover.
Each type is defined by its range, speed, ownership, and typical use case.
Key Exam Point: The classification is based on geographic coverage, not the number of devices. A LAN with 1000 devices is still a LAN if it stays within one building.

SAN Storage Area Network

Definition:
A high-speed, specialized network that provides block-level access to consolidated data storage.
SAN connects servers to storage devices (tape libraries, disk arrays) at the data-block level, not file level.

Key Characteristics

Scope

• Typically within a data center

• Can span multiple rooms/buildings

• Not accessible from the public Internet

Speed

• 1 Gbps to 128 Gbps (Fibre Channel)

• Very low latency

• Dedicated bandwidth

Technology

• Fibre Channel (FC)

• iSCSI (TCP/IP-based)

• FCoE (Fibre Channel over Ethernet)

Use Cases

• Enterprise data centers

• Database servers

• Cloud storage infrastructure

• Disaster recovery

Fibre Channel Speeds:
FC-1G = 1 Gbps  |  FC-2G = 2 Gbps  |  FC-4G = 4 Gbps  |  FC-8G = 8 Gbps  |  FC-16G = 16 Gbps  |  FC-32G = 32 Gbps
Doubles each generation. FC-128G is the latest standard.
Key Formula — Storage Throughput:
Throughput = Number of Links × Bandwidth per Link × Utilization Factor
Example: 4 links × 16 Gbps × 0.9 = 57.6 Gbps effective throughput

PAN Personal Area Network

Definition:
A network centered around an individual person, covering a range of approximately 1–10 meters.
PAN connects personal devices like smartphones, tablets, wearables, and headphones around one person.

Key Characteristics

Range

• 1 to 10 meters

• Typically within arm’s reach

• Body-area networks: even closer

Speed

• Bluetooth Classic: 1–3 Mbps

• Bluetooth LE: 125 Kbps–2 Mbps

• USB: up to 40 Gbps (USB4)

Technologies

• Bluetooth / BLE

• Infrared (IrDA)

• NFC (Near Field Communication)

• USB / Zigbee

• Wi-Fi Direct

Use Cases

• Wireless headphones

• Smartwatch sync

• Tethering phone to laptop

• Medical body sensors

PAN Topology

┌───────────────┐ │ Smartphone │◄── Bluetooth ──► Wireless Earbuds │ │◄── Bluetooth ──► Smartwatch │ │◄── NFC ────────► Payment Terminal │ │◄── USB ────────► Laptop └───────────────┘ ↑ Star topology centered on the person
Common Confusion: PAN vs. LAN — A PAN is personal (one person’s devices). A LAN covers a building. If your phone connects to your laptop via Bluetooth, that’s PAN. If both connect to a Wi-Fi router, that’s LAN.

LAN Local Area Network

Definition:
A network that connects devices within a limited geographic area such as a home, office, or building.
LAN is the most common network type. Usually owned and managed by a single organization.

Key Characteristics

Range

• Up to 1–2 km

• Single building or campus

• Typically < 1 km practical

Speed

• Ethernet: 100 Mbps – 100 Gbps

• Wi-Fi 6: up to 9.6 Gbps

• Wi-Fi 6E/7: even faster

Ownership

• Privately owned

• Managed by IT department

• No recurring ISP fees (for internal traffic)

Technologies

• Ethernet (IEEE 802.3)

• Wi-Fi (IEEE 802.11a/b/g/n/ac/ax)

• Switches & Routers

LAN Speed Formula (Ethernet):
Data Rate = Cable Standard × Number of Lanes
Example: 10 Gbps base × 4 lanes (40G Ethernet) = 40 Gbps
Wi-Fi Data Rate (approximate):
Rate = Subcarriers × Bits per Subcarrier × Coding Rate / Symbol Duration
Wi-Fi 6 (802.11ax): up to 9.6 Gbps with 8 spatial streams, 1024-QAM

MAN Metropolitan Area Network

Definition:
A network that spans an entire city or metropolitan area, typically 5–50 km.
MAN connects multiple LANs across a city using high-speed fiber optic or wireless links.

Key Characteristics

Range

• 5 to 50 km

• City-wide coverage

• Multiple connected buildings

Speed

• 100 Mbps to 10+ Gbps

• Fiber backbone

• microwave, WiMAX

Ownership

• ISP or consortium

• Shared or leased infrastructure

• Municipal networks

Examples

• City-wide cable TV networks

• Municipal Wi-Fi

• University campus networks

• WiMAX deployments

MAN vs. WAN: MAN covers one city. WAN covers multiple cities or countries. A MAN is often operated by a single ISP, while WANs use leased lines from multiple carriers.

WAN Wide Area Network

Definition:
A network that spans large geographic areas — countries, continents, or the entire globe.
WAN connects multiple LANs and MANs over long distances using leased lines, satellites, or the Internet.

Key Characteristics

Range

• Hundreds to thousands of km

• Country-wide or global

• The Internet is the largest WAN

Speed

• Varies: 56 Kbps (dial-up) to 100+ Gbps

• Depends on carrier & medium

• Higher latency than LAN/MAN

Ownership

• Telecommunication companies

• Multiple ISPs

• Leased lines / MPLS / VPN

Technologies

• MPLS

• Frame Relay

• ATM

• Satellite links

• VPN over Internet

WAN Bandwidth Formula:
Effective BW = Link Speed × (1 − Overhead%) − Latency Penalty
TCP throughput over WAN ≈ Window Size / Round-Trip Time (RTT). High latency reduces effective throughput.
Bandwidth-Delay Product (BDP):
BDP = Bandwidth × RTT
Determines how much data must “in flight” to fill the pipe. Example: 1 Gbps × 50ms = 6.25 MB window needed.

Bonus Network Types

HAN Home Area Network

Range: Single home/residence

Speed: 100 Mbps – 10 Gbps

Use: Smart home devices, streaming, home Wi-Fi

Subset of LAN focused on residential use.

CAN Campus Area Network

Range: Multiple buildings in a campus (1–5 km)

Speed: 1–100 Gbps backbone

Use: Universities, corporate campuses, military bases

Interconnects multiple LANs within a campus.

WLAN Wireless LAN

Range: Same as LAN but wireless

Speed: Wi-Fi 6: 9.6 Gbps

Use: Offices, homes, cafes

LAN using IEEE 802.11 standards instead of cables.

Speed vs. Range Trade-off

General Rule:
As geographic range increases, typical bandwidth decreases (and latency increases).
SAN (128 Gbps) > LAN (100 Gbps) > MAN (10 Gbps) > WAN (variable) > PAN (40 Gbps USB, but usually lower wireless)

Network Topologies Overview

Topology:
Topology is the physical or logical arrangement of nodes and links in a network.
Physical topology = actual cable layout. Logical topology = how data flows.

Topology Comparison

Topology Description Pros Cons Used In
Bus All devices share a single cable (backbone) Simple, cheap Single point of failure, hard to troubleshoot Legacy LAN, cable TV
Star All devices connect to a central hub/switch Easy to manage, fault isolation Central device is single point of failure Modern LAN, Wi-Fi
Ring Devices form a circular chain Equal access, no collisions One break disrupts entire ring Token Ring, FDDI
Mesh Every device connects to every other (full) or some (partial) High redundancy, fault tolerance Expensive, complex cabling WAN backbone, SAN fabrics
Tree Hierarchical combination of star topologies Scalable, organized Root failure affects entire subtree Large LAN, campus networks
Hybrid Combination of two or more topologies Flexible, optimized Complex design Enterprise WAN, MAN

Topology Formulas

Number of Links in Full Mesh:
Links = n(n − 1) / 2
Where n = number of nodes. Example: 5 nodes = 5(4)/2 = 10 links
Max Nodes in Star Topology:
Max nodes = Switch Port Count
24-port switch → 24 devices. Cascading switches increases total.
Ring Topology — Max Failures Tolerated:
Single Ring: 0  |  Dual Ring (FDDI): 1 link failure
Dual ring wraps around a single break for self-healing.
Bus Topology — Collision Domain:
Shared medium → Half-duplex → Collisions possible
CSMA/CD manages collisions. Switched star = full-duplex = no collisions.
Network Diameter (Star):
Diameter = 2 hops (PC → Switch → PC)
Always 2 in a single-switch star. For tree: 2 × depth.

Addressing & MAC Address Formula

MAC Address:
48 bits = 6 bytes = XX:XX:XX:XX:XX:XX
First 3 bytes = OUI (manufacturer). Last 3 bytes = device ID. Total: 2^48 ≈ 281 trillion addresses.
IPv4 Address:
32 bits = 4 octets = A.B.C.D
Total: 2^32 ≈ 4.3 billion addresses. Classful: A(0-127), B(128-191), C(192-223), D(multicast), E(reserved).
IPv6 Address:
128 bits = 8 groups of 16-bit hexadecimal
Total: 2^128 ≈ 3.4 × 10^38 addresses. Written as xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
Subnet Mask (CIDR):
/n → n bits for network, (32-n) bits for hosts
/24 → 256 addresses, /16 → 65536 addresses. Usable hosts = 2^(32-n) - 2 (subtract network + broadcast).

Common Mistakes & Warnings

Mistake 1: Confusing SAN with LAN

SAN (Storage Area Network) is NOT a general-purpose network. It is a specialized network exclusively for storage traffic. A LAN carries all types of data (web, email, files). SAN carries only storage I/O between servers and disk arrays.

Mistake 2: PAN vs. LAN boundary

If devices connect through a Wi-Fi router in a house — that’s a LAN (or HAN). If your phone connects to your earbuds via Bluetooth — that’s a PAN. The key: PAN is one person’s personal bubble; LAN serves a group in a space.

Mistake 3: WAN = the Internet

The Internet is an WAN, but not all WANs are the Internet. A corporate MPLS network spanning cities is a WAN but uses private leased lines, not public Internet.

Mistake 4: MAN covers multiple cities

MAN is limited to one metropolitan area. If a network spans two cities, it is a WAN, not a MAN.

Mistake 5: Topology = Physical layout

A network can have a physical star topology but logical bus topology (via a hub). With a switch, both physical and logical topologies are star. Always specify which you mean.

Mistake 6: Bandwidth = Speed

Bandwidth is the maximum data rate (capacity). Actual throughput depends on latency, congestion, protocol overhead, and window size. A 1 Gbps WAN link may only deliver 100 Mbps effective throughput due to high RTT.

Mistake 7: Mesh topology = every node to every node

Full mesh connects every node to every other (n(n-1)/2 links). Partial mesh connects some nodes. WANs almost always use partial mesh due to cost.

Mistake 8: Forgetting the Bandwidth-Delay Product

For WAN links: BDP = Bandwidth × RTT. If you don’t set TCP window size ≥ BDP, you won’t fill the pipe. A 1 Gbps link with 100ms RTT needs at least 12.5 MB TCP window.

Worked Examples

Example 1: Classifying a Network

A hospital has 5 buildings on its campus. Each building has its own Ethernet network. The buildings are connected via fiber optic cables forming a high-speed backbone within the campus.

Question: What type of network is this?

Solution:

1. Each building has a LAN (within a building).

2. The buildings are in the same campus (not across a city).

3. Multiple LANs connected within a campus = CAN (Campus Area Network)

If the buildings were across a city (different neighborhoods), it would be a MAN. Since they share a campus, CAN is the precise answer.

Example 2: Storage Network Design

A company needs 3 servers to access a shared storage array holding 500 TB of database data. The access must be at block level with sub-millisecond latency.

Question: What network type should they deploy?

Solution:

1. Block-level access → not file-level (rules out NAS/NFS).

2. Sub-millisecond latency → requires dedicated, lossless network.

3. Multiple servers → shared storage fabric.

Answer: SAN (Storage Area Network) using Fibre Channel switches

SAN provides block-level access via FC or iSCSI. NAS provides file-level access and would not meet the sub-ms latency requirement as reliably.

Example 3: Mesh Topology Calculation

A WAN backbone connects 8 cities. The network engineer wants full mesh topology for redundancy.

Question: How many links are needed?

Solution:

Using the formula: Links = n(n-1)/2

Links = 8(8-1)/2 = 8 × 7 / 2 = 56/2 = 28 links

Each city connects to 7 others. Total bidirectional links = 28. This is expensive, so most WANs use partial mesh instead.

Example 4: Bandwidth-Delay Product

A WAN link has 2 Gbps bandwidth and 80 ms round-trip time (RTT) between New York and London.

Question: What is the minimum TCP window size needed to fully utilize this link?

Solution:

BDP = Bandwidth × RTT

BDP = 2 × 10^9 bits/s × 0.080 s

BDP = 160,000,000 bits = 20 MB (megabytes)

TCP window must be at least 20 MB. Standard TCP (16-bit window field, max 64 KB) is insufficient. Must use TCP Window Scaling (RFC 7323) or select ACKs.

Example 5: Network Type Identification

A user has a smartwatch connected to a smartphone via Bluetooth. The smartphone is connected to a home Wi-Fi router. The router connects to an ISP modem which links to the Internet.

Question: Identify each network type in this chain.

Solution:

1. Smartwatch ↔ Smartphone (Bluetooth, 1-3m) → PAN

2. Smartphone ↔ Wi-Fi Router (within home) → LAN / HAN

3. Router ↔ ISP Modem → WAN

4. ISP ↔ Internet → WAN (global)

This shows how multiple network types coexist. The same device (smartphone) participates in PAN, LAN, and WAN simultaneously.

Exam-Style Questions

Q1: Quick Classification

A company connects its main office and two branch offices across Tehran using leased fiber optic lines from a telecom provider.

Answer: WAN (multiple cities, leased lines, telecom provider)

Q2: Topology Calculation

In a full mesh network with 6 routers, how many links exist? If one link fails, can all routers still communicate?

Links = 6(5)/2 = 15 links. Yes, partial mesh still has alternate paths.

Q3: Protocol Matching

Match each network type with its primary protocol: SAN, PAN, LAN, WAN.

SAN → Fibre Channel | PAN → Bluetooth | LAN → Ethernet/Wi-Fi | WAN → MPLS/BGP

Q4: Speed Comparison

Which has higher bandwidth: a Bluetooth PAN or a fiber-optic SAN?

SAN: up to 128 Gbps. Bluetooth PAN: 1-3 Mbps. SAN is ~40,000x faster.

Q5: Practical Scenario

A university campus has 3 buildings, each with its own network. They are connected via fiber. A student accesses a server in Building A from Building C. What network types are involved?

CAN (campus backbone connecting 3 LANs). If the student also uses Bluetooth headphones: PAN + LAN + CAN.
