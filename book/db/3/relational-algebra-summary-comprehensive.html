Example 1: Selection

σ_{salary > 50000}(EMPLOYEE)

Selects all employees with salary greater than 50000.

Example 2: Projection

π_{name, salary}(EMPLOYEE)

Returns only name and salary columns from employee.

Set Operations

Requirements:
Union Compatibility
Both relations must have same number of attributes, and corresponding attributes must have compatible domains.
Example 3: Union

EMPLOYEES ∪ MANAGERS

Returns all distinct employees and managers.

Example 4: Set Difference

EMPLOYEES − MANAGERS

Returns employees who are NOT managers.

Example 5: Intersection

EMPLOYEES ∩ MANAGERS (can be expressed as EMPLOYEES − (EMPLOYEES − MANAGERS))

Returns employees who are also managers.

Example 6: Natural Join

EMPLOYEE ⋈ DEPARTMENT

Joins Employee and Department on common attribute (DeptID).

Example 7: Left Outer Join

EMPLOYEE ⟕ WORKS_ON

Returns all employees, including those not assigned to any project.

Example 8: Division

STUDENT_COURSES ÷ REQUIRED_COURSES

Returns students who have taken ALL required courses.

Complete Worked Examples

Example 9: Complex Query

Query: Find names of employees who work on project 'Database' and earn more than 50000

π_{name}(σ_{salary > 50000}(EMPLOYEE ⋈ (σ_{proj_name = 'Database'}(PROJECT ⋈ WORKS_ON)))

Example 10: Department Statistics

Query: Find departments with average salary greater than 60000

𝒢_{dept_id, AVG(salary) → avg_sal}(EMPLOYEE) | (avg_sal > 60000)

Example 11: Find Students Taking All Required Courses

π_{student_id, course_id}(ENROLLS) ÷ π_{course_id}(σ_{required = 'Y'}(COURSES))
