SELECTION & PROJECTION

Database Systems — Basic Relational Algebra Operations

Selection Operation (σ)

The selection operation filters tuples based on a condition. It works on rows.

Notation:
σ_condition(R)
Returns all tuples in R that satisfy the condition.
Properties:
σ_c(R) ⊆ R
Result is always a subset of the original relation (or equal if condition is always true).

Projection Operation (π)

The projection operation selects specific columns from a relation. It works on columns.

Notation:
π_A₁,A₂,...,Aₙ(R)
Returns only the specified attributes from R. Duplicate rows are removed.
Properties:
π_A(R) ⊆ R
Result has fewer or equal attributes than original. Duplicates are eliminated.
Example 3: Basic Projection

Given Employee(EmpID, Name, Dept, Salary):

Combined Selection and Projection

Reading Order:
π_A,B(σ_condition(R))
First apply selection (filter rows), then projection (select columns).

Key Rules to Remember

✓ Selection filters rows, Projection selects columns

✓ Projection removes duplicates by default

✓ Apply selection before projection for efficiency

✓ Selection result has same schema as input

✓ Projection result has fewer attributes than input
