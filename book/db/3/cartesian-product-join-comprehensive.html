CARTESIAN PRODUCT & JOIN OPERATIONS

Database Systems — Combining Relations for Exam Preparation

Cartesian Product (×)

The Cartesian product combines every tuple of one relation with every tuple of another relation.

Notation:
R × S
If R has m tuples and S has n tuples, R × S has m × n tuples.
Schema:
R(A₁,...,Aₙ) × S(B₁,...,Bₘ) = T(A₁,...,Aₙ,B₁,...,Bₘ)
Result contains all attributes from both relations.

Size Warning:

Cartesian product can produce very large results. If |R| = 1000 and |S| = 1000, then |R × S| = 1,000,000!

Natural Join (⋈)

The natural join combines tuples from two relations where common attributes have equal values, and removes duplicate columns.

Definition:
R ⋈ S = π_R.*,S.*_non-common(σ_R.common = S.common(R × S))
Filter Cartesian product where common attributes match, then remove duplicate columns.

Natural Join Properties

• Combines on common attributes

• Removes duplicate columns

• Similar to INNER JOIN

Requirements

• Common attributes must have same domain

• Result degree = deg(R) + deg(S) - |common|

Theta Join (⋈_θ)

The theta join is a generalized join using any comparison operator θ.

Definition:
R ⋈_θ S = σ_θ(R × S)
A selection on the Cartesian product using condition θ.
Example 3: Theta Join

Given Student and Course with Grade and MinGrade:

Student ⋈_{Grade ≥ MinGrade} Course

Only combines tuples where student's grade meets or exceeds minimum required grade.

Example 4: Equi-Join

An equi-join is a theta join where θ uses only equality (=):

R ⋈_{R.A = S.B} S

Natural join is a special case of equi-join on all common attributes.

Example 6: Complex Join Query

Find suppliers in London who shipped part P1:

π_Sname(σ_City='London' ∧ P#='P1'(S ⋈ SP))

Combine S and SP, filter by city and part number, then project supplier name.

Example 7: Join with Selection

Find all parts shipped by supplier S1:

P ⋈ (σ_S#='S1'(SP))

First filter SP for S1's shipments, then join with P to get part details.

Key Rules to Remember

✓ Cartesian product multiplies all tuples

✓ Natural join matches on common attributes

✓ Theta join uses any comparison operator

✓ Join is commutative: R ⋈ S = S ⋈ R

✓ Join is associative: (R ⋈ S) ⋈ T = R ⋈ (S ⋈ T)
