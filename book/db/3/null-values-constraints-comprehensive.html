NULL VALUES & CONSTRAINTS

Database Systems — NULL Handling and Constraints for Exam Preparation

Understanding NULL Values

NULL represents a missing, unknown, or inapplicable value. It is NOT the same as zero, empty string, or any other value.

NULL Properties:
NULL ≠ NULL
NULL is not equal to any value, including itself. Use IS NULL or IS NOT NULL for comparisons.

Unknown Value

The value exists but we don't know it

Example: Employee's middle name

Missing Information

The data hasn't been entered yet

Example: Student's GPA (new student)

Not Applicable

The attribute doesn't apply to this tuple

Example: Spouse name for single person

NOT NULL Constraint

The NOT NULL constraint ensures that an attribute cannot have NULL values.

Constraint Rule:
A ≠ NULL for all tuples
Every tuple must have a value for attribute A.
Example 2: NOT NULL in SQL
CREATE TABLE Employee (
  EmpID INT NOT NULL PRIMARY KEY,
  Name VARCHAR(50) NOT NULL,
  Phone VARCHAR(20), -- NULL allowed
  Salary DECIMAL(10,2) NOT NULL
);
When to Use NOT NULL:

✓ Primary key attributes (always NOT NULL)

✓ Essential information (Name, Date of Birth)

✓ Foreign keys (unless NULL has meaning)

✗ Optional information (Phone, Middle Name)

NULL in Relational Operations

Three-Valued Logic

When NULL is involved, comparisons result in TRUE, FALSE, or UNKNOWN.

ExpressionResult
5 = NULLUNKNOWN
NULL = NULLUNKNOWN
NULL > 5UNKNOWN
NULL IS NULLTRUE
NULL IS NOT NULLFALSE
Example 3: NULL in WHERE Clause
-- WRONG: This won't find NULLs
SELECT * FROM Employee WHERE Phone = NULL;

-- RIGHT: Use IS NULL
SELECT * FROM Employee WHERE Phone IS NULL;

NULL in Aggregate Functions

FunctionNULL Handling
COUNT(*)Counts all rows (including NULLs)
COUNT(A)Counts rows where A is NOT NULL
SUM(A)Ignores NULL values
AVG(A)Ignores NULL values
MIN/MAX(A)Ignores NULL values

Worked Examples

Example 4: NULL with Selection

Given Employee(EmpID, Name, Phone, Salary):

EmpIDNamePhoneSalary
E1John555-123450000
E2JaneNULL60000
E3Bob555-5678NULL

σ(Phone = '555-1234')(Employee) → Returns only E1

σ(Phone IS NULL)(Employee) → Returns only E2

σ(Salary > 50000)(Employee) → Returns only E2 (E3 excluded due to NULL)

Example 5: NULL with Projection

π(Phone)(Employee) → {555-1234, NULL, 555-5678}

Projection includes NULL values in the result.

Example 6: NULL in Joins

When joining tables, NULL in FK will NOT match any PK value:

Employee ⋈ Department → E2 (Phone=NULL) won't match any department

Use OUTER JOIN to include tuples with NULL FK values.
