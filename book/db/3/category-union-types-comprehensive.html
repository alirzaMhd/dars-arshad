CATEGORY (UNION TYPES)

Database Systems — Union of Different Entity Types for Exam Preparation

What is a Category?

A category (union type) represents a collection of entities that are the union of entities from different entity types.

Definition:
Category = Union of E₁, E₂, ..., Eₙ
A category contains entities that belong to at least one of the contributing entity types.
Example 1: Category Concept

Consider an Owner entity type:

  • An Owner can be a Person
  • An Owner can be a Company
  • An Owner can be a Bank

Owner is a category that is the union of Person, Company, and Bank.

Category Properties

• Union of different entity types

• Each instance belongs to exactly one contributing type

• Has its own identifier

Notation

• Shown as circle with "U" symbol

• Arrows from contributing types to category

SQL Implementation:

CREATE TABLE Owner (
  OwnerID INT PRIMARY KEY,
  OwnerType VARCHAR(20) CHECK (OwnerType IN ('Person','Company','Bank')),
  PersonSSN CHAR(11),
  CompanyTaxID CHAR(10),
  BankRouting CHAR(9),
  StartDate DATE,
  FOREIGN KEY (PersonSSN) REFERENCES Person(SSN),
  FOREIGN KEY (CompanyTaxID) REFERENCES Company(TaxID),
  FOREIGN KEY (BankRouting) REFERENCES Bank(RoutingNumber),
  CHECK ((OwnerType='Person' AND PersonSSN IS NOT NULL AND CompanyTaxID IS NULL AND BankRouting IS NULL) OR
         (OwnerType='Company' AND PersonSSN IS NULL AND CompanyTaxID IS NOT NULL AND BankRouting IS NULL) OR
         (OwnerType='Bank' AND PersonSSN IS NULL AND CompanyTaxID IS NULL AND BankRouting IS NOT NULL))
);

The CHECK constraint ensures that only one FK is non-NULL based on OwnerType.

Mapping Category to Relations

Mapping Rule:
Create a relation for the category with its own attributes plus a foreign key to each contributing type
Use a type discriminator to indicate which contributing type each instance belongs to.
