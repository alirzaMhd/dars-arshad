DIVISION OPERATION

Database Systems — The Divide Operator for Exam Preparation

What is Division (÷)?

The division operation finds tuples in one relation that are associated with all tuples in another relation.

Notation:
R(A,B) ÷ S(B) = T(A)
Returns values of A that are associated with ALL values of B in S.
Formal Definition:
R ÷ S = {t | ∀s ∈ S, (t,s) ∈ R}
A tuple t is in the result if for every tuple s in S, the combination (t,s) exists in R.

Step-by-Step Process

Example 2: Division Algorithm

To compute R(A,B) ÷ S(B):

  1. Project R onto A: π_A(R)
  2. For each value a in π_A(R):
    • Find all B values associated with a: π_B(σ_A=a(R))
    • Check if this set equals π_B(S)
    • If yes, include a in result

SQL Equivalent of Division

SQL Pattern:
SELECT A FROM R GROUP BY A HAVING COUNT(DISTINCT B) = (SELECT COUNT(*) FROM S)
Group by A, count distinct B values, keep only those matching S's count.
Example 6: SQL Division
-- Find suppliers who ship ALL parts
SELECT S#
FROM SP
GROUP BY S#
HAVING COUNT(DISTINCT P#) = (SELECT COUNT(*) FROM P);

-- Alternative: Using NOT EXISTS
SELECT S#
FROM SP AS sp1
WHERE NOT EXISTS (
  SELECT P# FROM P
  WHERE NOT EXISTS (
    SELECT * FROM SP AS sp2
    WHERE sp2.S# = sp1.S# AND sp2.P# = P.P#
  )
);
Key Insight:

Division is the inverse of Cartesian product. If R = A × B, then R ÷ B = A.

Quick Reference Card

Division Properties

PropertyDescription
R(A,B) ÷ S(B)Result has schema T(A)
Result ⊆ π_A(R)Result is always a subset of A values
Empty SIf S is empty, result = π_A(R)
No matchIf no A matches all B, result is empty

Division vs Other Operations

OperationQuestion Answered
Selection (σ)Which tuples satisfy condition?
Projection (π)What values exist for attributes?
Join (⋈)What combinations exist?
Division (÷)What is associated with ALL?

Key Rules to Remember

✓ Division answers "for all" queries

✓ Result schema has fewer attributes than dividend

✓ Division is not commutative: R ÷ S ≠ S ÷ R

✓ If S is empty, result = π_A(R)

✓ Division is lossless: (R ÷ S) × S ⊆ R
