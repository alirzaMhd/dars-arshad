NULL Values — Problems and Handling

Database Systems — Complete Guide for Exam Preparation

What is NULL?

NULL represents missing, unknown, or not applicable data. It is a special marker used in databases to indicate the absence of a value.

Definition
NULL ≠ 0 ≠ "" (empty string) ≠ FALSE
NULL is its own special value — it is NOT the same as zero, empty string, or false.

NULL vs Other Values

Value Meaning Example
NULL Unknown / Missing Phone number not provided
0 Known value of zero Score is zero (tested, got 0)
"" (empty string) Known value of nothing Name field left blank
FALSE Known boolean false Active = false (account deactivated)
NULL is NOT the same as 0, empty string, or FALSE. Always use IS NULL / IS NOT NULL to check for NULL.

When Does NULL Occur?

Optional Fields

No value provided

Phone number, middle name, email

Unknown Values

Value exists but is unknown

Employee salary unknown

Not Applicable

Field doesn't apply

Spouse name for unmarried person

Default Value

No default set

Column with no DEFAULT constraint

Problem 1: Comparison Operators Fail

Regular comparison operators (=, <, >, <=, >=, <>) do not work correctly with NULL.

Three-Valued Logic
NULL = NULL → UNKNOWN (not TRUE!)
Comparing NULL with anything always returns UNKNOWN, not TRUE or FALSE.
Example: Comparison Failure
-- These queries return NOTHING:
SELECT * FROM Employees WHERE Salary = NULL;
SELECT * FROM Employees WHERE Salary <> NULL;
SELECT * FROM Employees WHERE Salary > NULL;

-- Correct way:
SELECT * FROM Employees WHERE Salary IS NULL;
SELECT * FROM Employees WHERE Salary IS NOT NULL;

Problem 2: Aggregate Functions

Most aggregate functions ignore NULL values, which can give unexpected results.

Example: Aggregate with NULL
EmpID Name Salary
1 Ahmed 5000
2 Sara 6000
3 Ali NULL
SELECT AVG(Salary) FROM Employees;
-- Result: 5500 (only 2 values: (5000+6000)/2)
-- NOT 3667 (which would include NULL as 0)

SUM, AVG, COUNT(column) ignore NULL. COUNT(*) counts all rows including NULLs.

Problem 3: Outer Joins Required

To include rows with NULL in joins, you must use OUTER JOIN instead of INNER JOIN.

Example: INNER JOIN vs OUTER JOIN
-- INNER JOIN excludes NULL foreign keys
SELECT * FROM Students s
JOIN Departments d ON s.DeptID = d.DeptID;
-- Student with NULL DeptID is EXCLUDED

-- OUTER JOIN includes NULL foreign keys
SELECT * FROM Students s
LEFT JOIN Departments d ON s.DeptID = d.DeptID;
-- Student with NULL DeptID IS included (with NULL dept info)

Problem 4: Three-Valued Logic

SQL uses three-valued logic: TRUE, FALSE, and UNKNOWN. NULL produces UNKNOWN in comparisons.

Logic Truth Table
TRUE AND UNKNOWN = UNKNOWN
FALSE AND UNKNOWN = FALSE
TRUE OR UNKNOWN = TRUE
FALSE OR UNKNOWN = UNKNOWN
Example: WHERE Clause with NULL
-- This row will NOT be returned:
SELECT * FROM Employees WHERE Salary > 4000;
-- If Salary is NULL, comparison returns UNKNOWN
-- WHERE clause only returns rows where condition is TRUE

IS NULL / IS NOT NULL

The most basic way to check for NULL values.

Syntax
column IS NULL
column IS NOT NULL
Example: Find NULL Values
-- Find employees without salary
SELECT * FROM Employees WHERE Salary IS NULL;

-- Find employees with salary set
SELECT * FROM Employees WHERE Salary IS NOT NULL;

COALESCE

Returns the first non-NULL value from a list of expressions.

Syntax
COALESCE(val1, val2, val3, ...)
Returns first non-NULL value. If all are NULL, returns NULL.
Example: Replace NULL with Default
-- Replace NULL salary with 0
SELECT Name, COALESCE(Salary, 0) AS Salary
FROM Employees;

-- Replace NULL with chain of defaults
SELECT Name, COALESCE(Phone, Email, 'No Contact')
FROM Customers;
Name Salary COALESCE(Salary, 0)
Ahmed 5000 5000
Ali NULL 0

NULLIF

Returns NULL if two expressions are equal, otherwise returns the first expression.

Syntax
NULLIF(expr1, expr2)
Returns NULL if expr1 = expr2, else returns expr1.
Example: Avoid Division by Zero
-- Safe division: avoid divide by zero
SELECT Salary / NULLIF(DepartmentCount, 0)
FROM DepartmentStats;

-- If DepartmentCount is 0, result is NULL (not error)

IFNULL / NVL (Database-Specific)

Different databases have their own NULL-handling functions.

Database-Specific Syntax
-- MySQL
IFNULL(Salary, 0)

-- Oracle / PostgreSQL
NVL(Salary, 0)
-- or
COALESCE(Salary, 0)

-- SQL Server
ISNULL(Salary, 0)
-- or
COALESCE(Salary, 0)

NULL in Keys

Key Type Can be NULL? Reason
Primary Key NO PK uniquely identifies rows — NULL would break uniqueness
Foreign Key YES FK can be NULL if relationship is optional
Candidate Key NO Same reason as PK — must be unique and non-null
Unique Key Depends Usually allows one NULL (depends on DBMS)

Example 1: NULL in Employee Table

Scenario: Employee with Missing Data
EmpID Name Phone Salary DeptID
1 Ahmed 555-1234 5000 10
2 Sara NULL 6000 10
3 Ali 555-5678 NULL NULL
-- Find employees without phone
SELECT Name FROM Employees WHERE Phone IS NULL;
-- Result: Sara

-- Find employees without department
SELECT Name FROM Employees WHERE DeptID IS NULL;
-- Result: Ali

-- Safe salary query
SELECT Name, COALESCE(Salary, 0) AS Salary FROM Employees;

Example 2: NULL in Aggregations

Scenario: Calculate Statistics
SELECT
  COUNT(*) AS TotalRows, -- 5 (counts all rows)
  COUNT(Salary) AS NonNullSalaries, -- 3 (ignores NULLs)
  AVG(Salary) AS AvgSalary, -- 5500 (ignores NULLs)
  SUM(Salary) AS TotalSalary -- 16500 (ignores NULLs)
FROM Employees;

COUNT(*) counts rows. COUNT(column) counts non-NULL values in that column.

Example 3: NULL in JOINs

Scenario: Students without Department
-- INNER JOIN: excludes NULL DeptID
SELECT s.Name, d.DeptName
FROM Students s
INNER JOIN Departments d ON s.DeptID = d.DeptID;
-- Only shows students with a department

-- LEFT JOIN: includes NULL DeptID
SELECT s.Name, d.DeptName
FROM Students s
LEFT JOIN Departments d ON s.DeptID = d.DeptID;
-- Shows ALL students, NULL dept if no match

Example 4: NULLIF for Safe Division

Scenario: Average Salary per Department
-- DANGER: Division by zero error
SELECT SUM(Salary) / COUNT(*) FROM Employees;

-- SAFE: Use NULLIF to handle zero
SELECT SUM(Salary) / NULLIF(COUNT(*), 0)
FROM Employees;
-- If COUNT is 0, returns NULL instead of error

Example 5: NULL with CASE

Scenario: Conditional Logic with NULL
SELECT Name,
  CASE
    WHEN Salary IS NULL THEN 'Not Set'
    WHEN Salary < 4000 THEN 'Low'
    WHEN Salary < 7000 THEN 'Medium'
    ELSE 'High'
  END AS SalaryCategory
FROM Employees;

Sara 8000 High
Ali NULL Not Set
