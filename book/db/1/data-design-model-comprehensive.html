Relational Model & Relational Algebra — Complete Guide

Design Model Components

The design model (also called logical design or specific view) maps the analysis model to a specific data model. It is more detailed and closer to implementation.

1. Table Design

• Uses Relational Model

• Converts ERD to tables

• Performed by DBA

2. Query Design

• Uses Relational Algebra

• Defines operations on relations

• Performed by DBA

Key Relationship:
Analysis Model → Design Model → Implementation
The design model depends on which analysis model was chosen. If ER was used, relational model follows. If OO was used, OO model follows.
Important: The design model is model-specific. If you chose ER for analysis, you must use relational for design. If you chose OO for analysis, you must use OO for design.

Relational Algebra - Query Design

Relational algebra is a procedural query language that defines a sequence of operations to retrieve data.

Basic Operators

σ (Select)

• Selects rows that satisfy a condition

• σ_condition(R)

• Horizontal filtering

π (Project)

• Selects specific columns

• π_columns(R)

• Vertical filtering

× (Cartesian Product)

• Combines all rows from two relations

• R × S

• Results in m×n rows

Relational Algebra Expression:
π_sname(σ_city='C2'(S))
First select rows from S where City='C2', then project (select) only the Sname column.

Worked Examples

Example 1: Find names of suppliers in city C2
Relational Algebra: π_sname(σ_city='C2'(S))
Step 1: σ_city='C2'(S) → Select rows where City='C2' → {(S2,Sn2,C2), (S3,Sn3,C2)}
Step 2: π_sname → Extract Sname column → {Sn2, Sn3}
Example 2: Find part numbers with quantity greater than 20
Relational Algebra: π_p#(σ_qty>20(SP))
Step 1: σ_qty>20(SP) → Select rows where QTY>20 → {(S2,P1,30)}
Step 2: π_p# → Extract P# column → {P1}
Example 3: Find suppliers who supply part P1
Relational Algebra: π_s#(σ_p#='P1'(SP))
Step 1: σ_p#='P1'(SP) → {(S1,P1,10), (S2,P1,30)}
Step 2: π_s# → {S1, S2}
Example 4: Find names of suppliers who supply red parts (join)
Relational Algebra: π_sname(S ⨯(S.s#=SP.s#) SP ⨯(SP.p#=P.p#) σ_color='Red'(P))
This joins S, SP, and P tables, then filters for red parts.
Example 5: Cartesian product example
S × P results in all combinations:
(S1,Sn1,C1, P1,Pn1,Red)
(S1,Sn1,C1, P2,Pn2,Blue)
(S2,Sn2,C2, P1,Pn1,Red)
(S2,Sn2,C2, P2,Pn2,Blue)
(S3,Sn3,C2, P1,Pn1,Red)
(S3,Sn3,C2, P2,Pn2,Blue)

Cartesian product combines every row from S with every row from P.
