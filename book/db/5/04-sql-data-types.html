NUMERIC(p,q):
• p = total digits (precision)
• q = digits after decimal (scale)
• Example: NUMERIC(5,2) → max value = 999.99
Example 1 — Numeric Types
CREATE TABLE Products (
    ProductID   INT,
    Price       NUMERIC(8,2),    -- max 999999.99
    Weight      FLOAT,           -- approximate
    Quantity    SMALLINT,        -- max 32767
    TotalSales  DECIMAL(12,2)    -- exact to 2 decimal places
);

2. Character/String Types

TypeDescriptionMax LengthPadded?
CHAR(n)Fixed-length stringn charactersYes (spaces)

CLOBCharacter Large ObjectUp to 2GBNo
CHAR(10) storing 'Ali' → 'Ali ' (padded with 7 spaces)
VARCHAR(10) storing 'Ali' → 'Ali' (no padding)
CHAR vs VARCHAR:
• CHAR is faster for fixed-length data (SSN, phone codes)
• VARCHAR saves space for variable-length data (names, emails)
• CHAR pads with spaces, VARCHAR does not
Example 2 — Character Types
CREATE TABLE Users (
    Username    VARCHAR(30),     -- variable length
    Password    CHAR(32),        -- fixed length (e.g., MD5 hash)
    Bio         TEXT,            -- long text
    CountryCode CHAR(2)          -- fixed 2-letter code
);

6. Type Casting vs Type Coercion

FeatureType Casting (Explicit)Type Coercion (Implicit)
TriggerDeveloper writes codeDatabase engine does it
SyntaxCAST(x AS type) or ::typeAutomatic
RiskControlled, predictableMay lose data silently
ExampleCAST('5' AS INT)'5' + 3 → 8
Type Casting: CAST(column AS DataType)
PostgreSQL shorthand: column::DataType
Example 5 — Type Casting
-- Explicit casting
SELECT CAST(Salary AS VARCHAR) FROM Employees;
SELECT '2024-01-15'::DATE;

-- Implicit coercion (database does it automatically)
SELECT * FROM Students WHERE Age = '25';  -- '25' (string) compared to Age (int)
Implicit type coercion can cause unexpected results:
• '10' + 5 may return 15 or '105' depending on system
• Always prefer explicit CAST for clarity and safety

8. Exam Tips

Key points for exams:
• CHAR(n) pads with spaces, VARCHAR(n) does not
• NUMERIC(p,q): p = total digits, q = decimal places
• INTEGER = INT (synonyms)
• TIMESTAMP includes DATE + TIME
• CAST is explicit, coercion is implicit
• BLOB stores binary data (images, files)
• BOOLEAN stores TRUE/FALSE/NULL
