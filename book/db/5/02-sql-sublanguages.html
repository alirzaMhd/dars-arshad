SQL Sublanguages (DDL, DML, DCL, TCL)

1. Data Sublanguage Concept

SQL is divided into sublanguages based on function. This separation is called the Data Sublanguage concept — SQL handles only data access and manipulation, while a Host Language (C, COBOL, Java, Python) handles everything else.

Complete Database Language = Data Sublanguage (SQL) + Host Language (C/Java/Python)

2. DDL — Data Definition Language

DDL defines and modifies the database structure (schema). These commands affect the database metadata, not the data itself.

2.1 Commands

CommandPurposeReversible?
CREATECreate new database objectsYes (DROP)
ALTERModify existing structureYes (can ALTER back)
DROPDelete database objectsNo (permanent)
TRUNCATERemove all rows, keep structureNo (data gone)

2.2 Object Types Created by DDL

  • CREATE DATABASE — Create a new database
  • CREATE TABLE — Create a new table
  • CREATE VIEW — Create a virtual table
  • CREATE INDEX — Create an index
  • CREATE DOMAIN — Create a named data type
  • CREATE TYPE — Create a composite data type
  • CREATE TRIGGER — Create a trigger
  • CREATE ASSERTION — Create a constraint
Example 1 — DDL: Create Table
CREATE TABLE Students (
    ID      INT         PRIMARY KEY,
    Name    VARCHAR(50) NOT NULL,
    Major   VARCHAR(30) DEFAULT 'CS',
    GPA     DECIMAL(3,2) CHECK (GPA >= 0 AND GPA <= 4)
);
Example 2 — DDL: Alter Table
ALTER TABLE Students ADD Email VARCHAR(100);
ALTER TABLE Students DROP COLUMN Major;
ALTER TABLE Students ALTER COLUMN Name VARCHAR(100);
Example 3 — DDL: Drop & Truncate
DROP TABLE Students;         -- removes table + data permanently
TRUNCATE TABLE Students;     -- removes all rows, keeps structure

Difference: TRUNCATE is faster, doesn't fire triggers, and can be rolled back in some systems.

3. DML — Data Manipulation Language

DML reads and modifies actual data in tables. This is the most commonly used sublanguage.

3.1 Commands

CommandPurposeReturns
SELECTRead dataResult set
INSERTAdd new rowsAffected row count
UPDATEModify existing rowsAffected row count
DELETERemove rowsAffected row count
Example 4 — DML: SELECT with WHERE
SELECT Name, GPA 
FROM Students 
WHERE GPA > 3.5 
ORDER BY GPA DESC;
Example 5 — DML: INSERT Variants
-- With column list (recommended)
INSERT INTO Students (ID, Name, Major) VALUES (1, 'Ali', 'CE');

-- Without column list (all columns, in order)
INSERT INTO Students VALUES (2, 'Sara', 'CS', 3.8, 'sara@mail.com');

-- From another table
INSERT INTO GradStudents SELECT * FROM Students WHERE GPA >= 3.5;
Example 6 — DML: UPDATE & DELETE
UPDATE Students SET GPA = 3.9 WHERE ID = 1;
DELETE FROM Students WHERE GPA < 2.0;

4. DCL — Data Control Language

DCL controls access permissions and security. It manages who can do what on which objects.

4.1 Commands

CommandPurposeExample
GRANTGive permissions to usersGRANT SELECT ON Students TO user1;
REVOKERemove permissionsREVOKE DELETE ON Students FROM user1;
Example 7 — DCL: Grant & Revoke
-- Grant specific permission
GRANT SELECT, INSERT ON Students TO Admin;

-- Grant all permissions
GRANT ALL PRIVILEGES ON Students TO SuperAdmin;

-- Grant to all users
GRANT SELECT ON Students TO PUBLIC;

-- Revoke a permission
REVOKE INSERT ON Students FROM Admin;

-- Revoke all from a user
REVOKE ALL PRIVILEGES ON Students FROM SuperAdmin;

5. TCL — Transaction Control Language

TCL manages transactions — logical units of work that must complete entirely or not at all.

5.1 Commands

CommandPurpose
BEGIN TRANSACTIONStart a new transaction
COMMITSave all changes permanently
ROLLBACKUndo all changes since BEGIN
SAVEPOINTCreate a checkpoint within transaction
Example 8 — TCL: Transaction
BEGIN TRANSACTION;
    INSERT INTO Accounts VALUES (1, 1000);
    UPDATE Accounts SET Balance = Balance - 200 WHERE ID = 1;
    INSERT INTO Accounts VALUES (2, 200);
COMMIT;  -- both changes are saved permanently
Example 9 — TCL: Rollback
BEGIN TRANSACTION;
    UPDATE Accounts SET Balance = Balance - 500 WHERE ID = 1;
ROLLBACK;  -- the UPDATE is undone, balance unchanged

8. Exam Tips

Key points for exams:
• DDL = structure (CREATE, ALTER, DROP, TRUNCATE)
• DML = data (SELECT, INSERT, UPDATE, DELETE)
• DCL = security (GRANT, REVOKE)
• TCL = transactions (COMMIT, ROLLBACK)
• Host Language + Data Sublanguage = Complete Language
• TRUNCATE is DDL, not DML (no WHERE clause possible)
• SELECT is technically DML but doesn't modify data
