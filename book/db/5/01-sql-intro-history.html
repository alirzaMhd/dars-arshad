SQL Introduction & History

1. What is SQL?

SQL (Structured Query Language) is a standardized programming language designed for managing and manipulating relational databases. Despite the name, SQL is not a procedural language in the traditional sense — it operates on sets of data rather than single records.

SQL uses set-based logic, not row-by-row processing. This is key to its power and a common exam topic.

1.1 Key Characteristics

  • Declarative: You specify what data you want, not how to get it
  • Set-based: Operations work on entire sets of rows
  • Standardized: ANSI/ISO standard ensures cross-platform compatibility
  • Interactive & Embedded: Can be used directly or embedded in host languages (COBOL, C, etc.)

Example 1 — SQL Standard Naming

The name "SQL" is sometimes written as "SQL" (pronounced "sequel") and sometimes as "S-Q-L" (pronounced letter by letter). Both are acceptable.

SEQUEL originally stood for Structured English Query Language. It was later shortened to SQL for trademark reasons.

Example 2 — Why SQL Won

SQL won over Quel and QBE because:

  1. IBM backed it commercially
  2. It was standardized early (1986)
  3. It was relatively easy to learn for non-programmers
  4. It could be embedded in host languages

3. SQL Sublanguages Overview

SQL is divided into four sublanguages based on functionality:

SublanguageFull NamePurposeKey Commands
DDLData Definition LanguageDefine database structureCREATE, ALTER, DROP, TRUNCATE
DMLData Manipulation LanguageRead/modify dataSELECT, INSERT, UPDATE, DELETE
DCLData Control LanguageControl accessGRANT, REVOKE
TCLTransaction Control LanguageManage transactionsBEGIN, COMMIT, ROLLBACK, SAVEPOINT
Data Sublanguage = SQL commands (data access + manipulation)
Host Language = Programming language embedding SQL (C, COBOL, Java, Python, etc.)
Example 3 — Complete SQL Workflow

A typical database interaction involves all four sublanguages:

  1. DDL: CREATE TABLE students (id INT PRIMARY KEY, name VARCHAR(50));
  2. DML: INSERT INTO students VALUES (1, 'Ali');
  3. DCL: GRANT SELECT ON students TO public;
  4. TCL: COMMIT;
Example 4 — Host Language vs Data Sublanguage

In a program written in C with embedded SQL:

  • The C code handles: loops, variables, I/O, control flow
  • The SQL code handles: database queries, data manipulation

This separation is called Data Sublanguage — SQL handles only data access, while the host language handles everything else.

Example 5 — SQL Standard Evolution

The SQL standard has evolved significantly:

  • SQL-86: Basic SELECT, INSERT, UPDATE, DELETE
  • SQL-92: Added JOIN syntax, subqueries, CAST, CASE
  • SQL:1999: Added stored procedures, triggers, object-relational features
  • SQL:2003: Added window functions, XML support

The core syntax has remained remarkably stable, with new features added incrementally.

5. Exam Tips

Key points for exams:
• SQL was originally called SEQUEL (Structured English Query Language)
• First commercial implementation: Oracle (1979)
• First ANSI standard: SQL-86
• SQL is declarative (you say what, not how)
• Four sublanguages: DDL, DML, DCL, TCL
• Host Language vs Data Sublanguage distinction
