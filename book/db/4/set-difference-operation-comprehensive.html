SET DIFFERENCE OPERATION

Relational Algebra - Excluding Tuples

Definition

The Set Difference operation (denoted by −) returns tuples that are in R₁ but NOT in R₂. Both relations must be union-compatible.

Formal Definition
R₃ = R₁ − R₂
R₁ and R₂ must be union-compatible. The result contains tuples present in R₁ but absent from R₂.

Set difference is directional — R₁ − R₂ ≠ R₂ − R₁ in general. It extracts tuples from the first relation while removing any that also appear in the second relation.

Relationship to Other Operations
R₁ − R₂ = R₁ − (R₁ ∩ R₂)
Set difference can be expressed as removing the intersection from the first relation.

Requirements for Set Difference

Same Degree
Both relations must have the same number of attributes
Compatible Domains
Corresponding attributes must have compatible data types
Order Matters
R₁ − R₂ ≠ R₂ − R₁ (not commutative)

Algorithm / Pseudocode

Algorithm SetDifference(R₁, R₂):
  Input: Two union-compatible relations R₁ and R₂
  Output: Relation R₃ = R₁ − R₂

  R₃ ← empty relation
  FOR EACH tuple t IN R₁:
    IF t NOT IN R₂ THEN:
      INSERT t INTO R₃
  RETURN R₃

Core Formulas

Set Difference Definition
R₃ = R₁ − R₂
Result contains tuples in R₁ but not in R₂.
Degree of Difference Result
deg(R₃) = deg(R₁) = deg(R₂)
All relations have the same degree.
Cardinality — General Case
card(R₃) = card(R₁) − k
Where k = number of tuples in R₁ that also appear in R₂ (i.e., k = card(R₁ ∩ R₂)).
Cardinality Bounds
0 ≤ card(R₃) ≤ card(R₁)
The difference can never have more tuples than R₁.
Cardinality — Disjoint Relations
If R₁ ∩ R₂ = ∅, then card(R₃) = card(R₁)
When no tuples are shared, nothing is removed.
Cardinality — Identical Relations
If R₁ = R₂, then card(R₃) = 0
When both relations are identical, the difference is empty.
Cardinality — Subset Case
If R₁ ⊆ R₂, then card(R₃) = 0
When R₁ is a subset of R₂, all tuples of R₁ are removed.
Cardinality — Superset Case
If R₂ ⊆ R₁, then card(R₃) = card(R₁) − card(R₂)
When R₂ is a subset of R₁, all tuples of R₂ are removed from R₁.

Key Constraint Formulas

Candidate Key of Difference Result
C.K.(R₃) = C.K.(R₁)
The candidate key of the difference result is the same as the key of R₁. Since every tuple in R₃ comes from R₁ and R₁'s key uniquely identifies tuples in R₁, the same key works for R₃.
Important: The candidate key of R₃ = R₁ − R₂ is C.K.(R₁), NOT C.K.(R₂). The result is a subset of R₁, so R₁'s key remains valid.

Selection + Set Difference Composition

Selection distributes over Set Difference
σP(R₁ − R₂) = σP(R₁) − σP(R₂)
Selection distributes over set difference.
Relationship to Intersection
R₁ − R₂ = R₁ − (R₁ ∩ R₂)
Removing the intersection from R₁ gives the same result.
Expressing Intersection via Difference
R₁ ∩ R₂ = R₁ − (R₁ − R₂)
Intersection can be derived from two set difference operations.

Algebraic Properties

NOT Commutative: R₁ − R₂ ≠ R₂ − R₁ in general.
NOT Associative: (R₁ − R₂) − R₃ ≠ R₁ − (R₂ − R₃) in general.
Identity Element (Right)
R − ∅ = R
Subtracting the empty relation returns the original relation.
Identity Element (Left)
∅ − R = ∅
Subtracting from the empty relation returns empty.
Self-Difference
R − R = ∅
Subtracting a relation from itself yields the empty relation.
Union-Difference Identity
R₁ = (R₁ − R₂) ∪ (R₁ ∩ R₂)
Any relation can be decomposed into its difference and intersection with another relation.

Relationship to Symmetric Difference

Symmetric Difference
R₁ △ R₂ = (R₁ − R₂) ∪ (R₂ − R₁)
The symmetric difference contains tuples in either R₁ or R₂ but not both.
Alternative Expression
R₁ △ R₂ = (R₁ ∪ R₂) − (R₁ ∩ R₂)
Symmetric difference equals union minus intersection.

Distribution Laws

Set Difference distributes over Union
R₁ − (R₂ ∪ R₃) = (R₁ − R₂) ∩ (R₁ − R₃)
Set difference distributes over union via intersection.
Set Difference distributes over Intersection
R₁ − (R₂ ∩ R₃) = (R₁ − R₂) ∪ (R₁ − R₃)
Set difference distributes over intersection via union.

Common Mistakes

Mistake 1: Assuming R₁ − R₂ = R₂ − R₁. Set difference is NOT commutative. The order matters!
Mistake 2: Confusing set difference with "except" in SQL. In SQL, EXCEPT (or MINUS) eliminates duplicates, while some implementations may behave differently.
Mistake 3: Forgetting that the candidate key of R₁ − R₂ is C.K.(R₁), not C.K.(R₂). The result inherits the key structure from the first operand.
Mistake 4: Assuming associativity. (R₁ − R₂) − R₃ ≠ R₁ − (R₂ − R₃) in general. Be careful with chaining multiple differences.
