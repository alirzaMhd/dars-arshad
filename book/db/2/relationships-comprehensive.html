RELATIONSHIPS IN DATABASE DESIGN

Types, Attributes & Notation — Complete Guide for Exam

What is a Relationship?

Definition:
Relationship = An association between two or more entities
Relationships describe how entities are connected to each other

Key Concepts

Relationship Type

Describes which entities participate and how

e.g., Enrolls_In between Student and Course

Relationship Set

Collection of all relationship instances

e.g., All enrollments at a university

Degree

Number of entity types participating

Binary=2, Ternary=3, N-ary=N

Relationship can have attributes:
Student --Enrolls_In-- Course {Grade, Semester}
Grade and Semester are attributes of the relationship, not of Student or Course

Types of Relationships

Type Definition Example Notation
One-to-One (1:1) Each A relates to at most one B, and vice versa Person ↔ Passport 1 ---- 1
One-to-Many (1:n) A can relate to many B, but B relates to at most one A Department → Employees 1 ---- n
Many-to-One (n:1) Many A relate to one B Students → Department n ---- 1
Many-to-Many (m:n) Both can relate to multiple instances Students ↔ Courses m ---- n
Key Point

The relationship type is determined by reading both directions. "One Department has many Employees" AND "Each Employee works in one Department" = 1:n relationship.

Relationship Attributes

Types of Attributes on Relationships

Simple

Single value per relationship instance

e.g., Semester in Enrolls_In

Composite

Can be divided into sub-parts

e.g., Grade (Midterm, Final)

Multi-valued

Multiple values per instance

e.g., Comments in Reviews

Example: Student_Course Relationship

Entities: Student, Course

Relationship: Enrolls_In (m:n)

Relationship Attributes: Grade, Semester, Year, Status

These attributes belong to the enrollment, not to Student or Course individually.

When to put attribute on relationship vs entity:
If it describes the association → Relationship attribute
If it describes the entity itself → Entity attribute

Examples & Notation

Example 1: University System

Relationship: Student Enrolls_In Course (m:n)

Attributes: Grade, Semester

ER Notation: Student --Enrolls_In-- Course

Example 2: Company System

Relationship: Employee Works_In Department (n:1)

Attributes: Start_Date, Salary

Example 3: Hospital System

Relationship: Doctor Treats Patient (m:n)

Attributes: Treatment_Date, Diagnosis

Common Mistake

Don't confuse relationship attributes with entity attributes. If Grade describes the enrollment (not the student or course), it must be on the relationship.
