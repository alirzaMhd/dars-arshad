What are Armstrong's Axioms?

Armstrong's Axioms are a set of inference rules used to derive all functional dependencies logically implied by a given set F. They were proposed by William W. Armstrong in 1974.

Core Property
Sound & Complete
Every derived FD is logically implied (sound), and every implied FD can be derived (complete).

The Three Primary Axioms

1. Reflexivity

(Trivial dependency rule)

If Y ⊆ X, then X → Y

e.g., AB → A, ABC → BC

2. Augmentation

(Add attributes rule)

If X → Y, then XZ → YZ

Adding same attributes to both sides preserves FD

3. Transitivity

(Chain rule)

If X → Y and Y → Z, then X → Z

FDs chain together

Axiom 1: Reflexivity

Formal Statement
If Y ⊆ X, then X → Y
Also known as the "trivial FD rule." If Y is a subset of X, then X determines Y trivially.
Examples

Given X = {A, B, C}:

  • ABC → A (since A ⊆ ABC)
  • ABC → B (since B ⊆ ABC)
  • ABC → AB (since AB ⊆ ABC)
  • ABC → BC (since BC ⊆ ABC)
  • ABC → ABC (since ABC ⊆ ABC)
Reflexivity always holds — it is not dependent on the semantics of the data.

Axiom 2: Augmentation

Formal Statement
If X → Y, then XZ → YZ
We can add the same set of attributes Z to both sides of an FD.
Examples

Given A → B:

  • A, C → B, C (adding C to both sides)
  • A, D → B, D (adding D to both sides)
  • A, CD → B, CD (adding CD to both sides)

Common use: Expanding a determinant to match composite keys.

Axiom 3: Transitivity

Formal Statement
If X → Y and Y → Z, then X → Z
The most powerful rule — it chains FDs together.
Examples

Given A → B and B → C:

  • We can derive A → C (by transitivity)

Given StudentID → DeptID and DeptID → Dean:

  • We can derive StudentID → Dean (by transitivity)

This is how transitive dependencies are identified for 3NF normalization.

Why Soundness & Completeness Matter

Soundness: If we derive X → Y using Armstrong's Axioms from F, then X → Y holds in every relation instance that satisfies F.

Completeness: If X → Y is logically implied by F (i.e., holds in every instance satisfying F), then it can be derived using Armstrong's Axioms.

Closure of F
F⁺ = { X → Y | F ⊢ X → Y using Armstrong's Axioms }
F⁺ contains exactly the set of FDs that are logically implied by F.

Derived Inference Rules

In addition to the three primary axioms, several derived rules can be proven using Armstrong's Axioms. These make reasoning about FDs more convenient.

Union Rule

Combine RHS

If X → Y and X → Z, then X → YZ

Decomposition Rule

Split RHS

If X → YZ, then X → Y and X → Z

Pseudo-Transitivity

Extended chain

If X → Y and YW → Z, then XW → Z

Composition Rule

Combine FDs

If X → Y and A → B, then XA → YB

Self-Determination

Trivial

X → X (always holds)

Accumulation Rule

Special chain

If X → YZ and Z → W, then X → YZW

1. Union Rule

Union Rule
If X → Y and X → Z, then X → YZ
Two FDs with the same LHS can be combined.
Proof:

1. X → Y   (given)

2. X → Z   (given)

3. X → XZ   (augmentation of 2 with X: X → Z ⇒ XX → XZ ⇒ X → XZ)

4. XZ → YZ   (augmentation of 1 with Z: X → Y ⇒ XZ → YZ)

5. X → YZ   (transitivity: 3 and 4)

∎
Example

Given: A → B and A → C

Derived: A → BC

Useful when computing attribute closure — combine all RHS attributes for a given LHS.

2. Decomposition Rule

Decomposition Rule
If X → YZ, then X → Y and X → Z
An FD can be split into multiple FDs, one for each attribute on the RHS.
Proof:

1. X → YZ   (given)

2. YZ → Y   (reflexivity, since Y ⊆ YZ)

3. X → Y   (transitivity: 1 and 2)

Similarly:

4. YZ → Z   (reflexivity, since Z ⊆ YZ)

5. X → Z   (transitivity: 1 and 4)

∎
Example

Given: A → BC

Derived: A → B and A → C

Decomposition is the inverse of the union rule.

3. Pseudo-Transitivity

Pseudo-Transitivity Rule
If X → Y and YW → Z, then XW → Z
A generalization of transitivity that includes extra attributes on the LHS of the second FD.
Proof:

1. X → Y   (given)

2. YW → Z   (given)

3. XW → YW   (augmentation of 1 with W: X → Y ⇒ XW → YW)

4. XW → Z   (transitivity: 3 and 2)

∎
Example

Given: A → B and BC → D

Derived: AC → D

The extra attribute C from the second FD's LHS is added to the first FD's LHS.

4. Composition Rule

Composition Rule
If X → Y and A → B, then XA → YB
Combine two FDs that have different LHS sets.
Proof:

1. X → Y   (given)

2. A → B   (given)

3. XA → YA   (augmentation of 1 with A: X → Y ⇒ XA → YA)

4. YA → YB   (augmentation of 2 with Y: A → B ⇒ YA → YB)

5. XA → YB   (transitivity: 3 and 4)

∎

Example 1: Basic Derivations

Given F = { A → B, B → C, C → D }

Derive: A → D

1. A → B   (given)

2. B → C   (given)

3. A → C   (transitivity: 1, 2)

4. C → D   (given)

5. A → D   (transitivity: 3, 4)

Result: A → D is in F⁺

Example 2: Using Augmentation

Given F = { A → B, C → D }

Derive: AC → BD

1. A → B   (given)

2. AC → BC   (augmentation of 1 with C)

3. C → D   (given)

4. BC → BD   (augmentation of 3 with B: C → D ⇒ BC → BD)

5. AC → BD   (transitivity: 2, 4)

Alternative: Use composition rule directly.

Example 3: Multiple Derivations

Given F = { AB → C, C → D, D → E, A → B }

a) Derive: AB → D

1. AB → C   (given)

2. C → D   (given)

3. AB → D   (transitivity: 1, 2)

b) Derive: A → B — given (already in F)

c) Derive: AB → E

4. AB → D   (from above)

5. D → E   (given)

6. AB → E   (transitivity: 4, 5)

d) Derive: AB → DE

7. AB → D   (from 3)

8. AB → E   (from 6)

9. AB → DE   (union: 7, 8)

Example 4: Checking FD Membership

Given R(A, B, C, D, E) with F = { A → BC, CD → E, B → D, E → A }

Question: Does A → E hold? (Is A → E ∈ F⁺?)

1. A → BC   (given)

2. A → B   (decomposition of 1)

3. A → C   (decomposition of 1)

4. B → D   (given)

5. A → D   (transitivity: 2, 4)

6. A → CD   (union: 3, 5; we have A→C and A→D, so A→CD)

7. CD → E   (given)

8. A → E   (transitivity: 6, 7)

Yes, A → E is in F⁺.

Example 5: Finding Candidate Keys

Given R(A, B, C, D) with F = { A → B, B → C, C → D, D → A }

All attributes determine each other!

Find all candidate keys:

• Is A a candidate key?

A → B (given), A → B → C, A → B → C → D, so A → ABCD. Yes!

• Is B a candidate key?

B → C → D → A, so B → ABCD. Yes!

• Similarly C and D are candidate keys.

All four singleton sets {A}, {B}, {C}, {D} are candidate keys.

Example 6: Proving an FD Does NOT Hold

Given F = { A → B, A → C }

Question: Does B → C hold?

We cannot derive B → C from F using Armstrong's Axioms.

Counterexample instance:

ABC
1xp
2xq

This satisfies A→B and A→C (A is a key), but B→C fails (x→p and x→q).

B → C ∉ F⁺. It is NOT implied.

Formal Proofs of Armstrong's Axioms

These proofs demonstrate that Armstrong's Axioms are sound — they only generate FDs that are logically implied by the given set.

Proof of Reflexivity

Theorem:

If Y ⊆ X, then X → Y.

Proof:

Let t₁, t₂ be any two tuples in relation R such that t₁[X] = t₂[X].

Since Y ⊆ X, the values of t₁ and t₂ on all attributes in Y must be the same as their values on the corresponding attributes in X.

Since t₁[X] = t₂[X] and Y ⊆ X, we have t₁[Y] = t₂[Y].

Therefore, X → Y holds by definition.

∎

Reflexivity does not depend on any data semantics — it is a logical truth.

Proof of Augmentation

Theorem:

If X → Y, then XZ → YZ for any set of attributes Z.

Proof:

Assume X → Y holds. Let t₁, t₂ be two tuples with t₁[XZ] = t₂[XZ].

From t₁[XZ] = t₂[XZ], we have:

  (1) t₁[X] = t₂[X] (since X ⊆ XZ)

  (2) t₁[Z] = t₂[Z] (since Z ⊆ XZ)

From (1) and X → Y, we get t₁[Y] = t₂[Y].

From (2), we have t₁[Z] = t₂[Z].

Therefore t₁[YZ] = t₂[YZ] (combining Y and Z).

Thus XZ → YZ holds.

∎

Proof of Transitivity

Theorem:

If X → Y and Y → Z, then X → Z.

Proof:

Assume X → Y and Y → Z hold. Let t₁, t₂ be two tuples with t₁[X] = t₂[X].

From t₁[X] = t₂[X] and X → Y, we get t₁[Y] = t₂[Y].

From t₁[Y] = t₂[Y] and Y → Z, we get t₁[Z] = t₂[Z].

Therefore X → Z holds.

∎

Proof of the Union Rule

Theorem:

If X → Y and X → Z, then X → YZ.

Proof:

1. X → Y   (given)

2. X → Z   (given)

3. X → XZ   (augment 2 with X: X → Z ⇒ XX → XZ ⇒ X → XZ)

4. XZ → YZ   (augment 1 with Z: X → Y ⇒ XZ → YZ)

5. X → YZ   (transitivity: 3 and 4)

∎

Proof of the Decomposition Rule

Theorem:

If X → YZ, then X → Y and X → Z.

Proof:

1. X → YZ   (given)

2. YZ → Y   (reflexivity: Y ⊆ YZ)

3. X → Y   (transitivity: 1 and 2)

Similarly for Z:

4. YZ → Z   (reflexivity: Z ⊆ YZ)

5. X → Z   (transitivity: 1 and 4)

∎

Proof of Pseudo-Transitivity

Theorem:

If X → Y and YW → Z, then XW → Z.

Proof:

1. X → Y   (given)

2. YW → Z   (given)

3. XW → YW   (augment 1 with W: X → Y ⇒ XW → YW)

4. XW → Z   (transitivity: 3 and 2)

∎

Proof of the Composition Rule

Theorem:

If X → Y and A → B, then XA → YB.

Proof:

1. X → Y   (given)

2. A → B   (given)

3. XA → YA   (augment 1 with A: X → Y ⇒ XA → YA)

4. YA → YB   (augment 2 with Y: A → B ⇒ YA → YB)

5. XA → YB   (transitivity: 3 and 4)

∎
