The Fundamental Theorem:
RE ⟺ NFA/DFA ⟺ Regular Grammar
All three formalisms describe exactly the same class of languages: REGULAR LANGUAGES. Each can be algorithmically converted to any other.

Key Theoretical Results

Result 1:
For every regular expression R, there exists a regular grammar G such that L(G) = L(R)
Result 2:
For every regular grammar G, there exists a regular expression R such that L(R) = L(G)
Result 3:
For every DFA/NFA M, there exists a regular expression R such that L(R) = L(M)
Result 4:
For every regular expression R, there exists a DFA M such that L(M) = L(R)
Result 5:
For every regular grammar G, there exists a DFA/NFA M such that L(M) = L(G)
Result 6:
For every DFA/NFA M, there exists a regular grammar G such that L(G) = L(M)

Characterization of Regular Languages

A language L is regular if and only if:
L can be described by a regular expression
OR equivalently: a DFA exists for L, OR an NFA exists for L, OR a regular grammar generates L.

Practical Implications

  • Lexical Analysis: Use RE for token patterns (identifiers, numbers), implement as DFA for efficiency
  • Pattern Matching: grep/regex engines use RE syntax, compile to DFA for fast matching
  • Protocol Design: Model message sequences with RE, verify with FA
  • Compiler Design: Token specifications → RE → DFA → lexical analyzer

Practice: True or False?

Statement: "Every regular language has a unique regular expression"

FALSE. A regular language can have infinitely many equivalent regular expressions. For example, a* and (a*)* both describe the same language.

Practice: True or False?

Statement: "Every regular language has a unique minimal DFA"

TRUE (up to isomorphism). The minimal DFA for a regular language is unique — it has the fewest possible states.

Practice: True or False?

Statement: "The language {aⁿbⁿ : n ≥ 0} is regular"

FALSE. This language requires counting/matching, which finite automata cannot do. It is context-free but not regular. This can be proved using the pumping lemma for regular languages.

Practice: Which is not equivalent?

Which DFA has a different language?

If L(M) = L₁ = L₂ = L₃ but L₄ ≠ L₁, then M₄ is the non-equivalent one.

Question: Which language CANNOT be described by a DFA with only one accepting state?

Options: (1) 0*1   (2) 0*   (3) 0*(0+1)   (4) (0+1)*1

Answer: 0*(0+1) — requires at least 2 accepting states.

Test: Which Statement is Correct?

Question: Which statement about regular languages is correct?

Options:
(1) Every regular language has a unique regular grammar
(2) Every regular language has a unique regular expression
(3) Every regular language has a DFA with one final state
(4) The minimal DFA of a regular language is unique

Answer: option (4) The minimal DFA of a regular language is unique (up to renaming states).

Options 1, 2, and 3 are FALSE: grammars and regular expressions are NOT unique, and not every regular language has a DFA with one final state.
