Regular Grammar → NFA

Convert a right-linear grammar to an NFA:

Construction Rules:
States = Variables (V), Start = S, Final = {A | A → λ ∈ P}
For each rule A → aB: add transition δ(A, a) = B. For each rule A → a: make A a final state (or add λ-transition to a new final state).
Example: Convert Grammar to NFA

G: S → baA | bB

A → aA | bbB

B → d

Step 1: Normalize to A → aB or A → a form

S → bX₁ | bB, X₁ → aA, A → aX₃ | bD, X₃ → aA, D → bB, B → dX₄, X₄ → λ

Step 2: Build NFA

States: {S, X₁, A, X₃, D, B, X₄}

Transitions: S--b-->X₁, S--b-->B, X₁--a-->A, A--a-->X₃, A--b-->D, X₃--a-->A, D--b-->B, B--d-->X₄

Start: S, Final: {X₄}

Example 3-10: Grammar to NFA with Normalization

G: S → abcS | A, A → aaAB, B → bB | d | λ

Step 1: Normalize (break multi-terminal rules):

S → aX₁ | A

X₁ → bX₂

X₂ → cS

A → aX₃ | B

X₃ → aA

B → bB | dX₄ | λ

X₄ → λ

Step 2: Build NFA from normalized grammar

States: {S, X₁, X₂, A, X₃, B, X₄}

Transitions: S--a-->X₁, S--λ-->A, X₁--b-->X₂, X₂--c-->S, A--a-->X₃, A--λ-->B, X₃--a-->A, B--b-->B, B--d-->X₄

Start: S, Final: {B, X₄} (B is final because B → λ)

NFA → Regular Grammar

Convert an NFA to a right-linear grammar:

Construction Rules:
For each transition δ(A, a) = B: add rule A → aB
For each final state A: add rule A → λ. Variables = States, Start = q₀.
Example: Convert NFA to Grammar

NFA M: States = {A, B, C, D}

δ(A, a) = A, δ(A, b) = B

δ(B, a) = C, δ(B, b) = D

δ(C, a) = A, δ(C, b) = D

δ(D, a) = B, δ(D, b) = A

Start: A, Final: {B, D}

Grammar:

A → aA | bB

B → aC | bD | λ

C → aA | bD

D → aB | bA | λ

Special Case: λ-Transitions

If NFA has λ-transitions: For each λ-transition δ(A, λ) = B, add rule A → B to the grammar (unit production). This is allowed in regular grammars derived from NFAs.

Regular Grammar → RE (Method 1)

One approach: Convert grammar to NFA, then NFA to RE using GTG method.

Grammar to RE via NFA

G: S → aA | bC

A → bB | aA | λ

B → bB | aA

C → aD | bc | λ

D → aD | bC

By generating strings, we observe: G generates all strings over {a, b} where first and last characters are the same.

L(G) = {a}{a,b}*{a} + {b}{a,b}*{b} + {a} + {b}

RE = a(a+b)*a + b(a+b)*b + a + b

Grammar → RE (Method 2)

Direct method: Use the grammar structure to write the RE.

Direct Grammar Analysis

G: S → aaB

B → bbB | λ

Analysis: S always starts with "aa", then B generates zero or more "bb" pairs.

L(G) = {a^(2n) · b^(2m) : n ≥ 1, m ≥ 0}

RE = (aa)(bb)*

RE → Regular Grammar (Direct)

Convert a regular expression directly to a right-linear grammar:

Conversion Rules:
For RE 'a': S → a
For RE 'r₁r₂': S → r₁A, A → r₂ (chain through intermediate variables)
For RE 'r₁+r₂': S → r₁ | r₂ (union = alternatives)
For RE 'r*': S → rS | λ (recursion for zero or more)
Example: RE = 00*11* + (010)*

Grammar:

S → 0A | C

A → 0A | 0B

B → 1B | 1

C → 010C | λ

L(G) = {0^n · 1^m : n ≥ 1, m ≥ 1} ∪ {(010)^k : k ≥ 0}

Example: RE to Grammar

RE = a*(baa*)* (b+λ)

Grammar:

S → aS | A

A → baD | B

D → aD | A

B → b | λ

This RE describes all strings over {a,b} NOT containing substring "bb".

Example 3-16: Decimal Multiples of 4

RE, Grammar, and DFA for strings over {0,1} whose decimal value is a multiple of 4

RE = 00* + 0*1(0+1)*00

Right-linear Grammar:

S → 0S | 1B | 0

B → 0B | 1B | 00

DFA states track remainder mod 4:

q₀ (rem 0, final), q₁ (rem 1), q₂ (rem 2, final), q₃ (rem 3)

Transitions: reading 0 or 1 updates remainder: new_rem = (2·old_rem + digit) mod 4

L(G) = {w ∈ {0,1}* : decimal(w) mod 4 = 0}
