Properties of Regular Expressions

Algebraic Identities and Equivalence — Complete Guide

Definition of Equivalence

Two regular expressions r₁ and r₂ are equivalent (written r₁ = r₂) if and only if L(r₁) = L(r₂).

Important: The same language can have many different regular expression descriptions. They are all equivalent if they describe the same set of strings.

Basic Algebraic Identities

For regular expressions α, β, γ over alphabet Σ:

Identity 1 — Kleene Star Idempotence:
(α*)* = α* = (α*)+ = (α+)*
Applying star to star gives star. Also equals "one or more" star.
Identity 2 — Rotation:
(αβ)*α = α(βα)*
You can rotate concatenation around a star.
Identity 3 — Distributivity:
α(β + γ) = αβ + αγ or (β + γ)α = βα + γα
Concatenation distributes over union.
Identity 4 — Union Idempotence:
(α + α) = α
Union with self is idempotent.
Identity 5 — Empty String:
ε · α = α · ε = α
Concatenating with empty string doesn't change anything.
Identity 6 — Empty Set:
∅ · α = α · ∅ = ∅
Concatenating with empty set gives empty set.

Kleene Star Properties

Star of Union:
(α + β)* = (α* + β*)* = (α* + β)* = (α + β*)* = (β + α)*
Star of union can be rewritten in multiple equivalent forms.
Star Decomposition:
(α + β)* = (α*β*)* = (β*α*)* = (α*β*)+ = (β*α*)+
Star can be decomposed into nested stars.
Star with Concatenation:
(α + β)* = (α*β)*α* = (β*α)*β*
Equivalence with alternating star patterns.
Star Decomposition (two forms):
(α + β)* = (α*β)* + (β*α)*
Union of two alternating star expressions.
Cross-Product Star:
α*β* ≠ β*α* in general, but α*β* = β*α* when α and β commute
Stars don't generally commute under concatenation.
Identity 13 — Commutativity of Star:
α* = β* only if α = β (in general)
Star is not generally commutative.

Additional Star Properties

Identity 16:
(α*)ᴿ = (αᴿ)*
Star and reverse commute.
Identity 17:
(α+)⁺ = α + (redundant, already equals α*)
Identity 18:
αα* = a*a = α+ (i.e., α+ = αα*)
Concatenation with star gives "one or more".

Distributive and Complex Properties

Identity 7:
(α + β)* = (α* + β*)* = (α* + β)* = (α + β*)*
Identity 8:
(α + β)* = (α*β*)* = (β*α*)* = (α*β*)+ = (β*α*)+
Identity 9:
(α + β)* = (α*β)*α* = (β*α)*β*
Identity 10:
(α + β)* = (α + β)(α + β)* = α(α + β)* + β(α + β)*
Star of union can be factored: at least one copy of (α+β), then zero or more.
Identity 11:
(α + β)* = (α*β)* + (β*α)*
Identity 12:
β*α* = α*β* = (α + β)* only when they commute
Identity 14:
(αβ)ᴿ = βᴿαᴿ
Reverse of concatenation reverses the order.
Identity 15:
(αᴿ)ᴿ = α
Reverse is an involution.
Identity 13 — Injectivity of Star:
α* = β* if and only if α = β
Star is injective: equal stars imply equal arguments.
Identity 17 — Plus Idempotence:
(α+)+ = α+
The plus of plus is just plus (idempotence of plus).
Identity 18 — Concatenation with Plus:
aa+ = a+a = a++ = a+
Concatenation with plus on either side gives plus. All four forms are equivalent.
Simplification — Plus equals Concatenation with Star:
a+ = aa* = a*a
One-or-more equals concatenation with star. This is the fundamental link between + and *.

Example Equivalences

Example 3-4: Four equivalent REs for "at least one a" over {a,b}

r₁ = (a+b)*a(a+b)*

r₂ = (b*ab*)+

r₃ = (b*a*b*)+

r₄ = a*(ba*)*ab*

All equivalent: L(r₁) = L(r₂) = L(r₃) = L(r₄) = {a,b}*{a}{a,b}*

All four describe the set of strings over {a,b} containing at least one 'a'.

Practice: Which identity is correct?

Problem: Which of these is true?

(1) (α+β)* = (β*αβ*)*

(2) (α*β*)*α* = (βα*)*

(3) αα* = α*a = α*

(4) (α+β)* = (α*β)* + (β*α)*

Answer: Option (3) is always correct: αα* = α*a = α+

Option (1) is wrong because β*αβ* doesn't generate β alone.

Option (4) doesn't hold in general.

Practice: Which identity is NOT correct?

Problem: Which is false?

(1) (α* + β)* = (α*βα*)*

(2) (α*β)* + α* = (β*α*)*

(3) (αⁿβⁿ)αⁿ = βⁿ(αβⁿ)ⁿ

(4) α + ∅ = α and α + α = α

Answer: Option (4) — while α+∅=α is true, α+α=α is true, but the combination claims something incorrect about option (4) being false. Actually all of 1,2,3 are true and 4 is the correct choice as "not correct" because the statement includes an error.

Equivalence Proof Example

Prove: (a+b)* = (a*b*)* = (b*a*)*

Proof sketch:

1. L((a+b)*) = {all strings over {a,b}} = Σ*

2. L((a*b*)*) = all strings formed by concatenating blocks of a's followed by blocks of b's, repeated. This includes all strings since any string can be decomposed into alternating runs of a's and b's.

3. Similarly for (b*a*)*.

Therefore all three are equivalent to Σ*.
