Right-Linear → Left-Linear Conversion

Converting Between Grammar Forms — Complete Guide

Method 1: Find Language, Then Write New Grammar

The simplest conceptual approach:

  1. Determine L(G) from the right-linear grammar G
  2. Write a left-linear grammar G' for the same language L(G)
Example: Convert Right-Linear to Left-Linear

G (right-linear): S → abA, A → bbB, B → aaA | b

Step 1: Find L(G) by generating strings:

S → abA → abbbB → abbb(aaA | b) → ...

L(G) = {ab³(a²b²)*b} = {ab(bbaa)*bbb}

Step 2: Write left-linear grammar for same language:

G' (left-linear): S → Db

D → Da²b² | ab³

L(G') = L(G) = {ab(bbaa)*bbb}

Method 2: Using Generalized Transition Graph

A more systematic approach:

  1. Convert right-linear grammar G to GTG M
  2. Reverse the GTG: swap start/final states, reverse edge directions
  3. Convert the reversed GTG to a right-linear grammar G'
  4. Reverse all production rules in G' → left-linear grammar
Step-by-Step with GTG

Step 1: Right-linear G → GTG M (with L(M) = L(G))

Step 2: Reverse M → M' (with L(M') = L(G)ᴿ)

Step 3: M' → right-linear grammar G'

Step 4: Reverse all rules in G' → left-linear grammar G''

L(G'') = (L(G')ᴿ)ᴿ = L(G') = L(G)ᴿᴿ = L(G)

Method 3: Via Regular Expression

Use the regular expression as an intermediate:

  1. Convert right-linear grammar G to RE (via NFA or directly)
  2. Convert RE to left-linear grammar (via NFA or directly)
Example: Via RE

G (right-linear): S → aA | bB, A → aA | λ, B → bB | λ

L(G) = a⁺ + b⁺ (RE: a⁺ + b⁺)

Left-linear grammar for a⁺ + b⁺:

G' (left-linear): S → Aa | Bb

A → Aa | a

B → Bb | b

L(G') = L(G) = {aⁿ : n≥1} ∪ {bᵐ : m≥1}

Complete Example 1

Right-Linear to Left-Linear

G: S → 0S | 1B | 0

B → 0B | 1B | 00

L(G): Strings over {0,1} whose decimal value is divisible by 4.

RE: 00* + 0*1(0+1)*00

Left-linear G':

S → 0A | 0

A → 0A | 1B | 0

B → 0B | 1B | 00

L(G') = L(G)

Example 3-18: Method 3 Complete Walkthrough (Via RE)

Right-linear G → GTG → Reverse GTG → Right-linear G' → Left-linear G''

G (right-linear): S → abA, A → bbB, B → aaA | b

L(G) = {ab(bbaa)*bbb}

Step 1: GTG M for G (Figure 3-25)

States: S, A, B. Edges: S--ab-->A, A--bb-->B, B--aa-->A, B--b-->F (final)

Step 2: Reverse GTG → M' (Figure 3-26)

Swap start/final: start = F, final = S. Reverse all edges.

F--b-->B, B--aa-->A, A--bb-->B, A--ba-->S (reversed ab = ba)

Step 3: Convert M' to right-linear grammar G'

D → bB, B → bbA, A → aaB | ba, S → λ

(D is new start state from reversed GTG start)

Step 4: Reverse all rules → left-linear grammar G''

D → Bb, B → Abb, A → Baa | Sab, S → λ

L(G'') = (L(G'))ᴿᴿ = L(G') = L(G)ᴿᴿ = L(G) = {ab(bbaa)*bbb}

Key Insight

The reversal property:
If G is right-linear, then Gᴿ (with all rules reversed) is left-linear, and L(Gᴿ) = (L(G))ᴿ
To get back to the original language, reverse the GTG twice, which is equivalent to reversing all rules twice.
