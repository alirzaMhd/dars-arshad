Introduction to Constraint Satisfaction Problems (CSP)

Artificial Intelligence — Chapter 4: Complete Guide

What is a CSP?

A Constraint Satisfaction Problem (CSP) is a special type of problem where states and the goal test follow a standard, structured, and simple representation. Unlike general search problems where states are black boxes, CSPs have a well-defined internal structure that allows specialized algorithms.

Formal Definition:
CSP = (X, D, C)
A CSP is defined by a set of variables X, domains D, and constraints C
State Representation:
{X1 = v1, X2 = v2, ..., Xn = vn}
Each state is an assignment of values to a subset of variables

Key Terminology

Consistent Assignment

An assignment that does not violate any constraint

Complete Assignment

Every variable has been assigned a value

Solution

A complete and consistent assignment satisfying all constraints

Partial Assignment

Only a subset of variables have values

CSP Components in Detail

Variables (X)

Each problem has a set of variables X = {X1, X2, ..., Xn}. Each variable represents a decision point or entity in the problem.

Domains (D)

Each variable Xi has a non-empty domain Di of possible values. Domains can be:

  • • Finite: e.g., {red, green, blue}
  • • Infinite: e.g., integers, strings
  • • Continuous: e.g., real numbers

Constraints (C)

Each constraint Ci involves a subset of variables and specifies the allowed combinations of values for that subset. Constraints restrict which assignments are valid.

Initial State:
{ }
No variables have values assigned yet
Important: CSPs can have objective functions that need to be maximized (optimization CSPs). These are called Constraint Satisfaction Optimization Problems (CSOPs).

Worked Examples

Example 1: Simple CSP with 3 Variables

Variables: A, B, C

Domains: DA = {1, 2}, DB = {1, 2}, DC = {1, 2}

Constraints: A ≠ B, B ≠ C, A = C

Solution: {A=1, B=2, C=1} or {A=2, B=1, C=2}

✓ Both assignments satisfy all constraints

Example 2: CSP with No Solution

Variables: X, Y, Z

Domains: DX = {a, b}, DY = {a, b}, DZ = {a}

Constraints: X ≠ Y, X ≠ Z, Y ≠ Z

Since Z can only be 'a', and both X and Y must differ from Z, at most one of X or Y can be 'a'. But X ≠ Y means they must be different, and one must be 'a'. Contradiction — no solution exists.

✗ No complete assignment satisfies all constraints

Example 3: CSP with Optimization

Variables: Task1, Task2 with domains {morning, afternoon}

Constraints: Task1 ≠ Task2 (cannot be same time)

Objective: Minimize cost: Task1=morning costs 1, Task1=afternoon costs 2; Task2=morning costs 2, Task2=afternoon costs 1

Optimal Solution: {Task1=morning (cost 1), Task2=afternoon (cost 1)} — total cost = 2

✓ Optimal solution found with total cost 2

Example 4: Binary CSP

Variables: P, Q, R

Domains: DP = {0, 1}, DQ = {0, 1}, DR = {0, 1}

Constraints: P + Q = 1 (exactly one is 1), Q + R ≥ 1, P + R ≤ 1

Solutions: {P=1, Q=0, R=1}, {P=0, Q=1, R=0}

Quick Reference

CSP Components

X = Variables

D = Domains (non-empty)

C = Constraints

Assignment Types

• Consistent: No violations

• Complete: All assigned

• Solution = Complete + Consistent

CSP Advantages

• Standard representation

• Generic successor & goal functions

• Domain-independent heuristics

• Constraint graph reveals structure

Why CSP over standard search?

• No need for domain-specific heuristics

• Structure of constraints visible

• Can reduce complexity exponentially

Common Mistake: Confusing "consistent" (no constraint violation) with "complete" (all variables assigned). A solution requires BOTH properties simultaneously.
