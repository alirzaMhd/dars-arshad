Detailed Analysis

USA Map Coloring

BT and BT+MRV both perform poorly (>1,000K). The key insight: without constraint propagation, backtracking on the USA map is very expensive. Forward Checking (2K) provides a 500x improvement by pruning inconsistent values early.

N-Queens

This is where Min-Conflicts truly shines. With only 64 nodes explored, it outperforms all other methods by orders of magnitude. The solution space is dense enough that local search finds a solution almost immediately.

Min-Conflicts on N-Queens:
Average steps ≈ 50 (independent of N, even for millions!)

Zebra Puzzle

A classic constraint satisfaction puzzle with 5 houses, 5 attributes each (25 variables). BT+MRV and FC+MRV perform best here. The MRV heuristic is crucial because the Zebra puzzle has many constraints that quickly restrict domains.

Random Problems

Forward Checking alone performs worse than plain BT on random problems! Why? The overhead of maintaining arc consistency doesn't pay off when constraints are randomly distributed. However, FC+MRV recovers well by choosing the right variable ordering.

Important Lesson: No single algorithm dominates all problems. The best approach depends on the problem's structure, density, and constraint type.

Detailed Examples

Example 1: Why FC+Fails on Random Problems

Random CSP: Many variables, random constraints, moderate tightness.

Forward checking checks arc consistency after each assignment. On random graphs, most constraints are unrelated to the assigned variable. The overhead of checking O(n²) arcs after each step doesn't help prune the search.

With MRV, though, we at least ensure we're picking the hardest-to-satisfy variable, which helps regardless.

Example 2: Min-Conflicts on Million-Queens

Problem: 1,000,000 queens on a 1,000,000 × 1,000,000 board.

Algorithm: Start with one queen per column, all in random rows. Count conflicts for each queen.

Each step: Pick a random conflicted queen, move it to the row with fewest conflicts.

Result: After ≈50 steps, no conflicts remain. 50 steps for 1 million queens!

Backtracking would never finish (40,000K nodes for just 8 queens).

Min-Conflicts achieves near-constant time for N-Queens!

Example 3: Zebra Puzzle — MRV Impact

The Zebra puzzle: "Who owns the zebra?" — 25 variables (5 houses × 5 attributes), 14 constraints.

Without MRV: 3,859,000 nodes explored. The algorithm wastes time on variables with large domains when constrained variables are waiting.

With MRV: Only 1,000 nodes. MRV picks the most constrained variable first (e.g., the house color that fewest options remain for), immediately narrowing the search.

MRV provides a 3,859x speedup on the Zebra puzzle!
