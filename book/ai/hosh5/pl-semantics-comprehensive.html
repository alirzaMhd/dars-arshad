What is a Model?

A model is a complete assignment of truth values (true or false) to every propositional symbol in a knowledge base.

Model Definition
m = {P: true, Q: false, R: true}
A model assigns T or F to each of the n propositional symbols. It represents one possible "world".
Number of Models
For n symbols: 2^n possible models
Each symbol has 2 choices (T or F), so 2 × 2 × ... × 2 = 2^n total combinations.
Worked Example: Counting Models

1 symbol (P): 2^1 = 2 models → {P=T}, {P=F}

2 symbols (P, Q): 2^2 = 4 models → {P=T,Q=T}, {P=T,Q=F}, {P=F,Q=T}, {P=F,Q=F}

3 symbols (P, Q, R): 2^3 = 8 models

4 symbols: 2^4 = 16 models

10 symbols: 2^10 = 1024 models

Warning: The number of models grows exponentially! With just 20 symbols, you'd need to enumerate over 1,000,000 models. This is why model checking algorithms have exponential time complexity.

Truth Value Computation

Given a model, we can compute the truth value of ANY sentence recursively:

Atomic Sentences
True → true
False → false
P → model(P)
Look up the symbol in the model.
Negation
¬α: true if α is false
Flip the truth value of α.
Conjunction
α ∧ β: true if BOTH true
Only true when α=true AND β=true.
Disjunction
α ∨ β: true if at least one true
False only when both α and β are false.
Implication
α ⇒ β: true if α false OR β true
Only false when α=true and β=false.
Biconditional
α ⇔ β: true if α and β same
True when both true or both false.

Worked Examples: Evaluating Sentences

Example 1: Evaluate (P ∧ Q) ⇒ ¬R with model {P=T, Q=F, R=T}

Step 1: P ∧ Q = T ∧ F = F

Step 2: ¬R = ¬T = F

Step 3: F ⇒ F = T (false premise → vacuously true)

The implication is true because the premise (P ∧ Q) is false.

Example 2: Evaluate ¬(P ∨ Q) ∧ R with model {P=T, Q=F, R=T}

Step 1: P ∨ Q = T ∨ F = T

Step 2: ¬(P ∨ Q) = ¬T = F

Step 3: F ∧ R = F ∧ T = F

The conjunction fails because the left conjunct is false.

Example 3: Evaluate (P ⇒ Q) ⇔ (¬Q ⇒ ¬P) — Contrapositive

Test with model {P=T, Q=F}:

Step 1: P ⇒ Q = T ⇒ F = F

Step 2: ¬Q ⇒ ¬P = T ⇒ F = F

Step 3: F ⇔ F = T

Test with model {P=T, Q=T}:

Step 1: P ⇒ Q = T ⇒ T = T

Step 2: ¬Q ⇒ ¬P = F ⇒ F = T

Step 3: T ⇔ T = T

This is true for ALL models — the contrapositive is a logical equivalence!

Knowledge Base (KB) as Conjunction

A knowledge base is a set of sentences that the agent knows to be true. We represent it as a conjunction of all its sentences.

KB Representation
KB = R1 ∧ R2 ∧ R3 ∧ ... ∧ Rn
Where R1, R2, ..., Rn are the individual rules/assertions in the KB.
Example: Wumpus World KB

Suppose we have:

R1: "There is no breeze in square [1,1]" → ¬B11

R2: "Breeze means pit nearby" → B11 ⇔ (P12 ∨ P21)

KB = ¬B11 ∧ (B11 ⇔ (P12 ∨ P21))

The KB is satisfied by models where all rules are true simultaneously.

Exclusive OR (XOR)

XOR (exclusive or) is true when exactly one operand is true, but not both. It is not a standard connective but can be expressed using the five standard connectives.

XOR Definition
α ⊕ β ≡ (α ∨ β) ∧ ¬(α ∧ β)
True when exactly one of α, β is true.
XOR Alternative Form
α ⊕ β ≡ (α ∧ ¬β) ∨ (¬α ∧ β)
"α true and β false, or α false and β true."

Satisfiability and Tautology

Satisfiable
A sentence α is satisfiable if there exists at least one model where α is true.
Example

P ∧ Q is satisfiable (model {P=T, Q=T} satisfies it).

Unsatisfiable
A sentence α is unsatisfiable if it is false in EVERY model.
Example

P ∧ ¬P is unsatisfiable (contradiction).

Tautology
A sentence α is a tautology if it is true in EVERY model.
Example

P ∨ ¬P is a tautology (law of excluded middle).

Key Relationships
α is a tautology ⟺ ¬α is unsatisfiable
α is satisfiable ⟺ ¬α is not a tautology
