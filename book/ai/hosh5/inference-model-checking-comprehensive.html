Logical Entailment

Entailment (⊨) is the fundamental relationship in logic. A sentence α is entailed by KB if α is true in every model where KB is true.

Entailment Definition
KB ⊨ α
"KB entails α" — In every model where KB is true, α is also true.
Intuition: Entailment

If KB says "All humans are mortal" and "Socrates is human", then KB ⊨ "Socrates is mortal".

There is no possible world where the KB is true but the conclusion is false.

Counter-Example (Non-Entailment)
KB ⊭ α
"KB does not entail α" — There exists at least one model where KB is true but α is false.

Soundness and Completeness

Sound Algorithm
If the algorithm says KB ⊨ α, then it is truly the case.
Soundness Property

No false positives — never claims entailment when it doesn't hold.

KB ⊨ α ⟹ Algorithm says YES

Complete Algorithm
If KB ⊨ α is true, the algorithm will find it.
Completeness Property

No false negatives — never misses a real entailment.

KB ⊨ α ⟸ Algorithm says YES

Sound and Complete
Algorithm says YES ⟺ KB ⊨ α
The algorithm is both sound AND complete — it gives exactly the right answer every time.

TT-ENTAILS Algorithm

The Truth Table Entailment (TT-ENTAILS) algorithm determines if KB entails α by exhaustively checking all possible models.

function TT-ENTAILS(KB, α): symbols = list of propositional symbols in KB and α return TT-CHECK-ALL(KB, α, symbols, {}) function TT-CHECK-ALL(KB, α, symbols, model): if symbols is empty: if KB is true in model: return α is true in model else: return true // KB false → vacuously true else: P = first(symbols) rest = symbols without P true_model = extend(model, P, true) false_model = extend(model, P, false) return TT-CHECK-ALL(KB, α, rest, true_model) AND TT-CHECK-ALL(KB, α, rest, false_model)

How It Works Step by Step

Algorithm Walkthrough

Step 1: Collect all unique propositional symbols from KB and α.

Step 2: Start with an empty model (no assignments yet).

Step 3: Pick the first symbol P. Recursively try P=true and P=false.

Step 4: For each branch, pick the next symbol and branch again.

Step 5: When all symbols are assigned (leaf node), check:

• If KB is false in this model → return true (vacuously satisfied)

• If KB is true → check if α is also true. If yes → continue. If no → return false (counter-example found!)

Step 6: Return true only if ALL models where KB is true also make α true.

Key Insight
KB ⊨ α iff in every model where KB is true, α is also true
TT-ENTAILS checks this by brute force: enumerate all 2^n models and verify.

Why Return True When KB is False?

This is the concept of vacuous truth. An implication with a false premise is always true.

Vacuous Truth Example

Consider: "If pigs can fly, then the moon is made of cheese."

Since pigs cannot fly (premise is false), the statement is vacuously true — it hasn't been violated.

In logic, we only reject an implication when the premise is true and the conclusion is false.

Time and Space Complexity

AspectComplexityExplanation
TimeO(2^n)Must enumerate all 2^n models. Each model takes O(n) to evaluate.
SpaceO(n)Depth-first recursion stack. Only one path through the tree at a time.
Space Efficiency
Space: O(n) not O(2^n)
Because we use depth-first enumeration, we only need to store the current path (at most n deep). We don't store all models simultaneously.
Practical Limits

10 symbols: 2^10 = 1,024 models → instant

20 symbols: 2^20 = 1,048,576 models → seconds

30 symbols: 2^30 = 1,073,741,824 models → minutes

50 symbols: 2^50 ≈ 10^15 models → years!

This exponential blowup makes TT-ENTAILS impractical for large problems.

NP-Completeness Warning

⚠ Important: Propositional entailment (and satisfiability) is CO-NP-complete. This means:

• No known polynomial-time algorithm exists for general propositional logic
• TT-ENTAILS is the simplest (but slowest) approach
• For practical systems, we need smarter methods: DPLL, resolution, unit propagation
• Even small improvements matter — SAT solvers handle thousands of variables using heuristics
CO-NP-Complete
The complement problem (is α NOT entailed?) is in NP. Equivalently, finding a counter-example model is in NP — you can verify one quickly.
SAT Problem
Determining if a sentence is satisfiable (has at least one true model) is NP-complete. This is the canonical NP-complete problem.
