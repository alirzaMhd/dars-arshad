CIRCUIT-BASED AGENTS

Artificial Intelligence — Logical Agents Chapter

Sequential Circuits and Dataflow

A circuit-based agent is a special type of reactive agent with internal state. Instead of using inference algorithms (like DPLL), it directly evaluates propositional sentences using a hardware circuit.

What is a Sequential Circuit?

A sequential circuit is a network of logic gates and registers:

Logic Gates

Implement logical connectives: AND, OR, NOT, etc. Each gate computes a Boolean function of its inputs.

Registers

Store truth values of propositional symbols. Output of registers = action outputs. Each register holds one Boolean value.

Feedback Loops

Output connects back to input (delayed by one time step). This preserves state across time steps.

Dataflow Evaluation

Circuits are evaluated using dataflow — signals propagate through the circuit:

  1. At each time step, inputs get values from sensors
  2. Signals propagate through gates
  3. When ALL inputs of a gate are ready, it produces its output
  4. This process continues until all register inputs are determined
  5. Register values update for the next time step
Dataflow Analogy
Dataflow evaluation ≈ Forward chaining in AND-OR graphs
Just as forward chaining propagates facts through Horn clauses, dataflow propagates signal values through logic gates until a stable state is reached.

State Preservation via Feedback

The agent's internal state is preserved by connecting output registers back to inputs:

Example: The Alive Register

The Alive register stores whether the Wumpus is alive. At time t, the register's output feeds into the circuit. At time t+1, it becomes an input again (delayed by one step).

Key insight: The register's value at time t represents the current truth of the proposition "Alive." Unlike inference-based agents, there's no time-stamped copy — just one register that updates each step.

Important distinction: In an inference-based agent, you'd have propositions like Alive₁, Alive₂, Alive₃ for each time step. In a circuit, a single register stores the current truth value and updates automatically via feedback.

Wumpus World Circuit

The circuit-based agent for the Wumpus World uses propositional logic directly in hardware. Here are the key formulas implemented as circuits:

Alive Register

Alive' (next state of Alive)
Alive' = (Alive ∧ ¬Scream) ∨ (Alive ∧ ¬eaten_by_wumpus)
The Wumpus stays alive unless a Scream is heard (meaning the agent shot it) or the Wumpus is eaten. In the simple version: Alive stays true unless Scream is true.
Simplified Alive
Alive' = Alive ∧ ¬Scream
Once Scream is true (Wumpus killed), Alive becomes false and stays false forever.

Forward Action

Forward (conditional expression)
Forward = (Alive ∧ ¬Forward_prev ∧ ¬Bump) ∧ (some navigation condition)
The agent moves forward when it's alive, hasn't bumped into a wall, and navigation logic permits movement. The exact condition depends on the agent's facing direction.

Inputs and Outputs

Inputs (Sensors)

Breeze, Stench, Glitter, Bump, Scream

These come from the environment at each time step

Outputs (Actions)

Forward, TurnLeft, TurnRight, Grab, Shoot

These are the values of output registers

Signal Propagation Examples

Trace how signals flow through the circuit at each time step.

Example 1: Agent Sees Glitter → Grabs Gold

Time step t:

  1. Input: Glitter = true (sensor detects gold)
  2. Signal reaches the Grab output gate
  3. Grab = true (output register set to true)
  4. Action: Agent executes Grab

Time step t+1:

  1. Glitter may now be false (gold picked up)
  2. Grab = false (no longer grabbing)
  3. But gold is now in agent's possession

Latency: 1 time step from perception to action.

Example 2: Scream Kills the Wumpus

Time step t:

  1. Input: Scream = true (Wumpus was shot)
  2. Signal propagates to Alive register input
  3. Alive' = Alive ∧ ¬Scream = true ∧ false = false
  4. Register updates: Alive = false

Time step t+1:

  1. Alive = false (Wumpus is dead)
  2. All actions requiring Alive (like Shoot) are disabled
  3. Stench = false (dead Wumpus doesn't stink)

State change: Alive goes from true → false, persisting across all future steps.

Example 3: Bump Prevents Forward Movement

Time step t:

  1. Input: Bump = true (agent hit a wall)
  2. Forward register input = (some condition) ∧ ¬Bump = false
  3. Forward = false (agent does not move)

Time step t+1:

  1. Bump = false (no longer bumping)
  2. Agent can now try Forward again
  3. But the agent's position did NOT change (stayed in same square)

The Bump signal acts as a temporary inhibitor — it blocks Forward for one step only.

Example 4: TurnLeft Updates Facing Direction

Time step t:

  1. Agent decides to turn left (some condition makes TurnLeft = true)
  2. TurnLeft output triggers facing register updates
  3. If FacingRight → now FacingUp (or FacingLeft depending on convention)

Time step t+1:

  1. FacingUp = true (new direction)
  2. Forward now moves in the new direction

Facing direction persists across steps via register feedback.

Circuit-Based vs Inference-Based Agents

Property Circuit-Based Agent Inference-Based Agent
Mechanism Propositional logic evaluated as circuit KB + inference algorithm (DPLL)
Speed Very fast (parallel gate evaluation) Slower (sequential inference steps)
Response time Real-time (signals propagate in nanoseconds) May require multiple inference cycles
State representation Single register per proposition (current value) Time-stamped propositions (Alive₁, Alive₂, ...)
Completeness Limited — only computes what circuit implements Complete — can derive all entailed sentences
Flexibility Fixed — must rebuild circuit for new knowledge Flexible — just TELL new sentences to KB
Parallelism All gates evaluate simultaneously Typically sequential inference steps
Hardware requirement Physical circuit or FPGA Software on general-purpose computer

Advantages of Circuit-Based Agents

Speed

Signals propagate through gates in nanoseconds. Response time is essentially the circuit's propagation delay.

Parallelism

All gates evaluate simultaneously — no sequential inference steps needed.

Simplicity

No complex inference algorithms — just signal propagation through logic gates.

Limitations

Critical limitation: Circuit-based agents cannot express complex relationships like time, space, or quantifiers. They are limited to propositional logic — no "for all squares x" or "there exists a path." This makes them inadequate for complex reasoning tasks.

Other limitations:

  • Cannot handle quantified sentences (need first-order logic)
  • Cannot reason about unobserved parts of the environment beyond propositional inference
  • Circuit must be redesigned for new knowledge or changed environment
  • Scaling: circuits for complex domains become enormous
  • No learning capability — cannot adapt to new situations
Bottom Line
Circuit-based = fast but rigid | Inference-based = flexible but slower
Both approaches implement propositional logic. Circuits evaluate it in hardware; inference agents compute it in software. Choose based on whether you need speed (circuit) or flexibility (inference).

Propositional Logic in Hardware

Each gate in the circuit directly implements a logical connective:

AND gate: output = input1 ∧ input2 OR gate: output = input1 ∨ input2 NOT gate: output = ¬input

The entire circuit is a hardware implementation of a propositional sentence. No inference is needed — the circuit simply evaluates the sentence by signal propagation. This is why circuits are so fast: they compute the answer in parallel, in hardware, in a single time step.
