Fundamentals

Breadth-First Search (BFS)

FIFO queue, level-by-level expansion, O(b^(d+1)) time & space, optimal with uniform costs.

Uninformed

Uniform-Cost Search (UCS)

Priority queue by g(n), optimal for any cost ≥ ε, O(b^(1+⌊C*/ε⌋)) complexity.

Uninformed

Depth-First Search (DFS)

LIFO stack, O(bm) space, backtracking variant O(m), not complete or optimal.

Uninformed

Depth-Limited Search (DLS)

Depth cutoff l, solves infinite paths, recursive implementation, cutoff vs failure.

Uninformed

Iterative Deepening Search (IDS)

Repeated DLS with increasing l, O(b^d) time, O(bd) space, combines BFS + DFS benefits.

Uninformed

Bidirectional Search

Forward + backward, O(b^(d/2)) time, requires predecessor computation, hash table intersection.

Uninformed

Avoiding Repeated States

Tree vs graph search, closed/open lists, exponential waste from repeats, optimality trade-offs.
