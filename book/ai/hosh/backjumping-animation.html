Problem Setup

We solve a Constraint Satisfaction Problem (CSP) using Conflict-Directed Backjumping — an intelligent backtracking algorithm that tracks conflict sets.

Variables: A, B, C (ordered A → B → C)

Domains: D(A)={a,b}, D(B)={a,b}, D(C)={a}

Constraints: A ≠ B, B ≠ C, A ≠ C

The Backjumping Idea

When a dead-end occurs at variable X, backjump to the most recent variable in X's conflict set

This skips irrelevant variables — unlike naive backtracking which always goes back one step.
