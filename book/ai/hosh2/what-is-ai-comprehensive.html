What is Artificial Intelligence?

Chapter 1 — Foundations and Definitions

AI Overview

Artificial Intelligence asks two distinct questions:

Thinking vs Acting

One axis asks whether AI systems should think like humans or whether they should act rationally.

Human-Like vs Ideal

The other axis asks whether systems should mimic humans or achieve ideal rational intelligence.

Four Dimensions:
Think Humanly | Act Humanly | Think Rationally | Act Rationally
Combinations of these span most AI definitions.
Example: Two Perspectives

Human-like: A chess program that makes mistakes similar to a human amateur.

Rational: A chess engine that always chooses the maximally strong legal move within the time limit.

Definitions of AI

Definitions cluster around four common categories.

Warning: Treat each definition as a lens, not a rigid boundary. Modern AI systems often blend multiple categories.

Category 1 - Systems That Think Like Humans

Focus on modeling internal cognitive mechanisms. The goal is understanding how minds work by building working systems.

Example: GPS (General Problem Solver, 1961) compared reasoning steps directly to human analysis.

Category 2 - Systems That Act Like Humans

Turing Test (1950): if a machine can converse indistinguishably from a human through text, it demonstrates AI. Requires NLP, knowledge representation, automated reasoning, ML, computer vision, and robotics.

Category 3 - Systems That Think Rationally

Based on formal logic. Aristotle's syllogism: if all premises are true, the conclusion must be true. Difficulties include transforming informal knowledge into logical axioms, and the gap between theoretical solvability and practical computation.

Category 4 - Systems That Act Rationally

An agent should perform the action that maximizes expected performance given its percept history and capabilities. This is the definition used in this text.

Thinking Rationally

This tradition traces back to Aristotle's laws of thought. The ideal is a formal system in which true premises and correct inference rules yield only true conclusions.

Aristotle's Pattern:
All men are mortal.
Socrates is a man.
Therefore, Socrates is mortal.
A classic syllogism: true premises and a valid rule guarantee true conclusion.

Two Major Obstacles

ObstacleDescription
Formalization DifficultyConverting informal knowledge into precise logical form is hard, especially with uncertainty below 100%.
Theory vs Practice GapProblems solvable in principle may be intractable in practice due to computational limits.
Warning: Rational thinking is about making the best inference given available knowledge, not achieving omniscience or perfection.

Acting Rationally

A rational agent chooses actions that maximize an expected performance measure based on percept history, prior knowledge, and feasible actions.

Rationality Condition:
at = argmaxa E[performance | percept1:t, knowledge]
Select action a that maximizes expected performance given all percepts so far and what the agent knows.

Expected vs Actual Performance

Expected Performance

Measured across the distribution of scenarios the agent can encounter. Rationality optimizes this.

Actual Performance

What happens in a single execution. Enlightenment strives for ideal behavior, but rational agents cope with uncertainty.

Four Dependencies of Rationality

  1. Performance measure defining success.
  2. Percept sequence the agent has received.
  3. Prior knowledge about the environment.
  4. Actions the agent can execute.

Information Gathering

Actions that obtain useful future information are themselves rational even if they do not immediately improve the score. This is called information gathering and is a key part of rationality.

Example

Before crossing a busy street, a rational agent looks both ways. The look does not directly advance the goal, but it improves future expected performance by reducing uncertainty.

Rationality Includes Exploration:
at = argmaxa E[performance | percept1:t, knowledge + future info from a]
Information-gathering actions increase expected performance by improving future percepts.

Additional Examples

Example 1 - Rational Street Crossing

You see no cars on a busy street and decide to cross. Even if a rare falling object appears, your decision was rational because it maximized expected success under available evidence.

Example 2 - Robot Vacuum

A robot vacuum mapping dirt probability typically maximizes cleaned area per hour. It gathers information about high-dirt areas efficiently rather than cleaning randomly.

Example 3 - Medical Diagnosis

A doctor orders additional tests not because they always help, but because they reduce diagnostic uncertainty and increase expected treatment success.

Example 4 - Chess Program

A perfect chess engine is rational within time limits: it searches the game tree and selects the move with the highest estimated win probability given board state and remaining time.
