Iterative Deepening Search (IDS)

AI Search - Complete Guide for 20/20 Exam

IDS Algorithm

Iterative Deepening Search combines the space efficiency of DFS with the completeness of BFS. It runs DLS repeatedly with increasing depth limits: 0, 1, 2, ... until a goal is found.

function IDS(problem) returns solution or failure
for depth = 0 to ∞ do
result ← DLS(problem, depth)
if result ≠ cutoff then return result
return failure
Key Insight:
Most nodes in a uniform branching tree appear at the maximum depth. Shallow nodes are a tiny fraction. Therefore, re-expanding shallow nodes costs almost nothing compared to the final expansion.

Time and Space Complexity

IDS performs DLS with limits 0, 1, ..., d. The total number of nodes expanded is less than BFS because most nodes lie at the deepest level and are expanded only once.

Total Nodes Expanded:
N(IDS) = b^d + b^(d-1) + ... + b + 1
This is dominated by b^d, the last iteration. Shallower levels contribute negligibly.
Time Complexity:
O(b^d)
Same asymptotic time as BFS, but with smaller constant factors.
Space Complexity:
O(b * d)
Same as DFS - only the current path plus siblings are stored.
Example - Numeric Comparison

If b = 10 and d = 5, BFS generates 111,110 nodes. IDS generates: 1 + 10 + 100 + 1000 + 10000 + 100000 = 111,111 nodes. The overhead is negligible.

Properties

Property IDS
Complete? Yes, for finite b
Optimal? Yes, if step costs are uniform or non-increasing with depth
Time Complexity O(b^d)
Space Complexity O(b*d)
Queue Type LIFO with increasing depth limit
When Optimality Fails: If step costs are not uniform, IDS may find a non-optimal goal at a shallow depth before the optimal deeper goal. Use Iterative Lengthening Search (ILS) for optimality with varying costs.

Worked Examples

Example 1 - Finding Goal at Depth 3

IDS runs DLS(limit=0): no goal, cutoff. DLS(limit=1): no goal, cutoff. DLS(limit=2): no goal, cutoff. DLS(limit=3): finds goal. Total nodes expanded: 1 + b + b^2 + b^3.

For b=2: 1+2+4+8 = 15 nodes vs BFS's 15 nodes for same depth. Nearly identical.

Example 2 - Large Branching Factor

If b = 100, d = 4: BFS needs 100^4 + 100^3 + ... = 101010100 nodes. IDS needs 1 + 100 + 10000 + 1000000 + 100000000 = same dominant term. Re-expansion cost is tiny.

Example 3 - IDS vs DFS

DFS with l=10 on a tree where goal is at depth 3: DFS explores to depth 10, missing the shallow goal. IDS finds the goal at depth 3 after trying limits 0, 1, 2, 3.

Example 4 - Preferred Choice

When the state space is huge and solution depth is unknown, IDS is the default uninformed search strategy. It guarantees completeness with linear memory, unlike BFS which needs exponential memory.
