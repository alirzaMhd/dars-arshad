Uniform Cost Search (UCS)

AI Search - Complete Guide for 20/20 Exam

UCS Algorithm

Uniform Cost Search expands the node with the lowest path cost first, regardless of its depth. It uses a priority queue ordered by g(n), the cost of the path from the start to node n.

function UCS(problem) returns solution or failure
fringe ← PriorityQueue ordered by path cost
fringe ← Insert(Make-Node(Initial-State[problem]), fringe)
loop do
if Empty?(fringe) then return failure
node ← Pop-Min(fringe)
if Goal-Test[problem](State[node]) then return Solution(node)
fringe ← Insert-All(Expand(node, problem), fringe)
Priority Criterion:
f(n) = g(n)
g(n) is the path cost from start to node n. UCS always selects the node with minimum g(n).

Time and Space Complexity

UCS explores all paths with cost less than the optimal solution cost C*. In the worst case, it behaves like BFS on a tree where each level corresponds to a cost increment.

Time Complexity:
O(b^(C*/epsilon))
Where epsilon is the minimum nonzero step cost. If step costs are 1 or greater, this simplifies to O(b^d) similar to BFS.
Space Complexity:
O(b^(C*/epsilon))
All nodes with path cost less than C* may need to be stored simultaneously.
Example - Cost Variability

If the optimal path cost is C* = 20 and each action costs at least 1, UCS may expand up to depth 20. With b = 3, this is 3^20 ≈ 3.5 billion nodes in the worst case.

Properties

Property UCS
Complete? Yes, if step costs >= epsilon > 0
Optimal? Yes, for any step cost function
Time Complexity O(b^(C*/epsilon))
Space Complexity O(b^(C*/epsilon))
Queue Type Priority Queue by g(n)
Critical Safety Condition: If any action has zero cost, UCS can loop forever by cycling through zero-cost actions. The condition step-cost >= epsilon > 0 prevents this infinite loop.

Worked Examples

Example 1 - Romania with Real Distances

Start: Arad. Goal: Bucharest. Each road has a real distance cost. UCS explores paths in order of accumulated kilometers, not number of cities. The cheapest path may not be the shortest in hops.

Result: Arad → Sibiu → Rimnicu → Pitesti → Bucharest with cost 418 km is found before the longer-hop Arad → Sibiu → Fagaras → Bucharest with cost 450 km.

Example 2 - Step Costs of 5 and 10

Actions have costs 5 or 10. Start S, goal G. Path S→A→G costs 5+5=10. Path S→B→C→G costs 10+5+5=20. UCS selects A (cost 5) before B (cost 10), then G from A is found first.

Example 3 - Zero-Cost Loop Danger

State A has a Noop action with cost 0 that returns to A. UCS will keep expanding A→A→A→... forever without making progress. Always ensure minimum step cost > 0.

Example 4 - UCS vs BFS on Weighted Graph

Consider graph: S--1-->A--1-->G, S--10-->B--1-->G. BFS (treating all edges as equal) finds G via A at depth 2. UCS finds G via A at total cost 2, which is optimal. If BFS treated edges as hops, it still finds the shallowest goal. UCS considers actual costs.
