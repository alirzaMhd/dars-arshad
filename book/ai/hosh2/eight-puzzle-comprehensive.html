8-Puzzle (Sliding Block Puzzle)

Classic Toy Problem for Heuristic Search — Complete Guide

Defining the 8-Puzzle

The 8-puzzle is a 3×3 board with 8 numbered tiles (1-8) and one empty space. Tiles slide into the empty space.

Goal state: tiles 1-8 in order, empty at bottom-right

State Representation

A 3×3 grid specifying each cell's tile number or empty.

Equivalently: a permutation of {0,1,...,8} where 0 = empty

Actions

Move empty space Up, Down, Left, Right

Each action swaps the empty with an adjacent tile

Goal Test

Check if state matches goal configuration.

Single goal state: [[1,2,3],[4,5,6],[7,8,0]]

Path Cost

1 per move

Optimal solution minimizes number of moves

5-Component Problem Formulation
P = (S, A, T, G, Cost)
S = set of all 3x3 tile configurations (9! / 2 reachable from a given start)
A = {Up, Down, Left, Right} (subject to edge constraints)
T(s, a) = s' where empty cell moves in direction a
G(s) = true iff s = [[1,2,3],[4,5,6],[7,8,0]]
Cost(s, a, s') = 1 for all valid transitions
Example: Action Constraints at Edges

The empty space cannot move outside the board. If empty is at:

Corner (0,0): Only Down and Right are valid.

Edge (0,1): Only Down, Left, and Right are valid.

Center (1,1): All 4 directions are valid.

Branching factor is 2-4 depending on the empty cell's position.

State Space Size

The 8-puzzle has a total of 9! = 362,880 possible tile arrangements. However, not all are reachable from a given start state due to parity constraints.

Reachable States
9! / 2 = 181,440
Exactly half of all permutations are reachable from any given starting state.
Half of all possible tile arrangements are unreachable from a given start state. The state space is split into two disjoint sets. If you start in one set, you can never reach any state in the other set. This is determined by the parity (even/odd) of the permutation.

Inversion Parity Explanation

An inversion is a pair of tiles (a, b) where a > b but a appears before b in the linearized row-major order (reading left-to-right, top-to-bottom, ignoring the empty space).

Solvability Condition
(inversions mod 2) = (blank_row_from_bottom mod 2)
If the parity of inversions matches the parity of the row distance of the blank from the bottom, the puzzle is solvable from the given start.
Example: Checking Solvability

State: [[1, 2, 3], [4, 5, 6], [8, 7, 0]]

Linearized (ignoring 0): [1, 2, 3, 4, 5, 6, 8, 7]

Inversions: (8,7) = 1 inversion. Inversion count = 1 (odd).

Blank row from bottom: row 1 (bottom) → distance = 1 (odd).

Parity match: odd = odd → SOLVABLE.

Example: 15-Puzzle Scale

The 15-puzzle has 16! = 20,922,789,888,000 (about 20.9 trillion) total permutations. Half are reachable: about 10.5 trillion states.

Even with a computer checking 1 billion states per second, exploring the full 15-puzzle state space would take ~10,500 seconds (~3 hours). In practice, heuristics are essential.

The optimal solution for any 15-puzzle instance requires at most 80 moves.

Example: 24-Puzzle Scale

The 24-puzzle has 25! ≈ 1.55 × 1025 total permutations. This is about 1.55 septillion states.

Comparing scales:

24-puzzle states ≈ number of grains of sand on Earth (× 1000)

Even with a computer checking 1 trillion states per second, it would take ~500 billion years to explore all states.

The optimal solution for any 24-puzzle instance requires at most 208 moves.

Why NP-Complete?

The generalized n×n sliding puzzle is NP-complete. This means:

  • No polynomial-time algorithm exists (unless P = NP)
  • Finding the optimal (shortest) solution is computationally hard
  • Heuristic search (e.g., A* with Manhattan distance) is used in practice
  • Even finding any solution is easy (linear-time algorithms exist), but finding the optimal solution is hard

Example 3: Counting Reachable States from Different Random Starts

Scenario: You randomly generate 1,000,000 initial tile arrangements for a 3×3 board. How many are solvable?

Analysis:

Total permutations = 9! = 362,880

Solvable from a given starting state = 9! / 2 = 181,440

If we consider all possible permutations as start states, each belongs to one of two equivalence classes (even parity or odd parity). The goal state [[1,2,3],[4,5,6],[7,8,0]] has a specific parity. Let's compute its parity:

Linearized goal: [1,2,3,4,5,6,7,8,0] (ignoring 0). Inversions = 0 (even). Blank row from bottom = 0 (bottom row, row 2, distance 0. Even = even).

Goal parity = even. So only states with matching parity (even inversions or matching row parity) are solvable to the standard goal.

50% of random arrangements are solvable (181,440 out of 362,880).

Example 4: Why 9!/2? Proof by Invariant

Every move in the 8-puzzle is a transposition (swap) of the empty tile with an adjacent numbered tile. Moving the empty tile horizontally does not change the permutation parity (it's a single swap + row change). Moving it vertically involves a swap plus two "wrap-around" effects that effectively change parity.

Key invariant: The parity of (inversions + blank_row_distance) never changes with any move.

Since the goal state has this value = 0 (even), any solvable state must also have an even value.

Exactly half of all 9! permutations satisfy this constraint, giving us 9!/2 = 181,440 reachable states.
