Depth-Limited Search (DLS)

AI Search - Complete Guide for 20/20 Exam

DLS Algorithm

Depth-limited search is DFS with a predetermined cutoff depth. Nodes beyond the limit are treated as having no successors, preventing infinite descent down infinite branches.

function DLS(problem, limit) returns solution, failure, or cutoff
return Recursive-DLS(Make-Node(Initial-State), problem, limit)

function Recursive-DLS(node, problem, limit) returns solution, failure, or cutoff
if Goal-Test[problem](State[node]) then return Solution(node)
else if Depth(node) = limit then return cutoff
else
cutoff-occurred? ← false
for each child in Expand(node, problem) do
result ← Recursive-DLS(child, problem, limit)
if result = cutoff then cutoff-occurred? ← true
else if result ≠ failure then return result
if cutoff-occurred? then return cutoff else return failure
Cutoff Condition:
if Depth(node) = limit → return cutoff
When depth equals the limit, the algorithm stops expanding that branch and signals "cutoff" rather than "failure."

Time and Space Complexity

DLS is identical to DFS except that it never explores beyond depth l, the cutoff limit. This bounds both time and space by l.

Time Complexity:
O(b^l)
l = depth limit. All nodes up to depth l may be generated.
Space Complexity:
O(b * l)
Only the current path of length l plus siblings at each level need storage.
Example - Choosing Limit

In Romania with 20 cities, the maximum useful route has at most 19 edges. Setting l = 19 ensures DLS never cuts off a valid solution. The graph diameter gives the tightest safe bound.

Properties

Property DLS
Complete? Yes, if l >= d (solution depth)
Optimal? No - goal at depth l may be non-optimal
Time Complexity O(b^l)
Space Complexity O(b*l)
Queue Type LIFO Stack with depth bound
Choosing the Limit: If l < d (actual goal depth), DLS returns cutoff and cannot find the goal, making it incomplete. If l >> d, DLS wastes time exploring irrelevant deep branches. The diameter of the state space often gives the best limit.

Worked Examples

Example 1 - Romania with l=19

With 20 cities, the longest simple path has 19 edges. Setting l=19 means DLS explores every possible route. It will find Bucharest if reachable, but may explore very deep irrelevant routes first.

Example 2 - l Too Small

Goal at depth d=8. Set l=5. DLS explores all nodes up to depth 5, returns cutoff at every leaf, and ultimately reports failure. Even though a solution exists, DLS never finds it.

Example 3 - Backtracking Search

Backtracking search is a variant of DLS that generates only one child at a time instead of all children. It remembers which children remain to be explored. Space complexity drops to O(m) = O(l), at the cost of more bookkeeping.

Example 4 - When to Use DLS

DLS is useful when the state space is known to have bounded depth, such as chess with a 50-move rule, or when exploring all positions up to a certain ply in game-tree search.
