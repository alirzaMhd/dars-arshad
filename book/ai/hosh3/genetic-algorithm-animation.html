Problem Setup

We want to maximize f(x) = x² where x is an integer encoded as a 6-bit binary string.

The search space has 2⁶ = 64 possible values (0–63). The global maximum is f(63) = 3969.

How It Works

A population of candidate solutions evolves over generations:

1. Evaluate fitness of each individual

2. Select parents via tournament selection

3. Crossover parents to create offspring

4. Mutate offspring with small probability

5. Replace population with new generation (elitism keeps best)

fitness(x) = x², where x = decode(binary string)
