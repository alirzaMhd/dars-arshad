Overview & Formulations

Local search algorithms operate on a complete-state formulation: each state assigns a value to every variable, and a move changes one or more variables. They keep only the current state in memory, not the path to it.

8-Queens Successors:
n × (n - 1) = 8 × 7 = 56 neighbors
Each queen can move to any other row in its column.

When the path to a goal is unimportant, local search is ideal. Examples: 8-Queens (only final placement matters), VLSI layout, job-shop scheduling, vehicle routing, network design.

Objective Function vs Cost Function

Cost Function h(n)

Minimize cost

Example: number of attacking queen pairs. Goal is global minimum h=0.

Objective Function

Maximize value

Example: fitness, number of non-attacking pairs. Max = C(8,2)=28. Convert via h_cost = C - h_obj.

Hill Climbing

Hill climbing is greedy local search. It evaluates neighbors and moves to the highest-valued (or lowest-cost) neighbor. It does not look beyond immediate neighbors.

Pseudocode -- Steepest-Ascent Hill Climbing
function HILL-CLIMBING(problem) returns a state current ← MAKE-NODE(INITIAL-STATE[problem]) loop do neighbor ← a HIGHEST-VALUED successor of current if VALUE[neighbor] <= VALUE[current] then return STATE[current] current ← neighbor

8-Queens Example

Worked Example

Initial state has h=17 attacking pairs. All 56 successors are evaluated; best neighbor has h=12. After one move, h=12. This continues until a local maximum is reached.

From random starts, steepest-ascent hill climbing solves only 14% of 8-Queens instances and takes 4 steps on average when successful, 3 steps when it fails.

Time & Space Complexity

Time Complexity

Best case: O(d)

Worst case: O(infinity) on plateau

Each step evaluates up to c successors. For 8-Queens, c=56 per step.

Space Complexity

O(1)

Only current state and value stored. No search tree.

Variants of Hill Climbing

Stochastic Hill Climbing

Choose randomly among uphill moves, weighted by steepness. May find better paths than always taking the single best.

First-Choice Hill Climbing

Generate successors randomly one at a time until an improvement is found. Efficient when there are many successors but few uphill moves.

Random-Restart Hill Climbing

Run steepest-ascent hill climbing from multiple random initial states. With probability ~1, eventually finds a solution.

Completion Probability:
P(success in k restarts) = 1 - (1 - p)^k
p = single-run success probability. With k→infinity, probability approaches 1.
Worked Example: Random-Restart for 8-Queens

Plain HC success rate p = 0.14. For P≥0.99: k ≥ ln(0.01)/ln(0.86) ≈ 30 restarts. With sideways moves (p=0.94): k ≥ ln(0.01)/ln(0.06) ≈ 2 restarts. Sideways moves dramatically reduce required restarts.

Sideways Moves

Allow moves to a neighbor with the same value, in hope of crossing a shoulder. Limit consecutive sideways moves to avoid infinite loops on flat local maxima.

Warning: Unlimited sideways moves can cause infinite loops on flat local maxima. A limit of 100 yields 94% success on 8-Queens.

Gradient Descent

When minimizing cost instead of maximizing value, hill climbing is called gradient descent. Same issues: local minima, ridges, plateaus.

When Local Search Fails

Failure Modes

Local Maximum

A peak higher than all neighbors but not the global peak. Greedy moves stop here.

Ridge

A narrow path of improving states with 90-degree turns. Greedy cannot navigate because it requires multiple downhill steps.

Plateau

Flat region where all neighbors have equal value. Two types: flat local maximum (stuck) and shoulder (can still lead up).

Exponential Local Optima

For NP-hard problems, local maxima grow exponentially with size. Random restart becomes impractical.

Online Search

Standard local search assumes the full state space and action model are known. Online search relaxes this: the agent has no prior model. It must explore and learn heuristics as it goes.

LRTA* Heuristic Update:
h_new(s) = min( h_old(s), actual_cost(parent, s) + h(s) )
After moving to a successor s, the agent updates the heuristic for the previous state using the actual cost observed plus the successor's current heuristic estimate.
Warning: Online search is not optimal. The agent may wander into dead ends before finding the goal. It is useful when no problem model is available, e.g., a robot exploring an unknown terrain.
