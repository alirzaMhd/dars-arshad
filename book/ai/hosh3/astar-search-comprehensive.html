A* Search Algorithm

A* is the most famous and widely used form of best-first search. It evaluates nodes by combining the cost to reach the node (g(n)) and the estimated cost from the node to the goal (h(n)):

A* Evaluation Function
f(n) = g(n) + h(n)
where g(n) = cost from initial state to node n, h(n) = estimated cost from n to nearest goal. f(n) estimates the total cost of a cheapest solution through n.

Intuition

A* combines the benefits of Uniform-Cost Search (which minimizes g(n)) and Greedy Best-First Search (which minimizes h(n)):

  • g(n) ensures we don't ignore the cost already incurred
  • h(n) directs the search toward the goal
  • Together, f(n) = g(n) + h(n) gives the estimated cost of the cheapest solution through n

Pseudocode

function A-STAR-SEARCH(problem) returns a solution node ← MAKE-NODE(INITIAL-STATE[problem]) frontier ← priority queue ordered by f(n) = g(n) + h(n) explored ← empty set add node to frontier loop do if frontier is empty then return failure node ← POP(frontier) // node with lowest f(n) if GOAL-TEST(node) then return SOLUTION(node) add node to explored for each successor in SUCCESSORS(node) do if successor not in explored and not in frontier then add successor to frontier else if successor is in frontier with higher f then replace with lower f path

Optimality Proof Sketch (with Admissible Heuristic)

Proof by Contradiction
Suppose A* returns a suboptimal path with cost C > C* (optimal cost).
Let n be an unexpanded node on the optimal path.
Then: f(G₂) = g(G₂) + h(G₂) = g(G₂) > C* (since h(G₂)=0)
And: f(n) = g(n) + h(n) ≤ g*(n) + h*(n) = C* (by admissibility: h(n) ≤ h*(n))
So f(n) ≤ C* < f(G₂), meaning n would be expanded before G₂ — contradiction.
If h(n) is admissible (never overestimates), then A* with TREE-SEARCH is complete and optimal.
⚠ Space Complexity Warning: A* keeps all generated nodes in memory. Space complexity is O(bd), which is often the limiting factor in practice — not time. For many problems, A* runs out of memory before it runs out of time.
