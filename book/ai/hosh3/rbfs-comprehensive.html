RBFS — Recursive Best-First Search

Artificial Intelligence — Informed Search

Algorithm Overview

RBFS is a recursive algorithm that mimics best-first search using only linear space. It performs recursive DFS but tracks the f-value of the best alternative path. When the current path's f exceeds the limit, it backtracks and updates f-values so the best forgotten leaf is remembered.

f-value Update on Backtracking
f[node] ← min(f[descendant], f[node])
When backtracking, a node's f-value is updated to the minimum f of its descendants — remembering the best leaf in the forgotten subtree

Pseudocode

function RECURSIVE-BEST-FIRST-SEARCH(problem) returns solution return RBFS(problem, MAKE-NODE(INITIAL-STATE[problem]), ∞) function RBFS(problem, node, f-limit) returns solution or failure and new f-cost if GOAL-TEST(STATE[node]) then return node successors ← EXPAND(node, problem) if successors is empty then return failure, ∞ for each s in successors do f[s] ← max(g(s)+h(s), f[node]) repeat best ← lowest f-value node in successors if f[best] > f-limit then return failure, f[best] alternative ← second-lowest f-value in successors result, f[best] ← RBFS(problem, best, min(f-limit, alternative)) if result ≠ failure then return result

Key Concepts

f[s] = max(g(s)+h(s), f[node])
Each child inherits at least the parent's f-value. This ensures f is non-decreasing along paths.
Backtracking Trigger
When f[best] > f-limit, RBFS backtracks because this path is no longer promising.
f-Value Update
On backtracking, f[best] is set to the returned value — the best alternative from that subtree.
One Backtrack = One IDA* Iteration
Each backtrack of RBFS corresponds to one full iteration of IDA*. But RBFS is more efficient because it updates f-values instead of restarting.

Examples

Example 1: Simple Tree RBFS Execution
  Tree:
         A (f=5)
       /     \
    B(7)      C(8)
    /  \      /  \
  D(9) E(10) F(9) G(11)

  Goal: F (f=9)

  RBFS trace:
  1. RBFS(A, ∞): successors B(7), C(8). best=B, alt=C.
     → RBFS(B, min(∞,8)=8)

  2. RBFS(B, 8): successors D(9), E(10). best=D(9), alt=E(10).
     f[D]=9 > limit=8 → backtrack, return (fail, 9)
     f[B] updated to 9

  3. Back at A: successors B(9), C(8). best=C(8), alt=B(9).
     → RBFS(C, min(∞,9)=9)

  4. RBFS(C, 9): successors F(9), G(11). best=F(9), alt=G(11).
     f[F]=9 ≤ 9 → expand F.
     F is goal! Return solution.

  Nodes expanded: A, B, D, C, F = 5
  IDA* would expand: A,B,D + A,B,D,E + A,C,F = 8 (3 iterations)
Example 2: RBFS on Grid with Obstacle
  5×5 grid, S=(0,0), G=(4,4). Obstacles at (2,1), (2,2), (2,3).

  . . . . G
  . . . . .
  . # # # .
  . . . . .
  S . . . .

  Heuristic: Manhattan distance

  RBFS expansion order:
  1. (0,0) f=8
  2. (1,0) f=8   ← best, alt=(0,1) f=9
  3. (2,0) f=9   ← f=9 ≤ limit=9, expand
  4. (3,0) f=10  ← f=10 > limit=9, backtrack!
     f[(2,0)] updated to f[(3,0)] = 10
  5. Back at (1,0): successors now (2,0)=10, (1,1)=8
     best=(1,1) f=8, alt=(2,0)=10
  6. (1,1) f=8, (1,2) f=8, (1,3) f=8, (1,4) f=8
  7. (2,4) f=9... → continues until G found

  Updated f-values propagate the cost of going through blocked regions.

Warning: RBFS may re-expand "forgotten" nodes many times when the heuristic is inaccurate. In graphs with many similar f-values, the algorithm can alternate between two subtrees repeatedly — each time re-exploring. This is analogous to thrashing in virtual memory systems.
