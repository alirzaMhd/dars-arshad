Heuristic Function h(n)

Artificial Intelligence — Informed Search

Definition of h(n)

The heuristic function h(n) estimates the cheapest cost from node n to the goal. It is the most common way to add domain-specific knowledge to a search algorithm.

Heuristic Function
h(n) = estimated cost of the cheapest path from node n to a goal
If n is a goal state, then h(n) = 0 by definition. The function h(n) operates on a node, but actually needs only the node's state.

Role in Informed Search

Heuristic functions provide the "informed" part of informed search. They encode domain-specific knowledge that guides the search toward promising areas of the state space. Without h(n), the search becomes uninformed (blind).

⚠ Key Constraint: h(n) = 0 if n is a goal. For non-goal nodes, h(n) should provide a meaningful estimate of remaining cost. A poor heuristic can mislead the search, making it perform worse than uninformed search.

The Romania Example: Straight-Line Distance

In the Romania pathfinding problem, the heuristic hSLD(n) is the straight-line distance from city n to Bucharest. This is computed from map coordinates, not from the actual road network.

Properties of Heuristic Functions

Admissibility

A heuristic is admissible if it never overestimates the true cost to reach the goal.

Admissibility Condition
h(n) ≤ h*(n)
where h*(n) is the true optimal cost from node n to the nearest goal. An admissible heuristic is optimistic — it thinks the problem is easier than it actually is.

Consistency (Monotonicity)

A heuristic is consistent (also called monotonic) if it satisfies the triangle inequality for every node n and its successor n' generated by action a.

Consistency (Monotonic) Condition
h(n) ≤ c(n, a, n') + h(n')
This is a form of the triangle inequality: a side of a triangle cannot be longer than the sum of the other two sides.
Triangle Inequality (Visual Intuition)
h(n) ≤ cost(n → n') + h(n')
The heuristic estimate from n cannot be more than the cost to go to a successor plus the estimate from that successor. Every consistent heuristic is admissible, but not vice versa.

Common Heuristics for the 8-Puzzle

For the 8-puzzle problem, two classic admissible heuristics are widely used:

h₁ = Number of Misplaced Tiles
h₁ = count of tiles not in their goal position
Admissible: each misplaced tile must move at least once. Example start state: [2,8,3; 1,6,4; 7,0,5] → h₁ = 5 misplaced tiles (2,8,1,6,4).
h₂ = Manhattan Distance
h₂ = Σ |xᵢ - xᵢ'| + |yᵢ - yᵢ'| for each tile i
Also called city-block distance. Sum of horizontal and vertical distances from each tile to its goal position. Admissible because each move changes Manhattan distance by at most 1.
