Genetic Algorithm

Genetic algorithms (GAs) are a variant of stochastic beam search where new states (offspring) are generated by combining two parent states rather than modifying a single state. This mimics the biological process of natural selection and reproduction.

Pseudocode

function GENETIC-ALGORITHM(population, FITNESS-FN) returns an individual repeat new-population ← empty set for i = 1 to SIZE(population) do x ← RANDOM-SELECTION(population, FITNESS-FN) y ← RANDOM-SELECTION(population, FITNESS-FN) child ← REPRODUCE(x, y) if (small random probability) then child ← MUTATE(child) add child to new-population population ← new-population until some individual is fit enough or time elapsed return best individual function REPRODUCE(x, y) returns an individual n ← LENGTH(x) c ← random number from 1 to n return APPEND(SUBSTRING(x, 1, c), SUBSTRING(y, c+1, n))

Key Components

Population
A set of k individuals (states). Each individual is a candidate solution represented as a string (often binary). Initialized randomly.
Fitness Function
Evaluates how good each individual is. Higher fitness = higher probability of being selected for reproduction.
Selection
Roulette wheel selection: individuals are chosen randomly with probability proportional to their fitness.
Crossover
Two parents are combined at a random split point to produce a child that inherits features from both.
Mutation
A small random change to the child's representation (e.g., flip a bit, change a digit). Introduces new genetic material.

Fitness for 8-Queens

Fitness Function
fitness = number of non-attacking queen pairs
Maximum = 28 (all 8 queens safe). Each queen pair either attacks (0 points) or does not attack (1 point).
GAs are not magic. They work well when the representation allows meaningful building blocks (schemas) that can be combined via crossover. If crossover disrupts good patterns, GAs perform no better than random search.

Theory & Analysis

Schema Theory

A schema is a pattern with fixed and wildcard positions. For 8-queens, a schema like "2 4 6 * * * * *" matches all states with queens in rows 2, 4, 6 in the first three columns.

Schema Growth
N(H, t+1) ≥ N(H, t) · (f(H) / f̄) · (1 − crossover disruption − mutation loss)
N(H, t) = number of instances of schema H at generation t. f(H) = average fitness of H. f̄ = average population fitness.

Key insight: If a schema has above-average fitness and is short (compact), its number of instances grows exponentially in the population. This is the Schema Theorem — the theoretical foundation of why GAs work.

Building Blocks

Crossover Power
Crossover combines large, meaningful building blocks from two parents. If the 8-queens problem has blocks like "first 4 columns safe" and "last 4 columns safe", combining them can quickly yield a perfect solution.
When Crossover Fails
If there are no meaningful building blocks (e.g., the fitness landscape is random), crossover disrupts rather than helps. In such cases, mutation-driven search (like stochastic beam search) is equally effective.
Schema Length
Short schemas (with few defined positions close together) are less likely to be disrupted by crossover. Long schemas are more fragile.

The success of a GA depends critically on representation choice. If the representation does not support meaningful building blocks (schemas), crossover may be destructive and the GA will perform no better than random mutation. Always test if crossover actually helps on your problem.
