Problem Setup

Recursive Best-First Search (RBFS) is a search algorithm that finds the optimal path using heuristic guidance while using only linear space.

Unlike A* which stores all frontier nodes, RBFS mimics depth-first search but can backtrack when a path exceeds its f-limit.

Key Formula

f(n) = g(n) + h(n)

g(n) = actual cost from start to n

h(n) = heuristic estimate from n to goal

f(n) = total estimated cost through n

How RBFS Works

RBFS expands the node with the lowest f-value, keeping track of the f-value of the best alternative (the f-limit).

If the best path exceeds the f-limit, RBFS backtracks and tries the alternative — all in O(b^d) space like DFS.
