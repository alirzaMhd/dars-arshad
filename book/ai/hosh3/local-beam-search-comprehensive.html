Local Beam Search

Artificial Intelligence — Informed Search

Local Beam Search Algorithm

Local beam search is a generalization of hill climbing that keeps track of k states simultaneously, rather than just one. At each step, all k states generate their successors, and the k best successors are selected as the new population.

Pseudocode

function BEAM-SEARCH(problem, k) returns a state current ← set of k random initial states loop do successors ← all successors of all states in current if successors is empty then return best state in current current ← k best states from successors (by VALUE)

Key Idea: Information Sharing

The k states share information with each other. Good states influence the search direction because their successors are more likely to be selected in the next iteration. This creates a cooperative search process.

Parallel Exploration
k states explore different regions of the state space simultaneously, providing broader coverage than single-path hill climbing.
Cooperative Selection
The k best successors are selected together, so promising regions are naturally favored across all k beams.
Resource Focus
Computational resources are concentrated on the most promising areas, unlike random restart where each trial is independent.

How It Works

  1. Start with k randomly generated states
  2. Generate all successors of all k states (up to k × b successors, where b = branching factor)
  3. Evaluate all successors and select the k best
  4. Repeat until a goal state is found or no improvement occurs

Stochastic Beam Search

Instead of deterministically selecting the k best successors, stochastic beam search selects successors randomly with probability proportional to their fitness (value). This helps maintain diversity in the population.

  • A state with high value is more likely to be selected, but lower-value states still have a chance
  • Resembles natural selection: states = organisms, successors = offspring, value = fitness
  • Better diversity maintenance compared to deterministic beam search
The main problem with local beam search is that the k states can quickly converge to the same local region, losing diversity and behaving like k runs of the same hill climbing algorithm.

Diversity Loss Problem

The Convergence Problem
If all k states are in the same local region, their successors will be similar. The k best successors will all come from the same valley, effectively wasting the parallelism. This is why stochastic beam search often outperforms deterministic beam search — the randomness helps maintain some diversity.
Diversity Measure
D = (1/k²) · Σᵢ Σⱼ distance(stateᵢ, stateⱼ)
Average pairwise distance between states in the beam. If D → 0, the beam has lost diversity.
To mitigate diversity loss: (1) use stochastic selection, (2) add random perturbations to states, (3) encourage state diversity in the selection criteria, or (4) periodically inject random states into the beam.

Example 3: Multimodal Function Optimization (k = 4)

Setup: Minimize f(x) = x·sin(3πx) on the interval [0, 2]. This function has multiple local minima.

Analysis:

  • HC finds a local minimum (−0.68 at x ≈ 0.23) but misses the global minimum (−0.95 at x ≈ 1.71)
  • Beam search with k=4 finds the global minimum — one of the 4 initial states was near the global region
  • Stochastic beam search with k=4 also finds it, but needs slightly more evaluations due to random exploration

Beam search with deterministic selection is prone to population collapse — all k states converge to the same local region. Always consider the stochastic variant when diversity is important for your problem.
