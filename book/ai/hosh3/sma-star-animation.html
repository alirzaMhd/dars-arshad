Problem Setup

Find the shortest path from S to G using SMA* with a memory limit of 3 nodes.

SMA* extends A* by pruning the shallowest highest f-cost leaf when memory is full.

Key Formula

f(s) = MAX(f(n), g(s) + h(s))

Where n is the parent, g(s) is actual cost, h(s) is heuristic estimate.

Pruning Rule

When |Queue| > MEMORY_LIMIT:
delete shallowest highest-f-cost leaf
remove from parent's successor list
re-add parent if needed
