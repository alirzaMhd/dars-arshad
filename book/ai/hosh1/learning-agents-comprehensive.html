Learning Agents

Artificial Intelligence — Chapter 1: AI and Intelligent Agents

What Is a Learning Agent?

A learning agent is an intelligent agent that improves its behavior over time based on experience. Unlike a fixed agent, it can adapt to new situations, correct mistakes, and discover better strategies.

Core Principle
Learning Agent = Agent + Feedback + Adaptation
Any change to any component of an agent that uses feedback to improve overall performance counts as learning.
Common Mistake: Learning is not memorization. Memorizing percepts without changing behavior is not learning. Learning requires that the agent's future performance improves.

The Four Components

Learning Element

Makes changes and improvements to the agent based on feedback from the critic. It is the component that actually does the learning.

Performance Element

The "acting" part — selects actions based on current knowledge. It uses what has been learned to perform the task.

Critic

Evaluates the agent's performance against an external performance standard. Observes the world and compares actual outcomes to expected ones.

Problem Generator

Suggests exploratory actions that may not be optimal in the short term but yield valuable experiences for long-term learning.

How They Work Together

The agent acts in the world via the Performance Element. The Critic observes the outcome against the performance standard and sends feedback. The Learning Element uses this feedback to improve the agent's knowledge. The Problem Generator suggests novel actions to explore, which are then executed by the Performance Element, and the cycle repeats.

Feedback and Adaptation

The performance standard defines what "good" behavior looks like. It provides reward or penalty signals that the critic uses to generate feedback.

Performance Standard

An external benchmark (e.g., driving safely, no passenger complaints, shortest route). Not learned — it is given.

Reward Signal

Positive feedback (e.g., passenger tips, on-time arrival). Reinforces successful behavior.

Penalty Signal

Negative feedback (e.g., complaints, accidents). Discourages and corrects poor behavior.

Important Distinction: The performance standard is external and fixed — the agent does not learn it. The critic compares the agent's actual performance to this standard. Learning happens when the agent changes its internal components to better match the standard over time.

Three Types of Learning in Agents

1. Direct Learning from Percept Sequence

The agent learns simply by observing how the environment changes over time. No action is needed — the agent watches and records patterns.

Example: Traffic Pattern Observation

A taxi agent observes that from 8:00–9:00 AM, Main Street is congested. It records this percept sequence day after day. Over time, it learns that morning rush hour causes delays on Main Street — without having to drive there.

2. Learning from Action Outcomes

The agent performs an action, observes the result, and learns the relationship between its actions and environmental changes.

Example: Brake Pressure

A taxi agent applies 30% brake pressure and observes the car decelerates at 2 m/s². Next time it applies 50% and observes 3.5 m/s² deceleration. It learns a model: more brake pressure → stronger deceleration.

3. Learning Utility Information

The agent learns what outcomes are desirable by using signals from the performance standard — such as tips, complaints, or fuel consumption.

Example: Tips vs No Tips

A taxi agent notices that when it takes the scenic route, passengers tip 80% of the time, but when it takes shortcuts through rough roads, tips drop to 10%. It learns that scenic routes have higher utility even if they take slightly longer.

Learning Taxonomy
Learning = Observation + Feedback + Model Update
All three types follow this pattern but differ in what triggers the feedback and what part of the model is updated.
Common Mistake: Confusing "learning from percepts" with "learning from action outcomes." Percept learning is passive (watching the world); action outcome learning is active (experimenting and observing results). Only the latter requires the agent to act.

Learning = Any Component Change Using Feedback

A broad definition: learning is any modification to any component of the agent (knowledge base, rules, models, utility estimates) that uses feedback from experience to improve overall performance. This includes:

Updating Rules

If action A leads to negative outcome, add rule: avoid A in similar situations.

Tuning Parameters

Adjust how much weight the agent gives to different sensory inputs.

Refining Models

Improve the agent's internal model of how the world works based on observations.

Worked Examples — Taxi Learning Agent

All examples use a self-driving taxi agent in a city environment.

Example 1: Taxi Driver Learns from Complaints

Scenario: A taxi agent makes a quick left turn (action). A passenger complains about the rough ride (feedback).

  1. Performance Element: Executes a quick left turn at an intersection.
  2. Percept: Passenger says "That was too fast! I felt unsafe."
  3. Critic: Compares actual outcome (complaint) with the performance standard (no complaints, safe ride). Detects a negative deviation.
  4. Feedback: Critic sends a penalty signal to the Learning Element.
  5. Learning Element: Formulates a new rule: "When turning left with passengers, reduce speed to below 15 km/h."
  6. Result: Next time the Performance Element selects a left turn, it uses the new rule and makes a smoother turn.
The agent's future performance improves — fewer complaints from passengers.
Example 2: Problem Generator — Testing Braking

Scenario: The taxi agent has only ever driven on dry roads. It does not know how braking behaves on wet or icy surfaces.

  1. Problem Generator: Proposes a test: "Apply brakes at 40% pressure on a wet road surface during a controlled low-speed run." This action is suboptimal (wastes time) but fills a knowledge gap.
  2. Performance Element: Executes the proposed test at the next safe opportunity.
  3. Critic: Observes that the car took 18 meters to stop instead of the usual 10 meters on dry road.
  4. Learning Element: Updates the internal braking model: wet_road_stopping_distance[40%] = 18m.
  5. Long-term benefit: Now the agent can safely adjust braking on wet roads, preventing accidents.
The Problem Generator sacrificed short-term efficiency for long-term knowledge gain.
Example 3: Learning from Percept Sequence — Traffic Patterns

Scenario: The taxi agent needs to learn the best routes at different times of day.

Day 1-5: Agent records travel times on each street during each hour. No action — just passive observation.
Day 6: Agent notices that Oak Street averages 12 min at 5 PM but only 4 min at 10 AM.
Day 10: Pattern confirmed: Oak Street is congested 4-7 PM weekdays.
Day 11: Agent updates route selection: avoid Oak Street between 4-7 PM.
Learned purely from percept sequences — no experimentation needed.
Example 4: Learning from Action Outcomes — Brake Pressure Dynamics

Scenario: The taxi agent wants to understand exactly how brake pressure affects deceleration.

Exam Tip: Be able to identify which type of learning is happening in a given scenario. Ask: "Is the agent passively observing? Experimenting actively? Or receiving reward/penalty signals?" Each maps to a different learning type.

Learning Agent Architecture Diagram

The diagram below shows how the four components of a learning agent interact with each other and with the environment.

Understanding the Flow

1. Percepts

The environment sends sensory data to the Critic and the Performance Element.

2. Evaluation

The Critic compares actual outcomes to the Performance Standard. Generates feedback.

3. Learning

The Learning Element uses feedback to update the agent's knowledge or rules.

4. Action

The Performance Element selects actions using updated knowledge. The Problem Generator may suggest exploratory actions.

5. Cycle

The loop repeats. Over time, the agent's performance converges toward the standard.
