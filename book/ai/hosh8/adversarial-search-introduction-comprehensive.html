Multi-Agent Environments

In Chapter 1, we introduced multi-agent environments where each agent must consider the actions of other agents and how they affect the situation.

Key Insight: The unpredictability of other agents creates uncertainty in decision-making for the agent.
Agent Interaction:
Agent A ↔ Agent B ↔ Agent C ↔ ...
Each agent must consider the actions and effects of all other agents in the environment.
Example 1: Robot Soccer

Consider a team of robots playing soccer. Each robot must:

  • Track positions of all teammates
  • Predict movements of opponents
  • Coordinate plays with team members
  • React to opponent strategies in real-time

Example 2: Autonomous Vehicles

Self-driving cars must constantly:

  • Monitor behavior of nearby vehicles
  • Predict pedestrian movements
  • Respond to changing traffic conditions
  • Coordinate with traffic systems

Single-Agent

• Deterministic environment

• Predictable outcomes

• Simple planning

Multi-Agent

• Interactive environment

• Unpredictable outcomes

• Strategic planning required

Competitive vs Cooperative Environments

Feature Competitive Cooperative
Goals Conflicting Shared/Aligned
Outcome Win-Lose (Zero-sum) Win-Win or Lose-Lose
Example Chess, Checkers Robot team, Multi-robot exploration
Search Type Adversarial Search Cooperative Search
Zero-Sum Game Property:
Utility(A) + Utility(B) = 0
One player's gain is exactly the other player's loss.
Example 3: Chess

Chess is a classic zero-sum game:

  • If White wins: White gets +1, Black gets -1
  • If Black wins: Black gets +1, White gets -1
  • If Draw: Both get 0

Every possible outcome benefits one player at the expense of the other.

Key Distinction: Competitive environments lead to adversarial search problems, often called "games" in AI literature.

Game Theory Fundamentals

Mathematical game theory is a branch of economics that models multi-agent environments where each agent's impact on others is significant.

Game Theory Perspective:
Game = (Agents, Actions, Utilities)
Every multi-agent environment can be viewed as a game, regardless of whether agents cooperate or compete.
Example 4: Prisoner's Dilemma

Two prisoners must decide independently whether to confess or remain silent:

  • Both confess: 3 years each
  • Both silent: 1 year each
  • One confesses, one silent: Confessor goes free, silent gets 5 years

This demonstrates how individual rational decisions can lead to suboptimal outcomes.

Example 5: Rock-Paper-Scissors

A simple two-player zero-sum game:

  • Rock beats Scissors: +1 for rock player
  • Scissors beats Paper: +1 for scissors player
  • Paper beats Rock: +1 for paper player
  • Same choice: 0 (draw)

No pure strategy is optimal; mixed strategies are required.

Historical Note

• 1950: First chess program written

• Almost immediately after computers became programmable

• One of the earliest AI applications

Why Games are Interesting

• Complex but well-defined

• Require decision-making under uncertainty

• Often computationally intractable

• Mirror real-world strategic situations

Comprehensive Examples

Example 6: Tic-Tac-Toe as Adversarial Search

Tic-Tac-Toe demonstrates adversarial search concepts:

  • Players: X (maximizer) and O (minimizer)
  • Initial State: Empty 3×3 board
  • Successor Function: All legal moves (place mark in empty cell)
  • Terminal Test: Win, lose, or draw
  • Utility Function: +1 for X win, -1 for O win, 0 for draw

This simple game perfectly illustrates the adversarial search framework.

Example 7: Backgammon Complexity

Backgammon shows the complexity of real games:

  • States: ~10²⁰ possible positions
  • Legal Moves: ~40 per position on average
  • Utility Range: -192 to +192 points
  • Challenge: Cannot explore entire game tree

This demonstrates why heuristic evaluation functions are necessary.

Game Complexity Comparison:
Tic-Tac-Toe << Chess << Go << Backgammon
Increasing complexity in state space, branching factor, and game length.
Key Insight: Unlike simple search problems, games require real-time decision-making even when finding optimal solutions is computationally impossible.

Board Games
