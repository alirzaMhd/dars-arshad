Artificial Intelligence — First-Order Logic Foundation

Overview: Complex Sentences in FOL

In First-Order Logic (FOL), complex sentences are constructed by combining atomic sentences using logical connectives. These connectives have the same semantics as in propositional logic, but they operate over predicates and quantified variables rather than simple propositions.

Key distinction: In propositional logic, connectives operate on propositions (P, Q). In FOL, connectives operate on sentences built from predicates, functions, and quantifiers.
Structure of Complex Sentences:
S → S ∧ S | S ∨ S | ¬S | S → S | S ↔ S | ∀x S | ∃x S
A sentence can be built from atomic sentences using these five binary connectives and two quantifiers.

Connective Equivalences

De Morgan's Laws

¬(P ∧ Q) ≡ ¬P ∨ ¬Q

¬(P ∨ Q) ≡ ¬P ∧ ¬Q

Implication Elimination

P → Q ≡ ¬P ∨ Q

Useful for converting to CNF

Biconditional Elimination

P ↔ Q ≡ (P → Q) ∧ (Q → P)

Contrapositive

P → Q ≡ ¬Q → ¬P

Worked Examples: Building Complex Sentences

Example 1: Negation with Predicates
Atomic sentence:
King(Richard)
"Richard is a king"
Complex sentence:
¬King(Richard)
"Richard is not a king"

Evaluation: If Richard is indeed a king, then King(Richard) = T, so ¬King(Richard) = F.

Example 2: Disjunction of Complex Terms
Atomic sentences:
Brother(LeftLeg(Richard), John)
"The left leg of Richard is a brother of John" (complex term as argument)
Complex sentence:
Brother(LeftLeg(Richard), John) ∨ Brother(John, Richard)
"Either the left leg of Richard is a brother of John, or John is a brother of Richard"
Notice how LeftLeg(Richard) is a complex term (function applied to a constant). Functions in FOL map objects to objects — they are not predicates.
Example 3: Simple Disjunction
Complex sentence:
King(Richard) ∨ King(John)
"Either Richard is a king, or John is a king (or both)"

Evaluation scenarios:

Scenario A:

King(Richard) = T, King(John) = T

Result: T ∨ T = T

Scenario B:

King(Richard) = T, King(John) = F

Result: T ∨ F = T

Scenario C:

King(Richard) = F, King(John) = T

Result: F ∨ T = T

Scenario D:

King(Richard) = F, King(John) = F

Result: F ∨ F = F

Example 4: Implication Between Predicates
Complex sentence:
King(Richard) → King(John)
"If Richard is a king, then John is a king"

Counterintuitive truth: If Richard is NOT a king, this implication is true regardless of whether John is a king. This is called vacuous truth.

Common misconception: "If P then Q" does NOT mean "P causes Q". It only specifies a logical relationship between truth values.

Example 5: Multi-Connective Sentence
Building step by step:
(King(Richard) ∧ ¬King(John)) → Brother(LeftLeg(Richard), John)
"If Richard is a king and John is not a king, then the left leg of Richard is a brother of John"

Parsing (highest precedence first):

Step 1: ¬King(John) [Negation] Step 2: King(Richard) ∧ ¬King(John) [Conjunction] Step 3: LeftLeg(Richard) [Function application] Step 4: Brother(LeftLeg(Richard), John) [Atomic sentence] Step 5: (Step 2) → (Step 4) [Implication — lowest precedence]
Without parentheses, the sentence would be parsed as King(Richard) ∧ (¬King(John) → Brother(LeftLeg(Richard), John)) due to precedence rules.
Example 6: Biconditional with Quantifiers
Complex sentence:
∀x (Smart(x) ↔ ¬Lazy(x))
"For all x, x is smart if and only if x is not lazy"

Expanding for specific individuals:

(Smart(Alice) ↔ ¬Lazy(Alice)) ∧ (Smart(Bob) ↔ ¬Lazy(Bob)) ∧ (Smart(Charlie) ↔ ¬Lazy(Charlie)) ∧ ...
The biconditional establishes a two-way equivalence: being smart is equivalent to not being lazy in this domain.

FOL vs Propositional Logic

Propositional Logic

• Connectives operate on propositions

• No variables or predicates

• P, Q, R are atomic

Example: P ∧ Q

First-Order Logic

• Connectives operate on predicate sentences

• Uses variables, constants, functions

• P(x), Q(a,b) are atomic

Example: Smart(x) ∧ ¬Lazy(x)

The connectives themselves have identical truth tables in both logics — only the atomic building blocks differ.

Quick Decision Guide

When building a sentence: - "not" → ¬ - "and" → ∧ - "or" → ∨ - "if...then" → → - "iff" / "if and only if" → ↔ When evaluating: 1. Start with innermost parentheses 2. Apply negations first 3. Then conjunctions, then disjunctions 4. Then implications, then biconditionals 5. Work outward until done
