Atomic Sentences in First-Order Logic

Building blocks of logical expressions in FOL

1. Structure of Atomic Sentences

In first-order logic, atomic sentences are the simplest propositions that can be true or false. They are built by applying a predicate to one or more terms.

General Form:
Predicate(Term₁, Term₂, ..., Termₙ)
A predicate symbol applied to n terms produces an atomic sentence.

Components

Predicate Symbol
Represents a relation or property
e.g., Brother, Married, Greater
Terms
Objects the predicate applies to
Constants: Richard, John
Variables: x, y
Functions: Father(Richard)
Arity
Number of terms
Unary: Likes(x)
Binary: Brother(Richard, John)
n-ary: Predicate(t₁,...,tₙ)

2. Types of Terms

Terms refer to objects in the domain of discourse:

Constant Symbols (ground terms)
Richard, John, Mary, CS3201
Denote specific, fixed objects in the domain.
Variables
x, y, z, student
Stand for arbitrary objects; their meaning depends on assignment.
Function Symbols (complex terms)
Father(Richard), Mother(John), Plus(x, y)
Functions map terms to terms. Father(Richard) refers to Richard's father.
Functions do NOT produce sentences — they produce terms. Only predicates applied to terms produce atomic sentences.

3. Equality as an Atomic Sentence

The equality symbol = is a special binary predicate built into FOL:

Equality Form:
Term₁ = Term₂
True when Term₁ and Term₂ refer to the same object.
Equality Examples
Mother(John) = Mary // John's mother is Mary
Father(Richard) = Father(John) // Richard and John share a father
x = y // x and y are the same object
Equality is interpreted universally — it must hold for every possible interpretation that satisfies the domain constraints. It is not a user-defined predicate.

4. Truth Conditions

An atomic sentence is true under an interpretation if the relation denoted by the predicate holds between the objects denoted by the terms.

Interpretation I makes Predicate(t₁,...,tₙ) true iff:
⟨I(t₁), I(t₂), ..., I(tₙ)⟩ ∈ I(Predicate)
The tuple of denoted objects must be in the relation's extension.
Truth depends on the interpretation. Brother(Richard, John) is true only if Richard and John are indeed brothers in the current model.

1. Building Complex Sentences from Atomic Ones

Atomic sentences can be combined using logical connectives to form complex sentences. The connectives work the same way as in propositional logic.

Connective Symbol Meaning Example in FOL
Negation ¬ not ¬Brother(Richard, John)
Conjunction ∧ and Brother(Richard, John) ∧ Male(Richard)
Disjunction ∨ or Brother(Richard, John) ∨ Brother(John, Richard)
Implication → if...then Brother(Richard, John) → Male(Richard)
Biconditional ↔ if and only if Brother(Richard, John) ↔ Brother(John, Richard)

2. Precedence of Connectives

When multiple connectives appear, apply in this order (tightest binding first):

¬ > ∧ > ∨ > → > ↔
Negation binds tightest; biconditional binds loosest.
Parentheses Clarify Meaning
¬Brother(Richard, John) ∧ Male(Richard)
is parsed as: (¬Brother(Richard, John)) ∧ Male(Richard)

Use parentheses to avoid ambiguity:
(Brother(Richard, John) ∨ Brother(John, Richard)) → Male(Richard)

3. Semantics of Connectives

The truth tables for connectives in FOL are identical to those in propositional logic:

¬P
True when P is false
P ∧ Q
True only when both P and Q are true
P ∨ Q
True when at least one of P, Q is true
P → Q
False only when P is true and Q is false
P ↔ Q
True when P and Q have the same truth value
The key difference from propositional logic: in FOL, P and Q can be complex sentences involving predicates, quantifiers, and variables — not just propositional variables.

4. Nesting Complex Sentences

Complex sentences can be arbitrarily nested:

(Brother(Richard, John) ∧ Male(Richard)) → (¬Brother(John, Richard) ∨ Father(Richard, John))
If Richard is John's brother and Richard is male, then either John is not Richard's brother or Richard is John's father.
Always use parentheses to make the scope of connectives unambiguous, especially when mixing multiple connectives.

Worked Examples with Truth Evaluation

Given a model M with domain: {Richard, John, Mary}, evaluate each sentence.

Model M
Brother = {⟨Richard, John⟩, ⟨John, Richard⟩}
Male = {Richard, John}
Female = {Mary}
Mother = {⟨John, Mary⟩, ⟨Richard, Mary⟩}
Father = {⟨John, Richard⟩, ⟨Richard, Richard⟩}
The relation Brother contains ordered pairs; Mother maps a person to their mother.
Example 1:
Brother(Richard, John)
Check: Is ⟨Richard, John⟩ in the Brother relation? TRUE ✓
Example 2:
Mother(John) = Mary
Evaluate: Mother(John) = Mary. Is Mary = Mary? TRUE ✓
Example 3:
¬Brother(Richard, Mary)
Check: Is ⟨Richard, Mary⟩ in Brother? No. So ¬FALSE = TRUE ✓
Example 4:
Brother(Richard, John) ∧ Male(Richard)
Brother(Richard, John) = TRUE, Male(Richard) = TRUE. TRUE ∧ TRUE = TRUE ✓
Example 5:
Father(Richard, John) → Brother(Richard, John)
Father(Richard, John): Is ⟨Richard, John⟩ in Father? No → FALSE. FALSE → anything = TRUE ✓ (vacuously true)
A false antecedent makes the implication true regardless of the consequent. This is the principle of vacuous truth.

Additional Practice Examples

Example 6:
Mother(John) = Father(Richard)
Mother(John) = Mary. Father(Richard) = Richard. Mary = Richard? FALSE ✗
Example 7:
Brother(Richard, John) ∨ Brother(John, Richard)
TRUE ∨ TRUE = TRUE ✓
Example 8:
Male(Mary) ↔ Female(Mary)
Male(Mary) = FALSE. Female(Mary) = TRUE. FALSE ↔ TRUE = FALSE ✗
When evaluating, always work from the inside out: evaluate functions and predicates first, then apply connectives.

Summary of Key Concepts

Atomic Sentence
Predicate(Term₁, ..., Termₙ)
The smallest unit of meaning in FOL. Cannot be decomposed further without losing propositional content.
Predicates
Represent relations or properties
Unary (property): Male(x)
Binary (relation): Brother(x, y)
n-ary: R(x₁, ..., xₙ)
Terms
Objects and their compositions
Constants, variables, and function applications. Functions produce terms, not sentences.
Equality =
Built-in binary predicate
Term₁ = Term₂ is true when both terms refer to the same object.

Common Mistakes to Avoid

Mistake 1: Confusing functions with predicates. Father(Richard) is a term (refers to an object). Brother(Richard, John) is a sentence (has truth value).
Mistake 2: Forgetting that functions can nest inside predicates. Married(Father(Richard), Mother(John)) is valid — functions produce terms that become predicate arguments.
Mistake 3: Treating atomic sentences as having fixed truth values. Their truth depends entirely on the interpretation (model) being used.
Mistake 4: Omitting parentheses in complex sentences. Without them, the scope of connectives is ambiguous.

From Propositional to First-Order Logic

Feature Propositional Logic First-Order Logic
Atomic units Propositions (P, Q, R) Predicate(Term₁,...,Termₙ)
Internal structure None (black boxes) Predicates + Terms + Functions
Connectives ¬, ∧, ∨, →, ↔ Same connectives, same semantics
Variables Not available Available for generalization
Quantifiers Not available ∀ (for all), ∃ (exists)
Atomic sentences in FOL extend propositional logic by exposing the internal structure of propositions through predicates and terms.

Quick Reference
