1. Using Multiple Quantifiers Together

Nested quantifiers express relationships between multiple variables. The type and order of quantifiers fundamentally changes the meaning of a sentence.

Universal + Universal (Same Type — Can Combine)
∀x∀y Brother(x,y) → Sibling(x,y)
"For all x and for all y, if x is a brother of y, then x and y are siblings."
Shorthand Notation for Same-Type Quantifiers
∀x,y Sibling(x,y) → Sibling(y,x)
"For all x and y, if x is a sibling of y, then y is a sibling of x." When quantifiers are the same type, they can be written in shorthand with a comma.
Universal + Existential — "Everyone loves someone"
∀x∃y loves(x,y)
"Everyone loves someone." Each person may love a different person. For every x, there exists some y such that x loves y.
Existential + Universal — "There is someone loved by everyone"
∃y∀x loves(x,y)
"There is someone who is loved by everyone." There exists one particular person y that everyone loves. This is much stronger than ∀x∃y loves(x,y).
⚠ The order of different quantifiers MATTERS. ∀x∃y loves(x,y) ≠ ∃y∀x loves(x,y). The first says "everyone loves someone (possibly different)" — the second says "there is a single person loved by all."

2. Variable Scoping

A variable belongs to the innermost quantifier that mentions it. The scope of a quantifier extends over the expression it governs.

Variable Scope Example
∀x [Loves(x, Mary) ∨ ∀y [Loves(John, y) → Jealous(x, y)]]
The variable x is bound by ∀x (outermost). The variable y in the inner ∀y is bound by the inner quantifier. Outer ∀x does not capture y — each quantifier only binds variables in its own scope.
⚠ A quantifier only binds variables that appear within its scope. If a variable appears both inside and outside a quantifier's scope, they are different variables — like local variables in programming.

Quantifier Duality via Negation

The universal and existential quantifiers are related through negation, analogous to De Morgan's laws in propositional logic.

Equivalence 1
∀x ¬P ≡ ¬∃x P
"Everything is not P" is the same as "It is not the case that something is P." Both mean no object satisfies P.
Equivalence 2
¬∀x P ≡ ∃x ¬P
"Not everything is P" is the same as "Something is not P." At least one object fails to satisfy P.
Equivalence 3
∀x P ≡ ¬∃x ¬P
"Everything is P" is the same as "It is not the case that something is not P." No object fails to satisfy P.
Equivalence 4
∃x P ≡ ¬∀x ¬P
"Something is P" is the same as "It is not the case that everything is not P." At least one object satisfies P.
These four equivalences follow from De Morgan's laws. To negate a quantified expression, flip the quantifier and negate the inner formula. This applies recursively for nested quantifiers.

Unique Existential Quantifier (∃!)

The unique existential quantifier asserts that exactly one object satisfies a predicate.

Definition of ∃!
∃!x King(x) ≡ ∃x King(x) ∧ ∀y King(y) → (x = y)
"There exists exactly one king" means there is some x who is a king, and for any y, if y is also a king then y must be x (i.e., they are the same person).
Alternative Formulation
∃!x P(x) ≡ ∃x [ P(x) ∧ ∀y (P(y) → y = x) ]
"There exists exactly one x such that P(x)" — there exists an x that satisfies P, and anything else that satisfies P must be identical to x.

Worked Examples

Example 1: "Every student took a course in AI"
English
∀x [Student(x) → ∃y [Course(y) ∧ Took(x,y)]]
Each student has at least one AI course they took. Different students may have taken different courses.
Example 2: "There is a course that every student took"
English
∃y [Course(y) ∧ ∀x [Student(x) → Took(x,y)]]
One specific course was taken by every student. Order matters — this is different from Example 1.
Example 3: "Nobody loves nobody"
Translation (double negation)
¬∃x∃y ¬Loves(x,y) ≡ ∀x∀y Loves(x,y)
Using duality: the negation of "there exists someone nobody loves" becomes "everyone loves everyone." Double negation in English can be tricky.
Example 4: "Every number has a successor"
First-Order Logic
∀x∃y [Number(x) → (Number(y) ∧ Successor(y,x))]
For every number x, there exists a number y that is the successor of x. The existential quantifier is inside the universal — each x gets its own y.
Example 5: Negating a Nested Statement
Original
∀x∃y Loves(x,y)
Original: "Everyone loves someone."
Negation (flip quantifiers, negate predicate)
∃x∀y ¬Loves(x,y)
Negation: "There exists someone who loves nobody." Applied duality twice: flip ∀ to ∃, then flip ∃ to ∃, and negate loves.

Common Mistakes

⚠ MISTAKE 1: Assuming ∀x∃y P ≡ ∃y∀x P
"Everyone loves someone" ≠ "Someone is loved by everyone." The order of different quantifiers changes meaning. Same-type quantifiers (both ∀ or both ∃) can be swapped freely.
⚠ MISTAKE 2: Forgetting to flip quantifiers when negating
¬(∀x P) is NOT ∀x ¬P. The correct negation is ∃x ¬P. Always flip the outermost quantifier first.
⚠ MISTAKE 3: Confusing implication with conjunction in universal statements
∀x [P(x) → Q(x)] is correct for "every P is Q." Using ∧ instead of → makes the sentence vacuously false or changes meaning: ∀x [P(x) ∧ Q(x)] means "everything is both P and Q."
⚠ MISTAKE 4: Using implication with existential statements
∃x [P(x) → Q(x)] is almost always trivially true (pick x where P(x) is false). Use conjunction: ∃x [P(x) ∧ Q(x)] means "there exists something that is both P and Q."
⚠ MISTAKE 5: Misreading "nobody loves nobody"
In English, double negatives are confusing. "Nobody loves nobody" logically means ∀x∀y Loves(x,y) — everyone loves everyone — NOT "nobody loves anybody."
