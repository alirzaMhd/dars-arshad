QUANTIFIERS IN FIRST-ORDER LOGIC

Universal (∀) · Existential (∃) · Nested Quantifiers · Common Pitfalls

Universal Quantifier (∀) — "For All"

The universal quantifier asserts that a property holds for every object in the domain of discourse.

SYNTAX
∀x P(x)
Read as: "For all x, P(x) is true" or "For every x, P(x) holds"

How It Works

A universally quantified sentence ∀x P(x) is true if and only if P(a) is true for every single object a in the domain. If even one object makes P false, the whole sentence is false.

EQUIVALENCE TO CONJUNCTION
∀x P(x) ≡ P(a₁) ∧ P(a₂) ∧ P(a₃) ∧ ... ∧ P(aₙ)
For a finite domain {a₁, a₂, ..., aₙ}, the universal quantifier is equivalent to the conjunction over all elements.
EXAMPLE 1: All kings are persons
∀x King(x) → Person(x)

Domain: {John, Richard, France}

EQUIVALENT CONJUNCTION
King(John) → Person(John) ∧ King(Richard) → Person(Richard) ∧ King(France) → Person(France)

Since France is not a king, King(France) is false, making the implication true. Since John and Richard are kings and persons, both implications are true. The whole conjunction is true.

EXAMPLE 2: Everyone likes pizza
∀x Likes(x, Pizza)

Domain: {Alice, Bob, Carol}

This is true only if Alice likes pizza AND Bob likes pizza AND Carol likes pizza. If any one person dislikes pizza, the sentence is false.

Key Insight: Scope of ∀

Wrong Reading

∀x (King(x) → Person(x))

"For all x: if x is a king, then x is a person" — This is the correct way to say "All kings are persons."

Often Intended

∀x King(x) → Person(x)

Without parentheses, this can be ambiguous. Always use parentheses to make scope clear!

The universal quantifier is the strongest quantifier — it makes the most demanding claim about the world.

Existential Quantifier (∃) — "There Exists"

The existential quantifier asserts that a property holds for at least one object in the domain of discourse.

SYNTAX
∃x P(x)
Read as: "There exists an x such that P(x) is true" or "Some x has property P"

How It Works

An existentially quantified sentence ∃x P(x) is true if and only if P(a) is true for at least one object a in the domain. It doesn't matter how many objects satisfy P — even one is enough.

EQUIVALENCE TO DISJUNCTION
∃x P(x) ≡ P(a₁) ∨ P(a₂) ∨ P(a₃) ∨ ... ∨ P(aₙ)
For a finite domain {a₁, a₂, ..., aₙ}, the existential quantifier is equivalent to the disjunction over all elements.
EXAMPLE 1: There is a crown on John's head
∃x Crown(x) ∧ OnHead(x, John)

Domain: {Crown1, Crown2, Hat, Chair}

EQUIVALENT DISJUNCTION
(Crown(Crown1) ∧ OnHead(Crown1, John)) ∨ (Crown(Crown2) ∧ OnHead(Crown2, John)) ∨ ...

If Crown1 is a crown and is on John's head, the whole sentence is true, regardless of the other objects.

EXAMPLE 2: Someone loves everyone
∃x ∀y Loves(x, y)

This claims there is one person who loves every person in the domain — a very strong claim!

EXAMPLE 3: There exists a prime number greater than 100
∃x (PrimeNumber(x) ∧ GreaterThan(x, 100))

This is true because, for example, 101 is prime and greater than 100. Finding one witness is sufficient.

Unique Existential (∃!) — "Exactly One Exists"

DEFINITION
∃!x P(x) ≡ ∃x P(x) ∧ ∀y (P(y) → y = x)
"There exists exactly one x such that P(x) is true" — there is at least one, and any two satisfying x must be equal.
The existential quantifier is the weakest quantifier — it makes the least demanding claim. It only requires one witness.

Common Pitfalls with Quantifiers

Pitfall 1: Using ∧ instead of → with ∀

MISTAKE: ∀x King(x) ∧ Person(x) says "Everything is a king AND everything is a person" — an extremely strong (and usually false) claim!
Formula Meaning Strength Typically True?
∀x King(x) → Person(x) All kings are persons Reasonable Often yes
∀x King(x) ∧ Person(x) Everything is a king and a person Extremely strong Almost never
WHY THE DISTINCTION MATTERS
Domain: {John, France, Richard}
∀x King(x) → Person(x) = T ∧ T ∧ T = TRUE
∀x King(x) ∧ Person(x) = F ∧ F ∧ F = FALSE

France is not a king, so King(France) is false. In the → version, the implication is vacuously true. In the ∧ version, the conjunction is false.

Pitfall 2: Using ∨ instead of ∧ with ∃

MISTAKE: ∃x Crown(x) ∨ OnHead(x, John) says "There exists something that is a crown OR is on John's head" — this is trivially true if anything in the domain is a crown OR anything is on John's head!
Formula Meaning Strength Useful?
∃x Crown(x) ∧ OnHead(x, John) There is a crown on John's head Specific claim Yes
∃x Crown(x) ∨ OnHead(x, John) There is something that is a crown or is on John's head Trivially weak Almost never useful
WHY THE DISTINCTION MATTERS
Domain: {Crown1, Chair, Hat}
∃x Crown(x) ∧ OnHead(x, John) = F ∨ F ∨ F = FALSE
∃x Crown(x) ∨ OnHead(x, John) = T ∨ F ∨ F = TRUE

Crown1 is a crown but not on John's head. The ∧ version correctly says FALSE (no crown on his head). The ∨ version trivially says TRUE (there exists a crown somewhere).

Summary Rule of Thumb

∀ goes with →

∀x (Dog(x) → Mammal(x))

"All dogs are mammals" — the implication restricts to dogs first.

∃ goes with ∧

∃x (Dog(x) ∧ Mammal(x))

"Some dog is a mammal" — the conjunction identifies a witness.

Pitfall 3: Scope Ambiguity

MISTAKE: Not using parentheses to clearly indicate scope leads to ambiguous or incorrect readings.
AMBIGUOUS
∀x King(x) → Person(x)
Does the ∀ apply to just King(x), or to the whole implication? Always write: ∀x (King(x) → Person(x))

Nested Quantifiers — Order Matters!

When multiple quantifiers appear together, their order completely changes the meaning. This is one of the most important concepts in first-order logic.

KEY FORMULA
∀x ∃y Loves(x, y) ≠ ∃y ∀x Loves(x, y)
The order of quantifiers produces different logical statements with different truth values.

Case 1: ∀x∃y — Everyone loves someone

∀x ∃y Loves(x, y)

"For every person x, there exists some person y (possibly depending on x) such that x loves y."

Domain: {Alice, Bob, Carol}
Alice loves Bob ✓
Bob loves Carol ✓
Carol loves Alice ✓
Result: TRUE

Each person can love a different person. Alice loves Bob, Bob loves Carol, Carol loves Alice.

Case 2: ∃y∀x — There is someone everyone loves

∃y ∀x Loves(x, y)

"There exists some person y such that every person x loves y." (The same y must work for all x.)

Domain: {Alice, Bob, Carol}
Is there one person loved by all?
Alice loves Carol ✓
Bob loves Carol ✓
Carol loves Carol ✓
Result: TRUE (Carol is loved by everyone)

But if Carol doesn't love Carol, the sentence would be FALSE — there is no single person loved by all.

Side-by-Side Comparison

Formula Meaning Who picks? Example Truth Value
∀x∃y Loves(x,y) Everyone loves someone Each x picks its own y Often true
∃y∀x Loves(x,y) Someone is loved by everyone One y works for all x Often false

More Nested Quantifier Examples

∀x∀y Likes(x,y)

Everyone likes everyone. (Very strong.)

∃x∃y Likes(x,y)

There are two people who like each other. (Weak.)

∀x∃y Likes(x,y)

Everyone has someone they like. (Moderate.)

∃x∀y Likes(x,y)

There is someone who likes everyone. (Strong.)

RULE: Alternating ∀ and ∃ creates progressively stronger/weaker statements. A universally quantified variable that appears later can depend on earlier existentially quantified variables, but not vice versa.

Worked Examples

EXAMPLE 1: Translating English to FOL
English: "Every student who takes AI passes it."
FORMALIZATION
∀x (Student(x) ∧ Takes(x, AI) → Passes(x, AI))
For all x: if x is a student and x takes AI, then x passes AI.

Why → and not ∧? We want to say something only about students who take AI. The implication restricts the domain of interest. Using ∧ would say everything is a student who takes AI and passes AI.

EXAMPLE 2: Translating English to FOL
English: "There is a student who passed every course."
FORMALIZATION
∃x (Student(x) ∧ ∀y (Course(y) → Passes(x, y)))
There exists an x who is a student and for every y, if y is a course, then x passed y.

Note: The ∃x comes first — we are claiming a specific student exists. The ∀y is inside the scope of ∃x, so the same student must have passed all courses.

EXAMPLE 3: Nested Quantifiers — Different Meanings
Domain: Students and Courses
∀c∃s Took(s, c)

"For every course, there is some student who took it." — Every course has at least one student.

∃s∀c Took(s, c)

"There is a student who took every course." — One ambitious student took all courses.

These have very different truth values. The first might be true even if no single student took all courses. The second requires one student who did everything.

EXAMPLE 4: De Morgan's Laws for Quantifiers
Relationship between ∀ and ∃ via negation
LAW 1
∀x P(x) ≡ ¬∃x ¬P(x)
"Everyone is tall" is the same as "It's not the case that someone is not tall."
LAW 2
∃x P(x) ≡ ¬∀x ¬P(x)
"Someone is tall" is the same as "It's not the case that no one is tall."

These dualities allow you to express any quantified sentence using only one type of quantifier and negation.

EXAMPLE 5: Identifying True/False
Domain: {1, 2, 3, 4, 5}
P(x) means "x is prime"
L(x, y) means "x ≤ y"
FormulaTranslationValue
∀x P(x) All numbers are prime FALSE
∃x P(x) Some number is prime TRUE
∀x∃y L(x,y) For every number, there is a bigger or equal number TRUE
∃y∀x L(x,y) There is a number bigger than or equal to all numbers TRUE
∀x∃y L(x,y) ∧ ¬L(y,x) Every number has a strictly larger number FALSE

The last one is false because 5 is the largest element — there is no y strictly greater than 5.
