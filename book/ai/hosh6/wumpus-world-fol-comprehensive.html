WUMPUS WORLD IN FIRST-ORDER LOGIC

Comprehensive Guide to FOL Representation of the Wumpus World Environment

1. Percept Sequences with Time

The Wumpus agent perceives its environment at each time step through a 5-component percept vector. Time is explicitly indexed using a numeric parameter.

Percept Vector with Time Index
Percept([Stench, Breeze, Glitter, Bump, Scream], t)
Where:
- Stench: True if the wumpus is adjacent to the agent's current cell
- Breeze: True if a pit is adjacent to the agent's current cell
- Glitter: True if the agent is in the same cell as the gold
- Bump: True if the agent walked into a wall
- Scream: True if the wumpus was killed somewhere in the world
- t: Time step index (0, 1, 2, ...)
Example Percept at Time 0
Percept([Stench, Breeze, Glitter, None, None], 0)
At the start, the agent smells a stench and feels a breeze. No gold glitter, no bump, no scream yet.

2. Actions in FOL

The agent can perform exactly one action at each time step. Actions are represented as FOL terms with a time parameter.

Rotate 90° counter-clockwise
Forward
Move one square in facing direction
Shoot
Fire arrow in facing direction
Grab
Pick up gold from current cell
Release
Drop gold at current cell
Climb
Exit cave from starting cell [1,1]
BestAction Function
BestAction(a, t)
This predicate states that action a is the optimal action to take at time step t. A rational agent must select actions that maximize expected performance.

3. Perception Rules in FOL

FOL rules connect percept components to world properties. These are universally quantified axioms that the agent knows.

Breeze Perception Rule
∀t, s, g, m, c: Percept([s, Breeze, g, m, c], t) → Breeze(t)
For all time steps t and any values of stench s, glitter g, bump m, scream c: if the agent perceives a breeze at time t, then the Breeze predicate holds at time t. This connects the raw percept to an internal knowledge representation.
Glitter Perception Rule
∀t, s, b, m, c: Percept([s, b, Glitter, m, c], t) → Glitter(t)
For all time steps t and any values of stench s, breeze b, bump m, scream c: if the agent perceives glitter at time t, then the Glitter predicate holds at time t. This means gold is present in the current cell.
Stench Perception Rule
∀t, b, g, m, c: Percept([Stench, b, g, m, c], t) → Stench(t)
If the percept contains Stench at time t, then the wumpus is adjacent to the agent's current cell.
Important: These perception rules bridge the gap between raw sensory input (percept vectors) and the agent's internal knowledge base. Without them, the agent cannot reason about what it perceives.

4. Reflex Agent

A simple reflex agent acts based only on current percepts, ignoring percept history. In FOL, this is expressed as a condition-action rule.

Reflex Rule for Gold
∀t: Glitter(t) → BestAction(Grab, t)
Whenever glitter is perceived (gold is in the current cell), the best action at that time is to grab the gold. This is a direct mapping from percept to action.
Reflex Agent Limitation

A reflex agent cannot reason about consequences beyond the immediate percept. For example, it cannot plan a path to escape after grabbing gold, or decide whether to shoot the wumpus to clear a path. It only reacts to the current situation.

Limitation: Reflex agents fail in partially observable environments like Wumpus World because they cannot maintain internal state about what they have already seen or done.

5. Environment Representation

To reason about the Wumpus World, the agent must represent spatial relationships and object locations using FOL predicates and functions.

Adjacent Relation
Adjacent([x, y], [a, b]) = { [x+1, y], [x−1, y], [x, y+1], [x, y−1] }
The adjacent relation defines the set of squares that are one step away from a given square [x, y] in the 4 cardinal directions (up, down, left, right). This is the connectivity graph of the grid.
Pit Predicate
Pit(s)
A unary predicate that is true if square s contains a pit. Squares containing pits are dangerous — the agent falls in and dies if it enters them.
Wumpus Location Function
Home(Wumpus) = [x_w, y_w]
A function that returns the coordinates of the wumpus. The wumpus occupies exactly one square and does not move. The wumpus is killed if an arrow reaches its square.
Agent Position Predicate
At(Agent, s, t)
States that the agent is at square s at time step t. This tracks the agent's position over time, enabling temporal reasoning about movement.

6. Diagnostic Rules (Percept → World)

Diagnostic rules work backwards from observed effects (percepts) to infer hidden causes in the environment. This is abductive reasoning.

Breeze → Nearby Pit
∀s: Breezy(s) → ∃r (Adjacent(r, s) ∧ Pit(r))
If square s is breezy, then there exists at least one adjacent square r that contains a pit. The breeze is a necessary consequence of having a pit nearby. Note: we cannot determine WHICH adjacent square has the pit — only that at least one does.
Stench → Nearby Wumpus
∀s: Stinky(s) → ∃r (Adjacent(r, s) ∧ Home(Wumpus) = r)
If square s has a stench, then the wumpus is located at some adjacent square r.
Diagnostic Reasoning Example

Suppose the agent is at [2,1] and feels a breeze. It knows:

Adjacent([2,1]) = { [3,1], [1,1], [2,2], [2,0] }

From the diagnostic rule: ∃r ∈ {[3,1], [1,1], [2,2], [2,0]} such that Pit(r).

The agent knows a pit exists in one of these four squares, but cannot determine which one without further exploration.

Uncertainty: Diagnostic rules produce existential conclusions — they tell you SOMETHING exists but not WHAT exactly. The agent must use additional percepts from other squares to narrow down possibilities.

7. Causal Rules (World → Percept)

Causal rules work forwards from known facts about the world to predict what percepts will be observed. This is deductive reasoning.

Pit → Breezy Adjacent Squares
∀r: Pit(r) → [∀s (Adjacent(r, s) → Breezy(s))]
If a square r contains a pit, then every square s adjacent to r is breezy. This is the causal relationship: pits CAUSE breezes in neighboring squares. Every adjacent square MUST have a breeze.
Wumpus → Stench Adjacent Squares
∀r: (Home(Wumpus) = r) → [∀s (Adjacent(r, s) → Stinky(s))]
If the wumpus is at square r, then every square adjacent to r has a stench.

Worked Examples

Example 1: Initial Percept Interpretation
Percept([Stench, Breeze, None, None, None], 0)

Given: At time t=0, the agent is at [1,1] (starting square).

Reasoning:

  • Stench(0) is true → ∃r Adjacent(r, [1,1]) ∧ Home(Wumpus) = r
  • Adjacent([1,1]) = {[2,1], [1,2]} (squares within bounds)
  • Therefore: Wumpus is at [2,1] OR [1,2]
  • Breeze(0) is true → ∃r Adjacent(r, [1,1]) ∧ Pit(r)
  • Therefore: A pit is at [2,1] OR [1,2]

Conclusion: The wumpus and at least one pit are in cells adjacent to [1,1].

Example 2: Reflex Action — Grabbing Gold
Percept([None, None, Glitter, None, None], 5)

Given: At time t=5, agent is at [3,3].

Reasoning using reflex rule:

∀t: Glitter(t) → BestAction(Grab, t)

Glitter(5) is true → BestAction(Grab, 5)

Agent grabs the gold at [3,3] at time step 5.

Example 3: Diagnostic Inference — Mapping a Pit
Agent at [2,2] at t=3: Percept([None, Breeze, None, None, None], 3) Agent at [3,2] at t=4: Percept([None, None, None, None, None], 4)

At t=3: Breeze(3) true at [2,2]

→ Pit exists in one of: {[3,2], [1,2], [2,3], [2,1]}

At t=4: No breeze at [3,2]

→ ∀s Adjacent([3,2], s) → ¬Breezy(s) is NOT the right form

→ ¬Breeze(4) at [3,2] means no pit adjacent to [3,2]

→ Adjacent([3,2]) = {[4,2], [2,2], [3,3], [3,1]}

→ Pit is NOT at [4,2], [2,2], [3,3], or [3,1]

Combining: If [3,2] was a candidate from t=3 inference, it is now ruled out. The pit must be at [1,2], [2,3], or [2,1].

Example 4: Causal Prediction — Planning a Path
Known: Pit([1,3]) Agent wants to reach [1,2]

Causal reasoning:

Pit([1,3]) → ∀s Adjacent([1,3], s) → Breezy(s)

Adjacent([1,3]) = {[2,3], [1,2], [1,4]}

→ Breezy([2,3]), Breezy([1,2]), Breezy([1,4])

Agent checks adjacent cells for safe path:

If agent goes to [1,2], it will feel a breeze (expected). The breeze confirms the pit at [1,3] but [1,2] itself is safe (not a pit).

Agent can safely pass through [1,2] since it is breezy (has a pit neighbor) but is not itself a pit.

Example 5: Temporal Tracking with At Predicate
t=0: At(Agent, [1,1], 0) — Start t=1: At(Agent, [2,1], 1) — Moved right t=2: At(Agent, [2,1], 2) — Turned left t=3: At(Agent, [2,2], 3) — Moved forward (up)

Using At predicate to track position:

At(Agent, [1,1], 0) ∧ BestAction(Forward, 0) → At(Agent, [2,1], 1)

At(Agent, [2,1], 1) ∧ BestAction(Turn(Left), 1) → At(Agent, [2,1], 2)

At(Agent, [2,1], 2) ∧ BestAction(Forward, 2) → At(Agent, [2,2], 3)

Path history stored as:

{ [1,1], [2,1], [2,1], [2,2] }

The At predicate enables the agent to remember its trajectory and avoid revisiting squares.

8. Synchronic vs Diachronic Sentences

FOL sentences in Wumpus World can be classified by whether they describe relationships at a single time step or across multiple time steps.

Synchronic Sentences

Describe relationships that hold at the same time step. They relate properties of the world that coexist simultaneously.

Example: ∀s Breezy(s) → ∃r Adjacent(r,s) ∧ Pit(r)

This relates breeziness and pit locations at the same moment — no time travel involved.

Diachronic Sentences

Describe relationships that hold across different time steps. They capture how the world changes over time.

Example: At(Agent,[1,1],0) ∧ BestAction(Forward,0) → At(Agent,[2,1],1)

This relates the agent's position at t=0 to its position at t=1 — a temporal transition.

PropertySynchronicDiachronic
Time scopeSingle time stepMultiple time steps
PurposeDescribe static structureDescribe change and effects
ExamplesPit locations, adjacency, breeze causationAgent movement, action effects, percept history
Key predicatesPit(s), Adjacent(s1,s2), Breezy(s)At(Agent,s,t), BestAction(a,t), Percept(p,t)
Exam Tip: When asked to classify a FOL sentence, check if it involves multiple time indices (t, t+1, etc.). If yes → diachronic. If all variables refer to the same time → synchronic.

9. Model-Based Reasoning Systems

Model-based reasoning goes beyond simple reflex agents by maintaining an internal model of the world state, including unobserved properties.

Reflex Agent vs Model-Based Agent
AspectReflex AgentModel-Based Agent
State trackingCurrent percept onlyFull world model over time
MemoryNonePercept history + inferred states
Handles partially observable?NoYes
Handles unknown initial state?NoYes (builds model incrementally)
Reasoning typeDirect mappingInference over model
Model-Based Knowledge Base Structure
KB = { Percepts, Inferred_Properties, Action_Effects, Temporal_Rules }
A model-based agent maintains a knowledge base containing:
- Percepts: All observed percepts with their time indices
- Inferred Properties: Deduced facts about pits, wumpus, safe squares
- Action Effects: How actions change the world state
- Temporal Rules: Diachronic sentences connecting time steps
Updating the World Model
KB(t+1) = KB(t) ∪ NewPercept(t) ∪ Deductions(KB(t), NewPercept(t))
At each time step, the agent updates its knowledge base by adding the new percept and computing all logical deductions that follow from the existing knowledge combined with the new information.
Critical Concept: Model-based agents can distinguish between "I know this is safe" and "I don't know if this is dangerous." A reflex agent treats unknown squares the same as safe ones, which is fatal in Wumpus World.
