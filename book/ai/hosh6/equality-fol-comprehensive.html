EQUALITY IN FIRST-ORDER LOGIC

How equality works as a logical connective

How = Works in FOL

In first-order logic, equality (=) is a special predicate that compares two terms. It is not an assignment or a function—it simply states whether two terms refer to the same object in the domain.

Atomic Sentence
t1 = t2
True if t1 and t2 refer to the same object in the current model/interpretation.

Structure of Equality Sentences

Both sides of the = sign must be terms—constants, variables, function applications, or any combination thereof.

Example
Father(John) = Henry
This is true if the object denoted by Father(John) is the same as the object denoted by Henry in the current model.

Truth Conditions

To evaluate an equality, check both terms against the model:

Term 1
Evaluate t1 in the model

Determines what object t1 refers to.

Term 2
Evaluate t2 in the model

Determines what object t2 refers to.

Compare
Same object? → True

If both refer to the same entity, equality holds.

Negating Equality

You can express that two terms are different by negating the equality:

Inequality
¬(t1 = t2)   or   t1 ≠ t2
Asserts that t1 and t2 refer to distinct objects.

Worked Examples

Example 1: Basic Identity

Suppose our domain has {Anne, Bob}. We know Anne = Anne.

Formula
Anne = Anne
Always true in any model where Anne exists. Every object is identical to itself (reflexivity).
Example 2: Using Functions

Let Father(x) be a function. If Father(John) = Henry, we can substitute Henry anywhere Father(John) appears.

Substitution Property
Father(John) = Henry → Likes(John, Father(John)) ↔ Likes(John, Henry)
If two terms are equal, one can replace the other in any predicate without changing truth value.
Example 3: At Least 2 Brothers

Richard has at least 2 brothers. We use two variables x, y and assert they are different people.

Formula
∃x∃y ( Brother(x, Richard) ∧ Brother(y, Richard) ∧ ¬(x = y) )
There exist x and y such that both are brothers of Richard and x ≠ y.
Example 4: At Least 3 Students

There are at least 3 students in the class. We need three distinct variables.

Formula
∃x∃y∃z ( Student(x) ∧ Student(y) ∧ Student(z) ∧ ¬(x = y) ∧ ¬(x = z) ∧ ¬(y = z) )
Three distinct individuals exist that are all students.
Example 5: Exactly One

There is exactly one king. Assert existence, then show any two kings must be the same.

Formula
∃x ( King(x) ∧ ∀y ( King(y) → y = x ) )
There is a king x, and every king y must equal x—meaning there is only one.
Example 6: At Most 1 Doctor

There is at most one doctor. For any two people, if both are doctors they must be the same person.

Formula
∀x∀y ( (Doctor(x) ∧ Doctor(y)) → x = y )
If x and y are both doctors, then x must equal y—so at most one doctor exists.
Warning: Don't confuse equality with programming assignment. In FOL, "=" means "is the same as"—it does not change any variable. Writing x = 5 does not assign 5 to x; it states a claim that can be true or false.

Summary of Key Concepts

Concept Meaning Example
t1 = t2 t1 and t2 refer to the same object Alice = Bob
¬(t1 = t2) t1 and t2 are different objects ¬(x = y)
Reflexivity t = t is always true ∀x (x = x)
Symmetry t1 = t2 implies t2 = t1 (x = y) → (y = x)
Transitivity t1 = t2 and t2 = t3 implies t1 = t3 (x = y ∧ y = z) → (x = z)
Substitution If t1 = t2, replace t1 with t2 in any formula P(t1) ↔ P(t2)

Patterns: "At Least N"

At Least 1
∃x P(x)

No inequality needed.

At Least 2
∃x∃y (P(x) ∧ P(y) ∧ x ≠ y)

One inequality: x ≠ y.

At Least 3
∃x∃y∃z (P(x) ∧ P(y) ∧ P(z) ∧ x ≠ y ∧ x ≠ z ∧ y ≠ z)

Three inequalities for three pairs.

Patterns: "At Most N" and "Exactly N"

At Most 1
∀x∀y (P(x) ∧ P(y) → x = y)

Any two P-things must be the same.

Exactly 1
∃x (P(x) ∧ ∀y (P(y) → y = x))

At least 1 + At most 1 combined.

Common Mistakes

Mistake 1: Confusing equality with assignment. In FOL, "x = 5" is a claim, not an instruction. It can be true or false depending on the model—it does not change x.
Mistake 2: Forgetting to assert the predicates with distinct variables. Writing ∃x (P(x) ∧ P(y) ∧ x ≠ y) is wrong because y is free—it must be ∃x∃y.
Mistake 3: Omitting inequalities. "At least 2" requires ¬(x = y). Without it, x and y could both refer to the same object, so you haven't guaranteed two distinct individuals.
Mistake 4: Using equality in the wrong direction for "at most." The formula ∀x∀y (P(x) ∧ P(y) → x = y) is correct for "at most 1," but ∀x∀y (P(x) ∧ P(y) ∧ x = y) only says there exists a case where they are equal—it doesn't constrain all cases.
Key takeaway: Equality in FOL is a binary predicate with built-in axioms (reflexivity, symmetry, transitivity, substitution). Use it to express "same object," "different objects," and counting patterns like "at least N" and "at most N."
