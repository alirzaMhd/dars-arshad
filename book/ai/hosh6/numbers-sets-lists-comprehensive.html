Numbers, Sets, and Lists in First-Order Logic

Foundation of Mathematical Objects for AI Reasoning

Peano Axioms — Defining Natural Numbers

The Peano axioms define natural numbers using five core axioms plus recursive definitions for addition and multiplication. These axioms provide the foundation for all arithmetic reasoning.

Axiom 1 — Zero is a natural number
NatNum(0)
Zero is the first natural number. Every natural number can be traced back to zero through successors.
Axiom 2 — Successor produces natural numbers
∀n [NatNum(n) → NatNum(S(n))]
If n is a natural number, then S(n) — its successor — is also a natural number. S(n) effectively means "n + 1".
Axiom 3 — Zero has no predecessor
∀n [¬(S(n) = 0)]
Zero is not the successor of any natural number. This prevents cycles and ensures the sequence starts at zero.
Axiom 4 — Successor is injective
∀m,n [S(m) = S(n) → m = n]
If two successors are equal, their predecessors must be equal. The successor function is one-to-one (injective).
Axiom 5 — Induction (Second-order)
[P(0) ∧ ∀n(P(n) → P(S(n)))] → ∀n NatNum(n) → P(n)
If a property holds for zero and is preserved by successor, it holds for all natural numbers. This is the principle of mathematical induction.

Recursive Addition

Base case
∀m [NatNum(m) → +(m, 0) = m]
Adding zero to any number yields that number itself.
Recursive step
∀m,n [NatNum(m) ∧ NatNum(n) → +(S(m), n) = S(+(m, n))]
Adding the successor of m to n gives the successor of (m + n). This recursively defines addition for all pairs.
Key Insight: The function + is defined recursively, not as primitive. The axioms guarantee its existence and uniqueness. Infix notation m + n is syntactic sugar for +(m, n).

Recursive Multiplication

Base case
∀m [NatNum(m) → ×(m, 0) = 0]
Multiplying any number by zero yields zero.
Recursive step
∀m,n [NatNum(m) ∧ NatNum(n) → ×(S(m), n) = +(×(m, n), n)]
Multiplying the successor of m by n gives (m × n) + n. This uses the previously defined addition function.
Building Numbers
0
S(0) = 1
S(S(0)) = 2
S(S(S(0))) = 3
...
∀n: n = S(S(...S(0)...)) n times

Every natural number is a finite chain of successor applications to zero.

Set Theory Axioms

Sets are defined inductively — as either the empty set or the result of adding one element to an existing set. All set operations are built on this foundation.

Set Constructor Axiom
Set(s) → [s = {} ∨ ∃x,s' (Set(s') ∧ s = {x | s'})]
Every set is either the empty set or is constructed by adding some element x to an existing set s'. The notation {x | s'} means "the set s' with element x adjoined".
Empty Set Property
∀x [¬(x ∈ {})]
The empty set contains no elements. No matter what x is, it is not a member of {}.
Add Existing Element (Absorption)
∀x,s [Set(s) ∧ (x ∈ s) → {x | s} = s]
If x is already in s, adding it again produces the same set. Sets do not contain duplicate elements — {x | {x, y}} = {x, y}.
Add New Element
∀x,s [Set(s) ∧ ¬(x ∈ s) → x ∈ {x | s}]
If x is not already in s, then x is an element of the augmented set {x | s}.

Derived Set Operations

Subset
A ⊆ B

∀x (x ∈ A → x ∈ B). Every element of A is also in B.

Equality
A = B ↔ A ⊆ B ∧ B ⊆ A

Two sets are equal iff they have exactly the same elements.

Intersection
A ∩ B = {x | x ∈ A ∧ x ∈ B}

Elements common to both A and B.

Union
A ∪ B = {x | x ∈ A ∨ x ∈ B}

Elements in A, or in B, or in both.

Subset Axiom
∀A,B [A ⊆ B ↔ ∀x(x ∈ A → x ∈ B)]
A is a subset of B if and only if every element of A is also an element of B.
Set Equality Axiom
∀A,B [A = B ↔ ∀x(x ∈ A ↔ x ∈ B)]
Two sets are equal if and only if they have the same members. This is the Axiom of Extensionality.
Caution: In this inductive definition, {x | s'} = {y | s'} if x = y. The constructor adds exactly one element. Duplicate additions are absorbed — sets ignore multiplicity.
Building Sets Inductively
{} = empty set
{a | {} } = {a}
{b | {a}} = {a, b}
{a | {a, b}} = {a, b} (absorbed — a already present)
{c | {a, b}} = {a, b, c}

Lists — Lisp-Style Operations

Lists are ordered sequences of elements built from two primitives: Nil (empty list) and Cons (prepend element to list). This mirrors Lisp/Scheme list construction.

List Constructor Axiom
List(L) → [L = Nil ∨ ∃x,L' (List(L') ∧ L = Cons(x, L'))]
Every list is either Nil or is constructed by Cons-ing some element x onto an existing list L'. This is the inductive definition of lists.

Primitive Operations

Nil
Nil

The empty list. List(Nil) is true. Length of Nil = 0.

Cons
Cons(x, L)

Constructs a new list by placing x at the front of list L.

First (Head)
First(Cons(x, L)) = x

Returns the first element. Undefined for Nil.

Rest (Tail)
Rest(Cons(x, L)) = L

Returns the list without the first element. Undefined for Nil.

First Axiom
∀x,L [First(Cons(x, L)) = x]
The First function extracts the leading element from a non-empty list.
Rest Axiom
∀x,L [Rest(Cons(x, L)) = L]
The Rest function returns the tail of the list — everything after the first element.
Append Axiom — Base
∀L [Append(Nil, L) = L]
Appending Nil to any list L yields L itself. Nil acts as the identity element for append.
Append Axiom — Recursive
∀x,L1,L2 [Append(Cons(x, L1), L2) = Cons(x, Append(L1, L2))]
To append Cons(x, L1) to L2, Cons x onto the result of appending L1 to L2. This recursively processes each element.

List Length

Length — Base
Length(Nil) = 0
Length — Recursive
∀x,L [Length(Cons(x, L)) = S(Length(L))]
The length of a list is one plus the length of its tail. Uses the successor function S from Peano arithmetic.
Order Matters: Unlike sets, lists are ordered. [A, B, C] ≠ [C, B, A]. Lists also allow duplicate elements: [A, A, B] is a valid list of length 3.
List Construction Step by Step
Nil
Cons(A, Nil) → [A]
Cons(B, Cons(A, Nil)) → [B, A]
Cons(C, Cons(B, Cons(A, Nil))) → [C, B, A]

Standard notation: [A, B, C] = Cons(A, Cons(B, Cons(C, Nil)))

The rightmost element is innermost (closest to Nil). Cons prepends, so [A,B,C] has A at the front.

Worked Examples

Example 1 — Peano Addition: 2 + 1
2 + 1
= +(S(S(0)), S(0))
= S(+(S(0), S(0))) [by recursive addition step]
= S(S(+(0, S(0)))) [by recursive addition step]
= S(S(S(0))) [by base case: +(0, n) = n]
= 3

Each step applies one axiom. The base case fires when the first argument reaches 0.

Example 2 — Set Construction
Start: {}
Add 'a': {a | {} } = {a}
Add 'b': {b | {a}} = {a, b}
Add 'a': {a | {a, b}} = {a, b} (absorbed)
Add 'c': {c | {a, b}} = {a, b, c}

Final set: {a, b, c} (size = 3)

Notice that adding 'a' the second time had no effect — sets do not track multiplicity.

Example 3 — List Append: Append([A, B], [C, D])
Append([A, B], [C, D])
= Append(Cons(A, Cons(B, Nil)), Cons(C, Cons(D, Nil)))
= Cons(A, Append(Cons(B, Nil), Cons(C, Cons(D, Nil)))) [recursive rule]
= Cons(A, Cons(B, Append(Nil, Cons(C, Cons(D, Nil))))) [recursive rule]
= Cons(A, Cons(B, Cons(C, Cons(D, Nil)))) [base case]
= [A, B, C, D]

Append processes elements left-to-right, recursively unwinding the first list, then attaching the second.

Example 4 — List Length
Length([X, Y, Z])
= Length(Cons(X, Cons(Y, Cons(Z, Nil))))
= S(Length(Cons(Y, Cons(Z, Nil))))
= S(S(Length(Cons(Z, Nil))))
= S(S(S(Length(Nil))))
= S(S(S(0)))
= 3

Length uses the same successor function S from Peano axioms — arithmetic and list operations are unified.

Example 5 — Set Intersection
A = {1, 2, 3}, B = {2, 3, 4}
A ∩ B = {x | x ∈ A ∧ x ∈ B}

x = 1: (1 ∈ A) ∧ (1 ∈ B) = T ∧ F = F → 1 ∉ A∩B
x = 2: (2 ∈ A) ∧ (2 ∈ B) = T ∧ T = T → 2 ∈ A∩B
x = 3: (3 ∈ A) ∧ (3 ∈ B) = T ∧ T = T → 3 ∈ A∩B
x = 4: (4 ∈ A) ∧ (4 ∈ B) = F ∧ T = F → 4 ∉ A∩B

Result: A ∩ B = {2, 3}

Intersection tests each element against both sets using logical AND (∧).

Key Takeaways

All three domains follow the same pattern:
1. Define base objects (0, {}, Nil)
2. Define constructors (S, {x|s}, Cons)
3. Define functions recursively on the constructors
4. Prove properties by structural induction

This inductive approach is how first-order logic builds all mathematical objects from nothing.
