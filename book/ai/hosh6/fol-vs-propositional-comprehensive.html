FOL vs Propositional Logic

Artificial Intelligence — Complete Comparison Guide

Detailed Comparison Table

Feature Propositional Logic (PL) First-Order Logic (FOL)
Basic Units Propositions (atomic symbols) Objects, Relations, Functions
Variables None Yes (x, y, z, ...)
Quantifiers None ∀ (universal), ∃ (existential)
Predicates Not supported P(x), Loves(x,y), King(x)
Connectives ∧, ∨, ¬, →, ↔ ∧, ∨, ¬, →, ↔ (same)
Objects Not representable First-class entities
Relationships Cannot express Native support
Generalization Impossible (need separate proposition per object) Built-in via quantifiers
Ontological Commitment Facts exist Facts, Objects, Relations exist
Epistemological Commitment Each fact: true/false/unknown Each fact: true/false/unknown (same)
Model Checking Works (finite number of models) Doesn't work (infinite models possible)
Inference Method Truth tables, model checking Theorem proving, inference rules
Complexity NP-complete (SAT problem) Undecidable in general
Expressiveness Limited Very high
Key Distinction: PL treats facts as indivisible atoms. FOL breaks facts into objects and relations, enabling far more powerful reasoning.

Commitment Comparison

Ontological Commitment

PL: Only facts exist (true/false propositions)

FOL: Facts, Objects, AND Relations exist

Ontological commitment = what we assume exists in the world

Epistemological Commitment

Both: Each fact can be true, false, or unknown

Epistemological commitment = what we can know about facts

What FOL Can Do That PL Cannot

1. Express Relationships Between Objects

Relationship: "John loves Mary"
PL: Requires a single proposition symbol
L (true or false, no structure)

FOL: Uses predicate with arguments
Loves(John, Mary) — clearly shows relationship

FOL reveals the structure: who loves whom. PL just says "something is true."

2. Quantify Over Objects

Universal Statement: "All humans are mortal"
PL: Cannot express this! Would need:
Human(Socrates) → Mortal(Socrates)
Human(Alice) → Mortal(Alice)
Human(Bob) → Mortal(Bob)
... (infinite propositions for infinite objects)

FOL: One sentence covers all humans
∀x Human(x) → Mortal(x)

3. Express Existence

Existential Statement: "There exists a prime greater than 2"
PL: Cannot express!

FOL: ∃x (Prime(x) ∧ Greater(x, 2))

4. Nested Quantifiers for Complex Rules

"Everyone loves someone"
PL: Impossible to express

FOL: ∀x ∃y Loves(x, y)

5. Functions and Terms

"The father of Alice is tall"
PL: Cannot express function composition

FOL: Tall(Father(Alice))
Critical Limitation of PL: Propositional logic can only state that certain combinations of facts are true or false. It cannot describe patterns, relationships, or rules that apply to categories of objects.

Expressiveness Spectrum

Propositional Logic

• Atomic propositions only

• Boolean connectives

• No variables, no quantifiers

Limited to finite fact combinations

First-Order Logic

• Predicates with arguments

• Variables and quantifiers (∀, ∃)

• Objects and relations as first-class

Can express general rules and patterns

Higher-Order Logic

• Quantify over predicates

• Properties of properties

• Even more expressive

Undecidable, rarely used in practice

Translation Examples: PL ↔ FOL

Example 1: Simple Fact

English: "It is raining"
PL: R
(R is a proposition symbol, true if raining)

FOL: Raining
(Same here — no objects involved, so FOL reduces to PL)

When there are no objects or relations to discuss, FOL and PL are equivalent.

Example 2: Relationship

English: "Alice is friends with Bob"
PL: F_AB (a single proposition symbol)
(Loses the information that it's a friendship between two specific people)

FOL: Friends(Alice, Bob)
(Clearly shows: Alice and Bob are friends)

Example 3: Universal Rule

English: "All kings are persons"
PL: Requires listing every king:
King(Richard) → Person(Richard)
King(John) → Person(John)
King(Henry) → Person(Henry)
... (must list ALL kings individually)

FOL: ∀x King(x) → Person(x)
(One sentence covers ALL kings, past, present, and future)
Why PL fails here: If a new king is born, PL needs a new proposition. FOL automatically covers the new king through quantification.

Example 4: Existential Statement

English: "Some students passed the exam"
PL: Cannot express "some" — only all-or-nothing:
P (true if at least one passed, but loses who passed)

FOL: ∃x (Student(x) ∧ Passed(x, Exam))
(Exactly captures: there exists at least one student who passed)

Example 5: Complex Relationship

English: "Every student who studies passes every exam"
PL: Would need propositions for every student-exam pair:
(S_Alice ∧ Stud_Alice) → Pass_Alice_Exam1
(S_Alice ∧ Stud_Alice) → Pass_Alice_Exam2
(S_Bob ∧ Stud_Bob) → Pass_Bob_Exam1
... (exponential growth!)

FOL: ∀x ∀y ((Student(x) ∧ Studies(x)) → Passes(x, y))
(Two quantifiers capture the universal pattern)

The PL version requires one proposition per (student, exam) pair. FOL handles this with a single quantified sentence.

Quick Reference: Common Patterns

English Pattern FOL Translation PL Equivalent
"All A are B" ∀x A(x) → B(x) Must list each object individually
"Some A are B" ∃x A(x) ∧ B(x) Cannot express precisely
"No A are B" ¬∃x A(x) ∧ B(x) Must list negations individually
"A is related to B" R(a, b) Single proposition R
"A or B, but not both" A ⊕ B (same in both) A ⊕ B

When to Use Which Logic

Use Propositional Logic When:

• Facts are independent (no relationships)

• Small, fixed number of propositions

• Need quick model checking

• Example: Simple circuit design, basic puzzles

Use First-Order Logic When:

• Objects have relationships

• Need to express general rules

• Domain has many similar objects

• Example: Wumpus world, knowledge bases, databases

The Wumpus World Case: The Wumpus world has many squares (potentially infinite). You need rules like "if a square has a stench, an adjacent square has a Wumpus." This requires FOL because you need to quantify over all squares and express adjacency relations.

Summary of Key Differences

Complexity

PL: NP-complete (SAT is NP-complete)

FOL: Undecidable (no general algorithm exists)

Model Checking

PL: Works — finite number of models (2ⁿ for n propositions)

FOL: Fails — infinite models possible

Inference

PL: Truth tables, DPLL, resolution

FOL: Unification, resolution, Prolog-style backtracking

Practical Use

PL: Hardware verification, SAT solvers

FOL: AI planning, databases, semantic web

Final Summary

The Core Insight

Propositional Logic treats the world as a collection of independent true/false facts. It's simple but severely limited — you cannot express rules that apply to categories of objects.


First-Order Logic adds three crucial capabilities: objects (things in the world), relations (how objects connect), and quantifiers (rules that apply to groups). This makes FOL dramatically more expressive but also computationally harder.


The trade-off: PL is decidable and efficient for small problems. FOL is undecidable in general but necessary for any domain with structure and patterns.

Relationship:
PL ⊂ FOL
Propositional Logic is a subset of First-Order Logic. Every PL sentence is also a valid FOL sentence, but not vice versa.
Exam Tip: If a problem involves objects, relationships, or quantifiers (all/some), you MUST use FOL. PL can only handle pure boolean combinations of facts.
