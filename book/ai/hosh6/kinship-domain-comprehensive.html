KINSHIP DOMAIN IN FIRST-ORDER LOGIC

Artificial Intelligence — Complete Guide for Kinship Relations

Kinship Domain Axioms

Axioms are the fundamental definitions that establish the base vocabulary and rules for reasoning about family relationships. They define both primitive and derived predicates.

Axiom 1 — Mother (Derived Predicate)
Mother(c, m) ⇔ Female(m) ∧ Parent(m, c)
A person m is the mother of c if and only if m is female and m is a parent of c. This defines Mother in terms of the primitive predicates Female and Parent.
Axiom 2 — Father (Derived Predicate)
Father(c, f) ⇔ Male(f) ∧ Parent(f, c)
A person f is the father of c if and only if f is male and f is a parent of c. Similar to Mother, this is defined using primitive predicates Male and Parent.
Axiom 3 — Husband (Derived Predicate)
Husband(h, w) ⇔ Male(h) ∧ Spouse(h, w)
A person h is the husband of w if and only if h is male and h is a spouse of w. Husband is defined using the primitive predicates Male and Spouse.
Axiom 4 — Mutual Exclusivity
Male(x) → ¬Female(x)
If x is male, then x is not female. This enforces that Male and Female are mutually exclusive categories — no individual can be both.
Axiom 5 — Inverse Parent-Child
Parent(p, c) → Child(c, p)
If p is a parent of c, then c is a child of p. The Child relation is the logical inverse of Parent. This is a bidirectional implication in practice.
Axiom 6 — Grandparent (Derived Predicate)
Grandparent(g, c) ⇔ ∃p [Parent(g, p) ∧ Parent(p, c)]
A person g is a grandparent of c if and only if there exists some person p such that g is a parent of p and p is a parent of c. Grandparent is a chain of two Parent relations.
Axiom 7 — Sibling (Derived Predicate)
Sibling(x, y) ⇔ (x ≠ y) ∧ ∃p [Parent(p, x) ∧ Parent(p, y)]
x and y are siblings if they are distinct individuals and they share at least one common parent. Note: x ≠ y ensures a person is not their own sibling.
Key Insight: The choice of which predicates are primitive versus derived is not unique. You could alternatively choose Parent and Mother as primitive and define Female from them. The important thing is consistency within a knowledge base.

Primitive vs Derived Predicates

Primitive Predicates

• Parent(x, y) — x is a parent of y

• Male(x) — x is male

• Female(x) — x is female

• Spouse(x, y) — x and y are married

These are the building blocks — not defined using other predicates.

Derived Predicates

• Mother(c, m) — defined via Female + Parent

• Father(c, f) — defined via Male + Parent

• Husband(h, w) — defined via Male + Spouse

• Grandparent(g, c) — defined via Parent ∘ Parent

• Sibling(x, y) — defined via shared Parent

These are shorthand — fully expressible using primitives.

Axioms vs Theorems — Key Distinction

Axioms

• Base definitions assumed to be true

• Part of the knowledge base

• Define the vocabulary

• Cannot be proved — they are given

Example: "Mother(c,m) ⇔ Female(m) ∧ Parent(m,c)"

Theorems

• Derived facts provable from axioms

• Follow logically from the axioms

• Extend the knowledge base

• Must be proved using inference rules

Example: "If Mother(john,mary) then Female(mary)"

How Theorems Are Derived

A theorem is any statement that can be logically deduced from the axioms using inference rules like modus ponens, universal instantiation, and existential generalization.

Modus Ponens (Primary Inference Rule)
If P → Q and P is true, then Q is true
From "Parent(m, c) → Child(c, m)" and "Parent(mary, john)", we can conclude "Child(john, mary)".
Universal Instantiation
∀x P(x) → P(a) for any constant a
From "∀x [Male(x) → ¬Female(x)]" and "Male(ahmad)", we conclude "¬Female(ahmad)".
Existential Generalization
P(a) → ∃x P(x) for any constant a
From "Parent(ali, sara)" we can conclude "∃x Parent(x, sara)" — there exists someone who is sara's parent.

Worked Example — From Axiom to Theorem

Scenario: Given axioms and facts
Axioms:
A1: Mother(c,m) ⇔ Female(m) ∧ Parent(m,c)
A2: Parent(p,c) → Child(c,p)
A3: Male(x) → ¬Female(x)

Known Facts:
F1: Parent(mary, john)
F2: Female(mary)
F3: Male(ahmad)
Theorem 1: Mother(john, mary)

Step 1: From A1 (forward direction): Female(mary) ∧ Parent(mary, john) → Mother(john, mary)

Step 2: From F1 and F2: Female(mary) ∧ Parent(mary, john) is TRUE

Step 3: By modus ponens: Mother(john, mary) ✓

Theorem 2: Child(john, mary)

Step 1: From A2: Parent(mary, john) → Child(john, mary)

Step 2: From F1: Parent(mary, john) is TRUE

Step 3: By modus ponens: Child(john, mary) ✓

Theorem 3: ¬Female(ahmad)

Step 1: From A3 (universal instantiation): Male(ahmad) → ¬Female(ahmad)

Step 2: From F3: Male(ahmad) is TRUE

Step 3: By modus ponens: ¬Female(ahmad) ✓

Common Mistake: Students often confuse axioms with theorems. An axiom like "Mother(c,m) ⇔ Female(m) ∧ Parent(m,c)" is a DEFINITION — it's true by construction. A theorem like "Mother(john, mary)" must be PROVED from the axioms applied to specific facts.

Worked Examples — Using Kinship Axioms

Example 1: Identifying a Grandparent
Given: Parent(ahmad, sara), Parent(sara, omar)
Query: Grandparent(ahmad, omar)?

Using Axiom 6: Grandparent(g, c) ⇔ ∃p [Parent(g, p) ∧ Parent(p, c)]

Let g = ahmad, c = omar. We need ∃p [Parent(ahmad, p) ∧ Parent(p, omar)]

Try p = sara: Parent(ahmad, sara) ∧ Parent(sara, omar) = TRUE ∧ TRUE = TRUE

Therefore: Grandparent(ahmad, omar) ✓

Example 2: Proving Two People Are Siblings
Given: Parent(mary, john), Parent(mary, anne), john ≠ anne
Query: Sibling(john, anne)?

Using Axiom 7: Sibling(x, y) ⇔ (x ≠ y) ∧ ∃p [Parent(p, x) ∧ Parent(p, y)]

Check x ≠ y: john ≠ anne is TRUE

Check ∃p: Let p = mary. Parent(mary, john) ∧ Parent(mary, anne) = TRUE ∧ TRUE = TRUE

Both conditions satisfied: Sibling(john, anne) ✓

Example 3: Multi-Step Grandparent Chain
Given: Parent(hassan, ali), Parent(ali, sara), Parent(sara, omar)
Query: Grandparent(hassan, omar)?

Analysis: Grandparent requires a TWO-generation gap, not three.

For Grandparent(hassan, omar): ∃p [Parent(hassan, p) ∧ Parent(p, omar)]

Try p = ali: Parent(hassan, ali) = TRUE, but Parent(ali, omar) = ? (not given) → UNKNOWN

Try p = sara: Parent(hassan, sara) = ? (not given) → UNKNOWN

Result: Cannot prove Grandparent(hassan, omar) from given facts

However, we CAN prove: Grandparent(ali, omar) since Parent(ali, sara) ∧ Parent(sara, omar)

Hassan is a great-grandparent of omar, not a grandparent. The Grandparent predicate only covers exactly two generations up.
Example 4: Proving Non-Sibling (Reflexivity)
Given: Parent(mary, john)
Query: Sibling(john, john)?

Using Axiom 7: Sibling(x, y) ⇔ (x ≠ y) ∧ ∃p [Parent(p, x) ∧ Parent(p, y)]

Check x ≠ y: john ≠ john is FALSE

Since the first conjunct is FALSE, the entire conjunction is FALSE regardless of the second part.

Result: Sibling(john, john) is FALSE ✓

The x ≠ y condition correctly prevents a person from being their own sibling.

Example 5: Husband Relation from Spouse
Given: Male(ahmad), Spouse(ahmad, fatima), Female(fatima)
Query: Husband(ahmad, fatima)?

Using Axiom 3: Husband(h, w) ⇔ Male(h) ∧ Spouse(h, w)

Let h = ahmad, w = fatima. Male(ahmad) = TRUE, Spouse(ahmad, fatima) = TRUE

TRUE ∧ TRUE = TRUE

Therefore: Husband(ahmad, fatima) ✓

Also: From Axiom 1, Mother(fatima, x) requires Female(fatima) ∧ Parent(fatima, x). We know Female(fatima) but not Parent(fatima, x) for any x, so we cannot conclude any Mother relation for fatima.

Important: When applying axioms, always verify ALL conditions are met. For Sibling, you need both (x ≠ y) AND a shared parent. Missing either condition makes the result false.

Key Distinctions

Primitive Predicates

• Parent(x, y)

• Male(x)

• Female(x)

• Spouse(x, y)

Not defined using other predicates. These are the foundation.

Derived Predicates

• Mother, Father, Husband

• Grandparent, Sibling, Child

Shorthand — fully expressible using primitives + logical connectives.

Axioms

• Base definitions in knowledge base

• Assumed true — not proved

• Define the vocabulary

Examples: "Mother(c,m) ⇔ Female(m) ∧ Parent(m,c)"

Theorems

• Derived facts from axioms

• Must be proved via inference

• Extend the knowledge base

Examples: "Mother(john, mary)" given facts about mary and john

Common Pitfalls

1. Gender Assumptions: Never assume gender from names or roles. Always use the explicit Male(x) or Female(x) predicates. A mother must be female — this is enforced by the axiom, not assumed.
2. Reflexivity in Sibling: A person is NOT their own sibling. The condition x ≠ y is critical and must always be checked first.
3. Generation Counting: Grandparent means exactly TWO generations up (parent of parent). Great-grandparent would require a separate definition with three Parent links.
4. Primitive Choice Flexibility: There is no single "correct" set of primitive predicates. Different textbook editions may choose different primitives. What matters is that the knowledge base is consistent and complete.
5. Axiom Direction: Most axioms use ⇔ (if and only if), not just →. This means the axiom works in both directions — you can use it to prove things AND to check conditions.

Inference Rules for Kinship

Modus Ponens

If P → Q and P, then Q

Most commonly used rule for applying axioms to specific facts.

Universal Instantiation

From ∀x P(x), derive P(a)

Apply general axiom to a specific individual.

Existential Elimination

From ∃x P(x), assume P(c) for fresh c

Used when an axiom requires ∃ — introduce a witness.

Conjunction Introduction

From P and Q, derive P ∧ Q

Combine multiple conditions (e.g., Male(x) ∧ Spouse(x,y)).
