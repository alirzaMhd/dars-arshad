CHAINING (Collision Resolution)

Data Structures — Complete Guide for 20/20 Exam

What is Chaining?

Chaining is a collision resolution technique where each slot of the hash table contains a linked list. All elements that hash to the same slot are stored in that slot's linked list.

Structure:
T[j] → linked list of elements with h(k) = j
Each slot points to a chain of elements that hash to the same index
Example: Hash Table with Chaining

Keys: {17, 20, 12, 10, 30, 24, 27}

Hash function: h(k) = k mod 7

Table size: m = 7 (slots 0-6)

173

T[2] → 30, T[3] → 17 → 10 → 24, T[5] → 12, T[6] → 20 → 27

Algorithms

Insert Operation

Insert(T, x): Insert x at the head of list T[h(x.key)]

Insert at the beginning of the linked list for O(1) time.

Search Operation

Search(T, k): Search for an element with key k in list T[h(k)]

Traverse the linked list at slot h(k) to find the element.

Delete Operation

Delete(T, x): Delete x from the list T[h(x.key)]

Remove element x from the linked list at slot h(x.key).

For Delete, we need to know the exact element x (not just the key). For Search, we need to traverse the list.
Note: The Insert algorithm assumes the element x does not already exist in the table. The Delete algorithm requires x to be a pointer to the element (not just the key), because we need to know the exact position in the linked list.

Worked Examples

Example 1: Insert Sequence

Keys: {17, 20, 12, 10, 30, 24, 27}

Hash function: h(k) = k mod 7

Step 1: Insert 17 → T[3] = [17]

Step 2: Insert 20 → T[6] = [20]

Step 3: Insert 12 → T[5] = [12]

Step 4: Insert 10 → T[3] = [10, 17] (insert at head)

Step 5: Insert 30 → T[2] = [30]

Step 6: Insert 24 → T[3] = [24, 10, 17]

Step 7: Insert 27 → T[6] = [27, 20]

Final: T[2]=30, T[3]=24→10→17, T[5]=12, T[6]=27→20

Example 2: Search Operation

Search for key 10 in the table above

h(10) = 10 mod 7 = 3

Check T[3]: 24 → 10 (found!)

Search(10) succeeds, compares 2 elements

Example 3: Delete Operation

Delete element with key 17

h(17) = 17 mod 7 = 3

T[3] = [24, 10, 17]

Remove 17 from the list

T[3] = [24, 10]

Example 4: Worst Case Search

All keys hash to same slot (worst case)

Keys: {7, 14, 21, 28, 35}, h(k) = k mod 7

All hash to slot 0

T[0] = [35, 28, 21, 14, 7]

Search(7) must traverse 5 elements → O(n)

Example 5: Average Case

n = 100 elements, m = 25 slots

Load factor α = n/m = 4

Average chain length = 4

Average search time ≈ O(4) = O(1) for successful search

Complexity Analysis

Average Case (α = n/m)

Successful Search: O(1 + α)

Unsuccessful Search: O(1 + α)

Insert: O(1)

Delete: O(1)

Worst Case

All operations: O(n)

When all keys hash to same slot

Load Factor:
α = n/m
n = number of elements, m = number of slots, α = average chain length
Successful Search (Average):
1 + α/2
On average, need to search half the chain plus one
Unsuccessful Search (Average):
α
Must traverse entire chain on average
