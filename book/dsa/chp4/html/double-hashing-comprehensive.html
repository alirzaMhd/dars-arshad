DOUBLE HASHING

Data Structures — Complete Guide for 20/20 Exam

What is Double Hashing?

Double hashing uses two hash functions to compute the probe sequence. The second hash function determines the step size, making probe sequences different for different keys.

Probe Function:
h(k, i) = (h₁(k) + i · h₂(k)) mod m
h₁(k) gives initial position, h₂(k) gives step size
h₂(k) must never be 0. Also, h₂(k) should be relatively prime to m for the probe sequence to cover all slots.
Example: Why Double Hashing?

Linear probing: Keys with same h(k) have same probe sequence (primary clustering)

Quadratic probing: Keys with same h(k) have same probe sequence (secondary clustering)

Double hashing: Different step sizes for different keys (minimal clustering)

Hash Function Choices

Common h₁(k)

Division Method:
h₁(k) = k mod m
Simple, but not always good for step size

Common h₂(k)

From Textbook:
h₂(k) = 1 + (k mod (m-1))
Ensures h₂(k) is never 0 and is between 1 and m-1
Alternative:
h₂(k) = m' - (k mod m')
Where m' < m is a prime number

Key Requirements

1. h₂(k) ≠ 0 for any k

2. h₂(k) should be coprime with m (gcd(h₂(k), m) = 1)

3. If m is prime, any h₂(k) in range [1, m-1] works

Worked Examples

Example 1: Insert with Double Hashing

m = 13, h₁(k) = k mod 13, h₂(k) = 1 + (k mod 11)

Key 14: h₁(14) = 1, h₂(14) = 1 + (14 mod 11) = 4

Probe: h(14,0) = 1, h(14,1) = 5, h(14,2) = 9, h(14,3) = 0

Key 14 placed in slot 0

Example 4: Search in Double Hashing

Search for key 14 (from Example 1)

h₁(14) = 1, h₂(14) = 4

h(14,0) = 1 → T[1] = 88 ≠ 14

h(14,1) = 5 → T[5] = 15 ≠ 14

h(14,2) = 9 → T[9] = 31 ≠ 14

h(14,3) = 0 → T[0] = 22 ≠ 14

h(14,4) = 4 → T[4] = 4 ≠ 14

h(14,5) = 8 → T[8] = 59 ≠ 14

h(14,6) = 12 → T[12] = NIL → stop

Search(14) takes 7 probes, returns NIL (not found)

Example 5: All Slots Visited

m = 7 (prime), h₁(k) = k mod 7, h₂(k) = 1 + (k mod 5)

Key with h₁=0, h₂=3: probes 0, 3, 6, 2, 5, 1, 4

All 7 slots visited! (because gcd(3,7)=1)

Algorithm

Insert

Insert(T, k): i = 0 repeat j = (h₁(k) + i * h₂(k)) mod m if T[j] == NIL or T[j] == DELETED: T[j] = k return j i = i + 1 until i == m error "hash table overflow"

Search

Search(T, k): i = 0 repeat j = (h₁(k) + i * h₂(k)) mod m if T[j] == k: return j if T[j] == NIL: return NIL i = i + 1 until i == m return NIL
The step size h₂(k) is computed once and used throughout the probe sequence. This is different from linear probing where step is always 1.

Complexity Analysis

Expected Probes

Successful Search: O(1/α ln(1/(1-α)))

Unsuccessful Search: O(1/(1-α))

Advantages

• No primary clustering

• No secondary clustering

• Best probe distribution

Comparison of All Open Addressing Methods

Method Probe Formula Clustering Best For
Linear (h(k) + i) mod m Primary Low α, simple impl.
Quadratic (h(k) + c₁i + c₂i²) mod m Secondary Medium α
Double (h₁(k) + i·h₂(k)) mod m Minimal High α, best performance
Key Insight:
Double hashing is the best open addressing method
It produces probe sequences that behave like random probing, giving the best theoretical performance
Double hashing requires computing two hash functions, which adds overhead. But the improved probe distribution is usually worth it.
