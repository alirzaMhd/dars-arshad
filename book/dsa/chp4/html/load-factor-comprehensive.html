LOAD FACTOR & EXPECTED PROBES

Data Structures — Complete Guide for 20/20 Exam

What is Load Factor?

The load factor (α) measures how full a hash table is. It's the ratio of elements to slots.

Definition:
α = n/m
n = number of elements stored, m = number of slots in table

Low α (e.g., 0.3)

• Table is mostly empty

• Few collisions

• Fast operations

• Wasted space

High α (e.g., 0.9)

• Table is mostly full

• Many collisions

• Slow operations

• Space efficient

For open addressing, α must be ≤ 1 (table cannot have more elements than slots). For chaining, α can be > 1.

Expected Probes Formulas

Chaining

Successful Search:
1 + α/2
Average comparisons for successful search
Unsuccessful Search:
α
Average comparisons for unsuccessful search

Open Addressing (General)

Successful Search:
1/α · ln(1/(1-α))
Expected probes for successful search
Unsuccessful Search:
1/(1-α)
Expected probes for unsuccessful search

Linear Probing (More Precise)

Successful Search:
½(1 + 1/(1-α))
Average probes for successful search with linear probing
Unsuccessful Search:
½(1 + 1/(1-α)²)
Average probes for unsuccessful search with linear probing

Worked Examples

Example 1: Calculate Load Factor

Hash table with m = 100 slots

Contains n = 75 elements

α = 75/100 = 0.75

Table is 75% full

Example 2: Expected Probes (Open Addressing)

α = 0.5

Successful: 1/0.5 · ln(1/(1-0.5)) = 2 · ln(2) ≈ 2 · 0.693 ≈ 1.39

Unsuccessful: 1/(1-0.5) = 2

About 1.4 probes for success, 2 probes for failure

Example 3: Impact of High Load Factor

α = 0.9

Successful: 1/0.9 · ln(1/0.1) ≈ 1.11 · 2.303 ≈ 2.56

Unsuccessful: 1/(1-0.9) = 10

Unsuccessful searches take 10 probes on average!

Example 4: Chaining vs Open Addressing

α = 0.75, n = 75, m = 100

Chaining successful: 1 + 0.75/2 = 1.375

Chaining unsuccessful: 0.75

Open addressing successful: ≈ 1.85

Open addressing unsuccessful: 4

Chaining is better for high load factors

Example 5: Choosing Table Size

Want to store 1000 elements with α ≤ 0.7

m ≥ n/α = 1000/0.7 ≈ 1429

Choose m = 1429 (prime number)

Table size should be at least 1429

Key Theorems

Theorem 1 (Open Addressing - Unsuccessful):
Expected probes = 1/(1-α)
For any open addressing scheme, the expected number of probes for unsuccessful search is at most 1/(1-α)
Theorem 2 (Open Addressing - Successful):
Expected probes = 1/α · ln(1/(1-α))
For any open addressing scheme, the expected number of probes for successful search is at most 1/α · ln(1/(1-α))
Theorem 3 (Linear Probing - Insert):
Maximum expected probes for insert = 1/(1-α)
When inserting into a table with load factor α using linear probing

Proof Sketch (from textbook)

Key Insight:
If k is the (i+1)-th key inserted, expected probes ≤ m/(m-i)
For successful search of k, average over all n keys gives 1/α · ln(1/(1-α))
The proof uses the fact that for each key k, the probe sequence produced during search is exactly the same as during insertion. If k was the (i+1)-th key inserted, the maximum expected probes is m/(m-i). Averaging over all n keys and using integral approximation gives the final formula.

Practical Implications

Keep α ≤ 0.7

For open addressing, keep load factor below 0.7 for reasonable performance

Resize at α > 0.75

Most implementations resize (double table size) when α exceeds 0.75

As α approaches 1, the number of probes increases dramatically. Always monitor load factor and resize when necessary.
