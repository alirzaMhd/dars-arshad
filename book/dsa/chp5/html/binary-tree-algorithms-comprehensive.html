Counting Nodes

1. Count Leaf Nodes

function countLeaves(t: tree): integer; begin if t = nil then countLeaves := 0 else if (t.left = nil) AND (t.right = nil) then countLeaves := 1 // It's a leaf else countLeaves := countLeaves(t.left) + countLeaves(t.right); end;
Complexity:
Time: O(n), Space: O(h)
Visits every node once. Space depends on recursion depth (tree height).
Trace: Count Leaves
a / \ b c / \ d e

countLeaves(a) = countLeaves(b) + countLeaves(c)

countLeaves(b) = countLeaves(d) + countLeaves(e) = 1 + 1 = 2

countLeaves(c) = 1 (c is a leaf)

countLeaves(a) = 2 + 1 = 3

2. Count All Nodes

function countNodes(t: tree): integer; begin if t = nil then countNodes := 0 else countNodes := 1 + countNodes(t.left) + countNodes(t.right); end;
Trace: Count Nodes
a / \ b c / \ d e

countNodes(a) = 1 + countNodes(b) + countNodes(c)

countNodes(b) = 1 + countNodes(d) + countNodes(e) = 1 + 1 + 1 = 3

countNodes(c) = 1

countNodes(a) = 1 + 3 + 1 = 5

3. Count Internal Nodes

function countInternal(t: tree): integer; begin if t = nil then countInternal := 0 else if (t.left = nil) AND (t.right = nil) then countInternal := 0 // It's a leaf, not internal else countInternal := 1 + countInternal(t.left) + countInternal(t.right); end;
Alternative:
countInternal = countNodes - countLeaves
Internal nodes = Total nodes - Leaf nodes.

Computing Tree Properties

4. Compute Tree Height (Depth)

function treeHeight(t: tree): integer; begin if t = nil then treeHeight := -1 // or 0, depending on convention else treeHeight := 1 + max(treeHeight(t.left), treeHeight(t.right)); end;
Complexity:
Time: O(n), Space: O(h)
Must visit every node. Worst case: O(n) space for skewed tree.
Trace: Compute Height
a / \ b c / \ d e

treeHeight(d) = 1 + max(-1, -1) = 0

treeHeight(e) = 0

treeHeight(c) = 0

treeHeight(b) = 1 + max(0, 0) = 1

treeHeight(a) = 1 + max(1, 0) = 2

5. Count Nodes at Level k

function countAtLevel(t: tree, level: integer): integer; begin if t = nil then countAtLevel := 0 else if level = 0 then countAtLevel := 1 else countAtLevel := countAtLevel(t.left, level-1) + countAtLevel(t.right, level-1); end;
Trace: Count at Level 2
Level 0: a / \ Level 1: b c / \ Level 2: d e

countAtLevel(a, 2) = countAtLevel(b, 1) + countAtLevel(c, 1)

countAtLevel(b, 1) = countAtLevel(d, 0) + countAtLevel(e, 0) = 1 + 1 = 2

countAtLevel(c, 1) = 0 (c has no children)

countAtLevel(a, 2) = 2 + 0 = 2

6. Check if Balanced

function isBalanced(t: tree): boolean; begin if t = nil then isBalanced := true else leftH := treeHeight(t.left); rightH := treeHeight(t.right); isBalanced := (abs(leftH - rightH) <= 1) AND isBalanced(t.left) AND isBalanced(t.right); end;
⚠ This naive approach is O(n²) in worst case. An optimized O(n) approach computes height and checks balance in a single pass.

Copy Tree

Tree* copyTree(Tree* source) { Tree* temp; if (source != NULL) { temp = new(Tree); temp->data = source->data; temp->left = copyTree(source->left); temp->right = copyTree(source->right); return temp; } return NULL; }
Complexity:
Time: O(n), Space: O(h)
Creates a deep copy of the entire tree. Each node is visited once.
Trace: Copy Tree
Original: Copy: a a' / \ / \ b c b' c'

copyTree(a) → create node a' with data 'a'

copyTree(b) → create node b' with data 'b'

copyTree(c) → create node c' with data 'c'

Result: Independent copy with same structure and data

Tree Equality

bool isEqual(Tree* a, Tree* b) { if (a == NULL && b == NULL) return true; if (a != NULL && b != NULL && a->data == b->data && isEqual(a->left, b->left) && isEqual(a->right, b->right)) return true; return false; }
Equality Conditions:
Both empty OR (same data AND equal left subtrees AND equal right subtrees)
Structural equality: same shape AND same data at each node.
Example: Equality Check

Tree A

a / \ b c

Tree B (Equal)

a / \ b c

Tree C (Not Equal)

a / \ c b

isEqual(A, B) = true

isEqual(A, C) = false (different structure)

Mirror (Reverse) Tree

Tree* mirror(Tree* source) { Tree* temp; if (source != NULL) { temp = new(Tree); temp->left = mirror(source->right); // Swap! temp->right = mirror(source->left); // Swap! temp->data = source->data; return temp; } return NULL; }
Key Difference from Copy:
Left child ↔ Right child are SWAPPED
Creates a mirror image: left subtree becomes right and vice versa.
Note on Naming:
reverse() = mirror() = invert()
Different textbooks use different names for this operation. The PDF calls it "reverse" but it's the same as mirror/invert.
Example: Mirror Tree

Original

a / \ b c / \ d e

Mirror

a / \ c b / \ e d

The mirror swaps left and right at every level.

In-Place Mirror (Modifies Original)

void mirrorInPlace(Tree* node) { if (node == NULL) return; // Swap children Tree* temp = node->left; node->left = node->right; node->right = temp; // Recurse mirrorInPlace(node->left); mirrorInPlace(node->right); }
⚠ The first version (mirror) creates a NEW tree. The second version (mirrorInPlace) modifies the ORIGINAL tree in place. Know which one you need!

Other Useful Algorithms

Check if Binary Search Tree (BST)

bool isBST(Tree* node, int min, int max) { if (node == NULL) return true; if (node->data <= min || node->data >= max) return false; return isBST(node->left, min, node->data) && isBST(node->right, node->data, max); }

Find Lowest Common Ancestor (LCA)

Tree* findLCA(Tree* root, Tree* a, Tree* b) { if (root == NULL) return NULL; if (root == a || root == b) return root; Tree* left = findLCA(root->left, a, b); Tree* right = findLCA(root->right, a, b); if (left && right) return root; return left ? left : right; }

Worked Examples

Example 1: Count All Nodes
1 / \ 2 3 / \ \ 4 5 6

Solution:

countNodes(1) = 1 + countNodes(2) + countNodes(3)

countNodes(2) = 1 + countNodes(4) + countNodes(5) = 3

countNodes(3) = 1 + countNodes(nil) + countNodes(6) = 2

countNodes(1) = 1 + 3 + 2 = 6

Example 2: Compute Height
1 / \ 2 3 / \ 4 5 / 6

Solution:

treeHeight(6) = 0

treeHeight(4) = 1 + max(0, -1) = 1

treeHeight(2) = 1 + max(1, -1) = 2

treeHeight(5) = 0

treeHeight(3) = 1 + max(-1, 0) = 1

treeHeight(1) = 1 + max(2, 1) = 3

Example 3: Count Leaves
a / \ b c / / \ d e f

Solution:

Leaves: d, e, f

countLeaves = 3

Example 4: Mirror a Tree

Original tree:

1 / \ 2 3 / \ 4 5

Mirrored tree:

1 / \ 3 2 / \ 5 4
Example 5: Tree Equality

Tree A: [1, 2, 3], Tree B: [1, 3, 2]

isEqual(A, B) = false

Even though they have the same nodes, the structure is different!

Example 6: Function Call Count

For a tree with n nodes, how many times is countLeaves called?

Solution:

Each node is visited once, plus each NIL pointer causes a call.

For n nodes: n visits + (n+1) NIL pointers = 2n + 1 calls

Key Patterns

Base Case:
if (node == NULL) return appropriate value
All tree algorithms start with a base case for empty tree.
Recursive Case:
Combine results from left and right subtrees
Process current node, recurse on children, combine results.
