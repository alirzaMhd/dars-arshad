AVL Trees

Data Structures — Complete Guide for 20/20 Exam

What is an AVL Tree?

Definition:
AVL Tree is a self-balancing BST where the height difference between left and right subtrees of ANY node is at most 1
Named after Adelson-Velsky and Landis (inventors)
Balance Condition:
For every node x: |height(left[x]) - height(right[x])| ≤ 1
This is called the AVL property
Balanced vs Unbalanced
Balanced AVL Tree: Unbalanced (NOT AVL): 20 20 / \ / \ 10 30 10 30 / \ / 5 15 5 / 2

Left tree: All nodes have balance factor in {-1, 0, 1} → AVL

Right tree: Node 20 has balance factor = 2 → NOT AVL

Key Point: AVL trees guarantee O(lg n) height, which means ALL operations (search, insert, delete) are O(lg n).

Balance Factor

Balance Factor Formula:
BF(x) = height(left[x]) - height(right[x])
Can be -1, 0, or 1 for AVL trees
Balance Factor Values:
BF = 0: Left and right subtrees same height (perfectly balanced)
BF = 1: Left subtree one level taller (left-heavy)
BF = -1: Right subtree one level taller (right-heavy)
Any other value means the tree is NOT balanced
Example: Compute balance factors
20 (BF = 0) / \ 10 30 (BF = 0) / \ / \ 5 15 25 35 (BF=0)(BF=0)(BF=0)(BF=0)

All nodes have BF = 0 → Perfectly balanced AVL tree

Example: Tree with BF = -1
20 (BF = -1) / \ 10 30 (BF = 0) / \ / \ 5 15 25 35 \ 40 (BF = 0)

Node 20: height(left)=1, height(right)=2 → BF = -1

Still valid AVL! (BF is within {-1, 0, 1})

AVL Tree Height Properties

Minimum nodes for height h:
N(h) = N(h-1) + N(h-2) + 1
Where N(0) = 1, N(1) = 2
This is related to Fibonacci numbers:
N(h) = F(h+2) - 1
Where F is the Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8, 13, ...
Example: Minimum nodes for different heights
Height (h) Min Nodes N(h) Fibonacci F(h+2)
0 1 1
1 2 2
2 4 5
3 7 8
4 12 13
Maximum height of AVL tree with n nodes:
h < 1.44 × lg(n+2) - 0.328
This is approximately O(lg n)
Key Insight: AVL trees are ALWAYS approximately balanced. The height is guaranteed to be O(lg n), which ensures O(lg n) for all operations.

AVL Tree Examples

Example 1: Valid AVL tree with 7 nodes
20 (BF=0) / \ 10 30 (BF=0) / \ / \ 5 15 25 35 (0)(0)(0)(0)

Height = 2, all BFs in {-1, 0, 1} → Valid AVL

Minimum nodes for h=2: N(2) = 4 ✓ (we have 7 ≥ 4)

Example 2: Invalid AVL tree
20 (BF=2) ← NOT AVL! / \ 10 30 / 5 / 2

Node 20: height(left)=3, height(right)=1 → BF = 2

NOT valid AVL! Needs rotation to fix.

Example 3: How many AVL trees with 4 nodes?

For n=4 distinct keys, there are 4 different AVL trees

All have height = 2 (minimum possible for 4 nodes)
