Finding Minimum & Maximum in BST

Data Structures — Complete Guide for 20/20 Exam

Find Minimum Element

MINIMUM(x) while left[x] ≠ NIL x = left[x] return x
Key Insight:
Minimum is the leftmost node in BST
Keep going left until you can't go anymore. The last node is the minimum.
Visual Example
20 / \ 10 30 / \ / \ 5 15 25 35 / 2

Start at 20 → go left to 10 → go left to 5 → go left to 2 → left is NIL

Minimum = 2

Important: In a BST, the minimum element has NO left child. It's always a leaf node (or the root if tree has only one node).

Find Maximum Element

MAXIMUM(x) while right[x] ≠ NIL x = right[x] return x
Key Insight:
Maximum is the rightmost node in BST
Keep going right until you can't go anymore. The last node is the maximum.
Visual Example
20 / \ 10 30 / \ / \ 5 15 25 35 \ 40

Start at 20 → go right to 30 → go right to 35 → go right to 40 → right is NIL

Maximum = 40

Important: In a BST, the maximum element has NO right child. It's always a leaf node (or the root if tree has only one node).

Trace Examples

Example 1: Find min and max
30 / \ 20 40 / \ / \ 10 25 35 50 / \ 5 15

MINIMUM: 30 → 20 → 10 → 5 (left is NIL) → min = 5

MAXIMUM: 30 → 40 → 50 (right is NIL) → max = 50

Example 2: Single node tree
15

MINIMUM: 15 (left is NIL) → min = 15

MAXIMUM: 15 (right is NIL) → max = 15

When tree has only one node, it's both min and max!

Example 3: Skewed tree
10 \ 20 \ 30 \ 40

MINIMUM: 10 (left is NIL) → min = 10

MAXIMUM: 10 → 20 → 30 → 40 (right is NIL) → max = 40

Time & Space Complexity

Best Case

Time: O(1)

When min/max is at root

Average Case

Time: O(lg n)

When tree is balanced

Worst Case

Time: O(n)

When tree is skewed

Space

Iterative: O(1)

Recursive: O(h)

Complexity Formula:
Time = O(h), where h = height of tree
The algorithm traverses one path from root to leaf
Key Insight: Finding min/max takes O(h) time, which is O(lg n) for balanced trees but O(n) for skewed trees. This is why balanced BSTs are important!

Quick Reference Card

MINIMUM Algorithm

MINIMUM(x) while left[x] ≠ NIL x = left[x] return x

Go LEFT until NIL

MAXIMUM Algorithm

MAXIMUM(x) while right[x] ≠ NIL x = right[x] return x

Go RIGHT until NIL

Key Properties

• Minimum: leftmost node

• Maximum: rightmost node

• Both are leaf nodes (usually)

Time Complexity

• All cases: O(h)

• h = height of tree

• O(lg n) balanced, O(n) skewed
