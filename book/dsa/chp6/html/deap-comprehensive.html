DEAP (Double-Ended Heap)

Data Structures — Complete Exam-Ready Guide

1. What is a Deap?

A deap (double-ended heap) is a complete binary tree data structure that supports efficient find-min, find-max, insert, delete-min, and delete-max operations.

Key Structural Property

The root node is always empty. No key is ever stored at index 1 (the root). The deap stores n elements using an array of size n+1, where index 0 is unused and index 1 is the empty root.

Complete Binary Tree Structure

A deap is a complete binary tree of height h. The tree is divided into two subtrees:

  • Left Subtree — A min-heap (minimum values)
  • Right Subtree — A max-heap (maximum values)
[ ] (root, always empty)

2. Correspondence Between Nodes

The deap maintains a correspondence between nodes in the left (min) subtree and nodes in the right (max) subtree. This is the key invariant that enables all operations.

Correspondence Formula

Given index i in the left subtree (min-heap):
j = 2⌊lg i⌋ + 1 + i - 1
Where j is the corresponding index in the right subtree (max-heap), and lg denotes log base 2.
Inverse: Given index j in the right subtree (max-heap):
i = j - 2⌊lg j⌋ + 1 + 1
Where i is the corresponding index in the left subtree (min-heap).

Why This Correspondence?

The correspondence pairs nodes that are at the same depth in their respective subtrees. For a node at position i in the left subtree, its corresponding node j in the right subtree is at the same level. The deap invariant requires:

Deap Invariant:
min-heap[i] ≤ max-heap[j]
Every element in the left (min) subtree must be ≤ every element in the right (max) subtree. The correspondent of each left-node must satisfy this ordering.

4. Finding the Minimum — O(1)

The minimum element is always at the root of the left (min) subtree.

Find-Min:
return array[2]
The root of the min-heap is always at index 2. This is O(1) since no search is needed.

Key Point

• The left subtree root (index 2) holds the global minimum

• This is because the min-heap property ensures the root of any min-heap is its smallest element

Time Complexity

Find-Min: O(1)

Space: O(1)

5. Finding the Maximum — O(1)

The maximum element is always at the root of the right (max) subtree.

Find-Max:
return array[3]
The root of the max-heap is always at index 3. This is O(1) since no search is needed.

Key Point

• The right subtree root (index 3) holds the global maximum

• The max-heap property ensures the root of any max-heap is its largest element

Time Complexity

Find-Max: O(1)

Space: O(1)

Important Note

Unlike a regular heap, the deap provides O(1) access to both min AND max. A standard binary heap only gives O(1) access to one extreme.

7. Insert Operation — O(lg n)

Inserting a new element into a deap involves placing it at the next available position and then restoring the deap invariant.

Insert Algorithm (Pseudocode)

function DEAP-INSERT(deap, key): // Step 1: Place key at next available position n = n + 1 array[n] = key // Step 2: Find which subtree it belongs to if n is in the left subtree (min-heap): // Compare with its correspondent in right subtree j = correspondent(n) if j exists and array[n] > array[j]: swap(array[n], array[j]) BUBBLE-DOWN-MAX(j) // fix max-heap else: BUBBLE-DOWN-MIN(n) // fix min-heap else: // n is in the right subtree (max-heap) // Compare with its correspondent in left subtree i = inverse-correspondent(n) if i exists and array[n] < array[i]: swap(array[n], array[i]) BUBBLE-DOWN-MIN(i) // fix min-heap else: BUBBLE-DOWN-MAX(n) // fix max-heap

Helper: Bubble Down in Min-Heap

function BUBBLE-DOWN-MIN(i): while i has children: smallest = i if left_child(i) ≤ n and array[left_child(i)] < array[smallest]: smallest = left_child(i) if right_child(i) ≤ n and array[right_child(i)] < array[smallest]: smallest = right_child(i) if smallest ≠ i: swap(array[i], array[smallest]) i = smallest else: break

Helper: Bubble Down in Max-Heap

function BUBBLE-DOWN-MAX(i): while i has children: largest = i if left_child(i) ≤ n and array[left_child(i)] > array[largest]: largest = left_child(i) if right_child(i) ≤ n and array[right_child(i)] > array[largest]: largest = right_child(i) if largest ≠ i: swap(array[i], array[largest]) i = largest else: break
Critical Step

When inserting at position n, always check the correspondence first. The new element might violate the deap invariant with its correspondent, requiring a swap before the standard heap bubble-down.

8. Delete-Min Operation — O(lg n)

Remove the minimum element (at index 2) and restore the deap invariant.

Delete-Min Algorithm (Pseudocode)

function DEAP-DELETE-MIN(deap): // Step 1: Save the minimum min_val = array[2] // Step 2: Move last element to position 2 array[2] = array[n] n = n - 1 // Step 3: If tree is now empty or has only root, done if n < 2: return min_val // Step 4: Check if element now at position 2 belongs in right subtree if 2 is in the right subtree range: // The element came from the right side; find its correct left position i = find-correct-left-position(array[2]) swap(array[2], array[i]) BUBBLE-DOWN-MAX(2) else: // Standard: bubble down in min-heap BUBBLE-DOWN-MIN(2) // Step 5: Fix correspondence invariant FIX-CORRESPONDENCE() return min_val
After Delete-Min

When the last element replaces the deleted min, it may not belong in the min-heap. Check whether it should be moved to the max-heap by testing the correspondence. If violated, swap with the correspondent and fix both heaps.

9. Delete-Max Operation — O(lg n)

Remove the maximum element (at index 3) and restore the deap invariant.

Delete-Max Algorithm (Pseudocode)

function DEAP-DELETE-MAX(deap): // Step 1: Save the maximum max_val = array[3] // Step 2: Move last element to position 3 array[3] = array[n] n = n - 1 // Step 3: If tree is now small, done if n < 3: return max_val // Step 4: Check if element now at position 3 belongs in left subtree if 3 is in the left subtree range: // The element came from the left side; find its correct right position j = find-correct-right-position(array[3]) swap(array[3], array[j]) BUBBLE-DOWN-MIN(3) else: // Standard: bubble down in max-heap BUBBLE-DOWN-MAX(3) // Step 5: Fix correspondence invariant FIX-CORRESPONDENCE() return max_val

Delete-Min

• Removes from index 2

• Replaces with last element

• Bubbles down in min-heap

• Fixes correspondence

Delete-Max

• Removes from index 3

• Replaces with last element

• Bubbles down in max-heap

• Fixes correspondence

10. Worked Example 1: Building a Deap by Insertion

Insert the sequence: 10, 5, 20, 3, 15, 25, 8 into an empty deap.

Step-by-Step Insertion

Insert 10 (n=1 → index 2, left subtree)

  [ ]
  /
[10]

No correspondent yet (right subtree empty). Done. Array: [_, 10]

Insert 5 (n=2 → index 3, right subtree)

    [ ]
   /    \
[10]  [5]

Correspondent of index 3 (right) is index 2 (left). 5 < 10, so swap: array becomes [_, 5, 10]

Fix min-heap (index 2): 5 has no children. Fix max-heap (index 3): 10 has no children. Done.

Insert 20 (n=3 → index 4, left subtree)

      [ ]
     /    \
  [5]    [10]
  /
[20]

Correspondent of 4 (left) is j = 2⌊lg 4⌋+1 + 4 - 1 = 23 + 3 = 11. Index 11 doesn't exist yet. Bubble down in min-heap: 20 > 5 (parent), done. Array: [_, 5, 10, 20]

Insert 3 (n=4 → index 5, right subtree)

      [ ]
     /    \
  [5]    [10]
  / \     /
[20][3]

Correspondent of 5 (right) is i = 5 - 2⌊lg 5⌋+1 + 1 = 5 - 8 + 1 = -2 (invalid, so use left child of root). Actually, inverse: i = 5 - 23 + 1 = -2. Try parent: correspondent of position 5 in right is position 2 in left. 3 < 5, so swap: array becomes [_, 3, 10, 20, 5]

Fix min-heap at index 2: 3 < 10 (parent). Fix max-heap at index 5: 5 < 10 (parent). Done.

Insert 15 (n=5 → index 6, left subtree)

Correspondent of 6 (left): j = 2⌊lg 6⌋+1 + 6 - 1 = 23 + 5 = 13. Doesn't exist. Bubble down in min-heap: 15 > 3, done. Array: [_, 3, 10, 20, 5, 15]

Insert 25 (n=6 → index 7, right subtree)

Correspondent: i = 7 - 2⌊lg 7⌋+1 + 1 = 7 - 16 + 1 = -8. Use index 2. 25 > 3, OK. Bubble down in max-heap: 25 > 10, done. Array: [_, 3, 10, 20, 5, 15, 25]

Insert 8 (n=7 → index 8, left subtree)

Correspondent of 8 (left): j = 2⌊lg 8⌋+1 + 8 - 1 = 24 + 7 = 23. Doesn't exist. Bubble down in min-heap: 8 > 10? No, 8 < 10. Swap with parent. 8 > 3 (root). Done. Array: [_, 3, 8, 20, 5, 15, 25, _, _, _, _, _, _, _, _, _, _, _, _, _, _, _, _, 10]

Final Deap

           [ ]
          /       \
     [ 3 ]       [ 25 ]
     /    \       /     \
 [ 8 ]  [15 ] [ 20 ] [ 10 ]
 / \     /
[5] [20]

Min-heap: 3, 8, 15, 5, 20 — root is 3 (global min)

Max-heap: 25, 20, 10 — root is 25 (global max)

Verify deap invariant: every element in left ≤ every element in right. 20 (max of left) ≤ 25 (max of right) ✓

11. Worked Example 2: Delete-Min

Starting from the deap in Example 1, delete the minimum.

Delete-Min from Deap

Before:

           [ ]
          /       \
     [ 3 ]       [ 25 ]
     /    \       /     \
 [ 8 ]  [15 ] [ 20 ] [ 10 ]
 / \     /
[5] [20]
  1. Save min: min_val = 3 (at index 2)
  2. Replace with last: Move 20 (last element) to index 2. n becomes 7.
  3. Check position 2: 2 is in left subtree. Standard bubble-down in min-heap.
  4. Bubble-down min at index 2: Compare 20 with children (8, 15). Swap with smaller child (8). Now at index 4.
  5. Continue bubble-down: Compare 20 with children (5). 20 > 5, swap. Now at index 8. No children. Done.
  6. Verify correspondence: Check all left-right pairs still satisfy deap invariant.

After:

           [ ]
          /       \
     [ 5 ]       [ 25 ]
     /    \       /     \
 [ 8 ]  [15 ] [ 20 ] [ 10 ]
   \
   [20]

Returned: 3

The new minimum is 5 (at index 2). The max is still 25 (at index 3).

14. Deap vs Min-Max Heap Comparison

Both data structures support efficient dual-priority operations, but they differ in structure and implementation.

Feature Deap Min-Max Heap
Structure Two separate subtrees (min-heap + max-heap) Single alternating-level heap
Root Always empty Contains the minimum
Min location Root of left subtree (index 2) Root (index 1)
Max location Root of right subtree (index 3) Child of root (index 2 or 3)
Find-Min O(1) O(1)
Find-Max O(1) O(1)
Insert O(lg n) O(lg n)
Delete-Min O(lg n) O(lg n)
Delete-Max O(lg n) O(lg n)
Array size n + 1 (index 0 unused, index 1 empty) n + 1 (index 0 unused)
Correspondence Explicit left-right pairing formula Level-based alternating min/max
Implementation More complex correspondence tracking Simpler level-based logic
Key Invariant min-heap[i] ≤ max-heap[j] for all correspondents min at even levels, max at odd levels
Advantage Clean separation of min/max concerns Single unified structure
Exam Tip: Key Difference

The deap's defining feature is its empty root and the correspondence formula j = 2⌊lg i⌋+1 + i - 1. A min-max heap uses alternating levels (min at even depth, max at odd depth) with a single root holding the minimum.

15. When to Use Deap

Use Deap When

• You need both min and max access

• You want clean separation of min/max heaps

• Priority queue with dual-ended access

• Scheduling with min and max priorities

Use Min-Max Heap When

• Simpler implementation is preferred

• Single unified structure is easier to reason about

• Level-based logic is more intuitive

• Less concern about correspondence tracking

16. Quick Reference Card

Deap Properties

  • Type: Complete binary tree
  • Structure: Left subtree = min-heap, Right subtree = max-heap
  • Root: Always empty (index 1 unused for data)
  • Min element: array[2]
  • Max element: array[3]
  • Storage: Array of size n+1

Core Formulas

Correspondence (left → right):
j = 2⌊lg i⌋ + 1 + i - 1
Inverse correspondence (right → left):
i = j - 2⌊lg j⌋ + 1 + 1
Deap invariant:
array[left[i]] ≤ array[right[j]]
For every correspondent pair (i, j)

Operation Summary

  • Find-Min: return array[2] — O(1)
  • Find-Max: return array[3] — O(1)
  • Insert: place at end, compare with correspondent, swap if needed, bubble down — O(lg n)
  • Delete-Min: remove array[2], replace with last, bubble down, fix correspondence — O(lg n)
  • Delete-Max: remove array[3], replace with last, bubble down, fix correspondence — O(lg n)

Common Mistakes (Exam Warnings)

  • Don't store anything at index 1 — the root is always empty
  • Don't forget the correspondence check on insert — a new element might violate the invariant with its correspondent
  • Don't skip the correspondence fix on delete — after replacing with the last element, check if it belongs in the other subtree
  • Don't confuse deap with min-max heap — deap has TWO subtrees; min-max heap has alternating levels
  • Remember lg = log base 2 — in formulas, lg means log2
