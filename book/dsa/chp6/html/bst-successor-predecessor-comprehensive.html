Successor & Predecessor in BST

Data Structures — Complete Guide for 20/20 Exam

Definitions

Successor of x:
succ(x) = the smallest key greater than x
The node that comes immediately AFTER x in inorder traversal
Predecessor of x:
pred(x) = the largest key smaller than x
The node that comes immediately BEFORE x in inorder traversal
Visual Example
20 / \ 10 30 / \ / \ 5 15 25 35

Inorder traversal: 5 → 10 → 15 → 20 → 25 → 30 → 35

• succ(10) = 15, pred(10) = 5

• succ(20) = 25, pred(20) = 15

• succ(35) = NIL, pred(35) = 30

Key Point: Successor and predecessor always exist in inorder traversal. The only exceptions are: minimum has no predecessor, maximum has no successor.

Successor Algorithm

SUCC(x) if right[x] ≠ NIL return MINIMUM(right[x]) y = parent[x] while y ≠ NIL and x = right[y] x = y y = parent[y] return y
Two Cases:
Case 1: x has right subtree → min of right subtree
If right child exists, successor is the minimum in right subtree
Case 2: x has no right subtree
Go up until we find a node whose left child is in the path
Traverse up the tree until we find an ancestor where x is in its left subtree
Example: Find successor of 15
20 / \ 10 30 / \ / \ 5 15 25 35

Case 1: 15 has no right child → use Case 2

Go up: 15 → parent is 10 → 15 is right child of 10

Go up: 10 → parent is 20 → 10 is left child of 20

Stop! 20 is the successor → succ(15) = 20

Predecessor Algorithm

PRED(x) if left[x] ≠ NIL return MAXIMUM(left[x]) y = parent[x] while y ≠ NIL and x = left[y] x = y y = parent[y] return y
Two Cases:
Case 1: x has left subtree → max of left subtree
If left child exists, predecessor is the maximum in left subtree
Case 2: x has no left subtree
Go up until we find a node whose right child is in the path
Traverse up the tree until we find an ancestor where x is in its right subtree
Example: Find predecessor of 25
20 / \ 10 30 / \ / \ 5 15 25 35

Case 1: 25 has no left child → use Case 2

Go up: 25 → parent is 30 → 25 is left child of 30

Stop! 30 is NOT the predecessor because 25 is left child

Continue: 30 → parent is 20 → 30 is right child of 20

Stop! 20 is the predecessor → pred(25) = 20

Quick Reference Card

Successor Algorithm

if right[x] ≠ NIL return MINIMUM(right[x]) y = parent[x] while y ≠ NIL and x = right[y] x = y; y = parent[y] return y

Predecessor Algorithm

if left[x] ≠ NIL return MAXIMUM(left[x]) y = parent[x] while y ≠ NIL and x = left[y] x = y; y = parent[y] return y

Key Properties

• Successor: smallest > x

• Predecessor: largest < x

• Both are O(h) time

Special Cases

• Min has no predecessor

• Max has no successor

• Single node: both are NIL
