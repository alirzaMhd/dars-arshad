BST Deletion Algorithm

Data Structures — Complete Guide for 20/20 Exam

Three Cases of Deletion

TRANSPLANT(T, u, v) if parent[u] = NIL root[T] = v else if u = left[parent[u]] left[parent[u]] = v else right[parent[u]] = v if v ≠ NIL parent[v] = parent[u] DELETE(T, z) if left[z] = NIL TRANSPLANT(T, z, right[z]) else if right[z] = NIL TRANSPLANT(T, z, left[z]) else y = MINIMUM(right[z]) if parent[y] ≠ z TRANSPLANT(T, y, right[y]) right[y] = right[z] parent[right[y]] = y TRANSPLANT(T, z, y) left[y] = left[z] parent[left[y]] = y
Three Cases:
Case 1: No children (leaf) → simply remove
Case 2: One child → replace with child
Case 3: Two children → replace with successor
The tricky part is Case 3 where we need to find the in-order successor
Important: Deletion is NOT commutative! Deleting nodes in different orders can result in different final trees.

Case 1: Deleting a Leaf Node

When to use:
Node has NO children (left and right are both NIL)
Simply remove the node by setting parent's pointer to NIL
Example: Delete node 5 (leaf)
Before: After: 20 20 / \ / \ 10 30 10 30 / \ / \ \ / \ 5 15 25 35 15 25 35

Step 1: Find node 5

Step 2: 5 has no children → leaf node

Step 3: Set parent[10]'s left pointer to NIL

Result: Node 5 removed, tree remains valid BST

Example: Delete node 35 (leaf)
Before: After: 20 20 / \ / \ 10 30 10 30 / \ / \ / \ / 5 15 25 35 5 15 25

Step 1: Find node 35

Step 2: 35 has no children → leaf node

Step 3: Set parent[30]'s right pointer to NIL

Result: Node 35 removed

Case 2: Deleting Node with One Child

When to use:
Node has EXACTLY one child (left or right)
Replace the node with its child (like bypassing the node)
Example: Delete node 10 (has left child only)
Before: After: 20 20 / \ / \ 10 30 5 30 / \ / \ / \ 5 15 25 35 15 25 35

Step 1: Find node 10

Step 2: 10 has only left child (5)

Step 3: Replace 10 with 5 (bypass)

Result: Node 10 removed, 5 becomes left child of 20

Example: Delete node 30 (has two children)

This is Case 3 - see next tab!

Case 3: Deleting Node with Two Children

When to use:
Node has BOTH left and right children
1. Find in-order successor (smallest in right subtree)
2. Replace node's key with successor's key
3. Delete the successor (which has at most one child)
Example: Delete node 20 (has two children)
Before: 20 / \ 10 30 / \ / \ 5 15 25 35 Step 1: Find successor of 20 → MINIMUM(right[20]) = MINIMUM(30) = 25 Step 2: Copy 25 to node 20's position Step 3: Delete node 25 (which is a leaf) After: 25 / \ 10 30 / \ \ 5 15 35

Result: Node 20 replaced by its successor 25

Alternative: Using Predecessor

Instead of successor, we could use the predecessor (largest in left subtree).

pred(20) = MAXIMUM(left[20]) = MAXIMUM(10) = 15

Replace 20 with 15, then delete the original 15 node.

Both methods are valid! The choice depends on implementation.

Key Insight: When deleting a node with two children, we always replace it with either its successor or predecessor. This ensures the BST property is maintained.

Quick Reference Card

Case 1: Leaf

• No children

• Simply remove

• O(1) operation

Case 2: One Child

• Has left OR right child

• Replace with child

• O(1) operation

Case 3: Two Children

• Has both children

• Replace with successor/predecessor

• O(h) operation

Time Complexity

• Search: O(h)

• Delete: O(h)

• Total: O(h)

Key Properties

• BST property preserved

• Inorder remains sorted

• Deletion order matters

Remember: For Case 3, always use the in-order successor (MINIMUM of right subtree) or in-order predecessor (MAXIMUM of left subtree). Never use a random node!
