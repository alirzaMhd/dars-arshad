Array Implementation

Structure:
struct Stack { Type items[MAX_SIZE]; int top; } // Initialize void Init(Stack &s): s.top = -1 // Push void Push(Stack &s, Type x): if s.top == MAX_SIZE - 1: print("Stack Overflow") return s.top++ s.items[s.top] = x // Pop Type Pop(Stack &s): if s.top == -1: print("Stack Underflow") return null Type x = s.items[s.top] s.top-- return x
Step-by-Step
OperationtopStack Content

Push(10)0[10]
Push(20)1[10, 20]
Push(30)2[10, 20, 30]
Pop()1[10, 20] → returns 30
Top()1[10, 20] → returns 20

Advantages

• Simple implementation

• No memory overhead

• Cache friendly

Disadvantages

• Fixed size (MAX_SIZE)

• Wasted space if not full

• Cannot grow dynamically

Linked List Implementation

Structure:
struct Node { Type data; Node* next; } // Push void Push(Node* &top, Type x): Node* newNode = new Node(x) newNode.next = top top = newNode // Pop Type Pop(Node* &top): if top == NULL: print("Stack Underflow") return null Node* temp = top Type x = temp->data top = top->next delete temp return x
Visual

Push(10), Push(20), Push(30):

TOP → [30|→] → [20|→] → [10|→] → NULL

Pop(): TOP → [20|→] → [10|→] → NULL

Advantages

• Dynamic size

• No overflow

• Memory efficient

Disadvantages

• Extra pointer memory

• Not cache friendly

• slower than array

Multiple Stacks in One Array

Problem:
Store k stacks in a single array of size n
Stack 1 grows left→right, Stack 2 grows right←left
Two Stacks
// Two stacks in one array struct TwoStacks { Type items[n]; int top1; // Stack 1 top (grows right) int top2; // Stack 2 top (grows left) } // Initialize top1 = -1 top2 = n // Push to Stack 1 void Push1(Type x): if top1 + 1 == top2: print("Overflow") return top1++ items[top1] = x // Push to Stack 2 void Push2(Type x): if top1 + 1 == top2: print("Overflow") return top2-- items[top2] = x

⚠ Key Point:

Overflow occurs when top1 + 1 == top2

This is more efficient than two separate arrays!

⚠ Exam Tips:

• Stack Overflow: push to full stack

• Stack Underflow: pop from empty stack

• Catalan: remember C(n) = C(2n,n)/(n+1)

• Two stacks: overflow when tops meet
