DIRECT ADDRESSING

Data Structures — Complete Guide for 20/20 Exam

What is Direct Addressing?

Direct addressing is a simple technique used when the universe of keys is small. Each key maps directly to a slot in a table (array) using the key itself as the index.

Key Mapping:
T[key] = element
The key itself is used as the index into the table T
Key Universe:
U = {0, 1, ..., m-1}
U is the set of all possible keys, m is the size of the universe
Direct addressing is only practical when the key universe U is small enough to fit in memory.
Example: Student ID System

Suppose student IDs range from 0 to 999. We can create a table T of size 1000 where:

• T[425] stores the record of student with ID 425

• T[0] stores the record of student with ID 0

• T[999] stores the record of student with ID 999

Basic Operations

Insert Operation

Insert(T, key, value): T[key] = value

Simply store the value at the index equal to the key.

Search Operation

Search(T, key): return T[key]

Return the value stored at index equal to the key.

Delete Operation

Delete(T, key): T[key] = NIL

Set the slot at index equal to key to NIL (empty).

Example: Operations on Small Key Set

Universe U = {0, 1, 2, ..., 9}

Keys in our collection: {2, 3, 5, 8}

Insert(2, "Apple"), Insert(5, "Banana"), Insert(8, "Cherry")

Search(5) → "Banana"

Delete(3) → T[3] = NIL

Worked Examples

Example 1: Character Frequency Counter

Count frequency of characters in "HELLO WORLD"

Universe U = {A, B, ..., Z} (26 characters)

Create table T[26], initialize all to 0

For each character c: T[c]++

T[H]=1, T[E]=1, T[L]=3, T[O]=2, T[W]=1, T[R]=1, T[D]=1

Example 2: Boolean Membership

Check if numbers {1, 4, 7, 9} are in the set

Universe U = {0, 1, ..., 10}

Create boolean table T[11]

Insert: T[1]=true, T[4]=true, T[7]=true, T[9]=true

Search(4) → true (in set)

Search(5) → false (not in set)

Example 3: Grade Storage

Store grades for 5 students (IDs: 101-105)

Universe U = {101, 102, 103, 104, 105}

T[101]=85, T[102]=92, T[103]=78, T[104]=95, T[105]=88

Search(103) → 78

Average = (85+92+78+95+88)/5 = 87.6

Example 4: ASCII Value Lookup

Create lookup table for ASCII values 0-127

T[65] = 'A', T[97] = 'a', T[48] = '0'

Search(65) → 'A'

Search(32) → ' ' (space)

Example 5: Day of Week

Map day numbers to names (0=Sunday, 1=Monday, ..., 6=Saturday)

T[0]="Sunday", T[1]="Monday", ..., T[6]="Saturday"

Search(3) → "Wednesday"

Complexity Analysis

Time Complexity

Insert: O(1)

Search: O(1)

Delete: O(1)

Space Complexity

Table Size: O(|U|)

Where |U| is universe size

Key Insight:
All operations are O(1)
Direct addressing provides constant time for all basic operations

Comparison with Other Methods

Method Insert Search Delete Space
Direct Addressing O(1) O(1) O(1) O(|U|)
Hash Table O(1) avg O(1) avg O(1) avg O(n)
Binary Search Tree O(log n) O(log n) O(log n) O(n)
When |U| is much larger than the number of keys actually stored, direct addressing wastes space. Use hash tables instead.
