Matrix Multiplication Algorithm

Formula:
C[i,j] = Σ (A[i,k] × B[k,j]) for k = 1 to n
If A is m×n and B is n×p, result C is m×p
Algorithm Steps
for i = 1 to m: for j = 1 to p: C[i,j] = 0 for k = 1 to n: C[i,j] = C[i,j] + A[i,k] × B[k,j]

Requirements

• A must be m × n

• B must be n × p

• Inner dimensions must match!

Result

• C will be m × p

• Each element needs n multiplications

• Total: m × p × n multiplications

Time Complexity Analysis

Basic Algorithm

Time = O(m × n × p)
For square matrices: O(n³)

Space Complexity

Space = O(m × p)
For storing result matrix C
Complexity Comparison
OperationTimeSpace
Matrix AdditionO(n²)O(n²)
Matrix TransposeO(n²)O(n²)

⚠ Key Point: Matrix multiplication is expensive!

For n=1000, that's 1 billion operations (10⁹)

Matrix Chain Multiplication

Problem:
Given A₁ × A₂ × ... × Aₙ, find optimal parenthesization
Different parenthesizations can have vastly different costs!
Example: 4 Matrices

A₁ (10×30), A₂ (30×5), A₃ (5×60), A₄ (60×10)

Parenthesization 1

((A₁ × A₂) × A₃) × A₄

Cost: 10×30×5 + 10×5×60 + 10×60×10

Cost: 1500 + 3000 + 6000 = 10,500

Parenthesization 2

A₁ × (A₂ × (A₃ × A₄))

Cost: 30×5×60 + 30×60×10 + 10×30×10

Cost: 9000 + 18000 + 3000 = 30,000

Optimal

(A₁ × (A₂ × A₃)) × A₄

Cost: 30×5×60 + 10×30×60 + 10×60×10

Cost: 9000 + 18000 + 6000 = 33,000

Dynamic Programming Solution
// m[i,j] = minimum cost to multiply A[i..j] // s[i,j] = split point for optimal solution for len = 2 to n: for i = 1 to n-len+1: j = i + len - 1 m[i,j] = INFINITY for k = i to j-1: q = m[i,k] + m[k+1,j] + p[i-1]*p[k]*p[j] if q < m[i,j]: m[i,j] = q s[i,j] = k

Time Complexity

O(n³)
Using dynamic programming

Space Complexity

O(n²)
For storing m and s tables

⚠ Catalan Numbers:

Number of ways to parenthesize n matrices = C(n-1)

C(n) = (2n)! / ((n+1)! × n!)

For n=4 matrices: C(3) = 5 different parenthesizations

Solved Examples (Exam Practice)

Example 1: Basic Multiplication

A = [1 2; 3 4], B = [5 6; 7 8]

C[1,1] = 1×5 + 2×7 = 5 + 14 = 19

C[1,2] = 1×6 + 2×8 = 6 + 16 = 22

C[2,1] = 3×5 + 4×7 = 15 + 28 = 43

C[2,2] = 3×6 + 4×8 = 18 + 32 = 50

Result: C = [19 22; 43 50]

Example 2: Dimensions Check

A is 3×4, B is 4×2, C is 2×5

(A × B) × C = (3×4) × (4×2) × (2×5)

Option 1: (3×4×2) + (3×2×5) = 24 + 30 = 54

A × (B × C) = (3×4) × (4×2) × (2×5)

Option 2: (4×2×5) + (3×4×5) = 40 + 60 = 100

Option 1 is better! Parenthesization matters.

Example 3: Chain Multiplication

Dimensions: [10, 30, 5, 60]

Matrices: A₁(10×30), A₂(30×5), A₃(5×60)

Option 1: (A₁×A₂)×A₃ = 10×30×5 + 10×5×60 = 1500 + 3000 = 4500

Option 2: A₁×(A₂×A₃) = 30×5×60 + 10×30×60 = 9000 + 18000 = 27000

Optimal: Option 1
