Sparse Matrix Representation

Definition:
A matrix is sparse if most elements are zero
Store only non-zero elements to save memory
Triplet Representation

Each non-zero element stored as: (row, col, value)

Plus header: (total_rows, total_cols, total_nonzeros)

Naive Transpose Algorithm

Algorithm:
for col = 0 to total_cols-1: for each element (row, col, value) in original: if element's column == col: add (col, row, value) to result

Time Complexity

O(cols × nonzeros)
Must scan all elements for each column

Space Complexity

O(nonzeros)
For storing transposed matrix

Fast Transpose Algorithm

Key Insight:
Use row/column counts to find exact positions
1. Count elements in each column 2. Compute starting positions 3. Place elements directly
Algorithm Steps
// Step 1: Count elements in each column for i = 0 to numTerms-1: colCounts[original[i].col]++ // Step 2: Compute starting positions rowStarts[0] = 0 for i = 1 to total_cols: rowStarts[i] = rowStarts[i-1] + colCounts[i-1] // Step 3: Place elements for i = 0 to numTerms-1: pos = rowStarts[original[i].col]++ result[pos] = (original[i].col, original[i].row, original[i].value)

Polynomial Representation

Using Sparse Matrix:
P(x) = a₀ + a₁x + a₂x² + ... + aₙxⁿ
Each term (coefficient, exponent) is a non-zero element
Example: Polynomial

P(x) = 3x⁴ + 5x³ + 2x + 7

Addition of Polynomials

P1 = 3x² + 5x + 2

P2 = 4x² + 2x + 7

Result = (3+4)x² + (5+2)x + (2+7) = 7x² + 7x + 9

// Algorithm while (p1 != null and p2 != null): if p1.exp == p2.exp: sum = p1.coeff + p2.coeff if sum != 0: insert(sum, p1.exp) p1 = p1.next; p2 = p2.next elif p1.exp > p2.exp: insert(p1.coeff, p1.exp) p1 = p1.next else: insert(p2.coeff, p2.exp) p2 = p2.next
