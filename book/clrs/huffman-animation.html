Problem Setup

Huffman Coding is a greedy algorithm for lossless data compression. It assigns variable-length codes to characters based on their frequencies — more frequent characters get shorter codes.

Input characters with frequencies:

A: 5, B: 9, C: 12, D: 13, E: 16, F: 45 (total: 100)

Algorithm

1. Create a leaf node for each character, weighted by frequency

2. Repeatedly pick the two nodes with smallest frequency

3. Merge them into a new internal node whose frequency = sum of the two

4. Repeat until only one node remains — the root of the Huffman tree

Key Property

Optimal prefix code: no code is a prefix of another code
