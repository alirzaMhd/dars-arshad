Component Graph Concept

A component graph GSCC = (VSCC, ESCC) is formed from a directed graph G = (V, E) by:

• VSCC: one vertex per strongly connected component

• ESCC: edge (Ci, Cj) if there is an edge from any vertex in Ci to any vertex in Cj in G

The Critical Property

GSCC is always a directed acyclic graph (DAG).

If there were a cycle in GSCC, all vertices on that cycle would be mutually reachable → they'd belong to one SCC. Contradiction.
