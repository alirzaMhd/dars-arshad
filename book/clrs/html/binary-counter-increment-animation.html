Problem Setup

INCREMENT(A, k): Add 1 to a k-bit binary counter stored in array A[0..k-1] (A[0] = LSB).

Pseudocode

INCREMENT(A, k):   i = 0   while i < k and A[i] == 1:     A[i] = 0     i = i + 1   if i < k:     A[i] = 1

Key Insight

Cost = tᵢ + 1 where tᵢ = number of trailing 1s.
