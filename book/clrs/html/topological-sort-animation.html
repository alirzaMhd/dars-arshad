What is a DAG?

A Directed Acyclic Graph (DAG) is a directed graph with no cycles.

In a DAG, edges flow in one direction — you can never return to a vertex by following edges.

Topological Sort

A topological ordering of a DAG is a linear ordering of its vertices such that for every directed edge u → v, vertex u comes before v in the ordering.

DFS-based Algorithm

Run DFS on the graph. When a vertex finishes (turns black), prepend it to the result. The final order is the reverse of finish times.

• If DFS finds a back edge, the graph has a cycle — topological sort is impossible.
