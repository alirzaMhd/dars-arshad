Articulation Points & Bridges

An articulation point (or cut vertex) is a vertex whose removal disconnects the graph. A bridge (or cut edge) is an edge whose removal disconnects the graph.

Graph

8 vertices {0,1,2,3,4,5,6,7} with 9 undirected edges.

Edges: 0-1, 1-2, 1-3, 2-3, 1-4, 4-5, 5-6, 5-7, 6-7

Three regions connected by bridges: left side {0,1,2,3} (triangle {1,2,3} + pendant 0), middle node 4, right cycle {5,6,7}.

Key Formulas

low[v] = min( d[v], d[w] for each back edge (v,w), low[w] for each child w )

Non-root v is articulation point if ∃ child w with low[w] ≥ d[v]

Root is articulation point if it has ≥ 2 children

Edge (u,v) is a bridge if low[v] > d[u]
