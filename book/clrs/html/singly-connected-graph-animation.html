🧠 What Is a Singly Connected Graph?

A directed graph is dots (vertices) connected by arrows (edges). Arrow u → v means you go from u to v in one step.

A simple path from u to v is a route following arrows that never visits the same vertex twice. For example, 0→1→3 is a simple path.

🌟 The Definition:

A directed graph is singly connected if for every pair of vertices (u, v), there is at most one simple path from u to v.

🔹 If there are two different ways to get from u to v, the graph is NOT singly connected.

📊 Our Two Graphs

Graph A (left) — 5 vertices, edges: 0→1, 1→2, 2→3, 2→4

A tree-like DAG — every vertex has exactly one way to reach any other vertex it can reach.

Graph B (right) — 4 vertices, edges: 0→1, 0→2, 1→3, 2→3

A diamond pattern — from 0 you can reach 3 via 0→1→3 or 0→2→3. Two different paths to the same destination!

🔬 How the Algorithm Works

We run DFS (Depth-First Search) from each vertex as a source. For each destination we reach, we count how many distinct simple paths got us there. If any count reaches 2, the graph fails.

We'll process Graph A first (all paths should be unique), then Graph B (has a violation).
