🎓 Welcome to the Generic MST Algorithm

This page explains how Minimum Spanning Trees (MSTs) are built using the fundamental Cut Property. The Generic-MST algorithm is the most general method for growing an MST — it adds one safe edge at a time until all vertices are connected.

📜 The Five Key Concepts

Cut (S, V−S): A partition of the vertex set V into two nonempty subsets S and V−S.

Edge crosses a cut: An edge with one endpoint in S and the other in V−S.

Cut respects A: A set A of edges. A cut respects A if no edge in A crosses the cut. All edges in A stay entirely within S or entirely within V−S.

Light edge: An edge crossing a cut whose weight is minimum among all crossing edges.

Safe edge: An edge (u,v) such that A ∪ {(u,v)} is still a subset of some MST. The Cut Property guarantees that the light edge is always safe.

Generic-MST: Start with A = ∅. Repeat: find any cut that respects A, pick the light edge crossing it (which is safe), and add it to A. Stop when A has |V|−1 edges.
