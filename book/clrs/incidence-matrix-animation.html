Incidence Matrix

For a directed graph G = (V, E), the incidence matrix B is a |V| × |E| matrix where:

bij = 1  if vertex vi is incident to edge ej, 0 otherwise

Each column ej has exactly two ones: one for the source and one for the target (self-loops have one 1).

For this demo: |V| = 5, |E| = 6

e0: (0→1), e1: (0→3), e2: (1→2), e3: (1→3), e4: (2→4), e5: (3→4)

Press ▶ Play or ⏭ Step to fill the matrix one edge at a time.
