Euler Tour (Eulerian Cycle)

An Euler tour (also called an Eulerian cycle) is a cycle in a directed graph that traverses each edge exactly once and returns to the starting vertex.

Existence Conditions

A directed graph has an Euler tour iff:

1. The graph is strongly connected

2. Every vertex has in-degree = out-degree

Hierholzer's Algorithm

1. Start from any vertex. Follow unused edges, pushing vertices onto a stack.

2. When a vertex has no unused outgoing edges, pop it to the circuit.

3. Repeat until the stack is empty. The circuit, reversed, is the Euler tour.
