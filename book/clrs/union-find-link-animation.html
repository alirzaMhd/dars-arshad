Problem Setup

The LINK(x, y) operation connects two roots in a Disjoint Set Union (Union-Find) data structure.

We maintain a forest where each node has a parent pointer p[·] and a rank (an upper bound on tree height).

Union by Rank Rule

if rank[x] > rank[y]: p[y] = x else: p[x] = y; if rank[x] == rank[y]: rank[y]++

Always attach the tree with smaller rank under the tree with larger rank. This keeps tree height ≤ log₂(n).
