The Classic 2-Location Vacuum World

The vacuum cleaner world is a toy problem used to illustrate search concepts. It features a simple, fully observable, deterministic, and discrete environment.

Locations

Two squares: A and B

Each can be Clean or Dirty

Agent Position

Agent is in A or B

Fully observable location

Actions

Left, Right, Suck

Deterministic effects

Goal

Both squares Clean

Agent can end anywhere

Problem Formulation
P = (S, A, T, G, Cost)
ComponentDefinition
States S{(agent, A_status, B_status)} where agent ∈ {A, B}, status ∈ {Clean, Dirty}
Initial stateAny of the 8 possible states
Actions A{Left, Right, Suck}
Transition TSuck → cleans current location. Left → move to A (if at B). Right → move to B (if at A). No-op if at edge (Left at A, Right at B).
Goal testBoth squares Clean
Path costEach action costs 1
Example: Transition Details

At A, Suck: A becomes Clean (if dirty), agent stays at A.

At A, Right: Agent moves to B, no change in dirt status.

At A, Left: No effect (agent stays at A, nothing changes).

At B, Suck: B becomes Clean (if dirty), agent stays at B.

At B, Left: Agent moves to A, no change in dirt status.

At B, Right: No effect (agent stays at B, nothing changes).

Environment Properties

PropertyValue
ObservabilityFully observable (agent knows its location and both squares' status)
DeterminismDeterministic (each action has a single guaranteed outcome)
Episodic vs SequentialSequential (actions affect future states)
Static vs DynamicStatic (world does not change while agent deliberates)
Discrete vs ContinuousDiscrete states and actions
Single vs Multi-agentSingle agent
The vacuum world assumes perfect sensing (agent always knows exact dirt status) and perfect actuation (Suck always cleans completely). Real vacuum cleaners have noisy sensors, partially blocked nozzles, and battery constraints.

Solution Examples

Shortest Solution from Each Non-Goal State

From [A]DD (S1): Suck → Right → Suck = 3 steps (cost=3)

From [A]CD (S2): Right → Suck = 2 steps (cost=2)

From [A]DC (S3): Suck = 1 step (cost=1)

From [B]CD (S6): Suck = 1 step (cost=1)

From [B]DC (S7): Left → Suck = 2 steps (cost=2)

Example: 3-Location Vacuum World

Locations: A, B, C (arranged in a line). Agent at any of 3 locations, each of 3 locations dirty or clean.

State count: 3 × 23 = 3 × 8 = 24 states.

Goal: All 3 squares clean.

Actions: Left (move towards A), Right (move towards C), Suck (clean current square).

From location B: Left goes to A, Right goes to C, Suck cleans B.

From location A: Left is no-op, Right goes to B, Suck cleans A.

From location C: Left goes to B, Right is no-op, Suck cleans C.

Worked Examples

Example 1: Agent at [A], both dirty

Initial state: (A, Dirty, Dirty)

Goal test: (_, Clean, Clean)

Possible actions from S1: Left (no-op, stays S1), Right (goes to S5: [B]DD), Suck (goes to S2: [A]CD)

Rational plan: Suck → Right → Suck

Trace:

  1. S1 [A]DD — Suck → S2 [A]CD (cost=1)
  2. S2 [A]CD — Right → S6 [B]CD (cost=2)
  3. S6 [B]CD — Suck → S8 [B]CC (cost=3, goal reached)

Total path cost = 3. Also optimal (any other plan takes ≥ 3).

Example 2: Agent at [B], A clean, B dirty

Initial state: (B, Clean, Dirty)

Actions from S6: Left (S2), Right (no-op), Suck (S8)

Optimal plan: Suck (1 step, cost=1) — directly reaches goal [B]CC.

Trivial case: agent is already in the dirty room and just needs to clean it.

Example 3: Agent at [A], A clean, B dirty

Initial state: (A, Clean, Dirty)

Actions from S2: Left (no-op), Right (S6), Suck (no-op, A already clean)

Optimal plan: Right → Suck

Trace:

  1. S2 [A]CD — Right → S6 [B]CD (cost=1)
  2. S6 [B]CD — Suck → S8 [B]CC (cost=2, goal)

Total path cost = 2. Note: Suck at S2 is useless because A is already clean.

Example 4: Non-Optimal vs Optimal: Agent at [A], both dirty (longer path)

Initial state: (A, Dirty, Dirty)

Non-optimal plan (cost=5):

  1. Right → [B]DD (cost=1)
  2. Suck → [B]CD (cost=2)
  3. Left → [A]CD (cost=3)
  4. Suck → [A]CC (cost=4)
  5. Right → [B]CC (cost=5, goal)

Optimal plan (cost=3): Suck → Right → Suck

The non-optimal plan cleans A, moves to B, cleans B, moves back to A, moves back to B — wasteful! Optimal is always preferred for efficiency.
