THROUGHPUT

Physical Layer — Complete Guide for Exam

What is Throughput?

Throughput is the actual rate at which data is successfully delivered over a communication channel. Unlike bandwidth (which represents the theoretical maximum), throughput measures what is actually achieved in practice.

Key Point: Throughput is always less than or equal to bandwidth. It represents real-world performance, not theoretical limits.

Key Concepts

Throughput ≤ Bandwidth
Always true in real systems
Affected by Factors
Noise, errors, protocol overhead, congestion
Real-World vs Theory
Actual throughput is always lower than bandwidth
Measurement Units
bps, Kbps, Mbps, Gbps

Why Throughput Matters

Throughput determines the actual user experience. When you download a file, stream a video, or make a video call, the speed you experience is the throughput, not the bandwidth your ISP advertises.

Warning: Throughput is never greater than bandwidth. If someone claims higher throughput than bandwidth, they are either measuring differently or making an error.
Warning: Throughput includes protocol overhead (headers, error correction, retransmissions), so the actual useful data rate is even lower.
Warning: The utilization factor is always between 0 and 1 (0% to 100%). A utilization of 1 means the channel is fully utilized at its maximum bandwidth.

Throughput Formulas

Formula 1: Basic Throughput
Throughput = R × U
Where R = bandwidth (channel capacity), U = utilization factor (0 ≤ U ≤ 1)
Formula 2: Data Rate Calculation
Throughput = Total data transferred / Time taken
Measures actual data delivery rate over a specific time period
Formula 3: Effective Throughput
Effective throughput = (Data bits delivered) / (Total time)
Accounts for all delays including transmission, propagation, and processing
Formula 4: Bandwidth from Throughput
Bandwidth = Throughput / U
Reverse calculation when throughput and utilization are known
Formula 5: Utilization Factor
U = Throughput / Bandwidth
Measures how effectively the channel is being used

Worked Examples

Example 1: Basic Throughput Calculation

Problem: Calculate throughput if bandwidth R = 100 Mbps and utilization U = 0.7

Solution
Throughput = R × U = 100 Mbps × 0.7 = 70 Mbps
The actual data rate achieved is 70 Mbps, which is 70% of the maximum bandwidth.
Example 2: Throughput from Data Transfer

Problem: Find throughput if 1500 bytes are transferred in 0.002 seconds

Solution
Throughput = (1500 × 8 bits) / 0.002 s = 12,000 bits / 0.002 s = 6,000,000 bps = 6 Mbps
Convert bytes to bits (×8), then divide by time to get bits per second.
Example 3: Bandwidth with Percentage Utilization

Problem: Bandwidth is 1 Gbps, utilization is 60%. Find throughput.

Solution
Throughput = 1 Gbps × 0.60 = 0.6 Gbps = 600 Mbps
60% utilization means only 600 Mbps out of 1000 Mbps is effectively used.
Example 4: Finding Bandwidth from Throughput

Problem: If throughput is 50 Mbps and utilization is 0.5, find bandwidth.

Solution
Bandwidth = Throughput / U = 50 Mbps / 0.5 = 100 Mbps
When utilization is 50%, the actual bandwidth must be double the throughput.
Example 5: Comparing Throughput on Different Links

Problem: Compare throughput on Link A (100 Mbps, U=0.8) vs Link B (50 Mbps, U=0.9)

Solution
Link A: 100 × 0.8 = 80 Mbps
Link B: 50 × 0.9 = 45 Mbps
Link A has higher throughput (80 Mbps > 45 Mbps)
Higher bandwidth with lower utilization can still outperform lower bandwidth with higher utilization.

Visual Analogy

Think of bandwidth as the width of a pipe, and throughput as the actual water flow through it. A wider pipe (higher bandwidth) allows more water (data), but the actual flow depends on pressure, obstructions, and other factors.

Key Difference: Bandwidth is what you pay for; throughput is what you actually get. ISPs advertise bandwidth, but your experience depends on throughput.

Quick Reference Card

Essential Formulas

  • Throughput = R × U (bandwidth × utilization)
  • Throughput = Total data / Time taken
  • Bandwidth = Throughput / U
  • U = Throughput / Bandwidth

Key Facts to Remember

  • Throughput is always ≤ Bandwidth
  • Utilization factor U is always between 0 and 1
  • Real throughput is always lower than theoretical bandwidth
  • Protocol overhead reduces effective throughput
  • Measured in bps, Kbps, Mbps, Gbps

Common Mistakes

  • Don't confuse throughput with bandwidth
  • Remember to convert bytes to bits (×8)
  • Utilization is a ratio (0-1), not percentage (unless specified)
  • Throughput includes all overhead, not just useful data

Unit Quick Reference

  • 1 Kbps = 1,000 bps
  • 1 Mbps = 1,000 Kbps = 1,000,000 bps
  • 1 Gbps = 1,000 Mbps = 1,000,000,000 bps
