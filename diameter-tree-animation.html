Tree Diameter

The diameter of a tree is the longest shortest-path distance between any two vertices.

Tree: 10 vertices {0..9}, 9 undirected edges

Edges: 0-1, 1-2, 2-3, 3-4, 2-5, 5-6, 6-7, 6-8, 8-9

Two-BFS Algorithm

1. Pick any vertex s, run BFS → farthest vertex a

2. Run BFS from a → farthest vertex b

3. Distance between a and b = diameter

Why It Works

The farthest vertex from any node is always an endpoint of some diameter. Two BFS passes suffice.

Complexity: O(V+E) — two BFS traversals
