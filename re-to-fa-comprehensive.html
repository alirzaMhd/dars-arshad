RE → Finite Automata Conversion

Converting Regular Expressions to NFA — Complete Guide

Theorem: Every RE has an Equivalent NFA

For every regular expression r, there exists an NFA M such that L(M) = L(r).

Proof Method:
By structural induction on the regular expression
We construct an NFA for each case: base expressions and recursive combinations.
Key Insight: The resulting NFA may have λ-transitions (epsilon transitions). To get a DFA, we must subsequently apply the subset construction algorithm.

Construction Overview

The construction proceeds by induction on the structure of the regular expression:

  • Base cases: Build NFAs for ε, ∅, and individual symbols a
  • Union (r₁ + r₂): Combine NFAs with new start state and λ-transitions
  • Concatenation (r₁r₂): Connect NFA of r₁ to NFA of r₂
  • Kleene Star (r₁*): Add λ-transitions for looping and bypass

Base Case: NFA for 'a' (a ∈ Σ)

M₁ for L(a) = {a}:

q₀ --a--> q_f

Start: q₀, Final: {q_f}

Two states: start state q₀, final state q_f. Single transition on symbol 'a'.

Base Case: NFA for ε

M₁ for L(ε) = {ε}:

q₀ --λ--> q_f

Start: q₀, Final: {q_f}

Two states with a λ-transition. The start state is also effectively final via λ.

Base Case: NFA for ∅

M₁ for L(∅) = {}:

q₀ (no transitions, not final)

Start: q₀, Final: {}

Single state, no transitions, not accepting. Accepts nothing.

Union: r = r₁ + r₂

Given NFAs M₁ for L(r₁) and M₂ for L(r₂):

New start state q₀ with λ-transitions to starts of M₁ and M₂

q₀ --λ--> q₀(M₁) and q₀ --λ--> q₀(M₂)

Final states of M₁ and M₂ become final states of M₃

L(M₃) = L(M₁) ∪ L(M₂) = L(r₁) ∪ L(r₂) = L(r₁ + r₂)

Concatenation: r = r₁r₂

Given NFAs M₁ for L(r₁) and M₂ for L(r₂):

λ-transitions from final states of M₁ to start state of M₂

Final states of M₂ become final states of M₃

Start state of M₁ is start state of M₃

L(M₃) = L(M₁) · L(M₂) = L(r₁r₂)

Kleene Star: r = r₁*

Given NFA M₁ for L(r₁):

New start state q₀ with:

• λ-transition to q₀(M₁) (enter the loop)

• λ-transition to new final state q_f (bypass for ε)

λ-transitions from final states of M₁ back to q₀(M₁) (loop)

λ-transitions from final states of M₁ to q_f (exit)

L(M₃) = (L(r₁))* = L(r₁*)

Example 1: r = (01* + 1)*0*

NFA Construction Steps

Step 1: Build NFA for '1' → simple two-state NFA

Step 2: Build NFA for '1*' → add λ-loops for Kleene star

Step 3: Build NFA for '0' → simple two-state NFA

Step 4: Build NFA for '01*' → concatenate NFA for '0' with NFA for '1*'

Step 5: Build NFA for '1' → simple two-state NFA

Step 6: Build NFA for '01* + 1' → union of step 4 and step 5

Step 7: Build NFA for '(01* + 1)*' → Kleene star of step 6

Step 8: Build NFA for '0*' → Kleene star of '0'

Step 9: Concatenate step 7 and step 8

Final NFA has λ-transitions throughout. Can be converted to DFA using subset construction.

Example 2: r = 01*(1 + 01)*

Simplified Construction

This NFA accepts strings that start with 0, then any number of 1's, then alternating 1's or 01 pairs.

States: q₀, q₁, q₂, q₃

Transitions: q₀--0-->q₁, q₁--1-->q₁, q₁--1-->q₂, q₁--0-->q₂, q₂--1-->q₃

Start: q₀, Final: {q₃}

Converting NFA to DFA (Subset Construction)

After building the NFA from RE, convert to DFA:

  1. Compute ε-closure of start state → initial DFA state
  2. For each DFA state and each input symbol, compute transition
  3. Any NFA final state in a DFA state makes that DFA state final
  4. Repeat until no new DFA states are generated
Complexity: In worst case, DFA can have 2ⁿ states where n is the number of NFA states. However, this is rarely the worst case in practice.

Key Takeaway

Conversion Chain:
RE → NFA (via Thompson's construction) → DFA (via subset construction) → Minimal DFA
Every regular expression can be converted to an equivalent finite automaton, proving that regular expressions describe exactly the regular languages.
