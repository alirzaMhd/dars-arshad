Biconnected Components

A biconnected component is a maximal set of edges where any two edges lie on a common simple cycle. Equivalently: a maximal 2-vertex-connected subgraph where no single vertex removal disconnects the remaining edges.

Edges that don't belong to any cycle (bridges) form their own single-edge biconnected component.

Graph

7 vertices {0,1,2,3,4,5,6} with 8 undirected edges.

Edges: 0-1, 1-2, 2-0, 1-3, 3-4, 4-5, 5-3, 5-6

Expected: 4 biconnected components (2 triangles, 2 bridges).

Articulation points (separate components): 1, 3, 5

Key Algorithm

DFS with low-link values and an edge stack. When low[child] ≥ d[current], pop edges from the stack to form a biconnected component.

low[v] = min( d[v], d[w] for back edge (v,w), low[w] for each child w )
