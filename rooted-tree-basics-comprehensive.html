Rooted Trees & k-ary Trees

Data Structures — Complete Guide for 20/20 Exam

What is a Rooted Tree?

A rooted tree (also called an ordered tree) is a connected acyclic graph (free tree) with one designated node called the root. The root has no parent, and all other nodes have exactly one parent.

Formal Definition:
T = (V, E, r)
A rooted tree consists of a set of vertices V, edges E, and a distinguished root node r ∈ V. The tree is connected and has no cycles.
⚠ Key distinction: A rooted tree is NOT the same as a general tree. Every rooted tree is a tree, but not every tree is rooted. The root gives the tree a "direction" — from parent to child.
a ← Root (no parent) /|\ b c d ← Children of a /| | e f g ← Grandchildren | h | k ← Leaf (no children)

Depth and Height

Depth of a Node:
depth(v) = length of path from root to v
The number of edges on the path from the root to node v. Root has depth 0.
Height of a Node:
height(v) = length of longest path from v to any leaf
The maximum distance from node v to any descendant leaf. Leaf nodes have height 0.
Height of a Tree:
height(T) = height(root) = max(depth of all nodes)
The height of the tree equals the height of the root, which equals the maximum depth among all nodes.
⚠ Some textbooks define height of a leaf as 1 instead of 0. Check your course convention! The formulas above use height(leaf) = 0.
Example: Computing Depth and Height
a (depth=0, height=3) /|\ b c d (d: depth=1, height=2) /| | e f g (g: depth=2, height=0) | \ h (f: depth=2, height=1) | k (k: depth=3, height=0)

Tree height = 3 (longest path: a → b → f → h → k has 4 edges, but height counts from root)

Properties of Rooted Trees

Edge-Vertex Relationship:
e = n - 1
A tree with n nodes has exactly n-1 edges. This is a fundamental property of all trees.
Level Counting:
At level i, maximum k^i nodes (in a k-ary tree)
Level 0 (root) has 1 node, level 1 has at most k nodes, level 2 has at most k² nodes, etc.
Example 1: 3-ary Tree with 4 Levels

What is the maximum number of nodes, internal nodes, and leaves in a 3-ary tree with 4 levels?

Solution:

Level 0 (root)

1 node

Level 1

3 nodes

Level 2

9 nodes

Level 3

27 nodes

Total nodes: 1 + 3 + 9 + 27 = 40

Leaves (last level): 27

Internal nodes: 40 - 27 = 13

Example 2: General k-ary Tree with x Levels

What is the maximum number of nodes, leaves, and internal nodes in a k-ary tree with x levels?

Solution:

Maximum Nodes:
n = k⁰ + k¹ + k² + ... + k^(x-1) = (k^x - 1) / (k - 1)
Maximum Leaves:
leaves = k^(x-1)
Maximum Internal Nodes:
internal = (k^x - 1)/(k-1) - k^(x-1) = (k^(x-1) - 1)/(k - 1)
Example 3: Finding Levels from Node Count

A full 7-ary tree of height m (m+1 levels) has 279,936 leaves. How many internal nodes does it have?

Solution:

Since leaves = 7^m = 279,936, we get m = 6

Internal nodes = (7^6 - 1)/(7 - 1) = (279,936 - 1)/6 = 46,655

Key Relationship Formula

Node Degree Relationship in k-ary Trees:
n₀ + n₁ + n₂ + ... + nₖ = n
where nᵢ = number of nodes with i children, and n = total nodes.
For Binary Trees (k=2):
n₀ = n₂ + 1
The number of leaves is always one more than the number of nodes with 2 children.
Proof: n₀ = n₂ + 1 for Binary Trees

Let n = total nodes, e = edges, n₀ = leaves, n₁ = nodes with 1 child, n₂ = nodes with 2 children.

We know: e = n - 1 (tree property)

Also: e = n₁ + 2n₂ (counting edges by child contributions)

And: n = n₀ + n₁ + n₂

Substituting: n₀ + n₁ + n₂ - 1 = n₁ + 2n₂

Simplifying: n₀ = n₂ + 1 ∎

⚠ Important: This relationship n₀ = n₂ + 1 holds for ALL binary trees, regardless of structure. It's a common exam question!
Test Question

A binary tree has 4 nodes: 2 have degree 2, 1 has degree 1. How many nodes have degree 0?

Solution: Using n₀ = n₂ + 1: n₀ = 2 + 1 = 3 leaves.

Verification: Total = n₀ + n₁ + n₂ = 3 + 1 + 2 = 6... but we only have 4 nodes. Let me recalculate.

Actually: n₀ + n₁ + n₂ = 4, n₂ = 2, n₁ = 1, so n₀ = 4 - 2 - 1 = 1. But n₀ = n₂ + 1 = 3. This means such a tree cannot exist! The formula constrains the possible structures.

k-ary Trees

A k-ary tree is a rooted tree where every node has at most k children. The degree of the tree is the maximum number of children any node can have.

Tree TypekMax Children per Node
Binary Tree22
Ternary Tree33
4-ary Tree44
k-ary Treekk
Maximum Nodes in k-ary Tree of Height h:
n_max = (k^(h+1) - 1) / (k - 1)
This is the sum of a geometric series: 1 + k + k² + ... + k^h
Maximum Leaves:
leaves_max = k^h
The last level (level h) can have at most k^h nodes, all of which are leaves in a full tree.
Maximum Internal Nodes:
internal_max = (k^h - 1) / (k - 1)
Total nodes minus leaves: (k^(h+1) - 1)/(k-1) - k^h = (k^h - 1)/(k-1)
⚠ Height vs Levels: A tree of height h has h+1 levels (0 through h). Be careful with this distinction in formulas!

Minimum Height for n Nodes

Minimum Height:
h_min = ⌈log_k(n(k-1) + 1)⌉ - 1
The minimum height needed to store n nodes in a k-ary tree.
Example: Minimum Levels for 1000 Nodes in 3-ary Tree

We need: (3^x - 1)/(3 - 1) ≥ 1000

3^x - 1 ≥ 2000 → 3^x ≥ 2001

Since 3^6 = 729 and 3^7 = 2187, we need x ≥ 7

Minimum levels = 7 (height = 6)

Full k-ary Tree

A full k-ary tree is one where every internal node has exactly k children. In a full k-ary tree of height h:

Properties of Full k-ary Tree:
Internal nodes = (k^h - 1)/(k - 1)
Every level is completely filled.
Leaves in Full k-ary Tree:
leaves = k^h
Example: Full Binary Tree with 5 Nodes

Given preorder: a b d e h i c f g, and we know d, h, i, f, g are leaves.

Using a stack-based approach:

Push leaves from right to stack: Read 'a' → push (internal node, look for children) Read 'b' → push Read 'd' → leaf, push to stack Read 'e' → push Read 'h' → leaf, push Read 'i' → leaf, push ... continue building tree

Worked Examples

Example 1: Basic Terminology

Given a rooted tree, identify: root, parent of each node, children of each node, siblings, leaves, internal nodes, depth of each node, height of each node, and tree height.

a /|\ b c d /| |\ e f g h | | i j

Solution:

• Root: a

• Parent of b = a, Parent of e = b, Parent of i = f, Parent of j = h

• Children of a: {b, c, d}, Children of b: {e, f}, Children of d: {g, h}

• Siblings of b: {c, d}, Siblings of e: {f}

• Leaves: {c, e, f, g, i, j} (degree 0)

• Internal nodes: {a, b, d, h} (degree > 0)

• Depth of a=0, b=1, e=2, i=3, j=3

• Height of a=3, b=2, d=2, f=1, h=1

• Tree height: 3

Example 2: Counting Nodes in k-ary Trees

A full binary tree has height 4. How many nodes does it have?

Solution:

n = (2^5 - 1)/(2 - 1) = 32 - 1 = 31 nodes

Leaves: 2^4 = 16

Internal nodes: 31 - 16 = 15

Example 3: Finding Minimum Height

What is the minimum height of a binary tree with 25 nodes?

Solution:

We need: 2^(h+1) - 1 ≥ 25

2^(h+1) ≥ 26

Since 2^4 = 16 and 2^5 = 32: h+1 = 5, so h = 4

Minimum height = 4

Level 0: 1 node, Level 1: 2 nodes, Level 2: 4 nodes, Level 3: 8 nodes (total 15)

Remaining: 25 - 15 = 10 nodes at level 4

Example 4: Using n₀ = n₂ + 1

In a binary tree, if there are 10 nodes with 2 children, how many leaves are there?

Solution:

Using n₀ = n₂ + 1: n₀ = 10 + 1 = 11 leaves

Example 5: Minimum Nodes for Given Height

What is the minimum number of nodes in a binary tree of height 5?

Solution:

Minimum nodes occurs when each level has exactly 1 node (a skewed tree):

n_min = h + 1 = 5 + 1 = 6 nodes

Example 6: Degree Count in 3-ary Tree

A 3-ary tree has 29 nodes: 4 have degree 0, 3 have degree 3, 2 have degree 2. How many have degree 1?

Solution:

Using: n₀ + n₁ + n₂ + n₃ = n

4 + n₁ + 2 + 3 = 29

n₁ = 29 - 9 = 20 nodes with degree 1

Example 7: Minimum Levels for k-ary Tree

What is the minimum number of levels needed for 1000 nodes in a 3-ary tree?

Solution:

We need: (3^(h+1) - 1)/(3-1) ≥ 1000

3^(h+1) - 1 ≥ 2000

3^(h+1) ≥ 2001

Since 3^6 = 729 and 3^7 = 2187: h+1 = 7, so h = 6

Minimum height = 6, so 7 levels needed

Level 0: 1 node, Level 1: 3, Level 2: 9, Level 3: 27, Level 4: 81, Level 5: 243 (total 364)

Remaining: 1000 - 364 = 636 nodes at level 6

Example 8: Building Minimum Height Tree

Build a minimum-height binary tree with 25 nodes. Show all cases.

Solution:

Minimum height = 4 (from Example 3)

Level 0: 1, Level 1: 2, Level 2: 4, Level 3: 8 (total 15)

Remaining: 25 - 15 = 10 nodes at level 4

Case 1: All 10 nodes are leftmost (complete tree)

Case 2: 10 nodes spread across level 4

Case 3: 10 nodes with some gaps (still valid)

Any arrangement with 10 nodes at level 4 works
