Frame Structure

Frame Structure Basics

A frame is the digital data transmission unit at the Data Link Layer. It consists of a set of bits organized into specific fields that carry control information, data, and error detection codes.

General Frame Format:
[Preamble][SFD][Dst Addr][Src Addr][Type/Len][Data][FCS][Frame Delimiter]
Each field serves a specific purpose in ensuring reliable data delivery.

Essential Frame Components

Frame Delimiter

• Marks start/end of frame

• Unique bit pattern

• Example: 01111110 in HDLC

Addressing

• Destination MAC address

• Source MAC address

• 6 bytes each (48 bits)

Payload

• Actual data being transmitted

• Network layer packet

• Variable length

Error Detection

• Frame Check Sequence (FCS)

• Usually CRC-32

• 4 bytes in Ethernet

Key Concept: Frames are the PDU (Protocol Data Unit) of the Data Link Layer. Each layer has its own PDU name: Segment (Transport), Packet (Network), Frame (Data Link), Bit (Physical).

Ethernet (IEEE 802.3) Frame

The Ethernet frame is the most commonly used frame format in LANs. It follows the IEEE 802.3 standard and has evolved over time.

Ethernet II Frame Format:
Preamble (7) | SFD (1) | Dst (6) | Src (6) | Type (2) | Data (46-1500) | FCS (4)
Numbers in parentheses indicate field size in bytes. Total frame size: 64-1518 bytes.

Field Descriptions

Field Size (bytes) Description
Preamble 7 Alternating 1s and 0s for clock synchronization
Start Frame Delimiter (SFD) 1 Pattern 10101011 marks end of preamble
Destination Address 6 MAC address of receiving device
Source Address 6 MAC address of sending device
Type/Length 2 Type (Ethernet II) or Length (IEEE 802.3)
Data/Payload 46-1500 Network layer packet (min 46 bytes with padding)
FCS 4 Frame Check Sequence (CRC-32)
Example 1: Minimum Frame Size

Why is the minimum Ethernet frame size 64 bytes?

Answer: To ensure collision detection. At 10 Mbps with maximum cable length of 2500m, a frame must be at least 64 bytes to guarantee the sender is still transmitting when a collision might occur.

Example 2: Padding Requirement

If the data payload is only 30 bytes, how many padding bytes are needed?

Answer: 16 bytes of padding (46 - 30 = 16). Minimum data field is 46 bytes.

Detailed Frame Fields

Preamble and SFD

Preamble: 10101010 10101010 10101010 10101010 10101010 10101010 10101010 SFD: 10101011

The preamble allows the receiver to synchronize its clock with the sender's clock. The SFD (Start Frame Delimiter) marks the actual beginning of the frame.

Address Fields

Destination Address

• First frame field after SFD

• Can be unicast, multicast, or broadcast

• All bits = 1 means broadcast

Source Address

• Always a unicast address

• Identifies the sender

• First bit always 0

Type vs Length Field

Value Meaning Standard
≥ 1536 (0x0600) Type field (Ethernet II) DIX Ethernet
≤ 1500 Length field (IEEE 802.3) IEEE 802.3
1501-1535 Reserved -

Common Type Values

Type (Hex) Protocol
0x0800 IPv4
0x0806 ARP
0x86DD IPv6
0x8100 VLAN (802.1Q)
Example 3: Frame Type Identification

An Ethernet frame has Type field value 0x0800. What protocol is being carried?

Answer: IPv4 - The value 0x0800 indicates the payload is an IPv4 packet.

Example 4: Maximum Frame Size

What is the maximum Ethernet frame size including all headers?

Answer: 1518 bytes (7+1+6+6+2+1500+4). With 802.1Q VLAN tagging, it becomes 1522 bytes.

Worked Examples

Example 5: Frame Overhead Calculation

Calculate the overhead percentage for a maximum-size Ethernet frame carrying IPv4 data.

Answer:

Overhead = Preamble(7) + SFD(1) + Dst(6) + Src(6) + Type(2) + FCS(4) = 26 bytes

Data = 1500 bytes

Overhead % = (26 / 1526) × 100 = 1.7%

Example 6: Frame Transmission Time

How long does it take to transmit a 1518-byte Ethernet frame at 10 Mbps?

Answer:

Frame size = 1518 bytes × 8 bits/byte = 12,144 bits

Time = 12,144 bits / 10,000,000 bps = 1.2144 ms

Example 7: Effective Throughput

If the data payload is 500 bytes, what is the effective throughput as a percentage of total frame bandwidth?

Answer:

Total frame = 500 + 26 = 526 bytes

Efficiency = (500 / 526) × 100 = 95.1%

Example 8: Fragmentation Need

A network layer packet is 2000 bytes. Does it need fragmentation at the Data Link Layer?

Answer: Yes - The maximum Ethernet payload is 1500 bytes, so the packet must be fragmented into at least 2 frames (1500 + 500 bytes).

Example 9: Padding Calculation

If a frame carries only 20 bytes of data, how many padding bytes are added?

Answer: 26 bytes (46 - 20 = 26). Minimum data field is 46 bytes.

Common Mistake: The minimum frame size of 64 bytes includes all headers (preamble, addresses, type, FCS) but NOT the preamble and SFD. The minimum frame from destination address to FCS is 64 bytes.
Minimum Frame Calculation:
6 (Dst) + 6 (Src) + 2 (Type) + 46 (Data) + 4 (FCS) = 64 bytes
This ensures proper collision detection in CSMA/CD networks.
