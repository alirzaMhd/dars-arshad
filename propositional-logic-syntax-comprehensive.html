Propositional Logic Syntax

Artificial Intelligence — Logical Agents

Syntax of Propositional Logic

Syntax defines which strings of symbols are valid sentences in the language. Propositional logic (also called Boolean logic) has a simple, well-defined syntax.

Atomic Sentences
Indivisible syntactic elements: propositional symbols (P, Q, R, W₁,₃) and the constants True, False
Complex Sentences
Built from simpler sentences using logical connectives (¬, ∧, ∨, ⇒, ⇔)
Literals
An atomic sentence or its negation: P (positive literal) or ¬P (negative literal)

Propositional Symbols

Propositional symbols are names for atomic propositions — statements that can be true or false. Convention:

Symbol TypeExamplesMeaning
Generic P, Q, R Arbitrary propositions
Wumpus World W₁,₃ "There is a Wumpus in room [1,3]"
Wumpus World P₁,₂ "There is a Pit in room [1,2]"
Wumpus World B₁,₁ "Breeze is perceived in room [1,1]"
Wumpus World S₁,₂ "Stench is perceived in room [1,2]"
Constants True, False Always-true and always-false propositions
Symbol Naming Convention

Symbols like W₁,₃ are atomic — the subscript is part of the symbol name, not an index operation. W₁,₃ is a single, indivisible symbol meaning "Wumpus in room [1,3]". The notation is chosen for readability but has no syntactic significance.

BNF Grammar

The formal grammar of propositional logic can be expressed in Backus-Naur Form (BNF).

BNF Grammar for Propositional Logic (Figure 6-7)
Sentence → AtomicSentence | ComplexSentence AtomicSentence → True | False | Symbol Symbol → P | Q | R | ... (any propositional symbol) ComplexSentence → ¬Sentence | (Sentence ∧ Sentence) | (Sentence ∨ Sentence) | (Sentence ⇒ Sentence) | (Sentence ⇔ Sentence)
This grammar is unambiguous — every sentence has exactly one parse tree. Parentheses are required for all binary connectives.

Understanding the BNF

ProductionExplanation
Sentence → AtomicSentence | ComplexSentenceEvery sentence is either atomic or complex
AtomicSentence → True | False | SymbolAtomic sentences are constants or symbols
Symbol → P | Q | R | ...Any letter or word can be a symbol (W₁,₃, etc.)
ComplexSentence → ¬SentenceNegation applies to any sentence
ComplexSentence → (Sentence ∧ Sentence)Conjunction: both must be true
ComplexSentence → (Sentence ∨ Sentence)Disjunction: at least one must be true
ComplexSentence → (Sentence ⇒ Sentence)Implication: if first is true, second must be true
ComplexSentence → (Sentence ⇔ Sentence)Biconditional: both have the same truth value
Important: The BNF grammar is strict about parentheses. Every complex sentence built with a binary connective (∧, ∨, ⇒, ⇔) must be enclosed in parentheses. This ensures the grammar is unambiguous — each sentence has exactly one parse tree.

Strict vs Relaxed Syntax

In practice, we relax the strict parenthesization rules using precedence and associativity conventions (see Precedence tab). The strict grammar requires:

  • Instead of A ∧ B ∧ C, write ((A ∧ B) ∧ C)
  • Instead of A ⇒ B ⇒ C, write (A ⇒ (B ⇒ C))

But for readability, we use precedence rules to omit parentheses where the meaning is unambiguous.

Logical Connectives

There are five standard logical connectives in propositional logic:

ConnectiveSymbolNameEnglish EquivalentArity
Negation ¬ Not "It is not the case that..." Unary
Conjunction ∧ And "Both ... and ..." Binary
Disjunction ∨ Or "At least one of ..." Binary
Implication ⇒ If-then "If ... then ..." Binary
Biconditional ⇔ Iff "... if and only if ..." Binary

Details

¬ (Negation)
¬P is true when P is false, and false when P is true. It flips the truth value.
∧ (Conjunction)
P ∧ Q is true only when both P and Q are true. Each sub-sentence is called a conjunct.
∨ (Disjunction)
P ∨ Q is true when at least one of P, Q is true. Each sub-sentence is called a disjunct.
⇒ (Implication)
P ⇒ Q is true unless P is true and Q is false. P is the antecedent, Q is the consequent.
⇔ (Biconditional)
P ⇔ Q is true when P and Q have the same truth value (both true or both false). Equivalent to (P ⇒ Q) ∧ (Q ⇒ P).

Literal

Definition
Literal = AtomicSentence | ¬AtomicSentence
A literal is either an atomic sentence (positive literal) or its negation (negative literal). Examples: P (pos), ¬Q (neg), W₁,₃ (pos), ¬B₁,₁ (neg)

Operator Precedence

To reduce parentheses, propositional logic uses a precedence hierarchy (highest to lowest):

Precedence (High to Low)
¬ > ∧ > ∨ > ⇒ > ⇔
Same principle as arithmetic: ¬ is like unary minus, ∧ is like multiplication, ∨ is like addition, ⇒ and ⇔ have lower precedence.
PrecedenceConnectiveExampleMeaningAnalogy
1 (Highest)¬¬P ∧ Q(¬P) ∧ QUnary minus: -x + y = (-x) + y
2∧P ∧ Q ∨ R(P ∧ Q) ∨ RMultiplication: a × b + c = (a×b) + c
3∨P ∨ Q ⇒ R(P ∨ Q) ⇒ RAddition: a + b > c = (a+b) > c
4⇒P ⇒ Q ⇔ R(P ⇒ Q) ⇔ R
5 (Lowest)⇔P ⇔ Q ⇒ RP ⇔ (Q ⇒ R)

Associativity

For ∧ and ∨, the grammar allows left-associative grouping when the same connective appears multiple times:

Associativity Rules
P ∧ Q ∧ R ≡ (P ∧ Q) ∧ R
P ∨ Q ∨ R ≡ (P ∨ Q) ∨ R
These are unambiguous because ∧ and ∨ are associative in classical logic. However, with mixed operators, parentheses are required.
Example: Precedence in Action

P ∧ Q ∨ R(P ∧ Q) ∨ R
P ∨ Q ⇒ R(P ∨ Q) ⇒ R
P ⇒ Q ⇒ RP ⇒ (Q ⇒ R) [right-assoc]
P ∧ Q ⇔ ¬R ∨ S(P ∧ Q) ⇔ ((¬R) ∨ S)

Wumpus World Sentence Examples

Example 1: Breeze Rule

Natural language: "There is a breeze in room [1,1] if and only if there is a pit in [1,2] or [2,1]"

Propositional logic:

B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁)

This is a well-formed sentence. Symbols: B₁,₁, P₁,₂, P₂,₁. Connectives: ⇔, ∨. Parentheses around the disjunction are required because precedence would make B₁,₁ ⇔ P₁,₂ ∨ P₂,₁ ambiguous.

Example 2: Stench Rule

Natural language: "If there is a stench at [1,2], and the wumpus cannot be at [1,1] or [2,2], then it must be at [1,3]"

Propositional logic:

(S₁,₂ ∧ ¬W₁,₁ ∧ ¬W₂,₂) ⇒ W₁,₃

Well-formed. Precedence: ¬ binds tighter than ∧, so ¬W₁,₁ is (¬W₁,₁). The whole antecedent is a conjunction, grouped with parentheses.

Example 3: Gold Rule

Natural language: "If the agent perceives glitter and grabs, the agent has the gold"

Propositional logic:

Glitter ⇒ (Grab ⇒ HaveGold)

Well-formed. Implication is right-associative. This reads as: Glitter ⇒ (Grab ⇒ HaveGold), meaning "if glitter, then (if you grab, you have gold)".

Example 4: KB as Conjunction

The Knowledge Base is logically equivalent to the conjunction of all its sentences:

KB = S₁ ∧ S₂ ∧ S₃ ∧ ... ∧ Sₙ

Where each Sᵢ is a sentence that has been TELL'd to the KB. The conjunction of all sentences represents the agent's entire knowledge.

Example KB for Wumpus World (after visiting [1,1] and [2,1]):

KB = ¬B₁,₁ ∧ B₂,₁ ∧ (B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁)) ∧ (B₂,₁ ⇔ (P₁,₁ ∨ P₂,₂ ∨ P₃,₁)) ∧ ¬P₁,₁

Note the last sentence: ¬P₁,₁ (no pit in [1,1]) is background knowledge — the start room is always safe.

Example 5: Complex Expression

Natural language: "If there is no breeze at [2,2] and no stench at [2,2], then [2,3] is safe (no pit and no wumpus)"

Propositional logic:

(¬B₂,₂ ∧ ¬S₂,₂) ⇒ (¬P₂,₃ ∧ ¬W₂,₃)

Checking well-formedness:

  • Atomic symbols: B₂,₂, S₂,₂, P₂,₃, W₂,₃ ✓
  • ¬B₂,₂, ¬S₂,₂ — well-formed (negation) ✓
  • (¬B₂,₂ ∧ ¬S₂,₂) — well-formed (conjunction in parentheses) ✓
  • (¬P₂,₃ ∧ ¬W₂,₃) — well-formed (conjunction in parentheses) ✓
  • Full sentence: well-formed ✓
