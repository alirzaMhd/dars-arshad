What is an SCC?

A strongly connected component (SCC) is a group of vertices where every vertex can reach every other vertex via a directed path.

Think of it like a friend group where everyone can reach everyone else through mutual friends.

Our Example Graph

|V| = 8 vertices, |E| = 12 edges. Hidden inside are 3 SCCs.

• SCC1: {0, 1, 2} — a triangle (directed cycle)

• SCC2: {3, 4} — two vertices pointing to each other

• SCC3: {5, 6, 7} — a directed cycle of 3

Kosaraju's Trick (Two Passes)

Pass 1: Run DFS on G, record when each vertex finishes (f time).

Pass 2: Run DFS on GT (edges reversed!) in order of latest finish time first. Each DFS tree = one SCC.

Why Does This Work?

The vertex that finishes last in Pass 1 belongs to a source SCC in the transposed graph GT. By processing in reverse finish order, we peel off SCCs one by one, like layers of an onion.
