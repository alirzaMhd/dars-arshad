QUADRATIC PROBING

Data Structures — Complete Guide for 20/20 Exam

What is Quadratic Probing?

Quadratic probing checks slots at quadratic intervals (i²) instead of sequential slots. This eliminates primary clustering but introduces secondary clustering.

Probe Function:
h(k, i) = (h'(k) + c₁i + c₂i²) mod m
c₁ and c₂ are constants (c₂ ≠ 0), i = 0, 1, 2, ..., m-1
For the probe sequence to cover all slots, m must be prime and c₁ = c₂ = 1 (or specific values). If m = 4k+3 (prime), all slots will be probed.
Example: Probe Sequence

h'(k) = 0, c₁ = 0, c₂ = 1, m = 11

i=0: h(k,0) = 0

i=1: h(k,1) = 1

i=2: h(k,2) = 4

i=3: h(k,3) = 9

i=4: h(k,4) = 16 mod 11 = 5

i=5: h(k,5) = 25 mod 11 = 3

Probe sequence: 0, 1, 4, 9, 5, 3, ...

Formula Details

Common Variants

Variant 1 (Simple):
h(k, i) = (h'(k) + i²) mod m
c₁ = 0, c₂ = 1
Variant 2 (With Linear Term):
h(k, i) = (h'(k) + i + i²) mod m
c₁ = 1, c₂ = 1
From Textbook:
h(k, i) = (h'(k) + 3i + i²) mod m
c₁ = 3, c₂ = 1 (as used in the examples)

When Does It Work?

For quadratic probing to work properly:

1. m must be prime

2. If m = 4k + 3 for some integer k, then using c₁ = 0, c₂ = 1 will probe all slots

3. c₂ must be relatively prime to m

Symmetric Quadratic Probing (from textbook):
h(k, i) = (h'(k) ± i²) mod m, where -m/2 ≤ i ≤ m/2
If m is first prime of form 4j+3 (e.g., 3, 7, 11, 19, 23, 31...), all slots will be probed
Not all choices of c₁ and c₂ work! In the textbook example with c₁=3, c₂=1, keys 88 and 88 produced h(88,3) = h(88,4), meaning two different probes mapped to the same slot.

Secondary Clustering

Secondary clustering occurs when two keys with the same initial hash value follow the same probe sequence. Unlike primary clustering, clusters don't grow from adjacent slots.

Secondary Clustering:
If h'(k₁) = h'(k₂), then h(k₁,i) = h(k₂,i) for all i
Same initial hash means same entire probe sequence
Example: Secondary Clustering

h'(k) = k mod 11, c₁ = 0, c₂ = 1

Key 4: h(4,0)=4, h(4,1)=5, h(4,2)=8, h(4,3)=2, ...

Key 15: h(15,0)=4, h(15,1)=5, h(15,2)=8, h(15,3)=2, ...

Both keys follow identical probe sequences!

Secondary clustering is less severe than primary clustering. The probe sequences are the same for same initial hash, but different for different initial hashes.

Solution: Double Hashing

Double hashing uses two hash functions to generate different probe sequences for different keys, even if h₁(k) is the same.

Complexity Analysis

Expected Probes

Successful Search: O(1/α ln(1/(1-α)))

Unsuccessful Search: O(1/(1-α))

Advantages

• Eliminates primary clustering

• Better cache behavior than chaining

• Simple implementation

Comparison: Linear vs Quadratic Probing

Aspect Linear Probing Quadratic Probing
Primary Clustering Yes (severe) No
Secondary Clustering No Yes (mild)
Probe Sequence Sequential Quadratic jumps
Cache Performance Good (sequential access) Poor (random access)
Guaranteed to Find Slot Yes (if not full) Only if m is prime and chosen correctly
Key Formula:
α ≤ 0.5 for good performance
Quadratic probing works well when load factor is below 0.5
