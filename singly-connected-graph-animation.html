Singly Connected Directed Graphs

A directed graph is singly connected if for every pair of vertices (u, v), there is at most one simple path from u to v.

Two Graphs to Compare

Graph A: 5 vertices {0,1,2,3,4}, 4 edges — tree-like DAG

Graph B: 4 vertices {0,1,2,3}, 4 edges — diamond pattern

Algorithm

For each source vertex u, run DFS to enumerate all simple paths to every other vertex v. If any pair has ≥2 paths, the graph is not singly connected.

Time: O(V·E) using DFS from each vertex, counting paths
