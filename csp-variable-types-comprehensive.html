CSP Variable Types

Discrete, Continuous, and Boolean CSPs

Discrete Variables with Finite Domains

This is the simplest and most common type of CSP. Each variable can take one value from a finite set.

Number of Complete Assignments:
dn
Where d = max domain size, n = number of variables

Examples

• Map coloring (3 colors)

• 8-Queens (domain {1...8})

• Boolean CSP (true/false)

• Sudoku (digits 1-9)

Properties

• Finite search space

• Enumerable combinations

• Exponential in worst case

• NP-complete in general

8-Queens as a Discrete Finite CSP

Variables: Q1, Q2, ..., Q8 — position of queen in each column

Domains: Di = {1, 2, 3, 4, 5, 6, 7, 8} (row number)

Constraints: No two queens share the same row or diagonal

Constraints:
Qi ≠ Qj (same row)
|Qi − Qj| ≠ |i − j| (same diagonal)
Boolean CSP: When all domains are {true, false}, the CSP is called a Boolean CSP. SAT (propositional satisfiability) is a Boolean CSP. SAT is NP-complete, so polynomial-time algorithms for general finite CSP are not expected.

Discrete Variables with Infinite Domains

Some problems require variables that can take values from infinite sets like integers or strings.

Example: Job Scheduling

Variables: StartJob1, StartJob2, ... (start dates as integers)

Domains: All positive integers (days from today)

Constraints: Linear inequalities over integer variables

Precedence Constraint:
StartJob1 + DurationJob1 ≤ StartJob2
If Job1 takes 5 days and must precede Job2

Handling Infinite Domains

Since enumerating all values is impossible, we use constraint languages instead of listing allowed combinations. Common approaches:

  • • Linear constraints: solvable with specialized algorithms
  • • Non-linear constraints: may have no general solution algorithm
  • • Domain bounding: restrict to finite range when possible
Important: For non-linear constraints over integers, there is no general solution algorithm (undecidable).

Continuous Variables

Real-world CSPs often involve continuous variables, e.g., start/end times of observations, physical measurements.

Hubble Space Telescope Scheduling

Telescope observations require precise timing. Start and end times are continuous variables that must follow astronomical laws.

Constraint: Observations must not overlap and must occur within specific celestial windows.

Linear Programming

The most famous class of continuous CSPs is Linear Programming (LP).

LP Formulation:
Minimize cTx subject to Ax ≤ b, x ≥ 0
Constraints are linear inequalities forming a convex region

Key result: Linear programming can be solved in polynomial time (in the number of variables).

Continuous CSP Examples

• Telescope scheduling

• Factory production planning

• Resource allocation

• Portfolio optimization

Solution Methods

• Linear: Simplex, Interior Point

• Convex: Gradient methods

• Non-convex: Global optimization
