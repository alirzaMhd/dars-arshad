Propositional Logic Syntax

Artificial Intelligence — Logical Agents Chapter

Propositional Symbols

Propositional logic uses atomic sentences — the smallest meaningful units that are either true or false.

Three Types of Symbols

Propositional Symbols
Uppercase letters: P, Q, R, ..., Z

Each represents a proposition (a statement that is true or false). Can also use multi-letter names like P1, Rain, SkyBlue.

True Constant
Written as: True or T or 1

Always evaluates to true regardless of the model.

False Constant
Written as: False or F or 0

Always evaluates to false regardless of the model.

Atomic Sentences

An atomic sentence is a single propositional symbol or a constant. It has no internal structure.

Atomic Sentence
P, Q, R, True, False
Cannot be broken down further. Each is a complete sentence on its own.
Examples of Atomic Sentences

Rain — "It is raining" (true or false depending on the world)

P — some proposition P

True — always true

The Five Logical Connectives

Connectives combine atomic sentences into complex sentences. There are exactly five connectives in propositional logic.

Negation (¬)
Unary connective (one operand)
¬P
"not P" — true when P is false
Conjunction (∧)
Binary connective (two operands)
P ∧ Q
"P and Q" — true only when both P and Q are true
Disjunction (∨)
Binary connective (two operands)
P ∨ Q
"P or Q" — true when at least one of P, Q is true
Implication (⇒)
Binary connective (two operands)
P ⇒ Q
"if P then Q" — P is premise, Q is conclusion
Biconditional (⇔)
Binary connective (two operands)
P ⇔ Q
"P if and only if Q" — same truth value in both directions

Literals

A literal is either an atomic sentence or its negation. Literals are the building blocks of clauses.

Literal Definition
P is a positive literal; ¬P is a negative literal
Literals cannot contain any connectives — just a symbol (optionally negated).

BNF Grammar for Propositional Logic

A Backus-Naur Form (BNF) grammar formally defines all valid sentences in propositional logic.

<sentence> ::= <symbol> | True | False | ¬ <sentence> | <sentence> ∧ <sentence> | <sentence> ∨ <sentence> | <sentence> ⇒ <sentence> | <sentence> ⇔ <sentence> | ( <sentence> ) <symbol> ::= P | Q | R | S | ... | Z <literal> ::= <symbol> | ¬ <symbol>

Reading the Grammar

How to Parse the BNF

Line 1: A sentence can be a symbol, True, or False (base cases).

Line 2: A sentence can be the negation of another sentence (unary).

Lines 3-6: A sentence can be two sentences joined by a binary connective.

Line 7: Parentheses override default grouping (precedence).

The grammar is recursive — sentences contain sentences.

Recursive Structure

The grammar is inherently recursive. You can build arbitrarily complex sentences from simple ones:

Building Complexity Step by Step

Level 0 (Atomic): P

Level 1 (Unary): ¬P

Level 2 (Binary): P ∧ ¬Q

Level 3 (Nested): (P ∧ Q) ⇒ R

Level 4 (Deep): ¬(P ∧ Q) ∨ (R ⇒ S)

Level 5 (Complex): (P ⇒ (Q ∨ R)) ⇔ (¬P ∨ (Q ∧ R))

Each level adds one more connective. The BNF ensures every well-formed formula (WFF) can be decomposed back into atoms.

Well-Formed vs. Ill-Formed

Valid (Well-Formed) Sentences

P ∧ Q — conjunction of two atoms

¬(P ∨ Q) — negation of a disjunction

(P ⇒ Q) ∧ (Q ⇒ P) — conjunction of two implications

¬¬P — double negation

Invalid (Ill-Formed) Sentences

P ∧ — missing second operand

∧ P Q — wrong syntax (prefix notation, not standard)

P Q — no connective between atoms

(P ∧ Q — unmatched parenthesis

Parsing with Precedence

Without parentheses, we parse using precedence. Always evaluate the highest priority connective first.

Worked Example 1: ¬P ∧ Q ∨ R

Step 1: ¬P binds first (highest priority) → (¬P) ∧ Q ∨ R

Step 2: ∧ binds next → ((¬P) ∧ Q) ∨ R

Step 3: ∨ binds last → ((¬P) ∧ Q) ∨ R

Result: "Either (not P and Q) or R"

Worked Example 2: P ∨ Q ∧ ¬R ⇒ S

Step 1: ¬R binds first → P ∨ Q ∧ (¬R) ⇒ S

Step 2: ∧ binds next → P ∨ (Q ∧ (¬R)) ⇒ S

Step 3: ∨ binds next → (P ∨ (Q ∧ (¬R))) ⇒ S

Step 4: ⇒ binds last → (P ∨ (Q ∧ (¬R))) ⇒ S

Result: "If (P or (Q and not R)) then S"

Worked Example 3: ¬P ⇒ Q ⇔ R ∧ S

Step 1: ¬P binds first → (¬P) ⇒ Q ⇔ R ∧ S

Step 2: ∧ binds next → (¬P) ⇒ Q ⇔ (R ∧ S)

Step 3: ⇒ binds next → ((¬P) ⇒ Q) ⇔ (R ∧ S)

Step 4: ⇔ binds last → ((¬P) ⇒ Q) ⇔ (R ∧ S)

Result: "(not P implies Q) if and only if (R and S)"

Parentheses for Disambiguation

Common Mistake: Forgetting that implication is right-associative.
P ⇒ Q ⇒ R is parsed as P ⇒ (Q ⇒ R), NOT (P ⇒ Q) ⇒ R.

Exam Tip: When in doubt, add parentheses! The safest approach is to fully parenthesize every expression to avoid ambiguity.

Common Equivalences to Know

Double Negation
¬¬P ≡ P
De Morgan's Laws
¬(P ∧ Q) ≡ ¬P ∨ ¬Q
¬(P ∨ Q) ≡ ¬P ∧ ¬Q
Implication Conversion
P ⇒ Q ≡ ¬P ∨ Q
Contrapositive
P ⇒ Q ≡ ¬Q ⇒ ¬P
