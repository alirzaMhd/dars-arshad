Breadth-First Search

BFS explores a graph in waves radiating from a source vertex s. It discovers all vertices at distance k before moving to distance k+1.

Source: Vertex 0

Graph: 6 vertices, 7 undirected edges

BFS Algorithm

1. Color all vertices WHITE, set d = ∞, π = NIL

2. Color source GRAY, d = 0, enqueue it

3. While queue ≠ ∅: dequeue u, explore neighbors

• If neighbor v is WHITE: color GRAY, d = d[u]+1, π = u, enqueue v

4. Color u BLACK when done

Shortest-path distance δ(s,v) = d[v] (min edges from s to v)

BFS works on both directed and undirected graphs. Press Play to begin.
