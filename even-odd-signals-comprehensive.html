Even and Odd Signals

Signals and Systems — Complete Guide for Exam Preparation

Even Signal Definition

Continuous-Time Even Signal
x(t) = x(-t)
A signal is even if its value at time t equals its value at time -t for all t.
Discrete-Time Even Signal
x[n] = x[-n]
A discrete signal is even if its value at index n equals its value at index -n for all n.
Symmetry Property

Even signals are symmetric about the vertical (y) axis. If you fold the signal along the y-axis, the left side lands exactly on the right side.

Odd Signal Definition

Continuous-Time Odd Signal
x(-t) = -x(t)
A signal is odd if its value at time -t equals the negative of its value at time t for all t.
Discrete-Time Odd Signal
x[-n] = -x[n]
A discrete signal is odd if its value at index -n equals the negative of its value at index n for all n.
Symmetry Property

Odd signals are symmetric about the origin. If you rotate the signal 180 degrees about the origin, it looks identical. Also, for any odd signal, x(0) = 0 and x[0] = 0.

Signal Type Reason
cos(t) Even cos(-t) = cos(t)
sin(t) Odd sin(-t) = -sin(t)

Important: A signal does NOT have to be even or odd. Most signals are neither. A signal can only be one or the other if it satisfies the condition for ALL t (continuous) or ALL n (discrete).

Mathematical Note: "iff"

Abbreviation
iff ≡ "if and only if"
In mathematics, "iff" is a standard abbreviation for "if and only if." It means the condition works both ways — the implication goes in both directions.
Example Usage

"x(t) is even iff x(t) = x(-t) for all t."

This means:

→ If x(t) = x(-t) for all t, then x(t) is even.

← If x(t) is even, then x(t) = x(-t) for all t.

Both directions must hold. This is stronger than just "if" (one direction only).

Decomposing Any Signal into Even + Odd Parts

Fundamental Decomposition
x(t) = x_e(t) + x_o(t)
Every signal can be written as the sum of its even part x_e(t) and its odd part x_o(t).
This decomposition is unique — there is only one way to split a signal into even and odd parts.

Even Part Formula

Continuous-Time Even Part
x_e(t) = (1/2)[x(t) + x(-t)]
Average the signal with its time-reversed version.
Discrete-Time Even Part
x_e[n] = (1/2)[x[n] + x[-n]]
Same idea for discrete signals.

Odd Part Formula

Continuous-Time Odd Part
x_o(t) = (1/2)[x(t) - x(-t)]
Half the difference between the signal and its time-reversed version.
Discrete-Time Odd Part
x_o[n] = (1/2)[x[n] - x[-n]]
Same idea for discrete signals.

Verification: Decomposition Property

Any signal can be decomposed as:
x(t) = x_e(t) + x_o(t)
where x_e(t) is even and x_o(t) is odd.
Step-by-Step Proof That x_e(t) + x_o(t) = x(t)

Given:

x_e(t) = (1/2)[x(t) + x(-t)]

x_o(t) = (1/2)[x(t) - x(-t)]

Compute the sum:

x_e(t) + x_o(t) = (1/2)[x(t) + x(-t)] + (1/2)[x(t) - x(-t)]

= (1/2)[x(t) + x(-t) + x(t) - x(-t)]

= (1/2)[2x(t)]

= x(t) ✓

Why This Works

The even part captures all the symmetric components of the signal. The odd part captures all the anti-symmetric components. Together they reconstruct the original signal perfectly.

Common mistake: Forgetting the factor of 1/2. Without it, you get x(t) + x(-t) for the even part, which is double the actual even component.

Integration Properties

Odd Function over Symmetric Interval
∫_{-T}^{T} x_o(t) dt = 0
The integral of any odd function over a symmetric interval [-T, T] is always zero. This is because the area on the left side exactly cancels the area on the right side.
Even Function over Symmetric Interval
∫_{-T}^{T} x_e(t) dt = 2∫_{0}^{T} x_e(t) dt
The integral of an even function over [-T, T] equals twice the integral from 0 to T. You only need to compute half the integral and double it.
Quick Proof for Odd Functions

Let u = -t, then du = -dt. When t = -T, u = T. When t = T, u = -T.

∫_{-T}^{T} x_o(t) dt = ∫_{T}^{-T} x_o(-u)(-du) = ∫_{-T}^{T} (-x_o(u)) du = -∫_{-T}^{T} x_o(u) du

So I = -I, which means 2I = 0, so I = 0.

Multiplication Properties

Signal 1 Signal 2 Product Reason
Even Even Even [(-t)²]·[cos(-t)] = t²·cos(t)
Odd Odd Even [(-t)³]·[sin(-t)] = (-t³)·(-sin t) = t³·sin(t)
Even Odd Odd [(-t)²]·[sin(-t)] = t²·(-sin t) = -(t²·sin t)
Odd Even Odd [(-t)³]·[cos(-t)] = (-t³)·cos(t) = -(t³·cos t)
Key rule: Even × Even = Even, Odd × Odd = Even, Even × Odd = Odd. The product of two identical parity signals is always even.

Additional Properties

Derivative
Even → Odd

The derivative of an even signal is odd, and vice versa.

Sum
Even + Odd → Neither

Adding even and odd parts generally yields a signal that is neither even nor odd.

x(0) for Odd
x[0] = 0 always

An odd signal must pass through the origin: x(0) = 0.

Energy
E_x = E_xe + E_xo

Total energy equals the sum of energies of the even and odd parts (cross terms vanish).

Worked Example 1: Identify Even or Odd

Determine whether x(t) = e^(-|t|) is even, odd, or neither.

Step 1: Compute x(-t).

x(-t) = e^(-|-t|) = e^(-|t|)

Step 2: Compare with x(t).

x(-t) = e^(-|t|) = x(t)

Answer: x(t) = e^(-|t|) is an EVEN signal.

Worked Example 2: Decompose into Even and Odd

Find the even and odd parts of x(t) = e^(t) for all t.

Step 1: Compute x(-t).

x(-t) = e^(-t)

Step 2: Compute the even part.

x_e(t) = (1/2)[x(t) + x(-t)] = (1/2)[e^t + e^(-t)] = cosh(t)

Step 3: Compute the odd part.

x_o(t) = (1/2)[x(t) - x(-t)] = (1/2)[e^t - e^(-t)] = sinh(t)

Step 4: Verify.

x_e(t) + x_o(t) = cosh(t) + sinh(t) = (e^t + e^(-t))/2 + (e^t - e^(-t))/2 = e^t = x(t) ✓

Answer: x_e(t) = cosh(t), x_o(t) = sinh(t).

Worked Example 4: Product Property

If x(t) = t is odd and y(t) = cos(t) is even, what is z(t) = x(t)·y(t)?

Step 1: Check: z(-t) = x(-t)·y(-t) = (-t)·cos(t) = -t·cos(t) = -z(t).

Answer: z(t) = t·cos(t) is an ODD signal.

This confirms: even × odd = odd.

Worked Example 5: Integration Using Symmetry

Evaluate ∫_{-π}^{π} t·cos(t) dt.

Step 1: Identify the parity of f(t) = t·cos(t).

t is odd, cos(t) is even. Therefore f(t) = t·cos(t) is odd × even = odd.

Step 2: Apply the odd function integration property.

Since f(t) is odd and the interval [-π, π] is symmetric:

∫_{-π}^{π} t·cos(t) dt = 0

No need to actually compute the integral! Recognizing the symmetry saves significant work.

Worked Example 6: Odd Part Integral (PDF Example)

Given x(t) shown in the figure, find the odd part o_x(t) and evaluate ∫₀^∞ o_x(t) dt.

Given signal: x(t) = 2 for 0 ≤ t ≤ 3, and x(t) = 0 otherwise.

Step 1: Find x(-t).

x(-t) = 2 for -3 ≤ t ≤ 0, and x(-t) = 0 otherwise.

Step 2: Apply the odd part formula.

Odd Part Formula
o_x(t) = (1/2)[x(t) - x(-t)]

For t > 0: x(t) = 2 (if t ≤ 3), x(-t) = 0 → o_x(t) = (1/2)(2 - 0) = 1

For t < 0: x(t) = 0, x(-t) = 2 (if t ≥ -3) → o_x(t) = (1/2)(0 - 2) = -1

Step 3: Evaluate ∫₀^∞ o_x(t) dt.

Since o_x(t) = 1 for 0 < t < 3 and o_x(t) = 0 for t > 3:

∫₀^∞ o_x(t) dt = ∫₀³ 1 dt = 3

Answer: o_x(t) = 1 for 0 < t < 3, o_x(t) = -1 for -3 < t < 0, and ∫₀^∞ o_x(t) dt = 3.

Worked Example 7: Integral with Change of Variables

Verify that ∫_{-∞}^{∞} o_x(t) dt = 0 using the definition and a change of variables.

Recall: o_x(t) = (1/2)[x(t) - x(-t)].

Step 1: Write out the integral.

∫_{-∞}^{∞} o_x(t) dt = ∫_{-∞}^{∞} (1/2)[x(t) - x(-t)] dt

= (1/2)∫_{-∞}^{∞} x(t) dt - (1/2)∫_{-∞}^{∞} x(-t) dt

Step 2: Apply the substitution λ = -t in the second integral.

Let λ = -t, then dλ = -dt. When t = -∞, λ = ∞. When t = ∞, λ = -∞.

∫_{-∞}^{∞} x(-t) dt = ∫_{∞}^{-∞} x(λ)(-dλ) = ∫_{-∞}^{∞} x(λ) dλ

Step 3: Combine.

∫_{-∞}^{∞} o_x(t) dt = (1/2)∫_{-∞}^{∞} x(t) dt - (1/2)∫_{-∞}^{∞} x(t) dt

= 0 ✓
The integral of any odd function over a symmetric interval is zero. This is consistent with our earlier result.

Note: While ∫_{-∞}^{∞} o_x(t) dt = 0, the one-sided integral ∫₀^∞ o_x(t) dt is generally NOT zero — it equals 3 in our example above.

Common Mistakes to Avoid

Mistake 1: Forgetting the 1/2 factor in decomposition. The formulas are x_e(t) = (1/2)[x(t) + x(-t)], NOT x(t) + x(-t).
Mistake 2: Assuming all signals are either even or odd. Most signals are neither. Only signals satisfying x(t) = x(-t) or x(-t) = -x(t) for ALL t qualify.
Mistake 3: Thinking x(0) can be nonzero for an odd signal. Since x(-0) = -x(0), we get x(0) = -x(0), so 2x(0) = 0, meaning x(0) = 0 always.
Mistake 4: Confusing even/odd with symmetric/antisymmetric. In signals context, these terms are used interchangeably, but be careful with the terminology.
