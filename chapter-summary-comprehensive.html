CHAPTER SUMMARY: SEARCH AND HASHING

Data Structures — Complete Guide for 20/20 Exam

Search Techniques Summary

1. Linear Search

• Search element x in A[1..n]

• Start from beginning, check each element

• Time: O(n)

• Works on any array (sorted or unsorted)

2. Binary Search

• Search x in sorted array A[1..n]

• Compare with middle, search half

• Time: O(log n)

• Requires sorted array

3. Binary Search on Rotated

• Find minimum in rotationally sorted array

• Compare A[mid] with A[U]

• Time: O(log n)

• Works because one half is always sorted

4. Binary Search for A[i]=i

• Find index where A[i] = i

• Requires distinct elements

• Time: O(log n)

• Compare A[mid] with mid

5. Binary Search (Unknown Length)

• Search in array with unknown size

• Two phases: find bounds, then search

• Time: O(log i) where i is answer index

• Better when target is near beginning

6. Interpolation Search

• Estimate position based on value

• Requires uniform distribution

• Time: Θ(log log n) average

• Worst case: Θ(n)

Hashing Summary

Goal of Hashing:
O(1) for search, insert, and delete
Achieved through hash function and collision resolution

Hash Function

• Maps key k to address h(k)

• h(k) = k mod m (simple hash)

• m = number of slots in table

Collision

• When h(k₁) = h(k₂) for k₁ ≠ k₂

• Must resolve to continue operations

• Two main approaches

Chaining

• Each slot points to linked list

• Elements with same hash go to same list

• Insert at beginning: O(1)

• Search: O(1 + α) average

Open Addressing

• All elements in table itself

• Linear probing: check next slot

• Must have n ≤ m

• Search: O(1/(1-α)) average

Key Formulas

Binary Search Recurrence:
T(n) = T(n/2) + Θ(1) → T(n) = Θ(log n)
Halves search space each step
Load Factor:
α = n/m
n = elements, m = slots. Average elements per slot.
Chaining Search (Average):
Θ(1 + α)
Constant time plus α for list traversal
Open Addressing Search (Average):
Θ(1/(1-α))
Degrades as α approaches 1
Interpolation Search Position:
Next_Guess = L + ((x - A[L]) × (U - L)) / (A[U] - A[L])
Linear interpolation to estimate position
Collision Probability:
P(collision) = 1/m
For two elements with simple hash function
