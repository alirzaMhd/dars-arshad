8-Puzzle Problem

The 8-puzzle consists of a 3x3 board with 8 numbered tiles and one blank. A tile adjacent to the blank can slide into the blank space. The goal is to reach the ordered configuration.

States

Arrangement of 8 tiles + blank on 3x3 board

Initial State

Any permutation of tiles

Actions

Slide blank Up, Down, Left, Right

Goal Test

Tiles 1-8 in order, blank at bottom-right

Path Cost

1 per move

State Space:
9! = 362,880 total permutations
Exactly half are reachable from any given state due to parity constraints. Reachable states = 181,440.
Example - Solvability Check

Configuration with inversion count odd is unsolvable. Inversions: pairs (i,j) where i appears before j but i > j. If inversion count is odd, puzzle is unsolvable.

NP-Complete Family: The 8-puzzle is part of the sliding-block puzzle family, which is NP-complete. Larger variants (15-puzzle, 24-puzzle) have exponentially more states and quickly become intractable for blind search.

8-Queens Problem

Place 8 queens on a chessboard so that no two queens attack each other. Queens attack along rows, columns, and diagonals.

States (Incremental)

Arrangement of 0 to 8 queens on board

Initial State

No queens on board

Actions

Add queen to any non-attacked square

Goal Test

8 queens placed with no attacks

Path Cost

0 (only final state matters)

State Space Sizes:
Incremental: 10^14 candidates to check
Complete-state with column constraint: 2,057 states
By enforcing that queens are placed left-to-right with no two in the same column, the search space shrinks from 10^14 to just 2,057.
Example - Constraint Propagation

With 1 queen, it must be in column 0 (leftmost). With 2 queens, the second queen can only be placed in columns 1-7 where it is not attacked by the first queen. This incremental constraint dramatically reduces branching.

Vacuum Cleaner World

A simple world with two squares (A and B). The agent can move left, move right, or suck dirt. Each square can be clean or dirty.

States

Agent location + dirt status of A and B

State Count

2 locations x 2^2 dirt status = 8 states

Actions

Left, Right, Suck

Goal Test

Both squares clean

Example - Deterministic Version

From state (A, Dirty, Dirty), Suck leads to (A, Clean, Dirty). From there, Right leads to (B, Clean, Dirty). Suck leads to (B, Clean, Clean) = goal. Total cost: 3.

Example - Sensorless Version

Agent knows initial belief is one of {1,2,3,4,5,6,7,8}. After [Right, Suck, Left, Suck], the belief state becomes {7} for sure. This is a guaranteed plan without any sensors.

Missionaries and Cannibals Problem

Three missionaries and three cannibals are on the left bank of a river. A boat that carries 1 or 2 people must transport everyone to the right bank. Missionaries cannot be outnumbered by cannibals on either bank.

States

(M, C, B) where M = missionaries on left, C = cannibals on left, B = boat position (L/R)

Initial State

(3, 3, L)

Actions

Move 1M, 1C, 2M, 2C, or 1M+1C across

Goal Test

(0, 0, R)

Safety Constraint:
On each bank: if M > 0 then M >= C
Missionaries must never be outnumbered on either bank, unless no missionaries are present on that bank.
Example - Valid Move Sequence

(3,3,L) → (2,2,R) [1M+1C cross] → (3,2,L) [1C returns] → (3,0,R) [2C cross] → (3,1,L) [1C returns] → (1,1,R) [2M cross] → (2,2,L) [1M+1C return] → (0,3,R) [2M cross] → (0,2,L) [1C returns] → (0,3,R) [2C cross] → (0,2,L) [1C returns] → (0,0,R). Total: 11 moves.

Real-World Problem Formulations

Example 1 - Airline Travel Planning

States: Current airport + current time
Actions: Scheduled flights between airports
Goal Test: At destination by required time
Path Cost: Money + waiting time + flight duration + immigration time + seat quality

Example 2 - Traveling Salesperson Problem (TSP)

States: Current city + set of visited cities
Initial State: (StartCity, {StartCity})
Goal Test: At StartCity having visited all cities
Path Cost: Sum of distances traveled
Note: NP-hard problem with n! possible tours.

Example 3 - Robot Navigation

States: Continuous robot pose (x, y, theta)
Actions: Continuous motion controls
Challenge: Infinite state space requires discretization or advanced sampling techniques.

Example 4 - VLSI Cell Layout

States: Positions of all cells on chip
Actions: Move a cell to a new position
Goal: Non-overlapping placement with minimal wire length and delay
Complexity: Millions of components make direct search infeasible; specialized heuristics required.

Example 5 - Internet Search Agent

States: Current web page
Actions: Click a link
Goal Test: Found answer to user query
Path Cost: Number of clicks or time spent
Note: Web as a directed graph with billions of nodes; search requires heuristic guidance.
