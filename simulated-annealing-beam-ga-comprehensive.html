Simulated Annealing, Beam Search & Genetic Algorithms

Informed Search Algorithms — Chapter 3

Simulated Annealing

Simulated annealing combines greedy hill climbing with random walk. It accepts downhill moves with a probability that decreases over time, allowing escape from local maxima. Inspired by annealing in metallurgy: heat metal then cool slowly.

Acceptance Probability:
P(accept downhill) = exp(deltaE / T)
deltaE = VALUE[next] - VALUE[current]. T = temperature. As T decreases, downhill moves become less likely. When T=0, behavior matches first-choice hill climbing.
function SIMULATED-ANNEALING(problem, schedule) returns a state current ← MAKE-NODE(INITIAL-STATE[problem]) for t = 1 to infinity do T ← schedule(t) if T = 0 then return current next ← randomly selected successor of current deltaE ← VALUE[next] - VALUE[current] if deltaE > 0 then current ← next else current ← next with probability exp(deltaE / T)

Worked Example

Effect of Temperature Schedule

At high T, the algorithm behaves like a random walk, exploring broadly. As T decays, it mimics greedy hill climbing. If cooling is too fast, it gets stuck in local maxima. With a sufficiently slow schedule, it converges to the global optimum with probability near 1.

Applications: VLSI layout, factory scheduling, large-scale optimization.

Warning: If T is reduced too quickly, the algorithm behaves like greedy hill climbing and may get stuck in local maxima. If T stays high too long, the search is inefficient.

Local Beam Search

Local beam search keeps k states in memory instead of one. At each iteration, all successors of all k states are generated, and the best k are retained. This is different from random-restart: states share information.

Stochastic Beam Search

Select the next k states probabilistically based on value, rather than deterministically taking the top k. This maintains diversity and avoids converging to a single region.

Selection Probability:
P(state i) ∝ exp(VALUE(state i) / T)
Worked Example: Beam Search Motivation

With k=5 beam states, if one state produces many good offspring and others produce poor ones, the good state's offspring dominate the next beam. This information sharing speeds convergence. Stochastic selection prevents premature convergence to one region.

Warning: Beam search may suffer from lack of diversity: all k states may concentrate in one region, missing better regions entirely.

Genetic Algorithms (GA)

A genetic algorithm is a variant of stochastic beam search where successors are produced by combining two parent states, not by modifying one state. It models natural selection.

function GENETIC-ALGORITHM(population, FITNESS-FN) returns individual repeat new-population ← empty set for i = 1 to SIZE(population) do x ← RANDOM-SELECTION(population, FITNESS-FN) y ← RANDOM-SELECTION(population, FITNESS-FN) child ← REPRODUCE(x, y) if small random probability then child ← MUTATE(child) add child to new-population population ← new-population until some individual is fit enough or time elapsed return best individual in population

Worked Example: 8-Queens GA

Population, Fitness, Crossover, Mutation

Population: 4 random 8-digit strings, e.g., 24748552, 32752411, 32752411, 24415124.

Fitness: number of non-attacking pairs. Max = 28. Values: 24 (31%), 23 (29%), 20 (26%), 11 (14%).

Crossover: pick a random crossover point. Parent1=24748552, Parent2=32752411 at position 3 gives Child=24752411.

Mutation: flip a random digit with small probability. If mutation hits position 4 of child 24415124, it might become 24415411.

Why Crossover Matters

Crossover combines building blocks -- subsequences that evolved for useful functionality. If two parents both have non-attacking triples in positions 1-3, crossover can preserve those blocks while exploring new combinations in positions 4-8.

Warning: GA with population size 1 is equivalent to random walk. The power of GA comes from maintaining a diverse population.

Schema Theorem

A schema is a substring with wildcards. The Schema Theorem shows that short, low-order schemas with above-average fitness grow exponentially in the population, while others die out.

Schema Theorem Estimate:
E[m(s, t+1)] ≥ m(s, t) × (f(s) / f_avg) × (1 - p_c × delta(s) / l) × (1 - p_m × o(s))
m(s,t)=instances of schema s at generation t; f(s)=avg fitness; p_c=crossover prob; delta(s)=defining length; l=string length; p_m=mutation prob; o(s)=order.

Summary

Simulated annealing trades completeness and near-optimality for simplicity, using only one state. Beam search and genetic algorithms maintain multiple states to share information. GA's crossover is its defining advantage: it combines building blocks from two parents to explore structured subspaces more efficiently than mutation alone.
