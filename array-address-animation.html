Problem Setup

Calculate the memory address of element A[i,j] in a 2D array stored in memory.

Array dimensions: 3×3, Base address: α = 1000, Element size: n = 4 bytes

Row Major Formula

Addr(A[i,j]) = α + n × [i × (U₂ - L₂ + 1) + (j - L₂)]

L₁, U₁ = lower, upper bounds of row dimension

L₂, U₂ = lower, upper bounds of column dimension

Column Major Formula

Addr(A[i,j]) = α + n × [(i - L₁) + (U₁ - L₁ + 1) × (j - L₂)]
