System Properties

Signals and Systems — Complete Guide for Exam Preparation

Memory

A system is memoryless if its output at any time depends ONLY on the input at that same time.

Memoryless System Definition
y(t) = f[x(t)]
Output at time t depends only on input at time t — no past or future values needed.

Memoryless vs. Systems with Memory

PropertyMemorylessWith Memory
Depends onCurrent input onlyPast and/or future inputs
Exampley(t) = x(t)y(t) = x(t-2)
Storage neededNonePrevious values must be stored
Example 1: Memoryless System
y(t) = x(t)
Output equals input at the same time. No past or future values needed.

✓ Memoryless — At t = 3, y(3) = x(3). Only current value used.

Example 2: System with Memory
y(t) = x(t - 2)
Output is input delayed by 2 seconds — needs past values.

✗ Has Memory — At t = 3, y(3) = x(1). Requires value from 2 seconds ago.

⚠ Common Mistake: y(t) = x(2t) looks like it only uses current time, but at t = 3 it needs x(6) — a future value. This is NOT memoryless.

Invertibility

A system is invertible if different inputs always produce different outputs. The inverse system recovers the original input from the output.

Invertibility Condition
If x₁(t) ≠ x₂(t) ⟹ y₁(t) ≠ y₂(t)
Distinct inputs must produce distinct outputs for invertibility.
Inverse System
y(t) = f[x(t)] → x(t) = f⁻¹[y(t)]
If the system is invertible, we can recover x(t) from y(t).
Example 3: Invertible System
y(t) = 3x(t)
Step 1: Different inputs give different outputs: x₁(t) = 1 → y₁(t) = 3, x₂(t) = 2 → y₂(t) = 6
Step 2: Inverse: x(t) = y(t) / 3

✓ Invertible

Example 4: Non-Invertible System
y(t) = x²(t)
Step 1: Test: x₁(t) = 2 → y₁(t) = 4, x₂(t) = -2 → y₂(t) = 4
Step 2: Different inputs (2 and -2) produce SAME output (4)

✗ Not Invertible — Cannot distinguish between x and -x from output.

⚠ Common Mistake: y(t) = |x(t)| is NOT invertible because x(t) = 2 and x(t) = -2 both give y(t) = 2.

Causality

A system is causal if its output at any time depends only on current and PAST inputs (not future inputs).

Causal System Condition
y(t₀) depends on x(t) where t ≤ t₀ only
No future values of input are used.

Key Properties of Causal Systems

All memoryless systems are causal
No memory = no future values used
Systems with delays are causal
x(t-t₀) for t₀ > 0 uses past values
Real-time systems must be causal
Cannot access future inputs in real-time
Example 5: Causal System
y(t) = x(t - 2)
Output at time t uses input from 2 seconds ago (past).

✓ Causal — Only past input values are used.

Example 6: Non-Causal System
y(t) = x(t + 2)
Output at time t uses input from 2 seconds in the future.

✗ Non-Causal — Requires future input value.

Example 7: Mixed System
y(t) = x(t) + x(t - 1)
Uses current input and one past input.

✓ Causal — Only current and past values used.

⚠ y(t) = x(t+1) + x(t-1) is NOT causal because of the x(t+1) term (future input).

Stability (BIBO)

A system is BIBO Stable (Bounded-Input Bounded-Output) if every bounded input produces a bounded output.

BIBO Stability Condition
|x(t)| ≤ Mₓ < ∞ ⟹ |y(t)| ≤ Mᵧ < ∞
If input is bounded by Mₓ, output must be bounded by some finite Mᵧ.
Example 8: Stable System
y(t) = x(t - 1)
Output is just a delayed version of input.
Step 1: If |x(t)| ≤ Mₓ for all t, then |x(t-1)| ≤ Mₓ
Step 2: Therefore |y(t)| = |x(t-1)| ≤ Mₓ = Mᵧ

✓ BIBO Stable

Example 9: Unstable System
y(t) = t · x(t)
Output is input multiplied by time.
Step 1: Let x(t) = u(t) (unit step), which is bounded: |x(t)| ≤ 1
Step 2: Then y(t) = t · u(t) which grows without bound as t → ∞

✗ Not BIBO Stable — Bounded input produces unbounded output.

Example 10: Unstable Accumulator
y(t) = ∫₋∞ᵗ x(τ) dτ
System accumulates (integrates) all past input values.
Step 1: Let x(t) = u(t) (unit step), bounded at 1
Step 2: y(t) = ∫₋∞ᵗ u(τ) dτ = t for t > 0, which grows without bound

✗ Not BIBO Stable

⚠ A system can be causal but unstable (like y(t) = t·x(t)), or stable but non-causal.

Time Invariance

A system is time-invariant if a time shift in the input produces the same time shift in the output.

Time Invariance Condition
If x(t) → y(t), then x(t - t₀) → y(t - t₀)
Shifting input by t₀ shifts output by t₀.

How to Test for Time Invariance

Step 1: Find y(t) = T{x(t)}
Step 2: Find y(t - t₀) by replacing t with (t - t₀) in the output expression
Step 3: Find response to shifted input: T{x(t - t₀)}
Step 4: If Step 2 = Step 3, system is time-invariant
Example 11: Time-Invariant System
y(t) = 2x(t) + 3
Step 1: y(t) = 2x(t) + 3
Step 2: y(t - t₀) = 2x(t - t₀) + 3
Step 3: Response to x(t-t₀): 2x(t-t₀) + 3
Step 4: They match! ✓ Time-Invariant
Example 12: Time-Variant System
y(t) = t · x(t)
Step 1: y(t) = t · x(t)
Step 2: y(t - t₀) = (t - t₀) · x(t - t₀)
Step 3: Response to x(t-t₀): t · x(t - t₀)
Step 4: (t - t₀)·x(t-t₀) ≠ t·x(t-t₀) → ✗ Time-Variant
⚠ Systems with time-dependent coefficients (like t, sin(t), eᵗ multiplying x) are typically time-variant.

Linearity

A system is linear if it satisfies the principle of superposition, which combines two properties:

Additivity
x₁(t) + x₂(t) → y₁(t) + y₂(t)

Sum of inputs produces sum of outputs

Homogeneity (Scaling)
a · x(t) → a · y(t)

Scaling input scales output by same factor

Linearity Condition (Superposition)
a·x₁(t) + b·x₂(t) → a·y₁(t) + b·y₂(t)
Combined additivity and homogeneity must hold for all inputs and all constants a, b.

How to Test for Linearity

Step 1: Apply input a·x₁(t) + b·x₂(t) to the system
Step 2: Find the output y(t) = T{a·x₁(t) + b·x₂(t)}
Step 3: Find a·y₁(t) + b·y₂(t) where y₁ = T{x₁} and y₂ = T{x₂}
Step 4: If Step 2 = Step 3 for ALL a, b, x₁, x₂ → Linear
Example 13: Linear System
y(t) = 2x(t)
Step 1: T{a·x₁ + b·x₂} = 2(a·x₁ + b·x₂) = 2a·x₁ + 2b·x₂
Step 2: a·y₁ + b·y₂ = a·(2x₁) + b·(2x₂) = 2a·x₁ + 2b·x₂
Step 3: They match! ✓ Linear
Example 14: Non-Linear System
y(t) = x(t) + 1
Step 1: Test with x = 0: y = 0 + 1 = 1 ≠ 0
Step 2: Linear system must give 0 output for zero input!

✗ Not Linear — Fails homogeneity (zero input should give zero output).

Example 15: Non-Linear System (Squared)
y(t) = x²(t)
Step 1: T{a·x₁} = (a·x₁)² = a²·x₁²
Step 2: a·T{x₁} = a·x₁²
Step 3: a²·x₁² ≠ a·x₁² (unless a = 0 or 1)

✗ Not Linear — Fails homogeneity.

⚠ Common Mistake: y(t) = x(t) + 1 looks "almost linear" but the constant +1 makes it non-linear. Any additive constant breaks linearity.

Worked Examples — All 6 Properties

Each example tests all 6 properties: Memory, Invertibility, Causality, Stability, Time Invariance, and Linearity.

Example A: y(t) = 3x(t) + 2

1. Memory

Output at time t depends only on x(t) — current input only.

✓ Memoryless

2. Invertibility

Different inputs give different outputs. Inverse: x(t) = (y(t) - 2) / 3

✓ Invertible

3. Causality

Memoryless systems are always causal.

✓ Causal

4. Stability (BIBO)

If |x(t)| ≤ Mₓ, then |y(t)| = |3x(t) + 2| ≤ 3Mₓ + 2 < ∞

✓ BIBO Stable

5. Time Invariance

y(t-t₀) = 3x(t-t₀) + 2, and T{x(t-t₀)} = 3x(t-t₀) + 2. They match.

✓ Time-Invariant

6. Linearity

Test zero input: x(t) = 0 → y(t) = 3(0) + 2 = 2 ≠ 0

✗ Not Linear (additive constant)

Example B: y(t) = x(t - 1)

1. Memory

Output at time t depends on x(t-1) — input from 1 second ago.

✗ Has Memory

2. Invertibility

Different inputs give different outputs. Inverse: x(t) = y(t + 1)

✓ Invertible

3. Causality

Uses only past input (t-1 < t). Always accesses previous values.

✓ Causal

4. Stability (BIBO)

If |x(t)| ≤ Mₓ, then |y(t)| = |x(t-1)| ≤ Mₓ < ∞

✓ BIBO Stable

5. Time Invariance

y(t-t₀) = x(t-t₀-1), and T{x(t-t₀)} = x((t-t₀)-1) = x(t-t₀-1). Match.

✓ Time-Invariant

6. Linearity

T{a·x₁ + b·x₂} = a·x₁(t-1) + b·x₂(t-1) = a·y₁ + b·y₂

✓ Linear

Example C: y(t) = x²(t)

1. Memory

Output at time t depends only on x(t) — current input.

✓ Memoryless

2. Invertibility

x = 2 and x = -2 both give y = 4. Cannot recover original sign.

✗ Not Invertible

3. Causality

Memoryless systems are always causal.

✓ Causal

4. Stability (BIBO)

If |x(t)| ≤ Mₓ, then |y(t)| = |x(t)|² ≤ Mₓ² < ∞

✓ BIBO Stable

5. Time Invariance

y(t-t₀) = x²(t-t₀), and T{x(t-t₀)} = x²(t-t₀). Match.

✓ Time-Invariant

6. Linearity

T{a·x₁} = (a·x₁)² = a²·x₁² ≠ a·x₁² = a·T{x₁}

✗ Not Linear (fails homogeneity)

Example D: y(t) = t · x(t)

1. Memory

Output at time t depends only on x(t) — current input.

✓ Memoryless

2. Invertibility

For t ≠ 0: x(t) = y(t)/t. Different inputs give different outputs.

✓ Invertible (for t ≠ 0)

3. Causality

Memoryless systems are always causal.

✓ Causal

4. Stability (BIBO)

Let x(t) = u(t) (bounded by 1). Then y(t) = t·u(t) → ∞ as t → ∞.

✗ Not BIBO Stable

5. Time Invariance

y(t-t₀) = (t-t₀)·x(t-t₀), but T{x(t-t₀)} = t·x(t-t₀). Not equal!

✗ Time-Variant

6. Linearity

T{a·x₁ + b·x₂} = t(a·x₁ + b·x₂) = a·(t·x₁) + b·(t·x₂) = a·y₁ + b·y₂

✓ Linear

Example E: y(t) = x(t + 1) + x(t - 1)

1. Memory

Uses x(t+1) — a future value. Requires storage of past and future inputs.

✗ Has Memory

2. Invertibility

Invertible via frequency domain or solving system of equations.

✓ Invertible

3. Causality

x(t+1) requires future input at time t+1.

✗ Non-Causal

4. Stability (BIBO)

If |x(t)| ≤ Mₓ, then |y(t)| ≤ |x(t+1)| + |x(t-1)| ≤ 2Mₓ < ∞

✓ BIBO Stable

5. Time Invariance

y(t-t₀) = x(t-t₀+1) + x(t-t₀-1) = T{x(t-t₀)}. Match.

✓ Time-Invariant

6. Linearity

T{a·x₁ + b·x₂} = a·x₁(t+1) + b·x₂(t+1) + a·x₁(t-1) + b·x₂(t-1) = a·y₁ + b·y₂

✓ Linear

Common Exam Patterns:
• y(t) = x(t) + C → Memoryless, Invertible, Causal, Stable, TI, NOT Linear
• y(t) = A·x(t) → Memoryless, Invertible, Causal, Stable, TI, Linear
• y(t) = x(t-t₀) → Has Memory, Invertible, Causal, Stable, TI, Linear
• y(t) = t·x(t) → Memoryless, Invertible, Causal, NOT Stable, NOT TI, Linear
• y(t) = x²(t) → Memoryless, NOT Invertible, Causal, Stable, TI, NOT Linear
