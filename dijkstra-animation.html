🎯 Dijkstra's Algorithm

Dijkstra's algorithm finds single-source shortest paths in a weighted directed graph with non-negative edge weights.

📝 How It Works

d[v]: current shortest distance estimate from source s to vertex v. Starts at ∞ (except d[s]=0).

π[v]: predecessor of v on the current shortest path from s. Starts at NIL.

Q: min-priority queue of all vertices not yet settled, keyed by d[v].

S: set of settled vertices whose shortest distance is finalized.

📜 Pseudocode

Dijkstra(G, w, s):

1. INIT-SINGLE-SOURCE(G, s) — d[s]=0, d[v]=∞

2. S = ∅, Q = V (keyed by d)

3. While Q ≠ ∅:

u = EXTRACT-MIN(Q), S = S ∪ {u}

For each v ∈ Adj[u]: RELAX(u, v, w)

if v.d > u.d + w(u,v):

v.d = u.d + w(u,v), v.π = u

DECREASE-KEY(Q, v, v.d)

4. Return d and π
