Problem Setup

Find the shortest path between every pair of vertices in a weighted directed graph.

Input graph: 4 vertices, edges with weights (including negative).

Key Insight: Repeated Squaring

SLOW-APSP computes L(1), L(2), L(3) one by one — that's n-1 matrix multiplications.

FASTER-APSP uses repeated squaring (like fast exponentiation):

L^(2^p) = L^(2^(p-1)) ⊗ L^(2^(p-1))

After ⌈lg(n-1)⌉ squarings, we have paths using up to n-1 edges.

For n=4: only 2 squarings (vs 3 multiplications for SLOW).
