Problem Setup

Transpose a sparse matrix stored in triplet format (row, col, value).

For sparse matrices, we only store non-zero elements to save space.

Fast Transpose Algorithm

1. Count elements in each column of A 2. Compute starting position of each row in B 3. Place elements in correct position in B

Time complexity: O(n + t) where n = columns, t = non-zero elements
