BANDWIDTH

Physical Layer — Complete Guide for Exam

What is Bandwidth?

Bandwidth is the maximum rate of data transmission across a given path. It represents the capacity of a communication link — how much data can flow through it per unit of time.

Digital Bandwidth Definition:
Bandwidth = maximum bits per second (bps)
The peak data rate a channel can sustain under ideal conditions.

Two Types of Bandwidth

Digital Bandwidth

• Measured in bps (bits per second)

• Used in data networks

• Indicates max bit transmission rate

• Example: 100 Mbps Ethernet

Analog Bandwidth

• Measured in Hz (Hertz)

• Used in signal processing

• Range of frequencies in a signal

• Example: Voice = 3000 Hz range

Bandwidth vs Throughput

Bandwidth

• Theoretical maximum

• What the link is capable of

• Advertised by ISP / vendor

• Ideal conditions

Throughput

• Actual measured rate

• What you really get

• Affected by overhead, congestion

• Always ≤ bandwidth

⚠ Throughput is always less than or equal to bandwidth due to protocol overhead, noise, and network congestion.

Digital Bandwidth Formulas

Basic Digital Bandwidth:
Bandwidth = Total bits transmitted / Time (in seconds)
Average data rate over a period of time.
Maximum Throughput:
Throughput = File size (bits) / Transfer time (seconds)
Actual data transferred per unit time.
Time to Transfer:
Time = File size (bits) / Bandwidth (bps)
How long it takes to send a file of given size.

Analog Bandwidth Formulas

Bandwidth of a Signal:
BW = f_max − f_min
Where f_max is the highest frequency and f_min is the lowest frequency in the signal (in Hz).
Baseband Bandwidth:
BW = f_max − 0 = f_max
For baseband signals starting from 0 Hz, bandwidth equals the highest frequency.

Worked Examples

Example 1: Convert 1500 Kbps to Mbps

Problem: A network link operates at 1500 Kbps. What is this in Mbps?

Solution:

Step 1: Know the conversion factor: 1 Mbps = 1000 Kbps

Step 2: Divide by 1000:

1500 Kbps ÷ 1000 = 1.5 Mbps

Step 3: Verify: 1.5 × 1000 = 1500 Kbps ✓

Example 2: Analog Bandwidth of a Signal

Problem: A signal spans from 100 Hz to 4000 Hz. What is its bandwidth?

Solution:

Step 1: Identify f_min and f_max:

    f_min = 100 Hz, f_max = 4000 Hz

Step 2: Apply formula:

BW = f_max − f_min
BW = 4000 − 100 = 3900 Hz

The signal occupies a 3900 Hz frequency range.

Example 3: File Transfer Time

Problem: How long does it take to transfer a 1 GB file over a 100 Mbps link?

Solution:

Step 1: Convert file size to bits (1 GB = 1 GB in networking = 10⁹ bytes):

    1 GB = 10⁹ bytes × 8 bits/byte = 8 × 10⁹ bits

Step 2: Apply formula:

Time = File size (bits) / Bandwidth (bps)
Time = (8 × 10⁹) / (100 × 10⁶) = 80 seconds

Step 3: Convert: 80 seconds = 1 minute 20 seconds

Problem: Compare the bandwidth of UTP Cat5, Fiber Optic, and Coaxial cable.

Solution:

Example 5: Bandwidth Utilization

Problem: A 1 Gbps link achieves an actual throughput of 850 Mbps. What is the utilization percentage?

Solution:

Step 1: Identify values:

    Bandwidth = 1 Gbps = 1000 Mbps

    Throughput = 850 Mbps

Step 2: Apply formula:

Utilization = (Throughput / Bandwidth) × 100%
Utilization = (850 / 1000) × 100% = 85%

15% of bandwidth is lost to overhead, congestion, or noise.

Bits vs Bytes Conversion

Critical Rule:
1 Byte = 8 bits
Bandwidth is in bits per second (bps). File sizes are in Bytes. Always multiply Bytes × 8 to get bits.
Example Conversion:
1 GB file = 1 × 10⁹ × 8 = 8 × 10⁹ bits
Convert Bytes to bits before dividing by bandwidth in bps.
⚠ bps (bits per second) ≠ Bps (Bytes per second). A "100 Mbps" connection downloads at 12.5 MBps (Megabytes per second) because 100/8 = 12.5.

Common Mistakes to Avoid

Mistake 1

Confusing bandwidth with throughput

Bandwidth = theoretical max

Throughput = actual rate

Mistake 2

Bit vs Byte confusion

File size = Bytes

Bandwidth = bits

Always convert: ×8

Mistake 3

Using 1024 instead of 1000

Networking uses SI (1000)

Storage uses binary (1024)

Mistake 4

Forgetting protocol overhead

TCP/IP headers reduce

actual throughput
