Special Discrete-Time Signals

Signals and Systems — Complete Guide for Exam Preparation

1. General Discrete Exponential Signal

Definition
x[n] = C · βn
where C is a complex constant, β = eα, and α is a complex number

In discrete time, the exponent is raised to the power of n (not multiplied by n as in continuous time).

2. Real Exponential Signals

When both C and β are real-valued, the behavior of x[n] = Cβn depends on |β|:

|β| > 1 (Growing)

|β| > 1
Signal grows without bound as n → +∞
Example: β = 2

x[0] = 1, x[1] = 2, x[2] = 4, x[3] = 8, x[4] = 16, ...

Exponential growth

|β| < 1 (Decaying)

|β| < 1
Signal decays to zero as n → +∞
Example: β = 0.5

x[0] = 1, x[1] = 0.5, x[2] = 0.25, x[3] = 0.125, ...

Exponential decay

|β| = 1 (Constant)

|β| = 1
Signal remains constant in magnitude
Example: β = 1

x[n] = C for all n

DC signal

⚠ Common Mistake: Do not confuse |β| > 1 with β > 1. A negative β with |β| > 1 still grows but oscillates in sign.

3. Complex Exponential Signal

Definition
x[n] = C · ej(ω0n + φ)
where C is the amplitude, ω0 is the discrete angular frequency, and φ is the phase
Euler's Formula
ejθ = cos(θ) + j sin(θ)
Decomposes complex exponential into real and imaginary parts
⚠ Unlike continuous-time, ejω0t is NOT always periodic in discrete time. See periodicity condition below.

4. Sinusoidal Discrete Signal

Definition
x[n] = A cos(ω0n + φ)
where A is the amplitude, ω0 is the angular frequency, and φ is the phase offset

5. Periodicity of Discrete Sinusoids

Periodicity Condition
ω0 N0 = 2πk
where N0 is the fundamental period (smallest positive integer) and k is a positive integer
Solving for N0
N0 = 2πk / ω0
The smallest integer N0 such that N0 is an integer makes x[n] periodic
⚠ KEY DIFFERENCE: In continuous time, ALL sinusoids are periodic (for any ω0). In discrete time, a sinusoid is periodic ONLY if ω0/(2π) is a rational number. This is a very common exam question!
Example: ω0 = π/4

ω0/(2π) = (π/4)/(2π) = 1/8 (rational!)

N0 = 2π/(π/4) = 8 samples

Periodic with period N0 = 8

Example: ω0 = 1

ω0/(2π) = 1/(2π) ≈ 0.15915... (irrational!)

NOT periodic

6. Power of Periodic Discrete Sinusoid

Average Power
P = A2 / 2
The average power of x[n] = A cos(ω0n + φ) equals A²/2, same as the continuous-time case
Proof Outline
P = (1/N0) ∑N0-1n=0 |A cos(ω0n + φ)|2 = A2/2
Uses identity cos²(θ) = (1 + cos(2θ))/2 and the fact that the average of cos over a full period is zero

Note: The power is independent of ω0 and φ — it depends only on the amplitude A.

7. Discrete vs Continuous: Quick Comparison

Property Continuous: x(t) = Ceαt Discrete: x[n] = Cβn
Variable t (real, continuous) n (integer)
Exponent form eαt βn
Growing condition Re(α) > 0 |β| > 1
Decaying condition Re(α) < 0 |β| < 1
Sinusoid periodicity Always periodic Only if ω0/(2π) is rational
Impulse ambiguity δ(t) undefined at t=0 δ[n] = 1 at n=0, well-defined

1. Discrete Unit Step Signal

Definition
u[n] = 1 for n ≥ 0,   0 for n < 0
The unit step turns "on" at n = 0 and remains on for all positive n
Sample Values

u[-2] = 0, u[-1] = 0, u[0] = 1, u[1] = 1, u[2] = 1, ...

2. Discrete Unit Impulse Signal (Kronecker Delta)

Definition
δ[n] = 1 for n = 0,   0 for n ≠ 0
The unit impulse is nonzero ONLY at n = 0
⚠ KEY DIFFERENCE FROM CONTINUOUS: The discrete impulse δ[n] has NO ambiguity at n = 0 — it is exactly 1. The continuous impulse δ(t) is a distribution, not a regular function.

3. Relation Between Impulse and Step

First Difference (Discrete Derivative)
δ[n] = u[n] - u[n-1]
The impulse is the first difference of the step — analogous to derivative in continuous time
Verification

n = 0: u[0] - u[-1] = 1 - 0 = 1 = δ[0]

n = 1: u[1] - u[0] = 1 - 1 = 0 = δ[1]

n = -1: u[-1] - u[-2] = 0 - 0 = 0 = δ[-1]

4. Step as Running Sum of Impulse

Accumulation Form
u[n] = ∑nk=-∞ δ[k]
The step is the cumulative sum of the impulse — analogous to integration in continuous time
Alternative Form (Convolution)
u[n] = ∑∞k=0 δ[n-k]
This is equivalent to convolution of δ[n] with u[n]
Verification of Accumulation

n = -1: ∑-1k=-∞ δ[k] = 0 (no impulse yet)

n = 0: ∑0k=-∞ δ[k] = δ[0] = 1

n = 1: ∑1k=-∞ δ[k] = δ[0] + δ[1] = 1 + 0 = 1

5. Sifting Property

Sifting Property of Impulse
∑∞k=-∞ x[k] δ[k - n0] = x[n0]
Multiplying x[k] by δ[k - n0] "sifts out" the value of x at k = n0
⚠ This property is fundamental to LTI system analysis. It allows us to decompose any signal into shifted impulses and compute the output via convolution.

6. Signal Representation Using Impulses

Any Signal as Impulse Sum
x[n] = ∑∞k=-∞ x[k] δ[n-k]
Every discrete signal can be written as a weighted sum of shifted impulses
Example: Decompose x[n] = {1, 2, 3} for n = 0, 1, 2

x[n] = 1·δ[n] + 2·δ[n-1] + 3·δ[n-2]

Weighted sum of three shifted impulses

7. Summary of Impulse-Step Relations

Impulse from Step

δ[n] = u[n] - u[n-1]
First difference

Step from Impulse

u[n] = ∑nk=-∞ δ[k]
Accumulation

Signal from Impulse

x[n] = ∑ x[k]δ[n-k]
Superposition

1. Discrete Ramp Signal

Definition
r[n] = n · u[n]
The ramp signal equals n for n ≥ 0, and 0 for n < 0
Sample Values

r[-1] = 0, r[0] = 0, r[1] = 1, r[2] = 2, r[3] = 3, r[4] = 4, ...

2. Ramp as Running Sum of Step

Accumulation Relation
r[n] = ∑n-1k=0 u[k]
The ramp is the cumulative sum of the unit step
Verification

n = 3: ∑2k=0 u[k] = u[0] + u[1] + u[2] = 1 + 1 + 1 = 3 = r[3]

n = 4: ∑3k=0 u[k] = u[0] + u[1] + u[2] + u[3] = 1 + 1 + 1 + 1 = 4 = r[4]

3. Step from Ramp (Inverse Relation)

First Difference of Ramp
u[n] = r[n] - r[n-1]
The unit step is the first difference of the ramp
Verification

n = 0: r[0] - r[-1] = 0 - 0 = 0 ≠ u[0]

⚠ This relation holds for n ≥ 1. For n = 0, we need to define r[-1] = 0, and u[0] = 1 follows from the step definition.

n = 1: r[1] - r[0] = 1 - 0 = 1 = u[1]

n = 2: r[2] - r[1] = 2 - 1 = 1 = u[2]

4. Discrete Signum (Sign) Signal

Definition
sgn[n] = 1 for n > 0,   0 for n = 0,   -1 for n < 0
The signum function extracts the sign of the integer index
Sample Values

sgn[-2] = -1, sgn[-1] = -1, sgn[0] = 0, sgn[1] = 1, sgn[2] = 1, ...

5. Signum from Unit Steps

Relation to Step Functions
sgn[n] = u[n] - u[-n]
Subtracting the time-reversed step from the original step yields the signum
Verification

n = 2: u[2] - u[-2] = 1 - 0 = 1 = sgn[2]

n = 0: u[0] - u[0] = 1 - 1 = 0 = sgn[0]

n = -3: u[-3] - u[3] = 0 - 1 = -1 = sgn[-3]

6. Relationship Summary: Step, Impulse, Ramp, Signum

From → To Relation Operation
δ[n] → u[n] u[n] = ∑nk=-∞ δ[k] Accumulation
u[n] → δ[n] δ[n] = u[n] - u[n-1] First difference
u[n] → r[n] r[n] = n · u[n] Multiplication by n
r[n] → u[n] u[n] = r[n] - r[n-1] First difference
u[n], u[-n] → sgn[n] sgn[n] = u[n] - u[-n] Subtraction
The chain: δ[n] → u[n] → r[n] via accumulation; the reverse chain via first differences. sgn[n] is built from two step functions.

7. Continuous vs Discrete Signum

⚠ In continuous time, sgn(0) = 0 is defined but the function is discontinuous at t = 0. In discrete time, sgn[0] = 0 is simply a point value — there is no continuity concern.
Continuous vs Discrete
sgn(t) = 1 (t>0), 0 (t=0), -1 (t<0)  vs  sgn[n] = 1 (n>0), 0 (n=0), -1 (n<0)
Same definition, but discrete version has no ambiguity issues at n = 0

Example 1: Is x[n] = cos(πn/3) Periodic?

Solution

Step 1: Identify ω0 = π/3

Step 2: Check periodicity condition: ω0/(2π) = (π/3)/(2π) = 1/6

Step 3: Since 1/6 is rational, the signal IS periodic.

Step 4: N0 = 2πk/ω0. For k = 1: N0 = (2π)/(π/3) = 6

Periodic with fundamental period N0 = 6 samples

Example 2: Is x[n] = cos(n/3) Periodic?

Solution

Step 1: Identify ω0 = 1/3

Step 2: Check: ω0/(2π) = (1/3)/(2π) = 1/(6π) ≈ 0.0531...

Step 3: Since 1/(6π) is IRRATIONAL, the signal is NOT periodic.

NOT periodic

⚠ This is a very common exam trap! cos(πn/3) is periodic, but cos(n/3) is NOT. The π in the argument is critical.

Example 3: Express x[n] = {2, 0, 5, 3} for n = -1, 0, 1, 2 in Terms of Impulses

Solution

Using x[n] = ∑ x[k]δ[n-k]:

x[-1] = 2, x[0] = 0, x[1] = 5, x[2] = 3

x[n] = 2δ[n+1] + 0·δ[n] + 5δ[n-1] + 3δ[n-2]

x[n] = 2δ[n+1] + 5δ[n-1] + 3δ[n-2]

The zero coefficient at n = 0 means δ[n] doesn't appear in the sum.

Example 4: Compute ∑∞n=-∞ (2n+1)δ[n-3]

Solution (Sifting Property)

By the sifting property: ∑ x[k]δ[k - n0] = x[n0]

Here x[n] = 2n + 1 and n0 = 3

Result = x[3] = 2(3) + 1 = 7

Example 5: Verify u[n] - u[n-2] = δ[n] + δ[n-1]

Solution

Compute u[n] - u[n-2] for various n:

n = 0: u[0] - u[-2] = 1 - 0 = 1

n = 1: u[1] - u[-1] = 1 - 0 = 1

n = 2: u[2] - u[0] = 1 - 1 = 0

n = 3: u[3] - u[1] = 1 - 1 = 0

n = -1: u[-1] - u[-3] = 0 - 0 = 0

Now compute δ[n] + δ[n-1]:

n = 0: δ[0] + δ[-1] = 1 + 0 = 1

n = 1: δ[1] + δ[0] = 0 + 1 = 1

n = 2: δ[2] + δ[1] = 0 + 0 = 0

Both sequences match: {1, 1, 0, 0, ...} Verified!

Quick Reference Card: Continuous vs Discrete

Signal Continuous-Time Discrete-Time
Impulse δ(t) — distribution, undefined at t=0 δ[n] = 1 at n=0 (well-defined)
Step u(t) — often defined as 0.5 at t=0 u[n] = 1 at n=0 (no ambiguity)
Ramp r(t) = t·u(t) r[n] = n·u[n]
Impulse-Step δ(t) = du(t)/dt δ[n] = u[n] - u[n-1]
Step-Impulse u(t) = ∫-∞t δ(τ)dτ u[n] = ∑nk=-∞ δ[k]
Signum sgn(t) — discontinuous at t=0 sgn[n] = u[n] - u[-n] — no issue
Sinusoid periodicity Always periodic for any ω0 Only if ω0/(2π) is rational
Exponential x(t) = Ceαt x[n] = Cβn, β = eα

Common Mistakes to Avoid

⚠ Mistake 1: Saying δ[n] is "infinite at n = 0" — it is exactly 1.
⚠ Mistake 2: Assuming all discrete sinusoids are periodic — check the rationality of ω0/(2π) first!
⚠ Mistake 3: Confusing x[n] = Cβn with x(t) = Ceαt — discrete uses power notation, continuous uses exponent notation.
⚠ Mistake 4: Forgetting that u[n] = 1 at n = 0 (not 0.5 as sometimes defined in continuous time).
⚠ Mistake 5: Writing δ[n] = u[n] - u[n-1] as δ[n] = u[n+1] - u[n] — the order matters!
