Logical Equivalence, Validity & Satisfiability

Artificial Intelligence — Logical Agents

Three Fundamental Concepts

Three properties classify every propositional logic sentence by its behavior across all possible models (truth assignments). Understanding these is essential for inference, automated reasoning, and complexity analysis.

Logical Equivalence (≡)
Same truth value in ALL models
α ≡ β means M(α) = M(β)
Validity (⊤)
True in EVERY model
α is a tautology if M(α) = Universe
Satisfiability
True in AT LEAST ONE model
α is satisfiable if M(α) ≠ ∅

Logical Equivalence (≡)

Formal Definition
α ≡ β ⟺ M(α) = M(β)
Two sentences are logically equivalent if they have exactly the same set of models (truth assignments that make them true).

Using Equivalence in Wumpus World

The Wumpus KB contains biconditionals like B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁). Using biconditional elimination and then implication elimination:

B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁) ≡ (B₁,₁ ⇒ (P₁,₂ ∨ P₂,₁)) ∧ ((P₁,₂ ∨ P₂,₁) ⇒ B₁,₁) ≡ (¬B₁,₁ ∨ P₁,₂ ∨ P₂,₁) ∧ (¬(P₁,₂ ∨ P₂,₁) ∨ B₁,₁) ≡ (¬B₁,₁ ∨ P₁,₂ ∨ P₂,₁) ∧ ((¬P₁,₂ ∧ ¬P₂,₁) ∨ B₁,₁) ≡ (¬B₁,₁ ∨ P₁,₂ ∨ P₂,₁) ∧ (¬P₁,₂ ∨ B₁,₁) ∧ (¬P₂,₁ ∨ B₁,₁)

This CNF form is used for resolution-based inference.

Validity (Tautology)

Formal Definition
α is valid ⟺ M(α) = ALL MODELS ⟺ α ≡ True
A sentence is valid (a tautology) if it is true under every possible truth assignment.

Common Valid Sentences

  • Law of Excluded Middle: P ∨ ¬P
  • Law of Non-Contradiction: ¬(P ∧ ¬P)
  • Implication to Self: P ⇒ P
  • Implication Tautology: P ⇒ (Q ⇒ P)
  • Peirce's Law: ((P ⇒ Q) ⇒ P) ⇒ P
  • Modus Ponens Form: ((P ⇒ Q) ∧ P) ⇒ Q
  • Modus Tollens Form: ((P ⇒ Q) ∧ ¬Q) ⇒ ¬P
Validation by Truth Table: (P ⇒ Q) ∨ (Q ⇒ P)

Satisfiability & Unsatisfiability

Formal Definition
α is satisfiable ⟺ M(α) ≠ ∅ ⟺ ∃ model where α is true
α is unsatisfiable ⟺ M(α) = ∅ ⟺ α ≡ False
A sentence is satisfiable if at least one model makes it true. It is unsatisfiable (a contradiction) if no model makes it true.

SAT: The First NP-Complete Problem

In 1971, Stephen Cook proved that SAT (Boolean satisfiability) is NP-complete. This means:

  • Every problem in NP can be reduced to SAT in polynomial time
  • If SAT could be solved in polynomial time, then P = NP
  • Many practical AI problems reduce to SAT: planning, constraint satisfaction, circuit verification

Key Relationships Between Concepts

1. Deduction Theorem
α ⊧ β ⟺ (α ⇒ β) is valid
Proof: If α ⊧ β, then every model making α true also makes β true. Thus in every model, either α is false or β is true, which is exactly α ⇒ β being true in all models.
2. Validity ↔ Unsatisfiability
α is valid ⟺ ¬α is unsatisfiable
If α is true in all models, ¬α is false in all models (unsatisfiable). Conversely, if ¬α has no satisfying model, α is true everywhere.
3. Satisfiability ↔ Non-Validity
α is satisfiable ⟺ ¬α is not valid
If there exists a model where α is true, then ¬α is false in that model, so ¬α is not valid.
4. Entailment by Contradiction (Refutation)
KB ⊧ α ⟺ (KB ∧ ¬α) is unsatisfiable
If assuming ¬α leads to a contradiction with KB, then α must follow from KB. This is the basis of proof by contradiction and resolution refutation.

Example 3: Refutation Proof in Wumpus World

We want to prove KB ⊧ ¬P₁,₂ using the refutation method.

Step 1: Add ¬(¬P₁,₂) = P₁,₂ to the KB.

Step 2: Show the resulting set is unsatisfiable.

Key rules in the KB:

  • R₁: ¬P₁,₁
  • R₂: B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁) which gives: ¬B₁,₁ ∨ P₁,₂ ∨ P₂,₁ and (¬P₁,₂ ∨ B₁,₁) and (¬P₂,₁ ∨ B₁,₁)
  • Observation: ¬B₁,₁

With P₁,₂ added: From (¬P₁,₂ ∨ B₁,₁) and P₁,₂ we get B₁,₁ by resolution. But we have ¬B₁,₁. Resolution of B₁,₁ and ¬B₁,₁ gives the empty clause (contradiction).

KB ∧ P₁,₂ is unsatisfiable → KB ⊧ ¬P₁,₂ ✓

Example 5: KB Consistency Check

An agent receives conflicting sensor readings. Check if ⟨B₁,₁, ¬P₁,₁, B₁,₁⇔(P₁,₂∨P₂,₁), ¬P₁,₂, P₂,₁⟩ is consistent.

From B₁,₁⇔(P₁,₂∨P₂,₁) and B₁,₁, we get P₁,₂∨P₂,₁ must be true. But we have ¬P₁,₂, so P₂,₁ must be true. The KB includes P₂,₁. So there is a model: B₁,₁=T, P₁,₂=F, P₂,₁=T. The KB is satisfiable.

Consistent — the agent's beliefs are satisfiable.

But if we add ¬P₂,₁ as well (another sensor), then the KB becomes unsatisfiable: we'd have both P₂,₁ and ¬P₂,₁.
