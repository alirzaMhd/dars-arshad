Problem Setup

Dynamic Tables (e.g., Python lists, C++ std::vector) grow automatically when full. The TABLE-INSERT algorithm doubles the table size when full, copying all existing items.

Algorithm (CLRS)

TABLE-INSERT(T, x):   if T.size == 0:     allocate T.table with 1 slot   if T.num == T.size:     allocate new table with 2·T.size slots     copy all items; free old table     T.table = new; T.size = 2·T.size   insert x; T.num++

Cost Model

Cost = 1 (no expansion) or i (expansion at i-th insertion: copy i−1 items + insert 1)
