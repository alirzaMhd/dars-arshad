Regular Grammars

Right-Linear and Left-Linear Grammars — Complete Guide

What is a Regular Grammar?

A regular grammar is a grammar that is either exclusively right-linear or exclusively left-linear. It generates regular languages.

Right-Linear Grammar:
A → xB or A → x
where A, B ∈ V (variables), x ∈ Σ* (terminals). The variable appears on the RIGHT side.
Left-Linear Grammar:
A → Bx or A → x
where A, B ∈ V (variables), x ∈ Σ* (terminals). The variable appears on the LEFT side.
Important: A grammar that mixes right-linear and left-linear rules (some rules with variable on right, others with variable on left) is NOT a regular grammar — it's a general linear grammar.

Formal Definition

A regular grammar G = (V, Σ, P, S) where:

  • V is a finite set of variables (non-terminals)
  • Σ is a finite set of terminal symbols (alphabet)
  • P is a set of production rules of the form A → xB or A → x (right-linear) OR A → Bx or A → x (left-linear)
  • S ∈ V is the start variable

Key Equivalence:
For every right-linear grammar, there exists an equivalent left-linear grammar (and vice versa)
Both generate exactly the same class of languages: regular languages.

Example: Right-Linear Grammar

G₁: Right-Linear Grammar

S → aaS | aB

B → bbB | b

Language: L(G₁) = {a^(2n+1) · b^(2m+1) : n, m ≥ 0}

Explanation: S generates odd number of a's, then B generates odd number of b's.

Regular expression: (aa)*a(bb)*b

Example: Left-Linear Grammar

G₂: Left-Linear Grammar

S → Bbbbb

B → Bb | A

A → Aaaa | λ

Language: L(G₂) = {a^n · b^m : n ≥ 2, m ≥ 3}

Regular expression: a²a*b³b* = a²a*b³b*

Example 1: Mixed Grammar (NOT Regular)

G: Mixed Linear Grammar

S → aS | aB

B → Bb | b

Analysis: This grammar has BOTH right-linear rules (S → aS) and left-linear rules (B → Bb).

This is a LINEAR grammar, but NOT a regular grammar.

L(G) = {a^n · b^m : n ≥ 1, m ≥ 1}

Example 2: Converting Regular Expression to Grammar

RE: r = (aa)*(bb)*

Right-Linear Grammar:

S → aaS | A

A → bbA | λ

L(G) = {a^(2n) · b^(2m) : n, m ≥ 0}

Example 3: Grammar for {a^(2n) · b^(2m)}

Two equivalent grammars

Right-linear G₁:

S → aaS | A

A → bbA | λ

Left-linear G₂:

S → A bb

A → A bb | B

B → aa B | λ

Both generate the same language L = {a^(2n) · b^(2m) : n, m ≥ 0}

Practice: Identify Grammar Type

Which grammar is regular?

(1) S → aSb | aS | b

(2) S → aS | bA, A → bA | a

(3) S → SA | a, A → bA | a

(4) S → aS | b | λ

Answer: (2) and (4) are right-linear (regular). (1) is context-free but not regular. (3) mixes forms.
