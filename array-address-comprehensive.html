ARRAY ADDRESS CALCULATION

Data Structures — Complete Guide for 20/20 Exam

1D Array Address Calculation

Formula:
Addr(A[i]) = α + n × (i - L)
α = base address, n = sizeof(Type), i = index, L = lower bound
Example 1: Float Array

In C: float f[100] — defines 100 elements (indices 0 to 99)

sizeof(float) = 4 bytes

Total memory = 100 × 4 = 400 bytes

Example 2: Address Calculation

Array A[1..20], α = 1000, sizeof(int) = 4

Addr(A[20]) = 1000 + 4 × (20 - 1) = 1000 + 76 = 1076

Note: If array starts at index 0, formula becomes: α + n × i

Key Points

• Array is a linear data structure

• Elements stored in contiguous memory

• Random access in O(1) time

Variables

• α = base address

• n = element size (bytes)

• L = lower bound

• i = target index

2D Array Address Calculation

Row Major Order

Addr(A[i,j]) = α + n × [i(U₂-L₂+1) + (j-L₂)]

Elements stored row by row:

A[1,1] A[1,2] A[2,1] A[2,2]

Column Major Order

Addr(A[i,j]) = α + n × [(i-L₁) + (U₁-L₁+1)(j-L₂)]

Elements stored column by column:

A[1,1] A[2,1] A[1,2] A[2,2]

Example: 2D Array A[1..3, 1..2]

Row Major: A[1,1] A[1,2] A[2,1] A[2,2] A[3,1] A[3,2]

→

Column Major: A[1,1] A[2,1] A[3,1] A[1,2] A[2,2] A[3,2]

Calculation Example

Array A[0..2, 0..2], α = 1000, sizeof(int) = 4

Find Addr(A[1,2]) using Row Major:

Addr = 1000 + 4 × [1 × (2-0+1) + (2-0)]

Addr = 1000 + 4 × [1 × 3 + 2] = 1000 + 4 × 5 = 1020

⚠ Important: L₁, U₁ = lower/upper bounds of row dimension

L₂, U₂ = lower/upper bounds of column dimension

3D Array Address Calculation

Row Major Order

Addr(A[i,j,k]) = α + n × [i(U₂-L₂+1)(U₃-L₃+1) + j(U₃-L₃+1) + k]
Simplified for 0-indexed: α + n × [i×cols×depth + j×depth + k]

Column Major Order

Addr(A[i,j,k]) = α + n × [i + (U₁-L₁+1)(j + (U₂-L₂+1)k)]
Simplified for 0-indexed: α + n × [i + rows×(j + cols×k)]
Example: 3D Array f[0..4, 0..9, 0..14]

α = 1000, sizeof(float) = 4

Find element f[2,3,4] using Row Major:

First, calculate position: (2×10×15) + (3×15) + 4 = 300 + 45 + 4 = 349

Addr = 1000 + 4 × 349 = 1000 + 1396 = 2396

Example: Column Major

Same array, find f[2,3,4] using Column Major:

Position: 2 + 5×(3 + 10×4) = 2 + 5×43 = 2 + 215 = 217

Addr = 1000 + 4 × 217 = 1000 + 868 = 1868

Special Matrices

Lower Triangular

A[i,j] = 0 when i < j

Non-zero elements: n(n+1)/2

B[k] = A[i,j] where k = i(i-1)/2 + j

Upper Triangular

A[i,j] = 0 when i > j

Non-zero elements: n(n+1)/2

B[k] = A[i,j] where k = i + j(j-1)/2

Diagonal Matrix

A[i,j] = 0 when i ≠ j

Non-zero elements: n

B[k] = A[i,i] where k = i

Tridiagonal Matrix

A[i,j] = 0 when |i-j| > 1

Non-zero elements: 3n-2

B[k] = A[i,j] where k = 2i + j - 2

Solved Examples (Exam Practice)

Example 1: 1D Array

Array A[50], α = 2000, sizeof(int) = 4

Find Addr(A[25]):

Addr = 2000 + 4 × 25 = 2000 + 100 = 2100

Example 2: 2D Row Major

Array A[0..3, 0..4], α = 1000, sizeof(char) = 1

Find Addr(A[2,3]):

Addr = 1000 + 1 × [2 × (4-0+1) + 3]

Addr = 1000 + [2 × 5 + 3] = 1000 + 13 = 1013

Example 3: 2D Column Major

Array A[0..3, 0..4], α = 1000, sizeof(char) = 1

Find Addr(A[2,3]):

Addr = 1000 + 1 × [2 + (3-0+1) × 3]

Addr = 1000 + [2 + 4 × 3] = 1000 + 14 = 1014

Example 4: 3D Array

Array A[0..2, 0..3, 0..4], α = 5000, sizeof(int) = 4

Find Addr(A[1,2,3]) using Row Major:

Position = (1 × 4 × 5) + (2 × 5) + 3 = 20 + 10 + 3 = 33

Addr = 5000 + 4 × 33 = 5000 + 132 = 5132

Example 5: Triangular Matrix

Lower triangular 4×4 matrix stored in array B

Find where A[3,2] is stored:

k = i(i-1)/2 + j = 3×2/2 + 2 = 3 + 2 = 5 (index 5 in B)

Elements before row 3: 1+2 = 3 elements

Position in row 3: j = 2

Total: 3 + 2 = 5

Example 6: Memory Calculation

Array A[10,20,30], sizeof(double) = 8

Total memory = 10 × 20 × 30 × 8 = 48,000 bytes

Always multiply dimensions × element size
