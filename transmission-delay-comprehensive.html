TRANSMISSION DELAY

Physical Layer — Complete Guide for Exam

What is Transmission Delay?

Transmission delay is the time required to push all bits of a packet onto the wire. It depends on two factors: the size of the packet and the bandwidth of the link.

Think of it like pouring water through a pipe — the larger the volume of water (packet size) and the narrower the pipe (lower bandwidth), the longer it takes to push all the water out.

Key Intuition

Packet Size ↑
Transmission Delay ↑

More bits to push onto the wire takes longer.

Bandwidth ↑
Transmission Delay ↓

Faster link sends bits more quickly.

Analogy

Like pushing a train of cars through a tunnel — longer trains take more time to clear the tunnel entrance.

NOT affected by
Distance or speed of light

Those factors affect propagation delay, not transmission delay.

Physical Meaning

When a router or host wants to send a packet onto a link, it must serialize all the bits of the packet one after another onto the medium. The time from the first bit entering the link to the last bit entering the link is the transmission delay.

Core Formula

Transmission Delay Formula
Ttrans = L / B
Ttrans = Transmission delay (seconds)
L = Packet length in bits
B = Bandwidth in bits per second (bps)

Derived Formulas

Find Packet Size
L = Ttrans × B
Find Bandwidth
B = L / Ttrans
Total time to send N packets (pipelined)
Ttotal = (N × L) / B
When packets are sent back-to-back on the same link.

Total End-to-End Delay

Complete Delay Formula
Ttotal = Tproc + Tqueue + Ttrans + Tprop
Tproc = Processing delay
Tqueue = Queuing delay
Ttrans = Transmission delay (L/B)
Tprop = Propagation delay (d/s)

Worked Examples

Example 1: 1500 Byte Packet on 100 Mbps Link
Given
L = 1500 bytes = 1500 × 8 = 12,000 bits
B = 100 Mbps = 100,000,000 bps
Solution
Ttrans = 12,000 / 100,000,000 = 0.00012 s = 120 μs
Example 2: 10,000 Bit Packet on 1 Gbps Link
Given
L = 10,000 bits
B = 1 Gbps = 1,000,000,000 bps
Solution
Ttrans = 10,000 / 1,000,000,000 = 0.00001 s = 10 μs
Example 3: Find Packet Size
Given
Ttrans = 0.001 s = 1 ms
B = 10 Mbps = 10,000,000 bps
Solution
L = Ttrans × B = 0.001 × 10,000,000 = 10,000 bits = 1,250 bytes
Example 4: Compare Different Packet Sizes (100 Mbps Link)

Example 5: Total Time for Multiple Packets
Given
5 packets, each 1,000 bits
Link bandwidth = 10 Mbps
Packets sent back-to-back (pipelined)
Solution
Ttotal = (5 × 1,000) / 10,000,000 = 5,000 / 10,000,000 = 0.0005 s = 500 μs
Individual packet transmission delay = 100 μs, but all 5 overlap on the link.

When Does Each Dominate?

Transmission dominates when:
  • Large packets (e.g., video, file transfers)
  • Low bandwidth links (e.g., dial-up)
  • Short distances (LAN, localhost)
Propagation dominates when:
  • Small packets (e.g., ACKs, DNS queries)
  • High bandwidth links (e.g., fiber backbone)
  • Long distances (satellite, transatlantic)

Exam Tips

  • Always convert bytes to bits before dividing by bandwidth.
  • Watch out for units: Mbps ≠ MBps (Megabits vs Megabytes per second).
  • Transmission delay is per-hop — it occurs at every router along the path.
  • For store-and-forward routers, each hop adds its own transmission delay.
  • Bandwidth is always in bits per second (bps), never Bytes per second in formulas.
  • Total delay = proc + queue + trans + prop. Don't confuse transmission with propagation!

Common Mistakes

❌ Using Ttrans = L / B when the question asks for propagation delay. Propagation = distance / speed of signal.
❌ Forgetting to multiply bytes by 8. If L is given in bytes, Lbits = L × 8.
❌ Confusing Mbps (10⁶) with MBps (10⁶ × 8). In networking, "bps" = bits per second.
❌ Not accounting for store-and-forward at intermediate routers — each router must receive the entire packet before forwarding.

Store-and-Forward Example

3-hop path (2 routers)
Packet size = 10,000 bits
Each link bandwidth = 10 Mbps
Each link propagation delay = 1 ms
Total Delay Calculation
T = 3 × (10,000 / 10,000,000) + 3 × 0.001 = 3 × 1 ms + 3 × 1 ms = 6 ms
3 × Ttrans (one per hop) + 3 × Tprop (one per link)
The packet must be fully received at each router before forwarding.
